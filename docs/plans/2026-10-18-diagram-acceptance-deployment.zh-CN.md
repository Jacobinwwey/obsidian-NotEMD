## 范围与设计

继续已完成的 ER 与其他五项跨图型修复，不将尚未实施的 33 类路线图冒充完成。建立离线验收文件夹，包含成对真实 PNG 导出、原始 SVG／来源 JSON、明确基线出处，以及文字可选择、键盘可操作的双语 HTML 对比页。优化前来自 Git HEAD 源码，不制作人为劣化图片。语义升级案例明确记录等价来源事实的旧 legacy 投影与新类型化载荷；其他案例前后输入完全一致。可恢复的环／森林结构与声明坐标下缺失的步骤必须保留为真实可导出图，并在图内标注来源问题；不能用诊断面板替代出图，也不能编造业务内容。保留结构／安全边界校验。

只有 HTML 模型不能证明导出质量；批量覆盖旧示例会破坏出处。采用可重复运行的生成器与全新时间戳目录，是最小完整方案。用户已授权直接执行并更新 1Knowledge，无需额外审批停顿。
