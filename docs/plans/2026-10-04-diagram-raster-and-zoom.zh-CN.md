# PNG 分辨率保留与逐图预览缩放

## 问题与契约

真实 architecture 回执中，Drawnix、HTML、SVG、PDF 成功，PNG 失败。4772 × 16749 CSS 像素的 SVG 在 300 PPI 下需要 14913 × 52341 像素，单份 RGBA 约占 3.12 GB；单 Canvas 编码返回 null。初次按内存预算缩小输出的方案得到约 44 PPI，违反既有 72–600 PPI 契约，已否决。默认仍为 300 PPI。SVG 是矢量格式，PPI 在栅格化时生效。

## 实现

保留请求的像素尺寸。小图继续使用原生 Canvas 编码；大图 PNG 或原生编码返回 null 时，改为有界 SVG 视口、扫描行条带与流式 zlib 编码。条带最多 16 MiB，单块最多宽 8192 像素、高 512 行，实际条带高度还受字节预算约束。将原 SVG 根节点保留为嵌套视口，保留 viewBox 原点、纵横比对齐、百分比坐标、定义和 Unicode 标签。直接写入 IHDR、pHYs，再输出流式 IDAT。释放 Canvas、图像源、对象 URL 和消息端口。压缩批次之间通过消息任务让出执行，避免后台定时器节流。API 返回压缩后的字节，压缩产物所占内存仍随文件大小增长。JPEG 没有生产调用方，禁止静默降低 PPI；其原生 Canvas 容量仍有限制。

每个图形预览独立管理显示视口：缩小、百分比、放大、适应窗口、实际大小。适应窗口同时考虑宽高。支持按钮、+/-、0 适应、1 实际大小、Ctrl/Command＋滚轮和拖拽；普通滚轮仍滚动。内联 SVG、JSON Canvas 与同源 iframe 共用控制器。导出使用原始产物，显示缩放不改变导出分辨率。重绘或关闭时清理观察器与监听器，保留沙箱策略及链接、表单和可编辑元素的交互。

## 验证与发布

单测检查 PNG 尺寸与密度、解压后跨块扫描行顺序、UTF-8 标签、非零 viewBox 保留、资源释放和失败时禁止隐性降低 PPI。小图在 300 PPI 下仍为 1250 × 625。浏览器像素对比覆盖 300 PPI 的横纵拼接与 600 PPI；末端半像素可能出现外边缘裁剪差异，内部通道差异最多一级。视口检查覆盖多面板独立状态、内联及 iframe 图形、键盘、滚轮、平移、异步替换与销毁后的监听器，按钮最小 44 像素。

通过 Obsidian CLI 在已打开的 1Knowledge 中验证最终正常构建。复用既有生成结果，不请求模型；使用防冲突的带编号同目录文件，对原笔记与已有产物比较哈希；缓存回执放在 notemd_assert。保留初次低 PPI 文件及用户编辑。逐项验证 PNG IHDR、pHYs、全部块 CRC、完整 zlib 流与扫描行数，避免一次解码为 3.12 GB 缓冲。正常导出可增加历史记录，用户配置必须保留。直接编写各语言手册与图表页面。推送 main 前需要最新构建、全量 Jest、lint 增量门禁、UI/render-host 审计及网站验证通过。保留已发布的 1.9.9 资产。

前端法则证据位于 .cache/diagram-preview-viewport；未测量的对比度及延迟指标保持未知。已安装的 ui-ux-pro-max 缺少其引用的搜索脚本，已按书面规则执行。

最终证据：299 个 Jest 套件通过，2891 项测试通过、1 项跳过。构建、lint 增量门禁、UI 文案及 render-host 审计、全部语言的网站构建和产物审计通过。导航审计覆盖 96 个页面，零失败。最终安装的正常构建在 1Knowledge 导出 architecture.zh-CN_drawnix-5.png，尺寸为 14913 × 52341 像素，密度为 11811 像素/米（299.9994 PPI），耗时约 77 秒。全部 5111 个块 CRC 与 52341 条扫描行的流式校验通过。原文件和既有产物哈希保持一致，未调用模型。
