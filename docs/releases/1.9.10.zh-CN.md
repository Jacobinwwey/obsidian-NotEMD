# Notemd v1.9.10

## 重点

本补丁根据社区扫描分诊与 ponytail 架构审查，修复真实用户预览、设置和桌面演示链路。扫描数量不等于已确认缺陷数；完整源码审查区分已复现问题、误报与剩余风险。

## 安全与兼容

- 导入 SVG 在浏览器导出与宿主挂载前净化，移除活动 HTML、事件属性、不安全引用和外部 CSS 资源。保留中文向量标签、渐变、marker 和各面板独立样式，每个图形具有自己的 CSS 作用域。
- 移动端加载插件不再提前导入本地服务器的 Node 依赖；桌面专属命令与设置使用已有平台检测边界。
- 演示 HTML 服务仅监听 127.0.0.1，校验 Host/Origin 和目录包含关系，明确 UTF-8 类型。并发消费者共享监听器，最后释放时关闭；卸载取消待启动实例。正式绑定直接处理端口占用，不再分离探测窗口。
- Mermaid 预览锁定 strict 配置并升至 11.17.2；浏览器 SVG 权限边界使用 DOMPurify 3.4.11。删除未使用的直接 lodash 运行时/类型依赖与重复维护的 builtin-modules 包。

## 设置与升级

仅设备 provider 现改用 Obsidian 的 Vault 隔离本地存储，保留已有配置。如果曾使用旧版设备共享列表，请在当前 Vault 设置中选择 **导入旧版仅设备 provider**。导入是显式操作，保留旧列表，不自动复制到其他 Vault，可替换未使用的默认项。存储失败会拒绝保存，防止静默丢失本地凭据。这是本地隔离，不是加密，也不是跨存储原子事务。

local-only 开关现在正常显示在有效 provider 下。收藏保存失败恢复状态并提示错误；复制仅在完成后提示成功。用户明确删除遵守 Vault 回收站偏好。

停止活动任务，备份 Vault，安装同一 Release 的 main.js、manifest.json、styles.css 并重载。README.md 同样作为必需资产提供。保留设置、笔记与既有产物，批处理前先验证一篇笔记。全部受影响翻译直接编写，没有使用翻译 API 或 LM Studio。

## 保留的图表行为

PNG 兼容默认开启：保留用户请求原图，仅当 Obsidian 解码失败时增加已验证的低 PPI 副本。导出 PPI 为 72–600，默认 300；SVG 不存在栅格 PPI。保留独立缩放和各类型多格式导出。请求文件位于源文件旁或直接进入指定输出目录，中间文件进入指定 cache 目录或相邻 notemd_assert。

Drawnix 保留明确的有向关系，不设置固定总量或每节点配额；按实测连线与标签几何扩展布局。旧 1.9.9 指南中的配额属于该版本原始历史，不是当前策略。PPTX/MP4 等演示导出维持独立设置与依赖。

## 验证与限制

发布验收记录 fresh build、全量回归、lint/UI/render-host 审计、真实 1Knowledge CLI 及本地化网站检查。社区审查见 docs/audits/2026-10-04-community-ponytail.zh-CN.md。same-origin Mermaid bridge、Obsidian 1.13 前向设置搜索和剩余导出工具链 advisories 仍是跟踪限制。纯 Node/offline SVG 不会自动进行浏览器净化。当前 main.js 仍为自包含包装，不代表重型运行时已独立隔离。原生 Drawnix 调整布局后，静态跨分支箭头仍可能脱离附着。
