# Notemd v1.9.12

## 重点

图形预览在没有错误时，默认收起整个诊断区域。紧凑摘要保留标题和严重级别计数，为图形留出更多空间。

有错误时展开诊断区域，且**仅错误分组自动展开**；警告和信息分组继续收起。诊断同时按标签和严重级别分组，避免一个错误把同标签下其他低级别消息一起展开。全部消息和建议仍可按需查看。

## 兼容与升级

本补丁仅调整诊断展示。保留 1.9.11 的 Drawnix 排布、通用 PDF 导出修复和会话日志保留。没有诊断时不显示该区域，原生折叠控件保留键盘操作与可见焦点。

安装 1.9.12 同一版本的 `main.js`、`manifest.json` 和 `styles.css` 后重载，同时提供 `README.md`。保留现有文件与设置，已公开的 1.9.11 资产不变。

## 文档与验证

同步更新全部受影响语言的 README 手册、网站图形/配置指南和发布页。翻译均直接编写，不调用翻译 API 或 LM Studio。回归覆盖默认收起、仅错误展开、同标签混合级别、重复标签、完整诊断与空诊断。构建、完整 CI、语言及网站检查记录于成对发布验收文档。
