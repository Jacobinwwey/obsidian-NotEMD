# Notemd v1.9.11

## 重点

本补丁改善复杂 Drawnix 图形的排布，修复通用 SVG 转 PDF 兼容问题，保留会话内任务日志，并将预览诊断按标签分组、默认收起。

## 图形排布与诊断

- 按实际尺寸和关系距离，将关联密切的同级分支与根节点放得更近。连线路由对重叠和交叉施加代价，使用分离的端点接口。保留全部节点、父子关系、标签和明确关系，不设置关系配额。
- 冻结的 `architecture.zh-CN` 样本保留全部 179 个节点和 24 条明确关系。关系连线总长从 152,805 降至 40,582.5，两两共线重叠长度从 12,163.5 降至 32，垂直交叉从 141 降至 20。统计不包含层级分支，也不代表全局最优或完全无交叉。
- Artifact 诊断按标签分组并默认收起。每组展示严重级别计数，展开后可查看所有消息与建议。顶部总计始终可见，后续新增的未知标签也无需修改注册表即可显示。

## PDF 稳定性与兼容

SVG 转 PDF 库会错误拆分 `:is(...)` 等函数选择器内的逗号，导致净化后的合法样式在导出时失败。PDF 准备阶段现在通过隔离文档中的浏览器层叠规则解析声明，保留优先级、重要性、内联覆盖、继承颜色和可复用 SVG 定义。成功或失败后均清理临时文档，原有 SVG 净化边界保持不变。

坐标转换前补全缺失的 viewBox。超过 PDF 库单边 14,400 点上限的页面等比例缩放，保留宽高比和向量图形。回归覆盖嵌套 SVG、复杂选择器、渐变、裁剪、中文文字、`<use>` 继承及无外部请求。这些共享修复适用于其他复杂 SVG，也兼容旧缓存产物。

## 日志与升级

插件会话内，侧栏日志跨任务阶段、后续动作、预览重开和侧栏重建持续累积。使用**清空日志**显式重置记录，进度弹窗各阶段也保留日志。此改动不提供插件重载后的日志持久化。

安装本次发布同一版本的 `main.js`、`manifest.json` 和 `styles.css` 后重载，同时提供 `README.md`。保留现有设置、笔记和生成文件。所有更新的翻译均直接编写，未调用翻译 API 或 LM Studio。

## 验证与限制

恢复验收记录了生产构建、全量回归、lint/UI/render-host 审计以及 Obsidian 1.13.7 官方 CLI 验证。真实样本完成 Drawnix、HTML、SVG、PNG 和 PDF 导出，PDF 运行时提取到全部 179 个节点标签。原先失败的 SVG 也无需重新生成即可成功导出。发布检查另覆盖诊断默认收起和网站全部 34 个语言版本。

原生 Drawnix 跨分支箭头仍使用静态坐标，重排后可能脱离节点。现有 PNG 兼容、导出目录、provider 设置、工作流串联和演示导出契约保留。不宣称 PDF 转换器支持第三方 SVG 的所有可能特性。
