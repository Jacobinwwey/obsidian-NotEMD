# Notemd v1.9.9

## 重点更新

- **一次生成多种图表。** 各类型独立保存输出选择。例如，同时生成 Drawnix 源文件与 PDF，以及流程图 SVG，不改变其他类型的格式。取消勾选保留偏好；不选任何类型时自动分析原文。
- **通过实时预览选择。** 紧凑的类型与格式菜单替代平铺列表。复选框控制参与生成，点击名称选中该类型并打开格式设置；悬停或键盘聚焦更新旁侧预览，不保存设置。支持格式优先，不兼容项保留并置灰。
- **在原文旁找到输出。** 所选文件使用包含类型的名称，如 `topic_drawnix.pdf`、`topic_flowchart.svg`。重名追加序号，不覆盖已有文件；继续支持自定义输出目录。

## 修复与鲁棒性

- 冻结原文、选择及执行设置，顺序生成多种类型。一种失败不阻断其他类型；取消停止尚未开始的类型，保留完成文件，并使用连续总进度。
- 为每种类型保存生成规格及逐格式交付收据。从预览、历史或维护 CLI 重试失败导出，无须再次请求模型。生成尚未完成就失败时，仍须重新生成该类型。
- 恢复记录、渲染缓存、写入暂存及可选附件存入可配置的 Vault 相对中间目录，默认各原文旁的 `notemd_assert/`。更改目录只影响新任务；保留仍被既有产物引用的文件。
- 继续读取 v1/v2 导出记录，新写 v3 将缓存标识与交付名称分离。恢复校验 SHA-256 收据，保留用户修改的输出；命名分配覆盖并发及大小写冲突。
- Drawnix 概览最多显示六条带标签的核心有向关系，每节点最多三条。省略关系及原因保存在原生元数据中；局部路线减少不必要的长连接线。
- 修复矢量 PDF 中 Drawnix 关系方框文字不可见的问题。转换 PDF 前规范化旧缓存 SVG 标签，避免白色文字描边覆盖字形。
- 在生成、存储和恢复链路保持 UTF-8；修复真实 Obsidian 的恢复记录写入，并在输入边界规范化对象形式引文。修复面向用户操作流程，而非单独修改演示产物。
- 保持 Escape 作用域、键盘焦点、串行设置保存与独立窗口文档边界。类型列表滚动时预览保持可见，菜单关闭后归位。

## 文档与格式边界

- 更新手册、README、首页与升级指南，覆盖已有 34 个网站语言和 31 份 README；译文全部直接撰写，未调用翻译 API、LM Studio 或其他翻译模型。这不等于独立母语人士审核，索引政策保持不变。
- **图形 HTML** 包含可缩放图形；**结构化摘要 HTML** 展示文字、结构与引文。“可编辑 HTML/SVG”是渲染器名称，不是浏览器编辑器；编辑请使用原生源文件。
- 演示导出继续保留独立设置、依赖库及环境检查。PPTX、MP4 属于该流程，不加入图形格式选择器。
- 已有的 33 项可执行图表、36 个 provider 预设和 21 个插件 UI 语言，不重复计为 1.9.9 新增目录。

## 验证与证据

- 发布候选版本已通过本地 298 个 Jest 套件：2,874 项通过、1 项既有跳过；插件与文档构建通过，包含 34 种语言的 850 个网站指南页面和 816 个浏览器导航场景。发布提交须通过 Linux、Windows 验证后才能公开。
- 在已打开的 `1Knowledge` Vault 中通过 CLI，生成 Nested、流程图和 Drawnix 共九个同目录文件；全部交付哈希匹配，原文未变，设置已恢复。一次模型请求超时未阻断其他类型，单独重试 Drawnix 后完成四种格式。
- 真实浏览器覆盖 320px／900px 菜单、悬停与聚焦不写配置、独立格式、Escape、预览移动及滚动。PDF 六条关系标签均经文字提取和视觉检查。
- [实施证据](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/main/docs/multiple-diagrams-implementation.zh-CN.md)及 [1.9.9 验收记录](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/main/docs/maintainer/release-1.9.9-acceptance.zh-CN.md)保留验证边界与发布收据。

## 升级与已知限制

- 停止活动任务并备份 Vault。从同一 Release 安装 `main.js`、`manifest.json`、`styles.css`，保留设置和生成文件，再重载 Obsidian。先检查一篇笔记，再执行大批量任务。
- 兼容读取旧单类型偏好，在编辑时迁移。未知配置版本保留存储，不将其误写为已知版本。
- 顺序生成用于限制 provider 和渲染器争用；选择更多类型会增加总耗时。取消不等于回滚，也不能保证 provider 停止生成或计费。
- Drawnix 跨分支箭头仍为静态关系，在编辑器重排后可能脱离节点。本次没有新增物理移动设备或 Obsidian 0.15.0 的兼容性验证。

必需发布资产：`main.js`、`manifest.json`、`styles.css`、`README.md`。
