# Notemd v1.9.7

Release date: 2026-08-30

## Highlights

- Fixed Mermaid quadrant labels that displayed a structural `[` copied from the coordinate array.
- Fixed editable HTML/SVG lane-grid diagrams whose summaries, headers, cells, connectors, or edge labels could overlap.
- Added collision-aware orthogonal routing and protected header spacing so long text remains readable without manual horizontal scrolling.
- Added a complete real-Vault example set under `docs/diagram-examples/`, with bilingual Markdown inputs, generated SVG/PNG results, and a machine-readable manifest.
- Updated the repository docs, maintainer manuals, and GitHub Pages diagrams guide with the repair contracts and real-run evidence.
- Replaced the retired Star History embed in every README locale with the token-free `star-history.dera.page` responsive chart format documented by SimRepo.

## Root Cause And Fix

The quadrant defect came from applying legacy flowchart quote/shape repair to a `quadrantChart` block. A valid point such as `"Docs gallery": [0.32, 0.68]` could be rewritten as visible label text. Mermaid family detection now gates those legacy rules, and a family-scoped normalizer removes only an unmatched trailing bracket from quadrant point labels.

The lane-grid defect came from placing a fixed header and labels before measuring the summary and occupied cells. The renderer now measures and wraps the summary first, places the header below the resulting protected region, paints cells before connectors and labels, and routes cross-lane edges through collision-aware orthogonal grid paths.
