# Notemd v1.9.5

## 亮点

- **Drawnix 预览现在显示完整的视觉组合**：Drawnix 知识导图与其中嵌入的每个 Mermaid 图都会按源文件顺序显示在同一个支持纵向滚动的预览窗口中。
- **多图导出更加明确且可恢复**：可以从每个 panel 的菜单单独导出，也可以选择原文件夹或自定义 Vault 相对文件夹后按顺序导出全部 panel；单个 panel 失败不会阻止其余图片写出。
- **保持矢量质量**：SVG 仍是标准矢量导出格式，PDF 直接从相同的 SVG 几何、样式、defs、marker 与文字度量转换而来。PPI 设置现在只影响 PNG 栅格化，默认值为 300 PPI。

## 主要升级

- 为 Mermaid iframe 增加自适应 panel 高度，避免图形被裁切或所有图形被强制使用第一个 panel 的固定高度。
- 增加可滚动的预览 shell，使长文档中的 Drawnix 画布、Mermaid panel、逐图操作与历史控制都可以访问。
- 增加自包含的 Drawnix 源图形：默认把安全清理后的 Mermaid SVG/源码和已解析图片的 data-backed SVG 预览写入 `.drawnix` metadata，因此生成不会创建 `.assets` 文件夹。开启 **同时完整输出 Mermaid 图** 后，才会写出 Mermaid 源码、SVG 与 manifest companion；旧 companion artifact 仍可读取，缺失的 Mermaid companion 也可以从 metadata 保留的源文本重建。
- 为多 panel SVG、PNG 与 PDF 导出增加确定性的逐图命名，并支持选择原文件夹或自定义 Vault 相对文件夹。
- 每个 Mermaid 或 Drawnix panel 都提供独立的 SVG、PNG、PDF 操作，同时保留对完整 panel 集合的顶部导出操作。
- 加固 Drawnix 关系标签：使用节点感知的正交路由、密集同 root 分支的稀疏网格兜底、置于节点层之上的确定性换行标签框；找不到无碰撞位置时会严格失败。
- 保留 Drawnix 标题/摘要页眉为路由障碍，并在最后用不透明防护带绘制，避免外侧虚线通道遮盖页面解释。
- 将原生 `arrow-line` 序列化更新为兼容 Plait 的 `shape`、marker、`texts[].position`、stroke 字段与 opacity，并保留旧版兼容字段。
- 显式 Drawnix 请求现在会 fail closed，不会在 Drawnix 操作下静默保存 Mermaid 文本。
- 更新公开图表手册以及所有已发布语言的图表路由，说明 Drawnix/Mermaid 组合预览和导出流程。

## 修复与鲁棒性

- 修复预览只显示第一个 Mermaid 代码块的问题，现在会保留全部 Mermaid fence。
- 修复多 panel 导出中的黑色几何、缺失样式/defs、外部资源引用与 PDF 退化为栅格图等问题。
- 修复历史重新打开与预览清理流程，避免 observer 和 panel 尺寸状态在关闭或重绘后泄漏。
- 修复长关系解释被节点矩形遮蔽或被画布边缘裁切的问题；原生 `arrow-line` 文本与 SVG 标签现在共享同一套换行和测量几何。
- 修复发布相关版本与 GitHub Pages GEO metadata，使网站、`llms.txt`、JSON-LD、首页和构建审计统一报告 1.9.5。
