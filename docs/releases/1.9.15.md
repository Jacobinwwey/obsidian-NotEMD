# Notemd v1.9.15

## Highlights

ER diagrams preserve field types, PK/FK/UK keys, comments and relationship cardinalities. Shared table measurements improve HTML/SVG and Draw.io exports; Mermaid keeps distinct class and participant identities.

Opening a saved .drawnix restores the main board before Mermaid attachments. Mermaid previews start fitted to the whole diagram. Export receipts support text selection and copying. Windows Slidev checks native Mermaid components and detects missing rendered diagrams.

Recoverable tree and lane references retain visual output with diagnostics. Short routes and compact layouts prioritize reading; the reviewed sequence example stays unchanged, including bottom actors. Invalid or unsafe content can still need repair.

The ER generation chain uses typed fields and shared measurements rather than flattening schema details into decorative labels. SQL types, quoted comments and references are retained where supported. Existing legacy string fields remain readable. Cyclic trees, forests and missing lane endpoints receive source-faithful recovery; diagnostics stay visible instead of silently dropping relationships. This is not a promise to accept unsafe or structurally unusable content.

## Compatibility and upgrade

Install matching main.js, manifest.json and styles.css from 1.9.15, then reload. Existing notes and settings remain. Drawnix cross-branch arrows are static after external rearrangement. README.md is included as the fourth release asset. The required Jacobinwwey Slidev fork and minimum Obsidian version remain unchanged. Reopen saved diagrams after reloading; keep existing companion files while legacy artifacts reference them. Preview fit does not change export resolution.

## Verification

Regression coverage includes ER semantics and layout, Mermaid identity collisions, saved Drawnix reconstruction, preview fit and text selection, source recovery, scale-aware SVG checks, Slidev Mermaid presence and browser acceptance comparisons. Release publication requires a fresh build, full Jest suite and UI/render-host audits. Website publication follows the verified public Release and its asset gate. See the paired [release execution report](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/1.9.15/docs/maintainer/release-1.9.15-acceptance.md) for actual run results and evidence boundaries.

The reviewed case4 PNG/SVG remains byte-identical to the earlier acceptance output. Cases6/7 use compact layouts rather than extra decoration. Historical native evidence and the comparison gallery do not establish fresh external-consumer verification of every diagram type.

All affected documentation translations were written directly by the root agent without translation APIs, LM Studio or delegated translation writing.
