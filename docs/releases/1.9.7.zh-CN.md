# Notemd v1.9.7

发布日期：2026-08-30

## 重点更新

- 修复 Mermaid 象限图标签错误显示坐标数组结构性 `[` 的问题。
- 修复 editable HTML/SVG lane-grid 图中摘要、标题、单元格、连接线和边标签互相覆盖的问题。
- 新增碰撞感知的正交路由和受保护的标题间距，长文本无需用户手动横向滚动即可保持可读。
- 在 `docs/diagram-examples/` 下补齐真实 Vault 示例集，包含双语 Markdown 输入、实测生成的 SVG/PNG 结果和机器可读 manifest。
- 更新仓库文档、维护者手册和 GitHub Pages 图表指南，记录修复契约与实机证据。
- 参考 SimRepo 的格式，将所有 README 语言版本中已停用的 Star History 嵌入替换为无需 token 的 `star-history.dera.page` 响应式图表。

## 根因与修复

象限图问题的根因是：旧版 flowchart 引号/形状修复链被应用到了 `quadrantChart` 代码块。合法点位 `"Docs gallery": [0.32, 0.68]` 可能被改写成带可见括号的标签。现在会先按 Mermaid family 做门控，专用规范化器只会从象限数据点标签末尾移除不匹配的结构性括号。

lane-grid 问题的根因是：摘要高度和占用单元格尚未测量时就固定放置标题与标签。现在先测量并换行摘要，再把标题放到受保护区域下方；随后先绘制单元格，再绘制连接线和标签；跨 lane 的边使用碰撞感知的正交网格路径。
