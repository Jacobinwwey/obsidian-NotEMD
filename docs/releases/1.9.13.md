# Notemd v1.9.13

## Highlights

Successful diagram export logs start collapsed; errors and unfinished exports remain visible. Each preview has an independent lock beside zoom-out, allowing SVG/HTML text selection without navigation. PNG/PDF previews use Obsidian's native viewer.

Presentation exports support selecting HTML, PDF, PNG, PPTX and MP4 together. Source preparation and layout convergence run once; PNG and MP4 share capture. The required Jacobinwwey Slidev fork now uses release `notemd-standalone-v52.16.0-2`, preserving standalone module namespaces and compatible dependencies.

## Compatibility and upgrade

Windows browser installation and detection share the same package/cache and verify a real launch. Cold probes allow 30 seconds for launch and 60 seconds for the process; failures retain their cause. The known-broken `-1` archive must be replaced through the installer. Update or clear explicit paths that still select it. Future fork releases remain eligible; there is no official Slidev fallback.

Install matching `main.js`, `manifest.json` and `styles.css` from 1.9.13, then reload; `README.md` is included. Existing notes/settings and the public 1.9.12 assets remain unchanged. Locked raster images do not gain selectable text.

## Verification

A new vault received complete settings before a real API test. Its architecture deck exported all five formats with 32 slides, all three Mermaid blocks preserved, 411 editable PPTX text boxes and eight tables. PNG decoding, PDF/PPTX page counts, video parsing and standalone page loading passed. Task logs were retained and source/settings restored. A fresh browser cache passed first installation and repeated detection. A headless Wake Lock permission rejection is recorded as an environment limitation; Linux acceptance is not claimed.

Documentation and website translations were authored directly without translation APIs or LM Studio. Detailed evidence and remaining release checks are recorded in the paired maintainer reliability documents.
