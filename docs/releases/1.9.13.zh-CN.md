# Notemd v1.9.13

## 主要更新

成功导出的图形日志默认收起，错误和未完成导出保持可见。每个预览的缩小按钮旁都有独立锁定按钮，便于选择 SVG／HTML 文字而不触发移动或缩放。PNG／PDF 使用 Obsidian 原生查看器。

演示导出支持同时选择 HTML、PDF、PNG、PPTX 和 MP4。源准备及布局收敛只执行一次，PNG 与 MP4 共用截图。项目要求的 Jacobinwwey Slidev fork 更新至 `notemd-standalone-v52.16.0-2`，修复 standalone 模块命名空间及依赖兼容性。

## 兼容与升级

Windows 浏览器安装和探测共用包及缓存，并实际启动验证。冷启动探测为浏览器启动预留 30 秒、整体进程预留 60 秒，保留失败原因。已知存在缺陷的 `-1` 压缩包需通过安装器替换；显式路径仍指向旧包时，请更新或清除路径。后续 fork 版本仍可使用，不回退到官方 Slidev。

安装 1.9.13 配套的 `main.js`、`manifest.json` 和 `styles.css` 后重载，发布资产也包含 `README.md`。现有笔记、设置和已公开的 1.9.12 资产保持不变。锁定位图不会使其中的文字变得可选择。

## 验证

新 vault 在真实 API 测试前完成配置迁移。architecture 文档的五格式导出均完成，共 32 页，保留三个 Mermaid 源块、411 个可编辑 PPTX 文本框和 8 个表格。PNG 解码、PDF／PPTX 页数、视频解析及 standalone 页面加载均通过。任务日志完整留存，源文件和设置恢复。全新浏览器缓存通过首次安装及重复探测。无头环境的一次 Wake Lock 权限拒绝作为环境限制记录；不宣称 Linux 验收通过。

文档与网站翻译均直接编写，未调用翻译 API 或 LM Studio。详细证据及尚待完成的发布检查记录于中英文维护者可靠性文档。
