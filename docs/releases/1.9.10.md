# Notemd v1.9.10

## Highlights

This patch hardens real user preview, settings and desktop presentation paths following community scanner triage and a ponytail architecture review. Scanner counts are not confirmed bug counts; the full source audit separates reproduced defects, false positives and remaining risks.

## Security and compatibility

- Imported SVG is sanitized before browser export and host mounting. Active HTML, event attributes, unsafe references and external CSS resources are removed. Chinese vector labels, gradients, markers and independent panel styles remain visible; every graphic gets its own CSS scope.
- Mobile plugin loading no longer eagerly imports the local server's Node dependencies. Desktop-only command/settings detection uses the existing platform boundary.
- Presentation HTML serving binds only to 127.0.0.1, validates Host/Origin and file containment, and emits UTF-8 content types. Concurrent consumers share a listener; final release closes it, and plugin unload cancels pending startups. Actual binding handles occupied ports without a probe window.
- Mermaid is locked to strict preview settings and updated to 11.17.2. DOMPurify 3.4.11 is used at the browser SVG authority boundary. Unused direct lodash typings/runtime dependencies and the redundant builtin-modules package are removed.

## Settings and upgrade

Device-only providers now use Obsidian's Vault-scoped local storage. Existing configured providers are preserved. If you used the old device-wide list, choose **Import legacy device-only providers** in this Vault's settings. Import is explicit; it preserves the old list, does not copy credentials automatically into other Vaults, and can replace unused defaults. Storage failure rejects instead of silently losing local credentials. This is local separation, not encryption or an atomic transaction across storage backends.

The local-only toggle now appears for valid providers. Failed favorites saves restore state and display an error; clipboard copy reports success only after completion. Explicit deletion uses the Vault's trash preference.

Stop active tasks, back up the Vault and install main.js, manifest.json and styles.css from this same Release, then reload. README.md is also included as a required release asset. Preserve settings, notes and generated outputs. Verify one note before a batch. All changed translations were authored directly without translation APIs or LM Studio.

## Retained diagram behavior

PNG compatibility remains enabled by default: preserve the requested original and add a verified lower-PPI companion only when the original cannot decode in Obsidian. Export PPI remains 72–600, default 300; SVG has no raster PPI. Independent zoom and per-type multi-format export remain available. Requested files stay beside the source or directly in the configured output folder; intermediate files stay in the configured cache folder or adjacent notemd_assert.

Drawnix retains explicit directed relationships without a fixed total or per-node quota. Measured lanes and labels grow the layout when required. The older 1.9.9 guide describes that release's original quota; it is historical, not the current policy. Presentation export, including PPTX/MP4, retains its separate settings and dependencies.

## Verification and limitations

Release acceptance records the fresh build, full regression results, lint/UI/render-host audits, real 1Knowledge CLI evidence and localized website checks. The community audit is in docs/audits/2026-10-04-community-ponytail.md. Same-origin Mermaid bridge isolation, forward Obsidian 1.13 search integration and remaining export-toolchain advisories are tracked limitations. Pure Node/offline SVG is not automatically browser-sanitized. Current packaging remains a self-contained main.js; it is not a claim of separate heavy-runtime isolation. Native Drawnix editing may detach static cross-branch arrows.
