# Notemd v1.9.6

## Highlights

- **Settings discovery is now compact and navigable**: field-aware search ranks visible names, descriptions, aliases, and categories, then jumps directly to the matching setting with stable IDs.
- **The discovery toolbar can collapse cleanly**: the expanded search controls preserve the current query; the collapsed state becomes a floating top-right control instead of consuming a full row.
- **Favorites have a dedicated panel**: clicking **★ Favorites** opens a navigable list with setting descriptions and categories. Favorites persist per Vault, remove stale IDs safely, and remain independent from the favorites-only filter.
- **Documentation is synchronized for the 1.9.6 settings contract**: the repository manuals and all published GitHub Pages locale routes document search, collapse, favorites, 300 PPI defaults, 72-600 PPI bounds, and Mermaid companion behavior.

## Fixes And Robustness

- Prevented search result targets from shrinking or losing their anchor when the settings layout is narrow.
- Anchored the collapsed control to the settings content column so it remains discoverable near the close controls without overlapping the sidebar.
- Added deterministic setting catalog IDs and cleanup of favorites that no longer resolve to a live setting.
- Added translation tooling guards for LM Studio batches: at most eight locales per run, a request context budget below 30,000 tokens, protected technical tokens, structural validation, and retry-on-omission behavior.
