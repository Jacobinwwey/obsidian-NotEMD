# Notemd v1.9.14

## Highlights

PNG and PDF now open inside the diagram preview window. Each PDF page has independent zoom, fit and lock controls. PDF zoom redraws the visible region from the original page at the current zoom and screen pixel density, fixing blurred Mermaid labels and connectors caused by stretching a fixed canvas. Rendering is bounded, obsolete work is cancelled, and offscreen detail canvases are released.

Hold Alt to temporarily freeze movement and zoom while selecting available SVG, HTML or PDF text. Releasing Alt restores the previous persistent lock state. PNG remains an image without OCR or selectable text.

Preview Export now offers SVG, PNG and PDF checkboxes with one destination choice and confirmation. The main action exports all panels; a panel action exports only that panel. Presentation formats also use checkboxes, retaining multiple ordinary-click selections and requiring at least one format. Controls show the active format and progress, block duplicate submissions, and retain partial failures in the final batch summary.

## Compatibility and upgrade

Install matching `main.js`, `manifest.json` and `styles.css` from 1.9.14, then reload; `README.md` is included. Existing notes, settings, earlier public release assets and the required Jacobinwwey Slidev fork remain unchanged. Export PPI remains independent of preview zoom. PDF text selection supports both maintained PDF.js text-layer APIs used by Obsidian.

Embedded raster images remain limited by their source resolution. Very large screens can reduce detail sampling to respect the canvas memory budget. PDF page dimensions and the source files are not modified.

## Verification

Obsidian CLI verified the 36-page `architecture.zh-CN.pdf`, including the third-page Mermaid diagram, at 8× zoom with simulated 1×/2× device pixel densities. The page contained 289 vector path operations and no bitmap paint operations. Local detail rendering closely matched an independent PDF.js source render, with only subpixel CSS-coordinate rounding differences. Panning, stable text layers, Alt selection, offscreen release, close cleanup and unchanged source/settings passed. These checks used a background-vault visibility override that was restored afterward; no desktop automation was used.

Earlier native checks in both the disposable vault and `1Knowledge` verified independent PDF pages, PNG decoding, SVG+PNG+PDF from one confirmation, and simultaneous presentation format selections. New regression tests cover zoom density, cropping, stale tasks, memory bounds, long/narrow pages and cleanup. Detailed evidence and validation records are in the paired [PDF zoom](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/1.9.14/docs/maintainer/2026-10-07-pdf-preview-zoom.md) and [multi-format UI](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/1.9.14/docs/maintainer/2026-10-07-multiformat-export-ui.md) documents.

Documentation, manuals, UI copy and website translations were authored directly by the root agent, without translation APIs or LM Studio.
