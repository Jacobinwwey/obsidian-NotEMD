# Notemd v1.9.8

## 重点更新

- **更可预测的取消与恢复。** 取消信号贯穿排队工作、provider 传输与重试等待；标题生成的晚到响应不能继续受保护的写入或移动。重叠图表保存会保留冲突编辑，并报告恢复产物。
- **修正原生导出。** PowerPoint 表格保留独立侧边、透明度、合并单元格外边线，以及合并表头下方完整的折叠行分隔线。CircuitikZ NAND／NOR 和传输门的连线已修正，镜像布局中的标签保持可读。
- **一致的批处理检索。** 标题生成批处理使用稳定的本地知识快照；索引可处理笔记消失或移出选定范围的情况。冻结语料和保留堆内存证据与更广泛的检索质量声明分开维护。

## 修复与鲁棒性

- 复用其他任务在准备期间先建好的译文目录；同路径是文件或目录仍不存在时保留源目录回退，不将他者创建的目录计为本任务产物。
- 最后一次源文件读取或输出目录准备期间取消时，阻止研究内容追加及译文创建／覆盖；Vault 已接受的写入仍保留完成结果。
- 历史抽屉在加载与 Tab 导航期间保留内部焦点，Escape 仅关闭抽屉；异步刷新保留搜索输入和光标。连续键入、筛选、重试焦点及关闭后晚到响应均有真实浏览器回归。
- 后续移动被取消时，仍准确统计已成功的写入；无法确认安全清理时，保留部分产物和二进制输出。
- 串行化 Vault 内路径重叠的保存，覆盖同名来源与共享附件；保留旧 Drawnix 附件目录供检查，不擅自假定其已经无用。
- 新增针对性的原生 PowerPoint 断言，检测此前漏检的半宽分隔线。DrawingML 节点存在和整页图像分数不能替代该检查。
- 使用经校验的分阶段发布流程：严格参数与版本／tag 检查、离线预览、干净源码重建、冻结上传字节、先上传草稿，再核对下载 SHA-256。
- 同 tag 重试只恢复归属匹配的候选版本。鉴权／网络失败不会被误判为 Release 不存在，已公开资产也不能被静默覆盖。
- 发布工作流安装两个锁定的 Chromium 版本；dispatch 输入先作为数据校验，再进入后续操作。

## 文档与可发现性

- 在从右向左的指南中保持行内路径与标识符的标点顺序，以实际字形位置检查 `.obsidian` 的前导点；浏览器覆盖补齐当前升级指南和 FAQ 的键盘访问。
- 教程采用实际 UI 控件名称，修正文档浅色／深色主题的表头可见性，并在窄屏保留韩语单词边界；浏览器检查在对比度与导航之外增加纯透明表头文字检测。
- 根据真实 workflow id、设置、输出路径和 provider 行为校正指南。默认 One-Click Extract 仍然是：添加链接 → 按标题批量生成 → 批量 Mermaid 修复。
- 为新人、日常用户、开发者和 Agent 提供明确入口，补齐独立升级指南和可用的贡献入口。
- 区分 36 个 provider preset、21 个插件 UI locale 和 34 个网站 locale。Provider 与 33 项图表目录在 1.9.7 已存在，不重复计为本版本新增功能。
- 由 Codex 直接撰写并复核文档翻译，不调用 LM Studio 或翻译引擎。AI 撰写不等于独立母语人士审阅，索引资格仍是单独的发布决定。
- 对齐元数据与文档中的发行事实，同时保留历史编年史真实的日期和 tag。以明确的实现边界替换没有依据的离线、平台和竞品声明。

## 验证与证据

- Linux 和 Windows 插件门禁覆盖构建、全量 Jest、UI／render-host 审计、逐条诊断的 lint 回归和 patch 格式。
- 发布进程测试使用真实临时 Git 仓库、构建和哈希计算，并控制远端边界，覆盖上传中断、下载损坏、查询错误、草稿发现与幂等重试。
- 文档门禁将公开设置默认值、workflow 示例、provider 条目和 Agent 公开命令集合与源码契约比较。
- 候选验证覆盖 816 个真实键盘网站场景、用户指定 1Knowledge Vault 中的 Obsidian CLI、PowerPoint 编辑／保存／重开及边框反例，以及十一项 CircuitikZ 编译。[1.9.8 验收记录](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/main/docs/maintainer/release-1.9.8-acceptance.zh-CN.md)保留候选哈希、执行收据和限制。

## 升级与已知限制

- 保留设置和已有 command id。先停止任务、备份 Vault，再安装同一 Release 的运行文件，重载后用临时笔记核对结果，最后恢复大批量工作。
- 取消不等于回滚，也不能保证上游停止生成或计费。已完成写入和恢复文件可能保留。
- Drawnix 跨分支箭头仍是固定关系，应用重排后可能脱离；PPTX 中的 Mermaid／SVG 内容可能继续使用图像回退，并非可编辑原生形状。
- 物理移动设备与 Obsidian 0.15.0 仍未验证；manifest 最低版本不是新鲜兼容性测试。可选原生导出器有各自依赖。
- 词法检索证据，包括冻结语料中 Top-3 正例 7/9 的结果，不能证明语义检索质量或任意 Vault 的性能。

必需发布资产：`main.js`、`manifest.json`、`styles.css`、`README.md`。
