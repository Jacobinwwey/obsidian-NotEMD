# Notemd v1.9.11

## Highlights

This patch improves dense Drawnix diagrams, fixes a general SVG-to-PDF compatibility failure, retains session task logs, and groups preview diagnostics into disclosures that are collapsed by default.

## Diagram layout and diagnostics

- Related sibling branches and roots are placed nearer using their actual dimensions and relationship distance. Routing penalizes overlapping and crossing connectors, with separate endpoint ports. All nodes, parentage, labels and explicit relationships are retained; there is no relationship quota.
- On the frozen `architecture.zh-CN` fixture, all 179 nodes and 24 explicit relationships remain. Relation route length decreased from 152,805 to 40,582.5, pairwise collinear overlap from 12,163.5 to 32, and perpendicular crossings from 141 to 20. These measurements exclude hierarchy branches and do not promise a globally optimal or crossing-free layout.
- Artifact diagnostics are grouped by tag and collapsed by default. Each group shows severity counts; expanding it reveals every message and suggestion. The overall count remains visible, and unknown future tags work without a registry change.

## PDF reliability and compatibility

The SVG-to-PDF library split commas inside functional selectors such as `:is(...)`, causing valid sanitized styles to fail during export. PDF preparation now resolves those declarations through the browser cascade in an isolated document, retaining specificity, importance, inline overrides, inherited colors and reusable SVG definitions. Temporary documents are cleaned up after success or failure. The existing SVG sanitization boundary remains in place.

Missing viewBoxes are supplied before coordinate conversion. Pages beyond the PDF library’s 14,400-point side limit scale proportionally, preserving aspect ratio and vectors. Regression coverage includes nested SVG, complex selectors, gradients, clipping, Chinese text, `<use>` inheritance and absence of external requests. These shared changes apply to complex SVG inputs generally, including older cached artifacts.

## Logs and upgrade

Sidebar logs accumulate across task stages, subsequent actions, preview reopening and sidebar rebuilding during the plugin session. **Clear log** explicitly resets the transcript. Progress-modal stages retain their logs too. This does not add persistence across plugin reloads.

Install matching `main.js`, `manifest.json` and `styles.css` from this release, then reload. `README.md` is also included. Existing settings, notes and generated files are preserved. All updated translations were authored directly without translation APIs or LM Studio.

## Verification and limitations

The recovery acceptance records the production build, full regression suite, lint/UI/render-host audits and official Obsidian CLI verification on 1.13.7. The real fixture exported Drawnix, HTML, SVG, PNG and PDF; the PDF runtime recovered all 179 node labels. The previously failing original SVG also exported successfully without regeneration. Release checks additionally cover collapsed diagnostics and all 34 website locales.

Cross-branch arrows still use static coordinates in native Drawnix and may detach after rearrangement. Existing PNG compatibility, export destinations, provider settings, workflow chaining and presentation exports retain their contracts. No claim is made that every possible third-party SVG feature is supported by the PDF converter.
