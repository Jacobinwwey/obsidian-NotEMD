# Notemd v1.9.5

## Highlights

- **Drawnix previews now show the complete visual composition**: the Drawnix knowledge map and every embedded Mermaid visual are rendered together in source order inside one vertically scrollable preview.
- **Multi-panel export is explicit and recoverable**: export a single panel from its panel menu, or export all panels sequentially after choosing the source folder or a custom Vault-relative folder. One failed panel no longer prevents the remaining images from being written.
- **Vector fidelity is preserved**: SVG remains the canonical vector export and PDF is converted directly from the same SVG geometry, styles, definitions, markers, and text metrics. The PPI setting now applies only to PNG rasterization and defaults to 300 PPI.

## Major Upgrades

- Added adaptive panel sizing for Mermaid iframes, so rendered diagrams are not clipped or forced into a fixed first-panel height.
- Added a scrollable preview shell that keeps the Drawnix canvas, Mermaid panels, per-panel actions, and history controls reachable for long documents.
- Added inline Drawnix Mermaid companions: sanitized SVG plus Mermaid source are stored in `.drawnix` metadata when safe, avoiding a redundant `.assets` directory for Mermaid-only visuals while preserving external or unresolved media companions.
- Added deterministic per-panel naming for multi-panel SVG, PNG, and PDF exports, with source-folder and custom Vault-relative folder selection.
- Added independent SVG, PNG, and PDF actions for each Mermaid or Drawnix panel, while retaining the top-level export actions for the complete panel set.
- Hardened Drawnix relation labels with node-aware orthogonal routing, a sparse-grid fallback for dense same-root branches, deterministic wrapped label boxes above node layers, and strict failure when no collision-free placement exists.
- Reserved the Drawnix title/summary header as a routing obstacle and rendered it last with an opaque guard band, preventing perimeter dashed routes from obscuring page-level explanations.
- Updated native `arrow-line` serialization to include Plait-compatible `shape`, markers, `texts[].position`, stroke fields, and opacity while retaining legacy compatibility fields.
- Explicit Drawnix requests now fail closed instead of silently persisting Mermaid text under a Drawnix operation.
- Updated the public diagrams guide and every published localized diagrams route to document the combined Drawnix/Mermaid preview and export workflow.

## Fixes And Robustness

- Fixed the preview to retain all Mermaid fences instead of displaying only the first diagram.
- Fixed multi-panel export failures caused by black geometry, missing styles/definitions, external resource references, and raster-only PDF conversion.
- Fixed history reopen and preview cleanup so observers and panel sizing do not leak across closed or redrawn previews.
- Fixed long relation explanations being hidden by node rectangles or clipped at the canvas edge; native `arrow-line` text and SVG labels now share the same wrapped lines and measured geometry.
- Fixed release-facing version and GitHub Pages GEO metadata so the website, `llms.txt`, JSON-LD, homepage, and build audit all report 1.9.5.
