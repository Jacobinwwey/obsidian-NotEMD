# Notemd v1.9.12

## Highlights

Diagram previews now keep the whole diagnostic panel collapsed when there are no errors. The compact summary retains the title and severity counts, leaving more room for the diagram.

When errors exist, the panel opens and **only error groups expand automatically**. Warning and information groups remain collapsed. Diagnostics are grouped by both tag and severity, so an error never causes unrelated lower-severity messages under the same tag to appear expanded. Every message and suggestion remains available on demand.

## Compatibility and upgrade

This patch changes diagnostic presentation only. The Drawnix layout, general PDF-export fixes and session log retention from 1.9.11 remain in place. Empty diagnostics do not render a panel. Native disclosure controls retain keyboard operation and visible focus.

Install matching `main.js`, `manifest.json` and `styles.css` from 1.9.12 and reload the plugin; `README.md` is also included. Existing files and settings are preserved. The public 1.9.11 assets remain unchanged.

## Documentation and verification

README manuals, website diagram/configuration guides and release pages are updated in all affected languages. All translations were authored directly without translation APIs or LM Studio. Regression tests cover default closure, error-only expansion, mixed severity under one tag, repeated tags, complete evidence and empty diagnostics. Build, full CI, locale and website checks are recorded in the paired release acceptance documents.
