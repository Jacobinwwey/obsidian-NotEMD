# Notemd v1.9.6

## 亮点

- **设置查找现在紧凑且可直达**：字段感知搜索会按可见名称、描述、别名与类别排序，并通过稳定 ID 直接跳转到匹配设置。
- **查找工具栏可以干净收起**：展开状态会保留当前搜索条件；收起后变为右上角悬浮控件，不再占用整行空间。
- **收藏拥有独立设置单**：点击 **★ Favorites** 会打开包含设置描述和类别的可导航列表。收藏按 Vault 持久化，会安全移除失效 ID，并与“仅显示收藏项”筛选保持独立。
- **文档已同步 1.9.6 设置契约**：仓库手册与 GitHub Pages 的全部已发布语言路由都记录搜索、收起、收藏、300 PPI 默认值、72-600 PPI 范围以及 Mermaid companion 行为。

## 修复与鲁棒性

- 防止设置页较窄时搜索结果目标缩小或丢失锚点。
- 将收起控件锚定到设置内容列，使其在关闭控件附近保持可发现，同时避免覆盖侧栏。
- 增加确定性的设置目录 ID，并在收藏指向的设置不存在时自动清理失效项。
- 为 LM Studio 翻译工具增加批次保护：每批最多 8 个 locale，请求上下文低于 30,000 token，保护技术 token，校验结构，并在模型省略 token 时自动重试。
