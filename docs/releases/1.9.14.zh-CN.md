# Notemd v1.9.14

## 主要更新

PNG 和 PDF 现在在图形预览窗口内打开。每个 PDF 页面都有独立的缩放、适应窗口和锁定控件。PDF 缩放会根据当前倍率及屏幕像素密度，从原始页面重新渲染可见区域，修复拉伸固定画布导致 Mermaid 文字与连线模糊的问题。渲染有资源上限，过时任务会取消，离屏高清画布会释放。

按住 Alt 可暂时冻结移动与缩放，便于选择 SVG、HTML 或 PDF 中已有的可选文字；松开后恢复之前的按钮锁定状态。PNG 仍是图像，不提供 OCR 或可选择的文字。

图形预览导出现在使用 SVG、PNG、PDF 复选框，只需选择一次目录并确认。主按钮导出全部面板，面板按钮仅导出该面板。演示格式也使用复选框，普通点击即可保留多项，且至少选择一种格式。控件显示当前格式和进度，阻止重复提交，并在最终整批汇总中保留部分失败。

## 兼容与升级

安装 1.9.14 配套的 `main.js`、`manifest.json` 和 `styles.css` 后重载；发布资产也包含 `README.md`。现有笔记、设置、此前公开资产及项目要求的 Jacobinwwey Slidev fork 保持不变。导出 PPI 与预览缩放独立。PDF 选字兼容 Obsidian 使用的两代受维护 PDF.js 文字层 API。

嵌入位图仍受源图分辨率限制。极大屏幕下可能降低局部采样密度，以遵守画布内存预算。PDF 页尺寸及源文件不会被修改。

## 验证

通过 Obsidian CLI 验证 36 页的 `architecture.zh-CN.pdf`，重点检查第三页 Mermaid 图表在 8 倍缩放和模拟 1×／2×设备像素密度下的效果。该页包含 289 个矢量路径操作，没有位图绘制操作。局部重绘与独立 PDF.js 原页渲染高度一致，仅存在 CSS 坐标小数舍入引起的亚像素差异。拖动、文字层保持、Alt 选字、离屏释放、关闭清理以及源文件／配置不变均通过。后台 vault 验证临时覆盖可见性属性，结束后恢复；未使用桌面自动化。

此前已在一次性测试 vault 与 `1Knowledge` 验证 PDF 逐页独立、PNG 解码、一次确认生成 SVG＋PNG＋PDF，以及演示格式多选。新增回归覆盖缩放密度、裁切、过时任务、内存预算、狭长页面及清理。详细证据和验证记录见成对的 [PDF 缩放](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/1.9.14/docs/maintainer/2026-10-07-pdf-preview-zoom.zh-CN.md)与[多格式界面](https://github.com/Jacobinwwey/obsidian-NotEMD/blob/1.9.14/docs/maintainer/2026-10-07-multiformat-export-ui.zh-CN.md)文档。

文档、手册、界面文案与网站翻译均由主代理直接编写，未调用翻译 API 或 LM Studio。
