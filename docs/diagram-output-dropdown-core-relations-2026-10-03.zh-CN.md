### 范围与实施计划

从 `c021976` 之后的未发布工作继续，不重做已完成的演示与全格式导出，不修改已发布的 1.9.8。图形生成与演示导出的配置、依赖库和执行链路保持独立。

1. 将设置页、工作台的平铺图形输出复选框改为紧凑多选下拉菜单，保留支持项优先、暂不可用请求、最新选择协调和生产渲染器生成的类型预览。
2. 在 Drawnix 渲染边界选择适合主图阅读的关系，保留完整语义树及被省略关系，不为旧箭头凭空补写标签。
3. 使用官方 Obsidian CLI 在已打开的 `1Knowledge` 验证，包括设置独立窗口。备份既有产物、恢复测试偏好、完成全量验证后更新远端 main，不创建 release/tag。

### 实现与取舍

- `diagramOutputSelector` 管理触发器、复选框分组、所属 document 的 portal、Obsidian 键盘作用域及清理。原生复选框保留多选语义，支持方向键、Home/End、Escape、Tab。收起时显示选择摘要，暂不可用状态保持简短，详细说明放入 tooltip。
- 兼容性继续由既有偏好解析与串行持久化逻辑决定，不将演示格式混入图形生成。图形 HTML 展示 SVG，结构化摘要 HTML 展示文本、结构与引文，两者都不承诺网页内图形编辑器。
- 设置可能进入独立 document。Escape 必须通过 Obsidian scope 先于宿主模态快捷键处理。缓存缩略图可能在独立窗口布局前返回，通过可清理的 `ResizeObserver` 等待 SVG 可见后执行几何校验，不绕过安全校验。
- `selectDrawnixCoreRelations` 最多保留六条明确有向关系，每个节点最多关联三条。无标签、泛化、重复/平行、层级及超密度关系保存在 `metadata.notemd.omittedRelations` 并附原因。重要性来自模型输出顺序；这是主图阅读预算，不是节点或语义容量上限。
- 路由器在障碍物允许时共同预留局部标签和短正交路径，避让此前局部路径与标签；密集布局仍可使用外侧预留通道。SVG 与原生箭头共享路径和标签位置。该方案减少绕行，不承诺所有图都零交叉，也不承诺原生 Drawnix 重排后箭头自动附着。
- 生成提示词要求标签明确表达起点到终点的关系，方向有原文支持并保留历史不确定性。结构校验不能证明语义正确。样例审查省略了依据不足的“氢聚变→超新星”推断，并修正 DNA/RNA 关系方向，没有用现代科学结论替换历史原文。
