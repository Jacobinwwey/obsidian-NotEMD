## 已实现改动

- 图形导出全部成功时，完成日志默认收起；部分完成、取消、待处理、诊断错误和历史记录错误保持展开。
- 每个预览视口的缩小按钮旁有独立锁定按钮。锁定后冻结导航，可选择 SVG/HTML 文字；位图不会因此具备可选择文字。
- PNG/PDF 预览先校验二进制签名，再等待 Obsidian 原生查看器打开，不再把字节当 Markdown 解码。
- 演示格式支持多选，兼容旧单格式设置。源准备与布局收敛只执行一次，PNG 与 MP4 共用截图，各格式失败单独保留。
- Playwright 安装、探测和消费者共享包及缓存解析。安装调用实际包的 CLI，并验证无头浏览器启动；不能仅凭退出码宣告成功。
- Obsidian 图片嵌入转换并复制到准备目录，代码字面量保持不变；缺失或不支持的嵌入显示诊断。
- 仅允许所要求的 Jacobinwwey Slidev fork，移除官方 npx 回退；安装后必须重新探测。显式 CLI 路径无效时，在运行 npm 前停止安装。

## Fork 来源与根因

故障发生时使用的发布包为 `notemd-standalone-v52.16.0-1`，提交为 `5f600c39cdd89df2a623a6cf2fd57c2c2284ba87`。该 GitHub 资产的 SHA-256：

`c456b934ac563805af13f55106e0779ffd7caaf48c698d8f91dae11bd485ae6a`

发布包中 13 个文件与 Vault 中安装的 CLI 逐字节一致，SHA-512 也与 npm 锁文件一致。本次故障没有运行官方 CLI。

fork 发布时锁定 UnoCSS 66.7.0 与 MagicString 0.30.21，但发布清单允许 `unocss: ^66.7.0`。消费者安装得到 66.10.5，其 Vite 集成使用 MagicString 1.4.3。Uno 指令先修改该实例，再在删除空 CSS 规则后替换整个原始范围；新版实例保留了此前插入的片段，导致重复的无选择器声明。同样转换使用 0.30.21 时可正确解析。

最小单页构建能够复现。准备目录中的兼容预处理仅在 Uno 运行前删除 Slidev 内置 CSS 的空规则，保留严格 CSS 压缩。这只是兼容措施，不能代替 fork 的依赖契约修复。

fork main `bbcb2efae709c2ebaa96bda522cd6c192476817c` 有更新的 standalone/shiki 修复，但独立安装打包产物又暴露了两个缺陷。standalone 转换器遇到默认导出时替换整个 exports 对象，丢失此前的命名导出，包括 Mermaid 的布局函数。本地修复保留命名空间，仅设置 `.default`，并添加 ESM 命名空间标记，供 Vue 异步组件加载器识别。五个真实执行的回归用例在修复前失败、修复后通过。

干净消费者还解析到 Twoslash 4.5.0 与 FloatingVue 5.4.0，Twoslash 的内部组件补丁在 `components.Popper` 处失败；正常源码环境使用 4.2.0 与 5.2.2。fork 候选包约束这组依赖，并从 CLI 解析对应运行时导入，避免消费者已有的新版副本替代它们。四个 UnoCSS catalog 条目固定为 66.7.0。这些约束已进入 CLI 打包清单，并非只修改工作区锁文件。

公开资产保持不可变。修复后的 `-2` fork 已发布，对应提交 `fc7045268a4e560bc479caef24ca4b73fea1b0cf`；下载回来的发布资产与验收压缩包一致。插件 1.9.13 指向该版本，拒绝已知存在缺陷的 `-1` 压缩包，同时保留后续 fork 版本的兼容性。
