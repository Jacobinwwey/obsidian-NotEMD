# 可见 Obsidian 窗口中的 PDF 预览验收

[English](./2026-10-07-pdf-preview-native-acceptance.md)

## 范围与安装候选

发布 1.9.14 前，通过 CLI 将配套的 `main.js`、`manifest.json`、`styles.css` 备份并完整安装到本机 `1Knowledge` vault。插件重载后报告版本为 1.9.14。三项安装文件均与本机候选一致，磁盘配置与内存设置均保持不变。源提交为 `11884b12fb0f75f12435081c54d1a78f4633b5b7`。

本次验收补充[修复记录](./2026-10-07-pdf-preview-zoom.zh-CN.md)中此前模拟像素密度的检查。测试使用 Obsidian 1.13.7，窗口真实可见，内容区域为 2064 × 1220 CSS 像素，原生设备像素比为 1.5。没有覆盖 `document.hidden` 或 `devicePixelRatio`。首次尝试检测到窗口暂时隐藏后立即停止；只有后续真实可见窗口中的运行计入通过结果。

打开文件、重载插件、检查 DOM 和调用 `dev:screenshot` 截图均通过官方 `Obsidian.com` CLI 完成。未使用 computer-use 或桌面输入自动化。独立的 `obsidian-cli` 可执行程序未安装。

## 源文件与测量结果

测试文件为 `slidev-acceptance-20261006-final/architecture.zh-CN.pdf`，共 36 页，每页为 735.12 × 414 PDF 单位。第三页包含 Mermaid 架构图，有 289 个矢量路径操作、80 个文字项，没有位图绘制操作。验收前后的 SHA-256 均为 `1d13653287a2e9773d0ca8c8293023b91ab5b5d84a870cc79598dd390846aa54`。

高清画布只覆盖页面可见部分及预留边缘，因此画布像素尺寸保持有界，而其对应的原页区域随缩放变小。本次各倍率均未因预算限制而降采样。验收阈值为 0.05 / 255；微小差异来自 CSS 小数坐标的序列化舍入。8× 时，旧底图直接放大后的结果与新高清图像的差异为 3.405559 / 255。

8× 下平移会替换并释放旧高清画布；新区域与独立参考的差异为 0.000658 / 255。文字层 DOM 始终保留。每页均有独立控件，修改第三页不会改变其他页面。按住 Alt 时移动与缩放被阻止，DOM Range 仍能选中文字；松开后恢复导航。按钮持久锁定在 Alt 按下／释放后仍然保留，也能显式解锁。离屏高清画布被释放，关闭测试弹窗后全部跟踪画布尺寸归零。

## 目视复核与证据

主代理检查了 4×、8× 的 CLI 真实窗口截图及原始分辨率的高清画布。文字、箭头和曲线边缘清晰，高倍率下的裁切符合视口范围；下一页仍保留独立的 100% 控件。选字截图和 DOM 断言证明的是文字层状态，不等同于使用实体鼠标拖动的测试。

本地记录包括 `.cache/native-real-install.json`、`.cache/native-real-acceptance.json`、`.cache/native-real-window-page3-{fit,1,2,4,8}.png`、`.cache/native-real-window-alt-selected.png`，以及 `.cache/native-real-page3-8-{actual,reference,old-magnified,panned}.png`。截图含本地 vault 信息，不作为仓库资产公开。旧插件文件保留在本地验收备份中。本记录不包含 vault 配置或凭据。

本机 Windows 样式表含混合换行；将 CRLF 统一为 LF 后，哈希为 Linux 发布候选的 `5adce9f393348babb544c946cff733a28ab38932fad8d954624e6424f793f11b`。这只是字节格式差异，CSS 规则一致。JavaScript 与 manifest 的哈希已经与发布候选相同。

## 发布边界

首次 Release workflow 在创建空草稿后立即停止，尚未上传资产，原因是发布器在立即回查时未取得预期草稿。后续认证 REST 列表返回了唯一的 1.9.14 草稿（ID 405541894），其来源记录符合预期，且没有公开时间。现有日志不足以确定 GitHub 可见性时序的底层原因。现有发布器可恢复这一匹配草稿，无需修改 tag 或替换公开资产。实机验收待完成期间，Pages 已确认取消。正式发布状态需与本验收记录分开核实。

验收通过后，[Release 运行 37593312768](https://github.com/Jacobinwwey/obsidian-NotEMD/actions/runs/37593312768)的第 2 次尝试通过构建、全套测试、审计和发布器校验。1.9.14 于 2026-10-07 10:01:46 UTC 正式公开，四项必需资产齐全。另行通过 CLI 下载后，四项哈希均通过验证。随后将本机三项插件文件与公开资产逐字节对齐并重载；与已验收候选相比，仅样式表换行不同，CSS 规则和配置均不变。最终本地记录为 `.cache/native-real-public-install.json`。

以上验收适用于本次实际屏幕与源文件，不新增 OCR，不恢复嵌入位图原本缺失的细节，也不代表已覆盖所有显示器配置。预览缩放仍与导出 PPI 独立。
