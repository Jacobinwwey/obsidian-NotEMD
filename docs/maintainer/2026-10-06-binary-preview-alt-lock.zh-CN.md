# 二进制图形预览与 Alt 锁定验证

## 中文

1.9.13 的 PNG/PDF 入口验证文件签名后打开 Obsidian 原生分栏；此前的回归测试也断言该分栏，因此没有覆盖用户要求的图形窗口。现在通过明确的宿主操作打开二进制预览窗口，由窗口负责解码与资源释放，已有视口负责导航。二进制文件不会伪装成可编辑的 SVG 源码。

PNG 使用浏览器图片解码器，关窗时释放对象 URL。PDF 使用 Obsidian 自带 PDF.js，顺序渲染页面，设置整份文档 3200 万像素的位图预算，并通过兼容的新旧文字层 API 提供文字选择。快照使用 print 渲染意图，避免后台 vault 的显示动画帧被暂停。加载期间关窗会取消渲染并释放资源。PNG 和纯图片 PDF 没有可选文字，本次不提供 OCR。

Alt 临时锁定不改变锁定按钮的持久状态。鼠标进入时能识别已经按住的 Alt；开始锁定会解除拖动捕获。松开 Alt 或窗口失焦会清除临时状态，并区分焦点进入内嵌预览导致的父窗口失焦与离开应用。解锁保留当前位置和比例。所有现有视口语言的可见操作提示均由人工直接翻译。

## 验证

### 10 月 7 日：PDF 页面独立预览

PDF 每页现在在对话框内有高度限制的滚动区中创建独立标题、面板及 `DiagramPreviewViewport`。尺寸只描述本页，初始适应窗口以及后续缩放、锁定均不影响相邻页。PNG 保持单一视口。资源清理保证所有已创建视口只销毁一次，包括取消或后续页面加载失败的情况。针对性回归测试覆盖不同页面尺寸、每个视口只有一页、PNG 兼容性及资源释放。

14 项针对性测试与新构建通过。Obsidian CLI 已验证测试 vault 的 32 页对应 32 个独立视口，1Knowledge 的 36 页对应 36 个独立视口。每个视口仅包含一张画布及一个文字层；改变第二页的缩放后其他页均保持不变。持久锁、Alt 选字与释放、外层滚动及画布释放通过。PDF 源文件与配置保持不变。本机凭据：`.cache/pdf-page-viewports-NotemdAcceptance-20261006.json` 和 `.cache/pdf-page-viewports-1Knowledge.json`。
