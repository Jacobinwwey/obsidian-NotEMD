# 图形预览与模式手册 — 1.9.15

[English](diagram-preview-and-schema-guide.md)

## 阅读与复制

对已保存的 .drawnix 直接执行**图形预览**。主画布先显示，Mermaid 附图按源顺序随后显示；不能仅用 Mermaid 附图替代主画布。从历史重新打开也采用一致的完整图形初始视图。缩放或平移后，可使用适配操作返回总览。预览缩放不决定 PNG 的 PPI。

在导出记录上拖选文字，复制文件名或错误内容以便搜索。图形区域仍可拖动画布。交互 SVG/HTML/PDF 内选字仍可使用既有 Alt／锁定控制；PNG 没有可选择的文字层。

## 保留模式语义

在源文档中明确给出实体及字段名、SQL 类型、PK/FK/UK 键、注释、引用及关系端点基数。Notemd 将支持的类型化字段贯穿 ER 模型，并为 HTML/SVG 与 Draw.io 采用统一表格测量。Mermaid 使用相同语义模式，但受自身语法及布局限制。仍兼容旧字符串字段；任何图形都不能保证推断出未提供的领域约束。

## 恢复而非隐藏图形

可恢复的循环树与森林通过易读回退保留节点和关系。缺失泳道端点只产生一个中性的占位节点，不重复报警或编造领域实体。请结合图形阅读诊断；结构恢复不等于领域校验。不安全 SVG 或完全不可恢复的输入仍可能需要修复。

## 对比导出

运行 npm run diagram:acceptance，在仓库缓存目录生成真实的优化前后 PNG/SVG 导出和 HTML 对比页。保留原始已评审验收页不变。阅读优先的评审保持 case4 原样，包括底部参与者；case6/7 减少绕行和空白。验收页用于回归对比，不代表每种导出格式都已在原生编辑器中验证。

Slidev 继续使用指定的 Jacobinwwey fork。重载后请从源文件重新构建导出；不会静默改写旧的已导出独立文件。缺少原生 Mermaid 组件或渲染图形缺失时会给出具体诊断，而非将空白输出误报为成功。

## 安全升级

安装同一发布版本配套的 main.js、manifest.json 与 styles.css 并重载。不要替换 data.json，也不要删除已保存文件仍引用的旧附属文件。批量使用前先验证一个代表性源文件及其 SVG/PNG/PDF 导出。Drawnix 跨分支箭头在外部重排后仍为静态。
