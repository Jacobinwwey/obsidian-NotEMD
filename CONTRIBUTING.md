# Contributing to Notemd

## English

Start with the [developer guide](./website/docs/developers/overview.mdx) for setup, source ownership, tests and native-consumer checks. [AGENTS.md](./AGENTS.md) is the repository execution authority. Public guides live in `website/docs/`; engineering evidence and bilingual plans live in `docs/`.

Open an [issue](https://github.com/Jacobinwwey/obsidian-NotEMD/issues) with exact versions and a minimal reproduction, or propose a focused PR with the resulting behavior and fresh validation. Keep credentials, private Vault content and unrelated generated outputs out of submissions. Update affected documentation in the same change.

## 简体中文

从[开发者指南](./website/i18n/zh-CN/docusaurus-plugin-content-docs/current/developers/overview.mdx)开始，了解环境、源码归属、测试与原生消费端核验。[AGENTS.md](./AGENTS.md) 是仓库执行规则的权威来源。公开指南位于 `website/docs/`，工程证据和双语计划位于 `docs/`。

提交 [Issue](https://github.com/Jacobinwwey/obsidian-NotEMD/issues) 时提供准确版本与最小复现；提交聚焦的 PR 时说明行为变化与新鲜验证。不要提交凭据、私有 Vault 内容或无关生成产物。受影响文档应与实现同批更新。
