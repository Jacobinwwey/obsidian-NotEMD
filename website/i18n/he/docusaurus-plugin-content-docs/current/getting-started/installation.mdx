# התקנה

<TLDR>התקינו את Notemd דרך Community plugins, או העתיקו לכספת את שלושת קובצי ההפעלה מאותה גרסת GitHub. הפעילו את התוסף, בחרו ספק ובדקו הערת ניסיון. שרתי מודלים וכלי ייצוא חיצוניים דורשים הכנה נפרדת.</TLDR>

## דרך 1: Community plugins, מומלץ

1. בכספת הרצויה פתחו **Settings → Community plugins**.
2. אפשרו תוספי קהילה לפי הצורך ובחרו **Browse**.
3. חפשו **Notemd**, ודאו שזהו `Jacobinwwey/obsidian-NotEMD` ובחרו **Install**.
4. בחרו **Enable** ופתחו את סרגל הצד דרך רצועת הכלים או לוח הפקודות.

[פתיחת Notemd ב־Obsidian](obsidian://show-plugin?id=notemd). אם הדפדפן אינו פותח את הקישור, השתמשו בתפריט שלמעלה. אין צורך בתמיכה בפרוטוקול כדי לקרוא את המדריך.

## דרך 2: התקנה ידנית

### דרישות מקדימות

נדרשים Obsidian וכספת שניתן לגבות. המינימום `0.15.0` במניפסט הוא הצהרה, לא הוכחה שהמועמד הנוכחי נבדק בגרסה הישנה הזו.

### שלבים

1. הורידו `main.js`, `manifest.json` ו־`styles.css` מאותה [גרסת GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` הוא חומר עזר, לא קובץ הפעלה נדרש.
2. העתיקו את שלושת הקבצים אל `<vault>/.obsidian/plugins/notemd/`. התאימו לנתיב האמיתי אם תיקיית התצורה שונתה.
3. טענו מחדש את Obsidian והפעילו את התוסף.
4. בדקו את הגרסה; אל תערבבו מניפסט חדש עם חבילה ישנה.

## חלופה: BRAT

אם אתם כבר משתמשים ב־[BRAT](https://github.com/TfTHacker/obsidian42-brat), הוסיפו את המאגר בתהליך תוספי הבטא שלו. לשחזור תקלה השתמשו בגרסה מסוימת. BRAT הוא כלי חיצוני אופציונלי.

## אימות

הגדירו מודל נגיש, הריצו **Test connection** ואז את [ההתחלה המהירה](./quick-start). רשימת מודלים אינה מוכיחה הרשאת יצירה במודל; בדקו את התוצר בפועל.

## גבולות מערכת

| רכיב | גבול |
| --------- | ---------- |
| מניפסט | לפחות Obsidian `0.15.0`; הערך `isDesktopOnly` הוא false |
| ראיות בדיקה | ראו דוחות מתוארכים; מכשירים ניידים פיזיים ו־0.15.0 לא אומתו בקבלה הנוכחית |
| מודל בענן | רשת, חשבון/מפתח מורשה ומודל זמין |
| מודל מקומי | שרת מותקן ופועל בנפרד ומודל שהורד/נטען |
| ייצוא למצגות או למעגלים בכלים חיצוניים | כלי מחשב ותלויות ייעודיות לפורמט; בדקו קודם את הסביבה |

אין הבטחת גרסת מערכת הפעלה משותפת לכל כלי הייצוא. תצוגת מעגל אינה מוכיחה הידור TeX; בדיקה במחשב אינה מוכיחה התנהגות בנייד.

## הסרה

השביתו או הסירו דרך Community plugins. הערות וקבצים שנוצרו נשארים קבצים רגילים בכספת. בדקו אותם לפני מחיקה ושמרו גיבוי הגדרות לפי הצורך. הסרת התוסף אינה מבטלת שינויים שהושלמו.

## עדכון

השתמשו ב־**Check for updates**. בעדכון ידני עצרו משימות, גבו כספת והגדרות, החליפו שלושה קובצי הפעלה מאותה גרסה וטענו מחדש. קראו את הערות הגרסה ובדקו משימה קטנה לפני אצווה. אל תחליפו את קובץ ההגדרות בקובץ מההפצה. חזרה דורשת גרסה תואמת שנבחרה במודע וגיבוי.
