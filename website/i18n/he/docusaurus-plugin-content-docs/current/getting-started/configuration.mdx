# תצורה

<TLDR>פתחו Settings → Notemd וחפשו את השדה. הגדירו ספק ומיקום פלט לפני המשימה. בדקו שינוי בהערה אחת; משימה שכבר פועלת עשויה לשמור את הגדרות ההתחלה.</TLDR>

## סקירה

ספק ברירת המחדל הוא DeepSeek עם פרטי גישה ריקים. בחירת פרופיל אינה יוצרת חשבון, מתקינה מודל או מעניקה הרשאות. ראו [ספקים](../providers/overview).

## חיפוש ומועדפים

**Search settings** מחפש בשמות, תיאורים, כינויים וקטגוריות גלויות ומוביל לשדה. **★ Favorites** מציג הגדרות שמורות עם תיאור, קטגוריה ויעד. הן נשמרות בכספת, שורדות הפעלה מחדש ומסירות מזהים ישנים. החיפוש נשמר בכיווץ הסרגל. רשימת המועדפים נפרדת ממסנן החיפוש רק במועדפים.

**Diagram preview export PPI** מתחיל ב־300, בטווח 72–600, ומשפיע רק על PNG. SVG/PDF שומרים גאומטריה וקטורית נתמכת. **Also export complete Mermaid visuals** שולט בקבצים נלווים, לא בהופעת Mermaid בתצוגת Drawnix.

## 1. ספק

הזינו נקודת קצה לפרוטוקול הנכון, מפתח נדרש ומודל נגיש. רשימה ויצירה מוצלחת הן בדיקות נפרדות. שרת/מודל מקומי צריכים להיות מוכנים; ענן/שער מקבלים תוכן. בדקו גם ניתוב לפי משימה לפני מידע פרטי.

## 2. מודל לפי משימה

`useMultiModelSettings` מאפשר ספק/מודל נפרדים לקישורים, כותרות, מחקר, תרגום, מושגים, טקסט מקורי ו־Mermaid. שדה מודל ריק משתמש במודל הספק; כשהאפשרות כבויה משתמשים בספק הפעיל. השוו דיוק, זמן ועלות בפועל על אותה הערה.

## 3. תוצרים

| משימה | תוצאת ברירת מחדל |
| ------ | ------------------------- |
| הוספת קישורים | קובץ `_processed.md` נפרד ליד המקור; העברת מקור כבויה |
| חילוץ מושגים עצמאי | תיקיית מושגים שנבחרה; כותרת בלבד, קישורי חזרה כבויים |
| תרגום | לצד המקור בשם `_<language>.md`; יעד קיים עשוי להידרס |
| מחקר | סיכום נוסף ל־Markdown הפעיל |
| יצירה באצווה מכותרות | כותב למקורות מתאימים ואז מעביר ל־`<folder>_complete` סמוכה אם היעד מאפשר |
| תצוגה/ייצוא תרשים | בחרו מקור נתמך או פלט חזותי ובדקו נתיב מדווח |

תיקיית המושגים מתחילה ריקה; `concepts` הוא שם לדוגמה. להערות עצמאיות יש צורה מינימלית/מלאה, לא מנוע תבניות כללי. [מושגים](../features/concept-notes). לעיבוד ולתרגום סיומות ותיקיות נפרדות. בדקו יעדים והתנגשויות שחזור; ביטול אינו מחזיר כתיבות שהושלמו.

## 4. שפות

בממשק 21 שפות ובאתר 34 מסלולי שפה. `uiLocale: auto` בוחר מיפוי נתמך, אחרת אנגלית. שפת התוכן נפרדת ומתחילה באנגלית. משימות נתמכות יכולות לבחור שפה משלהן; תרגום משתמש ב־`language`. המספרים אינם מוכיחים יכולת שפה של המודל.

## 5. חיפוש

בחרו Tavily עם מפתח או DuckDuckGo במפורש. מפתח Tavily ריק אינו מחליף שירות. שניהם משתמשים ברשת; DuckDuckGo עשוי להביא גם דפי תוצאות. מחקר ביצירה מכותרת כבוי: `enableResearchInGenerateContent`. אחזור מקומי כבוי אף הוא ובעל תחומי תיקיות/משימות נפרדים. קטעים מקומיים שנכנסים להקשר נשלחים ל־LLM הנבחר.

## 6. תהליכי עבודה

השתמשו בבונה התהליך או בשורת DSL עם שם לכל כפתור:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` מפריד שם מפעולות, `>` מפריד מזהי פעולות. מדיניות ברירת המחדל עוצרת בשגיאה מדווחת. ראו [תהליכים](../features/workflows) להיקף ולהשלכות המשך לאחר שגיאה.

## 7. הגדרות מתקדמות

| הגדרה | ערך התחלתי | השפעה |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | ספק ללא ניתוב נפרד למשימה |
| `useMultiModelSettings` | `false` | ספק/מודל לפי משימה |
| `useCustomConceptNoteFolder` | `true` | אפשר תוצרי מושגים אחרי בחירת תיקייה |
| `conceptNoteFolder` | `''` | אין תיקיית מושגים בתחילה |
| `extractConceptsMinimalTemplate` | `true` | כותרת בלבד במושגים עצמאיים |
| `extractConceptsAddBacklink` | `false` | קישורי חזרה בחילוץ עצמאי |
| `moveOriginalFileOnProcess` | `false` | שימור המקור בהוספת קישורים |
| `chunkWordCount` | `3000` | קטעי טקסט משוערים, לא מגבלת tokens |
| `batchConcurrency` | `1` | מקביליות ברירת מחדל לאצווה |
| `enableBatchParallelism` | `false` | תזמון מקביל במסלולים המשתמשים במתג |
| `enableStableApiCall` | `false` | מצב בקשות יציב שנבחר במפורש |
| `customWorkflowErrorStrategy` | `stop_on_error` | עצירה בשגיאת תהליך מדווחת |

גודל הקטע ותקציב tokens לפלט הם דברים שונים. קטע קטן לא פותר כל מגבלת הקשר ומקביליות נמוכה לא מונעת כל שגיאת 429.

## פרופילי הגדרות

ההגדרות הן נתוני תוסף בכספת. גבו לפני שינוי. לייצוא ספקים חוזה מיסוך משלו, לא גיבוי מלא לכספת. בדקו כתובות ומטא־נתונים גם בפלט ממוסך. אל תפרסמו הגדרות גולמיות או גוף אבחון עם הערות פרטיות.

## בעיות תצורה

בדקו ספק/מודל מדויקים בהערה קצרה. אם שדה חסר, בדקו חיפוש, קטגוריה, נראות במצב מפתח וכספת. ציינו גרסה והגדרות מינימליות בלי סודות.
