# התחלה מהירה

<TLDR>התחילו בהערת Markdown לניסיון ובספק שיש לכם גישה אליו. בדקו את קובץ התוצאה לפני תיקייה שלמה. משימות ענן שולחות תוכן; גם מודלים מקומיים דורשים שרת פועל ומודל מוכן.</TLDR>

## 1. הגדרת המודל

1. [התקינו והפעילו](./installation), ופתחו **Settings → Notemd**.
2. בחרו פרופיל, נקודת קצה, פרטי גישה נדרשים ומודל זמין. **Fetch models** אינו תחליף לבדיקת יצירה.
3. הריצו **Test connection** ותקנו בעיות חשבון, מודל או כתובת.
4. מצאו **Concept note folder path** ובחרו תיקייה נפרדת, למשל `concepts`. הערך ההתחלתי ריק; זהו שם שאתם בוחרים.

הורידו תחילה מודל Ollama והשתמשו בשמו המדויק; כתובת ברירת המחדל היא `http://localhost:11434/api`. הפעילו את שרת LM Studio ובחרו `LMStudio`. ראו [מודלים מקומיים](../providers/local). מחקר ברשת דורש חיבור גם כאשר מודל הסיכום מקומי.

## 2. המשימה הראשונה

כתבו ב־`Notemd trial.md` טקסט קצר שמותר לשלוח לספק:

```text
למידת מכונה משתמשת ברשתות עצביות כדי ללמוד דפוסים.
```

הריצו **Process file (add links)** בסרגל הצד או בלוח הפקודות. בדרך כלל המקור נשמר ולצדו נוצר `Notemd trial_processed.md`. פתחו את התוצר. דוגמה אפשרית:

```markdown
[[למידת מכונה]] משתמשת ב[[רשתות עצביות]] כדי ללמוד דפוסים.
```

ייתכן שייווצרו הערות גם בתיקיית המושגים שנבחרה. בדקו קבצים וקישורים; המודל אינו מבטיח רשימת מושגים שלמה או נכונה.

## 3. תכונות נוספות

### חילוץ מושגים

**Extract concepts (current file)** משאיר את המקור ללא שינוי ודורש תיקיית מושגים. בהערות עצמאיות חדשות יש תחילה רק כותרת, ללא קישור חזרה. הפעילו אותו במפורש לפי הצורך. [הערות מושגים](../features/concept-notes).

### מחקר וסיכום

בחרו נושא בעורך Markdown או השתמשו בכותרת, והריצו **Research & summarize**. בחרו במפורש Tavily עם מפתח או DuckDuckGo. הסיכום נוסף להערה הפעילה. פתחו מקורות ואמתו טענות.

### תהליך בלחיצה אחת

ברירת המחדל **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

התהליך מוסיף קישורים, ממלא הערות מתאימות מכותרות בתיקיית המושגים/התיקייה שנבחרה ומתקן Mermaid בתיקיית complete. גם הערות קיימות עשויות להיכלל. התחילו בתיקיית ניסיון. מחקר רשת ויצירת תרשימים כללית אינם נוספים אוטומטית.

## ביטול ובדיקה

**Cancel** עוצר עבודה עתידית שנתמכת בביטול. תוצרים שהושלמו נשארים; זו אינה עסקת שחזור ולא הבטחה להפסקת יצירה או חיוב אצל הספק. המתינו לסיום ובדקו נתיבים והתנגשויות שחזור לפני הרצה חוזרת.

## בעיות

- חשבון/מודל: בדקו פרופיל וחיבור.
- אין מושגים: הגדירו נתיב תיקייה פעיל ולא ריק.
- אין קישורים מועילים: בדקו תשובה והנחיה; אין אורך מינימלי שמבטיח תוצאה.
- מגבלות: שמרו מקביליות `1` בזמן בדיקת מכסות.
