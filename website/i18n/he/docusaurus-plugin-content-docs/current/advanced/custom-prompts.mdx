# הנחיות מותאמות

<TLDR>הנחיה מותאמת שאינה ריקה מחליפה את המובנית כאשר המתג הכללי ומתג המשימה פעילים. שמרו את חוזה הפלט: מנגנון התבנית אינו מחזיר אוטומטית הוראות פורמט שהושמטו.</TLDR>

## סקירה

בדקו קודם את ברירת המחדל בהערה מייצגת. ייתכן שמיקוד תחום או הנחיית מילים נרדפות יספיקו. שנו מדיניות, מבנה או סגנון תרגום לפי הצורך והשוו לפני אצווה.

## אופן הפעולה

### הרכבה

Notemd בוחר הנחיה מובנית/מותאמת, מוסיף הוראות תחום ושפה רלוונטיות וממלא משתנים שהמשימה מספקת. טקסט ההערה יכול להיות הודעה נפרדת. המשתנים אינם כלליים. החלפה עלולה להשמיט `CONCEPT:` או הקשר מחקר; בקשה תקינה אינה מבטיחה פלט שניתן לנתח או לבסס במקורות.

### משתנים

השתמשו ברישיות המדויקת ובסוגריים מסולסלים יחידים:

| משימה | משתנים זמינים |
| ------ | ----------------------- |
| יצירה מכותרת | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| סיכום מחקר | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| תרגום | `{LANGUAGE}`, `{TEXT}` |
| קטעים מקוריים | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` פועל לפי מדיניות שפת המשימה. קישורים וחילוץ מושגים עצמאי שולחים טקסט כתוכן משימה; אל תמציאו מצייני מקום נוספים. שמות לא מוכרים אינם מוחלפים. אלו משתני הנחיה, לא תבניות קובצי מושגים.

### תחום ממוקד

הפעילו למידה ממוקדת והזינו למשל `הנדסת חשמל`. `Relevant Fields` מכוון תשומת לב בלי מסנן קשיח או הוכחה שתוכן אחר הוחרג.

## הגדרות

| משימה | מתג | שדה הנחיה |
| ------ | --------------- | -------------- |
| קישורים | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| כותרות | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| מחקר | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| סיכום Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| מושגים | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| תרגום | `useCustomPromptForTranslate` | `translatePrompt` |
| טקסט מקורי | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

כולן דורשות `enableGlobalCustomPrompts`. טקסט ריק משתמש בהוראה המובנית. לחילוץ טקסט מקורי מאוחד צורה קבועה נפרדת; ההחלפה הרגילה אינה חלה שם. יצירת תרשימים דורשת פלט מטיפוס מוגדר; הנחיית Mermaid אינה כללית.

## דוגמה

הפעילו את המתג הכללי ואת מתג המושגים, ושמרו את סימון המפרש:

```text
חלצו את המושגים המרכזיים בהנדסת חשמל מתוך ההערה.
העדיפו רכיבים קונקרטיים ומנגנונים פיזיקליים על שמות עצם כלליים.
כתבו כל מושג בשורה נפרדת בדיוק בצורה הזאת:
CONCEPT: שם המושג
אל תוסיפו הסברים או בלוק קוד מסביב.
```

על עותק השוו שורות, שמות קבצים ומושגים חסרים מול ברירת המחדל. שמרו את ההנחיה הקודמת כדי לחזור אליה.

## עצות

- בדקו משימה אחת לפני הגדלת אצווה.
- שמרו מקורות מחקר וציטוטים מדויקים.
- תרגמו הוראות תוך שמירת מזהים וסימוני פלט.
- בדקו שוב אחרי החלפת מודל; הנחיה אינה ערובה לוולידציה.
