# פתרון תקלות

<TLDR>שחזרו בהערת ניסיון אחת עם אותו ספק, מודל והגדרות משימה. קראו התקדמות ונתיב פלט. הבדילו בין אימות, יצירה, ניתוח וכתיבה; בדיקת חיבור אינה בודקת תהליך שלם.</TLDR>

## סקירה

רשמו גרסאות Notemd/Obsidian, מערכת הפעלה, פעולה, פרוטוקול, מודל וצעדים מינימליים. אל תתחילו מחדש בזמן שהביטול מסתיים. שמרו תוצרים וקובצי שחזור עד שמקורם ברור.

## אבחון

### בדיקת חיבור

**Test connection** עשוי לבדוק רק רשימת מודלים או יצירה קצרה. אחריו הפעילו משימה קטנה אמיתית עם המודל ופורמט הפלט הנבחרים.

### התקדמות ואבחון למפתחים

התקדמות מראה מצב, שגיאות ונתיבים; פעילות API מבדילה בקשות ממתינות ומוכנות. הפעילו debug לפי הצורך. אבחון ארוך עשוי לצרוך מכסה. דוחות עלולים להכיל הערות, תשובות חלקיות, נקודות קצה ומפתחות. בדקו ומסכו מקומית לפני שיתוף, גם מטא־נתונים בפרופילים ממוסכים.

## שגיאות נפוצות

### מפתח חסר או לא תקין

401: ספק/כתובת נכונים וללא רווחים מקריים. 403: חשבון, פרויקט, גישה למודל וחיוב. ניסיונות חוזרים לא מתקנים פרטי גישה שגויים.

### רשת

בדקו שרת, יציאה, פרוטוקול ונתיב מהמכשיר שבו Obsidian פועל. Ollama/LM Studio חייבים לפעול עם מודל זמין. `localhost` הוא המכשיר הזה, לא מחשב אחר. בחרו פרופיל נכון; fallback נבחר אוטומטית, לא בכפתור תעבורה.

### מגבלת 429

הקטינו מקביליות ובדקו מכסות בקשות/tokens ושימוש נוסף באותו מפתח. ניסיונות חוזרים מסייעים רק לחלק מהתקלות הזמניות.

### המודל לא נמצא

השתמשו ב־**Fetch models** או במזהה מודל/deployment ידוע. בדקו גרסת API ואזור. דוגמאות יכולות להתיישן; Azure דורש deployment ו־Ark עשוי לדרוש מזהה נקודת קצה.

### אין קישורים או מושגים

בדקו קובץ תוצאה אמיתי, מקור שימושי, פורמט תשובה ותיקיית מושגים פעילה שנבחרה. חילוץ עצמאי מתחיל בכותרות בלבד וללא קישורי חזרה. השוו להנחיה המובנית אם סימונים הושמטו.

### פלט חסר או במקום אחר

קראו את הנתיב המדווח של `_processed.md`, `_<language>.md` או complete. יצירת תיקיית תרגום שנכשלה עשויה להפנות לתיקיית המקור. בדקו התנגשויות והרשאות לפני חזרה.

### קבצים אחרי ביטול

כתיבות שהושלמו נשארות ובקשות שהתקבלו יכולות להסתיים. בדקו קבצים והתנגשויות שחזור לפני מחיקה או הרצה חוזרת של כל התיקייה.

### תרשים או ייצוא ליישום

בחרו צמד סוג/מקור נתמך ובדקו סביבת שקופיות/CircuitikZ. תצוגה מקדימה אינה בדיקה ביישום היעד. שמרו מקור טקסט לכלי חיצוני מתאים אם אין תצוגה חזותית. [תרשימים](../features/diagrams).

## דיווח תקלה

1. שחזרו בהערה סינתטית ובתיקיית ניסיון.
2. ציינו גרסאות, פעולה, מודל, הגדרות נדרשות ותוצאה צפויה/אמיתית.
3. צרפו קבצים/יומנים מינימליים ללא מפתחות, תוכן פרטי או פרטי נקודת קצה מיותרים.
4. ציינו אם זה קורה בקובץ אחד עם הנחיות ברירת מחדל.
5. פתחו [GitHub Issue](https://github.com/Jacobinwwey/obsidian-NotEMD/issues).

צילום מסך לבדו כמעט אינו מוכיח תקלה בפורמט או בביטול. ספקו מקור/פלט או רצף שחזור מינימלי כשאפשר.
