# תרגום

<TLDR>Notemd מתרגם קובץ פעיל או קובצי תיקייה מתאימים באמצעות ה־LLM שנבחר. ברירת המחדל היא קובץ נפרד עם סיומת שפה. האיכות תלויה במודל; 21 שפות UI ו־34 שפות אתר אינן גבול או הבטחה לתרגום.</TLDR>

## סקירה

בחרו שפת יעד וספק ובדקו עותק עם מונחים, קישורים וקוד. המשימה משתמשת ב־LLM, לא בשילוב מיוחד של Google Translate. הפעולות חלות על קבצים/תיקיות. העבירו קטע להערה זמנית; בחירה אינה מצמצמת **Translate current file**.

## אופן הפעולה

### משימת תרגום

1. בחרו שפת יעד; בתחילה אנגלית, בנפרד משפת הממשק.
2. פתחו מקור והריצו **Translate current file**.
3. טקסט ארוך מחולק, נשלח ומחובר מחדש.
4. פתחו את הנתיב המדווח ובדקו משמעות, מונחים, ציטוטים, קישורי Markdown וקוד.

תרגום צרפתי של `Example.md` יוצר בדרך כלל `Example_fr.md` לצד המקור שנשמר. פלט קיים נדרס. הוספה למקור או כותרת קבועה `Translation` אינן הבטחות ברירת מחדל.

### זוגות שפות

המודל מסיק את שפת המקור. אפשרות בתפריט אינה מוכיחה איכות לזוג השפות. בדקו שפות מעורבות ומונחים מקצועיים; חלוקה יכולה לאבד הקשר.

### מודל למשימה

ניתוב משימה משתמש ב־`translateProvider`/`translateModel`, אחרת בספק הפעיל. מקומי דורש שרת/מודל, ענן מקבל הנחיה ותוכן. העריכו דוגמה מתחום העבודה שלכם.

### תרגום תיקייה

**Batch translate folder** כולל כברירת מחדל רק ילדים ישירים; פרופילים מתקדמים יכולים לשנות זאת. מקורות בעלי שם זהה לאותה תיקיית פלט עלולים להתנגש. בדקו תרגומים קודמים ויעדים לפני חזרה.

## הגדרות

| הגדרה | ערך התחלתי | השפעה |
| --------- | --------- | -------- |
| `language` | `en` | שפת יעד נבחרת |
| `translateProvider` | `DeepSeek` | ספק בניתוב משימות |
| `translateModel` | `''` | ריק משתמש במודל הספק |
| `useCustomTranslationSuffix` | `false` | קוד שפה כסיומת ברירת מחדל |
| `translationCustomSuffix` | `_translated` | סיומת כשהאפשרות המותאמת פעילה |
| `useCustomTranslationSavePath` | `false` | שמירה ליד המקור כברירת מחדל |
| `translationSavePath` | `''` | תיקיית פלט יחסית לכספת |
| `batchConcurrency` | `1` | מקביליות מבוקשת לתרגום תיקייה |

אם יצירת תיקייה מותאמת נכשלת, ייתכן שימוש בתיקיית המקור. קראו את הנתיב בפועל. סיומת מותאמת ריקה עלולה להצביע על המקור; השתמשו בסיומת מובחנת לתרגום נפרד.

## דוגמה

העתיקו הערה קצרה בסינית לתיקיית ניסיון, בחרו אנגלית ותרגמו. השוו `_en.md` למקור: מונחים, מספרים, נוסחאות וקישורים. רק אז הרחיבו.

## ביטול ובדיקה

ביטול עוצר המשך עבודה נתמך, אינו מחזיר תרגומים מוכנים ואינו מבטיח הפסקת חיוב. בדקו דוח וקבצים. שימור Markdown הוא הנחיה למודל, לא ערובה של המפרש לשוויון משמעות.

## עצות

- גיבוי מקור ובדיקת שמות מתנגשים.
- סיומת ניסיון ותיקיית פלט נפרדות.
- בדיקה ידנית לקוד, מתמטיקה, כתובות ושמות פרטיים.
- עיון באבחון לפני שיתוף.
