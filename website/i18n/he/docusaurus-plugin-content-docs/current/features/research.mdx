# מחקר וחיפוש ברשת

<TLDR>Research & summarize מחפש לפי בחירה או כותרת, מסכם הקשר זמין באמצעות LLM ומוסיף ל־Markdown הפעיל. בחרו במפורש Tavily או DuckDuckGo ואמתו הפניות למקורות.</TLDR>

## סקירה

ספק החיפוש ומודל הסיכום נפרדים. Tavily דורש מפתח; DuckDuckGo לא, אך משתמש ברשת ועשוי להגביל גישה. מודל מקומי אינו הופך מחקר רשת לפעולה ללא רשת.

## אופן הפעולה

### חיפוש וסיכום

1. פתחו את היעד בעורך Markdown; בחרו נושא או השתמשו בכותרת.
2. הריצו **Research & summarize**.
3. Tavily מספק קטעים; DuckDuckGo עשוי להביא דפי תוצאות.
4. הקשר מקומי מותר עשוי להתווסף מההיקף שנבחר.
5. המודל כותב תחת `Research Summary` עם נושא וסוג מקור.
6. פתחו כתובות רלוונטיות ובדקו טענות. הקשר שנשלף אינו מוכיח כל ציטוט שנוצר.

### Tavily או DuckDuckGo

| בחירה | הכנה | גבול תפעולי |
| -------- | ------- | ---------------------- |
| Tavily | בחרו Tavily והזינו מפתח | מכסות חשבון וקטעים שהוחזרו |
| DuckDuckGo | בחרו DuckDuckGo במפורש | ללא מפתח; הגבלות חיפוש וזמינות עמודים |

מפתח Tavily ריק או שגוי אינו מעביר שירות אוטומטית. בדקו את הדוח כאשר הקשר הרשת דל. קטעים מקומיים פעילים עדיין יכולים לתמוך בסיכום; תווית המקור מבדילה זאת מטקסט המבוסס על הרשת.

### מחקר ביצירה מכותרת

**Enable research in "Generate from title"** מוסיף מחקר גם לגרסת האצווה וכבוי בתחילה. זהו מסלול התיקייה הנתמך; אין פעולה עצמאית כללית בשם Research Folder.

## הגדרות

| הגדרה | ערך התחלתי | השפעה |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | בחירת שירות חיפוש |
| `tavilyApiKey` | `''` | מפתח Tavily |
| `tavilyMaxResults` | `5` | מספר תוצאות Tavily מבוקש |
| `tavilySearchDepth` | `basic` | עומק חיפוש Tavily |
| `ddgMaxResults` | `5` | מספר תוצאות DuckDuckGo מבוקש |
| `ddgFetchTimeout` | `15` | זמן קצוב לדפי תוצאות בשניות |
| `maxResearchContentTokens` | `3000` | תקציב הקשר רשת משוער |
| `researchProvider` | `DeepSeek` | ספק סיכום בניתוב משימות |
| `researchModel` | `''` | ריק משתמש במודל הספק |
| `researchSummarizeLanguage` | `en` | שפת פלט לפי משימה |
| `enableResearchInGenerateContent` | `false` | אפשר מחקר ביצירה מכותרת |
| `enableLocalKnowledgeRetrieval` | `false` | אפשר חיפוש מקומי בנפרד |
| `enableLocalKnowledgeForResearchSummarize` | `false` | חיפוש מקומי למשימה זו |

### הקשר ומודל

גבולות הקשר הם הערכות, לא ספירת tokens מדויקת של הספק. קיטום עלול להסיר ראיות. מקדו שאלות ותקציב מודל/פלט. האינדקס המקומי לקסיקלי, ללא embeddings משתמעים או הבטחה לאחזור מלא.

## דוגמה

צרו `קידוד מיקום יחסי`, בצעו מחקר והשוו לפרסומים המקוריים או לתיעוד רשמי. שמרו שאלה, כתובות אמיתיות ותיקונים כדי שאפשר יהיה לבדוק את המסקנה. זו דוגמה, לא חיפוש שכבר בוצע בכספת שלכם.

## ביטול ופרטיות

תוספות שהושלמו נשארות. בקשת מודל/דף שהתקבלה עשויה להסתיים. שירות החיפוש מקבל שאלה, אתרים בקשות וה־LLM את כל ההקשר, כולל קטעים מקומיים מותרים. בדקו אבחון לפני שיתוף.

## עצות

- הבדילו בין מקור רשת, הערה מקומית והסקת מודל.
- אמתו ציטוטים, תאריכים וטענות חשובות במקור.
- בדקו חיפוש ו־LLM בנפרד בשאלה קטנה.
- קראו סיכומים קיימים כדי להימנע מתוספות כפולות.
