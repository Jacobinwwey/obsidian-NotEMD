# הערות מושגים

<TLDR>חילוץ עצמאי קורא את המקור ויוצר מושגי Markdown בתיקייה נבחרת. בתחילה לא מוגדרת תיקייה. הערות חדשות מכילות כותרת בלבד וללא קישור חזרה. הוספת קישורים משתמשת בצורת מושג אחרת.</TLDR>

## סקירה

הגדירו קודם **Concept note folder path**. תיקייה נפרדת מקלה על בדיקת תוצרים, כפילויות ויצירה עתידית מכותרות. החילוץ אינו ממלא אוטומטית את הקבצים בהסברים מבוססי מחקר.

## אופן הפעולה

### חילוץ

ה־LLM הנבחר מקבל טקסט. המשימה קוראת שורות `CONCEPT:`, מסירה שמות חוזרים בתוך הפעולה ויוצרת/מעדכנת קבצים. הערות ארוכות מחולקות. בדקו חלקים שנכשלו; תשובה אינה רשימת מושגים מלאה בהכרח.

### הנחיית החילוץ

ברירת המחדל מבקשת מושגים קונקרטיים ורלוונטיים. הנחיות תחום ומילים נרדפות אינן מבטיחות אוצר מילים מוסכם. בהנחיה מותאמת שמרו `CONCEPT: Term`. ראו [הנחיות](../advanced/custom-prompts).

### קטעים

`chunkWordCount` מתחיל בכ־3000 מילים, לא תקציב tokens של הספק. ההקשר מעבר לגבול קטע מוגבל; בדקו יחסים ושמות עמומים.

## יצירת קבצים

### כללי שמות

תווים לא חוקיים לנתיב מוסרים, רווחים מנורמלים ושמות ארוכים מתקצרים; תוצאה ריקה נזנחת. מונחים שונים עלולים להפוך לאותו נתיב. בדקו שמות לפני יצירה המונית.

### תבניות

צורה מינימלית חדשה:

```markdown
# שם המושג
```

לקישור חזרה בהערה עצמאית חדשה, הפעילו **Add "Linked From" backlink** וכבו **Create minimal concept notes**:

```markdown
# שם המושג

## Linked From
- [[הערת מקור]]
```

הוספת קישורים משתמשת בצורה מלאה עם הפניה למקור כאשר תוצרי מושגים פעילים. מתגי חילוץ עצמאי אינם משנים את המסלול הזה.

### הערות קיימות

כשקישורי חזרה פעילים, הפניית מקור חסרה יכולה להתווסף תחת `## Linked From`. הטקסט הקיים נשמר ואותו קישור לא מתווסף פעמיים. שם הבסיס של המקור עלול להיות דו־משמעי בין תיקיות.

### הגדרות

| הגדרה | ערך התחלתי | השפעה |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | תוצרי מושגים אחרי בחירת תיקייה |
| `conceptNoteFolder` | `''` | טרם הוגדרה תיקייה |
| `extractConceptsMinimalTemplate` | `true` | כותרת בלבד במושגים עצמאיים |
| `extractConceptsAddBacklink` | `false` | קישורי חזרה בחילוץ עצמאי |
| `extractConceptsProvider` | `DeepSeek` | ספק בניתוב משימות |
| `extractConceptsModel` | `''` | ריק משתמש במודל הספק |
| `extractConceptsLanguage` | `en` | שפה כאשר שפות לפי משימה פעילות |
| `replaceSynonymsDuringConceptExtraction` | `false` | הנחיה לצמצום מילים נרדפות |
| `generateConceptLogFile` | `false` | יומן מושגים אופציונלי |

## כפילויות

הבדיקה משתמשת בהיוריסטיקת שמות: רישיות, רבים, נרמול סימנים ובמקרים מותרים מילה בתוך שם אחר. זה אינו מוכיח שוויון משמעות. בדקו צורות חריגות והבדלים טכניים דרך **Check & remove duplicates**, ואשרו רק מחיקות רצויות. Obsidian מנהל את פעולת האשפה. תיקיית מושגים אינה מטמון חד־פעמי; גבו אותה.

### היקף השוואה

השוו לכספת, לתיקיית המושגים עצמה, לתיקיות כלולות או להיקף עם החרגות. ההיקף משנה מועמדים, לא את משמעות הכפילות.

## שימוש

### חילוץ עצמאי

פתחו Markdown, בדקו תיקייה ובחרו **Extract concepts (current file)**. המקור נשאר. בדקו שמות, כיסוי וקישורי חזרה.

### חילוץ ותוכן

**Batch generate from titles** ממלא הערות מושגים אך עשוי לכלול קבצים מתאימים קודמים. בדקו את התיקייה לפני ההרצה ואת תיקיית complete המדווחת אחריה.

### קישור מבחירה

פעולת הבחירה הופכת מונח שבחרתם לקישור Wiki ויכולה ליצור קובץ מושג אם היעד הוגדר.

## עצות

- מקור קטן ותיקייה נפרדת.
- בחירת שפה לפני יצירה המונית.
- בדיקה נפרדת למילים נרדפות ולכפילויות.
- שמירת יומנים נדרשים לפני ריצה שתחליף אותם.
