# Google

<TLDR>Google משתמש ב־Gemini Generative Language המקורי. הגדירו מפתח מורשה ומודל זמין. ל־Gemini דרך שער תואם בחרו בפרופיל השער.</TLDR>

## הכנה

בחרו **Google**, מפתח, כתובת API מקורית ומודל בגרסה שנבחרה. בדקו חיבור והערה. זה אינו מגדיר אוטומטית פריסת Google Cloud/Vertex שרירותית.

## נקודת קצה ואימות

| שדה | ערך התחלתי |
| ------- | -------------- |
| תעבורה | `google` |
| מפתח API | נדרש |
| כתובת בסיס | `https://generativelanguage.googleapis.com/v1` |
| מודל | `gemini-2.0-flash-exp` |
| טמפרטורה | `0.5` |
| בדיקת חיבור | `chat-only` |

נשלחת בקשת `generateContent` עם מפתח. מזהים היסטוריים אינם מבטיחים גישה. בדקו כתובות אבחון לפני שיתוף; הן עלולות להכיל פרטי אימות.

## מודלים

השתמשו בגילוי הספק ואמתו יצירה ב־API הנבחר. רשימה ריקה עשויה לנבוע מהרשאות, כתובת או מודל חסר. אבחנו לפני החלפת פרוטוקול.

## תקלות

- 400: מזהה, פרמטרים וגבולות קלט/פלט.
- 401/403: מגבלות מפתח, API פעיל והרשאות.
- 404: האם המודל זמין בגרסת API זו?
- דוגמאות שער: השתמשו בפרופיל OpenAI-compatible המתאים.

## מתי לבחור

ל־Gemini דרך ה־API המקורי. בדקו תרגום, מחקר או תרשימים בחומר שלכם. אין הבטחת מהירות, מחיר או איכות כללית.
