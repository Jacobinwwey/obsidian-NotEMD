# Anthropic

<TLDR>השתמשו בפרופיל ל־Messages המקורי. Claude דרך שער OpenAI-compatible משתמש בפרופיל השער. ייתכן שצריך להחליף את מודל ההתחלה ההיסטורי במודל שזמין בחשבון.</TLDR>

## הכנה

בחרו **Anthropic**, מפתח ומודל נגיש. שמרו את כתובת ה־API המקורית אלא אם הפריסה מספקת אותו פרוטוקול. בדקו חיבור והערה.

## נקודת קצה ואימות

| שדה | ערך התחלתי |
| ------- | -------------- |
| תעבורה | `anthropic` |
| מפתח API | נדרש |
| כתובת בסיס | `https://api.anthropic.com` |
| מודל | `claude-3-5-sonnet-20240620` |
| טמפרטורה | `0.5` |
| בדיקת חיבור | `chat-only` |

המסלול משתמש ב־`/v1/messages` עם כותרות המפתח והגרסה הייעודיות. אל תוסיפו נתיב chat של OpenAI. הערכים מתארים את תצורת המאגר, לא זמינות מודלים עכשווית.

## מודלים

השתמשו בגילוי דרך API הספק כשאפשר. אם הרשימה חסומה, הזינו מזהה מורשה ובדקו יצירה. משימות ארוכות ומובנות צריכות בדיקות נפרדות.

## תקלות

- 401/403: מפתח, פרויקט, חיוב וגישה למודל.
- 404: כתובת וזמינות.
- מזהה שער נדחה: בחרו פרופיל/מזהה מתאימים.
- כשבקשות ארוכות נכשלות בדקו גבולות לפני הוספת חזרות.

## מתי לבחור

לנקודות קצה בפרוטוקול Messages המקורי. השוו למקורות שלכם בלי דירוג ספקים אוניברסלי. ניתוב משימות מאפשר שימוש ממוקד.
