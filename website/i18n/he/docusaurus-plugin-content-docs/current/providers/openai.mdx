# OpenAI

<TLDR>הפרופיל משתמש במסלול OpenAI Chat Completions המשותף. בחרו מפתח ומודל לפרוטוקול הזה. מודל ההתחלה אינו מבטיח גישה נוכחית או איכות כללית.</TLDR>

## הכנה

לשירות הרשמי בחרו **OpenAI**, מפתח ו־`https://api.openai.com/v1`. מודל שמופיע ברשימה עשוי לדרוש API אחר. לשערים פרופילים/כותרות משלהם; Azure משתמש ב־**Azure OpenAI**, deployment וגרסת API.

## נקודת קצה ואימות

| שדה | ערך התחלתי |
| ------- | -------------- |
| תעבורה | `openai-compatible` |
| מפתח API | נדרש |
| כתובת בסיס | `https://api.openai.com/v1` |
| מודל | `gpt-4o` |
| טמפרטורה | `0.5` |
| בדיקת חיבור | `models-then-chat` |

צורות URL מוכרות מנורמלות לפני בניית מסלולים. התחילו בפרופיל ובדקו את הכתובת שנוצרה במקום להוסיף מקטעי נתיב באקראי.

## מודלים

**Fetch models** מביא מודלים זמינים. **Test connection** יכול להצליח מרשימה בלבד. בדקו את המודל המדויק בהערה. Reasoning, thinking, דגימה ותקציבים צריכים להתאים לפרופיל/מודל.

## תקלות

- 401/403: מפתח, פרויקט, הרשאות וחשבון.
- 404: כתובת, מזהה מודל ותמיכת API.
- רשימה עובדת אך יצירה לא: בדקו שגיאת chat ופרמטרים.
- תשובה ארוכה נקטעת: קלט, תקציב ותשובה; בדיקה קצרה אינה מכסה זאת.

## מתי לבחור

לנקודות OpenAI ישירות שתומכות ב־Chat Completions. העריכו הערות משלכם; מחירים וזמינות משתנים ללא קשר ל־Notemd.
