# שדרוג ל־Notemd 1.9.8

<TLDR>1.9.8 מתמקד בביטול, בעלות על פלט, אחזור עקבי באצווה, ייצוא ליישומים ותיעוד מדויק. בדקו זמינות בגרסת GitHub הציבורית וקחו קבצים מאותה גרסה. מספרי הספקים והתרשימים הם יכולות שהיו קיימות.</TLDR>

## מאז 1.9.7

| תחום | השפעה |
| ------ | ------------- |
| ביטול | מצב משותף בתזמון, תעבורה וחזרות; תשובה מאוחרת לא מתחילה כתיבה מוגנת |
| עמידות תוצרים | בעלות על מקורות בעלי אותו שם וקבצים נלווים משותפים בשמירה/שחזור חופפים |
| אחזור מקומי | תמונת מצב אחת לאצוות כותרות; קורפוס קבוע ומדידות זיכרון |
| פלט ליישומי יעד | תיקון מפרידי PowerPoint מתחת לתאים ממוזגים וחיווט/תוויות CircuitikZ |
| אימות | CI ל־Linux/Windows, lint ברמת אבחנה, בדיקות תהליכים וראיות מיישומים |
| מסמכים | ברירות מחדל אמיתיות, ארבע כניסות קהל, תרגום ישיר ופרסום מבוקר |

חיפוש ההיסטוריה שומר הקלדה רציפה וסמן ברענון אסינכרוני. המגירה לוכדת Tab, מקבלת מיקוד בטעינה ונסגרת ב־Escape בלי לסגור את התצוגה ההורית. חזרות ותשובות ישנות מכוסות ברגרסיות דפדפן.

מחקר/תרגום בודקים ביטול אחרי הקריאה האחרונה או הכנת התיקייה ולפני הוספה/יצירה/דריסה. כתיבה שהכספת קיבלה נשארת תוצאה שהושלמה. תיקיית תרגום שמשימה אחרת יצרה בזמן ההמתנה משמשת שוב בלי לייחס את יצירתה למשימה הנוכחית. קובץ מתנגש או תיקייה שעדיין חסרה משמרים שגיאה מדווחת וחזרה לתיקיית המקור.

36 הפרופילים ו־33 פריטי התרשימים הניתנים להרצה כבר היו ב־1.9.7. קוד הריצה, התיעוד ומיזוגי Git נספרים בנפרד.

## שדרוג מבוקר

1. עצרו משימות וגבו כספת/הגדרות.
2. עדכנו דרך Community plugins או הורידו `main.js`, `manifest.json`, `styles.css` מאותה [1.9.8 ציבורית](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/tag/1.9.8).
3. בהתקנה ידנית החליפו רק קובצי הפעלה; שמרו הגדרות ותוצרים.
4. טענו מחדש ובדקו גרסה.
5. בדקו הערת ניסיון ותיקייה קטנה לפני אצוות גדולות.

מזהי פקודות והגדרות נשמרים. One-Click Extract עדיין מבצע קישורים, יצירה מכותרות באצווה ותיקון Mermaid. תיקון תיעוד אינו מוסיף מחקר לשרשרת ברירת המחדל.

## ביטול ושחזור

ביטול אינו עסקה הפוכה. קבצים מוכנים נשארים, בקשות/כתיבות שהתקבלו עשויות להסתיים והספק שולט בחיוב. המתינו ובדקו. השוו התנגשויות גלויות וקובצי שחזור לפני ניקוי. שמרו תיקיות נלוות שעדיין משמשות תוצרים ישנים.

## גבולות ייצוא ותאימות

- ל־PowerPoint בדיקות ממוקדות ביישום; ציון תמונה כולל החמיץ בעבר את הפגם.
- Mermaid/SVG ב־PPTX עשויים להופיע כתמונות.
- חצי Drawnix סטטיים בין ענפים אינם מוכחים כמחוברים אחרי פריסה מחדש.
- תצוגת CircuitikZ והידור TeX הן בדיקות נפרדות.
- מכשירים ניידים פיזיים ו־Obsidian 0.15.0 עדיין לא אומתו.
- מדגם לקסיקלי קבוע אינו מוכיח חיפוש סמנטי או ביצועים בכל כספת.

## שלמות ההפצה

המפרסם בודק גרסה וזהות תג מקומי/מרוחק, בונה מחדש מקור נקי מתויג, מעלה קובצי טיוטה ומשווה גיבובים לאחר הורדה לפני הפרסום. `main.js`, `manifest.json`, `styles.css`, `README.md` נדרשים. חזרה אינה רשאית להחליף בתים ציבוריים בפלט לא קשור.

Pages נפרס אחרי אימות גרסה ציבורית. Codex כותב ובודק ישירות בלי LM Studio או מנוע תרגום. זו אינה טענה לבדיקת דובר ילידי בלתי תלוי.
