# Notemd 1.9.12 — תצוגת אבחון נקייה יותר

<TLDR>
כשאין שגיאות, כל לוח האבחון מכווץ כברירת מחדל ורק הכותרת והמונים לפי חומרה נשארים גלויים. שגיאות פותחות את הלוח אוטומטית. הרחיבו את הלוח ואת קבוצות התגים כדי לקרוא את כל ההודעות וההצעות. לא נמחקות רשומות אבחון. רק קבוצות שגיאות נפתחות אוטומטית; אזהרות ומידע נשארים מכווצים גם אם הם חולקים את אותו תג.
</TLDR>
