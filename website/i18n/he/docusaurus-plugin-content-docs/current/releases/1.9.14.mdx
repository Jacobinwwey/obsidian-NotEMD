# Notemd 1.9.14 — תצוגות PDF חדות וייצוא למספר פורמטים

<TLDR>
קובצי PNG/PDF נפתחים בתצוגה המקדימה של תרשימים. לכל עמוד PDF פקדים נפרדים. שינוי הזום מצייר מחדש את האזור הגלוי בצפיפות הפיקסלים של המסך ובזיכרון מוגבל; תמונות רסטר מוטמעות נשארות מוגבלות לרזולוציית המקור.
</TLDR>

החזיקו Alt כדי לעצור ניווט בזמן בחירת טקסט זמין ב-SVG/HTML/PDF. שחרור המקש משחזר את מצב הנעילה הקודם. ל-PNG אין שכבת טקסט הניתנת לבחירה.

בחרו SVG, PNG ו/או PDF ותיקיית יעד, ואשרו פעם אחת. הייצוא הראשי כולל את כל הלוחות; ייצוא של לוח כולל רק אותו. פורמטי המצגת נבחרים בתיבות סימון ונדרשת בחירה אחת לפחות. ההתקדמות והכשלים החלקיים נשארים גלויים.

התקינו את main.js, manifest.json ו-styles.css התואמים לגרסה 1.9.14 וטענו מחדש את התוסף. ההערות וההגדרות הקיימות נשמרות.
