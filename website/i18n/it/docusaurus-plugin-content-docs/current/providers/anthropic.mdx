# Provider Anthropic

<TLDR>Questo profilo usa Messages nativo. Per Claude tramite gateway OpenAI-compatible scegli il profilo del gateway. Conferma la disponibilità del modello: il nome storico iniziale può richiedere sostituzione.</TLDR>

## Preparazione

Scegli **Anthropic**, chiave e modello accessibile. Conserva l’endpoint nativo salvo deployment che esponga lo stesso protocollo. Prova connessione e attività su una nota temporanea.

## Endpoint e autenticazione

| Campo | Valore iniziale |
| ------- | -------------- |
| Trasporto | `anthropic` |
| Chiave API | Obbligatoria |
| URL base | `https://api.anthropic.com` |
| Modello | `claude-3-5-sonnet-20240620` |
| Temperatura | `0.5` |
| Test di connessione | `chat-only` |

La richiesta usa `/v1/messages` e header nativi di chiave e versione. Non aggiungere rotte OpenAI chat. I valori descrivono il profilo del repository, non una disponibilità attuale garantita.

## Modelli

Usa la scoperta nativa quando disponibile. Se l’elenco è limitato, inserisci un ID autorizzato e prova la generazione. Valida separatamente output strutturati e attività lunghe.

## Problemi

- `401`/`403`: chiave, progetto, pagamenti e diritti.
- `404`: endpoint e disponibilità attuale.
- ID di gateway rifiutato: scegli protocollo e identificatore corretti.
- Richieste lunghe interrotte: leggi errore e limiti prima di aumentare i tentativi.

## Quando usarlo

Per endpoint Messages nativi. Confronta risultati sulle tue fonti senza assumere superiorità universale. L’instradamento per attività consente scelte specifiche.
