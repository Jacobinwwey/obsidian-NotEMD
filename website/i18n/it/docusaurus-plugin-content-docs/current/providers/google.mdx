# Provider Google

<TLDR>Il profilo usa Gemini Generative Language nativo. Configura chiave autorizzata e modello disponibile. Gemini esposto da un gateway OpenAI-compatible richiede il profilo del gateway.</TLDR>

## Preparazione

Scegli **Google**, chiave, endpoint nativo e modello della versione API selezionata. Prova connessione e nota. Il profilo non configura automaticamente deployment arbitrari Google Cloud o Vertex.

## Endpoint e autenticazione

| Campo | Valore iniziale |
| ------- | -------------- |
| Trasporto | `google` |
| Chiave API | Obbligatoria |
| URL base | `https://generativelanguage.googleapis.com/v1` |
| Modello | `gemini-2.0-flash-exp` |
| Temperatura | `0.5` |
| Test di connessione | `chat-only` |

La runtime costruisce una richiesta `generateContent` con chiave API. Il nome storico non garantisce disponibilità. Rivedi gli URL nei report prima di condividerli: possono contenere autenticazione.

## Modelli

Usa la scoperta nativa e verifica la generazione sulla versione API scelta. Un elenco vuoto può dipendere da permessi, endpoint o modello assente. Diagnostica prima di cambiare protocollo.

## Problemi

- `400`: ID, parametri e limiti di input/output.
- `401`/`403`: restrizioni della chiave, API attiva e permessi.
- `404`: disponibilità nella versione API.
- Esempi di gateway: usa il corrispondente profilo OpenAI-compatible.

## Quando usarlo

Per Gemini nativo. Valuta traduzioni, ricerca o diagrammi con un campione rappresentativo; velocità, prezzo e qualità non sono garanzie universali.
