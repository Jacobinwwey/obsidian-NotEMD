# Provider OpenAI

<TLDR>
Il profilo usa la runtime condivisa compatibile con OpenAI Chat Completions. Configura chiave e modello che accetti questo protocollo. Il valore iniziale non garantisce accesso attuale o qualità universale.
</TLDR>

## Preparazione

Scegli **OpenAI**, chiave e `https://api.openai.com/v1` per il servizio ufficiale. Essere elencato non rende compatibile un modello disponibile solo mediante un’altra API.

Per gateway usa il relativo profilo e gli header attesi. Azure richiede **Azure OpenAI**, deployment e versione API.

## Endpoint e autenticazione

| Campo | Valore iniziale |
| ------- | -------------- |
| Trasporto | `openai-compatible` |
| Chiave API | Obbligatoria |
| URL base | `https://api.openai.com/v1` |
| Modello | `gpt-4o` |
| Temperatura | `0.5` |
| Test di connessione | `models-then-chat` |

La runtime normalizza forme note dell’URL prima di costruire le rotte. Parti dal profilo e controlla l’indirizzo risolto, senza aggiungere segmenti a caso.

## Modelli

**Fetch models** interroga l’endpoint. **Testa connessione** può riuscire con la sola lista. Prova poi una nota con il modello esatto.

Reasoning, thinking, campionamento e limiti seguono regole del profilo e del modello. Un modello elencato non accetta necessariamente ogni parametro.

## Problemi

- `401`/`403`: chiave, progetto, diritti e account.
- `404`: endpoint, ID e API compatibile.
- Lista valida ma attività fallita: controllare errore chat e parametri.
- Risposta lunga troncata: budget, input e risposta; un test breve non copre tutto.

## Quando usarlo

Per OpenAI diretto compatibile con Chat Completions. Valuta le tue note; prezzi e disponibilità cambiano indipendentemente da Notemd.
