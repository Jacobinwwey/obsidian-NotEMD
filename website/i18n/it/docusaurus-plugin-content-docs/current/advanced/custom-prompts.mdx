# Prompt personalizzati

<TLDR>
Un prompt personalizzato sostituisce quello integrato quando le opzioni globale e specifica sono attive e il testo non è vuoto. Conserva il formato richiesto: nessun sistema ripristina automaticamente tutte le istruzioni omesse.
</TLDR>

## Panoramica

Prova prima il prompt standard. Dominio o riduzione dei sinonimi possono bastare. Personalizza criteri, struttura o stile e confronta i risultati prima del lotto.

## Funzionamento

### Composizione

Notemd sceglie il prompt, aggiunge istruzioni applicabili di dominio/lingua e sostituisce le variabili fornite dall’attività. Il testo può essere un messaggio separato. Le variabili non sono universali.

Una sostituzione può eliminare `CONCEPT:` o il contesto di ricerca. Richiesta valida non significa output analizzabile o affermazioni documentate.

### Variabili

Usa maiuscole esatte e parentesi graffe singole:

| Attività | Variabili disponibili |
| ------ | ----------------------- |
| Generazione dal titolo | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Sintesi di ricerca | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Traduzione | `{LANGUAGE}`, `{TEXT}` |
| Estrazione originale | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` segue la politica dell’attività. Link e concetti autonomi inviano testo come contenuto; non inventare variabili. I nomi sconosciuti non vengono compilati. Non sono modelli di file concettuali.

### Dominio mirato

Abilita l’apprendimento mirato e indica un dominio, ad esempio `ingegneria elettrica`. `Relevant Fields` orienta il modello, senza essere un filtro rigido.

## Impostazioni

| Attività | Attivazione | Campo del prompt |
| ------ | --------------- | -------------- |
| Link | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titoli | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Ricerca | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Sintesi Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Concetti | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Traduzione | `useCustomPromptForTranslate` | `translatePrompt` |
| Testo originale | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Tutti richiedono `enableGlobalCustomPrompts`. Testo vuoto usa il prompt integrato. L’estrazione originale aggregata ha un formato separato e non usa l’override ordinario. I diagrammi richiedono output tipati; il prompt Mermaid non è universale.

## Esempio

Abilita le opzioni globale e dei concetti e conserva il marcatore:

```text
Estrai i concetti centrali di ingegneria elettrica dalla nota fornita.
Preferisci componenti specifici e meccanismi fisici ai nomi generici.
Restituisci un concetto per riga in questo formato esatto:
CONCEPT: Nome del termine
Non aggiungere spiegazioni o blocchi di codice esterni.
```

Prova una copia e controlla voci, file e omissioni. Confronta con il prompt standard e conserva quello precedente per ripristinarlo.

## Consigli

- Prova un’attività prima di ampliare i lotti.
- Conserva prove di ricerca e citazioni esatte.
- Traduci le istruzioni mantenendo ID e marcatori.
- Ripeti i controlli dopo cambio modello: istruzioni non equivalgono a validazione.
