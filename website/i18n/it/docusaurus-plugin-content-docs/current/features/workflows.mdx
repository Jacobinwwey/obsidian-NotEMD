# Flussi di lavoro

<TLDR>
Un flusso esegue azioni esistenti in ordine. Può richiedere editor o selezione di cartella. Ogni azione conserva input, output ed effetti: non è una pipeline di testo arbitraria. Inizia con nota di prova e cartella dedicata.
</TLDR>

## Panoramica

Definizione inclusa di **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Aggiungere link alla nota attiva e concetti con cartella configurata.
2. Generare contenuto per note idonee nuove e precedenti nella cartella dei concetti o scelta.
3. Correggere Mermaid nella cartella complete prodotta.

La sequenza iniziale non include ricerca Web. La generazione può aggiungerla con la propria opzione. Vedi [lotti](../advanced/batch-processing).

## Funzionamento

### Esecuzione

Le fasi sono sequenziali e la barra indica stato e fallimenti. Annullare ferma le fasi successive e le richieste supportate. Le scritture concluse rimangono; nessuna reversibilità globale.

La cartella concettuale configurata è la prima scelta. La generazione in lotto registra fonte e complete; la correzione Mermaid successiva usa complete. Altre azioni mantengono requisiti di file, selezione o dialogo.

### DSL

Una riga per pulsante. `::` divide nome e azioni, `>` gli ID. Righe vuote o iniziate da `#` vengono ignorate; ID sconosciuti rifiutati.

```text
Estrai e rappresenta::extract-concepts-current>summarize-as-mermaid
```

Usa il costruttore o modifica la DSL. Gli ID sono stabili, le etichette seguono la lingua UI. Le varianti di cartella hanno ID propri, non sostituzioni generiche.

| Identificatore | Azione / requisito |
| ------------ | ----------------------- |
| `process-current-add-links` | Collegare la nota attiva |
| `process-folder-add-links` | Collegare le note di una cartella |
| `extract-concepts-current` | Estrarre concetti dalla nota attiva |
| `extract-concepts-folder` | Estrarre concetti da una cartella |
| `generate-from-title` | Generare dal titolo attivo |
| `batch-generate-from-titles` | Generare note idonee da titoli |
| `research-and-summarize` | Ricercare selezione/titolo nell’editor Markdown |
| `summarize-as-mermaid` | Riassumere input attivo supportato in Mermaid |
| `generate-diagram` | Seleziona più tipi di diagramma in un’esecuzione e più formati indipendenti per ciascun tipo. Deselezionare un tipo conserva i suoi formati; senza selezioni il contenuto viene analizzato automaticamente. |
| `preview-diagram` | Aprire anteprima di fonte o artefatto supportato |
| `translate-current-file` | Tradurre file attivo supportato |
| `batch-translate-folder` | Tradurre cartella |
| `extract-original-text` | Estrarre passaggi originali richiesti |
| `batch-extract-original-text` | Estrarre passaggi dai file idonei |
| `split-note-by-chapters` | Dividere nota attiva per capitoli |
| `batch-mermaid-fix` | Correggere Mermaid nella cartella |
| `fix-formula-current` | Normalizzare delimitatori delle formule attive |
| `batch-fix-formula` | Normalizzare formule nella cartella |
| `check-duplicates-current` | Controllare duplicati della nota attiva |
| `check-remove-duplicate-concepts` | Esaminare ed eliminare concetti duplicati interattivamente |
| `test-llm-connection` | Provare provider |
| `probe-slide-export-env` | Verificare ambiente locale delle slide |
| `export-slides` | Esportare file attivo come slide |

### Pulsanti personalizzati

One-Click Extract è incluso; gli altri sono definizioni personali. Imposta nome, azioni e ordine e controlla il suggerimento nella barra. Correggi gli errori di parsing prima dell’uso.

## Impostazioni

| Impostazione | Valore iniziale | Effetto |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Fermarsi al primo errore segnalato |
| `useMultiModelSettings` | `false` | Provider attivo fino all’attivazione delle scelte specifiche |
| `enableResearchInGenerateContent` | `false` | Ricerca esclusa dai titoli salvo attivazione |

`continue_on_error` consente fasi successive dopo un errore. Usalo solo se gli input residui bastano; un flusso parziale non diventa completo.

### Modelli specifici

Ogni attività conserva la scelta del modello. Un valore vuoto usa quello del provider. Verifica tutte le rotte per materiale privato.

## Esempio

Prepara `trial-concepts` vuota e prova una nota. Esamina concetti e complete. Esegui prima le azioni singole se i percorsi non sono chiari, poi amplia.

## Consigli

- Mantieni catene brevi e output attribuibili.
- Evita pulizia/eliminazione incustodita: le conferme restano richieste.
- Dopo annullamento o conflitto esamina report e file.
- Prova modello e ambito esatti; una connessione valida non garantisce quote per lotti lunghi.
