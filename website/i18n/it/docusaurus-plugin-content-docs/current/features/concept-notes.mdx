# Note dei concetti

<TLDR>
L’estrazione autonoma legge la fonte e crea concetti Markdown nella cartella scelta, inizialmente vuota nelle impostazioni. Le nuove note hanno solo titolo e nessun backlink. L’aggiunta di link usa un modello diverso.
</TLDR>

## Panoramica

Imposta **Percorso cartella note concetto** prima dell’estrazione. Una cartella dedicata facilita revisione, duplicati e generazione successiva. Estrarre non riempie ogni nota con spiegazioni ricercate.

## Funzionamento

### Estrazione

Il LLM riceve il testo; le righe `CONCEPT:` vengono analizzate, i nomi deduplicati nell’operazione e i file creati/aggiornati. Le note lunghe sono divise. Esamina gli errori: il modello non garantisce un inventario esaustivo.

### Prompt

Il prompt integrato richiede concetti specifici del tema. Dominio e riduzione dei sinonimi guidano senza garantire un lessico canonico. Un prompt personalizzato deve mantenere `CONCEPT: Term`. Vedi [prompt](../advanced/custom-prompts).

### Suddivisione

`chunkWordCount` vale inizialmente 3000 parole approssimative, non token del provider. Il contesto tra frammenti è limitato; rivedi concetti vicini e nomi ambigui.

## Creazione dei file

### Nomi

Si eliminano caratteri di percorso non ammessi, normalizzano spazi e troncano nomi lunghi. Nomi vuoti vengono saltati. Espressioni diverse possono quindi produrre lo stesso file; controlla prima di grandi raccolte.

### Modelli di nota

Forma minima iniziale:

```markdown
# Nome del concetto
```

Per backlink in nuove note autonome, abilita **Add "Linked From" backlink** e disabilita **Create minimal concept notes**:

```markdown
# Nome del concetto

## Linked From
- [[Nota di origine]]
```

L’aggiunta di link crea la forma completa quando la cartella concettuale è attiva. Le opzioni dell’estrazione autonoma non cambiano quel comportamento.

### Note esistenti

Con backlink attivi viene aggiunta la fonte mancante sotto `## Linked From`, mantenendo il corpo e senza duplicare lo stesso link. La fonte usa il basename; verifica note omonime.

### Impostazioni

| Impostazione | Valore iniziale | Effetto |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Consentire concetti dopo scelta cartella |
| `conceptNoteFolder` | `''` | Nessuna cartella iniziale |
| `extractConceptsMinimalTemplate` | `true` | Note autonome solo con titolo |
| `extractConceptsAddBacklink` | `false` | Backlink nell’estrazione autonoma |
| `extractConceptsProvider` | `DeepSeek` | Provider con instradamento specifico |
| `extractConceptsModel` | `''` | Modello del provider se vuoto |
| `extractConceptsLanguage` | `en` | Lingua con opzioni per attività |
| `replaceSynonymsDuringConceptExtraction` | `false` | Istruzione contro sinonimi |
| `generateConceptLogFile` | `false` | Registro concettuale opzionale |

## Duplicati

Si usano euristiche sui nomi: maiuscole, plurali, simboli e inclusione di una parola secondo ambito. Non provano equivalenza semantica; rivedi plurali irregolari e significati tecnici distinti.

In **Controlla e rimuovi duplicati**, esamina candidati e conferma solo i file voluti. Gli elementi approvati passano dal cestino Obsidian. La cartella non è una cache eliminabile: fai una copia prima della pulizia.

### Ambiti

Puoi confrontare vault, cartella dei concetti, cartelle incluse o ambito con esclusioni. Verifica prima di approvare; cambia i candidati, non il significato di duplicato.

## Uso

### Estrazione autonoma

Apri Markdown, verifica cartella ed esegui **Estrai concetti (file corrente)**. La fonte resta invariata. Controlla nomi, copertura e backlink.

### Estrarre e generare contenuto

**Generazione batch dai titoli** può elaborare note nuove e precedenti idonee. Controlla prima la cartella e poi la destinazione complete.

### Link da selezione

L’azione sulla selezione può collegare il termine scelto e creare una nota con destinazione configurata. Scegli tu il concetto invece di estrarlo dall’intero documento.

## Consigli

- Fonte piccola e cartella dedicata.
- Scegli lingua prima di ampliare.
- Rivedi sinonimi e duplicati separatamente.
- Conserva registri utili prima di nuove esecuzioni che li sostituiscano.
