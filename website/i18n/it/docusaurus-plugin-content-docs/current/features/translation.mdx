# Traduzione

<TLDR>
Notemd traduce il file attivo o quelli idonei di una cartella. Crea normalmente un file separato con suffisso linguistico. Qualità e copertura dipendono dal modello, non dalle 21 lingue UI o 34 del sito.
</TLDR>

## Panoramica

Scegli lingua e provider e prova una copia con termini, link e codice. Usa il LLM configurato, non un’integrazione dedicata Google Translate.

Le azioni operano su file e cartelle. Per un brano copialo in una nota temporanea. Una selezione non limita **Traduci file corrente**.

## Funzionamento

### Comando

1. Scegli la lingua di output, inizialmente inglese e separata dall’UI.
2. Apri la fonte e avvia **Traduci file corrente**.
3. I testi lunghi vengono divisi, tradotti e riuniti.
4. Apri il percorso indicato e verifica significato, termini, citazioni, link e codice.

`Example.md` verso francese crea `Example_fr.md` accanto alla fonte conservata. Un output corrispondente viene sovrascritto. Non è previsto l’accodamento alla fonte o un titolo `Translation` garantito.

### Coppie linguistiche

Il modello deduce la lingua originale. Una voce nel menu non dimostra accuratezza. Prova testi misti e terminologia; i frammenti possono perdere contesto reciproco.

### Modello per attività

Abilita scelte specifiche per `translateProvider` e `translateModel`; altrimenti vale il provider attivo. Locale richiede server e modello pronti; il cloud riceve prompt e contenuto. Valuta un campione del dominio, non classifiche generiche.

### Cartelle

**Traduci cartella in batch** include inizialmente solo figli diretti; i profili avanzati possono cambiare ambito. Fonti omonime nello stesso output possono collidere. Rivedi percorsi e traduzioni esistenti.

## Impostazioni

| Impostazione | Valore iniziale | Effetto |
| --------- | --------- | -------- |
| `language` | `en` | Lingua scelta |
| `translateProvider` | `DeepSeek` | Provider con instradamento specifico |
| `translateModel` | `''` | Modello del provider se vuoto |
| `useCustomTranslationSuffix` | `false` | Suffisso del codice lingua |
| `translationCustomSuffix` | `_translated` | Suffisso personalizzato quando attivo |
| `useCustomTranslationSavePath` | `false` | Salvare vicino alla fonte |
| `translationSavePath` | `''` | Cartella relativa al vault |
| `batchConcurrency` | `1` | Concorrenza richiesta per la cartella |

Se la cartella personalizzata non si crea, la fonte può diventare destinazione alternativa; controlla il percorso reale. Un suffisso personalizzato vuoto può puntare all’originale. Usa un suffisso distinto per separare la traduzione.

## Esempio

Scegli inglese e traduci una breve nota cinese di prova. Confronta `_en.md` con termini, numeri, formule e link della fonte prima di ampliare.

## Annullamento e revisione

Annullare interrompe lavoro successivo supportato, senza ripristinare traduzioni scritte o garantire fine degli addebiti. Verifica report e file. Chiedere di preservare Markdown non garantisce validazione sintattica o equivalenza semantica.

## Consigli

- Salva la fonte e controlla collisioni.
- Usa suffisso e cartella distinti nei test.
- Rivedi identificatori, matematica, URL e nomi propri.
- Ripulisci le diagnosi prima di condividerle.
