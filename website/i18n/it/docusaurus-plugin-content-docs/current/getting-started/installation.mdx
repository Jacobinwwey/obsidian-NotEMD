# Installazione

<TLDR>
Installa **Notemd** dai plugin della community oppure copia i tre file della stessa versione GitHub nel vault. Attivalo, configura un provider e verifica una nota di prova. Server locali ed esportatori nativi hanno requisiti separati.
</TLDR>

## Metodo 1: plugin della community (consigliato)

1. Apri **Settings → Community plugins** nel vault corretto.
2. Abilita i plugin se necessario, poi **Browse**.
3. Cerca **Notemd**, verifica `Jacobinwwey/obsidian-NotEMD` e scegli **Install**.
4. Seleziona **Enable** e apri la barra laterale dall’icona o dalla palette.

[Apri Notemd in Obsidian](obsidian://show-plugin?id=notemd). Se il browser non gestisce il collegamento, usa i passaggi precedenti.

## Metodo 2: installazione manuale

### Requisiti

Servono Obsidian e un vault di cui puoi fare una copia. Il manifest dichiara `0.15.0` come minimo: non dimostra una verifica attuale su quella versione.

### Passaggi

1. Scarica `main.js`, `manifest.json` e `styles.css` dalla stessa [versione GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). Il `README.md` incluso è una guida, non un requisito di esecuzione.
2. Copia in `<vault>/.obsidian/plugins/notemd/`, adattando `.obsidian` se usi un’altra directory di configurazione.
3. Ricarica Obsidian e attiva Notemd.
4. Controlla la versione visualizzata; non mescolare manifest nuovo e bundle vecchio.

## Alternativa: BRAT

Se usi già [BRAT](https://github.com/TfTHacker/obsidian42-brat), aggiungi `Jacobinwwey/obsidian-NotEMD` nel suo flusso beta. Per riprodurre errori scegli una versione precisa. BRAT resta facoltativo.

## Verifica

Scegli provider/modello accessibili ed esegui **Testa connessione**, poi prova una nota copiata seguendo l’[avvio rapido](./quick-start). Alcuni test controllano solo l’elenco dei modelli; una vera attività verifica generazione e scrittura.

## Requisiti di sistema

| Area | Limite |
| --------- | ---------- |
| Manifest | Minimo dichiarato `0.15.0`; `isDesktopOnly` è false |
| Prove di verifica | Consultare l’accettazione datata; dispositivi mobili fisici e Obsidian 0.15.0 non verificati |
| LLM ospitato | Rete, account/chiave autorizzati e modello compatibile |
| LLM locale | Server installato e attivo con modello scaricato o caricato |
| Esportazioni native di slide/circuiti | Strumenti desktop e dipendenze del formato; verificare l’ambiente prima di esportare |

Nessuna garanzia generale di versione del sistema operativo copre tutti gli esportatori. Un’anteprima non prova la compilazione TeX; un test desktop non verifica il mobile.

## Disinstallazione

Disattiva o rimuovi il plugin. Note e artefatti restano file del vault: esaminali prima di eliminarli. Salva le impostazioni per una reinstallazione. Disinstallare non annulla modifiche già concluse.

## Aggiornamento

Usa **Check for updates**. In manuale, ferma le attività, salva vault e impostazioni, sostituisci i tre file della stessa versione e ricarica. Leggi le novità e prova una nota prima dei lotti.

Non sostituire le impostazioni del vault con un asset della release. Per tornare indietro, installa consapevolmente una versione compatibile e conserva gli output utili.
