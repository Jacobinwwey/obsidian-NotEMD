# Configurazione

<TLDR>
Apri **Settings → Notemd** e cerca il campo. Imposta provider e destinazioni prima di elaborare. Prova le modifiche su una nota: un’operazione attiva può mantenere i valori acquisiti all’avvio.
</TLDR>

## Panoramica

DeepSeek è il provider iniziale, con credenziali vuote. Un profilo non crea account, installa modelli o concede accesso. Vedi [provider](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Ricerca delle impostazioni e preferiti

- **Search settings** cerca nomi, descrizioni, alias e categorie visibili e apre il campo.
- **★ Favorites** elenca impostazioni salvate con descrizione, categoria e destinazione. Persistono nel vault; gli ID obsoleti vengono scartati.
- La freccia riduce la barra e conserva la ricerca alla riapertura.
- Elenco dei preferiti e filtro della ricerca sono controlli distinti.

**Diagram preview export PPI**: **300** iniziali, intervallo **72–600**. Riguarda PNG; SVG/PDF mantengono geometria vettoriale dove supportata. **Also export complete Mermaid visuals** controlla i file accessori, non la visibilità di Mermaid in Drawnix.

## 1. Provider

Scegli profilo, endpoint adatto al protocollo, credenziali e modello accessibile. Usa **Fetch models** quando disponibile e poi **Testa connessione**. Elenco e generazione sono verifiche diverse.

Un modello locale richiede server e modello pronti. Il cloud riceve i dati inviati. Controlla anche le scelte per attività prima di usare note private.

## 2. Modelli per attività

`useMultiModelSettings` separa provider/modello per link, titoli, ricerca, traduzione, concetti, testo originale e sintesi Mermaid. Un modello specifico vuoto usa quello del provider scelto. Altrimenti vale il provider attivo.

Confronta precisione, latenza e prezzo reale con una nota rappresentativa. Non si garantiscono classifiche o disponibilità.

## 3. Output

| Attività | Comportamento iniziale |
| ------ | ------------------------- |
| Aggiunta di link | File separato `_processed.md`; originale non spostato |
| Concetti autonomi | Cartella scelta obbligatoria; titoli senza backlink |
| Traduzione | File separato `_<language>.md`; può sovrascrivere un output esistente |
| Ricerca | Sintesi aggiunta alla nota Markdown attiva |
| Generazione da titoli in lotto | Scrive contenuto e sposta note idonee nella cartella adiacente `<folder>_complete` quando consentito |
| Anteprima/esportazione | Scegliere sorgente o visuale compatibile e controllare il percorso indicato |

La cartella dei concetti parte vuota; `concepts` è una scelta possibile. I [modelli di nota](../features/concept-notes) sono minimo/completo, senza motore generale di variabili per file.

Suffissi e cartelle di elaborati e traduzioni sono distinti. Controlla destinazioni esistenti e messaggi di recupero. Annullare non ripristina le scritture concluse.

## 4. Lingue

L’interfaccia ha **21 lingue**, il sito **34 percorsi linguistici**. `uiLocale: auto` segue le corrispondenze disponibili e ricade sull’inglese quando manca supporto.

La lingua generata è indipendente e inizialmente inglese. Le scelte per attività valgono per link, titoli, ricerca, concetti e Mermaid dove supportato. Traduzione usa `language`, non la lingua UI. Le capacità del modello sono separate.

## 5. Ricerca

Scegli **Tavily** con chiave o **DuckDuckGo** esplicitamente. Chiave Tavily vuota non cambia motore. Entrambi usano rete; DuckDuckGo può leggere pagine.

I titoli non cercano per impostazione iniziale; abilita `enableResearchInGenerateContent` se necessario. Anche la ricerca locale è disattivata, con ambiti propri di cartelle/attività. Gli estratti usati vanno al LLM nel contesto.

## 6. Flussi

Usa il costruttore o una definizione DSL per riga:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` separa nome e azioni, `>` separa gli ID. Un errore segnalato interrompe la sequenza per impostazione iniziale. Vedi [flussi](../features/workflows).

## 7. Impostazioni avanzate

| Impostazione | Valore iniziale | Effetto |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Provider senza instradamento specifico |
| `useMultiModelSettings` | `false` | Separare modelli per attività |
| `useCustomConceptNoteFolder` | `true` | Consentire concetti dopo la scelta della cartella |
| `conceptNoteFolder` | `''` | Nessuna cartella iniziale |
| `extractConceptsMinimalTemplate` | `true` | Concetti autonomi solo con titolo |
| `extractConceptsAddBacklink` | `false` | Backlink solo dopo attivazione |
| `moveOriginalFileOnProcess` | `false` | Conservare fonte durante i link |
| `chunkWordCount` | `3000` | Dimensione approssimativa in parole, non limite token |
| `batchConcurrency` | `1` | Concorrenza iniziale |
| `enableBatchParallelism` | `false` | Pianificazione parallela nei percorsi compatibili |
| `enableStableApiCall` | `false` | Modalità stabile esplicita |
| `customWorkflowErrorStrategy` | `stop_on_error` | Fermare al primo errore di fase segnalato |

Divisione del testo e budget di output sono diversi. Frammenti piccoli non garantiscono il rispetto del contesto; meno concorrenza non evita ogni 429.

## Profili

Le impostazioni appartengono al vault. Salva la configurazione prima di cambiarla. Profili esportati con chiavi oscurate non sono backup completi; rivedi endpoint e metadati prima di condividere. Non pubblicare configurazioni grezze o diagnosi con note private.

## Diagnosi

Prova provider/modello esatti e poi una nota. Per campi assenti controlla ricerca, categoria, visibilità sviluppatore e vault. Segnala problemi riproducibili con versione e dettagli ripuliti.
