# Avvio rapido

<TLDR>
Inizia con una nota Markdown eliminabile e un provider già disponibile. Controlla il file generato prima di elaborare una cartella. Il cloud riceve i contenuti; un modello locale richiede server attivo e modello pronto.
</TLDR>

## Passo 1: configurare il provider

1. [Installa e attiva Notemd](./installation), quindi **Settings → Notemd**.
2. Scegli provider, endpoint, credenziali richieste e modello accessibile. **Fetch models** individua modelli compatibili; un elemento elencato non garantisce la generazione.
3. Esegui **Testa connessione** e risolvi errori di accesso, modello o indirizzo.
4. Cerca **Percorso cartella note concetto** e scegli una cartella dedicata, ad esempio `concepts`. Il valore iniziale è vuoto: `concepts/` è un esempio, non una destinazione preconfigurata.

Con Ollama scarica prima il modello e usa il nome esatto; endpoint iniziale `http://localhost:11434/api`. Con LM Studio avvia il server e scegli `LMStudio`. Vedi [modelli locali](../providers/local). La ricerca Web richiede comunque rete.

## Passo 2: provare un’attività

Crea `Notemd trial.md` con testo che puoi inviare al provider:

```text
L’apprendimento automatico usa reti neurali per riconoscere schemi negli esempi.
```

Esegui **Elabora file (aggiungi link)**. Per impostazione iniziale crea `Notemd trial_processed.md` accanto all’originale conservato. Esamina i collegamenti reali. Esempio possibile:

```markdown
L’[[apprendimento automatico]] usa [[reti neurali]] per riconoscere schemi negli esempi.
```

La cartella scelta può ricevere anche concetti. File e collegamenti vanno verificati: il modello non garantisce di identificare correttamente ogni concetto.

## Passo 3: esplorare le funzioni

### Estrarre concetti

**Estrai concetti (file corrente)** conserva la fonte e richiede una cartella. L’estrazione autonoma crea solo titoli senza backlink per impostazione iniziale. Attivali esplicitamente. Vedi [concetti](../features/concept-notes).

### Ricerca e sintesi

Seleziona un tema nell’editor Markdown o usa il titolo e avvia **Ricerca e riassunto**. Scegli Tavily con chiave o DuckDuckGo esplicitamente. Il riepilogo viene aggiunto alla nota; verifica le fonti.

### Concatenare azioni

Definizione esatta di **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Aggiunge collegamenti, genera contenuto per note idonee nella cartella dei concetti o selezionata e corregge Mermaid nella cartella complete. Può coinvolgere note preesistenti. Usa una cartella di prova. Non aggiunge automaticamente ricerca Web o diagrammi.

## Annullamento e verifica

**Annulla** ferma il lavoro successivo. Gli output completati restano: non è una transazione reversibile e non garantisce l’arresto di generazione o addebiti remoti. Attendi la conclusione e controlla percorsi e conflitti prima di ripetere.

## Problemi

- Accesso/modello: verifica il profilo esatto e ripeti la connessione.
- Nessun concetto: controlla cartella scelta e attiva.
- Collegamenti poco utili: analizza risposta e prompt; nessuna lunghezza minima garantisce successo.
- Quote: mantieni `batchConcurrency: 1` durante il controllo.
