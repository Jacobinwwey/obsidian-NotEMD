# Китайские провайдеры

<TLDR>Выбирайте профиль своего аккаунта и deployment. Даже общий OpenAI-compatible протокол не делает регионы, пути, модели и права взаимозаменяемыми. Проверьте маленькую задачу.</TLDR>

## Подготовка

Получите аккаунт и ключ, выберите профиль и подтвердите регион/права модели. Начальные параметры не гарантируют текущего доступа; после соединения проверьте заметку.

## Адрес и авторизация

| Профиль | Начальная модель | Начальный URL |
| -------- | --------------- | ------------------ |
| DeepSeek | `deepseek-v4-pro` | `https://api.deepseek.com` |
| Qwen | `qwen3-235b-a22b` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Qwen Code | `qwen3-coder-plus` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Doubao | `ep-xxxxxxxxxxxxxxxx` | `https://ark.cn-beijing.volces.com/api/v3` |
| Moonshot | `kimi-k2-0905-preview` | `https://api.moonshot.cn/v1` |
| Xiaomi MiMo | `mimo-v2.5-pro` | `https://api.xiaomimimo.com/v1` |

Замените пример Doubao на действительный endpoint ID Ark или поддерживаемую модель. GLM и Z AI — разные региональные профили. Ключ другого региона/тарифа может не работать. Следуйте условиям аккаунта, а не только географическому положению.

## Модели

Получайте список, когда разрешено. Huawei Cloud MaaS зависит от deployment, другие профили используют совместимое обнаружение по возможностям. Запрет списка не всегда запрещает генерацию по явному ID. DeepSeek может пройти проверку по списку, ряд региональных профилей генерирует короткий ответ. Реальная задача всё равно обязательна.

## Ошибки

- Ключ принят, генерация запрещена: модель, deployment и регион.
- Ark отвергает ID: требуется endpoint или имя модели?
- Рассуждение обрезано: бюджет и правила thinking.
- Сеть: проверяйте адрес с устройства Obsidian и транспортную ошибку.

## Когда выбирать

При подходящих правах, доступности и требованиях к данным. Категория не задаёт языковое качество или стоимость. Сравнивайте образец с записанными параметрами.
