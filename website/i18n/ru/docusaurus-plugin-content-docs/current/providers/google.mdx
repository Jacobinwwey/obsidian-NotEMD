# Провайдер Google

<TLDR>Используется нативный Gemini Generative Language. Нужны разрешённый ключ и доступная модель. Gemini через совместимый шлюз требует профиля этого шлюза.</TLDR>

## Подготовка

Выберите **Google**, ключ, нативный адрес и модель выбранной API-версии. Проверьте соединение и заметку. Произвольные Google Cloud/Vertex deployment автоматически не настраиваются.

## Адрес и авторизация

| Поле | Начальное значение |
| ------- | -------------- |
| Протокол | `google` |
| API-ключ | Обязателен |
| Базовый URL | `https://generativelanguage.googleapis.com/v1` |
| Модель | `gemini-2.0-flash-exp` |
| Температура | `0.5` |
| Проверка соединения | `chat-only` |

Формируется `generateContent` с API-ключом. Старый ID не обещает доступности. Проверяйте диагностические URL перед передачей: они могут содержать авторизацию.

## Модели

Используйте нативный список и проверяйте генерацию на выбранной API. Пустой список может означать ограничения прав, неверный адрес или отсутствующую модель. Диагностируйте до смены протокола.

## Ошибки

- 400: ID, параметры, лимиты входа/вывода.
- 401/403: ограничения ключа, включение API, права.
- 404: поддерживается ли модель этой версией API.
- Пример шлюза: выберите соответствующий OpenAI-compatible профиль.

## Когда выбирать

Для нативного Gemini. Проверяйте перевод, исследование и диаграммы на своей выборке; универсальных обещаний скорости, цены и качества нет.
