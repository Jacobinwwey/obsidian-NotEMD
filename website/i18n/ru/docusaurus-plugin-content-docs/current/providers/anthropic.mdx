# Провайдер Anthropic

<TLDR>Профиль предназначен для нативного Messages. Claude через OpenAI-compatible шлюз использует профиль шлюза. Историческое начальное имя может требовать замены на доступную модель.</TLDR>

## Подготовка

Выберите **Anthropic**, ключ и модель с доступом. Сохраните нативный адрес, если собственный deployment не предоставляет тот же протокол. Проверьте соединение и заметку.

## Адрес и авторизация

| Поле | Начальное значение |
| ------- | -------------- |
| Протокол | `anthropic` |
| API-ключ | Обязателен |
| Базовый URL | `https://api.anthropic.com` |
| Модель | `claude-3-5-sonnet-20240620` |
| Температура | `0.5` |
| Проверка соединения | `chat-only` |

Запрос идёт в `/v1/messages` с нативными заголовками ключа/версии. Не подставляйте маршрут OpenAI chat. Таблица описывает конфигурацию репозитория, не текущую доступность.

## Модели

Используйте нативное обнаружение, если доступно. При запрете списка задайте разрешённый ID и проверьте chat. Длинные и структурированные задачи проверяются отдельно.

## Ошибки

- 401/403: ключ, проект, оплата, права.
- 404: endpoint и доступность.
- ID шлюза отклонён: сопоставьте профиль и идентификатор.
- Длинная задача: изучите лимиты до увеличения повторов.

## Когда выбирать

Для нативных Messages endpoint. Сравнивайте результат с источниками без универсального рейтинга. Индивидуальные маршруты позволяют использовать модель в нужных задачах.
