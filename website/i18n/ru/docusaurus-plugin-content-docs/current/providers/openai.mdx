# Провайдер OpenAI

<TLDR>Профиль использует общий путь OpenAI Chat Completions. Задайте ключ и модель, принимающую этот протокол. Начальная модель не гарантирует актуального доступа или универсального качества.</TLDR>

## Подготовка

Для официального сервиса выберите **OpenAI**, ключ и `https://api.openai.com/v1`. Наличие модели в списке не делает совместимой модель, работающую только через другую API. Для шлюза используйте его профиль/заголовки; Azure требует **Azure OpenAI**, deployment и API-версию.

## Адрес и авторизация

| Поле | Начальное значение |
| ------- | -------------- |
| Протокол | `openai-compatible` |
| API-ключ | Обязателен |
| Базовый URL | `https://api.openai.com/v1` |
| Модель | `gpt-4o` |
| Температура | `0.5` |
| Проверка соединения | `models-then-chat` |

Runtime нормализует известные формы адреса перед построением маршрута. Начните с профиля, проверьте итоговый адрес, не дописывайте сегменты наугад.

## Модели

**Fetch models** получает список. **Проверить подключение** может пройти по нему без чата. Проверьте точную модель на заметке. Reasoning, thinking, сэмплирование и лимиты подчиняются правилам модели/профиля; наличие в списке не означает поддержку каждого параметра.

## Ошибки

- 401/403: ключ, проект, доступ и аккаунт.
- 404: адрес, ID и совместимость API.
- Список работает, задача нет: изучите chat-ошибку и параметры.
- Длинный ответ обрывается: вход, бюджет и реальный ответ; короткий тест недостаточен.

## Когда выбирать

Для прямых OpenAI endpoint с Chat Completions. Сравнивайте на собственных заметках; цены и доступность меняются независимо от Notemd.
