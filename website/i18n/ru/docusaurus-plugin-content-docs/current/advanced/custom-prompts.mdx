# Собственные prompt

<TLDR>Непустой пользовательский prompt заменяет встроенный при включённых общем и индивидуальном переключателях. Сохраняйте контракт вывода: система не восстанавливает автоматически все пропущенные инструкции формата.</TLDR>

## Обзор

Сначала проверьте встроенный prompt. Возможно, достаточно домена или подавления синонимов. Собственная инструкция полезна для политики извлечения, структуры или стиля перевода; сравните результаты до пакета.

## Как это работает

### Сборка prompt

Выбирается встроенный или собственный текст, добавляются применимые инструкции языка/домена, подставляются переменные задачи. Содержимое может идти отдельным сообщением. Доступные переменные различаются. Удаление `CONCEPT:` ломает разбор; исключение поискового контекста лишает исследование основания. Корректный запрос не доказывает корректный ответ.

### Переменные

Используйте точный регистр и одиночные фигурные скобки:

| Задача | Доступные переменные |
| ------ | ----------------------- |
| Генерация заголовка | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Исследовательская сводка | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Перевод | `{LANGUAGE}`, `{TEXT}` |
| Извлечение оригинала | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` следует политике задачи. Ссылки и отдельные понятия передают текст как содержимое; не придумывайте переменные. Неизвестные имена не подставляются. Это не шаблоны файлов понятий.

### Тематическая область

Включите focused learning и задайте, например, `электротехника`. Инструкция `Relevant Fields` направляет внимание модели, а не жёстко отфильтровывает посторонние понятия.

## Настройки

| Задача | Переключатель | Поле prompt |
| ------ | --------------- | -------------- |
| Ссылки | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Заголовки | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Исследование | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Сводка Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Понятия | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Перевод | `useCustomPromptForTranslate` | `translatePrompt` |
| Исходные отрывки | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Всем нужен `enableGlobalCustomPrompts`. Пустой текст использует встроенный. Объединённое извлечение оригинала имеет собственную встроенную форму и не разделяет обычный override. Диаграммы требуют типизированного вывода; prompt сводки Mermaid не универсален.

## Пример

Включите общий переключатель и извлечение понятий, сохранив маркер:

```text
Извлеките основные электротехнические понятия из заметки.
Предпочитайте конкретные компоненты и физические механизмы общим словам.
Выведите по одному понятию на строке в точном формате:
CONCEPT: Название термина
Не добавляйте объяснения и внешнюю рамку кода.
```

На копии проверьте строки, имена файлов и пропуски, сравните со встроенным вариантом. Сохраните предыдущий prompt для восстановления.

## Практика

- Одна задача за раз до расширения пакета.
- Сохраняйте доказательства исследования и точные цитаты.
- Переводите прозу, оставляя ID и маркеры стабильными.
- После смены модели повторите проверку: инструкция не заменяет валидацию.
