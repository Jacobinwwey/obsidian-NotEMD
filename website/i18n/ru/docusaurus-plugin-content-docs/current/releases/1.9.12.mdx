# Notemd 1.9.12 — Более компактный просмотр диагностики

<TLDR>
Если ошибок нет, вся панель диагностики по умолчанию свёрнута: видны только заголовок и счётчики по уровню серьёзности. При наличии ошибок панель открывается автоматически. Разверните панель и группы меток, чтобы прочитать все сообщения и рекомендации. Диагностические записи не удаляются. Автоматически открываются только группы ошибок; предупреждения и информация остаются свёрнутыми, даже если имеют общую метку.
</TLDR>

Установите main.js, manifest.json и styles.css из одной версии 1.9.12, затем перезагрузите плагин. Настройки и существующие файлы сохраняются.
