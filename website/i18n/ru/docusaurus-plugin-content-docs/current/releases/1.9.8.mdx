# Обновление до Notemd 1.9.8

<TLDR>1.9.8 улучшает отмену и владение выходами, согласованность пакетного поиска, нативный экспорт и точность документации. Проверьте публичный GitHub Release и используйте файлы одного выпуска. Числа провайдеров и диаграмм — прежние возможности.</TLDR>

## После 1.9.7

| Область | Результат для пользователя |
| ------ | ------------- |
| Отмена | Общее состояние планирования, транспорта и повторов; поздний ответ не продолжает защищённую запись |
| Сохранение артефактов | Владение пересекающимися сохранениями/восстановлением, одноимёнными источниками и общими вложениями |
| Локальный поиск | Один снимок для пакетных заголовков; измерения памяти и фиксированного корпуса |
| Нативный вывод | Разделители PowerPoint под объединёнными ячейками, проводники/подписи CircuitikZ |
| Проверки | Linux/Windows CI, lint по диагностикам, процессные и нативные доказательства |
| Документация | Исправленные значения, четыре пути читателей, прямые переводы и контролируемая публикация |

Поиск истории сохраняет последовательный ввод и курсор при асинхронном обновлении. Drawer удерживает Tab, получает фокус при загрузке и не закрывает родительский preview по Escape. Повторы и устаревшие ответы покрыты браузерными регрессиями.

Исследование/перевод повторно проверяют отмену после последнего чтения или подготовки папки перед добавлением, созданием и перезаписью. Принятые Vault записи остаются завершёнными. Если параллельная задача создала папку перевода во время ожидания, она используется без присвоения авторства создания. Файл-конфликт или по-прежнему отсутствующая папка сохраняют сообщение и возврат к папке источника.

36 профилей и 33 исполняемых пункта существовали в 1.9.7. Runtime, документация и merge-записи учитываются без двойного подсчёта.

## Безопасное обновление

1. Остановите задачи, сохраните Vault и настройки.
2. Обновитесь через Community plugins либо скачайте `main.js`, `manifest.json`, `styles.css` из одного [публичного 1.9.8](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/tag/1.9.8).
3. Вручную заменяйте только runtime; сохраняйте настройки/выходы.
4. Перезагрузите и проверьте версию.
5. Испытайте заметку и небольшую папку до большого пакета.

ID и настройки сохраняются. One-Click Extract остаётся цепочкой ссылок, пакетных заголовков и Mermaid. Исправление текста не добавляет исследование в стандартный сценарий.

## Отмена и восстановление

Отмена не обратная транзакция. Готовые файлы остаются, принятые записи/запросы могут закончиться, оплатой управляет провайдер. Дождитесь завершения и осмотрите результаты. Конфликты видимы: сравните текущую заметку и восстановление до удаления. Сохраняйте companion-папки, на которые ссылаются старые артефакты.

## Границы экспорта и совместимости

- PowerPoint проверяется целевыми нативными утверждениями; общий балл изображения раньше пропустил дефект.
- Mermaid/SVG в PPTX могут остаться изображениями.
- Статические межветвевые стрелки Drawnix не гарантируют прикрепление после перестройки.
- Preview CircuitikZ и компиляция TeX проверяются отдельно.
- Физические мобильные устройства и Obsidian 0.15.0 не проверены.
- Лексический фиксированный тест не доказывает семантическое качество или скорость произвольного Vault.

## Целостность выпуска

Publisher проверяет версии и локальные/удалённые tag, пересобирает чистый исходник, загружает draft и сравнивает хеши скачанных файлов перед публикацией. Обязательны `main.js`, `manifest.json`, `styles.css`, `README.md`. Повтор не заменяет публичные байты посторонними.

Сайт публикуется после проверки доступности Release. Codex пишет и проверяет переводы напрямую, без LM Studio и переводческих API. Это не независимая проверка носителем языка.
