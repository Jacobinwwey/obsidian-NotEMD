# Notemd 1.9.11 — Более понятные диаграммы и надёжный экспорт PDF

<TLDR>
Drawnix размещает тесно связанные ветви ближе друг к другу и уменьшает наложения и пересечения соединительных линий, сохраняя все узлы и явные связи. Стрелки между ветвями остаются статичными после перестановки.
</TLDR>

Экспорт PDF обрабатывает сложные селекторы SVG и наследуемые стили после очистки. Отсутствующие viewBox восстанавливаются; слишком большие страницы масштабируются пропорционально с сохранением векторной графики.

Диагностика сгруппирована по меткам и по умолчанию свёрнута. Разверните группу, чтобы прочитать все сообщения и рекомендации; счётчики по уровню серьёзности остаются видимыми.

Журнал накапливается между этапами задачи и повторными открытиями предпросмотра в течение сеанса плагина. Используйте Очистить журнал для сброса; перезагрузка плагина не сохраняет историю.

Установите main.js, manifest.json и styles.css из одной версии 1.9.11, затем перезагрузите плагин. Настройки и существующие файлы сохраняются.
