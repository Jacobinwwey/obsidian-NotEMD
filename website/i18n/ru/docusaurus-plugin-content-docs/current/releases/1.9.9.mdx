# Notemd 1.9.9 — Несколько диаграмм, независимый экспорт

<TLDR>
Выберите несколько типов диаграмм за один запуск и несколько форматов для каждого типа отдельно. Снятие отметки сохраняет форматы типа; без выбранных типов содержимое анализируется автоматически.
</TLDR>

## Несколько диаграмм, независимый экспорт

Флажок включает тип. Нажмите название, чтобы выбрать его и настроить форматы. Наведение указателя или фокус клавиатуры меняет предпросмотр без сохранения настроек. Escape закрывает меню и возвращает фокус.

Поддерживаемые форматы идут первыми; несовместимые остаются видимыми, но недоступными для выбора. Ранее сохранённые неактивные запросы можно удалить. Форматы закреплены за своим типом. Если ни один не подходит, используется попытка экспорта в исходный формат по умолчанию текущего рендерера с отчётом о недоступных запросах.

HTML диаграммы содержит масштабируемую графику; HTML структурированного резюме — текст, структуру и ссылки на источники. Редактируемый HTML/SVG — название рендерера, а не веб-редактора. Для правок используйте родной исходный файл. Экспорт презентаций, включая PPTX и MP4, сохраняет отдельные настройки и зависимости.

Drawnix показывает до шести подписанных основных направленных связей, не более трёх на узел. Пропущенные связи остаются в метаданных. Текст в рамках виден в PDF, в том числе из старого кэша SVG. Стрелки между ветвями статичны и могут отсоединяться после перестановки узлов в Drawnix.

## Файлы и восстановление

Выбранные файлы автоматически экспортируются рядом с исходной заметкой или прямо в указанную папку. Имя содержит тип, например `topic_drawnix.pdf` и `topic_flowchart.svg`. При совпадении добавляются `-2`, `-3` и далее, без перезаписи файлов.

Задайте общую папку промежуточных файлов относительно Vault или оставьте поле пустым для `notemd_assert/` рядом с каждым источником. Здесь хранятся записи восстановления, кэш рендеринга и необязательные вложения. Сохраняйте ещё используемые файлы; смена папки влияет только на новые запуски.

Типы создаются последовательно. Ошибка одного не блокирует остальные; отмена останавливает ожидающие типы и сохраняет готовые файлы. Повторите экспорт из предпросмотра или истории без нового запроса к модели. Ошибка генерации требует повторной генерации этого типа. Записи v1/v2 остаются читаемыми.

## Обновление

Остановите задачи и сохраните копию Vault. Установите `main.js`, `manifest.json` и `styles.css` из одного выпуска 1.9.9, сохраните настройки и файлы, затем перезагрузите Obsidian. Проверьте одну заметку до большого пакета. Старые предпочтения переносятся при редактировании. Переводы написаны напрямую, без API перевода и LM Studio.
