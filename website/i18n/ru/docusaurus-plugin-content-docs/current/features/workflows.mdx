# Сценарии

<TLDR>Сценарий последовательно запускает существующие действия. Они могут требовать папку или открытый редактор. Это не текстовый pipe: каждое сохраняет свои входы, выходы и побочные эффекты. Начинайте с пробной заметки и отдельной папки.</TLDR>

## Обзор

Стандартная цепочка **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Добавляет ссылки в активную заметку и создаёт понятия при настроенной папке.
2. Генерирует содержимое подходящих заметок в папке понятий или выбранной папке, включая существовавшие ранее.
3. Исправляет Mermaid в complete-папке генерации.

Веб-исследования по умолчанию нет; генерация использует его только при отдельном включении. [Пакетная обработка](../advanced/batch-processing).

## Как это работает

### Исполнение

Панель сообщает текущий шаг и ошибку. Отмена прекращает следующие шаги и передаётся поддерживаемым запросам, но готовые записи остаются. Отката всей цепочки нет. Папка понятий служит начальным предпочтением, генерация запоминает источник/complete, а Mermaid использует complete. Другие действия сохраняют требования к файлу, выделению и диалогам.

### Формат DSL

Одна именованная кнопка на строку: `::` после имени, `>` между ID. Пустые строки и строки с начальным `#` игнорируются; неизвестные ID отклоняются.

```text
Извлечь и построить::extract-concepts-current>summarize-as-mermaid
```

Выбирайте действия конструктором или редактируйте DSL. ID стабильны, подписи зависят от UI. Папочные варианты имеют собственные ID, а не выводятся произвольной заменой строк.

| ID | Действие / условие |
| ------------ | ----------------------- |
| `process-current-add-links` | Ссылки в активной заметке |
| `process-folder-add-links` | Ссылки в выбранной папке |
| `extract-concepts-current` | Понятия из активной заметки |
| `extract-concepts-folder` | Понятия из выбранной папки |
| `generate-from-title` | Генерация по заголовку активной заметки |
| `batch-generate-from-titles` | Генерация подходящих заметок папки |
| `research-and-summarize` | Исследование выделения/заголовка в Markdown-редакторе |
| `summarize-as-mermaid` | Сводка поддерживаемого ввода в Mermaid |
| `generate-diagram` | Выберите несколько типов диаграмм за один запуск и несколько форматов для каждого типа отдельно. Снятие отметки сохраняет форматы типа; без выбранных типов содержимое анализируется автоматически. |
| `preview-diagram` | Предпросмотр поддерживаемого источника/артефакта |
| `translate-current-file` | Перевод активного поддерживаемого файла |
| `batch-translate-folder` | Перевод выбранной папки |
| `extract-original-text` | Извлечение заданных исходных отрывков |
| `batch-extract-original-text` | Извлечение из подходящих файлов папки |
| `split-note-by-chapters` | Разбиение активной заметки по главам |
| `batch-mermaid-fix` | Исправление Mermaid-блоков папки |
| `fix-formula-current` | Нормализация разделителей формул заметки |
| `batch-fix-formula` | Нормализация разделителей формул папки |
| `check-duplicates-current` | Проверка дубликатов активной заметки |
| `check-remove-duplicate-concepts` | Интерактивный просмотр/удаление понятий-дубликатов |
| `test-llm-connection` | Проверка настроенного провайдера |

### Стандартные и свои цепочки

One-Click Extract поставляется готовым; остальные кнопки определяете вы. Найдите настройки сценариев, задайте имя и порядок, проверьте tooltip панели. Исправьте ошибки разбора до запуска.

## Настройки

| Настройка | Начальное значение | Эффект |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Остановка при первой сообщённой ошибке |
| `useMultiModelSettings` | `false` | Активный провайдер до включения индивидуальных маршрутов |
| `enableResearchInGenerateContent` | `false` | Исследование отсутствует в генерации, пока не включено |

`continue_on_error` запускает следующие шаги после ошибки. Используйте только если они допускают оставшиеся входы: продолжение не превращает частичный результат в полный успех.

### Модели отдельных задач

Выбор остаётся у задачи. Пустой override берёт модель её провайдера. Перед частной работой проверьте каждый маршрут.

## Пример

Задайте пустую `trial-concepts`, обработайте пробный источник и проверьте понятия и complete-папку. Если назначения неясны, сначала выполните действия отдельно. Расширяйте область после проверки.

## Практика

- Короткая цепочка делает ошибки и владельцев выходов понятными.
- Очистка/удаление сохраняют интерактивные подтверждения; не помещайте их в безнадзорные цепочки.
- После отмены/конфликта смотрите журнал и файлы.
- Проверяйте точные модель и область: короткий тест соединения не доказывает достаточность квоты для большого пакета.
