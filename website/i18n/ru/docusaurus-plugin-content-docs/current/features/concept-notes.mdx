# Заметки понятий

<TLDR>Отдельное извлечение читает источник и создаёт Markdown-файлы в выбранной папке. Изначально папка не задана, новые заметки содержат только заголовок, обратные ссылки выключены. Добавление ссылок использует другую форму понятий.</TLDR>

## Обзор

Задайте **Путь к папке заметок-концептов**. Отдельная папка упрощает проверку файлов, дубликатов и последующей генерации. Само извлечение не заполняет каждый файл исследованным объяснением.

## Как это работает

### Конвейер

Текст отправляется LLM, разбираются строки `CONCEPT:`, имена устраняются как дубликаты внутри операции, файлы создаются/обновляются. Длинный текст дробится. Проверяйте ошибки фрагментов: ответ модели не исчерпывающий перечень.

### Prompt извлечения

Встроенная инструкция просит конкретные понятия темы. Домен и подавление синонимов не гарантируют каноническую терминологию. Свой prompt должен сохранить `CONCEPT: Term`. [Настройка prompt](../advanced/custom-prompts).

### Фрагменты

`chunkWordCount: 3000` — приближённое деление по словам, не лимит токенов провайдера. Межфрагментный контекст ограничен; проверяйте связанные понятия и неоднозначность.

## Создание файлов

### Имена

Недопустимые символы пути удаляются, пробелы нормализуются, длинные имена сокращаются, пустые пропускаются. Разные формулировки могут дать один путь. Проверьте имена перед массовой генерацией.

### Формы

Минимальная новая заметка:

```markdown
# Название понятия
```

Для обратной ссылки новой отдельной заметки включите **Add "Linked From" backlink** и выключите **Create minimal concept notes**:

```markdown
# Название понятия

## Linked From
- [[Исходная заметка]]
```

Добавление ссылок создаёт полную форму с backlink при включённом выводе понятий. Переключатели отдельного извлечения не меняют этот путь.

### Существующие заметки

При включённых backlinks можно добавить отсутствующую ссылку в `## Linked From`, сохранив тело и не повторяя существующий backlink. Ссылка использует basename источника: одинаковые имена нужно проверять.

### Настройки

| Настройка | Начальное значение | Эффект |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Разрешить вывод после выбора папки |
| `conceptNoteFolder` | `''` | Изначально папки нет |
| `extractConceptsMinimalTemplate` | `true` | Только заголовки новых отдельных заметок |
| `extractConceptsAddBacklink` | `false` | Включить backlinks отдельного извлечения |
| `extractConceptsProvider` | `DeepSeek` | Провайдер при индивидуальной маршрутизации |
| `extractConceptsModel` | `''` | Пустое поле использует модель провайдера |
| `extractConceptsLanguage` | `en` | Язык при индивидуальных языках задач |
| `replaceSynonymsDuringConceptExtraction` | `false` | Инструкция против синонимов |
| `generateConceptLogFile` | `false` | Необязательный журнал понятий |

## Дубликаты

Используются эвристики имён: регистр, множественное число, нормализация символов, включение одного слова при подходящей области. Это не доказательство семантической эквивалентности. Проверьте неправильные формы и разные технические значения. В **Проверить и удалить дубликаты** подтвердите только нужные файлы; используется корзина Obsidian. Папка понятий — не одноразовый cache, сохраните backup.

### Области сравнения

Сравнивайте с хранилищем, самой папкой понятий, включёнными папками или областью с исключениями. Перед удалением проверьте режим: он меняет кандидатов, а не значение дубликата.

## Использование

### Отдельное извлечение

Откройте Markdown, проверьте папку и выполните **Извлечь концепции (текущий файл)**. Оригинал не меняется. Проверьте имена, охват и backlinks.

### Извлечение и генерация

**Пакетная генерация по заголовкам** добавляет объяснения, но может обработать и прежние подходящие заметки. Сначала осмотрите папку, затем проверьте complete-назначение.

### Ссылка из выделения

Действие выделения оборачивает выбранный термин в wiki-link и создаёт понятие при настроенном назначении. Используйте его для собственного выбора термина.

## Практика

- Маленький источник и отдельная папка.
- Язык до массового создания.
- Отдельная проверка синонимов и дубликатов.
- Сохранение нужного журнала до следующей перезаписи.
