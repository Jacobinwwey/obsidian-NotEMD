# Вики-ссылки

<TLDR>Process file (add links) просит LLM выделить понятия и добавить ссылки Obsidian. По умолчанию создаётся отдельный `_processed.md`, оригинал сохраняется. Для файлов понятий нужна выбранная папка. Сначала проверьте один результат.</TLDR>

## Обзор

Термины выбираются по содержимому, могут меняться между запусками и не иметь существующего файла. Ссылка — цель навигации, а не доказательство равнозначности понятий или правильности объяснения.

## Как это работает

### Обработка

Заметка делится на фрагменты, отправляется модели, ответы объединяются и записываются. В настроенной папке могут создаваться/обновляться понятия. Проверяйте частичные ошибки и фактический путь в отчёте.

### Пример

Оригинал:

```text
Машинное обучение использует нейронные сети для поиска закономерностей.
```

Возможный результат:

```markdown
[[Машинное обучение]] использует [[нейронные сети]] для поиска закономерностей.
```

Выбор ссылок зависит от исходника, модели и prompt; пример не гарантирует одинаковый ответ.

## Использование

### Текущая заметка

На копии Markdown выполните **Обработать файл (добавить ссылки)** через панель/палитру и откройте соседний `_processed.md`. Пользовательские суффиксы, папка и перемещение оригинала меняют назначения.

### Несколько заметок

В **Обработать папку (добавить ссылки)** проверьте папку и область, начните с малого. Универсального переключателя перезаписи/пропуска для всех задач нет. [Пакеты](../advanced/batch-processing).

### Выбранный термин

**Create wiki link and generate note from selection** — отдельное действие для явно выбранного термина. Оно не ограничивает выделением обработку всего файла. Проверьте созданную заметку и генерацию.

## Выбор подхода

Модель полезна для поиска понятий по смыслу текста. Детерминированное сопоставление заголовков предпочтительнее, если важна воспроизводимость по существующим именам. Сравнивайте другие инструменты по текущим документам и датированному одинаковому тесту.

## Возможности

### Подавление синонимов

`replaceSynonymsDuringConceptExtraction` добавляет инструкцию избегать близких понятий. Это выключенный по умолчанию Boolean, не числовой порог сходства. Проверяйте сокращения и близкие термины.

### Целостность ссылок

Обновлением ссылок при переименовании управляет Obsidian с учётом его настроек и операции. Удалённая цель оставляет неразрешённую ссылку, а не просто несвязанное упоминание. Проверяйте одинаковые basenames в разных папках.

### Отдельное извлечение

**Извлечь концепции (текущий файл)** создаёт понятия без переписывания источника. Его минимальная форма и обратные ссылки отличаются от добавления ссылок. [Понятия](./concept-notes).

## Создание понятий

### Автоматическое создание

При включённой и заданной папке могут появляться заголовок и `Linked From`. Исследованное объяснение, раздел связанных понятий и общий frontmatter-шаблон автоматически не возникают. Для полного содержания запускайте генерацию по заголовкам отдельно.

### Настройки

Найдите папку понятий, папку обработанных файлов, суффикс и перемещение оригинала. Папка понятий первоначально пуста; на испытаниях отделяйте выходные пути от источников.

## Дополнительные параметры

### Контекст и prompt

`chunkWordCount` — приблизительный размер фрагмента. Домен и пользовательский prompt сужают понятия. Селекторов контекста по предложениям/абзацам, минимальной частоты и общих переменных шаблона здесь нет.

## Практика

- Сверяйте цитаты, формулы и код с оригиналом.
- Оцените, нужны ли выделенным словам отдельные понятия.
- Меняйте prompt на стабильной выборке.
- Сохраняйте backup перед перемещением оригинала и повторной записью.

## Производительность

Время и стоимость зависят от провайдера, модели, размеров prompt/ответа и повторов. Фиксированных секунд на заметку или цены за сто заметок не обещается. Измерьте выборку и фактический расход.

## Ошибки

### Нет ссылок

Проверьте запрос, ответ, нужную исходную заметку и сообщённый файл результата. Минимального числа слов, гарантирующего полезные ссылки, нет.

### Слишком много ссылок

Сузьте prompt или домен. Подавление синонимов направляет модель, но не навязывает словарь.

### Ссылки после переименования

Проверьте настройку Obsidian и неоднозначность имени, затем исправьте цель. Повтор LLM не является детерминированным ремонтом ссылок.
