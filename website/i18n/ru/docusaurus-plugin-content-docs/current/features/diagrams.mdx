# Диаграммы

<TLDR>
Выберите несколько типов диаграмм за один запуск и несколько форматов для каждого типа отдельно. Снятие отметки сохраняет форматы типа; без выбранных типов содержимое анализируется автоматически.
</TLDR>


У каждого предпросмотра независимые масштаб, перемещение, вписывание и исходный размер. Ctrl/Command + колесо меняет масштаб; обычное колесо прокручивает. Большие PNG сохраняют выбранные 72–600 PPI (по умолчанию 300). SVG — векторный формат; PPI применяется только к растровому экспорту.


**Создавать изображения, совместимые с Obsidian** — Включено по умолчанию. Проверяет декодирование PNG в Obsidian; при ошибке сохраняет оригинал и добавляет копию с меньшим PPI. PPI указан в обоих именах файлов. При отключении экспортируется только запрошенный оригинал. (`note_drawnix_300ppi.png`, `note_drawnix_obsidian_87ppi.png`).

## Три разных выбора

| Выбор | Что определяет | Примеры |
| --- | --- | --- |
| Тип диаграммы | Смысл диаграммы | Блок-схема, последовательность, схема цепи, график |
| Исходный формат | Редактируемый или повторно используемый файл | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Формат экспорта | Изображение или документ для передачи | SVG, PNG, PDF |

HTML диаграммы содержит масштабируемую графику; HTML структурированного резюме — текст, структуру и ссылки на источники. Редактируемый HTML/SVG — название рендерера, а не веб-редактора. Для правок используйте родной исходный файл. Экспорт презентаций, включая PPTX и MP4, сохраняет отдельные настройки и зависимости.

## Исходный формат

| Формат | Назначение | Исходный файл |
| --- | --- | --- |
| Mermaid | Диаграммы внутри Markdown | Блок кода Mermaid |
| JSON Canvas | Нативные canvas Obsidian | `.canvas` |
| Draw.io | Редактирование в diagrams.net и совместимых средствах | `.drawio` |
| Drawnix | Редактирование в стиле доски/ручного рисунка | `.drawnix` |
| CircuitikZ | Структурированные электрические и транзисторные цепи | `.tex` |

Поддерживаемые форматы идут первыми; несовместимые остаются видимыми, но недоступными для выбора. Ранее сохранённые неактивные запросы можно удалить. Форматы закреплены за своим типом. Если ни один не подходит, используется попытка экспорта в исходный формат по умолчанию текущего рендерера с отчётом о недоступных запросах.

## Генерация и экспорт

1. Откройте поддерживаемую исходную заметку. Для отрывка сделайте отдельную: выделение не сужает файловое действие.
2. Выберите несколько типов диаграмм за один запуск и несколько форматов для каждого типа отдельно. Снятие отметки сохраняет форматы типа; без выбранных типов содержимое анализируется автоматически.
3. Флажок включает тип. Нажмите название, чтобы выбрать его и настроить форматы. Наведение указателя или фокус клавиатуры меняет предпросмотр без сохранения настроек. Escape закрывает меню и возвращает фокус.
4. Выполните **Создать диаграмму**.
5. Выбранные файлы автоматически экспортируются рядом с исходной заметкой или прямо в указанную папку. Имя содержит тип, например `topic_drawnix.pdf` и `topic_flowchart.svg`. При совпадении добавляются `-2`, `-3` и далее, без перезаписи файлов.
6. Проверьте доску и панели в порядке источника внутри единого вертикального preview; Mermaid использует реальную высоту.
7. Используйте **Экспортировать SVG**, **Экспортировать PNG**, **Export PDF** панели или верхний экспорт всех панелей. Для нескольких задайте исходную/собственную Vault-папку: отдельные детерминированные имена и продолжение после ошибки одной панели. **Сохранить исходный файл** сохраняет редактируемый артефакт.

Задайте общую папку промежуточных файлов относительно Vault или оставьте поле пустым для `notemd_assert/` рядом с каждым источником. Здесь хранятся записи восстановления, кэш рендеринга и необязательные вложения. Сохраняйте ещё используемые файлы; смена папки влияет только на новые запуски.

Типы создаются последовательно. Ошибка одного не блокирует остальные; отмена останавливает ожидающие типы и сохраняет готовые файлы. Повторите экспорт из предпросмотра или истории без нового запроса к модели. Ошибка генерации требует повторной генерации этого типа. Записи v1/v2 остаются читаемыми.

Меню Export и заголовки панелей дают те же три действия. **History** открывает историю, не скрывая preview: поиск, фильтры, повторное открытие и сохранённые артефакты. История доступна также из палитры/панели без активной заметки.

SVG/PDF используют векторную геометрию; PDF повторяет SVG-макет и метрики текста, а не растрирует весь preview. PPI относится только к PNG: 72–600, начальное 300.

## Плотные макеты

Редактируемые HTML/SVG lane-grid измеряют и переносят сводку до размещения названия/шапки, рисуют ячейки перед соединителями и подписями. Ортогональные маршруты обходят занятые ячейки и области текста.

`quadrantChart` нормализуется отдельно без flowchart-ремонта кавычек/форм. Копированная открывающая скобка удаляется только как непарный последний символ подписи точки; намеренные скобки осей/заголовков остаются.

[Набор примеров](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) хранит двуязычные входы, SVG/PNG и manifest. `passed` относится к записанному запуску и bundle, не к новой проверке всех типов на последующем релизе. Исполняемый каталог — 33 строки, UI — 21 локаль, сайт — 34. Пять точных эталонных грамматик остаются вне селектора до независимых доказательств макета.

## Drawnix со встроенным Mermaid

SVG очищается, исходник Mermaid сохраняется в метаданных `.drawnix`; preview не требует runtime Drawnix/Plait. Стандартный путь самодостаточен, без `.assets`. **Also export complete Mermaid visuals** добавляет исходники, SVG и manifest companions. Старые `.assets` поддерживаются, недостающий SVG можно восстановить из сохранённого исходника.

Разрешённые изображения по возможности получают SVG с данными. Порядок загрузки: встроенные данные, старые companion-файлы, восстановление из исходника. Сохраняйте используемые ссылки: новый самодостаточный экспорт не доказывает ненужность старой общей папки.

Drawnix сохраняет все явно заданные направленные связи без общего ограничения или лимита на узел. Удаляются только одинаковые утверждения; разные предикаты и обратные направления сохраняются. Перекрывающиеся внешние маршруты получают отдельные дорожки, непересекающиеся используют дорожки повторно. Для подписей выделяются строки по размеру текста, а холст расширяется по необходимости. Стрелки без подписи, общие ассоциации и связи, повторяющие иерархию, остаются в метаданных с причиной. Текст в рамках виден в PDF, в том числе из старого кеша SVG. Межветвевые стрелки статичны и могут отсоединяться после перестановки узлов в Drawnix.

## Нативные границы

Исходник и визуальный экспорт — разные результаты. Проверьте образец в целевом приложении. PowerPoint сохраняет поддерживаемые редактируемые таблицы, включая исправленные разделители под объединёнными ячейками; Mermaid/SVG могут остаться изображениями. Preview и общий балл снимка не заменяют проверку нативного потребителя.

## Электрические схемы

Выберите **Circuit diagram** и **CircuitikZ source file**. Сначала формируется структурированное описание, затем source; это ограничивает произвольный LaTeX. Поддержка намеренно узкая: common-source NMOS и поддерживаемые CMOS-блоки. Всегда проверяйте source/preview перед техническим или публикационным применением.

SVG — вспомогательная проверка, не доказательство компиляции LaTeX/TikZJax. Preview, SVG/PNG и preview PDF не требуют LaTeX. Для нативного PDF/диагностики на desktop откройте **CircuitikZ native compile environment**: системный `tectonic`/`pdflatex`, собственный executable либо фиксированный управляемый Tectonic после явного **Install**. Панель показывает прогресс/ошибки и позволяет удалить управляемую среду.

## Ошибки

### Неверный тип

Выберите тип явно. Для цепи — **Circuit diagram** и **Создать диаграмму**, а не старый **Суммировать как диаграмму Mermaid**.

### Неподходящий источник

Поддерживаемые форматы идут первыми; несовместимые остаются видимыми, но недоступными для выбора. Ранее сохранённые неактивные запросы можно удалить. Форматы закреплены за своим типом. Если ни один не подходит, используется попытка экспорта в исходный формат по умолчанию текущего рендерера с отчётом о недоступных запросах.

### Нет меню Export

SVG/PNG/PDF требуют визуального preview. При одном тексте сохраните source и откройте подходящим внешним инструментом.

### CircuitikZ не компилируется

Запустите проверку **CircuitikZ native compile environment**. Восстановите управляемую среду или убедитесь, что системный/собственный компилятор получает `circuitikz`. Полная TeX-дистрибуция не включена в файл плагина.
