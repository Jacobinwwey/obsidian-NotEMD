# Перевод

<TLDR>Настроенная LLM переводит активный файл или подходящие файлы папки. По умолчанию создаётся отдельный файл с языковым суффиксом. Качество зависит от модели; 21 локаль UI и 34 локали сайта не ограничивают и не гарантируют перевод.</TLDR>

## Обзор

Выберите язык и провайдера, испытайте копию с терминами, ссылками и кодом. Это выбранная LLM, не отдельная интеграция Google Translate. Действия работают с файлами/папками: для одного отрывка создайте временную заметку. Выделение не сужает **Перевести текущий файл**.

## Как это работает

### Команда

1. Выберите целевой язык: изначально английский, независимо от UI.
2. Откройте источник и выполните **Перевести текущий файл**.
3. Длинный текст делится, отправляется модели, ответы объединяются.
4. Откройте сообщённый путь и проверьте смысл, термины, цитаты, ссылки и код.

Французский перевод `Example.md` по умолчанию становится соседним `Example_fr.md`. Оригинал сохраняется, существующий результат заменяется. Добавление к источнику и заголовок `Translation` не являются гарантированным стандартным поведением.

### Языковые пары

Исходный язык определяет модель. Пункт меню не доказывает точность пары. Проверяйте смешанные языки и термины; разбиение может терять межфрагментный контекст.

### Модель задачи

При включённых индивидуальных моделях действуют `translateProvider`/`translateModel`, иначе активный профиль. Локальной модели нужен сервер, облако получает prompt и текст. Выбирайте по проверке отраслевого образца, не общему рейтингу.

### Папка

**Пакетный перевод папки** по умолчанию берёт только непосредственные дочерние файлы; расширенные профили могут менять область. Одноимённые источники в общей выходной папке могут столкнуться. Проверяйте существующие переводы и назначения до повтора.

## Настройки

| Настройка | Начальное значение | Эффект |
| --------- | --------- | -------- |
| `language` | `en` | Целевой язык |
| `translateProvider` | `DeepSeek` | Провайдер при индивидуальной маршрутизации |
| `translateModel` | `''` | Пустое поле использует модель провайдера |
| `useCustomTranslationSuffix` | `false` | По умолчанию суффикс кода языка |
| `translationCustomSuffix` | `_translated` | Суффикс при включении пользовательского режима |
| `useCustomTranslationSavePath` | `false` | По умолчанию рядом с источником |
| `translationSavePath` | `''` | Папка относительно хранилища |
| `batchConcurrency` | `1` | Запрошенный параллелизм перевода папки |

Если пользовательскую папку создать нельзя, возможен возврат к исходной: проверяйте фактически сообщённый путь. Пустой собственный суффикс может указывать на имя оригинала. Для отдельного результата задайте отличающийся суффикс.

## Пример

Скопируйте короткую китайскую заметку в тестовую папку, выберите английский и переведите файл. Сравните `_en.md` с оригиналом: термины, числа, формулы и ссылки. Затем расширяйте область.

## Отмена и проверка

Отмена останавливает дальнейшую поддерживаемую работу, но не откатывает переводы и не гарантирует прекращение оплаты. Проверьте отчёт и файлы. Инструкция сохранять Markdown — просьба модели, не гарантия семантической эквивалентности на уровне парсера.

## Практика

- Сохраните оригинал и проверьте конфликты имён.
- Для эксперимента используйте отдельные суффикс/папку.
- Сверяйте идентификаторы, формулы, URL и имена.
- Очистите диагностику перед передачей.
