# Установка

<TLDR>Установите Notemd через Community plugins либо скопируйте три исполняемых файла одного GitHub Release в хранилище. Включите плагин, настройте провайдера и обработайте пробную заметку. Сервер модели и необязательные средства нативного экспорта готовятся отдельно.</TLDR>

## Способ 1: каталог плагинов — рекомендуется

1. В нужном хранилище откройте **Settings → Community plugins**.
2. При необходимости разрешите плагины сообщества и выберите **Browse**.
3. Найдите **Notemd**, проверьте репозиторий `Jacobinwwey/obsidian-NotEMD` и нажмите **Install**.
4. Нажмите **Enable** и откройте боковую панель значком или через палитру команд.

[Открыть Notemd в Obsidian](obsidian://show-plugin?id=notemd). Если браузер не обрабатывает ссылку, используйте меню выше; чтение документации не требует обработчика протокола.

## Способ 2: вручную

### Требования

Нужны установленный Obsidian и хранилище, которое можно сохранить в резервной копии. Минимум `0.15.0` в manifest — декларация, а не свидетельство проверки нового кандидата на этой версии.

### Шаги

1. Скачайте `main.js`, `manifest.json`, `styles.css` из одного [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` — справочный, не обязательный исполняемый файл.
2. Создайте `<vault>/.obsidian/plugins/notemd/` и скопируйте туда три файла. Если каталог конфигурации изменён, используйте фактический путь.
3. Перезагрузите Obsidian и включите плагин.
4. Проверьте версию; не смешивайте новый manifest со старым bundle.

## Альтернатива: BRAT

Если уже используете [BRAT](https://github.com/TfTHacker/obsidian42-brat), добавьте репозиторий через его установку бета-плагинов. Для воспроизведения ошибки фиксируйте выпуск. Это внешний необязательный инструмент.

## Проверка

Настройте доступные провайдер и модель, выполните **Проверить подключение**, затем [пробную задачу](./quick-start). Проверка списка моделей может пройти без генерации; реальное задание проверяет модель и запись результата.

## Системные условия

| Область | Граница поддержки |
| --------- | ---------- |
| Manifest | Объявлены Obsidian `0.15.0` и `isDesktopOnly: false` |
| Свидетельства проверки | Смотрите датированный отчёт выпуска; физические мобильные устройства и 0.15.0 сейчас не проверены |
| Облачная модель | Сеть, разрешённые аккаунт/ключ и модель |
| Локальная модель | Отдельно установленный работающий сервер и загруженная модель |
| Нативный экспорт слайдов/схем | Настольные инструменты и зависимости формата; сначала проверьте среду |

Общей гарантии версий ОС для всех экспортёров нет. Предпросмотр схемы не доказывает компиляцию TeX; настольный тест не подтверждает работу на телефоне.

## Удаление

Отключите или удалите плагин через Community plugins. Созданные заметки и артефакты остаются обычными файлами. Проверьте их перед удалением и сохраните настройки для переустановки. Удаление плагина не отменяет выполненные изменения.

## Обновление

Используйте **Check for updates**. При ручном обновлении остановите задачи, сохраните хранилище/настройки, замените три файла из одного выпуска и перезагрузите приложение. Изучите изменения и проверьте маленькую задачу перед пакетной работой. Не заменяйте настройки хранилища файлом релиза. Для отката намеренно установите известный совместимый выпуск, сохранив нужные результаты.
