# Настройки

<TLDR>Откройте Settings → Notemd и найдите поле поиском. Задайте провайдера и назначения до обработки. Проверяйте изменения на одной заметке: работающая задача может сохранять конфигурацию, полученную при запуске.</TLDR>

## Обзор

Изначально выбран DeepSeek с пустыми учётными данными. Профиль не создаёт аккаунт, не устанавливает модель и не предоставляет права. См. [провайдеров](../providers/overview).

## Поиск и избранное

**Search settings** ищет имена, описания, псевдонимы и видимые категории, затем переходит к полю. **★ Favorites** показывает сохранённые настройки с описаниями и переходами; они переживают перезапуск текущего хранилища, устаревшие ID удаляются. Сворачивание панели сохраняет запрос. Список избранного и фильтр поиска по избранному — отдельные элементы.

**Diagram preview export PPI**: 300 по умолчанию, диапазон 72–600; влияет только на PNG. SVG/PDF сохраняют поддерживаемую векторную геометрию. **Also export complete Mermaid visuals** управляет сопутствующими файлами, а не видимостью Mermaid внутри Drawnix.

Выберите несколько типов диаграмм за один запуск и несколько форматов для каждого типа отдельно. Снятие отметки сохраняет форматы типа; без выбранных типов содержимое анализируется автоматически.

Задайте общую папку промежуточных файлов относительно Vault или оставьте поле пустым для `notemd_assert/` рядом с каждым источником. Здесь хранятся записи восстановления, кэш рендеринга и необязательные вложения. Сохраняйте ещё используемые файлы; смена папки влияет только на новые запуски.

## 1. Провайдер

Сохраните подходящий протоколу адрес, задайте ключ при необходимости и доступную модель. Список и успешная генерация — разные проверки. Локальному серверу нужна модель; облако/шлюз получает содержимое. Для частной работы проверяйте также маршруты отдельных задач.

## 2. Модели по задачам

`useMultiModelSettings` разделяет провайдеров/модели для ссылок, заголовков, исследования, перевода, понятий, извлечения оригинала и Mermaid. Пустой override использует модель выбранного провайдера; без этого режима действует активный профиль. Сравнивайте точность, задержку и фактическую цену на одной заметке, без универсального рейтинга.

## 3. Выходные файлы

| Задача | Поведение по умолчанию |
| ------ | ------------------------- |
| Ссылки | Соседний `_processed.md`; перемещение оригинала выключено |
| Отдельное извлечение понятий | Выбранная папка, только заголовки, без обратных ссылок |
| Перевод | Соседний `_<language>.md`; существующий результат может быть заменён |
| Исследование | Добавление сводки в активную Markdown-заметку |
| Пакетная генерация по заголовкам | Запись содержимого и перенос подходящих заметок в соседнюю `<folder>_complete`, если назначение позволяет |
| Предпросмотр/экспорт диаграмм | Выбранные файлы автоматически экспортируются рядом с исходной заметкой или прямо в указанную папку. Имя содержит тип, например `topic_drawnix.pdf` и `topic_flowchart.svg`. При совпадении добавляются `-2`, `-3` и далее, без перезаписи файлов. |
Папка понятий изначально пуста. `concepts` — выбранный вами пример. Формы заметок минимальная/полная, общего движка переменных шаблонов нет. [Понятия](../features/concept-notes). Суффиксы и папки ссылок/перевода — отдельные настройки. Проверяйте существующие назначения, восстановление и конфликты; отмена не откатывает готовые записи.

## 4. Языки

UI имеет 21 локаль, сайт — 34 языковых маршрута. `uiLocale: auto` следует доступному отображению и использует английский при отсутствии поддержки. Язык генерации независим и изначально английский. У поддерживаемых задач есть отдельные языки; перевод использует `language`. Способности модели не следуют из этих чисел.

## 5. Поиск

Явно выберите Tavily с ключом или DuckDuckGo: пустой ключ не переключает движок. Оба используют сеть, DuckDuckGo может загружать страницы. Исследование в генерации заголовков изначально выключено: `enableResearchInGenerateContent`. Локальный поиск тоже выключен и имеет отдельные области папок/задач. Найденные локально фрагменты передаются LLM вместе с prompt.

## 6. Сценарии

Используйте конструктор или одну именованную строку DSL на кнопку:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` отделяет имя, `>` — ID действий. По умолчанию сценарий останавливается при сообщённой ошибке. [Сценарии](../features/workflows) описывают ID, папки и продолжение после ошибок.

## 7. Дополнительные настройки

| Настройка | Начальное значение | Эффект |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Провайдер без индивидуальных маршрутов |
| `useMultiModelSettings` | `false` | Раздельный выбор провайдера/модели |
| `useCustomConceptNoteFolder` | `true` | Разрешить понятия после выбора папки |
| `conceptNoteFolder` | `''` | Папка изначально не выбрана |
| `extractConceptsMinimalTemplate` | `true` | Только заголовки при отдельном извлечении |
| `extractConceptsAddBacklink` | `false` | Обратные ссылки только при включении |
| `moveOriginalFileOnProcess` | `false` | Сохранять оригинал при добавлении ссылок |
| `chunkWordCount` | `3000` | Приблизительный размер фрагмента, не лимит токенов |
| `batchConcurrency` | `1` | Параллелизм пакета |
| `enableBatchParallelism` | `false` | Включить параллельность на использующих переключатель путях |
| `enableStableApiCall` | `false` | Явный стабильный режим запросов |
| `customWorkflowErrorStrategy` | `stop_on_error` | Остановка при сообщённой ошибке |

Размер фрагмента и бюджет выходных токенов различаются. Уменьшение фрагментов не гарантирует соблюдения всех лимитов контекста, а последовательность не предотвращает каждый ответ 429.

## Профили конфигурации

Настройки принадлежат данным плагина в хранилище. Сохраните резервную копию. Экспорт профилей имеет собственный контракт удаления секретов и не заменяет полный backup. Проверяйте URL/метаданные даже очищенного файла. Не публикуйте сырые настройки или диагностические тексты с частными заметками.

## Диагностика настроек

Проверьте конкретный профиль и маленькую задачу. Если поле не видно, проверьте поиск, категорию, режим разработчика и выбранное хранилище. Сообщайте версию и минимальную очищенную конфигурацию.
