# Быстрый старт

<TLDR>Начните с пробной Markdown-заметки и провайдера, к которому у вас уже есть доступ. Облако получает содержимое задачи; локальная модель требует готового сервера. Проверьте файл результата перед обработкой папки.</TLDR>

## 1. Настройте модель

1. [Установите](./installation) плагин и откройте **Settings → Notemd**.
2. Выберите профиль, адрес, необходимые учётные данные и доступную модель. **Fetch models** не заменяет проверку генерации.
3. Выполните **Проверить подключение**; сначала исправьте ошибки авторизации, модели или адреса.
4. Найдите **Путь к папке заметок-концептов** и выберите отдельную папку, например `concepts`. Изначально поле пустое; это пример, а не готовый путь.

Для Ollama сначала получите модель и укажите точное имя; начальный адрес — `http://localhost:11434/api`. Для LM Studio запустите сервер и выберите `LMStudio`. [Локальные модели](../providers/local). Веб-поиск всё равно требует сети.

## 2. Выполните задачу

Создайте `Notemd trial.md` с безопасным для выбранного провайдера текстом:

```text
Модели машинного обучения используют нейронные сети для изучения закономерностей на примерах.
```

Запустите **Обработать файл (добавить ссылки)** через панель или палитру. По умолчанию появится соседний `Notemd trial_processed.md`, а оригинал сохранится. Откройте результат. Возможный пример:

```markdown
Модели [[машинного обучения]] используют [[нейронные сети]] для изучения закономерностей на примерах.
```

В выбранной папке могут появиться заметки понятий. Проверьте их и ссылки: модель не гарантирует полный и точный набор терминов.

## 3. Другие функции

### Извлечение понятий

**Извлечь концепции (текущий файл)** не переписывает оригинал, но требует папку понятий. По умолчанию новые заметки содержат только заголовок, без обратных ссылок. Включайте их отдельно. [Понятия](../features/concept-notes).

### Исследование и сводка

Выделите тему в Markdown-редакторе или используйте заголовок и выполните **Исследовать и суммировать**. Явно выберите Tavily с ключом либо DuckDuckGo. Сводка добавляется в текущую заметку; откройте источники и проверьте утверждения.

### Сценарии одной кнопкой

Стандартный **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Добавляет ссылки, генерирует содержимое подходящих заметок в папке понятий/выбранной папке, затем исправляет Mermaid в complete. Могут обрабатываться и ранее существовавшие понятия. Используйте тестовую папку. Веб-исследование и генерация произвольных диаграмм не добавляются автоматически.

## Отмена и проверка результата

**Отмена** останавливает последующую поддерживаемую работу. Готовые файлы остаются; это не транзакция отката и не гарантия прекращения генерации/оплаты у провайдера. Дождитесь завершения и проверьте пути и конфликты восстановления перед повтором.

## Устранение ошибок

- Авторизация/модель: проверьте профиль и соединение.
- Нет понятий: выберите и включите папку.
- Нет полезных ссылок: изучите ответ/prompt; гарантированного минимума слов нет.
- Ограничения: оставьте параллелизм `1`, пока проверяете квоты.
