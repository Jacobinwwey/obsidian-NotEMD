# 常见问题

<TLDR>
从可丢弃笔记、可访问 provider 和明确输出路径开始。以下回答描述实际任务边界，完整配置与验证见链接指南。

## 问题

### 如何在 Obsidian 安装 Notemd？

打开设置 → 第三方插件 → 浏览，搜索 Notemd，安装并启用。手动安装需使用同一个 GitHub Release 的 main.js、manifest.json 和 styles.css。manifest 声明最低 Obsidian 0.15.0，但当前发布证据尚未验证该旧版本或实体移动设备。

### Notemd 支持哪些 LLM Provider？

注册表包含 36 个预设，覆盖 OpenAI-compatible、Anthropic、Google、Azure OpenAI 和 Ollama 五类协议。托管 API、网关和本地服务需配置各自的端点、凭据和模型。预设存在或模型在列表中，不保证当前上游可用性或生成权限。

### Notemd 可以使用本地 LLM 吗？

可以。配置已运行的 Ollama、LM Studio、OVMS 或兼容自托管端点。先下载或加载模型并验证目标任务。本地推理端点不会让网络研究、依赖安装或其他云端任务离线。

### Notemd 与 ChatGPT 有何区别？

Notemd 聚焦明确的 Obsidian 文件操作：链接笔记、创建概念文件、追加研究、翻译文件和生成产物。需要这些 Vault 工作流时可选择它。应按其他工具当前的持久化、导出和集成功能评估；对话工具同样可以保留历史和生成文件。

### 如何与 Copilot 或 Smart Connections 比较？

比较实际任务及各项目当前版本、配置和文档。Notemd 提供笔记转换和有界词法本地检索，不提供通用 chat-with-vault 界面或 embedding 语义搜索。本网站不宣称其他项目当前的功能排名。

### 研究功能支持哪些搜索服务？

选择 Tavily 并填写 API key，或明确选择 DuckDuckGo。Tavily 密钥为空不会自动切换 DuckDuckGo。两者均联网。所选 LLM 总结可用网络和可选本地上下文，并向活动 Markdown 笔记追加研究摘要。应核对来源 URL 与重要结论。

### 是否支持中文及其他语言？

插件 UI 有 21 个 locale，网站有 34 个语言路由。生成内容语言独立配置，支持的任务可使用专用覆盖。翻译能力和质量取决于所选模型，与界面或网站语言数量无关。

### 能否用于阅读论文或 PDF？

先用合适的外部工具把论文转换为可读 Markdown，并检查公式、表格和图片的转换错误，再用 Notemd 链接概念、提取原文、研究问题、翻译或生成图表。常规笔记工作流不承诺原生 PDF OCR 或任意二进制文档的忠实提取。

### 可以生成哪些图表？

可执行目录有 33 项，具有兼容的源格式与预览路径。Mermaid、JSON Canvas、Vega-Lite、可编辑 HTML/SVG、Draw.io、Drawnix 和受约束 CircuitikZ 面向不同需求。使用选择器支持的组合，并在目标工具核对输出；预览不能证明原生编辑或编译保真度。

### Notemd 免费且开源吗？

Notemd 采用 MIT 许可证。Provider 账户、模型推理、搜索服务和可选外部工具有各自费用与条款。仓库公开并欢迎贡献；许可证自由不代表所有外部服务免费。

### 可以百分之百离线运行吗？

本地服务、模型文件和依赖安装完成后，部分笔记任务可使用本地模型。网络研究仍需联网，包括 DuckDuckGo。断网前检查任务专用 provider 和可选导出依赖，不存在覆盖全部功能的离线保证。

### 数据会发送到云端吗？

提示词和内容发送至配置的 LLM 端点，搜索服务接收查询，页面抓取访问目标网站。本地检索可把 Vault 片段加入云端提示词，本地预设也可被配置为远端地址。分享日志前核对路由并脱敏；本地存储本身不证明数据仅留在设备。

### One-Click Extract 实际执行什么？

默认依次为活动笔记添加链接，为概念目录或所选目录内符合条件的笔记生成正文，再修复 complete 目录中的 Mermaid 块。它可能处理已有概念笔记，不自动加入网络研究或图表生成。准确的 name::action>action 语法见工作流指南。

### 取消任务会撤销修改吗？

不会。取消在支持路径停止后续工作并保留已完成输出。已接受的请求或写入仍可能完成，计费由远端 provider 控制。等待任务收敛，核对输出路径和恢复冲突，再重试所需工作。

### Agent 能否自动化 Notemd？

四个受限导出命令通过可用的 Obsidian 宿主和 Vault 提供脱敏 provider profile、能力清单、调用契约及公开 CLI 能力面，会写入导出文件。仓库维护者操作属于独立契约，内部 operation 数量不是公开自动化 API。请从 Agent 指南开始。

### 开发者与贡献者从哪里开始？

开发者指南提供仓库设置、构建与完整测试命令、模块归属及扩展规则。AGENTS.md 是仓库执行规范。提交包含准确版本和脱敏证据的可复现问题，并在提出集成前验证改动。
