# 自定义提示词

<TLDR>
全局开关和任务开关均开启、且自定义文本非空时，自定义提示词替换任务内置提示词。你需要保留输出契约；没有自动模板系统会补回所有遗漏的格式要求。
</TLDR>

## 概览

先在代表性笔记上测试默认提示词。若聚焦学习或同义词抑制已能解决问题，优先使用现有设置；需要特定提取策略、结构或翻译风格时再自定义，批量使用前比较输出。

## 工作原理

### 提示词结构

Notemd 选择内置或已启用的自定义任务提示词，添加适用的聚焦学习与语言指令，再替换该任务提供的占位符。笔记内容也可能作为独立消息发送。各任务输入不同，研究可用的变量不代表所有任务都可用。

替换提取提示词可能删掉 `CONCEPT:` 契约，替换研究提示词可能遗漏检索上下文。请求格式正确并不能证明输出可解析或有来源支撑。

### 提示词变量

必须使用下列大写名称和单层花括号：

| 任务 | 提供的占位符 |
| ------ | ----------------------- |
| 标题生成 | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| 研究摘要 | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| 翻译 | `{LANGUAGE}`, `{TEXT}` |
| 原文提取 | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` 按任务语言策略解析。添加链接和独立概念提取将源文作为任务内容发送，不要虚构内容占位符。未知变量不会自动填充；这些是任务提示词替换，不是概念笔记文件模板。

### 聚焦学习领域

启用聚焦学习并填写领域，例如 `electrical engineering`，提示词会收到 `Relevant Fields` 指令。它引导注意力，不是硬过滤器，也不能证明无关概念已排除。

## 配置

| 任务 | 启用开关 | 提示词字段 |
| ------ | --------------- | -------------- |
| 添加链接 | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| 标题生成 | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| 研究摘要 | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid 摘要 | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| 概念提取 | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| 翻译 | `useCustomPromptForTranslate` | `translatePrompt` |
| 原文提取 | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

这些开关都要求 `enableGlobalCustomPrompts`。自定义文本为空时回退内置提示词。合并原文提取有独立内置格式，不共享普通提取覆盖。图表能力生成也有自己的类型化输出要求；Mermaid 摘要提示词不是通用图表提示词。

## 示例

电路笔记的概念提取可开启全局和提取开关，使用保留解析标记的聚焦指令：

```text
从给定笔记中提取核心电气工程概念。
优先选择具体元件名称和物理机制，避免泛化名词。
每行只返回一个概念，严格使用以下格式：
CONCEPT: 术语名称
不要添加解释，也不要用代码块包裹结果。
```

用笔记副本测试，检查返回条目、文件名和遗漏概念，并与默认提示词比较。修改前保存原提示词以便恢复。

## 建议

- 一次测试一个任务，先控制范围再扩大批量。
- 研究提示词保留来源证据，提取提示词保留准确原文。
- 本地化说明时保留可执行标识符和输出标记。
- 更换模型或 provider 后重新验证；提示词不是校验保证。
