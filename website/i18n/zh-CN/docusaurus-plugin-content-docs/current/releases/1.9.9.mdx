# Notemd 1.9.9 — 多种图表，独立导出

<TLDR>
一次勾选多种图表，每种类型独立选择多种输出格式。取消勾选仍保留该类型的格式偏好；全部取消则自动分析原文。
</TLDR>

## 多种图表，独立导出

复选框控制是否生成该类型；点击名称会选中该类型并打开其格式配置。悬停或键盘聚焦切换预览，不保存设置。Escape 关闭菜单并返回焦点。

支持的格式优先显示；不兼容项保留并置灰，已有暂不可用请求仍可移除。格式选择归属于各自图表类型。全部请求不可用时，尝试有效渲染器的默认源文件，并报告不可用请求。

图形 HTML 包含可缩放的图形；结构化摘要 HTML 展示文字、结构与引文。可编辑 HTML/SVG 是渲染器名称，不代表网页内编辑器；编辑请使用原生源文件。PPTX、MP4 等演示导出保留独立设置与依赖。

Drawnix 概览最多保留六条带标签的核心有向关系，每节点最多三条；省略关系保存在源文件元数据中。PDF 关系方框文字正常显示，也兼容旧 SVG 缓存。跨分支箭头仍为静态关系，在 Drawnix 重排后可能脱离节点。

## 文件与恢复

所选文件自动导出到原笔记所在目录，或直接保存到配置的输出目录。名称包含图表类型，如 `topic_drawnix.pdf`、`topic_flowchart.svg`；重名追加 `-2`、`-3` 等序号，不覆盖已有文件。

图形中间文件目录可设置为统一的 Vault 相对路径；留空则使用各原文旁的 `notemd_assert/`。恢复记录、渲染缓存及可选附件存放于此。保留仍被已有产物引用的文件；目录变更仅影响新任务。

各类型顺序生成，一种失败不阻断其余类型；取消会停止后续类型并保留完成文件。导出失败可从预览或历史重试，无须再次请求模型；生成阶段失败仍需重新生成该类型。旧版 v1/v2 恢复记录继续可读。

## 升级

停止活动任务并备份 Vault。从同一 1.9.9 Release 安装 `main.js`、`manifest.json`、`styles.css`，保留设置与生成文件，再重载 Obsidian。先验证一篇笔记，再执行大批量任务。旧偏好在编辑时迁移；译文直接撰写，未调用翻译 API 或 LM Studio。
