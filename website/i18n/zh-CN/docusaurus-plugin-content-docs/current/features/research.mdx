# 研究与网络搜索

<TLDR>
研究与摘要会搜索选中主题或当前笔记标题，让配置的 LLM 总结可用上下文，再将结果追加到活动 Markdown 笔记。请明确选择 Tavily 或 DuckDuckGo，并核对搜索结果和模型引用。
</TLDR>

## 概览

搜索 provider 与写摘要的 LLM 分别配置。Tavily 需要密钥，DuckDuckGo 无需密钥但仍联网且可能限流。本地摘要模型不会让网络研究变成离线流程。

## 工作原理

### 先搜索再总结

1. 在 Markdown 编辑器打开目标笔记，选取短主题；无选区时使用标题。
2. 从侧边栏或命令面板运行 **研究并总结**。
3. 查询所选搜索 provider；Tavily 使用返回片段，DuckDuckGo 结果可能触发页面抓取。
4. 若为本任务启用了本地知识检索，限定范围的片段也会进入提示词。
5. 研究 provider/model 生成摘要，追加在标识主题和上下文来源的 `Research Summary` 标题下。
6. 核对追加文本并打开来源 URL；检索成功不证明所有生成陈述或引用都有依据。

### Tavily 与 DuckDuckGo

| 选项 | 设置 | 运行边界 |
|---|---|---|
| Tavily | 选择 Tavily 并填写 API key | 使用账户搜索配额和返回片段 |
| DuckDuckGo | 明确选择 DuckDuckGo | 无密钥；受搜索限流和结果页面可用性约束 |

Tavily 密钥为空或无效不会自动选择 DuckDuckGo。没有有效网络上下文时检查报告；已启用且可用的本地知识仍可能支持摘要，来源标签会将其与网络研究区分。

### 标题生成中的研究

开启 **在“从标题生成”中启用研究** 可为标题生成及批量版本加入研究，默认关闭。这是支持的文件夹生成入口，并不存在独立通用 Research Folder 动作。

## 配置

| 设置 | 默认值 | 作用 |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | 搜索后端 |
| `tavilyApiKey` | `''` | 使用 Tavily 前填写密钥 |
| `tavilyMaxResults` | `5` | 请求的 Tavily 结果数 |
| `tavilySearchDepth` | `basic` | Tavily 搜索深度 |
| `ddgMaxResults` | `5` | 请求的 DuckDuckGo 结果数 |
| `ddgFetchTimeout` | `15` | 结果页面抓取超时，单位秒 |
| `maxResearchContentTokens` | `3000` | 近似网络上下文预算 |
| `researchProvider` | `DeepSeek` | 任务专用路由启用时的摘要 provider |
| `researchModel` | `''` | 为空时使用该 provider 配置的模型 |
| `researchSummarizeLanguage` | `en` | 任务专用语言开启时的输出语言 |
| `enableResearchInGenerateContent` | `false` | 按需在标题生成中启用研究 |
| `enableLocalKnowledgeRetrieval` | `false` | 独立启用限定范围本地检索 |
| `enableLocalKnowledgeForResearchSummarize` | `false` | 为本任务使用本地检索 |

### 上下文与模型选择

上下文限制基于估算，不是 provider 精确 token 化，截断可能遗漏证据。按材料选择模型与输出预算，保持问题聚焦。本地索引是词法检索，不代表 embedding 语义搜索或完整召回。

## 示例

创建标题为 `Relative positional encoding` 的笔记，运行研究，再用引用原论文或官方文档核验解释。保留问题、实际来源 URL 和更正，便于他人审计结论。指南中的示例不是为你的 Vault 实际产生的研究结果。

## 取消与隐私

取消在受支持路径停止后续工作，已追加文本保留，进行中的 provider 请求或网页抓取仍可能完成。搜索服务接收查询，目标网站接收请求，所选 LLM 接收收集的上下文，包括启用时的本地片段。分享诊断前审核。

## 建议

- 区分网络来源、本地笔记和模型推断。
- 在原材料中核对引文、日期和重要结论。
- 用小查询分别诊断搜索和 LLM 失败。
- 重跑前检查已有摘要，避免重复追加。
