# Wiki 链接

<TLDR>
“处理文件：添加链接”让所选 LLM 识别概念并添加 Obsidian wiki 链接。默认写入独立 `_processed.md` 文件并保留源文件；生成概念文件需要指定概念目录。扩大到文件夹前先审核输出。
</TLDR>

## 概览

适合根据笔记含义发现候选链接。模型每次选择的术语可能不同，也可能链接尚无文件的概念。Wiki 链接是导航目标，不能证明概念等价或生成的解释正确。

## 工作原理

### 处理流程

任务分块读取笔记，把各块发送给所选 provider/model，合并响应并写入处理结果，还可在配置目录创建或更新概念笔记。通过进度报告检查部分失败和实际目标路径。

### 示例

源文：

```text
机器学习模型使用神经网络，从示例中学习规律。
```

可能的输出：

```markdown
[[机器学习]]模型使用[[神经网络]]，从示例中学习规律。
```

这只是示例；具体链接取决于源文、模型和提示词。

## 使用方式

### 基础：为当前笔记添加链接

打开 Markdown 副本，从侧边栏或命令面板运行 **处理文件（添加链接）**。默认检查同级 `_processed.md` 文件；自定义后缀、处理后目录与移动原文件设置会改变目标行为。

### 批量：处理多篇笔记

选择 **处理文件夹（添加链接）**，确认文件夹与范围，从小样本开始。不同文件夹任务没有统一的覆盖／跳过开关；重跑前阅读[批量处理](../advanced/batch-processing)。

### 选区：链接指定文本

要自行指定术语，使用 **Create wiki link and generate note from selection**。这是独立动作，不会让整文件添加链接动作只处理选区。核对创建的概念笔记和正文。

## 选择链接方式

需要从内容发现候选概念时使用模型辅助链接；需要按现有笔记名称稳定复现时，选择确定性标题匹配。比较其他插件应依据其当前文档；本指南不作缺少带日期基准的功能或性能比较。

## 功能

### 同义词抑制

`replaceSynonymsDuringConceptExtraction` 添加避免同义或高度重叠概念的指令，是默认关闭的布尔设置，不是数值相似度阈值。缩写与近义词仍需人工审核。

### 链接完整性

重命名后的内部链接更新由 Obsidian 根据设置和操作类型负责。删除目标可能留下未解析链接，与未链接提及不同。不同目录有同名笔记时，应检查 basename 歧义。

### 纯提取模式

需要创建概念文件而不改写源笔记时，运行 **提取概念（当前文件）**。其最小模板和反向链接设置不同于添加链接，参见[概念笔记](./concept-notes)。

## 概念笔记生成

### 自动创建

启用概念目录输出并配置路径后，添加链接可创建含标题与 `Linked From` 来源链接的笔记；不会自动生成研究解释、相关概念章节或可配置 frontmatter 模板。需要正文时单独执行标题生成。

### 配置

搜索概念目录、处理后目录、添加链接后缀及移动原文件设置。概念目录初始为空。测试时将输出与源文件集分开。

## 高级选项

### 上下文与提示词

`chunkWordCount` 控制近似分块大小。聚焦学习与自定义添加链接提示词可以缩小概念范围；本任务没有句子／段落上下文选择器、最少出现次数阈值或通用概念模板变量。

## 建议

- 对照源文审核引文、公式和代码。
- 判断新链接术语是否值得建立概念笔记。
- 先在稳定样本上测试提示词，再处理文件夹。
- 开启移动源文件或重写已有目标前备份。

## 性能

延迟和费用取决于 provider、模型、提示词大小、输出长度及重试次数，不承诺固定的单篇耗时或每百篇费用。扩大范围前测量代表性样本并核对账户实际用量。

## 故障排查

### 没有新增链接

检查请求状态和模型响应，确认处理了预期笔记并打开报告中的输出文件。不存在保证产生有效链接的最小字数。

### 链接过多

缩小提示词范围或启用聚焦学习后核对结果。同义词抑制可引导模型，但不能强制执行词表。

### 重命名后链接失效

检查 Obsidian 链接更新设置和既有歧义，明确恢复或修复目标。重跑 LLM 任务不是确定性的链接修复。
