# 概念笔记

<TLDR>
独立概念提取读取源笔记，在指定目录创建概念 Markdown 文件。目录设置初始为空，新笔记默认仅含标题，来源反向链接默认关闭。添加链接流程使用不同的概念笔记模板。
</TLDR>

## 概览

先配置 **Concept note folder（概念笔记文件夹）**。专用目录便于检查结果、重复项和后续标题生成范围。提取只创建概念文件，不会自动为每个概念补充研究解释。

## 工作原理

### 提取管线

任务将内容发送给 LLM，解析 `CONCEPT:` 条目，在操作内去重，然后创建或更新概念文件。长笔记会分块；检查失败块和不完整输出。模型响应不等于完整概念清单。

### 提取提示词

内置提示词要求与主题相关的具体概念。聚焦学习和同义词抑制可影响模型，但不保证规范词表。自定义提示词必须保留 `CONCEPT: Term` 输出契约，详见[自定义提示词](../advanced/custom-prompts)。

### 分块

`chunkWordCount` 默认 `3000`，是按词估计的切分大小，不是 provider token 预算。跨块上下文有限，处理后应核对相关概念和歧义名称。

## 创建概念笔记

### 文件名规则

名称会清理不支持的路径字符、规范空白并截断过长部分；空结果跳过。不同短语可能映射到同一文件名，大规模生成前先检查命名。

### 模板

新独立概念笔记默认使用最小模板：

```markdown
# Concept Name
```

新笔记需要反向链接时，开启 **添加 “Linked From” 回链** 并关闭 **创建最简概念笔记**。支持的完整形式为：

```markdown
# Concept Name

## Linked From
- [[Source Note]]
```

添加链接流程启用概念输出后创建带反向链接的完整笔记；独立提取开关不会改变这一行为。

### 更新已有笔记

启用反向链接后，可在已有概念笔记的 `## Linked From` 下补充缺失来源链接，保留正文且不重复追加相同链接。来源使用笔记 basename，Vault 有同名来源时需检查歧义。

### 配置

| 设置 | 默认值 | 作用 |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | 配置目录后启用概念输出 |
| `conceptNoteFolder` | `''` | 初始未选择目录 |
| `extractConceptsMinimalTemplate` | `true` | 独立提取创建仅标题笔记 |
| `extractConceptsAddBacklink` | `false` | 为独立提取启用反向链接 |
| `extractConceptsProvider` | `DeepSeek` | 任务专用路由启用时的 provider |
| `extractConceptsModel` | `''` | 为空时使用所选 provider 的模型 |
| `extractConceptsLanguage` | `en` | 任务专用输出语言启用时的语言 |
| `replaceSynonymsDuringConceptExtraction` | `false` | 添加同义词抑制指令 |
| `generateConceptLogFile` | `false` | 按需生成概念日志 |

## 去重

重复检测使用文件名启发式，包括不区分大小写、复数形式、符号规范化，以及所选范围允许的单词包含关系。它们不是语义等价证明，不规则复数与不同技术含义需人工核对。

选择 **检查并移除重复项**，检查候选列表，只确认需要删除的文件。批准项通过 Obsidian 垃圾箱操作处理。概念目录不是可随意丢弃的缓存，批量清理前备份。

### 范围模式

可与整个 Vault、概念目录、指定包含目录或排除部分目录后的范围比较。批准删除前核对范围；范围改变候选集合，不改变“重复”的含义。

## 使用方式

### 独立提取概念

打开 Markdown 笔记，确认概念目录，执行 **提取概念（当前文件）**。源笔记不变；核对文件名、概念覆盖和可选反向链接。

### 提取并生成正文

对概念目录运行 **从标题批量生成** 补充解释。可能处理目录内已有的符合条件笔记，不限于最近提取的文件。先审核目录，再核对报告中的 complete 目标目录。

### 从选区创建 Wiki 链接

选区动作可将指定术语包装为 wiki 链接，并在目标配置完成时创建概念笔记。适合由你选词，而不是让模型从整篇笔记选择概念。

## 建议

- 从短源文和专用目录开始。
- 大量创建前确定输出语言。
- 分别审核同义词建议与重复候选。
- 后续运行覆盖日志前，保留仍需使用的日志。
