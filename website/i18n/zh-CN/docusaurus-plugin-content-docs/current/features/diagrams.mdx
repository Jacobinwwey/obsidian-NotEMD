# 图表

<TLDR>
一次勾选多种图表，每种类型独立选择多种输出格式。取消勾选仍保留该类型的格式偏好；全部取消则自动分析原文。
</TLDR>

PNG／PDF 在图形预览窗口内打开，每个 PDF 页面都有独立控制。缩放时按屏幕像素密度重绘可见内容，并限制内存占用；嵌入位图的清晰度仍受源图分辨率限制。

按住 Alt 可暂时冻结移动和缩放，便于选择 SVG／HTML／PDF 中可选的文字；松开后恢复之前的锁定状态。PNG 没有可选择的文字层。


每个图形预览独立支持缩放、平移、适应窗口与实际大小。Ctrl/Command＋滚轮缩放，普通滚轮用于滚动。 大图 PNG 保留所选的 72–600 PPI（默认 300）。SVG 是矢量格式，PPI 仅作用于位图导出。


**生成图片兼容 Obsidian** — 默认开启。检查 PNG 能否在 Obsidian 中解码；若失败，保留请求 PPI 的原图，并追加较低 PPI 的兼容副本，两份文件名均标注 PPI。关闭时仅导出请求原图。 (`note_drawnix_300ppi.png`, `note_drawnix_obsidian_87ppi.png`).

## 理解三个不同选择

| 选择 | 控制内容 | 示例 |
|---|---|---|
| 图表类型 | 表达的含义 | 流程图、时序图、电路图、数据图 |
| 源格式 | 可编辑或复用的源文件 | Mermaid、JSON Canvas、Draw.io、Drawnix、CircuitikZ |
| 导出格式 | 用于分享的图像或文档 | SVG、PNG、PDF |

图形 HTML 包含可缩放的图形；结构化摘要 HTML 展示文字、结构与引文。可编辑 HTML/SVG 是渲染器名称，不代表网页内编辑器；编辑请使用原生源文件。PPTX、MP4 等演示导出保留独立设置与依赖。

## 选择源格式

| 格式 | 适用场景 | 源文件 |
| --- | --- | --- |
| Mermaid | 直接保存在 Markdown 的图表 | Mermaid 代码块 |
| JSON Canvas | Obsidian 原生画布流程 | `.canvas` |
| Draw.io | 后续在 diagrams.net 或兼容工具编辑 | `.drawio` |
| Drawnix | 手绘或白板编辑 | `.drawnix` |
| CircuitikZ | 结构化电路与晶体管电路 | `.tex` |

支持的格式优先显示；不兼容项保留并置灰，已有暂不可用请求仍可移除。格式选择归属于各自图表类型。全部请求不可用时，尝试有效渲染器的默认源文件，并报告不可用请求。

## 生成并导出图表

1. 打开受支持源笔记。仅需部分内容时放入独立笔记；选中文本不缩小文件生成范围。
2. 一次勾选多种图表，每种类型独立选择多种输出格式。取消勾选仍保留该类型的格式偏好；全部取消则自动分析原文。
3. 复选框控制是否生成该类型；点击名称会选中该类型并打开其格式配置。悬停或键盘聚焦切换预览，不保存设置。Escape 关闭菜单并返回焦点。
4. 从侧栏或命令面板运行 **生成图形**。
5. 所选文件自动导出到原笔记所在目录，或直接保存到配置的输出目录。名称包含图表类型，如 `topic_drawnix.pdf`、`topic_flowchart.svg`；重名追加 `-2`、`-3` 等序号，不覆盖已有文件。
6. 检查预览。多面板在一个垂直滚动容器内按源顺序显示 Drawnix 和 Mermaid，Mermaid 使用实际渲染高度而不裁剪。
7. 勾选 SVG、PNG 和／或 PDF 并选择目录，一次确认即可导出。主导出按钮处理全部面板，单个面板按钮仅处理该面板。演示格式改用复选框，至少保留一项；进度与部分失败会明确显示。

图形中间文件目录可设置为统一的 Vault 相对路径；留空则使用各原文旁的 `notemd_assert/`。恢复记录、渲染缓存及可选附件存放于此。保留仍被已有产物引用的文件；目录变更仅影响新任务。

各类型顺序生成，一种失败不阻断其余类型；取消会停止后续类型并保留完成文件。导出失败可从预览或历史重试，无须再次请求模型；生成阶段失败仍需重新生成该类型。旧版 v1/v2 恢复记录继续可读。

需要可编辑产物时，选择**保存源文件**。

在预览中点击**历史**可打开 Vault 历史抽屉而不隐藏图表，搜索筛选已完成图表，重新预览或打开产物。没有活动笔记时，也可从命令面板或侧栏进入历史。

SVG／PDF 使用矢量几何；PDF 复用 SVG 布局与文字度量，不对整个预览光栅化。图像 PPI 仅控制 PNG，范围 72–600，默认 300。

## 密集图表的可读预览

可编辑 HTML/SVG 泳道网格先测量和换行摘要，再放置标题与泳道表头。表头避开摘要区域，单元格先于连接线和边标签绘制。跨泳道边使用避碰正交网格路线，为标签和已占单元格保留空间，避免长文遮挡或迫使横向拖动。

Mermaid 象限图按家族规范化。`quadrantChart` 跳过仅适用流程图的引号／形状修复；只有数据点标签末尾未配对的多余左括号会被移除，标题、轴和象限名中有意使用的括号保留。

仓库为每种可执行图表类型保留真实 Vault 证据，见 [`docs/diagram-examples/`](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples)：双语输入、SVG／PNG 和机器可读 manifest。`passed` 只对应记录中的运行与 bundle 身份，不证明后续版本重新运行了所有类型。

当前可执行目录有 33 项，插件 UI 21 个 locale，网站路由 34 个 locale，三者不可混用。五个精确参考语法在独立布局证据齐备前不进入选择器。

## 含嵌入 Mermaid 的 Drawnix 预览

Drawnix 含 Mermaid 时，Notemd 净化渲染 SVG，并在 `.drawnix` 元数据保留源文；预览不需要 Drawnix／Plait 运行时。默认路径自包含，不创建独立 `.assets`。需要交接或外部编辑时开启**同时导出完整 Mermaid 可视化**，生成源文、SVG 和 manifest 配套文件。已有 `.assets` 仍支持，旧 Mermaid SVG 缺失时可用元数据源文重建。

尽可能为已解析图片嵌入生成数据支持的 SVG 预览。加载顺序为内嵌数据、旧配套文件、可用源文重建。已有产物仍引用配套目录时应保留；新导出自包含不证明旧共享目录未使用。

预览只有一个滚动区域，主 Drawnix 画布在前，随后按源顺序显示 Mermaid。关闭并重新打开历史记录，会重建相同面板列表、尺寸和导出动作。

Drawnix 保留全部明确的有向关系，不限制总条数或每个节点的关系数。相同关系去重，不同谓词及反向关系分别保留。外侧连线区间重叠时错开轨道，不重叠时复用轨道，标签按实际尺寸分行；画布随关系需要扩展。无标签、泛化或重复层级的连线仍附原因保存在元数据中。PDF 关系方框文字正常显示，也兼容旧 SVG 缓存。跨分支箭头仍为静态关系，在 Drawnix 重排后可能脱离节点。

## 原生导出边界

源导出与视觉导出是不同交付物，分享前在目标应用测试代表性产物。PowerPoint 表格保留受支持可编辑结构，包括修正后的合并单元格下方分隔线；Mermaid／SVG 可能回退为图像，而非原生可编辑形状。插件预览或全页图像评分不能代替原生应用检查。

## 电路图

受支持电路请求选择**电路图**与 **CircuitikZ 源文件**。Notemd 先生成结构化电路描述，再生成 CircuitikZ，比请求任意 LaTeX 更可控。

当前 CircuitikZ 支持有意保持受约束范围。共源 NMOS 放大器和受支持 CMOS 基础模块较适合；用于技术文档或出版前始终审核预览与源文。

SVG 是 Notemd 生成的审核辅助，不证明本地 LaTeX 或 TikZJax 已成功编译 `.tex`。

**可选原生编译。** 插件预览和 SVG、PNG、预览 PDF 不需要 LaTeX。桌面端需要编译诊断或原生 LaTeX PDF 时，从设置或命令面板打开 **CircuitikZ native compile environment**。可复用系统 `tectonic`／`pdflatex`、自定义可执行文件，或显式点击 **Install** 安装固定版本托管 Tectonic。面板内显示进度和错误，并支持日后移除。

## 故障排查

### 图表类型错误

显式选择类型而非自动检测。电路选**电路图**并运行 **生成图形**，不是旧 **总结为 Mermaid 图表**。

### 源格式不合适

支持的格式优先显示；不兼容项保留并置灰，已有暂不可用请求仍可移除。格式选择归属于各自图表类型。全部请求不可用时，尝试有效渲染器的默认源文件，并报告不可用请求。

### 导出菜单缺失

SVG、PNG、PDF 需要可视化预览。只有源文时保存源文件并在匹配外部工具打开。

### CircuitikZ 外部编译失败

打开 **CircuitikZ native compile environment** 检查环境，修复托管运行时或确认自定义／系统编译器可获取 `circuitikz`。插件文件不捆绑完整 TeX 发行版。

## 1.9.10 — 安全预览与 Vault 本地设置

导入 SVG 预览会移除活动内容和外部资源，同时保留中文标签与面板样式。仅设备 provider 现按 Vault 隔离；在设置中显式导入旧列表，保留原列表与已有配置。演示预览仅使用 loopback 服务器，并管理共享消费者的生命周期。收藏保存或剪贴板写入失败会报告错误；删除遵守 Vault 偏好。PNG 兼容默认开启，保留请求原图，仅在需要时增加已验证的低 PPI 副本。Drawnix 没有固定关系配额；演示导出保持独立设置。安装同版本发布文件、重载插件，批处理前先验证一篇笔记。

## 1.9.11 — 更清晰的图形与更可靠的 PDF 导出

Drawnix 将关联紧密的分支放得更近，减少连接线重叠与交叉，同时保留全部节点和明确关系。跨分支箭头重排后仍有静态坐标限制。

PDF 导出在净化 SVG 后正确处理复杂选择器与继承样式，补全缺失的 viewBox，并将超大页面等比例缩放，保留向量图形。

诊断按标签分组并默认收起。展开后可查看每条消息和建议，严重级别计数始终可见。

插件会话内的日志跨任务阶段和预览重开持续累积。使用“清空日志”重置；重新加载插件不会保留此前日志。

## 1.9.12 — 更清爽的诊断预览

没有错误时，整个诊断区域默认收起，仅显示标题和严重级别计数；有错误时默认展开。展开区域及其中的标签分组，即可查看每条消息和建议，不删除任何诊断记录。 仅错误分组自动展开，警告和信息分组仍收起；同一标签下的不同级别也分开展示。
