# 快速开始

<TLDR>
先准备一篇可丢弃的 Markdown 笔记和一个已能访问的 provider。处理文件夹前，先核对生成文件。云端调用会把任务内容发送给 provider；本地推理也需要已经运行的服务和下载完成的模型。
</TLDR>

## 第一步：配置首个 LLM Provider

1. [安装并启用 Notemd](./installation)，打开**设置 → Notemd**。
2. 选择 provider，按需填写端点和凭据，选择账户可用的模型。支持模型发现时可点击 **Get Model List（获取模型列表）**；模型出现在列表中，不等于聊天生成已通过验证。
3. 运行 **Test Connection（测试连接）**，先解决认证、模型或端点错误。
4. 搜索 **Concept note folder（概念笔记文件夹）**。如需生成概念文件，请选择专用文件夹，例如 `concepts`。初始值为空，`concepts/` 只是可选示例，并非预设输出目录。

Ollama 需先拉取模型并填写准确的本地名称，预设端点为 `http://localhost:11434/api`。LM Studio 需先启动本地服务器，选择 `LMStudio` 预设。参见[本地模型](../providers/local)。即使摘要模型在本地，网络研究仍需联网。

## 第二步：尝试首个任务

创建 `Notemd trial.md`，写入可安全发送给所选 provider 的短文：

```text
机器学习模型使用神经网络，从示例中学习规律。
```

在 Notemd 侧边栏或命令面板执行 **Process file (add links)（处理文件：添加链接）**。默认在源目录生成独立的 `Notemd trial_processed.md`，并保留原文件。打开输出核对实际链接；模型结果可能不同，例如：

```markdown
[[机器学习]]模型使用[[神经网络]]，从示例中学习规律。
```

配置的概念文件夹也可能收到概念笔记。需要审核文件与链接，不能把处理成功视为模型已完整识别所有重要概念。

## 第三步：探索功能

### 提取概念笔记

执行 **Extract concepts (current file)（提取当前文件概念）**，可在不改写源笔记的情况下提取概念，前提是已配置概念文件夹。独立提取默认创建仅含标题的笔记，不添加来源反向链接；需要时显式开启。[概念笔记](../features/concept-notes)说明其与添加链接流程的差异。

### 研究与摘要

在已打开的 Markdown 编辑器中选择主题文本，或使用笔记标题，运行 **Research & summarize（研究并总结）**。在设置中明确选择带 API key 的 Tavily，或 DuckDuckGo。摘要追加到当前笔记；引用结论前先打开并核对来源。

### 一键工作流

默认 **One-Click Extract** 按钮使用以下精确定义：

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

依次添加链接，为概念文件夹或所选文件夹内符合条件的笔记生成正文，再修复生成后 complete 文件夹中的 Mermaid 块。因此它也可能处理已有概念笔记。首次运行应使用专用测试文件夹；该定义不会自动添加网络研究或图表生成步骤。

## 取消与输出核对

在进度界面选择**取消**以停止后续工作。已完成输出会保留；取消不是撤销事务，也不保证 provider 停止生成或计费。等待任务收敛后再开始下一轮，并检查报告中的输出路径和恢复冲突，不要假定取消意味着没有产物。

## 故障排查

- 认证或模型错误：核对准确的 provider profile，并重跑连接测试。
- 未生成概念文件：确认概念文件夹已配置且启用。
- 链接无用：核对响应与自定义提示词；不存在保证提取有效的最小字数。
- 限流：排查账户配额时，保持默认批量并发数 `1`。
