# 配置

<TLDR>
打开**设置 → Notemd**，通过设置搜索定位字段。处理笔记前，配置 provider 与输出位置。先用一篇笔记验证设置变更，再应用于文件夹；已运行的任务可能继续使用启动时捕获的配置。
</TLDR>

## 设置概览

默认活动 provider 是 DeepSeek，账户凭据初始为空。选择预设不会创建账户、安装模型或授予托管模型访问权限。[Provider 设置](../providers/overview)解释协议与模型发现。

## 设置发现与收藏

- **搜索设置**匹配名称、说明、别名和可见分类，并跳转到相应字段。
- **★ 收藏**展示已收藏设置的说明、分类和跳转入口；收藏保存在当前 Vault，重启后保留，失效 ID 会被清理。
- 使用箭头折叠发现工具栏可节省垂直空间；重新打开会恢复当前查询。
- 收藏列表与“仅搜索收藏”是两个独立控件。

**图表预览导出 PPI** 默认为 **300 PPI**，范围 **72–600**，仅影响 PNG 光栅化；所选格式支持时，SVG/PDF 保留矢量几何。**同时导出完整 Mermaid 可视化**控制配套文件，不决定 Drawnix 预览是否显示 Mermaid。

一次勾选多种图表，每种类型独立选择多种输出格式。取消勾选仍保留该类型的格式偏好；全部取消则自动分析原文。

图形中间文件目录可设置为统一的 Vault 相对路径；留空则使用各原文旁的 `notemd_assert/`。恢复记录、渲染缓存及可选附件存放于此。保留仍被已有产物引用的文件；目录变更仅影响新任务。

## 1. Provider 配置

选择 provider，按需填写凭据，保留符合协议的预设端点，选择可用模型。支持时先获取模型列表，再测试连接；列出模型与成功生成响应是两项不同检查。

本地 provider 需要运行中的服务和已经下载或加载的模型。云端 provider 或网关会收到发送给它的任务内容。处理私密材料时，除活动 provider 外，还要检查各任务的独立 provider。

## 2. 任务专用模型

开启 `useMultiModelSettings` 后，可为链接、标题生成、研究、翻译、概念提取、原文提取和 Mermaid 摘要选择独立的 provider/model。任务模型覆盖值为空时，使用所选 provider 配置的模型；未启用时使用活动 provider。

比较模型时使用代表性笔记，记录输出准确性、延迟与实际账户价格。本指南不提供模型排名，也不保证模型持续可用。

## 3. 输出配置

| 任务 | 默认输出行为 |
|---|---|
| 添加链接 | 源目录中的独立 `_processed.md` 文件；默认不移动原文件 |
| 独立概念提取 | 需选择概念文件夹；默认仅标题，无反向链接 |
| 翻译 | 源目录中的独立 `_<language>.md` 文件；已有目标可能被覆盖 |
| 研究 | 将研究摘要追加到活动 Markdown 笔记 |
| 批量标题生成 | 写入正文，在目标允许时把符合条件的笔记移至报告中的同级 `<folder>_complete` 文件夹 |
| 图表预览／导出 | 所选文件自动导出到原笔记所在目录，或直接保存到配置的输出目录。名称包含图表类型，如 `topic_drawnix.pdf`、`topic_flowchart.svg`；重名追加 `-2`、`-3` 等序号，不覆盖已有文件。 |
概念文件夹初始为空。`concepts` 是可自行选择的名称，不是默认路径。独立概念笔记只支持最小／完整模板，不存在通用笔记模板变量引擎，详见[概念笔记](../features/concept-notes)。

链接处理后缀、处理后文件夹、翻译后缀和翻译保存路径是不同设置。重跑写入操作前检查目标是否已存在。恢复和冲突提示会指出需关注的输出；取消不会回滚已完成写入。

## 4. 语言设置

插件有 **21 个 UI locale**，网站有 **34 个语言路由**。`uiLocale: auto` 遵循可用 UI 语言映射，不支持的 UI 语言回退到英文。

生成内容语言独立于界面，默认是英文。可为链接、标题生成、研究、概念提取或 Mermaid 摘要启用任务专用输出语言。翻译使用所选输出语言 `language`，同样独立于 UI。模型语言能力与 UI／网站语言数量不是同一指标。

## 5. 搜索集成

选择 **Tavily** 并提供 API key，或明确选择 **DuckDuckGo**。Tavily 密钥为空不会自动切换到 DuckDuckGo。两者都联网，DuckDuckGo 还可能抓取结果页面。

标题生成默认不研究；需要额外研究步骤时才开启 `enableResearchInGenerateContent`。可选本地知识检索默认也关闭，具有独立文件夹和任务范围。索引虽在本地，作为上下文使用的笔记片段仍会发送给任务 LLM。

## 6. 工作流配置

使用构建器，或每行填写一个有名称的 DSL 定义。默认值为：

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` 分隔按钮名称和动作列表，`>` 分隔动作 ID。默认错误策略是在步骤报告失败后停止。[工作流](../features/workflows)列出有效 ID、文件夹上下文和忽略错误继续执行的后果。

## 7. 高级设置

| 设置 | 默认值 | 作用 |
|---|---|---|
| `activeProvider` | `DeepSeek` | 无任务专用路由时使用的 provider |
| `useMultiModelSettings` | `false` | 启用任务独立 provider/model |
| `useCustomConceptNoteFolder` | `true` | 选择文件夹后允许生成概念文件 |
| `conceptNoteFolder` | `''` | 初始未选择概念文件夹 |
| `extractConceptsMinimalTemplate` | `true` | 独立提取生成仅标题笔记 |
| `extractConceptsAddBacklink` | `false` | 显式开启后添加独立提取反向链接 |
| `moveOriginalFileOnProcess` | `false` | 添加链接时保留源文件 |
| `chunkWordCount` | `3000` | 近似文本块大小，不是 provider token 上限 |
| `batchConcurrency` | `1` | 默认批量并发数 |
| `enableBatchParallelism` | `false` | 对使用此开关的批量流程启用并行 |
| `enableStableApiCall` | `false` | 显式稳定请求模式 |
| `customWorkflowErrorStrategy` | `stop_on_error` | 报告错误后停止工作流 |

分块与输出 token 预算是不同控制项。较小的块不保证满足 provider 上下文限制；降低并发可减轻配额压力，但不能消除所有 429。

## 配置备份与 Profile

设置属于 Vault 插件数据，变更可用配置前先备份。Provider profile 导出有独立脱敏契约，不是完整 Vault 备份。即使已脱敏，分享前也要核对端点 URL 与其他元数据。不要公开原始插件设置或含私密笔记的诊断响应。

## 配置故障排查

针对实际 provider/model 运行连接测试，再重试一篇短笔记。设置似乎缺失时，按名称搜索，检查当前分类、开发者模式可见性，并确认打开了正确 Vault。报告问题时附插件版本和脱敏配置。
