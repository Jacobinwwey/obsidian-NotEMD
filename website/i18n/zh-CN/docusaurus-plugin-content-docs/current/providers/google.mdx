# Google Provider

<TLDR>
Google 预设使用原生 Gemini Generative Language API。配置对该端点有效的 API key，选择当前可用模型。通过 OpenAI-compatible 聊天提供 Gemini 的网关应使用网关预设。
</TLDR>

## 设置

选择 **Google**，填写密钥，保留原生 Generative Language 端点，选择该 API version 提供的模型。测试连接后翻译或处理可丢弃笔记。预设不会自动配置任意 Google Cloud 或 Vertex 部署。

## 端点与认证

| 字段 | 预设值 |
| ------- | -------------- |
| 传输协议 | `google` |
| API key | 必填 |
| 基础 URL | `https://generativelanguage.googleapis.com/v1` |
| 默认模型 | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| 连接测试 | `chat-only` |

运行时构建采用 API key 认证的模型 `generateContent` 请求。历史默认 ID 不是当前可用性保证；分享诊断前检查 URL，因为请求细节可能含认证信息。

## 模型发现

可用时使用原生 Google 模型发现，确认所选模型支持配置 API version 下的生成。空列表可能来自权限、端点或模型可用性问题；验证实际配置，避免随意切换协议。

## 故障排查

- `400`：检查模型 ID、参数及 token／输出限制。
- `401`／`403`：检查密钥限制、API 启用状态和模型授权。
- `404`：确认该 API version 是否提供模型。
- 网关示例失败：使用对应 OpenAI-compatible 网关预设。

## 适用场景

适用于原生 Gemini API。用代表性样本评估翻译、研究或图表任务，不承诺模型的相对速度、费用或翻译质量。
