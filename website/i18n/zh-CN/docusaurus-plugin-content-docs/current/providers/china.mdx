# 中国地区 Provider

<TLDR>
使用与账户和部署匹配的预设。即使共享 OpenAI-compatible 协议，地区端点、模型名和权限也不可互换。选择任务 provider 前先验证小样本。
</TLDR>

## 设置

在所选 provider 创建 API 账户、获取密钥并选择对应预设。确认账户端点区域与模型权限，测试连接并运行可丢弃笔记。预设默认值不保证当前模型可用。

## 模型发现

Provider 允许时使用模型发现。Huawei Cloud MaaS 使用部署感知发现，其他列出预设在支持时使用 OpenAI-compatible 路径。缺少列表权限不必然表示显式配置的模型无法生成。

连接测试也随预设不同：DeepSeek 可仅凭模型列表响应成功，部分地区预设会执行短聊天请求。仍需实际任务验证提示词与输出要求。

## 故障排查

- 密钥接受但拒绝生成：检查模型授权、部署和账户区域。
- Ark 模型拒绝：确认端点要求 deployment ID 还是 model ID。
- 推理响应截断：检查输出上限与 provider 专用 thinking 设置。
- 网络错误：从运行 Obsidian 的设备测试已配置端点，并检查传输错误。

## 适用场景

根据可访问端点、数据处理要求和实测任务输出选择。地区与模型品牌不是质量、隐私或费用保证。[Provider 概览](./overview)还列出可能更匹配部署的网关与本地服务。
