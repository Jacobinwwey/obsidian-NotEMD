# Notemd 1.9.12 — 更清爽的診斷預覽

<TLDR>
沒有錯誤時，整個診斷區域預設收合，僅顯示標題與嚴重程度計數；有錯誤時預設展開。展開區域及其中的標籤分組，即可查看每則訊息和建議，不刪除任何診斷記錄。 僅錯誤分組自動展開，警告和資訊分組仍收合；同一標籤下的不同級別也分開顯示。
</TLDR>

安裝 1.9.12 同一版本的 main.js、manifest.json 和 styles.css 後重新載入。保留現有設定與檔案。
