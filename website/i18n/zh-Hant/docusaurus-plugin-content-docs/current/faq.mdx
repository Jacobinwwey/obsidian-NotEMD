# 常見問題

<TLDR>

## 問題

### 如何安裝 Notemd？

開啟設定 → 社群外掛 → 瀏覽，搜尋 Notemd 並安裝、啟用。手動安裝使用同一 GitHub Release 的 main.js、manifest.json 和 styles.css。manifest 宣告最低 Obsidian 0.15.0，但該舊版本與實體行動裝置尚未經當前發布證據驗證。

### 支援哪些 LLM Provider？

登錄表有 36 個預設，涵蓋 OpenAI-compatible、Anthropic、Google、Azure OpenAI 和 Ollama 五類協定。雲端 API、閘道與本地服務各需端點、憑證和模型。預設或模型清單不保證當前上游可用性及生成權限。

### 可以使用本地 LLM 嗎？

可以設定執行中的 Ollama、LM Studio、OVMS 或相容自架端點。先下載／載入模型並測試目標任務。本地推理不使網路研究、依賴安裝或另行路由到雲端的任務離線。

### 與 ChatGPT 有何不同？

Notemd 著重明確的 Obsidian 檔案操作：添加連結、建立概念、附加研究、翻譯檔案與生成產物。這些 Vault 流程適合時可選用。評估其他工具應看當前持久化、匯出及整合能力；對話工具也能保留歷史和產生檔案。

### 如何與 Copilot 或 Smart Connections 比較？

依實際任務以及各專案目前版本、設定和文件比較。Notemd 提供筆記轉換及有界詞法本地檢索，不提供通用 chat-with-vault 介面或 embedding 語意搜尋。本站不宣稱其他專案當前功能排名。

### 研究支援哪些搜尋服務？

選擇 Tavily 並填 API key，或明確選 DuckDuckGo。Tavily 金鑰空白不自動切換。兩者都連網，所選 LLM 總結可用網路及選用本地上下文，附加至活動 Markdown 筆記。核對來源 URL 和重要結論。

### 是否支援中文和其他語言？

外掛 UI 有 21 個 locale，網站有 34 個語言路由。生成內容語言獨立設定，支援時可用任務專用覆寫。翻譯能力和品質取決於模型，不取決於 UI 或網站語言數量。

### 可以閱讀論文或 PDF 嗎？

先用合適外部工具轉為可讀 Markdown，檢查公式、表格及圖像轉換錯誤，再用 Notemd 連結概念、擷取原文、研究、翻譯或生成圖表。標準筆記流程不承諾原生 PDF OCR 或忠實擷取任意二進位文件。

### 可以產生哪些圖表？

可執行目錄有 33 項相容源格式與預覽路徑。Mermaid、JSON Canvas、Vega-Lite、可編輯 HTML/SVG、Draw.io、Drawnix 與受限 CircuitikZ 各有用途。使用選擇器支援的項目並在目標工具核驗；預覽不證明原生編輯或編譯保真度。

### 免費且開源嗎？

Notemd 採 MIT 授權。Provider 帳號、模型推理、搜尋服務與選用外部工具各有費用及條款。儲存庫公開並歡迎貢獻；開源授權不表示每個外部服務免費。

### 可以完全離線嗎？

本地伺服器、模型和必要依賴安裝後，部分筆記任務可本地推理。網路研究仍需連線，包括 DuckDuckGo。斷網前檢查任務 provider 和匯出依賴，沒有所有功能皆離線的保證。

### 資料會傳送到雲端嗎？

提示詞與內容會送至設定的 LLM 端點，搜尋服務接收查詢，網頁抓取會接觸目標網站。本地檢索可把 Vault 片段加入雲端提示詞，本地預設也可設遠端地址。檢查路由，分享前清理日誌；本地儲存不代表資料只在裝置內。

### One-Click Extract 實際執行什麼？

預設為活動筆記添加連結，對概念或所選目錄內合格筆記生成正文，再修復 complete 目錄 Mermaid。可能處理既有概念檔，不自動加入網路研究或圖表生成。精確 name::action>action 語法見工作流程指南。

### 取消會回復修改嗎？

不會。取消在支援處停止後續工作並保留完成輸出。已接受的請求／寫入仍可完成，計費由遠端控制。等待任務收斂，檢查輸出路徑和復原衝突，再重試必要部分。

### Agent 可以自動化 Notemd 嗎？

四個受限公開匯出命令透過可用 Obsidian 宿主和 Vault 提供去識別化 provider profile、能力清單、呼叫契約和公開 CLI 能力面，會寫入檔案。維護者操作是另一契約，內部操作數不是公開自動化 API。從 Agent 指南開始。

### 開發者和貢獻者從哪裡開始？

開發者指南涵蓋儲存庫準備、建置及完整測試、模組歸屬和擴充規範。AGENTS.md 是執行依據。回報附精確版本和去識別化證據，提出整合前驗證變更。
