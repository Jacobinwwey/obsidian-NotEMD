# Google 提供方

<TLDR>
Google 預設使用原生 Gemini Generative Language API。填入獲授權的 API key，選當前可用模型。透過 OpenAI-compatible 聊天提供 Gemini 的閘道應選閘道預設。
</TLDR>

## 設定

選 **Google**，填金鑰並保留原生端點，選該 API version 提供的模型。測試連線後翻譯或處理可捨棄筆記。此預設不會自動配置任意 Google Cloud／Vertex 部署。

## 端點與認證

| 欄位 | 預設值 |
| ------- | -------------- |
| 傳輸協定 | `google` |
| API key | 必填 |
| 基礎 URL | `https://generativelanguage.googleapis.com/v1` |
| 預設模型 | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| 連線測試 | `chat-only` |

執行時以 API key 認證建立模型 `generateContent` 請求。歷史模型 ID 不保證當前可用；分享診斷前審核 URL，請求細節可能包含認證資訊。

## 模型探索

可用時使用原生 Google 模型探索，確認所選模型支援該 API version 的生成。空清單可能涉及權限、端點或模型可用性；核對實際設定，不隨意切換協定。

## 疑難排解

- `400`：核對模型 ID、參數及 token／輸出上限。
- `401`／`403`：核對金鑰限制、API 是否啟用和模型權限。
- `404`：確認模型是否存在於該 API version。
- 閘道範例失敗：使用對應 OpenAI-compatible 閘道預設。

## 適用情境

適用原生 Gemini API，以代表性樣本評估翻譯、研究或圖表。本文不保證相對速度、費用或翻譯品質。
