# OpenAI 提供方

<TLDR>
OpenAI 預設使用共享 OpenAI-compatible Chat Completions 執行路徑。設定 API key 與支援該協定的模型。預設模型只是起點，不保證目前帳號可用或適合所有任務。
</TLDR>

## 設定

選 **OpenAI**，填寫金鑰，官方端點保持 `https://api.openai.com/v1`。選擇帳號可用且接受 chat completions 的模型；只提供其他 API 的模型不會因出現在清單中而相容。

閘道使用對應預設，以取得正確端點及標頭。Azure 部署選 **Azure OpenAI**，另設 deployment 與 API version。

## 端點與認證

| 欄位 | 預設值 |
| ------- | -------------- |
| 傳輸協定 | `openai-compatible` |
| API key | 必填 |
| 基礎 URL | `https://api.openai.com/v1` |
| 預設模型 | `gpt-4o` |
| Temperature | `0.5` |
| 連線測試 | `models-then-chat` |

執行時先正規化已知 URL 形式，再建立清單或聊天路由。調試從預設 URL 開始，檢查解析後路由，勿猜測疊加路徑。

## 模型探索

**取得模型** 查詢設定端點。**測試連線** 可能只驗證模型清單，未實際聊天。隨後用精確 provider/model 處理可捨棄筆記。

Reasoning、thinking、取樣與輸出 token 控制依預設及模型規則；列出模型不保證所有參數組合可接受。

## 疑難排解

- `401`／`403`：核對金鑰、專案權限、模型授權與帳號。
- `404`：核對端點、模型 ID 及 API 支援。
- 清單成功、任務失敗：檢查實際聊天錯誤與參數。
- 長輸出失敗／截斷：核對輸出預算、源文大小與回應；短測試不能覆蓋全部長請求問題。

## 適用情境

直接使用接受實作 Chat Completions 協定的 OpenAI 模型時採此預設。先測代表性筆記；上游定價與可用性可獨立於外掛版本改變。
