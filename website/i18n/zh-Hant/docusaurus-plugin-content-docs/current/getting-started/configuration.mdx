# 設定

<TLDR>
開啟**設定 → Notemd**，用設定搜尋定位欄位。處理前先配置 provider 與輸出位置。先以單篇筆記驗證，再套用至資料夾；執行中的操作可能保留啟動時擷取的設定。
</TLDR>

## 設定概覽

預設啟用 DeepSeek，帳號憑證初始為空。選擇預設不會建立帳號、安裝模型或授予雲端模型權限。協定與模型探索見[Provider 設定](../providers/overview)。

## 設定探索與收藏

- **搜尋設定**比對名稱、說明、別名與可見分類，並跳至欄位。
- **★ 收藏**列出收藏設定的說明、分類與入口，儲存在當前 Vault，重新啟動仍保留；失效 ID 會清除。
- 箭頭可收合探索工具列以節省空間，再開啟會恢復查詢。
- 收藏清單與「僅搜尋收藏」是不同控制項。

圖表預覽匯出預設 **300 PPI**，範圍 **72–600**，只影響 PNG 點陣化。所選匯出支援時，SVG／PDF 保留向量幾何。**同時匯出完整 Mermaid 視覺內容**控制配套檔案，不控制 Drawnix 中的 Mermaid 可見性。

一次勾選多種圖表，每種類型獨立選擇多種輸出格式。取消勾選仍保留該類型的格式偏好；全部取消則自動分析原文。

圖形中間檔案目錄可設為統一的 Vault 相對路徑；留空則使用各原文旁的 `notemd_assert/`。復原記錄、渲染快取及選用附件存放於此。保留仍被既有產物引用的檔案；目錄變更僅影響新工作。

## 1. Provider 設定

選擇 provider、填寫必要憑證，保留符合協定的端點並選擇可用模型。支援時取得模型清單，再測試連線。列出模型與成功生成回應是不同驗證。

本地 provider 需執行中的伺服器和已下載／載入模型；雲端或閘道會收到任務內容。處理私密材料時，活動 provider 和各任務的獨立 provider 都要檢查。

## 2. 任務專用模型

啟用 `useMultiModelSettings` 可為連結、標題生成、研究、翻譯、概念擷取、原文擷取及 Mermaid 摘要設定獨立 provider/model。模型覆寫值為空時使用該 provider 的模型；未啟用時使用活動 provider。

以代表性筆記比較準確性、延遲和實際帳號費用，本文不提供模型排名或持續可用性保證。

## 3. 輸出設定

| 任務 | 預設輸出 |
| ------ | ------------------------- |
| 添加連結 | 原檔旁的獨立 `_processed.md`；不移動原文 |
| 獨立概念擷取 | 需指定概念資料夾，僅標題且無反向連結 |
| 翻譯 | 原檔旁獨立 `_<language>.md`；既有目標可能覆寫 |
| 研究 | 將研究摘要附加至活動 Markdown 筆記 |
| 批次標題生成 | 寫入正文，目標允許時移至報告中的同層 `<folder>_complete` |
| 圖表預覽／匯出 | 所選檔案自動匯出至原筆記所在目錄，或直接儲存至設定的輸出目錄。名稱包含圖表類型，例如 `topic_drawnix.pdf`、`topic_flowchart.svg`；重名追加 `-2`、`-3` 等序號，不覆寫現有檔案。 |
概念資料夾初始為空，`concepts` 是自選名稱。獨立概念模板僅有最小／完整形式，沒有通用筆記模板變數引擎，見[概念筆記](../features/concept-notes)。

連結後綴、處理後目錄、翻譯後綴和翻譯儲存位置分別設定。重跑前檢查既有目標。復原與衝突提示會指出需關注的產物；取消不回復已完成寫入。

## 4. 語言設定

外掛有 **21 個 UI locale**，網站有 **34 個語言路由**。`uiLocale: auto` 使用可用的 UI 語言對應，不支援時回退英文。

生成語言獨立設定且預設英文。連結、標題生成、研究、概念擷取與 Mermaid 摘要可啟用專用輸出語言。翻譯使用所選 `language`，與 UI 無關；模型語言能力也不等於 UI／網站語言數。

## 5. 搜尋整合

明確選擇有 API key 的 **Tavily** 或 **DuckDuckGo**。Tavily 金鑰空白不自動切換 DuckDuckGo。兩者都連網，DuckDuckGo 還可能擷取結果網頁。

標題生成預設不研究，需要時啟用 `enableResearchInGenerateContent`。本地知識檢索預設也關閉，範圍和任務分別設定。索引在本地，但用作上下文的片段仍會傳送至任務 LLM。

## 6. 工作流程設定

使用建構器或每行一個有名稱的 DSL 定義，預設：

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` 分隔名稱與動作清單，`>` 分隔 ID。預設在步驟回報失敗時停止。有效 ID、資料夾上下文及忽略錯誤的後果見[工作流程](../features/workflows)。

## 7. 進階設定

| 設定 | 預設 | 作用 |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | 無任務專用路由時使用的 provider |
| `useMultiModelSettings` | `false` | 啟用任務 provider/model |
| `useCustomConceptNoteFolder` | `true` | 指定目錄後允許概念檔案 |
| `conceptNoteFolder` | `''` | 初始未選擇概念資料夾 |
| `extractConceptsMinimalTemplate` | `true` | 獨立擷取產生僅標題筆記 |
| `extractConceptsAddBacklink` | `false` | 明確啟用後添加來源連結 |
| `moveOriginalFileOnProcess` | `false` | 添加連結時保留源檔 |
| `chunkWordCount` | `3000` | 近似文字區塊大小，不是 provider token 上限 |
| `batchConcurrency` | `1` | 預設批次並行數 |
| `enableBatchParallelism` | `false` | 在採用此開關的批次路徑啟用平行 |
| `enableStableApiCall` | `false` | 明確穩定請求模式 |
| `customWorkflowErrorStrategy` | `stop_on_error` | 報告錯誤後停止流程 |

分塊與輸出 token 預算不同。較小區塊不保證符合上下文限制；低並行數可降低壓力，但不能杜絕 429。

## 設定備份與 Profile

設定屬於 Vault 外掛資料，改動可用配置前先備份。Provider profile 匯出有獨立去識別化契約，不是完整 Vault 備份。分享前仍須核對端點與元資料，不公開原始設定或含私密筆記的診斷。

## 設定疑難排解

用實際 provider/model 測試，再重跑短筆記。欄位似乎遺失時，按名稱搜尋、檢查分類與開發者模式可見性，並確認 Vault。附版本和去識別化設定回報可重現問題。
