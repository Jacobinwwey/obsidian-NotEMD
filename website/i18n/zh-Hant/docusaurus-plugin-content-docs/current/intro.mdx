# Notemd 簡介

<TLDR>
Notemd 是採 MIT 授權的 Obsidian 外掛，將筆記轉為可檢查並保留的 wiki 連結 Markdown、概念筆記、研究摘要、譯文與圖表。你選擇 provider、任務與輸出範圍；模型結果加入知識庫前仍需審核。
</TLDR>

## Notemd 是什麼？

Notemd 以 36 個 provider 預設連接 Vault 工作流程，涵蓋雲端 API、閘道與本地伺服器。任務依自身契約寫入檔案或更新筆記，可單獨執行或組合為側欄流程。

產物儲存在 Vault，但雲端 provider 會收到任務內容，網路研究也會發出請求。本地儲存與本地推理是不同選擇。

## 核心能力

### Wiki 連結與概念筆記

讓模型識別概念並添加連結，預設產生獨立處理後筆記。指定概念目錄後可建立概念檔；獨立擷取預設僅標題、無來源連結。差異見[連結](./features/wiki-links)與[概念筆記](./features/concept-notes)。

### 研究與本地上下文

選 Tavily 或 DuckDuckGo 搜尋，將模型摘要附加至活動筆記。可選限定範圍本地檢索能提供片段，當前索引為詞法，不是 embedding 語意搜尋。[研究](./features/research)說明來源與網路邊界。

### 翻譯與原文擷取

依輸出語言翻譯檔案或資料夾，或按問題擷取源文段落並核對。選取文字不會使檔案翻譯限於選取範圍。[翻譯](./features/translation)說明命名與覆寫。

### 圖表與匯出

一次勾選多種圖表，每種類型獨立選擇多種輸出格式。取消勾選仍保留該類型的格式偏好；全部取消則自動分析原文。 [圖表使用手冊: Draw.io, Drawnix, Mermaid, CircuitikZ](./features/diagrams).

### 工作流程

預設 **One-Click Extract** 添加連結、為概念或所選資料夾的合格筆記生成正文，再修復 complete 目錄的 Mermaid，可能包含既有概念筆記。自訂流程保留各動作先決條件與輸出，DSL 見[工作流程](./features/workflows)。

## 開始使用

1. 在目標 Vault [安裝](./getting-started/installation)。
2. 配置可用 provider/model，測試可捨棄筆記。
3. 指定概念目錄與輸出位置。
4. 審核後再擴大批次。

不保證完成時間或有用輸出的最小筆記長度；先用能完整核對的小樣本。

## 圖表能力方向

管線以型別化規格和目標專用渲染處理受支援目錄。`DiagramSpec` 描述開發契約，不保證任意語法或所有參考版面。

電路限制於支援的 `circuitikz` 結構。TikZJax 是外部工具，外掛預覽不證明原生編譯。Drawnix 靜態關係不保證重排後跨分支箭頭附著；挑選後續編輯格式時須保留限制。

## 架構

任務路由至所選 provider，校驗或解析輸出，再寫入筆記／產物。搜尋與本地檢索提供可選上下文，預覽與匯出有格式專用限制。

模組歸屬與驗證見[開發者指南](./developers/overview)。受限公開匯出見 [Agent 指南](./agents/overview)，內部 operation 登錄表不是通用公開自動化 API。

## 工具比較 {#notemd-vs-other-obsidian-ai-plugins}

依檔案轉換、對話、確定性連結、檢索或原生編輯需求選擇。查看各專案當前文件，使用相同代表性任務，記錄版本和啟用功能再比較。

## 資料與相容性邊界

雲端 provider 收到任務輸入，搜尋服務收到查詢，啟用本地上下文時片段也進入提示詞。判斷本地化前檢查各任務路由。取消在支援處停止後續工作並保留已完成輸出，不保證遠端生成／計費停止。

manifest 最低版本為 `0.15.0` 且允許行動端載入，但實體行動裝置與最低版本尚未驗證。選用原生匯出可能需要桌面工具。網站 34 個語言路由、外掛 UI 21 個 locale 與模型翻譯能力是不同維度。
