# 概念筆記

<TLDR>
獨立概念擷取讀取源筆記，在指定資料夾建立 Markdown 概念檔。目錄設定初始空白，新筆記預設只含標題且無來源反向連結。添加連結流程採不同模板。
</TLDR>

## 概覽

執行前設定 **概念筆記資料夾路徑**。專用資料夾方便核對產物、重複項與後續標題生成範圍。擷取只建立概念檔，不自動填入有研究依據的說明。

## 工作原理

### 擷取管線

內容傳給所選 LLM，解析 `CONCEPT:` 條目，在操作內去重並建立／更新檔案。長筆記分塊處理，檢查失敗區塊與不完整輸出；模型回應不等於完整概念清單。

### 擷取提示詞

內置提示詞要求具體且相關的概念；聚焦學習及同義詞抑制不保證標準詞彙。自訂擷取需保留 `CONCEPT: Term` 格式，見[提示詞指南](../advanced/custom-prompts)。

### 分塊

`chunkWordCount` 預設 `3000`，是按詞近似切分，不是 provider token 預算。跨塊上下文有限，完成後檢查關聯概念和歧義名稱。

## 建立概念筆記

### 檔名規則

清除不支援的路徑字元、正規化空白並截短過長名稱，略過空結果。因此不同片語可能對應同一檔名，大規模生成前核對。

### 模板

獨立新筆記預設使用最小模板：

```markdown
# Concept Name
```

新筆記需反向連結時啟用 **加入「Linked From」回鏈**，並關閉 **建立最小化概念筆記**。完整形式：

```markdown
# Concept Name

## Linked From
- [[Source Note]]
```

添加連結在概念輸出啟用時產生完整形式與來源連結，獨立擷取的開關不會改變該行為。

### 更新既有筆記

啟用反向連結後，可在既有 `## Linked From` 補入缺少來源。保留正文且不重複追加相同連結。來源使用 basename，同名源筆記需檢查歧義。

### 設定

| 設定 | 預設 | 作用 |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | 指定目錄後啟用概念檔輸出 |
| `conceptNoteFolder` | `''` | 初始未指定目錄 |
| `extractConceptsMinimalTemplate` | `true` | 獨立擷取建立僅標題筆記 |
| `extractConceptsAddBacklink` | `false` | 啟用獨立擷取反向連結 |
| `extractConceptsProvider` | `DeepSeek` | 專用路由啟用時的 provider |
| `extractConceptsModel` | `''` | 空白時使用所選 provider 模型 |
| `extractConceptsLanguage` | `en` | 專用輸出語言啟用時的語言 |
| `replaceSynonymsDuringConceptExtraction` | `false` | 加入同義詞抑制指令 |
| `generateConceptLogFile` | `false` | 選擇產生概念日誌 |

## 重複項審核

檢查使用檔名啟發式，包括忽略大小寫、複數形式、符號正規化和範圍允許的單詞包含關係。它們不是語意等價證明，不規則複數和不同技術含義仍需審核。

選 **檢查並移除重複項**，核對候選並只批准要移除的檔案。批准項透過 Obsidian 垃圾桶操作處理。概念資料夾不是快取，批次清理前備份。

### 範圍模式

可與整個 Vault、概念目錄、指定包含目錄或排除特定目錄後的範圍比較。移除前核對選項；範圍影響候選集合，不改變重複的含義。

## 使用方式

### 獨立擷取概念

開啟 Markdown 筆記，確認目錄後執行 **擷取概念（目前檔案）**。源文不變，檢查檔名、概念涵蓋及選用來源連結。

### 擷取後生成正文

對概念目錄執行 **從標題批次生成**。它也可能處理既有合格筆記，不限本次擷取。事先審核目錄，事後檢查 complete 移動目標。

### 從選取文字建立連結

選取動作可將術語包成 wiki 連結，在目標已配置時建立概念筆記。適合自行選詞，不必讓模型從整篇源文判斷。

## 建議

- 從小源文和專用目錄開始。
- 大量建立前先決定輸出語言。
- 分別審核同義詞建議與重複候選。
- 下次覆寫前保留需要的日誌。
