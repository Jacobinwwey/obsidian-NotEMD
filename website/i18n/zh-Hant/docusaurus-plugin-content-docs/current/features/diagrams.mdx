# 圖表

<TLDR>
請先選擇您需要的**圖表類型**，再選擇其可編輯的**原始格式**。在 Obsidian 中預覽完整的結果，其中包含 Drawnix 模板以及內嵌的 Mermaid 可視化內容，並可將每個面板匯出為 SVG、PNG 或 PDF 格式。
</TLDR>

## 了解三種選項

| 選項 | 控制內容 | 範例 |
|---|---|---|
| 圖表類型 | 圖表的含義 | 流程圖、序列圖、電路圖、資料圖表 |
| 原始格式 | Notemd 所產生的可編輯或可重複使用的檔案 | Mermaid、JSON Canvas、Draw.io、Drawnix、CircuitikZ |
| 匯出格式 | 用於分享的影像或文件 | SVG、PNG、PDF |

Draw.io 與 Drawnix 屬於**原始格式**，而非圖表類型。CircuitikZ 是專為電路圖設計的原始格式。同一個預覽可以匯出為多種可視化格式，因此選擇 CircuitikZ 並不會限制您只能使用 SVG 格式。

## 選擇原始格式

| 格式 | 最適用場景 | 原始檔案 |
|---|---|---|
| Mermaid | 直接儲存在 Markdown 中的圖表 | Mermaid 程式碼區塊 |
| JSON Canvas | Obsidian 內建的畫布工作流程 | `.canvas` |
| Draw.io | 後續在 diagrams.net 或相容工具中進行編輯 | `.drawio` |
| Drawnix | 手繪或白板式的編輯方式 | `.drawnix` |
| CircuitikZ | 有結構的電路與電晶體圖表 | `.tex` |

如果您不需要特定的編輯器，請將**預設原始格式**設定為**自動選擇**。Notemd 會根據所選的圖表類型自行挑選相容的格式。

## 產生並匯出圖表

1. 開啟筆記或選取您想要視覺化的文字。
2. 從 Notemd 的側邊欄或指令面板選擇**產生圖表**。
3. 選擇一種**圖表類型**，或保持設定為**自動偵測**。
4. 選擇一種**原始格式**，或保持設定為**自動選擇**。若您希望獲得具有可編輯節點及內嵌 Mermaid 可視化內容的知識地圖，請選擇 **Drawnix**。
5. 檢視預覽結果。多面板結果會將 Drawnix 模板以及所有 Mermaid 面板依照原始順序呈現在單一可垂直滾動的預覽區中；Mermaid 面板會使用其實際渲染的高度，而不會被裁切。
6. 為單一圖表選擇面板的**匯出 SVG**、**匯出 PNG** 或 **匯出 PDF** 操作，或為所有面板使用頂層的影像匯出功能。對於多個面板，可選擇原始資料夾或 Vault 相對路徑下的自訂資料夾；Notemd 會為每個面板產生一個確定的檔案，即便某次操作失敗也會繼續處理剩餘的面板。
7. 若您同時需要可編輯的原始檔案，請使用**儲存原始檔案**功能。

匯出選單提供了針對目前預覽結果的**匯出 SVG**、**匯出 PNG** 與 **匯出 PDF** 操作。每個面板的標題也會提供相同的操作選項，適用於單一的 Mermaid 或 Drawnix 可視化內容，因此無需將大型預覽整體匯出為一張不透明的影像。

在預覽中選擇**歷史記錄**，即可在不隱藏圖表的情況下打開 Vault 歷史抽屜。您可以在其中搜尋與過濾已完成的圖表、重新開啟預覽，或取得已儲存的原始檔案。即使沒有活躍的筆記，也可以直接從指令面板和 Notemd 側邊欄存取圖表歷史記錄。

SVG 與 PDF 是由向量幾何圖形生成的；PDF 會使用相同的 SVG 排版與文字度量方式，而非將整個預覽轉換為點陣格式。Notemd 設定中的影像匯出 PPI 僅用於控制 PNG 的點陣化程度（72–600 PPI，預設為 300）。

## 高密度圖表的可讀預覽

可編輯的 HTML/SVG lane-grid 圖表會先測量並換行摘要，再放置標題與 lane 標頭。標頭會移到受保護的摘要區域下方，儲存格則先於連接線與邊標籤繪製。跨 lane 的邊使用具碰撞感知能力的正交網格路徑，為 lane 標籤與已佔用儲存格保留空間，因此長篇描述不會遮住文字，也不需要水平平移才能理解圖表。

Mermaid 象限圖會經過 family 專用的正規化流程。對於 `quadrantChart`，只跳過 flowchart 專用的引號與形狀修復；標題、座標軸與象限名稱中刻意使用的方括號仍會顯示。provider 複製的開括號只有在它是點標籤不匹配的最後字元時才會移除。

儲存庫為每個可執行圖表類型保留真實 Vault 的學習與證據集合。雙語輸入筆記、產生的 SVG/PNG 結果與機器可讀狀態 manifest 請參考 [`docs/diagram-examples/`](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples)。`passed` 項目代表透過已載入 plugin bundle 的實際執行，不是靜態 screenshot fixture。

## 內嵌 Mermaid 的 Drawnix 預覽

當 Drawnix 檔案包含 Mermaid 可視化內容時，Notemd 會對渲染後的 SVG 進行過濾處理，並將 Mermaid 的原始程式碼一同保存在 `.drawnix` 中的元資料中。因此，預覽可以在 Drawnix 知識地圖中顯示 Mermaid 影像，而無需依賴 Drawnix 或 Plait 的執行環境。安全內嵌的純 Mermaid 可視化內容不會產生額外的 `.assets` 資料夾；至於外部的二進位媒體或尚未解析的可視化內容，則會保留對應的輔助檔案，以避免資料遺失。

預覽刻意設計為單一可滾動的界面：首先顯示主要的 Drawnix 畫布，接著依照原始順序呈現每個內嵌的 Mermaid 面板。再次開啟已儲存的歷史記錄項目時，會重新構建相同的面板列表、尺寸以及匯出選項。

## 電路圖表

對於支援的電路相關需求，請選擇**電路圖表**並搭配**CircuitikZ 原始檔案**。Notemd 會先產生結構化的電路描述，再寫入 CircuitikZ 的原始程式碼。這種方式比要求模型直接撰寫不受限制的 LaTeX 程式碼更為可靠。

目前對 CircuitikZ 的支援是有意限制的。以通用資料庫中的 NMOS 放大器以及已支援的 CMOS 构件效果最佳。在將生成的電路用於技術文件或出版品之前，務必先檢視預覽結果與原始程式碼。

SVG 預覽是由 Notemd 產生的輔助審核工具，並不能作為本地 LaTeX 或 TikZJax 安裝已成功編譯 `.tex` 檔案的證明。

**可選的本機編譯功能。** 您不需要使用 LaTeX 即可在插件內進行預覽，或匯出 SVG、PNG 與預覽用 PDF 格式。在桌面端，若需要編譯診斷結果或生成本機版的 LaTeX PDF，可從圖表設定或指令面板開啟**CircuitikZ 本機編譯環境**。Notemd 可以重複使用系統中的 `tectonic` 或 `pdflatex`，或是使用自訂執行檔，也可以在您明確選擇**安裝**之後，安裝已鎖定的管理型 Tectonic 執行環境。環境面板會即時顯示進度與錯誤訊息，並讓您日後移除該管理型執行環境。

## 故障排除

### 結果為錯誤的圖表類型

請直接選擇圖表類型，而非依賴自動偵測功能。對於電路圖表，應選擇**電路圖表**，並使用**產生圖表**指令，而非舊版的**摘要為 Mermaid 圖表**指令。

### 某種原始格式不適用

請將該原始格式恢復為**自動選擇**，或選擇適用於該圖表類型的格式。CircuitikZ 只適用於電路圖表；Draw.io 與 Drawnix 則專門用於支援的結構化圖表。

### 缺少匯出選單

SVG、PNG 與 PDF 需要可視化的預覽結果。如果只有原始文字，請先儲存原始檔案，再在對應的外部工具中打開它。

### CircuitikZ 檔案無法在外部環境編譯

請開啟**CircuitikZ 本機編譯環境**並執行環境檢查。修復管理型執行環境，或確認您的自訂/系統編譯器能夠取得 `circuitikz` 套件。Notemd 的插件檔案中並未內建完整的 TeX 發行版。
