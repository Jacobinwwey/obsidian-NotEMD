# 圖表

<TLDR>
一次勾選多種圖表，每種類型獨立選擇多種輸出格式。取消勾選仍保留該類型的格式偏好；全部取消則自動分析原文。
</TLDR>

## 理解三個選擇

| 選擇 | 控制內容 | 範例 |
|---|---|---|
| 圖表類型 | 表達的意義 | 流程、時序、電路、資料圖 |
| 源格式 | 可編輯／重用的檔案 | Mermaid、JSON Canvas、Draw.io、Drawnix、CircuitikZ |
| 匯出格式 | 分享的圖片或文件 | SVG、PNG、PDF |

圖形 HTML 包含可縮放的圖形；結構化摘要 HTML 顯示文字、結構與引文。可編輯 HTML/SVG 是渲染器名稱，不代表網頁內編輯器；編輯請使用原生原始檔。PPTX、MP4 等簡報匯出保留獨立設定與相依元件。

## 選擇源格式

| 格式 | 用途 | 源檔 |
| --- | --- | --- |
| Mermaid | 直接放在 Markdown 的圖表 | Mermaid 程式碼區塊 |
| JSON Canvas | Obsidian 原生畫布 | `.canvas` |
| Draw.io | 稍後用 diagrams.net 等工具編輯 | `.drawio` |
| Drawnix | 手繪／白板編輯 | `.drawnix` |
| CircuitikZ | 結構化電路與電晶體電路 | `.tex` |

支援的格式優先顯示；不相容項目保留並停用，已有暫不可用請求仍可移除。格式選擇屬於各自圖表類型。全部請求不可用時，嘗試有效渲染器的預設原始檔，並回報不可用請求。

## 生成與匯出

1. 開啟支援源筆記；只需片段時放入獨立筆記。選取文字不縮小檔案生成動作。
2. 一次勾選多種圖表，每種類型獨立選擇多種輸出格式。取消勾選仍保留該類型的格式偏好；全部取消則自動分析原文。
3. 核取方塊控制是否產生該類型；按一下名稱會選取該類型並開啟其格式設定。滑鼠停留或鍵盤聚焦會切換預覽，不儲存設定。Escape 關閉選單並返回焦點。
4. 執行 **生成圖形**。
5. 所選檔案自動匯出至原筆記所在目錄，或直接儲存至設定的輸出目錄。名稱包含圖表類型，例如 `topic_drawnix.pdf`、`topic_flowchart.svg`；重名追加 `-2`、`-3` 等序號，不覆寫現有檔案。
6. 核對預覽，Drawnix 和 Mermaid 按源順序在單一垂直捲動容器，Mermaid 依實際高度顯示不裁切。
7. 以面板 **Export SVG／PNG／PDF** 輸出單一視覺，或以頂部圖片匯出全部。多面板可選源目錄或 Vault 相對目錄，確定性逐檔輸出，個別失敗後繼續。 需要編輯產物時用 **儲存原始碼檔案**。

圖形中間檔案目錄可設為統一的 Vault 相對路徑；留空則使用各原文旁的 `notemd_assert/`。復原記錄、渲染快取及選用附件存放於此。保留仍被既有產物引用的檔案；目錄變更僅影響新工作。

各類型依序產生，一種失敗不阻斷其他類型；取消會停止後續類型並保留已完成檔案。匯出失敗可從預覽或歷史重試，無須再次請求模型；產生階段失敗仍須重新產生該類型。舊版 v1/v2 復原記錄繼續可讀。

匯出選單和各面板標頭都提供 SVG、PNG、PDF，不必把整個大型預覽變為單張不透明圖片。

在預覽選 **歷史** 可開啟 Vault 歷史抽屜而不隱藏圖表，搜尋篩選完成項、重開預覽或產物。沒有活動筆記也能由命令面板／側欄開啟歷史。

SVG／PDF 使用向量幾何，PDF 共用 SVG 排版與文字度量而不整體點陣化。PPI 只影響 PNG，72–600、預設 300。

## 密集圖表的可讀性

可編輯 HTML/SVG 泳道網格先量測與換行摘要，再放置標題和泳道表頭。表頭避開保護區，儲存格先畫、線與標籤後畫。跨泳道使用避碰正交網格，保留標籤和佔用區，避免長描述遮字或強制水平拖動。

Mermaid 象限圖按家族正規化，`quadrantChart` 跳過流程圖專用引號／形狀修復。只有點標籤尾端多餘且未配對的開括號移除，標題、軸和象限名稱的有意括號保留。

[圖表範例目錄](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples)包含各可執行類型的真實 Vault 雙語輸入、SVG／PNG 與 manifest。`passed` 只指記錄的執行和 bundle，不證明後續版本重新跑過全部類型。

目錄有 33 項，外掛 UI 21 個 locale，網站 34 個路由，屬不同指標。五種精確參考語法在取得獨立排版證據前不進入選擇器。

## 內嵌 Mermaid 的 Drawnix

Notemd 清理渲染 SVG，在 `.drawnix` 元資料保留 Mermaid 源文，因此預覽不需 Drawnix／Plait 執行環境。預設自包含，不產生獨立 `.assets`。交接或外部編輯需要時，啟用 **Also export complete Mermaid visuals** 產生源文、SVG 和 manifest 配套。舊 `.assets` 仍受支援，遺失 SVG 可由元資料重建。

已解析圖片盡可能轉為有資料支援的 SVG 預覽。載入依序使用內嵌資料、舊配套檔、可用源文重建。產物仍有引用時保留配套目錄，新自包含輸出不證明共用舊目錄已無用。

預覽是單一捲動面：Drawnix 在前，Mermaid 按源順序在後。關閉重開歷史會重建相同面板、尺寸與匯出操作。

Drawnix 概覽最多保留六條附標籤的核心有向關係，每個節點最多三條；省略關係保存在原始檔中繼資料中。PDF 關係方框文字正常顯示，也相容舊 SVG 快取。跨分支箭頭仍為靜態關係，在 Drawnix 重新排列後可能脫離節點。

## 原生匯出邊界

源檔與視覺匯出是兩種產物，分享前在目標應用測試。PowerPoint 表格保留支援的原生可編輯結構，含修正的合併儲存格下分隔線；Mermaid／SVG 可能是圖片回退。外掛預覽或全頁圖像分數不能取代原生驗證。

## 電路圖

選 **Circuit diagram** 和 **CircuitikZ source file**。先生成結構化電路描述再寫 CircuitikZ，比要求任意 LaTeX 更可靠。

CircuitikZ 有意限定範圍，適合共源 NMOS 放大器與支援的 CMOS 基礎模組。技術或出版用途前核對預覽及源檔。

SVG 是 Notemd 產生的審核輔助，不證明本地 LaTeX／TikZJax 成功編譯 `.tex`。

選用原生編譯：外掛預覽及 SVG、PNG、預覽 PDF 不需 LaTeX。桌面需原生 PDF／診斷時開 **CircuitikZ native compile environment**，可使用系統 `tectonic`／`pdflatex`、自訂執行檔，或明確按 **Install** 安裝固定托管 Tectonic。面板顯示進度和錯誤，支援日後移除。

## 疑難排解

### 類型錯誤

明確選類型，電路使用 **Circuit diagram** 與 **生成圖形**，不用舊 **摘要為 Mermaid 圖表**。

### 源格式不適合

支援的格式優先顯示；不相容項目保留並停用，已有暫不可用請求仍可移除。格式選擇屬於各自圖表類型。全部請求不可用時，嘗試有效渲染器的預設原始檔，並回報不可用請求。

### 匯出選單遺失

SVG、PNG、PDF 需要視覺預覽；只有源文時儲存檔案，再用相符外部工具。

### CircuitikZ 外部編譯失敗

執行 **CircuitikZ native compile environment** 檢查，修復托管執行環境或確認系統／自訂編譯器可取得 `circuitikz`。外掛不捆綁完整 TeX 發行套件。
