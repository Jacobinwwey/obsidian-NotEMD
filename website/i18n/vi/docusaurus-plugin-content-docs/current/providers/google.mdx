# Nhà cung cấp Google

<TLDR>Hồ sơ Google dùng Gemini Generative Language API gốc. Dùng khóa có quyền với điểm cuối và mô hình hiện có. Nếu cổng cung cấp Gemini qua chat tương thích OpenAI, chọn hồ sơ cổng.</TLDR>

## Thiết lập

Chọn **Google**, điền khóa, giữ điểm cuối Generative Language gốc và chọn mô hình được phiên bản API đó cung cấp. Chạy **Kiểm tra kết nối**, rồi dịch hoặc xử lý ghi chú thử. Hồ sơ không tự cấu hình mọi triển khai Google Cloud hoặc Vertex.

## Điểm cuối và xác thực

| Trường | Giá trị đặt sẵn |
| ------- | -------------- |
| Giao vận | `google` |
| Khóa API | Bắt buộc |
| URL cơ sở | `https://generativelanguage.googleapis.com/v1` |
| Mô hình mặc định | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| Thử kết nối | `chat-only` |

Chương trình dựng yêu cầu `generateContent` gốc và xác thực bằng khóa API. ID mô hình lịch sử không bảo đảm khả dụng hiện tại. Xem URL trước khi chia sẻ chẩn đoán vì chi tiết yêu cầu có thể chứa xác thực.

## Tìm mô hình

Dùng tìm mô hình Google gốc khi có. Xác nhận mô hình hỗ trợ sinh nội dung trên phiên bản API đã cấu hình. Danh sách rỗng có thể do quyền, điểm cuối hoặc mô hình; kiểm tra cấu hình thực tế thay vì đổi giao thức ngẫu nhiên.

## Khắc phục sự cố

- `400`: xem ID, tham số và giới hạn token/đầu ra.
- `401`/`403`: kiểm tra ràng buộc khóa, API đã bật và quyền mô hình.
- `404`: kiểm tra mô hình tồn tại trên phiên bản API đã chọn.
- Ví dụ từ cổng không chạy: dùng hồ sơ cổng tương thích OpenAI tương ứng.

## Khi nên dùng

Dùng cho Gemini API gốc. Đánh giá dịch, nghiên cứu hoặc sơ đồ trên mẫu đại diện. Hướng dẫn không hứa tốc độ, chi phí hoặc chất lượng dịch tương đối của mô hình.
