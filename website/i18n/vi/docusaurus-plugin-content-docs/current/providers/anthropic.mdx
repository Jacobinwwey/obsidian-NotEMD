# Nhà cung cấp Anthropic

<TLDR>Dùng hồ sơ Anthropic cho Messages API gốc. Claude qua cổng tương thích OpenAI dùng hồ sơ cổng đó. Xác nhận quyền truy cập hiện tại trước khi chạy; giá trị mô hình lịch sử có thể cần đổi.</TLDR>

## Thiết lập

Chọn **Anthropic**, nhập khóa Anthropic và giữ điểm cuối gốc trừ khi triển khai của bạn cung cấp đúng cùng giao thức. Nhập ID Claude hiện có, chạy **Kiểm tra kết nối** rồi thử ghi chú với tác vụ dự định.

## Điểm cuối và xác thực

| Trường | Giá trị đặt sẵn |
| ------- | -------------- |
| Giao vận | `anthropic` |
| Khóa API | Bắt buộc |
| URL cơ sở | `https://api.anthropic.com` |
| Mô hình mặc định | `claude-3-5-sonnet-20240620` |
| Temperature | `0.5` |
| Thử kết nối | `chat-only` |

Chương trình dùng `/v1/messages` với header khóa và phiên bản API gốc. Không nhập tuyến chat kiểu OpenAI vào hồ sơ này. Mô hình mặc định phản ánh cài đặt kho mã, không tuyên bố dịch vụ vẫn cung cấp nó.

## Tìm mô hình

Dùng tuyến danh sách Anthropic gốc khi khả dụng. Nếu quyền liệt kê bị hạn chế, nhập ID truy cập được và thử kết nối bằng chat. Xác minh riêng tác vụ dài hoặc có cấu trúc.

## Khắc phục sự cố

- `401`/`403`: kiểm tra khóa, quyền workspace/dự án, thanh toán và mô hình.
- `404`: kiểm tra điểm cuối và mô hình hiện có.
- ID của cổng không hoạt động: dùng hồ sơ cổng cùng định danh nó yêu cầu.
- Phản hồi dài thất bại: xem giới hạn đầu ra và lỗi nhà cung cấp trước khi tăng lần thử.

## Khi nên dùng

Chọn khi điểm cuối cung cấp Anthropic Messages. So đầu ra trên nguồn của bạn, không coi lựa chọn nhà cung cấp là xếp hạng chất lượng chung. Định tuyến theo tác vụ cho phép chỉ dùng nơi đáp ứng yêu cầu.
