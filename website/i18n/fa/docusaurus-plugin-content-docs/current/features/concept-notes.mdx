# یادداشت‌های مفهوم

<TLDR>استخراج مستقل اصل را می‌خواند و فایل Markdown مفهوم را در پوشهٔ انتخابی می‌سازد. پوشه ابتدا تعیین نشده و یادداشت تازه پیش‌فرض فقط عنوان دارد؛ پیوند بازگشت خاموش است. افزودن پیوند از قالب مفهوم دیگری استفاده می‌کند.</TLDR>

## نمای کلی

ابتدا **مسیر پوشهٔ یادداشت‌های مفهومی** را تعیین کنید. پوشهٔ جدا بررسی خروجی، موارد تکراری و تولید بعدی از عنوان را آسان می‌کند. استخراج فایل می‌سازد، نه اینکه هر فایل را خودکار با توضیح پژوهش‌شده پر کند.

## روش کار

### زنجیرهٔ استخراج

متن به LLM می‌رود، خطوط `CONCEPT:` خوانده و نام‌های تکراری در همان عملیات حذف می‌شوند؛ فایل‌ها ساخته یا به‌روزرسانی می‌شوند. متن بلند تقسیم می‌شود. قطعهٔ شکست‌خورده و خروجی ناقص را ببینید؛ پاسخ مدل فهرست جامع مفاهیم نیست.

### Prompt استخراج

دستور داخلی مفهوم مشخص مرتبط با موضوع را می‌خواهد. حوزه و کاهش مترادف واژگان استاندارد را تضمین نمی‌کنند. prompt سفارشی باید `CONCEPT: Term` را حفظ کند. [Prompt سفارشی](../advanced/custom-prompts).

### قطعه‌بندی

`chunkWordCount` ابتدا 3000 است و تقسیم تقریبی بر اساس واژه است، نه بودجهٔ token ارائه‌دهنده. زمینهٔ میان قطعه‌ها محدود است؛ نام مبهم و مفهوم مرتبط را بررسی کنید.

## ایجاد فایل

### نام فایل

نویسهٔ نامجاز مسیر حذف، فاصله نرمال و نام بلند کوتاه می‌شود؛ نام خالی کنار گذاشته می‌شود. دو عبارت متفاوت می‌توانند به نام یکسان برسند. قبل از ایجاد مجموعهٔ بزرگ نام‌ها را ببینید.

### قالب‌ها

قالب کمینهٔ فایل تازه:

```markdown
# نام مفهوم
```

برای افزودن پیوند بازگشت به فایل مستقل تازه، **Add "Linked From" backlink** را روشن و **Create minimal concept notes** را خاموش کنید:

```markdown
# نام مفهوم

## Linked From
- [[یادداشت منبع]]
```

افزودن پیوند، در صورت فعال بودن خروجی مفهوم، قالب کامل با پیوند بازگشت می‌سازد. کلیدهای استخراج مستقل این رفتار را تغییر نمی‌دهند.

### یادداشت موجود

با فعال بودن پیوند بازگشت، اشارهٔ غایب می‌تواند به `## Linked From` اضافه شود؛ متن قبلی حفظ و پیوند یکسان دوباره نوشته نمی‌شود. basename منبع استفاده می‌شود، پس منابع هم‌نام را بررسی کنید.

### تنظیمات

| تنظیم | مقدار اولیه | اثر |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | اجازهٔ خروجی پس از انتخاب پوشه |
| `conceptNoteFolder` | `''` | پوشه ابتدا انتخاب نشده |
| `extractConceptsMinimalTemplate` | `true` | فایل مستقل تازه فقط با عنوان |
| `extractConceptsAddBacklink` | `false` | فعال‌سازی پیوند بازگشت مستقل |
| `extractConceptsProvider` | `DeepSeek` | ارائه‌دهنده در مسیر اختصاصی کار |
| `extractConceptsModel` | `''` | خالی یعنی مدل همان ارائه‌دهنده |
| `extractConceptsLanguage` | `en` | زبان در حالت زبان اختصاصی کار |
| `replaceSynonymsDuringConceptExtraction` | `false` | دستور کاهش مترادف |
| `generateConceptLogFile` | `false` | ساخت اختیاری گزارش مفهوم |

## موارد تکراری

بررسی از نام فایل، بی‌توجهی به بزرگی حروف، جمع، نرمال‌سازی نماد و در محدودهٔ مجاز از دربرگیری تک‌واژه استفاده می‌کند. این اثبات هم‌معنایی نیست؛ جمع نامنظم و معانی فنی متفاوت را خود بررسی کنید. در **بررسی و حذف موارد تکراری** فقط موارد مطلوب را تأیید کنید؛ حذف از عملیات سطل زبالهٔ Obsidian می‌گذرد. پوشهٔ مفهوم حافظهٔ موقت دورریختنی نیست؛ پشتیبان بگیرید.

### محدودهٔ مقایسه

می‌توان با کل خزانه، خود پوشهٔ مفهوم، پوشه‌های شامل یا محدودهٔ دارای استثنا مقایسه کرد. محدوده نامزدها را تغییر می‌دهد، نه معنای تکرار را. قبل از حذف انتخاب را بررسی کنید.

## استفاده

### استخراج مستقل

Markdown و پوشه را تأیید و **استخراج مفاهیم (فایل فعلی)** را اجرا کنید. اصل تغییر نمی‌کند. نام‌ها، پوشش و پیوندهای اختیاری را بررسی کنید.

### استخراج و تولید متن

**تولید دسته‌ای از عنوان‌ها** برای افزودن توضیح است و ممکن است یادداشت واجد شرایط قدیمی را نیز پردازش کند. پوشه را پیش از اجرا و مقصد complete را پس از آن ببینید.

### پیوند از انتخاب

عمل انتخاب می‌تواند اصطلاح برگزیده را پیوند کند و با مقصد تنظیم‌شده فایل مفهوم بسازد. این راه برای انتخاب مستقیم واژه به‌جای انتخاب مدل از کل متن است.

## نکته‌ها

- از منبع کوچک و پوشهٔ جدا شروع کنید.
- زبان را پیش از ایجاد انبوه تعیین کنید.
- مترادف‌ها و نامزدهای تکرار را جدا بررسی کنید.
- گزارش لازم را پیش از بازنویسی اجرای بعد نگه دارید.
