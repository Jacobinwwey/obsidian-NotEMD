# ترجمه

<TLDR>Notemd فایل فعال یا فایل‌های واجد شرایط پوشه را با LLM تنظیم‌شده ترجمه می‌کند. حالت اولیه فایل جدا با پسوند زبان می‌سازد. کیفیت به مدل وابسته است؛ 21 زبان UI و 34 زبان سایت حد یا تضمین ترجمه نیستند.</TLDR>

## نمای کلی

زبان مقصد و ارائه‌دهنده را انتخاب و یک کپی با اصطلاح، پیوند و کد آزمایش کنید. این قابلیت از LLM منتخب استفاده می‌کند، نه اتصال ویژهٔ Google Translate. کارها در سطح فایل/پوشه‌اند؛ برای یک عبارت ابتدا یادداشت موقت بسازید. انتخاب متن، **ترجمه فایل فعلی** را محدود نمی‌کند.

## روش کار

### فرمان ترجمه

1. زبان خروجی را تعیین کنید؛ پیش‌فرض انگلیسی و مستقل از UI است.
2. اصل را باز و **ترجمه فایل فعلی** را اجرا کنید.
3. متن بلند قطعه‌بندی، به مدل ارسال و پاسخ‌ها ترکیب می‌شوند.
4. مسیر گزارش‌شده را باز و معنا، اصطلاح، نقل‌قول، پیوند Markdown و کد را بررسی کنید.

ترجمهٔ فرانسوی `Example.md` به‌طور پیش‌فرض `Example_fr.md` کنار اصل می‌سازد. اصل حفظ ولی مقصد موجود بازنویسی می‌شود. افزودن به اصل یا عنوان ثابت `Translation` رفتار تضمین‌شده نیست.

### جفت زبان

مدل زبان مبدأ را تشخیص می‌دهد. وجود زبان در منو دقت یک جفت را ثابت نمی‌کند. متن چندزبانه و اصطلاحات را نمونه‌گیری کنید؛ قطعه‌بندی می‌تواند زمینه را از بین ببرد.

### مدل کار

با مسیر اختصاصی، `translateProvider` و `translateModel` به کار می‌روند؛ وگرنه ارائه‌دهندهٔ فعال. مدل محلی سرور و مدل آماده می‌خواهد؛ ابر متن و prompt را می‌گیرد. بر اساس نمونهٔ حوزهٔ خود انتخاب کنید، نه رتبه‌بندی کلی.

### ترجمهٔ پوشه

**ترجمه دسته‌ای پوشه** ابتدا فقط فایل‌های مستقیم پوشه را می‌گیرد؛ نمایهٔ پیشرفته ممکن است محدوده را تغییر دهد. منابع هم‌نام که به یک پوشهٔ خروجی می‌روند می‌توانند تداخل کنند. مقصد و ترجمه‌های موجود را پیش از تکرار بررسی کنید.

## تنظیمات

| تنظیم | مقدار اولیه | اثر |
| --------- | --------- | -------- |
| `language` | `en` | زبان مقصد منتخب |
| `translateProvider` | `DeepSeek` | ارائه‌دهنده در مسیر اختصاصی |
| `translateModel` | `''` | خالی یعنی مدل ارائه‌دهنده |
| `useCustomTranslationSuffix` | `false` | پیش‌فرض پسوند کد زبان |
| `translationCustomSuffix` | `_translated` | پسوند هنگام فعال بودن انتخاب سفارشی |
| `useCustomTranslationSavePath` | `false` | پیش‌فرض ذخیره کنار اصل |
| `translationSavePath` | `''` | پوشهٔ خروجی نسبت به خزانه |
| `batchConcurrency` | `1` | هم‌زمانی درخواستی ترجمهٔ پوشه |

اگر پوشهٔ سفارشی ساخته نشود، ذخیره می‌تواند به پوشهٔ اصل برگردد؛ مسیر واقعی را بخوانید. پسوند سفارشی خالی می‌تواند نام خود منبع را هدف بگیرد. برای ترجمهٔ جدا پسوند متمایز بدهید.

## نمونه

یادداشت کوتاه چینی را در پوشهٔ آزمایشی کپی و با زبان خروجی انگلیسی ترجمه کنید. `_en.md` را با اصل از نظر اصطلاح، عدد، فرمول و پیوند بسنجید و سپس کل پوشه را اجرا کنید.

## لغو و بررسی

لغو ادامهٔ پشتیبانی‌شده را متوقف می‌کند، نه ترجمهٔ نوشته‌شده یا لزوماً هزینهٔ ارائه‌دهنده را. گزارش و فایل‌ها را بررسی کنید. دستور حفظ Markdown درخواست از مدل است، نه تضمین برابری معنا در سطح تحلیل‌گر.

## نکته‌ها

- اصل را پشتیبان بگیرید و نام‌های متداخل را بررسی کنید.
- برای آزمایش پسوند و پوشهٔ جدا بدهید.
- شناسهٔ کد، نشانهٔ ریاضی، نشانی و نام خاص را دستی بسنجید.
- پیش از اشتراک گزارش، اطلاعات خصوصی را پاک کنید.
