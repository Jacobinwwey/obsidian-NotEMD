# گردش‌کارها

<TLDR>گردش‌کار عملیات موجود را به‌ترتیب اجرا می‌کند. هر مرحله ممکن است پوشه یا ویرایشگر فعال بخواهد. این خط لولهٔ متن نیست؛ ورودی، خروجی و اثر جانبی هر کار حفظ می‌شود. با یادداشت و پوشهٔ آزمایشی شروع کنید.</TLDR>

## نمای کلی

تعریف اولیهٔ **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. به یادداشت فعال پیوند اضافه و در صورت تعیین پوشه، مفهوم ایجاد می‌کند.
2. برای یادداشت‌های واجد شرایط پوشهٔ مفهوم یا پوشهٔ منتخب از عنوان متن تولید می‌کند؛ فایل‌های قبلی هم شامل می‌شوند.
3. Mermaid پوشهٔ complete حاصل از تولید را ترمیم می‌کند.

پژوهش وب در زنجیرهٔ اولیه نیست؛ فقط تنظیم جداگانهٔ تولید می‌تواند آن را اضافه کند. [پردازش گروهی](../advanced/batch-processing).

## روش کار

### اجرای زنجیره

مراحل پشت سر هم اجرا و مرحلهٔ فعال و خطا گزارش می‌شوند. لغو ادامه را متوقف و به درخواست‌های پشتیبانی‌شده منتقل می‌شود؛ نوشته‌های کامل می‌مانند و بازگردانی سراسری وجود ندارد. پوشهٔ مفهوم ترجیح اولیه است؛ تولید گروهی پوشهٔ اصل و complete را ثبت و ترمیم Mermaid از complete استفاده می‌کند. شرط فایل فعال، انتخاب یا تعامل بقیهٔ کارها باقی است.

### قالب DSL

هر خط یک دکمهٔ نام‌دار است؛ `::` نام و کارها، `>` شناسهٔ کارها را جدا می‌کند. خط خالی و خط شروع‌شده با `#` نادیده و شناسهٔ ناشناخته رد می‌شود.

```text
استخراج و نمودار::extract-concepts-current>summarize-as-mermaid
```

از سازنده یا ویرایش مستقیم استفاده کنید. شناسه ثابت است و نام نمایشی از زبان UI پیروی می‌کند. نسخهٔ پوشه‌ای شناسهٔ خودش را دارد و با جایگزینی دلخواه متن ساخته نمی‌شود.

| شناسه | عمل و شرط |
| ------------ | ----------------------- |
| `process-current-add-links` | پیوند در یادداشت فعال |
| `process-folder-add-links` | پیوند در پوشهٔ انتخابی |
| `extract-concepts-current` | مفهوم از یادداشت فعال |
| `extract-concepts-folder` | مفهوم از پوشهٔ انتخابی |
| `generate-from-title` | تولید از عنوان یادداشت فعال |
| `batch-generate-from-titles` | تولید یادداشت واجد شرایط پوشه |
| `research-and-summarize` | پژوهش انتخاب یا عنوان در Markdown باز |
| `summarize-as-mermaid` | خلاصهٔ ورودی پشتیبانی‌شده به Mermaid |
| `generate-diagram` | در یک اجرا چند نوع نمودار و برای هر نوع چند قالب خروجی مستقل انتخاب کنید. برداشتن تیک، قالب‌های آن نوع را حفظ می‌کند؛ بدون انتخاب، محتوا خودکار تحلیل می‌شود. |
| `preview-diagram` | پیش‌نمایش منبع یا نمودار پشتیبانی‌شده |
| `translate-current-file` | ترجمهٔ فایل فعال پشتیبانی‌شده |
| `batch-translate-folder` | ترجمهٔ پوشهٔ انتخابی |
| `extract-original-text` | استخراج قطعات مشخص اصل |
| `batch-extract-original-text` | استخراج از فایل واجد شرایط پوشه |
| `split-note-by-chapters` | تقسیم یادداشت فعال به فصل |
| `batch-mermaid-fix` | ترمیم بلوک Mermaid پوشه |
| `fix-formula-current` | نرمال‌سازی جداکنندهٔ فرمول در یادداشت فعال |
| `batch-fix-formula` | نرمال‌سازی فرمول پوشه |
| `check-duplicates-current` | بررسی تکرار در یادداشت فعال |
| `check-remove-duplicate-concepts` | بررسی و حذف تعاملی مفهوم تکراری |
| `test-llm-connection` | آزمون ارائه‌دهندهٔ تنظیم‌شده |
| `probe-slide-export-env` | بررسی محیط خروجی اسلاید محلی |
| `export-slides` | خروجی اسلاید از فایل فعال |

### اولیه یا سفارشی

One-Click Extract آماده است و دکمهٔ اضافی تعریف شماست. تنظیم گردش‌کار را پیدا کنید، نام و ترتیب را تعیین و راهنمای دکمه را در نوار کناری ببینید. خطای تحلیل را قبل از اتکا به زنجیره اصلاح کنید.

## تنظیمات

| تنظیم | مقدار اولیه | اثر |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | توقف در نخستین خطای گزارش‌شده |
| `useMultiModelSettings` | `false` | ارائه‌دهندهٔ فعال تا روشن شدن مسیر اختصاصی |
| `enableResearchInGenerateContent` | `false` | حذف پژوهش از تولید عنوان تا فعال‌سازی |

`continue_on_error` می‌تواند مرحلهٔ بعد را با وجود خطا اجرا کند. فقط وقتی مناسب است که ورودی باقی‌مانده را بپذیرد. ادامه، اجرای ناقص را موفق کامل نمی‌کند.

### مدل هر مرحله

انتخاب مدل متعلق به خود کار است. override خالی مدل تنظیم‌شدهٔ ارائه‌دهنده را می‌گیرد. برای محتوای خصوصی تمام مسیرها را پیش از اجرا بررسی کنید.

## نمونه

پوشهٔ خالی `trial-concepts` را تعیین، یک اصل آزمایشی اجرا و مفهوم‌ها و complete را بررسی کنید. اگر مقصد نامشخص است، ابتدا هر کار را جدا امتحان کنید و سپس دامنه را گسترش دهید.

## نکته‌ها

- زنجیره را به‌اندازه‌ای کوتاه نگه دارید که خطا و مالک خروجی روشن بماند.
- حذف و پاک‌سازی هنوز تأیید تعاملی می‌خواهند؛ در زنجیرهٔ بی‌نظارت قرار ندهید.
- بعد از لغو یا تعارض، گزارش و فایل را ببینید.
- مدل و پوشهٔ دقیق را بیازمایید؛ اتصال کوتاه سهمیهٔ کافی برای گروه بزرگ را ثابت نمی‌کند.
