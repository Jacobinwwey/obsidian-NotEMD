# ارائه‌دهندهٔ Anthropic

<TLDR>این نمایه برای Messages بومی است. Claude از درگاه OpenAI-compatible باید نمایهٔ همان درگاه را استفاده کند. نام مدل تاریخی اولیه ممکن است نیاز به جایگزینی داشته باشد.</TLDR>

## آماده‌سازی

**Anthropic**، کلید و مدل در دسترس را انتخاب کنید. جز deployment دارای همان پروتکل، نشانی بومی را حفظ کنید. اتصال و کار روی یادداشت را بیازمایید.

## نشانی و احراز هویت

| فیلد | مقدار اولیه |
| ------- | -------------- |
| پروتکل | `anthropic` |
| کلید API | الزامی |
| نشانی پایه | `https://api.anthropic.com` |
| مدل | `claude-3-5-sonnet-20240620` |
| دما | `0.5` |
| آزمون اتصال | `chat-only` |

درخواست از `/v1/messages` با header کلید و نسخهٔ بومی استفاده می‌کند. مسیر chat OpenAI را اضافه نکنید. جدول تنظیم مخزن را نشان می‌دهد، نه تضمین دسترسی جاری.

## مدل‌ها

در صورت امکان فهرست بومی را بگیرید. اگر فهرست محدود است، شناسهٔ مجاز را مستقیم بدهید و تولید را تست کنید. کار بلند و خروجی ساختاریافته آزمون جدا می‌خواهند.

## رفع خطا

- 401 یا 403: کلید، پروژه، پرداخت و مجوز.
- 404: نشانی و مدل فعلی.
- شناسهٔ درگاه رد شده: نمایه و شناسه را هماهنگ کنید.
- درخواست بلند: قبل از افزایش تکرار، محدودیت و خطا را ببینید.

## کاربرد مناسب

برای endpoint بومی Messages. نتیجه را با منابع خود مقایسه کنید و رتبهٔ عمومی فرض نکنید. مسیر اختصاصی استفاده در کار منتخب را ممکن می‌کند.
