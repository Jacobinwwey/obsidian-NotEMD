# ارائه‌دهندهٔ Google

<TLDR>نمایه از Gemini Generative Language بومی استفاده می‌کند. کلید مجاز و مدل موجود لازم است. Gemini پشت درگاه سازگار از نمایهٔ همان درگاه استفاده می‌کند.</TLDR>

## آماده‌سازی

**Google**، کلید، نشانی بومی و مدل نسخهٔ API منتخب را تعیین و اتصال و یادداشت را آزمایش کنید. این نمایه deployment دلخواه Google Cloud یا Vertex را خودکار تنظیم نمی‌کند.

## نشانی و احراز هویت

| فیلد | مقدار اولیه |
| ------- | -------------- |
| پروتکل | `google` |
| کلید API | الزامی |
| نشانی پایه | `https://generativelanguage.googleapis.com/v1` |
| مدل | `gemini-2.0-flash-exp` |
| دما | `0.5` |
| آزمون اتصال | `chat-only` |

درخواست `generateContent` همراه کلید ساخته می‌شود. شناسهٔ تاریخی دسترسی را تضمین نمی‌کند. URL تشخیصی ممکن است احراز هویت داشته باشد؛ پیش از اشتراک بررسی کنید.

## مدل‌ها

از کشف بومی استفاده و تولید را در API منتخب تأیید کنید. فهرست خالی ممکن است ناشی از حق دسترسی، نشانی یا نبود مدل باشد. قبل از تغییر پروتکل علت را پیدا کنید.

## رفع خطا

- 400: شناسه، پارامتر و حد ورودی/خروجی.
- 401 یا 403: محدودیت کلید، فعال بودن API و مجوز.
- 404: وجود مدل در همان نسخهٔ API.
- نمونهٔ درگاه: نمایهٔ OpenAI-compatible مناسب را استفاده کنید.

## کاربرد مناسب

برای Gemini بومی. ترجمه، پژوهش و نمودار را روی نمونهٔ خود بسنجید؛ سرعت، هزینه و کیفیت عمومی تضمین نمی‌شود.
