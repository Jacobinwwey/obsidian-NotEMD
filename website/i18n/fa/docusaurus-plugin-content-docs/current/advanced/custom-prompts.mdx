# Prompt سفارشی

<TLDR>اگر کلید عمومی و کلید کار فعال و متن غیرخالی باشد، prompt سفارشی جای دستور داخلی می‌نشیند. قرارداد خروجی را حفظ کنید؛ سیستم همهٔ دستورهای حذف‌شدهٔ قالب را خودکار برنمی‌گرداند.</TLDR>

## نمای کلی

ابتدا دستور اولیه را روی نمونهٔ واقعی امتحان کنید. شاید حوزه یا کاهش مترادف کافی باشد. وقتی سیاست استخراج، ساختار یا سبک ترجمهٔ خاص می‌خواهید تغییر دهید و قبل از گروه مقایسه کنید.

## روش کار

### ساختار

دستور داخلی یا سفارشی انتخاب می‌شود، زبان و حوزهٔ مربوط افزوده و متغیرهای همان کار جایگذاری می‌شوند. متن می‌تواند پیام جدا باشد. متغیرها عمومی نیستند. حذف `CONCEPT:` تحلیل را مختل و حذف زمینهٔ پژوهش نتیجه را بی‌پشتوانه می‌کند؛ درخواست معتبر پاسخ معتبر را ثابت نمی‌کند.

### متغیرها

نام بزرگ و یک جفت آکولاد را دقیق حفظ کنید:

| کار | متغیرهای موجود |
| ------ | ----------------------- |
| تولید عنوان | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| خلاصهٔ پژوهش | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| ترجمه | `{LANGUAGE}`, `{TEXT}` |
| استخراج اصل | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` تابع سیاست زبان کار است. پیوند و استخراج مستقل مفهوم متن را به‌عنوان محتوا می‌فرستند؛ متغیر تازه اختراع نکنید. نام ناشناخته خودکار پر نمی‌شود و این‌ها قالب فایل مفهوم نیستند.

### حوزهٔ تمرکز

یادگیری متمرکز را با حوزه‌ای مانند `مهندسی برق` فعال کنید. `Relevant Fields` توجه مدل را هدایت می‌کند؛ فیلتر سخت یا اثبات حذف مفهوم نامرتبط نیست.

## تنظیمات

| کار | کلید فعال‌سازی | فیلد prompt |
| ------ | --------------- | -------------- |
| پیوند | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| عنوان | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| پژوهش | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| خلاصهٔ Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| مفهوم | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| ترجمه | `useCustomPromptForTranslate` | `translatePrompt` |
| متن اصلی | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

همه به `enableGlobalCustomPrompts` نیاز دارند. متن خالی از دستور داخلی استفاده می‌کند. استخراج ادغام‌شدهٔ اصل قالب داخلی جدا دارد و override عادی را به کار نمی‌گیرد. تولید نمودار قرارداد نوع‌دار خود را دارد؛ دستور Mermaid عمومی همهٔ نمودارها نیست.

## نمونه

کلید عمومی و مفهوم را فعال و نشانهٔ تحلیل‌گر را حفظ کنید:

```text
مفاهیم اصلی مهندسی برق را از یادداشت استخراج کنید.
قطعهٔ مشخص و سازوکار فیزیکی را بر اسم عمومی ترجیح دهید.
هر مفهوم را در یک خط با این قالب دقیق بنویسید:
CONCEPT: نام اصطلاح
توضیح اضافی یا بلوک کد بیرونی ننویسید.
```

روی نسخهٔ کپی، خروجی، نام فایل و مفهوم جاافتاده را با دستور داخلی مقایسه کنید. prompt قبلی را برای بازگشت نگه دارید.

## نکته‌ها

- هر بار یک کار، سپس گسترش گروه.
- شاهد پژوهش و نقل‌قول دقیق اصل را حفظ کنید.
- متن را ترجمه کنید، شناسه و نشانه را ثابت نگه دارید.
- بعد از تغییر مدل دوباره بیازمایید؛ دستور تضمین اعتبارسنجی نیست.
