# تنظیمات

<TLDR>Settings → Notemd را باز کنید و فیلد را جست‌وجو کنید. پیش از پردازش، ارائه‌دهنده و مقصد را تعیین و تغییرات را روی یک یادداشت بیازمایید. کار در حال اجرا ممکن است تنظیمات ثبت‌شده در آغاز را نگه دارد.</TLDR>

## نمای کلی

ارائه‌دهندهٔ اولیه DeepSeek و اطلاعات حساب خالی است. انتخاب نمایه حساب نمی‌سازد، مدل نصب نمی‌کند و مجوز نمی‌دهد. [راهنمای ارائه‌دهنده](../providers/overview) را ببینید.

## جست‌وجو و علاقه‌مندی‌ها

**Search settings** نام، توضیح، نام جایگزین و دستهٔ قابل‌نمایش را جست‌وجو و به فیلد می‌رود. **★ Favorites** تنظیمات ذخیره‌شده را همراه توضیح و مقصد نشان می‌دهد. این فهرست در خزانه می‌ماند و شناسهٔ منسوخ حذف می‌شود. بستن نوار جست‌وجو پرسش را حفظ می‌کند. فهرست علاقه‌مندی و فیلتر جست‌وجوی فقط علاقه‌مندی دو کنترل جدا هستند.

**Diagram preview export PPI** در ابتدا 300 و در بازهٔ 72–600 است و فقط روی PNG اثر دارد. SVG/PDF هندسهٔ برداری پشتیبانی‌شده را حفظ می‌کنند. **Also export complete Mermaid visuals** فایل همراه را کنترل می‌کند، نه نمایش Mermaid در Drawnix.

## ۱. ارائه‌دهنده

پروتکل، نشانی، کلید لازم و مدل در دسترس را انتخاب کنید. فهرست مدل و تولید موفق دو بررسی جدا هستند. مدل محلی به سرور و مدل آماده نیاز دارد؛ ابر و درگاه محتوا را دریافت می‌کنند. برای محتوای خصوصی مسیر هر کار را هم بررسی کنید.

## ۲. مدل هر کار

`useMultiModelSettings` ارائه‌دهنده و مدل جدا برای پیوند، عنوان، پژوهش، ترجمه، مفهوم، متن اصلی و خلاصهٔ Mermaid می‌دهد. override خالی از مدل همان ارائه‌دهنده استفاده می‌کند؛ در غیر این حالت ارائه‌دهندهٔ فعال حاکم است. یک نمونه را از نظر دقت، تأخیر و قیمت واقعی مقایسه کنید؛ رتبه یا دسترسی عمومی تضمین نمی‌شود.

## ۳. خروجی

| کار | رفتار اولیه |
| ------ | ------------------------- |
| افزودن پیوند | فایل جداگانهٔ `_processed.md` کنار اصل؛ جابه‌جایی اصل خاموش |
| استخراج مستقل مفهوم | پوشهٔ انتخابی؛ فقط عنوان و بدون پیوند بازگشت |
| ترجمه | فایل `_<language>.md` کنار اصل؛ امکان بازنویسی مقصد موجود |
| پژوهش | افزودن خلاصه به Markdown فعال |
| تولید گروهی از عنوان | نوشتن محتوا و انتقال یادداشت واجد شرایط به پوشهٔ هم‌سطح `<folder>_complete` در صورت امکان مقصد |
| پیش‌نمایش و خروجی نمودار | منبع یا خروجی تصویری پشتیبانی‌شده؛ بررسی مسیر گزارش‌شده |

پوشهٔ مفهوم ابتدا خالی است. `concepts` انتخاب شماست. شکل‌های مستقل کمینه/کامل هستند و موتور عمومی متغیر قالب ندارند. [مفاهیم](../features/concept-notes). پسوندها و پوشه‌های پردازش و ترجمه تنظیمات جدا دارند. مقصد موجود و تعارض بازیابی را بررسی کنید؛ لغو نوشتهٔ کامل را پس نمی‌گیرد.

## ۴. زبان

UI افزونه 21 locale و سایت 34 مسیر زبانی دارد. `uiLocale: auto` از نگاشت پشتیبانی‌شده پیروی می‌کند و زبان ناموجود به انگلیسی برمی‌گردد. زبان تولید مستقل و ابتدا انگلیسی است. کارهای پشتیبانی‌شده زبان جدا دارند؛ ترجمه از `language` استفاده می‌کند. توانایی مدل از این شمارش‌ها نتیجه نمی‌شود.

## ۵. جست‌وجو

Tavily با کلید یا DuckDuckGo را صریحاً انتخاب کنید. کلید خالی انتخاب را عوض نمی‌کند. هر دو شبکه می‌خواهند و DuckDuckGo ممکن است صفحه را دریافت کند. پژوهش عنوان ابتدا خاموش است: `enableResearchInGenerateContent`. بازیابی محلی نیز خاموش و دارای محدودهٔ پوشه/کار جداست؛ گزیدهٔ محلی در صورت استفاده به LLM منتخب ارسال می‌شود.

## ۶. گردش‌کار

از سازنده یا یک تعریف نام‌دار در هر خط استفاده کنید:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` نام را از کارها و `>` شناسه‌های کار را از هم جدا می‌کند. سیاست اولیه در خطای گزارش‌شده توقف می‌کند. [گردش‌کار](../features/workflows) شناسه و پیامد ادامه پس از خطا را توضیح می‌دهد.

## ۷. تنظیمات پیشرفته

| تنظیم | مقدار اولیه | اثر |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | ارائه‌دهنده بدون مسیر اختصاصی کار |
| `useMultiModelSettings` | `false` | انتخاب مدل و ارائه‌دهنده برای هر کار |
| `useCustomConceptNoteFolder` | `true` | اجازهٔ ساخت مفهوم پس از انتخاب پوشه |
| `conceptNoteFolder` | `''` | ابتدا پوشه‌ای انتخاب نشده |
| `extractConceptsMinimalTemplate` | `true` | یادداشت مستقل فقط با عنوان |
| `extractConceptsAddBacklink` | `false` | پیوند بازگشت مستقل تنها پس از فعال‌سازی |
| `moveOriginalFileOnProcess` | `false` | حفظ اصل هنگام پیوندگذاری |
| `chunkWordCount` | `3000` | اندازهٔ تقریبی قطعه، نه حد token |
| `batchConcurrency` | `1` | هم‌زمانی اولیهٔ گروه |
| `enableBatchParallelism` | `false` | اجازهٔ موازی‌سازی در مسیرهای استفاده‌کننده از این گزینه |
| `enableStableApiCall` | `false` | حالت صریح درخواست پایدار |
| `customWorkflowErrorStrategy` | `stop_on_error` | توقف زنجیره در خطای گزارش‌شده |

اندازهٔ قطعه و بودجهٔ token خروجی متفاوت‌اند. قطعهٔ کوچک رعایت همهٔ محدودیت‌های متن را تضمین نمی‌کند و هم‌زمانی کمتر جلوی تمام 429ها را نمی‌گیرد.

## نمایهٔ تنظیمات

تنظیمات جزو دادهٔ افزونه در خزانه است. پیش از تغییر پشتیبان بگیرید. خروجی نمایهٔ ارائه‌دهنده قرارداد حذف راز جدا دارد و پشتیبان کامل نیست. حتی خروجی پاک‌سازی‌شده را از نظر نشانی و metadata بررسی کنید؛ تنظیمات خام یا گزارش حاوی متن خصوصی را منتشر نکنید.

## خطای تنظیمات

مدل و نمایهٔ دقیق را آزمایش و یک یادداشت کوچک را تکرار کنید. اگر فیلد دیده نمی‌شود، جست‌وجو، دسته، حالت توسعه‌دهنده و خزانهٔ انتخابی را بررسی کنید. نسخه و تنظیمات حداقلی بدون دادهٔ خصوصی را گزارش دهید.
