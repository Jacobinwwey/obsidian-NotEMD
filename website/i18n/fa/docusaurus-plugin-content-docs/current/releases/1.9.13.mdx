# Notemd 1.9.13 — کنترل پیش‌نمایش و خروجی ارائه

<TLDR>
گزارش‌های خروجی موفق به‌طور پیش‌فرض جمع‌شده هستند. هر پیش‌نمایش را قفل کنید تا متن SVG/HTML را بدون جابه‌جایی یا بزرگ‌نمایی انتخاب کنید. پیش‌نمایش PNG/PDF و خروجی ارائه در چند قالب اصلاح شده‌اند. نصب مرورگر در Windows اجرای واقعی را بررسی می‌کند و برای شروع نخست زمان کافی می‌دهد. Slidev از فورک اصلاح‌شدهٔ Jacobinwwey استفاده می‌کند.
</TLDR>

فایل‌های هماهنگ main.js، manifest.json و styles.css نسخهٔ 1.9.13 را نصب و افزونه را دوباره بارگذاری کنید. یادداشت‌ها و تنظیمات موجود حفظ می‌شوند. بستهٔ قدیمی فورک Slidev را با نصب‌کنندهٔ محیط خروجی جایگزین کنید.
