# Μετάφραση

<TLDR>Το Notemd μεταφράζει το ενεργό αρχείο ή κατάλληλα αρχεία φακέλου με το επιλεγμένο LLM. Η προεπιλογή γράφει ξεχωριστό αρχείο με επίθημα γλώσσας. Η ποιότητα εξαρτάται από το μοντέλο· οι 21 γλώσσες UI και 34 του ιστοτόπου δεν είναι όρια ή εγγυήσεις μετάφρασης.</TLDR>

## Επισκόπηση

Επιλέξτε γλώσσα στόχο και πάροχο και δοκιμάστε αντίγραφο με όρους, συνδέσμους και κώδικα. Χρησιμοποιείται LLM, όχι ειδική ενσωμάτωση Google Translate. Οι εντολές αφορούν αρχεία/φακέλους. Για απόσπασμα χρησιμοποιήστε προσωρινή σημείωση· η επιλογή δεν περιορίζει το **Translate current file**.

## Πώς λειτουργεί

### Εργασία μετάφρασης

1. Επιλέξτε γλώσσα στόχο, αρχικά αγγλικά και ανεξάρτητα από UI.
2. Ανοίξτε πηγή και εκτελέστε **Translate current file**.
3. Μακρύ κείμενο χωρίζεται, αποστέλλεται και ενώνεται.
4. Ανοίξτε την αναφερόμενη διαδρομή και ελέγξτε νόημα, όρους, παραθέματα, Markdown και κώδικα.

Η γαλλική μετάφραση του `Example.md` δημιουργεί συνήθως `Example_fr.md` δίπλα στη διατηρημένη πηγή. Υπάρχουσα έξοδος αντικαθίσταται. Προσθήκη μέσα στο πρωτότυπο ή σταθερή επικεφαλίδα `Translation` δεν είναι προεπιλεγμένη εγγύηση.

### Ζεύγη γλωσσών

Το μοντέλο συμπεραίνει τη γλώσσα πηγής. Μια επιλογή μενού δεν αποδεικνύει ακρίβεια του ζεύγους. Δοκιμάστε μεικτές γλώσσες και ορολογία· ο τεμαχισμός μπορεί να χάσει πλαίσιο.

### Μοντέλο εργασίας

Η δρομολόγηση χρησιμοποιεί `translateProvider`/`translateModel`, αλλιώς τον ενεργό πάροχο. Τοπικά απαιτείται διακομιστής/μοντέλο· το cloud λαμβάνει περιεχόμενο και οδηγία. Αξιολογήστε δείγμα του δικού σας πεδίου.

### Μετάφραση φακέλου

Το **Batch translate folder** περιλαμβάνει προεπιλεγμένα μόνο άμεσα παιδιά· προηγμένα προφίλ μπορούν να το αλλάξουν. Ίδια ονόματα πηγών σε έναν φάκελο εξόδου μπορεί να συγκρουστούν. Ελέγξτε παλιές μεταφράσεις και προορισμούς πριν επαναλάβετε.

## Ρυθμίσεις

| Ρύθμιση | Αρχική τιμή | Επίδραση |
| --------- | --------- | -------- |
| `language` | `en` | Επιλεγμένη γλώσσα στόχος |
| `translateProvider` | `DeepSeek` | Πάροχος με ενεργές διαδρομές εργασιών |
| `translateModel` | `''` | Κενό χρησιμοποιεί μοντέλο παρόχου |
| `useCustomTranslationSuffix` | `false` | Κωδικός γλώσσας ως αρχικό επίθημα |
| `translationCustomSuffix` | `_translated` | Επίθημα όταν ενεργοποιείται δικό σας |
| `useCustomTranslationSavePath` | `false` | Προεπιλεγμένη αποθήκευση δίπλα στην πηγή |
| `translationSavePath` | `''` | Φάκελος εξόδου σχετικός με το vault |
| `batchConcurrency` | `1` | Ζητούμενος παραλληλισμός μετάφρασης φακέλου |

Αν δεν δημιουργηθεί ο ειδικός φάκελος, μπορεί να χρησιμοποιηθεί ο φάκελος πηγής. Διαβάστε την πραγματική διαδρομή. Κενό ειδικό επίθημα μπορεί να στοχεύσει το πρωτότυπο· χρησιμοποιήστε διακριτό επίθημα για ξεχωριστή μετάφραση.

## Παράδειγμα

Αντιγράψτε μικρή κινεζική σημείωση σε δοκιμαστικό φάκελο, επιλέξτε αγγλικά και μεταφράστε. Συγκρίνετε το `_en.md` με την πηγή σε όρους, αριθμούς, τύπους και συνδέσμους. Επεκτείνετε κατόπιν.

## Ακύρωση και έλεγχος

Η ακύρωση σταματά υποστηριζόμενη συνέχεια, όχι έτοιμες μεταφράσεις ούτε εγγυημένα τη χρέωση. Εξετάστε αναφορά και αρχεία. Διατήρηση Markdown είναι οδηγία μοντέλου, όχι εγγύηση αναλυτή για ισοδύναμο νόημα.

## Συμβουλές

- Αντίγραφο πηγής και έλεγχος συγκρούσεων.
- Ξεχωριστό δοκιμαστικό επίθημα/φάκελος.
- Χειροκίνητος έλεγχος κώδικα, μαθηματικών, URL και ονομάτων.
- Έλεγχος διαγνωστικών πριν από κοινοποίηση.
