# Σημειώσεις εννοιών

<TLDR>Ο αυτόνομος εντοπισμός διαβάζει την πηγή και δημιουργεί έννοιες Markdown σε επιλεγμένο φάκελο. Αρχικά δεν έχει οριστεί φάκελος. Οι νέες σημειώσεις περιέχουν μόνο τίτλο χωρίς σύνδεσμο επιστροφής. Η προσθήκη συνδέσμων χρησιμοποιεί διαφορετική μορφή.</TLDR>

## Επισκόπηση

Ορίστε πρώτα **Concept note folder path**. Ξεχωριστός φάκελος διευκολύνει έλεγχο αποτελεσμάτων, διπλοτύπων και παραγωγής από τίτλους. Ο εντοπισμός δεν γεμίζει αυτόματα τις σημειώσεις με ερευνημένες εξηγήσεις.

## Πώς λειτουργεί

### Εντοπισμός

Το επιλεγμένο LLM λαμβάνει κείμενο. Η εργασία διαβάζει γραμμές `CONCEPT:`, αφαιρεί επαναλαμβανόμενα ονόματα μέσα στη λειτουργία και δημιουργεί/ενημερώνει αρχεία. Μακριές σημειώσεις χωρίζονται. Ελέγξτε αποτυχημένα τμήματα· η απάντηση δεν είναι πλήρης απογραφή εννοιών.

### Οδηγία εντοπισμού

Η προεπιλογή ζητά συγκεκριμένες σχετικές έννοιες. Πεδίο και συνώνυμα δεν εξασφαλίζουν κανονικό λεξιλόγιο. Διατηρήστε `CONCEPT: Term` στις δικές σας οδηγίες. [Οδηγίες](../advanced/custom-prompts).

### Τμήματα

Το `chunkWordCount` αρχίζει περίπου στις 3000 λέξεις, όχι σε tokens παρόχου. Το πλαίσιο μεταξύ τμημάτων είναι περιορισμένο· ελέγξτε σχέσεις και αμφίσημα ονόματα.

## Δημιουργία αρχείων

### Κανόνες ονομάτων

Μη έγκυροι χαρακτήρες διαδρομής αφαιρούνται, κενά κανονικοποιούνται και μεγάλα ονόματα συντομεύονται· κενά αποτελέσματα παραλείπονται. Διαφορετικοί όροι μπορούν έτσι να καταλήξουν στην ίδια διαδρομή. Ελέγξτε ονόματα πριν από μεγάλες συλλογές.

### Πρότυπα

Ελάχιστη νέα σημείωση:

```markdown
# Όνομα έννοιας
```

Για επιστροφή σε νέα αυτόνομη σημείωση ενεργοποιήστε **Add "Linked From" backlink** και απενεργοποιήστε **Create minimal concept notes**:

```markdown
# Όνομα έννοιας

## Linked From
- [[Σημείωση πηγής]]
```

Η προσθήκη συνδέσμων δημιουργεί πλήρη μορφή με αναφορά πηγής όταν είναι ενεργά τα αποτελέσματα εννοιών. Οι διακόπτες αυτόνομου εντοπισμού δεν αλλάζουν αυτή τη διαδρομή.

### Υπάρχουσες σημειώσεις

Με ενεργούς συνδέσμους επιστροφής μπορεί να προστεθεί ελλείπουσα πηγή κάτω από `## Linked From`. Το κείμενο διατηρείται και ο ίδιος σύνδεσμος δεν διπλασιάζεται. Το basename της πηγής μπορεί να είναι αμφίσημο μεταξύ φακέλων.

### Ρυθμίσεις

| Ρύθμιση | Αρχική τιμή | Επίδραση |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Αποτελέσματα εννοιών μετά από επιλογή φακέλου |
| `conceptNoteFolder` | `''` | Δεν έχει οριστεί φάκελος |
| `extractConceptsMinimalTemplate` | `true` | Μόνο τίτλος σε αυτόνομες έννοιες |
| `extractConceptsAddBacklink` | `false` | Σύνδεσμοι επιστροφής στον αυτόνομο εντοπισμό |
| `extractConceptsProvider` | `DeepSeek` | Πάροχος με δρομολόγηση εργασιών |
| `extractConceptsModel` | `''` | Κενό χρησιμοποιεί το μοντέλο του παρόχου |
| `extractConceptsLanguage` | `en` | Γλώσσα με επιλογές ανά εργασία |
| `replaceSynonymsDuringConceptExtraction` | `false` | Οδηγία περιορισμού συνωνύμων |
| `generateConceptLogFile` | `false` | Προαιρετικό αρχείο καταγραφής εννοιών |

## Διπλότυπα

Ο έλεγχος βασίζεται σε ευρετικές ονομάτων: πεζά/κεφαλαία, πληθυντικό, σύμβολα και όπου επιτρέπεται μία λέξη μέσα σε άλλο όνομα. Δεν αποδεικνύει ίδια σημασία. Ελέγξτε ανώμαλους τύπους και τεχνικές διαφορές στο **Check & remove duplicates** και επιβεβαιώστε μόνο σκόπιμες διαγραφές. Το Obsidian διαχειρίζεται τον κάδο. Ο φάκελος εννοιών δεν είναι προσωρινή cache· κρατήστε αντίγραφο.

### Εύρος σύγκρισης

Συγκρίνετε με vault, ίδιο φάκελο εννοιών, συμπεριλαμβανόμενους φακέλους ή εύρος με εξαιρέσεις. Το εύρος αλλάζει υποψηφίους, όχι τη σημασία του διπλοτύπου.

## Χρήση

### Αυτόνομος εντοπισμός

Ανοίξτε Markdown, ελέγξτε φάκελο και επιλέξτε **Extract concepts (current file)**. Η πηγή μένει ίδια. Ελέγξτε ονόματα, κάλυψη και συνδέσμους επιστροφής.

### Εντοπισμός και περιεχόμενο

Το **Batch generate from titles** συμπληρώνει έννοιες αλλά μπορεί να πάρει υπάρχουσες κατάλληλες σημειώσεις. Ελέγξτε φάκελο πριν και αναφερόμενο complete μετά.

### Σύνδεσμος από επιλογή

Η ενέργεια επιλογής μετατρέπει δικό σας όρο σε wiki-link και μπορεί να δημιουργήσει αρχείο έννοιας όταν ο προορισμός έχει οριστεί.

## Συμβουλές

- Μικρή πηγή και ξεχωριστός φάκελος.
- Επιλογή γλώσσας πριν από μαζική δημιουργία.
- Χωριστή αξιολόγηση συνωνύμων και διπλοτύπων.
- Διατήρηση αναγκαίων logs πριν από επόμενη αντικατάσταση.
