# Ροές εργασίας

<TLDR>Μια ροή εκτελεί ενέργειες του πλαϊνού πάνελ διαδοχικά. Κάθε ενέργεια μπορεί να απαιτεί επιλογή φακέλου ή ενεργό επεξεργαστή. Δεν είναι διοχέτευση κειμένου: κάθε βήμα διατηρεί δικά του δεδομένα, έξοδο και παρενέργειες. Ξεκινήστε με δοκιμαστική σημείωση και χωριστό φάκελο.</TLDR>

## Επισκόπηση

Η έτοιμη **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Προσθέτει συνδέσμους στην ενεργή σημείωση και δημιουργεί έννοιες αν έχει οριστεί φάκελος.
2. Παράγει περιεχόμενο από τίτλους για κατάλληλες σημειώσεις στον φάκελο εννοιών/επιλεγμένο φάκελο, μαζί με υπάρχουσες.
3. Διορθώνει Mermaid στον φάκελο complete αυτής της παραγωγής.

Η προεπιλεγμένη αλυσίδα δεν ερευνά τον ιστό. Η παραγωγή από τίτλους μπορεί να προσθέσει έρευνα με ξεχωριστή ρύθμιση. [Μαζική επεξεργασία](../advanced/batch-processing).

## Πώς λειτουργεί

### Εκτέλεση

Τα βήματα εκτελούνται διαδοχικά με κατάσταση και σφάλματα στο πάνελ. Η ακύρωση σταματά επόμενα βήματα και φτάνει σε υποστηριζόμενα αιτήματα. Ολοκληρωμένα αρχεία παραμένουν· δεν υπάρχει συνολική συναλλαγή. Πρώτη προτίμηση είναι ο φάκελος εννοιών. Η μαζική παραγωγή θυμάται πηγή/complete και το Mermaid χρησιμοποιεί complete. Άλλες ενέργειες διατηρούν απαιτήσεις αρχείου, επιλογής και αλληλεπίδρασης.

### DSL

Μία ονομασμένη ενέργεια κουμπιού ανά γραμμή. Το `::` χωρίζει όνομα και ενέργειες, το `>` τα ID. Κενές γραμμές και γραμμές που αρχίζουν με `#` αγνοούνται· άγνωστα ID απορρίπτονται.

```text
Έννοιες και διάγραμμα::extract-concepts-current>summarize-as-mermaid
```

Χρησιμοποιήστε τον δημιουργό ροής ή επεξεργαστείτε DSL. Τα ID παραμένουν σταθερά, οι ετικέτες ακολουθούν το UI. Οι παραλλαγές φακέλου έχουν δικά τους ID· μην τα παράγετε με αυθαίρετες αντικαταστάσεις.

| ID | Ενέργεια / απαίτηση |
| ------------ | ----------------------- |
| `process-current-add-links` | Σύνδεσμοι στην ενεργή σημείωση |
| `process-folder-add-links` | Σύνδεσμοι σε επιλεγμένο φάκελο |
| `extract-concepts-current` | Έννοιες από ενεργή σημείωση |
| `extract-concepts-folder` | Έννοιες από επιλεγμένο φάκελο |
| `generate-from-title` | Περιεχόμενο από ενεργό τίτλο |
| `batch-generate-from-titles` | Περιεχόμενο κατάλληλων σημειώσεων φακέλου |
| `research-and-summarize` | Έρευνα επιλογής/τίτλου σε ανοικτό επεξεργαστή Markdown |
| `summarize-as-mermaid` | Σύνοψη υποστηριζόμενης ενεργής εισόδου σε Mermaid |
| `generate-diagram` | Επιλέξτε πολλούς τύπους διαγράμματος σε μία εκτέλεση και πολλές μορφές εξόδου για κάθε τύπο. Η αποεπιλογή διατηρεί τις μορφές του τύπου· χωρίς επιλογές το περιεχόμενο αναλύεται αυτόματα. |
| `preview-diagram` | Προεπισκόπηση υποστηριζόμενης πηγής ή διαγράμματος |
| `translate-current-file` | Μετάφραση ενεργού υποστηριζόμενου αρχείου |
| `batch-translate-folder` | Μετάφραση επιλεγμένου φακέλου |
| `extract-original-text` | Εντοπισμός ζητούμενων πρωτότυπων αποσπασμάτων |
| `batch-extract-original-text` | Αποσπάσματα κατάλληλων αρχείων φακέλου |
| `split-note-by-chapters` | Διαίρεση ενεργής σημείωσης σε κεφάλαια |
| `batch-mermaid-fix` | Επισκευή Mermaid blocks σε επιλεγμένο φάκελο |
| `fix-formula-current` | Κανονικοποίηση οριοθετών τύπων σε ενεργή σημείωση |
| `batch-fix-formula` | Κανονικοποίηση οριοθετών τύπων σε φάκελο |
| `check-duplicates-current` | Έλεγχος διπλοτύπων ενεργής σημείωσης |
| `check-remove-duplicate-concepts` | Διαδραστική εξέταση και διαγραφή διπλών εννοιών |
| `test-llm-connection` | Δοκιμή ρυθμισμένου παρόχου |
| `probe-slide-export-env` | Έλεγχος τοπικού περιβάλλοντος εξαγωγής διαφανειών |
| `export-slides` | Εξαγωγή ενεργού αρχείου σε διαφάνειες |

### Έτοιμη ή δική σας αλυσίδα

Η One-Click Extract είναι προκαθορισμένη. Ορίστε άλλα κουμπιά με όνομα και σειρά και δείτε την περιγραφή στο πάνελ. Διορθώστε σφάλματα ανάλυσης πριν βασιστείτε στη ροή.

## Ρυθμίσεις

| Ρύθμιση | Αρχική τιμή | Επίδραση |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Διακοπή στο πρώτο αναφερόμενο σφάλμα βήματος |
| `useMultiModelSettings` | `false` | Ενεργός πάροχος μέχρι να ενεργοποιηθεί δρομολόγηση εργασιών |
| `enableResearchInGenerateContent` | `false` | Χωρίς έρευνα στην παραγωγή τίτλων μέχρι να ενεργοποιηθεί |

Το `continue_on_error` επιτρέπει συνέχεια μετά από λάθος. Χρησιμοποιήστε το μόνο αν τα επόμενα βήματα λειτουργούν με όσα δεδομένα απέμειναν. Η συνέχεια δεν κάνει μια μερική ροή επιτυχή.

### Μοντέλα ανά βήμα

Το μοντέλο ανήκει στην εργασία. Κενό πεδίο χρησιμοποιεί το μοντέλο του επιλεγμένου παρόχου. Ελέγξτε όλες τις διαδρομές πριν στείλετε ιδιωτικό υλικό.

## Παράδειγμα

Επιλέξτε κενό `trial-concepts` και δοκιμαστική πηγή. Εξετάστε έννοιες και αναφερόμενο complete. Εκτελέστε τα βήματα χωριστά αν ο προορισμός είναι ασαφής. Αυξήστε το εύρος μετά τον έλεγχο.

## Συμβουλές

- Κρατήστε αλυσίδες κατανοητές για εντοπισμό σφαλμάτων και προέλευσης αρχείων.
- Ενέργειες διαγραφής κρατούν τη διαδραστική επιβεβαίωση· αποφύγετέ τες σε ροές χωρίς επίβλεψη.
- Διαβάστε logs και αρχεία μετά από ακύρωση ή σύγκρουση ανάκτησης.
- Δοκιμάστε ακριβές μοντέλο/φάκελο· η σύνδεση δεν αποδεικνύει επάρκεια ορίων για μεγάλη παρτίδα.
