# Anthropic

<TLDR>Χρησιμοποιήστε το προφίλ για το εγγενές Messages. Claude μέσω πύλης OpenAI-compatible χρησιμοποιεί το προφίλ πύλης. Το ιστορικό αρχικό μοντέλο μπορεί να χρειάζεται αντικατάσταση με διαθέσιμο.</TLDR>

## Προετοιμασία

Επιλέξτε **Anthropic**, κλειδί και προσβάσιμο μοντέλο. Κρατήστε τη διεύθυνση του εγγενούς API εκτός αν το deployment παρέχει ίδιο πρωτόκολλο. Δοκιμάστε σύνδεση και σημείωση.

## Endpoint και ταυτοποίηση

| Πεδίο | Αρχική τιμή |
| ------- | -------------- |
| Μεταφορά | `anthropic` |
| Κλειδί API | Απαιτείται |
| Βασική διεύθυνση | `https://api.anthropic.com` |
| Μοντέλο | `claude-3-5-sonnet-20240620` |
| Θερμοκρασία | `0.5` |
| Έλεγχος σύνδεσης | `chat-only` |

Η υλοποίηση χρησιμοποιεί `/v1/messages` με τα δικά του headers κλειδιού/έκδοσης. Μην προσθέτετε διαδρομή OpenAI chat. Αρχικές τιμές περιγράφουν τη ρύθμιση του αποθετηρίου, όχι τη σημερινή διαθεσιμότητα.

## Μοντέλα

Χρησιμοποιήστε εγγενή εύρεση όπου επιτρέπεται. Αν η λίστα είναι προστατευμένη, δώστε εξουσιοδοτημένο ID και δοκιμάστε παραγωγή. Μεγάλες ή δομημένες εργασίες χρειάζονται ξεχωριστό έλεγχο.

## Προβλήματα

- 401/403: κλειδί, έργο, χρέωση και δικαίωμα μοντέλου.
- 404: διεύθυνση και διαθεσιμότητα.
- ID πύλης απορρίπτεται: σωστό προφίλ/ID.
- Σφάλματα μεγάλων αιτημάτων: εξετάστε όρια πριν αυξήσετε επαναλήψεις.

## Πότε ταιριάζει

Για το εγγενές Messages API. Συγκρίνετε αποτελέσματα με δικές σας πηγές, όχι με καθολική κατάταξη παρόχων. Η δρομολόγηση ανά εργασία επιτρέπει στοχευμένη χρήση.
