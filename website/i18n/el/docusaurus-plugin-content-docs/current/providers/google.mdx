# Google

<TLDR>Το Google χρησιμοποιεί το εγγενές Gemini Generative Language. Ορίστε επιτρεπόμενο κλειδί και διαθέσιμο μοντέλο. Για Gemini μέσω συμβατής πύλης επιλέξτε το αντίστοιχο προφίλ.</TLDR>

## Προετοιμασία

Επιλέξτε **Google**, κλειδί, εγγενές endpoint και μοντέλο της επιλεγμένης έκδοσης API. Δοκιμάστε σύνδεση και σημείωση. Δεν ρυθμίζει αυτόματα οποιοδήποτε Google Cloud/Vertex deployment.

## Endpoint και ταυτοποίηση

| Πεδίο | Αρχική τιμή |
| ------- | -------------- |
| Μεταφορά | `google` |
| Κλειδί API | Απαιτείται |
| Βασική διεύθυνση | `https://generativelanguage.googleapis.com/v1` |
| Μοντέλο | `gemini-2.0-flash-exp` |
| Θερμοκρασία | `0.5` |
| Έλεγχος σύνδεσης | `chat-only` |

Δημιουργείται αίτημα `generateContent` με κλειδί. Ιστορικά ID δεν εγγυώνται πρόσβαση. Ελέγξτε διαγνωστικά URL πριν τα μοιραστείτε· μπορεί να περιέχουν διαπιστευτήρια.

## Μοντέλα

Χρησιμοποιήστε εύρεση μέσω του παρόχου και ελέγξτε παραγωγή στο επιλεγμένο API. Κενή λίστα μπορεί να σημαίνει δικαιώματα, endpoint ή απουσία μοντέλου. Ερευνήστε πριν αλλάξετε πρωτόκολλο.

## Προβλήματα

- 400: ID, παράμετροι και όρια εισόδου/εξόδου.
- 401/403: περιορισμοί κλειδιού, ενεργό API και δικαιώματα.
- 404: υπάρχει το μοντέλο στη συγκεκριμένη έκδοση API;
- Παραδείγματα πύλης: χρησιμοποιήστε κατάλληλο προφίλ OpenAI-compatible.

## Πότε ταιριάζει

Για εγγενές Gemini. Δοκιμάστε μετάφραση, έρευνα ή διαγράμματα στο δικό σας υλικό. Δεν δίνονται γενικές εγγυήσεις ταχύτητας, κόστους ή ποιότητας.
