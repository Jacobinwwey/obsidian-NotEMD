# OpenAI

<TLDR>Το προφίλ χρησιμοποιεί την κοινή υλοποίηση OpenAI Chat Completions. Επιλέξτε κλειδί και μοντέλο για αυτό το πρωτόκολλο. Το αρχικό μοντέλο δεν εγγυάται σημερινή πρόσβαση ή καθολική ποιότητα.</TLDR>

## Προετοιμασία

Για την επίσημη υπηρεσία χρησιμοποιήστε **OpenAI**, κλειδί και `https://api.openai.com/v1`. Μοντέλο σε λίστα μπορεί να χρειάζεται άλλο API. Οι πύλες έχουν δικά τους προφίλ/headers· το Azure χρησιμοποιεί **Azure OpenAI**, deployment και έκδοση API.

## Endpoint και ταυτοποίηση

| Πεδίο | Αρχική τιμή |
| ------- | -------------- |
| Μεταφορά | `openai-compatible` |
| Κλειδί API | Απαιτείται |
| Βασική διεύθυνση | `https://api.openai.com/v1` |
| Μοντέλο | `gpt-4o` |
| Θερμοκρασία | `0.5` |
| Έλεγχος σύνδεσης | `models-then-chat` |

Γνωστές μορφές URL κανονικοποιούνται πριν συντεθούν οι διαδρομές. Ξεκινήστε από το προφίλ και ελέγξτε την τελική διεύθυνση αντί να προσθέτετε τυχαία τμήματα.

## Μοντέλα

Το **Fetch models** παίρνει διαθέσιμα μοντέλα. Το **Test connection** μπορεί να περάσει μόνο με λίστα. Δοκιμάστε το ακριβές μοντέλο σε σημείωση. Reasoning, thinking, δειγματοληψία και προϋπολογισμοί πρέπει να συμφωνούν με προφίλ/μοντέλο.

## Προβλήματα

- 401/403: κλειδί, έργο, δικαιώματα και λογαριασμός.
- 404: endpoint, ID μοντέλου και υποστήριξη API.
- Λίστα λειτουργεί αλλά παραγωγή όχι: σφάλμα chat και παράμετροι.
- Μεγάλη απάντηση διακόπτεται: είσοδος, προϋπολογισμός και σώμα απάντησης· η σύντομη δοκιμή δεν το καλύπτει.

## Πότε ταιριάζει

Για άμεσα endpoints OpenAI με Chat Completions. Αξιολογήστε δικές σας σημειώσεις· τιμές και διαθεσιμότητα αλλάζουν ανεξάρτητα από Notemd.
