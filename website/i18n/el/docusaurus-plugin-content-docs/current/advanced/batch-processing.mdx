# Μαζική επεξεργασία

<TLDR>Οι ενέργειες φακέλων μοιράζονται επιλογή και πρόοδο, όχι κοινή πολιτική αντικατάστασης. Ο αρχικός παραλληλισμός είναι ένα. Δοκιμάστε μικρό φάκελο, ελέγξτε εύρος και προορισμούς και μετά επεκτείνετε.</TLDR>

## Επισκόπηση

Το πάνελ/εξερευνητής προσφέρει συνδέσμους, έννοιες, τίτλους, μετάφραση, πρωτότυπα αποσπάσματα, Mermaid και τύπους σε φακέλους. Γενική ενέργεια έρευνας φακέλου δεν υπάρχει· μπορεί να προστεθεί στην παραγωγή τίτλων. Η παρτίδα δεν είναι συναλλαγή φακέλου: έτοιμα αρχεία μένουν σε σφάλμα ή ακύρωση.

## Πώς λειτουργεί

### Μοντέλο εκτέλεσης

1. Επιλέξτε εργασία και φάκελο με τα επιθυμητά αρχεία.
2. Επεκτάσεις, επιλογή και ειδικά φίλτρα αποτελεσμάτων καθορίζουν υποψηφίους.
3. Η εργασία χρησιμοποιεί τον πάροχο/μοντέλο της και αναφέρει κατάσταση, σφάλματα και διαδρομές.
4. Ελέγξτε αναφορά και αρχεία μετά από τέλος/ακύρωση, πριν την επανάληψη.

Σύνδεσμοι, έννοιες, τίτλοι, πρωτότυπα αποσπάσματα, Mermaid και τύποι περιλαμβάνουν αρχικά υποφακέλους. **Η μετάφραση φακέλου περιλαμβάνει αρχικά μόνο άμεσα παιδιά.** Λειτουργία προγραμματιστή και προηγμένα προφίλ επιλογής μπορούν να αλλάξουν εύρος/φίλτρα. Ελέγξτε πραγματικές αντιστοιχίσεις.

### Αντικατάσταση

| Εργασία | Έλεγχος πριν από επανάληψη |
| ------ | ------------------------------------ |
| Σύνδεσμοι | Χωριστό αρχικό αποτέλεσμα· ελέγξτε επίθημα, φάκελο και μετακίνηση πηγής |
| Έννοιες | Ενεργοί σύνδεσμοι επιστροφής συμπληρώνουν υπάρχοντα· διπλότυπα χωριστά |
| Παραγωγή από τίτλους | Γράφει κατάλληλες πηγές και μετακινεί αν το complete είναι ελεύθερο |
| Μετάφραση | Υπάρχουσα μετάφραση μπορεί να αντικατασταθεί· αρχικά `_<language>.md` |
| Mermaid / τύποι | Τροποποιεί επιλεγμένες σημειώσεις· ελέγξτε και κρατήστε αντίγραφο |

Δεν υπάρχει γενική επιλογή παράλειψης/προσθήκης/αντικατάστασης. Κατειλημμένος στόχος complete μπλοκάρει τη μετακίνηση μετά την παραγωγή τίτλου, όχι την προηγούμενη παραγωγή. Παραγόμενα και μετακινημένα μετρώνται χωριστά.

### Παραλληλισμός

Κρατήστε `batchConcurrency: 1` μέχρι να πετύχει δείγμα. Ορισμένες διαδρομές απαιτούν και `enableBatchParallelism`· η μετάφραση φακέλου χρησιμοποιεί τον παραλληλισμό άμεσα. Περισσότερη ταυτόχρονη εργασία επιβαρύνει πάροχο, μνήμη και τοπικό διακομιστή χωρίς εγγύηση ταχύτητας. Διαστήματα αιτημάτων/ομάδων δεν αποτρέπουν όλα τα όρια ή άλλη χρήση του ίδιου λογαριασμού.

## Ρυθμίσεις

| Ρύθμιση | Αρχική τιμή | Επίδραση |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Ζητούμενος παραλληλισμός σε κατάλληλες διαδρομές |
| `enableBatchParallelism` | `false` | Ενεργοποίηση υποστηριζόμενου παράλληλου προγραμματισμού |
| `batchSize` | `50` | Μέγεθος ομάδας στην ομαδική εκτέλεση |
| `batchInterDelayMs` | `1000` | Παύση μεταξύ προγραμματισμένων ομάδων |
| `apiCallIntervalMs` | `500` | Διάστημα ταυτόχρονων αιτημάτων API |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Διατήρηση κανόνων υποφακέλων κάθε εργασίας |
| `enableStableApiCall` | `false` | Ρητή σταθερή λειτουργία αιτημάτων |

### Μοντέλα εργασιών

Οι φάκελοι ακολουθούν το μοντέλο της αντίστοιχης ενέργειας αρχείου. Ελέγξτε ιδιωτικές διαδρομές. Τοπικό πλαίσιο σε παρτίδα τίτλων χρησιμοποιεί ένα στιγμιότυπο από την αρχή· ενδιάμεσες αλλαγές δεν αναμειγνύονται σε επόμενες ανακτήσεις. Ξεκινήστε νέα παρτίδα για να τις συμπεριλάβετε.

## Παράδειγμα

Δημιουργήστε `trial-titles` με δύο σημειώσεις τίτλου. Εκτελέστε **Batch generate from titles** και ελέγξτε περιεχόμενο, γειτονικό `trial-titles_complete` και μετρήσεις παραγωγής/μετακίνησης/σφάλματος. Εξετάστε πρώτα το αποτυχημένο αρχείο. Επανάληψη του φακέλου πηγής δεν συνεχίζει αυτόματα ακριβώς τις εκκρεμότητες.

## Ακύρωση και ανάκτηση

Η ακύρωση σταματά νέα προγραμματισμένη εργασία και υποστηριζόμενα αιτήματα. Εξωτερικά συστήματα μπορεί να ολοκληρώσουν αποδεκτές κλήσεις/εγγραφές· τη χρέωση την ορίζει ο πάροχος. Περιμένετε, συγκρίνετε ολοκληρωμένα αρχεία με διαδρομές ανάκτησης/σύγκρουσης και καθαρίστε μετά τον έλεγχο.

## Συμβουλές

- Ελέγξτε την πραγματική επιλογή του προφίλ.
- Μειώστε παραλληλισμό και εξετάστε όρια σε 429.
- Διαχωρίστε ακυρωμένο, αποτυχημένο και ολοκληρωμένο.
- Διατηρήστε αμετάβλητο δείγμα και backup.
