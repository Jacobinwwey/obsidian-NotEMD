# Προσαρμοσμένες οδηγίες

<TLDR>Μη κενή δική σας οδηγία αντικαθιστά την ενσωματωμένη όταν είναι ενεργοί ο γενικός και ο ειδικός διακόπτης. Διατηρήστε τη σύμβαση εξόδου: το σύστημα προτύπων δεν επαναφέρει αυτόματα κανόνες μορφής που παραλείψατε.</TLDR>

## Επισκόπηση

Δοκιμάστε πρώτα την προεπιλογή σε αντιπροσωπευτική σημείωση. Πεδίο ή κανόνας συνωνύμων μπορεί να αρκεί. Αλλάξτε πολιτική, δομή ή ύφος μετάφρασης όταν χρειάζεται και συγκρίνετε πριν από παρτίδες.

## Πώς λειτουργεί

### Σύνθεση

Το Notemd επιλέγει ενσωματωμένη/δική σας οδηγία, προσθέτει κατάλληλους κανόνες πεδίου/γλώσσας και συμπληρώνει μεταβλητές της εργασίας. Το κείμενο σημείωσης μπορεί να σταλεί χωριστά. Οι μεταβλητές δεν είναι καθολικές. Μια αντικατάσταση μπορεί να ξεχάσει `CONCEPT:` ή ερευνητικό πλαίσιο· έγκυρο αίτημα δεν αποδεικνύει αναλύσιμη ή τεκμηριωμένη απάντηση.

### Μεταβλητές

Χρησιμοποιήστε ακριβή πεζά/κεφαλαία και μονά άγκιστρα:

| Εργασία | Διαθέσιμες μεταβλητές |
| ------ | ----------------------- |
| Παραγωγή τίτλων | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Σύνοψη έρευνας | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Μετάφραση | `{LANGUAGE}`, `{TEXT}` |
| Πρωτότυπα αποσπάσματα | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

Το `{LANGUAGE}` ακολουθεί την πολιτική της εργασίας. Σύνδεσμοι και αυτόνομες έννοιες στέλνουν κείμενο ως περιεχόμενο εργασίας· μην επινοείτε άλλες θέσεις μεταβλητών. Άγνωστα ονόματα δεν συμπληρώνονται. Αυτές είναι αντικαταστάσεις οδηγίας, όχι πρότυπα αρχείων εννοιών.

### Εστίαση πεδίου

Ενεργοποιήστε εστιασμένη μάθηση και δώστε π.χ. `ηλεκτροτεχνία`. Το `Relevant Fields` κατευθύνει την προσοχή χωρίς αυστηρό φίλτρο ή απόδειξη αποκλεισμού άλλου περιεχομένου.

## Ρυθμίσεις

| Εργασία | Διακόπτης | Πεδίο οδηγίας |
| ------ | --------------- | -------------- |
| Σύνδεσμοι | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Τίτλοι | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Έρευνα | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Σύνοψη Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Έννοιες | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Μετάφραση | `useCustomPromptForTranslate` | `translatePrompt` |
| Πρωτότυπο κείμενο | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Όλες απαιτούν `enableGlobalCustomPrompts`. Κενό κείμενο χρησιμοποιεί την ενσωματωμένη οδηγία. Ο ενοποιημένος εντοπισμός πρωτότυπου κειμένου έχει δική του σταθερή μορφή όπου η κοινή αντικατάσταση δεν ισχύει. Η παραγωγή διαγράμματος απαιτεί τυποποιημένη έξοδο· η οδηγία Mermaid δεν είναι καθολική.

## Παράδειγμα

Ενεργοποιήστε γενικό διακόπτη και διακόπτη εννοιών, κρατώντας τη σήμανση του αναλυτή:

```text
Εντόπισε τις σημαντικότερες έννοιες ηλεκτροτεχνίας στη σημείωση.
Προτίμησε συγκεκριμένα εξαρτήματα και φυσικούς μηχανισμούς αντί γενικών ουσιαστικών.
Γράψε κάθε έννοια σε ξεχωριστή γραμμή ακριβώς έτσι:
CONCEPT: Όνομα έννοιας
Μην προσθέτεις εξηγήσεις ή εξωτερικό μπλοκ κώδικα.
```

Σε αντίγραφο συγκρίνετε γραμμές, ονόματα αρχείων και ελλείπουσες έννοιες με την προεπιλογή. Κρατήστε την προηγούμενη οδηγία για επιστροφή.

## Συμβουλές

- Ελέγξτε μία εργασία πριν αυξήσετε την παρτίδα.
- Κρατήστε ερευνητικές πηγές και ακριβή παραθέματα.
- Μεταφράστε οδηγίες με αμετάβλητα ID και δείκτες.
- Επαναλάβετε δοκιμή μετά από αλλαγή μοντέλου· οδηγίες δεν υποκαθιστούν επικύρωση.
