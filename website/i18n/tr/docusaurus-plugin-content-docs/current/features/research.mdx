# Araştırma ve web araması

<TLDR>Research & summarize seçili metin veya not başlığından arama yapar, mevcut bağlamı LLM ile özetler ve etkin Markdown’a ekler. Tavily veya DuckDuckGo’yu açıkça seçin; kaynak bağlantılarını doğrulayın.</TLDR>

## Genel bakış

Arama sağlayıcısı ve özet modeli ayrıdır. Tavily anahtar ister; DuckDuckGo anahtarsızdır ancak ağ kullanır ve sınırlanabilir. Yerel model, web araştırmasını çevrimdışı yapmaz.

## Nasıl çalışır

### Arama ve özetleme

1. Hedef notu Markdown düzenleyicisinde açın, konu seçin veya başlığı kullanın.
2. **Araştır ve özetle** çalıştırın.
3. Tavily parçalar verir; DuckDuckGo sonuç sayfalarını alabilir.
4. İzin verilmiş yerel bağlam seçili kapsamdan eklenebilir.
5. Model, konu ve kaynak türüyle `Research Summary` altında özet yazar.
6. İlgili URL’leri açıp iddiaları kontrol edin. Alınan bağlam her üretilen alıntıyı kanıtlamaz.

### Tavily veya DuckDuckGo

| Seçim | Hazırlık | İşletim sınırı |
| -------- | ------- | ---------------------- |
| Tavily | Tavily seçip anahtar girin | Hesap kotaları ve dönen metin parçaları |
| DuckDuckGo | DuckDuckGo’yu açıkça seçin | Anahtar yok; arama sınırları ve sayfa erişimi |

Boş veya yanlış Tavily anahtarı otomatik geçiş yapmaz. Web bağlamı azsa raporu okuyun. Etkin yerel parçalar yine özeti destekleyebilir; kaynak etiketi bunu web kaynaklı içerikten ayırır.

### Başlık üretiminde araştırma

**Enable research in "Generate from title"** toplu biçim dahil araştırma ekler ve başlangıçta kapalıdır. Desteklenen klasör yolu budur; bağımsız genel Research Folder işlemi yoktur.

## Ayarlar

| Ayar | Başlangıç | Etkisi |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Arama arka ucu |
| `tavilyApiKey` | `''` | Tavily anahtarı |
| `tavilyMaxResults` | `5` | İstenen Tavily sonuç sayısı |
| `tavilySearchDepth` | `basic` | Tavily arama derinliği |
| `ddgMaxResults` | `5` | İstenen DuckDuckGo sonuç sayısı |
| `ddgFetchTimeout` | `15` | Sonuç sayfaları için saniye cinsinden zaman aşımı |
| `maxResearchContentTokens` | `3000` | Yaklaşık web bağlamı bütçesi |
| `researchProvider` | `DeepSeek` | Görev rotaları etkinken özet sağlayıcısı |
| `researchModel` | `''` | Boşsa sağlayıcının modeli |
| `researchSummarizeLanguage` | `en` | Göreve özel çıktı dili |
| `enableResearchInGenerateContent` | `false` | Başlık üretiminde araştırmaya izin |
| `enableLocalKnowledgeRetrieval` | `false` | Yerel aramayı ayrıca açma |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Bu görevde yerel arama |

### Bağlam ve model

Bağlam sınırları tahmindir; sağlayıcının tam token ölçümü değildir. Kırpma kanıtı silebilir. Soruyu daraltıp model/çıktı bütçesini ayarlayın. Yerel indeks sözcükseldir; gizli embedding veya tam geri getirme garantisi yoktur.

## Örnek

`Göreli konum kodlama` notunu oluşturup araştırın ve açıklamayı özgün yayınlar veya resmî belgelerle karşılaştırın. Soru, gerçek URL’ler ve düzeltmeleri saklayın. Örnek, kasanız için önceden yapılmış bir arama değildir.

## İptal ve gizlilik

Tamamlanan eklemeler kalır. Kabul edilmiş model/sayfa isteği bitebilir. Arama hizmeti sorguyu, siteler istekleri, LLM ise izinli yerel parçalar dahil toplanan bağlamı alır. Tanılamayı paylaşmadan inceleyin.

## İpuçları

- Web kaynağı, yerel not ve model çıkarımını ayırın.
- Alıntı, tarih ve önemli iddiaları özgün kaynaktan doğrulayın.
- Arama ve LLM’yi küçük soruyla ayrı test edin.
- Yinelenen eklemelerden kaçınmak için mevcut özetleri okuyun.
