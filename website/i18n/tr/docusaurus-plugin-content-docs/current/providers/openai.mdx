# OpenAI

<TLDR>Bu profil ortak OpenAI Chat Completions yürütme yolunu kullanır. Bu protokole uygun anahtar ve model seçin. Başlangıç modeli, güncel erişim veya genel kalite garantisi değildir.</TLDR>

## Hazırlık

Resmî hizmet için **OpenAI**, anahtar ve `https://api.openai.com/v1` kullanın. Listelenen bir model başka API isteyebilir. Geçitlerin kendi profilleri/başlıkları vardır; Azure, **Azure OpenAI**, deployment ve API sürümü kullanır.

## Uç nokta ve kimlik doğrulama

| Alan | Başlangıç |
| ------- | -------------- |
| Aktarım | `openai-compatible` |
| API anahtarı | Gerekli |
| Temel URL | `https://api.openai.com/v1` |
| Model | `gpt-4o` |
| Sıcaklık | `0.5` |
| Bağlantı testi | `models-then-chat` |

Bilinen URL biçimleri yollar kurulmadan önce normalleştirilir. Rastgele yol parçaları eklemek yerine profilden başlayıp çözümlenen adresi kontrol edin.

## Modeller

**Fetch models** erişilebilir modelleri alır. **Bağlantıyı test et** yalnız listeyle başarılı olabilir. Tam modeli bir notla deneyin. Reasoning, thinking, örnekleme ve bütçeler profil/modelle uyumlu olmalıdır.

## Sorunlar

- 401/403: anahtar, proje, yetki ve hesap.
- 404: uç nokta, model kimliği ve API desteği.
- Liste çalışır ama üretim çalışmaz: sohbet hatası ve parametreler.
- Uzun yanıt kesilir: girdi, bütçe ve yanıt; kısa test bunu kapsamaz.

## Ne zaman seçilmeli

Chat Completions destekleyen doğrudan OpenAI uç noktaları için. Kendi notlarınızı değerlendirin; fiyatlar ve erişim Notemd’den bağımsız değişir.
