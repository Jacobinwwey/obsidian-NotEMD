# Anthropic

<TLDR>Profili doğrudan Messages protokolü için kullanın. OpenAI uyumlu geçit üzerinden Claude için geçit profili gerekir. Tarihsel başlangıç modeli, erişilebilir bir modelle değiştirilmek zorunda olabilir.</TLDR>

## Hazırlık

**Anthropic**, anahtar ve erişebildiğiniz modeli seçin. Kurulumunuz aynı protokolü sunmadıkça sağlayıcının API URL’sini koruyun. Bağlantıyı ve notu test edin.

## Uç nokta ve kimlik doğrulama

| Alan | Başlangıç |
| ------- | -------------- |
| Aktarım | `anthropic` |
| API anahtarı | Gerekli |
| Temel URL | `https://api.anthropic.com` |
| Model | `claude-3-5-sonnet-20240620` |
| Sıcaklık | `0.5` |
| Bağlantı testi | `chat-only` |

Çalışma yolu, kendine özgü anahtar/sürüm başlıklarıyla `/v1/messages` kullanır. OpenAI sohbet yolu eklemeyin. Başlangıç değerleri depo yapılandırmasını açıklar, güncel model erişimini değil.

## Modeller

İzin verilen yerde doğrudan model keşfini kullanın. Liste kısıtlıysa yetkili kimliği girip üretimi deneyin. Uzun ve yapılandırılmış görevler ayrı kontrol ister.

## Sorunlar

- 401/403: anahtar, proje, ücretlendirme ve model yetkisi.
- 404: adres ve erişim.
- Geçit kimliği reddedilir: doğru profil/kimliği seçin.
- Uzun istekler başarısız: tekrarı artırmadan sınırları inceleyin.

## Ne zaman seçilmeli

Doğrudan Messages uç noktaları için. Evrensel sağlayıcı sıralaması yerine kendi kaynaklarınızla karşılaştırın. Görev rotaları belirli kullanım sağlar.
