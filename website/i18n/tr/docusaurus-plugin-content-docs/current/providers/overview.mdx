### Çin sağlayıcıları

[Bölgesel yapılandırmaya](./china) bakın. Kategori, coğrafi erişim veya Çince kalitesi garantisi değildir. Hesap bölgesi, uç nokta ve model yetkilerini eşleştirin.

## Göreve göre seçim

`useMultiModelSettings` ayrı sağlayıcı/model ayarlarını açar; aksi halde `activeProvider` kullanılır. Boş model alanı sağlayıcının modeline döner. Geçersiz kayıtlı sağlayıcı seçimleri yüklenirken etkin sağlayıcıyla uzlaştırılır.

| Görev | Sağlayıcı ayarı | Model alanı |
| ------ | ------------------ | ---------------- |
| Bağlantılar | `addLinksProvider` | `addLinksModel` |
| Başlık üretimi | `generateTitleProvider` | `generateTitleModel` |
| Araştırma özeti | `researchProvider` | `researchModel` |
| Çeviri | `translateProvider` | `translateModel` |
| Kavramlar | `extractConceptsProvider` | `extractConceptsModel` |
| Mermaid özeti | `summarizeToMermaidProvider` | `summarizeToMermaidModel` |
| Özgün metin | `extractOriginalTextProvider` | `extractOriginalTextModel` |

Etkin ve kayıtlı görev sağlayıcıları başlangıçta DeepSeek’tir. Yalnız etkin sağlayıcıyı değiştirmek açık görev rotalarını değiştirmez. Özel içerikten önce bunları kontrol edin.

## İstek mimarisi

### Aktarım katmanları

Notemd Obsidian isteklerini ve protokolün farkında olan fallback’i kullanır. Masaüstü Node HTTP akışlarını, diğer ortamlar fetch kullanabilir. OpenAI uyumlu geçidin arkasındaki Claude, Anthropic’in kendi API profilini değil geçit profilini kullanır.

### Tekrar denemeler

Kararlı mod kapalıdır; uygulanabilir varsayılanlar beş saniye arayla üç tekrardır. Geçici hatalar ortak fallback/tekrar yolundan geçebilir. Yetki ve model yapılandırması düzeltilmelidir. Uzun istekler yine zaman aşımı, sınır veya kotaya takılabilir.

### Yanıt önbelleği

Sınırlı bellek önbelleği başarılı yanıtları tekrar kullanabilir. Kimliğe uç nokta, model, üretim parametreleri, istem ve içerik katılır. Kalıcı depolama veya maliyet sayacı değildir; ücretsiz tekrar garantisi vermez.

### Akıl yürüten modeller

Reasoning/thinking profil ve model kurallarını izler. Protokole özgü parametreleri hizmetler arasında kopyalamayın. Gerçek görevi deneyin; model token, örnekleme veya akıl yürütme ayarlarını reddedebilir.

### Token tahmini

Metin uzunluğu ve çıktı sınırları sağlayıcının tam token sayıları değildir. Ücret değerlendirmesinde gerçek kullanım verisini esas alın. Evrensel maliyet hesabı yoktur.

## Modelleri bulma

**Fetch models** destekleyen profillerde çalışır. Bazı kurulumlarda ad elle girilmelidir. Listeleme ve üretim yetkileri ayrıdır. `models-then-chat` için **Bağlantıyı test et** yalnız listeyle geçebilir; `chat-only` kısa üretim yapar. Gerçek görevi ve çıktı biçimini kontrol edin.

- Anthropic ve Google kendi API’leriyle model keşfi yapar.
- Ollama indirilmiş etiketleri, LM Studio sunucu modellerini gösterir.
- Azure deployment ve API sürümü ister.
- Geçitler listeyi sınırlayıp açık model kimliğiyle isteğe izin verebilir.

## Başlangıç

1. **Settings → Notemd** içinde doğru profili seçin.
2. Uç nokta, anahtar ve erişilebilir model/deployment girin.
3. Bağlantıyı ve deneme notunu test edin.
4. Toplu işlem veya görev rotalarını açmadan çıktıyı ve raporu inceleyin.

Yerel model/sunucu hazır olmalıdır. Ollama anahtar istemez; LM Studio anahtarı isteğe bağlıdır ve `EMPTY` ile başlar. Gerektiğinde gerçek token girin. Yerel LLM, web aramasını çevrimdışı yapmaz.
