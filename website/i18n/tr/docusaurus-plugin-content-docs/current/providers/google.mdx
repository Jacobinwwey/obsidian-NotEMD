# Google

<TLDR>Google, doğrudan Gemini Generative Language kullanır. Yetkili anahtar ve erişilebilir model girin. Uyumlu bir geçitteki Gemini için geçit profilini seçin.</TLDR>

## Hazırlık

**Google**, anahtar, doğrudan uç nokta ve seçili API sürümündeki modeli kullanın. Bağlantıyı ve notu test edin. Bu, rastgele Google Cloud/Vertex kurulumunu otomatik ayarlamaz.

## Uç nokta ve kimlik doğrulama

| Alan | Başlangıç |
| ------- | -------------- |
| Aktarım | `google` |
| API anahtarı | Gerekli |
| Temel URL | `https://generativelanguage.googleapis.com/v1` |
| Model | `gemini-2.0-flash-exp` |
| Sıcaklık | `0.5` |
| Bağlantı testi | `chat-only` |

Anahtarla `generateContent` isteği yapılır. Eski kimlikler erişim garantisi değildir. Tanılama URL’lerini paylaşmadan kontrol edin; kimlik bilgileri içerebilir.

## Modeller

Doğrudan keşfi kullanın ve seçili API’de üretimi doğrulayın. Boş liste yetki, uç nokta veya eksik modelden kaynaklanabilir. Protokol değiştirmeden nedeni araştırın.

## Sorunlar

- 400: kimlik, parametreler ve girdi/çıktı sınırları.
- 401/403: anahtar kısıtları, açık API ve yetkiler.
- 404: model bu API sürümünde var mı?
- Geçit örnekleri: doğru OpenAI uyumlu profili kullanın.

## Ne zaman seçilmeli

Doğrudan Gemini için. Çeviri, araştırma veya diyagramı kendi malzemenizle test edin. Genel hız, fiyat veya kalite garantisi yoktur.
