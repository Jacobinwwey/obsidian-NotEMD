# Proveedores chinos

<TLDR>
Elige el perfil de tu cuenta y despliegue. Regiones, rutas, modelos y permisos no son intercambiables aunque compartan protocolo compatible OpenAI. Valida una tarea pequeña antes de adoptarlo.
</TLDR>

## Configuración

Obtén cuenta y clave API, selecciona perfil y confirma región y derechos del modelo. Prueba conexión y nota; los valores iniciales no garantizan disponibilidad actual.

## Modelos

Usa listado cuando se permita. Huawei Cloud MaaS conoce el despliegue; otros perfiles tienen descubrimiento compatible OpenAI donde se admite. Sin permisos de lista puede seguir funcionando un modelo explícito.

El test también varía: DeepSeek puede aprobar solo con la lista; varios perfiles regionales prueban chat breve. La tarea real sigue necesaria para validar prompt y salida.

## Problemas

- Clave aceptada, generación denegada: derechos, despliegue y región.
- Ark rechaza ID: comprobar si espera endpoint o modelo.
- Razonamiento truncado: límites y ajustes thinking específicos.
- Error de red: verificar endpoint desde dispositivo Obsidian y leer error de transporte.

## Cuándo usarlo

Decide según acceso real, tratamiento de datos y salida medida. Región o marca no garantizan calidad, privacidad ni precio. La [vista general](./overview) incluye pasarelas y servidores locales.
