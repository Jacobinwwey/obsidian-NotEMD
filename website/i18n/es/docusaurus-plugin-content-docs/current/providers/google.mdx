# Proveedor Google

<TLDR>
El perfil Google usa Gemini Generative Language nativo. Introduce una clave autorizada y un modelo disponible. Gemini mediante una pasarela OpenAI-compatible usa el perfil de la pasarela.
</TLDR>

## Configuración

Elige **Google**, clave, endpoint nativo y modelo compatible con su versión API. Prueba conexión y una nota. No configura automáticamente cualquier despliegue Google Cloud o Vertex.

## Endpoint y autenticación

| Campo | Valor inicial |
| ------- | -------------- |
| Transporte | `google` |
| Clave API | Obligatoria |
| URL base | `https://generativelanguage.googleapis.com/v1` |
| Modelo | `gemini-2.0-flash-exp` |
| Temperatura | `0.5` |
| Prueba de conexión | `chat-only` |

La implementación construye `generateContent` con autenticación de clave. El ID histórico no garantiza disponibilidad. Revisa URL antes de compartir diagnósticos: los detalles pueden incluir autenticación.

## Modelos

Usa descubrimiento nativo y confirma generación con la versión API. Una lista vacía puede significar permisos, endpoint o modelo ausente; no cambies protocolos sin diagnosticar.

## Problemas

- `400`: ID, parámetros y límites de tokens/salida.
- `401`/`403`: restricciones de clave, API habilitada y derechos.
- `404`: disponibilidad del modelo en esa versión API.
- Ejemplos de pasarela: usar perfil OpenAI-compatible correspondiente.

## Cuándo usarlo

Para Gemini nativo. Evalúa traducción, investigación o diagramas con una muestra propia; no se promete ventaja universal de velocidad, coste o calidad.
