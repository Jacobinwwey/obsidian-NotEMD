# Proveedor OpenAI

<TLDR>
El perfil utiliza la implementación compartida compatible con OpenAI Chat Completions. Configura clave y modelo que acepte ese protocolo. El modelo predeterminado no garantiza acceso actual ni es recomendación universal.
</TLDR>

## Configuración

Selecciona **OpenAI**, introduce clave y conserva `https://api.openai.com/v1` para el servicio oficial. Aparecer en la lista no hace compatible un modelo disponible solo mediante otra API.

Para una pasarela utiliza su perfil y encabezados. Azure usa **Azure OpenAI** con despliegue y versión API.

## Endpoint y autenticación

| Campo | Valor inicial |
| ------- | -------------- |
| Transporte | `openai-compatible` |
| Clave API | Obligatoria |
| URL base | `https://api.openai.com/v1` |
| Modelo | `gpt-4o` |
| Temperatura | `0.5` |
| Prueba de conexión | `models-then-chat` |

Se normalizan formas conocidas de URL antes de construir rutas de modelos/chat. Parte de la dirección inicial y examina la ruta resuelta, sin añadir segmentos al azar.

## Modelos

**Fetch models** consulta el endpoint. **Probar conexión** puede aprobar solo por la lista. Ejecuta después una nota con el proveedor/modelo exactos.

Reasoning, thinking, muestreo y límites siguen reglas del perfil y modelo. Un modelo listado no acepta necesariamente todos los parámetros.

## Problemas

- `401`/`403`: clave, proyecto, permisos de modelo y cuenta.
- `404`: dirección, ID y API compatible.
- Lista correcta pero tarea fallida: revisar error chat y ajustes.
- Respuesta larga truncada: presupuesto, entrada y error real; una prueba corta no cubre todo.

## Cuándo usarlo

Para modelos OpenAI directos compatibles con Chat Completions. Evalúa tus notas. Precios y disponibilidad pueden cambiar sin una versión de Notemd.
