# Proveedor Anthropic

<TLDR>
Usa este perfil para Messages nativo. Claude servido por una pasarela compatible OpenAI utiliza el perfil de esa pasarela. Comprueba un modelo disponible; el valor histórico puede necesitar sustitución.
</TLDR>

## Configuración

Selecciona **Anthropic**, introduce clave y modelo accesible. Conserva endpoint nativo salvo despliegue que exponga el mismo protocolo. Prueba conexión y tarea en una nota desechable.

## Endpoint y autenticación

| Campo | Valor inicial |
| ------- | -------------- |
| Transporte | `anthropic` |
| Clave API | Obligatoria |
| URL base | `https://api.anthropic.com` |
| Modelo | `claude-3-5-sonnet-20240620` |
| Temperatura | `0.5` |
| Prueba de conexión | `chat-only` |

Se usa `/v1/messages` con encabezados nativos de clave y versión. No introduzcas una ruta OpenAI chat. El modelo predeterminado refleja el repositorio, no disponibilidad actual garantizada.

## Modelos

Descubrimiento mediante ruta nativa cuando está disponible. Si la lista está restringida, introduce ID autorizado y usa la prueba chat. Valida por separado tareas largas y estructuradas.

## Problemas

- `401`/`403`: clave, espacio/proyecto, facturación y derechos.
- `404`: endpoint y disponibilidad actual.
- ID de pasarela rechazado: usar su perfil y formato.
- Fallos largos: revisar límites y errores antes de más reintentos.

## Cuándo usarlo

Para endpoints Anthropic Messages. Compara resultados con tus fuentes, sin tratar proveedores como clasificación universal. Las rutas por tarea permiten uso específico.
