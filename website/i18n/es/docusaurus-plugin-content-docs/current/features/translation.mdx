# Traducción

<TLDR>
Notemd traduce el archivo activo o los archivos aptos de una carpeta. Por defecto escribe otro archivo con sufijo lingüístico. Calidad y cobertura dependen del modelo; los 21 idiomas de interfaz y 34 del sitio no garantizan traducciones.
</TLDR>

## Visión general

Elige idioma y proveedor antes de ejecutar. Prueba una copia con terminología, enlaces y código. Esta función usa tu LLM, no una integración específica con Google Translate.

Las acciones operan sobre archivos y carpetas. Copia un pasaje a una nota temporal si solo quieres ese texto. Una selección no limita **Traducir archivo actual**.

## Funcionamiento

### Comando

1. Elige idioma de salida; inglés predeterminado, independiente de la interfaz.
2. Abre la fuente y ejecuta **Traducir archivo actual**.
3. Se dividen entradas largas y se reúnen las traducciones.
4. Abre el destino anunciado y comprueba significado, términos, citas, enlaces y código.

`Example.md` a francés produce `Example_fr.md` junto a la fuente conservada. Un destino igual se sobrescribe. No hay anexado a la fuente por defecto ni encabezado `Translation` garantizado.

### Pares lingüísticos

El modelo infiere el idioma fuente. Una opción del menú no acredita precisión. Prueba textos mixtos y términos; la fragmentación puede perder contexto.

### Modelo por tarea

Activa modelos específicos para `translateProvider` y `translateModel`; en otro caso se usa el proveedor activo. Un servidor local necesita modelo preparado; la nube recibe prompt y texto. Evalúa una muestra de tu dominio, no una clasificación genérica.

### Carpetas

**Traducir carpeta por lotes** incluye solo hijos directos por defecto; perfiles avanzados pueden cambiarlo. Fuentes homónimas enviadas a un destino común pueden colisionar. Revisa rutas y traducciones existentes.

## Ajustes

| Ajuste | Predeterminado | Efecto |
| --------- | --------- | -------- |
| `language` | `en` | Idioma destino seleccionado |
| `translateProvider` | `DeepSeek` | Proveedor con ruta por tarea |
| `translateModel` | `''` | Modelo del proveedor si vacío |
| `useCustomTranslationSuffix` | `false` | Sufijo lingüístico predeterminado |
| `translationCustomSuffix` | `_translated` | Sufijo personalizado cuando se activa |
| `useCustomTranslationSavePath` | `false` | Guardar junto a la fuente por defecto |
| `translationSavePath` | `''` | Carpeta destino relativa al almacén |
| `batchConcurrency` | `1` | Concurrencia solicitada de traducción por carpeta |

Si no se puede crear la carpeta personalizada, puede usarse la fuente como destino alternativo; comprueba la ruta real. Un sufijo personalizado vacío puede apuntar al original: usa uno distinto para una traducción separada.

## Ejemplo

Elige inglés y traduce una pequeña nota china de prueba. Compara `_en.md` con la fuente: términos, números, fórmulas y enlaces antes de ampliar al lote.

## Cancelación y revisión

Cancelar detiene trabajo posterior compatible, sin deshacer traducciones escritas ni garantizar fin de facturación. Revisa informe y archivos. Pedir conservar Markdown no garantiza equivalencia semántica ni validación sintáctica.

## Consejos

- Respaldar fuente y revisar colisiones.
- Usar sufijo y carpeta distintos durante pruebas.
- Revisar identificadores, matemáticas, URL y nombres propios.
- Expurgar diagnósticos antes de compartir.
