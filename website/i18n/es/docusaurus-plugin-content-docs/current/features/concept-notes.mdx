# Notas de conceptos

<TLDR>
La extracción independiente lee la fuente y crea conceptos Markdown en una carpeta elegida, inicialmente vacía en los ajustes. Las notas nuevas solo tienen título y no llevan backlinks por defecto. Añadir enlaces utiliza otra plantilla.
</TLDR>

## Visión general

Configura **Ruta de la carpeta de notas de concepto** antes de extraer. Una carpeta dedicada facilita revisión, duplicados y generación posterior. Extraer no completa cada concepto con una explicación investigada.

## Funcionamiento

### Extracción

El LLM recibe el texto; se analizan entradas `CONCEPT:`, se deduplican nombres dentro de la operación y se crean/actualizan archivos. Las notas largas se dividen. Consulta fallos parciales: el modelo no entrega un inventario exhaustivo garantizado.

### Prompt

El prompt integrado pide conceptos específicos del tema. Aprendizaje focalizado y reducción de sinónimos orientan sin garantizar vocabulario canónico. Un prompt propio debe conservar `CONCEPT: Term`. Véase [prompts](../advanced/custom-prompts).

### Fragmentación

`chunkWordCount` vale 3000 palabras aproximadas, no tokens del proveedor. El contexto entre fragmentos es limitado; revisa conceptos relacionados y nombres ambiguos.

## Creación de archivos

### Nombres

Se retiran caracteres de ruta no admitidos, se normalizan espacios y se truncan nombres largos. Los vacíos se omiten. Frases distintas pueden coincidir en el mismo nombre de archivo; compruébalo antes de una colección grande.

### Plantillas

Forma mínima predeterminada:

```markdown
# Nombre del concepto
```

Para backlinks en nuevas notas independientes, activa **Add "Linked From" backlink** y desactiva **Create minimal concept notes**:

```markdown
# Nombre del concepto

## Linked From
- [[Nota fuente]]
```

Añadir enlaces usa la forma completa cuando la salida conceptual está habilitada. Las opciones de extracción independiente no cambian ese comportamiento.

### Notas existentes

Con backlinks activos, puede añadirse el vínculo fuente que falta bajo `## Linked From`. Se conserva el cuerpo y no se repite el mismo vínculo. La fuente se referencia por basename; revisa nombres idénticos en distintas carpetas.

### Ajustes

| Ajuste | Predeterminado | Efecto |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Permitir conceptos tras elegir carpeta |
| `conceptNoteFolder` | `''` | Ninguna carpeta inicial |
| `extractConceptsMinimalTemplate` | `true` | Notas independientes solo con título |
| `extractConceptsAddBacklink` | `false` | Backlinks en extracción independiente |
| `extractConceptsProvider` | `DeepSeek` | Proveedor con rutas por tarea |
| `extractConceptsModel` | `''` | Usar modelo del proveedor si está vacío |
| `extractConceptsLanguage` | `en` | Idioma con opciones por tarea activas |
| `replaceSynonymsDuringConceptExtraction` | `false` | Añadir instrucción contra sinónimos |
| `generateConceptLogFile` | `false` | Generar registro conceptual opcional |

## Duplicados

Se aplican heurísticas de nombres: mayúsculas, plurales, normalización de símbolos e inclusión de una palabra según alcance. No prueban equivalencia semántica; revisa plurales irregulares y sentidos técnicos distintos.

En **Comprobar y eliminar duplicados**, inspecciona candidatos y confirma solo los archivos deseados. Se utiliza la papelera de Obsidian. La carpeta conceptual no es una caché desechable; respáldala antes de limpiar.

### Alcances

Puedes comparar con el almacén, la propia carpeta, carpetas incluidas o un ámbito con exclusiones. Verifica antes de confirmar. El alcance cambia candidatos, no la definición de duplicado.

## Uso

### Extracción independiente

Abre Markdown, confirma carpeta y ejecuta **Extraer conceptos (archivo actual)**. La fuente permanece. Revisa nombres, cobertura y backlinks.

### Extraer y generar contenido

**Generación por lotes desde títulos** puede completar notas nuevas y previas aptas. Examina la carpeta antes y el destino complete anunciado después.

### Enlace desde selección

La acción de selección puede enlazar el término elegido y crear su nota con destino configurado. Así eliges el término en lugar de solicitar extracción del archivo completo.

## Consejos

- Fuente pequeña y carpeta dedicada.
- Elegir idioma antes de ampliar.
- Revisar sinónimos y duplicados por separado.
- Guardar registros necesarios antes de otra ejecución que los sobrescriba.
