# Diagramas

<TLDR>
Elige tipo de diagrama y después formato fuente editable. Revisa el resultado completo en Obsidian, incluido Drawnix con Mermaid integrado. Exporta cada panel como SVG, PNG o PDF.
</TLDR>

## Tres decisiones distintas

| Elección | Qué controla | Ejemplos |
| --- | --- | --- |
| Tipo de diagrama | Significado del diagrama | Flujo, secuencia, circuito, gráfico de datos |
| Formato fuente | Archivo editable o reutilizable creado | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Formato de exportación | Imagen o documento para compartir | SVG, PNG, PDF |

Draw.io y Drawnix son **formatos fuente**, no tipos de diagrama. CircuitikZ es fuente para circuitos y no limita la exportación visual a SVG.

## Elegir fuente

| Formato | Uso | Archivo fuente |
| --- | --- | --- |
| Mermaid | Diagramas dentro de Markdown | Bloque de código Mermaid |
| JSON Canvas | Canvas nativo de Obsidian | `.canvas` |
| Draw.io | Edición en diagrams.net o compatibles | `.drawio` |
| Drawnix | Estilo de pizarra o dibujo manual | `.drawnix` |
| CircuitikZ | Circuitos eléctricos y de transistores estructurados | `.tex` |

Mantén **Preferred source format: Auto** si no necesitas un editor concreto. Notemd selecciona un formato compatible.

## Generar y exportar

1. Abre una nota admitida. Para un pasaje, usa otra nota; seleccionar texto no limita una acción de archivo.
2. Elige tipo o **Auto-detect**.
3. Elige fuente o **Auto**; Drawnix para mapas compatibles con nodos editables y Mermaid integrado.
4. Ejecuta **Generar diagrama**.
5. Revisa todos los paneles en orden de origen dentro del contenedor vertical; Mermaid usa su altura renderizada sin recortes.
6. Usa **Exportar SVG**, **Exportar PNG** o **Export PDF** por panel o exportación superior para todos. Elige carpeta fuente o relativa al almacén. Se escribe un archivo determinista por panel y se continúa ante fallos individuales.
7. **Guardar archivo fuente** guarda el artefacto editable.

El menú y cada cabecera ofrecen exportación individual, sin exigir una imagen única opaca para vistas grandes.

**History** abre el panel del historial sin ocultar el diagrama. Busca, filtra y abre vistas o archivos. También está en paleta y barra lateral sin nota activa.

SVG y PDF parten de geometría vectorial; PDF conserva disposición y métricas SVG. PPI solo afecta PNG: 72–600, 300 por defecto.

## Vistas densas legibles

Las cuadrículas HTML/SVG miden y ajustan el resumen antes de título y cabecera. Dibujan celdas antes de conectores/etiquetas. Las rutas ortogonales reservan zonas ocupadas y rótulos para reducir colisiones.

`quadrantChart` recibe normalización específica, sin reparaciones exclusivas de flowchart. Solo se elimina el corchete de apertura final no emparejado copiado en una etiqueta de punto. Los corchetes intencionados de título, ejes y cuadrantes permanecen.

Los [ejemplos del repositorio](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) contienen entradas bilingües, SVG/PNG y manifiesto. `passed` corresponde a una ejecución y bundle registrados, no a una prueba fresca de cualquier versión posterior.

El catálogo ejecutable tiene 33 entradas, la UI 21 idiomas y el sitio 34 rutas. Cinco gramáticas exactas de referencia quedan fuera del selector hasta tener evidencia independiente de su disposición.

## Drawnix con Mermaid

Notemd sanea el SVG Mermaid y conserva la fuente en metadatos `.drawnix`; la vista no requiere runtimes Drawnix/Plait. La ruta predeterminada es autónoma, sin `.assets`. **Also export complete Mermaid visuals** añade fuente, SVG y manifiesto acompañantes para edición externa. Los `.assets` antiguos siguen admitidos; un SVG ausente puede reconstruirse desde su fuente guardada.

Las imágenes resueltas usan SVG con datos integrados cuando es posible. Orden: datos embebidos, acompañantes antiguos, reconstrucción textual. Conserva carpetas referenciadas; una salida nueva autónoma no acredita que una antigua carpeta compartida esté sin uso.

El tablero principal precede paneles Mermaid en orden de origen. Reabrir historial reconstruye paneles, dimensiones y acciones.

El diseño reserva títulos, resúmenes y etiquetas y enruta conexiones estáticas alrededor de nodos. Si no logra una disposición legible admitida, falla con error de formato. Flechas entre ramas son relaciones estáticas; no se acredita que sigan unidas tras reorganizar en Drawnix. Prueba el editor destino.

## Límites de exportación nativa

Fuente e imagen son productos distintos. Prueba la aplicación destino. Las tablas PowerPoint conservan estructura editable compatible y separadores corregidos bajo celdas fusionadas; Mermaid/SVG pueden quedar como imágenes. Vista previa o puntuación visual global no sustituyen validación nativa.

## Circuitos

**Circuit diagram** con **CircuitikZ source file** produce primero una descripción estructurada y luego TeX, acotando la generación LaTeX arbitraria.

El soporte CircuitikZ es deliberadamente restringido, especialmente a amplificadores NMOS de fuente común y bloques CMOS compatibles. Revisa vista y fuente antes de uso técnico o publicación.

El SVG es una vista de revisión de Notemd, no evidencia de compilación por LaTeX o TikZJax.

No hace falta LaTeX para vista ni SVG/PNG/PDF de vista. En escritorio, **CircuitikZ native compile environment** permite diagnósticos y PDF nativo con `tectonic`, `pdflatex`, ejecutable propio o Tectonic gestionado fijado tras elegir **Install**. Muestra progreso y errores y permite retirarlo después.

## Problemas

### Tipo equivocado

Selecciona tipo explícito. Para circuitos, **Circuit diagram** y **Generar diagrama**, no el antiguo resumen Mermaid.

### Fuente inadecuada

Vuelve a **Auto** o elige formato destinado al tipo. CircuitikZ para circuitos; Draw.io/Drawnix para estructuras compatibles.

### Falta menú Export

SVG/PNG/PDF necesitan vista visual. Si solo hay texto fuente, guarda y abre en la herramienta externa correspondiente.

### CircuitikZ no compila

Comprueba el entorno nativo y repara el runtime gestionado o acceso al paquete `circuitikz` del compilador. El plugin no incluye una distribución TeX completa.
