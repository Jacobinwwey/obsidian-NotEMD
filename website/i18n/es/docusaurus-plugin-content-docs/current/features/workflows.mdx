# Flujos de trabajo

<TLDR>
Un flujo ejecuta acciones existentes en orden. Puede requerir editor activo o selección de carpeta. Cada acción conserva entradas, salidas y efectos: no es una tubería de texto arbitraria. Empieza con nota desechable y carpeta dedicada.
</TLDR>

## Visión general

Definición predeterminada de **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Añadir enlaces a la nota activa y conceptos si hay carpeta configurada.
2. Generar contenido en notas aptas nuevas y existentes del directorio conceptual o elegido.
3. Reparar Mermaid en el directorio complete resultante.

La cadena no investiga por defecto. La generación puede investigar si se activa su opción separada. Véase [lotes](../advanced/batch-processing).

## Funcionamiento

### Ejecución

Las etapas son secuenciales y la barra informa estado y fallos. Cancelar impide etapas posteriores y se propaga a peticiones compatibles. Las escrituras terminadas permanecen; no hay reversión global.

Inicialmente se prefiere la carpeta conceptual configurada. La generación por lotes registra fuente y complete; la reparación Mermaid siguiente usa complete. Otras acciones mantienen requisitos de archivo, selección o diálogo.

### DSL

Una línea por botón: `::` separa nombre y acciones, `>` sus IDs. Se ignoran líneas vacías o iniciadas por `#`; IDs desconocidos se rechazan.

```text
Extraer y representar::extract-concepts-current>summarize-as-mermaid
```

Utiliza el constructor o edita DSL. Los IDs son estables y las etiquetas siguen el idioma de interfaz. Las variantes de carpeta tienen IDs propios, sin regla general de sustitución.

| Identificador | Acción / requisito |
| ------------ | ----------------------- |
| `process-current-add-links` | Añadir enlaces a la nota activa |
| `process-folder-add-links` | Añadir enlaces en carpeta |
| `extract-concepts-current` | Extraer conceptos de la nota activa |
| `extract-concepts-folder` | Extraer conceptos de carpeta |
| `generate-from-title` | Generar contenido desde el título activo |
| `batch-generate-from-titles` | Generar notas aptas de carpeta desde títulos |
| `research-and-summarize` | Investigar selección o título en editor Markdown |
| `summarize-as-mermaid` | Resumir entrada activa compatible en Mermaid |
| `generate-diagram` | Generar artefacto de diagrama |
| `preview-diagram` | Abrir fuente o artefacto de diagrama compatible |
| `translate-current-file` | Traducir archivo activo compatible |
| `batch-translate-folder` | Traducir carpeta |
| `extract-original-text` | Extraer pasajes originales solicitados |
| `batch-extract-original-text` | Extraer pasajes de archivos aptos |
| `split-note-by-chapters` | Dividir nota activa por capítulos |
| `batch-mermaid-fix` | Reparar bloques Mermaid de carpeta |
| `fix-formula-current` | Normalizar delimitadores de fórmulas activos |
| `batch-fix-formula` | Normalizar fórmulas en carpeta |
| `check-duplicates-current` | Comprobar duplicados de nota activa |
| `check-remove-duplicate-concepts` | Revisar y eliminar conceptos duplicados con interacción |
| `test-llm-connection` | Probar proveedor |
| `probe-slide-export-env` | Comprobar entorno local de diapositivas |
| `export-slides` | Exportar archivo activo como diapositivas |

### Botones propios

One-Click Extract es el botón incluido. Los demás son definiciones tuyas. Nombra, elige y ordena acciones en ajustes, luego verifica la ayuda del botón. Corrige errores de sintaxis antes de ejecutar.

## Ajustes

| Ajuste | Predeterminado | Efecto |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Detener al primer error de etapa comunicado |
| `useMultiModelSettings` | `false` | Usar proveedor activo hasta habilitar rutas por tarea |
| `enableResearchInGenerateContent` | `false` | Excluir investigación de títulos salvo activación |

`continue_on_error` permite continuar pese a fallos; úsalo solo cuando las entradas restantes basten. No convierte un resultado parcial en éxito total.

### Modelos por tarea

Cada acción mantiene su proveedor/modelo. Un modelo vacío usa el del proveedor elegido. Revisa todas las rutas para contenido privado.

## Ejemplo

Configura `trial-concepts` vacía y prueba una nota. Revisa conceptos y directorio complete. Si desconoces destinos, ejecuta cada acción antes de encadenarla. Amplía solo después de inspeccionar.

## Consejos

- Mantener cadenas breves y salidas atribuibles.
- Evitar limpieza/borrado desatendidos: siguen necesitando confirmación.
- Tras cancelación o conflicto, leer informe y archivos.
- Probar modelo y alcance exactos; una conexión correcta no garantiza cuotas para lotes largos.
