# Enlaces wiki

<TLDR>
**Procesar archivo (añadir enlaces)** pide al LLM identificar conceptos y añadir enlaces Obsidian. Por defecto escribe `_processed.md` por separado y conserva la fuente. Los conceptos requieren una carpeta elegida. Revisa antes de ampliar a un lote.
</TLDR>

## Visión general

Los términos propuestos pueden variar y apuntar a conceptos sin archivo. Un enlace es un destino de navegación, no prueba de equivalencia entre conceptos ni de exactitud de una explicación.

## Funcionamiento

### Proceso

La tarea divide la nota, envía fragmentos al proveedor/modelo, reúne respuestas y escribe el resultado. Puede crear o actualizar conceptos. Revisa fallos parciales y destino real en el informe.

### Ejemplo

Fuente:

```text
El aprendizaje automático usa redes neuronales para reconocer patrones.
```

Salida posible:

```markdown
El [[aprendizaje automático]] usa [[redes neuronales]] para reconocer patrones.
```

Los enlaces concretos dependen de fuente, modelo y prompt.

## Uso

### Nota actual

Abre una copia Markdown y ejecuta **Procesar archivo (añadir enlaces)**. Examina `_processed.md`; sufijos, carpeta de procesados y traslado del original pueden cambiar el destino.

### Varias notas

Elige **Procesar carpeta (añadir enlaces)** y confirma carpeta y alcance. Empieza pequeño. No existe un ajuste global sobrescribir/omitir común a todas las tareas. Consulta [lotes](../advanced/batch-processing).

### Texto elegido

**Create wiki link and generate note from selection** permite escoger el término. Es una acción separada; seleccionar texto no limita el procesamiento del archivo entero. Revisa concepto y contenido generado.

## Elegir el método de enlace

Usa el modelo para descubrir conceptos a partir del contenido. Prefiere coincidencia determinista de títulos cuando importe reproducibilidad sobre nombres existentes. Compara otras extensiones con documentación actual y pruebas fechadas, sin asumir superioridad.

## Funciones

### Reducir sinónimos

`replaceSynonymsDuringConceptExtraction` añade una instrucción contra conceptos sinónimos o muy próximos. Es un booleano desactivado por defecto, no un umbral numérico de similitud. Revisa abreviaturas y casi sinónimos.

### Integridad de enlaces

Obsidian gestiona actualizaciones por renombrado según sus ajustes y la operación. Borrar una nota puede dejar un enlace sin resolver, distinto de una mención sin enlace. Comprueba basenames ambiguos en carpetas diferentes.

### Extracción independiente

**Extraer conceptos (archivo actual)** crea conceptos sin reescribir la fuente. Sus controles de plantilla y backlinks difieren de añadir enlaces. Véase [conceptos](./concept-notes).

## Archivos de conceptos

### Creación automática

Con salida de conceptos habilitada y carpeta elegida se pueden crear título y backlink `Linked From`. No se generan automáticamente explicación investigada, sección de conceptos relacionados ni frontmatter configurable. Genera desde títulos por separado para añadir contenido.

### Ajustes

Busca carpeta de conceptos, carpeta de procesados, sufijo y traslado del original. La ruta conceptual comienza vacía. Mantén destinos de prueba separados de las fuentes.

## Opciones avanzadas

### Contexto y prompts

`chunkWordCount` controla tamaño aproximado. Dominio de aprendizaje y prompt pueden acotar conceptos. No hay selectores documentados de contexto frase/párrafo, frecuencia mínima ni variables generales de plantilla conceptual.

## Buenas prácticas

- Compara salida y fuente, incluidas citas, fórmulas y código.
- Revisa si cada término merece una nota.
- Prueba prompts con un ejemplo estable.
- Respalda antes de mover fuentes o escribir sobre destinos existentes.

## Rendimiento

Latencia y coste dependen de proveedor, modelo, entrada, salida y reintentos. No se prometen segundos por nota ni precio por cien notas. Mide una muestra y consulta el consumo real.

## Problemas

### Sin enlaces

Inspecciona petición, respuesta, nota elegida y archivo de salida. Ninguna longitud mínima garantiza enlaces útiles.

### Demasiados enlaces

Acota el prompt o el dominio y revisa. La instrucción sobre sinónimos guía, pero no impone un vocabulario.

### Enlaces rotos tras renombrar

Comprueba ajustes Obsidian y ambigüedad previa. Restaura o corrige el destino de forma explícita; repetir el LLM no es reparación determinista.
