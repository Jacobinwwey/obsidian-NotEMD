# Prompts personalizados

<TLDR>
Un prompt propio sustituye al integrado cuando las opciones global y de tarea están activadas y el texto no está vacío. Conserva su contrato de salida; no existe un sistema que reponga automáticamente todas las instrucciones omitidas.
</TLDR>

## Visión general

Prueba primero el prompt integrado. Dominio focalizado o reducción de sinónimos pueden bastar. Personaliza políticas, estructura o estilo y compara la salida antes de un lote.

## Funcionamiento

### Composición

Notemd elige prompt integrado o propio, añade instrucciones aplicables de dominio/idioma y sustituye variables suministradas por la tarea. El contenido también puede enviarse en otro mensaje. Las variables no son universales.

Un reemplazo puede omitir `CONCEPT:` o el contexto de investigación. Una petición válida no acredita salida analizable ni respaldo en fuentes.

### Variables

Respeta mayúsculas y llaves simples:

| Tarea | Variables suministradas |
| ------ | ----------------------- |
| Generación desde título | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Resumen de investigación | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Traducción | `{LANGUAGE}`, `{TEXT}` |
| Extracción original | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` sigue la política de la tarea. Enlaces y conceptos independientes envían texto como contenido; no inventes una variable. Los nombres desconocidos no se rellenan. No son plantillas de archivos conceptuales.

### Dominio focalizado

Activa aprendizaje focalizado e indica, por ejemplo, `ingeniería eléctrica`. Se añade `Relevant Fields`; orienta al modelo, pero no impone un filtro rígido.

## Ajustes

| Tarea | Activación | Campo de prompt |
| ------ | --------------- | -------------- |
| Enlaces | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Títulos | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Investigación | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Resumen Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Conceptos | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Traducción | `useCustomPromptForTranslate` | `translatePrompt` |
| Texto original | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Todos necesitan `enableGlobalCustomPrompts`. Un texto vacío vuelve al integrado. La extracción original fusionada usa su propio formato, no el reemplazo ordinario. La generación de diagramas exige resultados tipados; el prompt Mermaid no sirve para cualquier diagrama.

## Ejemplo

Activa opciones global y de extracción conceptual y conserva el marcador:

```text
Extrae los conceptos centrales de ingeniería eléctrica de la nota.
Prefiere componentes concretos y mecanismos físicos a nombres genéricos.
Devuelve un concepto por línea con este formato exacto:
CONCEPT: Nombre del término
No añadas explicaciones ni un bloque de código envolvente.
```

Prueba una copia y revisa entradas, archivos y omisiones. Compara con el prompt integrado y guarda el anterior para restaurarlo.

## Consejos

- Probar una tarea antes de ampliar lotes.
- Conservar evidencia de investigación y citas exactas.
- Traducir instrucciones sin alterar IDs ni marcadores.
- Volver a comprobar al cambiar modelo; instrucciones no equivalen a validación.
