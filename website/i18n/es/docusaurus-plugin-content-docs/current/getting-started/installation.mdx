# Instalación

<TLDR>
Instala **Notemd** desde los complementos comunitarios o copia los tres archivos de la misma versión GitHub al almacén. Actívalo, configura un proveedor y comprueba una nota de prueba. Los servidores locales y exportadores nativos tienen requisitos propios.
</TLDR>

## Método 1: complementos comunitarios (recomendado)

1. Abre **Settings → Community plugins** en el almacén correcto.
2. Habilita complementos si es necesario y elige **Browse**.
3. Busca **Notemd**, verifica `Jacobinwwey/obsidian-NotEMD` y pulsa **Install**.
4. Pulsa **Enable** y abre la barra lateral desde la cinta o la paleta.

[Abrir Notemd en Obsidian](obsidian://show-plugin?id=notemd). Si el navegador no reconoce el enlace, usa los pasos anteriores.

## Método 2: instalación manual

### Requisitos

Necesitas Obsidian y un almacén que puedas respaldar. El manifiesto declara `0.15.0` como mínimo; esto no acredita pruebas actuales en esa versión antigua.

### Pasos

1. Descarga `main.js`, `manifest.json` y `styles.css` de la misma [versión GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). El `README.md` incluido es referencia, no requisito de ejecución.
2. Cópialos a `<vault>/.obsidian/plugins/notemd/`; ajusta `.obsidian` si tu directorio de configuración es distinto.
3. Recarga Obsidian y activa Notemd.
4. Comprueba la versión mostrada; no mezcles manifiesto nuevo y bundle antiguo.

## Alternativa: BRAT

Si ya utilizas [BRAT](https://github.com/TfTHacker/obsidian42-brat), añade `Jacobinwwey/obsidian-NotEMD` mediante su flujo beta. Para reproducir errores, elige una versión concreta. BRAT es opcional.

## Comprobación

Elige proveedor/modelo accesibles y ejecuta **Probar conexión**. Después sigue el [inicio rápido](./quick-start) con una copia. Algunos tests solo prueban la lista de modelos; una tarea real comprueba generación y escritura.

## Requisitos del sistema

| Área | Límite |
| --------- | ---------- |
| Manifiesto | Mínimo declarado `0.15.0`; `isDesktopOnly` es false |
| Evidencia de pruebas | Consultar la aceptación fechada; móviles físicos y Obsidian 0.15.0 sin verificación actual |
| LLM alojado | Red, cuenta/clave autorizadas y modelo compatible |
| LLM local | Servidor instalado y activo, con modelo descargado o cargado |
| Exportación nativa de diapositivas/circuitos | Herramientas de escritorio y dependencias del formato; comprobar antes de exportar |

No existe garantía global de versiones de SO para todos los exportadores. Una vista previa no prueba compilación TeX; una prueba de escritorio no verifica móviles.

## Desinstalación

Desactiva o desinstala el complemento. Las notas y artefactos siguen en el almacén: revísalos antes de borrarlos. Guarda la configuración para reinstalar. Desinstalar no revierte ediciones ya terminadas.

## Actualización

Usa **Check for updates**. Para actualizar manualmente, detén tareas, respalda almacén y ajustes, sustituye los tres archivos de una misma versión y recarga. Lee los cambios y prueba una nota antes de los lotes.

No sustituyas la configuración del almacén por un asset. Para retroceder, instala deliberadamente una versión compatible y conserva las salidas necesarias.
