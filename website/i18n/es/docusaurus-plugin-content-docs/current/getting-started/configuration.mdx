# Configuración

<TLDR>
Abre **Settings → Notemd** y busca el campo. Prepara proveedor y destinos antes de procesar. Prueba los cambios con una nota: una operación activa puede conservar los ajustes capturados al iniciarse.
</TLDR>

## Visión general

DeepSeek es el proveedor activo inicial, sin credenciales. Un perfil no crea cuenta, instala modelo ni concede acceso. Véase [proveedores](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Buscar ajustes y favoritos

- **Search settings** busca nombres, descripciones, alias y categorías visibles y conduce al campo.
- **★ Favorites** muestra campos guardados con descripción, categoría y destino. Persisten en el almacén; se descartan IDs obsoletos.
- La flecha repliega la barra y conserva la consulta al abrirla.
- Lista de favoritos y filtro de búsqueda solo en favoritos son controles distintos.

**Diagram preview export PPI**: **300** por defecto, rango **72–600**. Afecta a PNG; SVG/PDF mantienen geometría vectorial cuando se admite. **Also export complete Mermaid visuals** controla archivos acompañantes, no visibilidad de Mermaid en Drawnix.

Selecciona varios tipos de diagrama en una ejecución y varios formatos independientes por tipo. Al desmarcar un tipo se conservan sus formatos; sin tipos seleccionados se analiza el contenido automáticamente.

Configura una ruta compartida relativa al Vault para archivos intermedios, o déjala vacía para usar `notemd_assert/` junto a cada original. Allí se guardan registros de recuperación, cachés y adjuntos opcionales. Conserva los archivos aún referenciados; cambiar la carpeta solo afecta a nuevas ejecuciones.

## 1. Proveedor

Elige perfil, dirección adecuada al protocolo, credenciales y modelo accesible. Usa **Fetch models** cuando exista y luego **Probar conexión**. Listar y generar son comprobaciones separadas.

Un modelo local requiere servidor y modelo listos. Un endpoint cloud recibe el contenido. Revisa también las rutas por tarea antes de usar notas privadas.

## 2. Modelos por tarea

`useMultiModelSettings` separa proveedor/modelo para enlaces, títulos, investigación, traducción, conceptos, texto original y resumen Mermaid. Un modelo específico vacío usa el configurado en el proveedor. Sin esta opción se usa el proveedor activo.

Compara precisión, latencia y precio real con una nota representativa; no se garantiza una clasificación ni disponibilidad de modelos.

## 3. Salidas

| Tarea | Salida predeterminada |
| ------ | ------------------------- |
| Añadir enlaces | Archivo vecino `_processed.md`; sin mover el original |
| Conceptos independientes | Carpeta elegida obligatoria; títulos sin enlaces de regreso |
| Traducción | Archivo vecino `_<language>.md`; puede sobrescribir el destino |
| Investigación | Resumen añadido a la nota Markdown activa |
| Generación desde títulos por lotes | Escribe contenido y mueve notas aptas a `<folder>_complete` cuando el destino lo permite |
| Vista previa/exportación | Los archivos seleccionados se exportan automáticamente junto a la nota original o directamente a la carpeta configurada. El nombre incluye el tipo, como `topic_drawnix.pdf` o `topic_flowchart.svg`; las colisiones añaden `-2`, `-3`, etc., sin sobrescribir archivos. |
La carpeta de conceptos empieza vacía; `concepts` es una elección posible. Sus [plantillas](../features/concept-notes) son mínima/completa, sin motor general de variables para archivos.

Sufijos y carpetas de procesados y traducciones son independientes. Revisa destinos existentes y avisos de recuperación. Cancelar no revierte escrituras terminadas.

## 4. Idiomas

La interfaz dispone de **21 idiomas**, el sitio de **34 rutas lingüísticas**. `uiLocale: auto` sigue las correspondencias disponibles y vuelve al inglés si no existe soporte.

El idioma de contenido es independiente y por defecto inglés. Las opciones por tarea se aplican a enlaces, títulos, investigación, conceptos y Mermaid donde se admiten. Traducción usa el idioma de salida `language`, no el de interfaz. La capacidad del modelo es otra cuestión.

## 5. Búsqueda

Selecciona **Tavily** con clave o **DuckDuckGo** explícitamente. Una clave vacía no cambia el motor. Ambos usan red; DuckDuckGo también puede leer páginas.

Los títulos no investigan por defecto; activa `enableResearchInGenerateContent` si lo necesitas. La recuperación local también empieza desactivada y tiene alcance propio de carpetas/tareas. Los fragmentos usados se envían al LLM como contexto.

## 6. Flujos

Usa el constructor o una definición DSL por línea:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` separa nombre y acciones, `>` separa IDs. El comportamiento predeterminado se detiene ante un error comunicado. Véase [flujos](../features/workflows).

## 7. Ajustes avanzados

| Ajuste | Predeterminado | Efecto |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Proveedor sin ruta específica |
| `useMultiModelSettings` | `false` | Separar modelos por tarea |
| `useCustomConceptNoteFolder` | `true` | Permitir conceptos una vez elegida carpeta |
| `conceptNoteFolder` | `''` | Ninguna carpeta inicial |
| `extractConceptsMinimalTemplate` | `true` | Conceptos independientes solo con título |
| `extractConceptsAddBacklink` | `false` | Enlaces de regreso solo tras activación |
| `moveOriginalFileOnProcess` | `false` | Conservar la fuente al añadir enlaces |
| `chunkWordCount` | `3000` | Tamaño aproximado en palabras, no límite de tokens |
| `batchConcurrency` | `1` | Concurrencia inicial |
| `enableBatchParallelism` | `false` | Planificación paralela en rutas compatibles |
| `enableStableApiCall` | `false` | Modo estable de petición explícito |
| `customWorkflowErrorStrategy` | `stop_on_error` | Detener ante error de etapa |

División del texto y presupuesto de salida son distintos. Fragmentos pequeños no garantizan caber en el contexto del proveedor, ni menor concurrencia evita todos los 429.

## Perfiles

Los ajustes pertenecen al almacén. Respalda una configuración útil antes de cambiarla. Los perfiles de proveedor expurgados no son un respaldo completo; revisa URL y metadatos antes de compartir. No publiques ajustes brutos ni diagnósticos con notas privadas.

## Diagnosticar ajustes

Prueba proveedor/modelo exactos y luego una nota. Si faltan campos, busca por nombre y revisa categoría, modo desarrollador y almacén. Informa errores reproducibles con versión y detalles expurgados.

## 1.9.10 — Vistas previas seguras y ajustes locales del Vault

Las vistas SVG importadas eliminan contenido activo y recursos externos, conservando etiquetas chinas y estilos de paneles. Los proveedores locales se aíslan por Vault; importe explícitamente la lista anterior desde los ajustes, conservando la lista y las configuraciones existentes. Las presentaciones usan un servidor loopback que gestiona consumidores compartidos. Se notifican fallos al guardar favoritos o copiar; la eliminación respeta las preferencias del Vault. La compatibilidad PNG sigue activa: conserva el original y añade una copia verificada con menos PPI solo si hace falta. Drawnix no tiene un límite fijo de relaciones; la exportación de presentaciones mantiene ajustes separados. Instale archivos de la misma versión, recargue y pruebe una nota antes del procesamiento por lotes.

## 1.9.11

Los registros se acumulan entre etapas y al reabrir la vista previa durante la sesión del complemento. Use Borrar registro para reiniciarlos; recargar el complemento no conserva el historial.

Los diagnósticos se agrupan por etiqueta y aparecen contraídos. Expanda un grupo para leer todos sus mensajes y sugerencias; los recuentos por gravedad permanecen visibles.

## 1.9.12 — Vista previa de diagnósticos más despejada

Si no hay errores, todo el panel de diagnóstico aparece contraído; solo se ven el título y los recuentos por gravedad. Los errores abren el panel automáticamente. Expanda el panel y sus grupos de etiquetas para leer todos los mensajes y sugerencias. No se elimina ningún registro de diagnóstico. Solo se abren automáticamente los grupos de errores; los de advertencias e información siguen contraídos, aunque compartan etiqueta.
