# Inicio rápido

<TLDR>
Empieza con una nota Markdown desechable y un proveedor al que ya tengas acceso. Revisa el archivo generado antes de ampliar a una carpeta. La nube recibe el contenido; un modelo local requiere servidor activo y archivos preparados.
</TLDR>

## Paso 1: configurar el proveedor

1. [Instala y activa Notemd](./installation), luego abre **Settings → Notemd**.
2. Elige proveedor, dirección, credenciales necesarias y un modelo disponible. **Fetch models** descubre modelos compatibles; aparecer no garantiza generar.
3. Ejecuta **Probar conexión** y corrige errores de autenticación, modelo o dirección.
4. Busca **Ruta de la carpeta de notas de concepto** y elige una carpeta dedicada como `concepts`. El valor inicial está vacío: `concepts/` es un ejemplo, no una ruta preconfigurada.

Con Ollama, descarga primero el modelo y usa su nombre exacto; dirección predeterminada `http://localhost:11434/api`. En LM Studio, inicia el servidor y elige `LMStudio`. Véase [modelos locales](../providers/local). La investigación web sigue necesitando red.

## Paso 2: probar una tarea

Crea `Notemd trial.md` con texto que puedas enviar al proveedor:

```text
El aprendizaje automático utiliza redes neuronales para aprender patrones a partir de ejemplos.
```

Ejecuta **Procesar archivo (añadir enlaces)**. Por defecto crea `Notemd trial_processed.md` junto al original, que se conserva. Abre la salida y examina los enlaces. Ejemplo posible:

```markdown
El [[aprendizaje automático]] utiliza [[redes neuronales]] para aprender patrones a partir de ejemplos.
```

La carpeta de conceptos elegida también puede recibir notas. Revisa archivos y enlaces: el modelo no garantiza identificar correctamente todos los conceptos.

## Paso 3: explorar funciones

### Extraer conceptos

**Extraer conceptos (archivo actual)** conserva la fuente y requiere carpeta de conceptos. La extracción independiente crea solo títulos y no añade enlaces de regreso por defecto. Actívalos expresamente. Véase [conceptos](../features/concept-notes).

### Investigar y resumir

Selecciona un tema en el editor Markdown o usa el título y ejecuta **Investigar y resumir**. Elige Tavily con clave o DuckDuckGo explícitamente. El resumen se añade a la nota; abre las fuentes para verificarlo.

### Encadenar acciones

La definición exacta de **One-Click Extract** es:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Añade enlaces, genera contenido en notas aptas de la carpeta de conceptos o seleccionada y repara Mermaid en complete. Puede incluir notas previas. Usa una carpeta de ensayo propia. No añade automáticamente investigación web ni generación de diagramas.

## Cancelación y revisión

**Cancelar** detiene trabajo posterior. Los resultados terminados permanecen: no es una transacción reversible ni garantiza detener generación o facturación remotas. Espera a que concluya la cancelación y revisa rutas y conflictos antes de repetir.

## Solución de problemas

- Clave/modelo: revisa el perfil exacto y repite la conexión.
- Sin conceptos: comprueba carpeta elegida y habilitada.
- Enlaces poco útiles: inspecciona respuesta y prompt; no hay longitud mínima que garantice éxito.
- Cuotas: mantén `batchConcurrency: 1` durante el diagnóstico.
