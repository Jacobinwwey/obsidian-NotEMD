# Fournisseur Anthropic

<TLDR>
Utilisez Anthropic pour l’API Messages native. Un Claude servi par une passerelle compatible OpenAI utilise son propre préréglage. Vérifiez le modèle accessible : la valeur historique peut devoir être remplacée.
</TLDR>

## Configuration

Choisissez **Anthropic**, saisissez sa clé et gardez l’adresse native sauf déploiement exposant explicitement ce même protocole. Renseignez un modèle disponible, testez la connexion puis la tâche sur une note jetable.

## Adresse et authentification

| Champ | Valeur prédéfinie |
| ------- | -------------- |
| Transport | `anthropic` |
| Clé API | Obligatoire |
| URL de base | `https://api.anthropic.com` |
| Modèle | `claude-3-5-sonnet-20240620` |
| Température | `0.5` |
| Test de connexion | `chat-only` |

La route est `/v1/messages`, avec les en-têtes natifs de clé et de version API. N’utilisez pas une route Chat Completions dans ce profil. Le modèle prédéfini décrit le dépôt, pas sa disponibilité actuelle chez Anthropic.

## Découverte

La liste utilise le protocole Anthropic natif lorsqu’il est accessible. Si elle est restreinte, saisissez un modèle autorisé et utilisez le test par dialogue. Vérifiez séparément les tâches longues ou structurées.

## Dépannage

- `401`/`403` : clé, espace/projet, facturation et permissions.
- `404` : adresse et disponibilité actuelle du modèle.
- Identifiant de passerelle refusé : choisir son profil et sa syntaxe.
- Réponses longues en échec : vérifier limites et erreur avant d’augmenter les tentatives.

## Cas d’usage

Choisissez ce profil pour un endpoint Messages natif. Comparez les sorties sur vos sources ; aucun fournisseur n’établit un classement universel. Le routage par tâche permet un usage ciblé.
