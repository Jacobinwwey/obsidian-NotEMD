# Fournisseur Google

<TLDR>
Le préréglage Google utilise l’API native Gemini Generative Language. Renseignez une clé autorisée et un modèle actuellement disponible. Pour Gemini via une passerelle OpenAI-compatible, choisissez le profil de cette passerelle.
</TLDR>

## Configuration

Choisissez **Google**, sa clé, l’adresse Generative Language et un modèle servi par cette version API. Lancez **Tester la connexion**, puis une traduction ou un traitement de note jetable. Ce profil ne configure pas automatiquement un déploiement Google Cloud ou Vertex arbitraire.

## Adresse et authentification

| Champ | Valeur prédéfinie |
| ------- | -------------- |
| Transport | `google` |
| Clé API | Obligatoire |
| URL de base | `https://generativelanguage.googleapis.com/v1` |
| Modèle | `gemini-2.0-flash-exp` |
| Température | `0.5` |
| Test de connexion | `chat-only` |

Le moteur construit une requête native `generateContent` authentifiée par clé. Le modèle historique du préréglage n’est pas garanti disponible. Inspectez les URL des diagnostics avant partage : des informations d’authentification peuvent figurer dans les détails.

## Découverte

Utilisez la découverte native Google si accessible. Vérifiez que le modèle accepte la génération sur la version API choisie. Une liste vide peut indiquer permissions, adresse ou disponibilité ; ne changez pas de protocole sans diagnostic.

## Dépannage

- `400` : identifiant, paramètres et limites de tokens/sortie.
- `401`/`403` : restrictions de clé, activation API et droits du modèle.
- `404` : disponibilité sur cette version API.
- Exemple de passerelle en échec : sélectionner son préréglage compatible OpenAI.

## Cas d’usage

Ce profil vise l’API Gemini native. Testez votre traduction, recherche ou diagramme sur un échantillon ; aucun avantage universel de vitesse, coût ou qualité n’est promis.
