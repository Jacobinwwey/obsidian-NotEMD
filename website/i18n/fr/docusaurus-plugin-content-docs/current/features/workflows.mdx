# Workflows

<TLDR>
Un workflow exécute les actions existantes dans l’ordre. Certaines demandent un dossier ou un éditeur actif. Ce n’est pas un pipeline de texte : chaque action conserve ses entrées, sorties et effets de bord. Commencez avec une note jetable et un dossier dédié.
</TLDR>

## Vue d’ensemble

Définition livrée pour **One-Click Extract** :

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Ajouter des liens à la note active et créer des concepts si leur dossier est configuré.
2. Générer du contenu pour les notes admissibles de ce dossier ou du dossier choisi, y compris les notes préexistantes.
3. Réparer Mermaid dans le dossier complete issu du lot.

La recherche Web n’appartient pas à la chaîne par défaut. La génération peut la demander si son option distincte est activée. Voir les [lots](../advanced/batch-processing).

## Fonctionnement

### Exécution

Les étapes sont séquentielles, avec progression et erreurs visibles. L’annulation empêche les étapes suivantes et se propage aux requêtes prises en charge. Les écritures terminées restent ; aucun retour arrière global n’existe.

Le dossier de concepts configuré est préféré initialement. La génération par lot enregistre source et dossier complete, réutilisé par la réparation Mermaid suivante. Les autres actions gardent leurs exigences de fichier actif, sélection ou interaction.

### Format DSL

Une ligne par bouton. `::` sépare le nom des actions, `>` les identifiants. Les lignes vides ou commençant par `#` sont ignorées ; les actions inconnues sont rejetées.

```text
Extraire et tracer::extract-concepts-current>summarize-as-mermaid
```

Utilisez le constructeur ou modifiez le DSL. Les identifiants sont stables, les libellés suivent la langue de l’interface. Les variantes de dossier ont des identifiants propres, pas une règle universelle de substitution.

| Identifiant | Action / prérequis |
| ------------ | ----------------------- |
| `process-current-add-links` | Ajouter des liens à la note active |
| `process-folder-add-links` | Ajouter des liens dans un dossier choisi |
| `extract-concepts-current` | Extraire les concepts de la note active |
| `extract-concepts-folder` | Extraire les concepts d’un dossier |
| `generate-from-title` | Générer depuis le titre actif |
| `batch-generate-from-titles` | Générer les notes admissibles d’un dossier |
| `research-and-summarize` | Rechercher une sélection ou un titre dans l’éditeur Markdown |
| `summarize-as-mermaid` | Synthétiser l’entrée active prise en charge en Mermaid |
| `generate-diagram` | Générer un diagramme depuis une entrée prise en charge |
| `preview-diagram` | Prévisualiser une source ou un diagramme pris en charge |
| `translate-current-file` | Traduire le fichier actif pris en charge |
| `batch-translate-folder` | Traduire un dossier |
| `extract-original-text` | Extraire les passages originaux demandés |
| `batch-extract-original-text` | Extraire les passages des fichiers admissibles d’un dossier |
| `split-note-by-chapters` | Découper la note active par chapitres |
| `batch-mermaid-fix` | Réparer les blocs Mermaid d’un dossier |
| `fix-formula-current` | Normaliser les délimiteurs de formule actifs |
| `batch-fix-formula` | Normaliser les délimiteurs dans un dossier |
| `check-duplicates-current` | Contrôler les doublons de la note active |
| `check-remove-duplicate-concepts` | Examiner et supprimer interactivement les concepts doublons |
| `test-llm-connection` | Tester le fournisseur configuré |
| `probe-slide-export-env` | Vérifier l’environnement local d’export de diapositives |
| `export-slides` | Exporter le fichier actif en diapositives |

### Boutons prédéfinis et personnalisés

One-Click Extract est le bouton livré. Les autres sont vos définitions. Dans les paramètres, nommez le bouton, choisissez et ordonnez les actions, puis vérifiez l’infobulle latérale. Corrigez les erreurs de parsing avant exécution.

## Configuration

| Paramètre | Défaut | Effet |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Arrêter à la première erreur d’étape signalée |
| `useMultiModelSettings` | `false` | Fournisseur actif jusqu’à activation du routage par tâche |
| `enableResearchInGenerateContent` | `false` | Recherche exclue de la génération sauf activation |

`continue_on_error` autorise des étapes ultérieures après échec. Réservez-le aux actions capables d’utiliser les entrées restantes ; il ne transforme pas une exécution partielle en réussite.

### Modèles par tâche

Chaque action conserve son choix de modèle. Un remplacement vide reprend le modèle du fournisseur choisi. Contrôlez chaque route avant de manipuler du contenu privé.

## Exemple

Configurez un dossier vide `trial-concepts`, exécutez le workflow sur une note jetable et examinez concepts et dossier complete annoncés. Exécutez d’abord les actions séparément si leurs destinations restent incertaines, puis élargissez le périmètre.

## Conseils

- Gardez des chaînes courtes dont les échecs et sorties restent attribuables.
- Évitez nettoyage et suppression sans surveillance : leurs confirmations interactives demeurent.
- Après annulation ou conflit, consultez fichiers et progression avant relance.
- Testez le même modèle et périmètre ; une connexion réussie ne garantit pas les quotas d’un long lot.
