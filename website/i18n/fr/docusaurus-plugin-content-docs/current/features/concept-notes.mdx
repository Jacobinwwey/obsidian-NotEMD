# Notes de concepts

<TLDR>
L’extraction autonome lit une source et crée des fichiers Markdown de concepts dans un dossier choisi, initialement vide dans les réglages. Les nouvelles notes contiennent seulement un titre par défaut, sans backlink. L’ajout de liens utilise un autre modèle de note.
</TLDR>

## Vue d’ensemble

Configurez **Chemin du dossier des notes de concept**. Un dossier dédié facilite le contrôle des résultats, des doublons et de la génération ultérieure. Extraire ne remplit pas automatiquement chaque note d’une explication recherchée.

## Fonctionnement

### Chaîne d’extraction

Le contenu est envoyé au LLM ; les entrées `CONCEPT:` sont analysées, les noms dédupliqués dans l’opération et les fichiers créés ou actualisés. Les notes longues sont découpées. Consultez le rapport : une réponse n’est pas un inventaire exhaustif.

### Prompt d’extraction

Le prompt intégré demande des concepts précis liés au sujet. Apprentissage ciblé et réduction des synonymes influencent le modèle sans garantir une terminologie canonique. Un prompt personnalisé doit conserver `CONCEPT: Term`. Voir les [prompts](../advanced/custom-prompts).

### Découpage

`chunkWordCount` vaut 3000 par défaut, en mots approximatifs et non en tokens du fournisseur. Le contexte entre fragments est limité ; contrôlez concepts proches et noms ambigus.

## Création des notes

### Noms de fichiers

Les caractères de chemin non admis sont supprimés, les espaces normalisés et les noms longs tronqués. Un nom vide est ignoré. Plusieurs expressions peuvent donc aboutir au même fichier : examinez les noms avant une extraction massive.

### Modèles

Par défaut, une nouvelle note autonome contient :

```markdown
# Nom du concept
```

Pour un backlink dans une nouvelle note autonome, activez **Add "Linked From" backlink** et désactivez **Create minimal concept notes**. Forme complète :

```markdown
# Nom du concept

## Linked From
- [[Note source]]
```

L’ajout de liens crée la forme complète avec backlink quand la sortie de concepts est activée. Les options d’extraction autonome ne modifient pas ce comportement.

### Notes existantes

Avec les backlinks activés, un lien source manquant peut être ajouté sous `## Linked From`, sans remplacer le corps ni répéter le lien. La référence utilise le basename source ; vérifiez les sources homonymes.

### Configuration

| Paramètre | Défaut | Effet |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Autoriser les concepts une fois le dossier choisi |
| `conceptNoteFolder` | `''` | Aucun dossier initial |
| `extractConceptsMinimalTemplate` | `true` | Notes autonomes limitées au titre |
| `extractConceptsAddBacklink` | `false` | Activer les backlinks autonomes |
| `extractConceptsProvider` | `DeepSeek` | Fournisseur lorsque le routage par tâche est actif |
| `extractConceptsModel` | `''` | Reprendre le modèle du fournisseur si vide |
| `extractConceptsLanguage` | `en` | Langue lorsque les langues par tâche sont actives |
| `replaceSynonymsDuringConceptExtraction` | `false` | Ajouter une consigne contre les synonymes |
| `generateConceptLogFile` | `false` | Créer un journal de concepts sur demande |

## Déduplication

Le contrôle utilise des heuristiques de noms : casse, pluriels, symboles normalisés et inclusion d’un mot selon le périmètre. Il ne prouve pas l’équivalence sémantique ; pluriels irréguliers et sens techniques distincts nécessitent une relecture.

Dans **Vérifier et supprimer les doublons**, examinez les candidats et confirmez uniquement les suppressions voulues. Les éléments approuvés passent par la corbeille d’Obsidian. Ce dossier n’est pas un cache jetable : sauvegardez-le avant nettoyage.

### Périmètres

La comparaison peut viser le coffre, le dossier de concepts, des dossiers inclus ou un périmètre avec exclusions. Vérifiez ce choix avant confirmation ; il change les candidats, pas la définition d’un doublon.

## Utilisation

### Extraction autonome

Ouvrez une note Markdown, confirmez le dossier et lancez **Extraire les concepts (fichier actuel)**. La source reste inchangée. Vérifiez noms, couverture et backlinks éventuels.

### Extraction puis contenu

**Génération par lot à partir des titres** enrichit le dossier de concepts. Des notes admissibles antérieures peuvent aussi être traitées. Examinez le dossier avant exécution et la destination complete annoncée après celle-ci.

### Lien depuis une sélection

L’action de sélection peut entourer le terme choisi d’un lien et créer la note si sa destination est configurée. Elle permet de choisir le terme sans demander au modèle d’extraire toute la note.

## Conseils

- Commencez avec une petite source et un dossier dédié.
- Choisissez la langue avant une grande collection.
- Relisez séparément synonymes et doublons.
- Conservez les journaux utiles avant une exécution qui pourrait les remplacer.
