# Recherche Web et synthèse

<TLDR>
**Rechercher et résumer** recherche le sujet sélectionné ou le titre de la note, demande au LLM une synthèse du contexte disponible et l’ajoute à la note Markdown active. Choisissez Tavily ou DuckDuckGo explicitement. Résultats et citations générées doivent être vérifiés.
</TLDR>

## Vue d’ensemble

Le moteur de recherche et le LLM de synthèse se configurent séparément. Tavily exige une clé ; DuckDuckGo n’en exige pas mais peut limiter les requêtes. Un modèle local ne rend pas la recherche Web hors ligne.

## Fonctionnement

### Rechercher puis synthétiser

1. Ouvrez la note dans un éditeur Markdown ; sélectionnez un sujet court, ou laissez la sélection vide pour son titre.
2. Lancez **Rechercher et résumer**.
3. Notemd interroge le moteur choisi. Tavily fournit des extraits ; DuckDuckGo peut entraîner la lecture des pages trouvées.
4. Le contexte local peut compléter le prompt si la recherche locale est activée pour cette tâche.
5. Le LLM produit une synthèse, ajoutée sous `Research Summary` avec sujet et origine du contexte.
6. Relisez et ouvrez les URL : récupérer une page ne prouve pas qu’elle soutient chaque assertion ou citation.

### Tavily ou DuckDuckGo

| Choix | Configuration | Limite opérationnelle |
| -------- | ------- | ---------------------- |
| Tavily | Choisir Tavily et saisir sa clé | Quota du compte et extraits renvoyés |
| DuckDuckGo | Choisir DuckDuckGo explicitement | Sans clé ; limitations de recherche et disponibilité des pages |

Une clé Tavily absente ou invalide ne sélectionne pas DuckDuckGo. Sans contexte Web utile, consultez le rapport. Des extraits locaux activés et disponibles peuvent suffire à une synthèse, dont l’étiquette de source distingue alors l’origine.

### Recherche pendant la génération depuis les titres

**Enable research in "Generate from title"** ajoute la recherche à la génération, y compris par lot. Ce réglage est désactivé par défaut. Il n’existe pas d’action générique autonome Research Folder.

## Configuration

| Paramètre | Défaut | Effet |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Moteur de recherche |
| `tavilyApiKey` | `''` | Clé obligatoire pour Tavily |
| `tavilyMaxResults` | `5` | Nombre demandé de résultats Tavily |
| `tavilySearchDepth` | `basic` | Profondeur Tavily |
| `ddgMaxResults` | `5` | Nombre demandé de résultats DuckDuckGo |
| `ddgFetchTimeout` | `15` | Délai de lecture des pages, en secondes |
| `maxResearchContentTokens` | `3000` | Budget approximatif du contexte Web |
| `researchProvider` | `DeepSeek` | LLM de synthèse avec routage par tâche |
| `researchModel` | `''` | Modèle du fournisseur si vide |
| `researchSummarizeLanguage` | `en` | Langue avec configuration par tâche |
| `enableResearchInGenerateContent` | `false` | Ajouter la recherche à la génération depuis les titres |
| `enableLocalKnowledgeRetrieval` | `false` | Activer séparément la recherche locale délimitée |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Utiliser le contexte local pour cette tâche |

### Contexte et modèle

Les limites de contexte sont estimées, sans tokenisation exacte du fournisseur ; la troncature peut éliminer des preuves. Adaptez modèle et budget de sortie, et posez une question précise. L’index local est lexical, sans embeddings ni rappel exhaustif garanti.

## Exemple

Créez une note intitulée `Encodage positionnel relatif`. Lancez la recherche, puis confrontez la synthèse aux articles originaux ou à la documentation officielle liés. Conservez question, URL réelles et corrections pour rendre la conclusion vérifiable. Un exemple de guide n’est pas un résultat obtenu dans votre coffre.

## Annulation et confidentialité

Les ajouts terminés restent présents après annulation. Des requêtes déjà en cours peuvent finir. Le moteur reçoit la question, les sites reçoivent des requêtes et le LLM reçoit le contexte collecté, y compris les extraits locaux activés. Expurgez les diagnostics avant partage.

## Conseils

- Distinguez source Web, note locale et inférence du modèle.
- Vérifiez citations, dates et affirmations importantes dans l’original.
- Isolez recherche et LLM avec une petite question d’essai.
- Contrôlez les synthèses existantes avant relance pour éviter les ajouts redondants.
