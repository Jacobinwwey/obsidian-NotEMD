# Démarrage rapide

<TLDR>
Commencez avec une note Markdown jetable et un fournisseur déjà accessible. Contrôlez le fichier généré avant de traiter un dossier. Le cloud reçoit le contenu de la tâche ; un modèle local exige un serveur actif et un modèle téléchargé.
</TLDR>

## Étape 1 : configurer le premier fournisseur

1. [Installez et activez Notemd](./installation), puis ouvrez **Settings → Notemd**.
2. Choisissez le fournisseur, son adresse, ses identifiants si requis et un modèle accessible à votre compte. **Fetch models** découvre les modèles compatibles ; leur présence ne garantit pas la génération.
3. Lancez **Tester la connexion** et corrigez les erreurs d’adresse, de modèle ou d’authentification.
4. Cherchez **Chemin du dossier des notes de concept** et choisissez un dossier dédié, par exemple `concepts`. Le chemin initial est vide : `concepts/` est un exemple, pas une destination préconfigurée.

Pour Ollama, téléchargez d’abord un modèle et utilisez son nom exact ; l’adresse prédéfinie est `http://localhost:11434/api`. Pour LM Studio, lancez le serveur et choisissez `LMStudio`. Voir les [modèles locaux](../providers/local). La recherche Web reste connectée même avec une synthèse locale.

## Étape 2 : essayer une première tâche

Créez `Notemd trial.md` avec un paragraphe que vous pouvez transmettre au fournisseur :

```text
Les modèles d’apprentissage automatique utilisent des réseaux de neurones pour apprendre à partir d’exemples.
```

Lancez **Traiter le fichier (ajouter des liens)**. Par défaut, un fichier voisin `Notemd trial_processed.md` est créé et la source est conservée. Ouvrez-le et contrôlez les liens. Exemple possible :

```markdown
Les modèles d’[[apprentissage automatique]] utilisent des [[réseaux de neurones]] pour apprendre à partir d’exemples.
```

Le dossier de concepts choisi peut aussi recevoir des notes. Les fichiers et liens sont à relire : le modèle peut omettre un concept ou proposer une distinction incorrecte.

## Étape 3 : explorer les fonctions

### Extraire des notes de concepts

**Extraire les concepts (fichier actuel)** ne réécrit pas la source et exige un dossier de concepts. L’extraction autonome produit par défaut des titres seuls, sans lien de retour vers la source. Activez ces liens explicitement. Voir les [notes de concepts](../features/concept-notes).

### Rechercher et synthétiser

Sélectionnez un sujet dans l’éditeur Markdown, ou utilisez le titre, puis lancez **Rechercher et résumer**. Choisissez explicitement Tavily avec sa clé ou DuckDuckGo. La synthèse est ajoutée à la note ; ouvrez les sources avant de vous fier aux affirmations.

### Enchaîner des actions

Le bouton **One-Click Extract** utilise exactement :

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Il ajoute des liens, génère du contenu pour les notes admissibles du dossier de concepts ou du dossier choisi, puis répare Mermaid dans le dossier complete. Des notes préexistantes peuvent donc être traitées. Utilisez un dossier d’essai dédié. La chaîne par défaut n’ajoute ni recherche Web ni génération de diagrammes.

## Annulation et contrôle des sorties

**Annuler** arrête la suite du travail. Les sorties terminées restent présentes : ce n’est pas une transaction annulable, ni une garantie d’arrêt de génération ou de facturation distante. Attendez la fin de l’arrêt, puis examinez les chemins et conflits de récupération avant de relancer.

## Dépannage

- Authentification ou modèle absent : vérifiez le profil exact, puis **Tester la connexion**.
- Concepts absents : vérifiez que leur dossier est choisi et activé.
- Liens peu utiles : examinez réponse et prompt ; aucun nombre minimal de mots ne garantit l’extraction.
- Quotas : conservez `batchConcurrency: 1` pendant le diagnostic.
