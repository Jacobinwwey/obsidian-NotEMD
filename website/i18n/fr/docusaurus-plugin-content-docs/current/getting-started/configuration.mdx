# Configuration

<TLDR>
Ouvrez **Settings → Notemd** et cherchez le champ voulu. Configurez fournisseur et sorties avant de traiter les notes. Testez chaque modification sur une note : une opération en cours peut conserver les paramètres capturés au démarrage.
</TLDR>

## Vue d’ensemble

DeepSeek est le fournisseur actif par défaut, sans identifiants renseignés. Un préréglage ne crée ni compte, ni modèle installé, ni droit d’accès. Voir les [fournisseurs](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Recherche des paramètres et favoris

- **Search settings** recherche noms, descriptions, alias et catégories visibles, puis mène au champ.
- **★ Favorites** liste les paramètres enregistrés avec description, catégorie et destination. Ils persistent dans le coffre ; les identifiants obsolètes sont écartés.
- Le chevron replie la barre de découverte ; la requête est conservée à sa réouverture.
- La liste de favoris et le filtre de recherche limité aux favoris sont distincts.

**Diagram preview export PPI** vaut **300**, avec une plage de **72–600**. Il règle la rastérisation PNG ; SVG/PDF conservent la géométrie vectorielle lorsque l’export le permet. **Also export complete Mermaid visuals** contrôle les fichiers compagnons, pas la visibilité de Mermaid dans la prévisualisation Drawnix.

## 1. Fournisseur

Choisissez fournisseur, adresse adaptée au protocole, identifiants requis et modèle accessible. **Fetch models** découvre les modèles ; **Tester la connexion** teste la connexion. La liste et la génération sont deux vérifications distinctes.

Un serveur local doit fonctionner avec un modèle chargé. Un fournisseur cloud reçoit le contenu envoyé ; vérifiez aussi les routes propres à chaque tâche avant de traiter des notes privées.

## 2. Modèles par tâche

`useMultiModelSettings` permet des couples fournisseur/modèle distincts pour liens, génération depuis les titres, recherche, traduction, concepts, extraction originale et synthèse Mermaid. Un modèle spécifique vide reprend celui du fournisseur choisi. Sans cette option, le fournisseur actif est utilisé.

Comparez exactitude, latence et tarif réel sur une note représentative. Aucun classement ni accès garanti aux modèles n’est annoncé.

## 3. Destinations

| Tâche | Sortie par défaut |
| ------ | ------------------------- |
| Ajout de liens | Fichier voisin `_processed.md` ; déplacement de l’original désactivé |
| Extraction autonome de concepts | Dossier choisi requis ; titres seuls, sans liens de retour |
| Traduction | Fichier voisin `_<language>.md` ; la destination existante peut être écrasée |
| Recherche | Synthèse ajoutée à la note Markdown active |
| Génération par lot depuis les titres | Écriture du contenu puis déplacement des notes admissibles vers le dossier voisin `<folder>_complete` lorsque possible |
| Prévisualisation/export | Choisir une source ou un export visuel pris en charge et contrôler le chemin annoncé |

Le dossier de concepts est initialement vide. `concepts` est un choix possible. Les [modèles de notes de concepts](../features/concept-notes) sont limités aux formes minimale et complète ; aucun moteur général de variables de modèle n’est fourni.

Suffixe de traitement, dossier traité, suffixe de traduction et dossier de traduction sont indépendants. Vérifiez les destinations existantes et les conflits de récupération. Annuler ne restaure pas les écritures terminées.

## 4. Langues

L’interface dispose de **21 langues** et le site de **34 routes linguistiques**. `uiLocale: auto` suit la correspondance disponible et revient à l’anglais si nécessaire.

La langue de contenu est indépendante et vaut anglais par défaut. Les options par tâche s’appliquent aux liens, titres, recherche, concepts et synthèses Mermaid. La traduction suit la langue de sortie choisie (`language`), pas celle de l’interface. Les capacités du modèle restent une autre question.

## 5. Recherche

Choisissez **Tavily** avec sa clé ou **DuckDuckGo** explicitement. Une clé Tavily vide ne bascule pas sur DuckDuckGo. Les deux utilisent le réseau ; DuckDuckGo peut aussi charger les pages trouvées.

La génération depuis les titres ne recherche pas par défaut : activez `enableResearchInGenerateContent` pour l’ajouter. La recherche locale est elle aussi désactivée par défaut, avec des périmètres de dossiers et de tâches distincts. Ses extraits sont transmis au LLM s’ils alimentent le contexte.

## 6. Workflows

Utilisez le constructeur ou une définition DSL par ligne. Définition livrée :

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` sépare le nom et les actions ; `>` sépare les identifiants. Par défaut, une erreur signalée arrête la chaîne. Voir les [workflows](../features/workflows) pour le contexte de dossier et la poursuite après erreur.

## 7. Paramètres avancés

| Paramètre | Défaut | Effet |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Fournisseur sans routage par tâche |
| `useMultiModelSettings` | `false` | Choix fournisseur/modèle par tâche |
| `useCustomConceptNoteFolder` | `true` | Autoriser les concepts après choix d’un dossier |
| `conceptNoteFolder` | `''` | Aucun dossier choisi initialement |
| `extractConceptsMinimalTemplate` | `true` | Concepts autonomes limités au titre |
| `extractConceptsAddBacklink` | `false` | Activer explicitement les liens de retour autonomes |
| `moveOriginalFileOnProcess` | `false` | Conserver la source pendant l’ajout de liens |
| `chunkWordCount` | `3000` | Taille approximative en mots, pas limite de tokens |
| `batchConcurrency` | `1` | Concurrence des lots |
| `enableBatchParallelism` | `false` | Parallélisme uniquement sur les chemins utilisant ce réglage |
| `enableStableApiCall` | `false` | Mode de requête stable explicite |
| `customWorkflowErrorStrategy` | `stop_on_error` | Arrêter la chaîne sur erreur signalée |

Découpage et budget de tokens de sortie sont distincts. Des fragments plus courts ne garantissent pas de respecter la fenêtre du modèle. Réduire la concurrence peut soulager les quotas sans supprimer tous les codes 429.

## Profils de configuration

Les paramètres appartiennent au coffre. Sauvegardez-les avant modification. Les profils de fournisseurs expurgés ne sont pas une sauvegarde complète ; contrôlez adresses et métadonnées avant partage. Ne publiez ni paramètres bruts ni corps de diagnostic contenant des notes privées.

## Diagnostiquer la configuration

Testez le couple exact avec **Tester la connexion**, puis une petite note. Cherchez les champs par nom, vérifiez catégorie, visibilité développeur et coffre choisi. Signalez les échecs reproductibles avec version et configuration expurgée.
