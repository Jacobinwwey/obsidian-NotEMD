# Installation

<TLDR>
Installez **Notemd** depuis les extensions communautaires d’Obsidian, ou copiez les trois fichiers d’une même version GitHub dans votre coffre. Activez l’extension, configurez un fournisseur et vérifiez une note d’essai. Les serveurs locaux et les exportateurs natifs ont leurs propres prérequis.
</TLDR>

## Méthode 1 : extensions communautaires (recommandée)

1. Dans le coffre voulu, ouvrez **Settings → Community plugins**.
2. Autorisez les extensions si nécessaire, puis choisissez **Browse**.
3. Cherchez **Notemd**, vérifiez le dépôt `Jacobinwwey/obsidian-NotEMD`, puis cliquez sur **Install**.
4. Cliquez sur **Enable**. Ouvrez la barre latérale Notemd depuis le ruban ou la palette de commandes.

[Ouvrir Notemd dans Obsidian](obsidian://show-plugin?id=notemd). Si votre navigateur ne reconnaît pas ce lien, utilisez les étapes ci-dessus.

## Méthode 2 : installation manuelle

### Prérequis

Disposez d’Obsidian et d’un coffre sauvegardable. Le manifeste déclare Obsidian `0.15.0` au minimum ; cela ne prouve pas que la version actuelle a été testée sur cette ancienne version.

### Étapes

1. Téléchargez `main.js`, `manifest.json` et `styles.css` depuis une même [version GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). Le `README.md` fourni est une référence, pas un fichier requis à l’exécution.
2. Copiez-les dans `<vault>/.obsidian/plugins/notemd/`. Adaptez `.obsidian` si le coffre utilise un autre répertoire de configuration.
3. Rechargez Obsidian et activez Notemd dans **Community plugins**.
4. Vérifiez la version affichée. Ne mélangez pas un manifeste récent et un ancien bundle.

## Autre possibilité : BRAT

Si vous utilisez déjà [BRAT](https://github.com/TfTHacker/obsidian42-brat), ajoutez `Jacobinwwey/obsidian-NotEMD` dans son parcours d’extension bêta. Pour reproduire un défaut, choisissez une version précise. BRAT reste facultatif.

## Vérification

Choisissez un fournisseur et un modèle accessibles dans les paramètres, puis lancez **Tester la connexion**. Suivez ensuite le [démarrage rapide](./quick-start) avec une copie de note : certains tests de connexion vérifient seulement l’accès à la liste des modèles, pas la génération ni l’écriture.

## Configuration requise

| Élément | Limite |
| --------- | ---------- |
| Manifeste | Obsidian minimum `0.15.0` déclaré ; `isDesktopOnly` vaut false |
| Preuves de validation | Consultez le compte rendu daté de la version ; appareils mobiles physiques et Obsidian 0.15.0 non vérifiés |
| LLM hébergé | Réseau, compte/clé autorisés et modèle pris en charge |
| LLM local | Serveur installé et lancé séparément ; modèle téléchargé ou chargé |
| Export natif de diapositives ou circuits | Outils de bureau et dépendances propres au format ; vérifier l’environnement avant export |

Aucune garantie globale de version d’OS ne couvre tous les exportateurs. Une prévisualisation de circuit ne valide pas sa compilation TeX native ; un essai sur ordinateur ne valide pas le mobile.

## Désinstallation

Désactivez ou désinstallez l’extension dans Obsidian. Les notes et productions restent des fichiers du coffre : examinez-les avant toute suppression. Sauvegardez les paramètres pour une réinstallation. Désinstaller n’annule pas les modifications déjà effectuées.

## Mise à jour

Utilisez **Check for updates**, puis mettez Notemd à jour. En installation manuelle, arrêtez les tâches, sauvegardez coffre et paramètres, remplacez les trois fichiers depuis la même version et rechargez. Lisez les notes de version et testez une petite entrée avant les lots.

Ne remplacez pas les paramètres du coffre par un fichier de publication. Pour revenir en arrière, restaurez délibérément une version compatible et conservez les productions nécessaires.
