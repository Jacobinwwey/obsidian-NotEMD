# Prompts personnalisés

<TLDR>
Un prompt personnalisé remplace celui de la tâche quand les options globale et locale sont activées et le texte non vide. Vous devez préserver son contrat de sortie : aucun moteur automatique ne rétablit toutes les instructions omises.
</TLDR>

## Vue d’ensemble

Testez d’abord le prompt intégré. L’apprentissage ciblé ou la réduction des synonymes peut suffire. Personnalisez pour une politique d’extraction, une structure ou un style précis, puis comparez avant les lots.

## Fonctionnement

### Composition

Notemd choisit le prompt intégré ou personnalisé, ajoute les consignes de langue et de domaine applicables et remplace les variables fournies par la tâche. Le contenu peut aussi être un message séparé. Les variables de recherche ne sont pas universelles.

Un remplacement peut supprimer le contrat `CONCEPT:` ou le contexte recherché. Une requête valide ne garantit ni sortie analysable ni preuves suffisantes.

### Variables

Respectez les majuscules et accolades simples :

| Tâche | Variables fournies |
| ------ | ----------------------- |
| Génération depuis le titre | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Synthèse de recherche | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Traduction | `{LANGUAGE}`, `{TEXT}` |
| Extraction originale | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` suit la politique linguistique de la tâche. Liens et concepts autonomes transmettent le texte comme contenu ; ne leur inventez pas de variable. Les noms inconnus ne sont pas remplis automatiquement. Ces substitutions ne sont pas des modèles de fichiers de concepts.

### Domaine d’apprentissage ciblé

Activez l’option et indiquez un domaine, par exemple `génie électrique`. Une consigne `Relevant Fields` guide le modèle, sans constituer un filtre strict ni garantir l’exclusion des autres sujets.

## Configuration

| Tâche | Option d’activation | Champ du prompt |
| ------ | --------------- | -------------- |
| Ajout de liens | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Génération depuis les titres | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Synthèse de recherche | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Synthèse Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Concepts | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Traduction | `useCustomPromptForTranslate` | `translatePrompt` |
| Extraction originale | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Toutes requièrent `enableGlobalCustomPrompts`. Un texte vide reprend le prompt intégré. L’extraction originale fusionnée utilise son propre format et ne partage pas le remplacement ordinaire. La génération de diagrammes impose ses sorties typées ; le prompt de synthèse Mermaid n’est pas universel.

## Exemple

Pour les concepts de circuits, activez les options globale et d’extraction et conservez le marqueur du parseur :

```text
Extrais les concepts centraux du génie électrique dans la note fournie.
Privilégie les composants précis et mécanismes physiques aux noms génériques.
Retourne un concept par ligne sous cette forme exacte :
CONCEPT: Nom du terme
N’ajoute ni explications ni bloc de code englobant.
```

Testez une copie et contrôlez entrées, noms de fichiers et omissions, puis comparez au prompt intégré. Sauvegardez l’ancien texte pour pouvoir le restaurer.

## Conseils

- Testez une seule tâche à la fois, avant d’augmenter les lots.
- Conservez les preuves dans la recherche et les extraits exacts dans l’extraction.
- Traduisez les consignes sans changer marqueurs ni identifiants.
- Revérifiez après changement de modèle : les instructions ne sont pas des garanties de validation.
