# Présentation de Notemd

<TLDR>
Notemd est une extension Obsidian sous MIT qui transforme les notes en fichiers vérifiables : Markdown lié, concepts, synthèses, traductions et diagrammes. Choisissez fournisseur, tâche et périmètre ; relisez les résultats du modèle avant de les intégrer à vos connaissances.
</TLDR>

## Qu’est-ce que Notemd ?

Les 36 préréglages relient les tâches du coffre à des API hébergées, passerelles et serveurs locaux. Chaque tâche crée ou modifie des fichiers selon son contrat. Exécutez les actions seules ou enchaînez-les dans la barre latérale.

Les sorties restent dans le coffre, mais un fournisseur cloud reçoit le contenu envoyé. La recherche Web utilise aussi le réseau. Stockage local et inférence locale sont deux choix distincts.

## Capacités principales

### Liens et concepts

Le modèle propose concepts et liens. L’ajout de liens produit une note traitée séparée par défaut. Les concepts exigent un dossier configuré ; l’extraction autonome donne des titres sans backlinks par défaut. Voir les [liens](./features/wiki-links) et [concepts](./features/concept-notes).

### Recherche et contexte local

Tavily ou DuckDuckGo fournissent le contexte Web pour une synthèse ajoutée à la note. La recherche locale délimitée peut apporter des extraits ; l’index est lexical, pas sémantique par embeddings. Voir la [recherche](./features/research).

### Traduction et extraction originale

Traduisez un fichier ou dossier ; extrayez les passages répondant à une question et vérifiez les citations contre la source. Une sélection ne réduit pas la traduction du fichier entier. Voir la [traduction](./features/translation).

### Diagrammes et exports

Sélectionnez plusieurs types de diagramme par exécution et plusieurs formats indépendants pour chacun. Décocher un type conserve ses formats ; sans sélection, le contenu est analysé automatiquement. [Manuel des diagrammes: Draw.io, Drawnix, Mermaid, CircuitikZ](./features/diagrams).

### Workflows

**One-Click Extract** ajoute liens, génère les notes admissibles du dossier de concepts ou choisi, puis répare Mermaid dans complete. Les concepts préexistants peuvent être inclus. Les actions gardent leurs prérequis et sorties. Voir le [DSL](./features/workflows).

## Commencer

1. [Installer](./getting-started/installation) dans le bon coffre.
2. Configurer un modèle accessible et tester une note jetable.
3. Choisir dossier de concepts et destinations.
4. Relire avant un lot plus grand.

Aucun temps de traitement ni longueur minimale ne garantit un résultat utile ; commencez avec une entrée entièrement contrôlable.

## Orientation des diagrammes

Les entrées prises en charge utilisent des spécifications typées et des rendus par cible. `DiagramSpec` définit le contrat développeur, pas une prise en charge de toute syntaxe ou disposition de référence.

Les circuits sont limités aux structures `circuitikz` compatibles. TikZJax est externe ; la prévisualisation ne prouve pas une compilation native. Les relations Drawnix statiques ne garantissent pas des flèches attachées après réorganisation.

## Architecture

La tâche est routée vers le fournisseur choisi, puis sa réponse est analysée/validée et écrite. Recherche et index local apportent un contexte facultatif. Prévisualisation et export ajoutent leurs contraintes de format.

Le [guide développeur](./developers/overview) identifie modules, contrats et vérification. Le [guide Agent](./agents/overview) expose les commandes bornées ; le registre interne n’est pas une API publique générale.

## Comparer les outils {#notemd-vs-other-obsidian-ai-plugins}

Choisissez selon transformation de fichiers, dialogue, liens déterministes, recherche ou édition native. Consultez les docs actuelles et testez le même échantillon en enregistrant versions et fonctions activées.

## Données et compatibilité

Le cloud reçoit les entrées, le moteur de recherche les questions, et les extraits locaux deviennent contexte si activés. Vérifiez toutes les routes. Annuler arrête la suite prise en charge et conserve les sorties terminées, sans garantir l’arrêt de génération ni facturation distante.

Le manifeste déclare Obsidian `0.15.0` minimum et autorise le mobile ; cette version et les appareils physiques ne sont pas actuellement vérifiés. Certains exports natifs exigent des outils de bureau. Les 34 routes du site, 21 langues d’interface et capacités linguistiques du modèle restent distinctes.
