# Konfigurasi

<TLDR>Buka **Settings → Notemd** dan cari pengaturan yang diperlukan. Atur penyedia serta tujuan sebelum memproses catatan. Coba perubahan pada satu catatan terlebih dahulu; operasi yang berjalan dapat mempertahankan konfigurasi saat dimulai.</TLDR>

## Gambaran pengaturan

Penyedia aktif bawaan adalah DeepSeek dengan kredensial awal kosong. Memilih preset tidak membuat akun, memasang model, atau memberikan akses hosted. [Panduan penyedia](../providers/overview) menjelaskan protokol dan penemuan model.

## Menemukan pengaturan dan favorit

- **Search settings** mencocokkan nama, deskripsi, alias, dan kategori terlihat, lalu menuju bidang terpilih.
- **★ Favorites** menampilkan pengaturan tersimpan dengan deskripsi, kategori, dan tujuan navigasi. Favorit milik Vault saat ini, bertahan setelah restart, dan membuang ID usang.
- Tutup bilah pencarian dengan chevron untuk menghemat ruang; membukanya lagi memulihkan kueri.
- Daftar favorit dan filter pencarian khusus favorit adalah kontrol terpisah.

**Diagram preview export PPI** bawaan **300 PPI**, rentang **72-600**. Ini memengaruhi rasterisasi PNG; SVG/PDF mempertahankan geometri vektor pada ekspor yang mendukungnya. **Also export complete Mermaid visuals** mengatur berkas pendamping, bukan visibilitas Mermaid dalam pratinjau Drawnix.

Pilih beberapa jenis diagram dalam satu proses dan beberapa format keluaran secara terpisah untuk tiap jenis. Menghapus centang tetap menyimpan formatnya; tanpa pilihan, isi dianalisis otomatis.

Atur folder perantara bersama relatif terhadap Vault, atau kosongkan untuk memakai `notemd_assert/` di samping tiap sumber. Catatan pemulihan, cache render, dan lampiran opsional disimpan di sana. Pertahankan file yang masih dirujuk; perubahan folder hanya berlaku untuk proses baru.

## 1. Penyedia

Pilih penyedia, masukkan kredensial bila perlu, pertahankan endpoint sesuai protokol, dan pilih model yang dapat diakses. Gunakan **Fetch models** jika didukung, lalu **Uji koneksi**. Berhasil mendaftar model dan menghasilkan respons adalah dua pemeriksaan berbeda.

Penyedia lokal membutuhkan server berjalan dan model diunduh/dimuat. Cloud atau gateway menerima isi tugas yang dikirim. Periksa penyedia per tugas serta penyedia aktif untuk materi privat.

## 2. Model per tugas

Aktifkan `useMultiModelSettings` untuk pasangan penyedia/model terpisah bagi tautan, generasi judul, riset, terjemahan, konsep, kutipan asli, dan ringkasan Mermaid. Penggantian model kosong menggunakan model penyedia terkait. Jika tidak aktif, tugas memakai penyedia aktif.

Bandingkan menggunakan catatan representatif, ketepatan hasil, latensi, dan harga akun nyata. Dokumentasi tidak memberi peringkat model atau menjamin ketersediaannya.

## 3. Keluaran

| Tugas | Perilaku bawaan |
| ------ | ------------------------- |
| Tambah tautan | Berkas `_processed.md` terpisah di samping sumber; pemindahan sumber nonaktif |
| Ekstraksi konsep mandiri | Memerlukan folder konsep; catatan hanya judul tanpa tautan balik |
| Terjemahan | Berkas `_<language>.md` di samping sumber; tujuan yang ada dapat ditimpa |
| Riset | Menambahkan ringkasan ke catatan Markdown aktif |
| Generasi batch dari judul | Menulis isi dan memindahkan catatan yang memenuhi syarat ke `<folder>_complete` sejajar yang dilaporkan jika tujuan memungkinkan |
| Pratinjau/ekspor diagram | File terpilih otomatis diekspor di samping catatan sumber atau langsung ke folder keluaran yang ditentukan. Nama menyertakan jenis, seperti `topic_drawnix.pdf` dan `topic_flowchart.svg`. Benturan nama menambahkan `-2`, `-3`, dan seterusnya tanpa menimpa file. |
Folder konsep awalnya kosong. `concepts` adalah nama yang dapat dipilih, bukan lokasi bawaan. Ekstraksi mandiri memakai bentuk minimal/penuh yang didukung, bukan mesin variabel templat umum. Lihat [catatan konsep](../features/concept-notes).

Sufiks tambah tautan, folder hasil, sufiks terjemahan, dan tujuan terjemahan adalah pengaturan terpisah. Periksa tujuan sebelum mengulang penulisan. Pesan pemulihan/konflik menunjukkan hasil yang perlu diperiksa; pembatalan tidak mengembalikan penulisan selesai.

## 4. Bahasa

Plugin memiliki **21 bahasa UI**, sedangkan situs memiliki **34 rute bahasa**. `uiLocale: auto` mengikuti pemetaan tersedia; bahasa UI yang tidak didukung menggunakan bahasa Inggris.

Bahasa isi generasi terpisah dan bawaannya Inggris. Aktifkan bahasa per tugas jika tautan, judul, riset, konsep, atau Mermaid memerlukan bahasa berbeda. Terjemahan memakai bahasa keluaran terpilih (`language`), tidak bergantung UI. Kemampuan bahasa model terpisah dari jumlah bahasa UI/situs.

## 5. Integrasi pencarian

Pilih **Tavily** dengan kunci API atau pilih **DuckDuckGo** secara eksplisit. Kunci Tavily kosong tidak otomatis memilih DuckDuckGo. Keduanya memakai jaringan; DuckDuckGo juga dapat mengambil halaman hasil.

Generasi judul tidak melakukan riset secara bawaan. Aktifkan `enableResearchInGenerateContent` hanya jika diperlukan. Pengambilan pengetahuan lokal juga nonaktif secara bawaan, dengan lingkup folder/tugas tersendiri. Kutipan lokal yang dipakai sebagai konteks tetap dikirim ke LLM tugas meskipun indeks dibuat lokal.

## 6. Alur kerja

Gunakan pembangun alur atau satu definisi DSL bernama per baris. Bawaan:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` memisahkan nama tombol dari tindakan, `>` memisahkan ID. Kebijakan awal berhenti pada kegagalan langkah yang dilaporkan. [Alur kerja](../features/workflows) menjelaskan ID, konteks folder, dan akibat melanjutkan setelah kesalahan.

## 7. Pengaturan lanjutan

| Pengaturan | Bawaan | Efek |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Penyedia tanpa perutean per tugas |
| `useMultiModelSettings` | `false` | Aktifkan penyedia/model terpisah |
| `useCustomConceptNoteFolder` | `true` | Izinkan berkas konsep setelah folder dipilih |
| `conceptNoteFolder` | `''` | Belum ada folder konsep terpilih |
| `extractConceptsMinimalTemplate` | `true` | Buat konsep mandiri hanya judul |
| `extractConceptsAddBacklink` | `false` | Tautan balik ekstraksi mandiri hanya jika aktif |
| `moveOriginalFileOnProcess` | `false` | Pertahankan sumber saat menambah tautan |
| `chunkWordCount` | `3000` | Ukuran potongan perkiraan, bukan batas token penyedia |
| `batchConcurrency` | `1` | Konkurensi batch bawaan |
| `enableBatchParallelism` | `false` | Aktifkan paralelisme pada jalur yang memakai sakelar ini |
| `enableStableApiCall` | `false` | Mode permintaan stabil eksplisit |
| `customWorkflowErrorStrategy` | `stop_on_error` | Hentikan alur pada kesalahan yang dilaporkan |

Pemotongan dan anggaran token keluaran berbeda. Potongan lebih kecil tidak menjamin batas konteks terpenuhi. Konkurensi rendah mengurangi tekanan kuota tetapi tidak mencegah semua 429.

## Profil konfigurasi

Pengaturan berada dalam data plugin Vault. Cadangkan sebelum mengubah konfigurasi yang bekerja. Ekspor profil memiliki aturan redaksi sendiri, bukan cadangan penuh Vault. Periksa URL dan metadata sebelum berbagi, termasuk ekspor teredaksi. Jangan publikasikan pengaturan mentah atau diagnostik berisi catatan privat.

## Masalah konfigurasi

Jalankan **Uji koneksi** pada penyedia/model persis, lalu coba catatan kecil. Jika pengaturan tidak terlihat, cari nama, periksa kategori dan visibilitas mode pengembang, serta pastikan Vault benar. Laporkan masalah yang dapat direproduksi dengan versi dan detail konfigurasi yang telah dibersihkan.

## 1.9.10 — Pratinjau aman dan pengaturan lokal Vault

Pratinjau SVG yang diimpor menghapus konten aktif dan sumber eksternal, sambil mempertahankan label Tionghoa dan gaya panel. Penyedia lokal dipisahkan per Vault; impor daftar lama secara eksplisit melalui pengaturan, dengan mempertahankan daftar asli dan konfigurasi yang ada. Presentasi memakai server loopback yang mengelola pengguna bersama. Kegagalan menyimpan favorit dan menyalin dilaporkan; penghapusan mengikuti preferensi Vault. Kompatibilitas PNG tetap aktif: gambar asli disimpan dan salinan PPI lebih rendah yang terverifikasi ditambahkan hanya bila perlu. Drawnix tidak memiliki batas relasi tetap; presentasi tetap memiliki pengaturan terpisah. Instal berkas versi yang sama, muat ulang, dan uji satu catatan sebelum pemrosesan massal.
