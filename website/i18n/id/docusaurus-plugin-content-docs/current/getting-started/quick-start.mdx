# Mulai cepat

<TLDR>Mulai dengan satu catatan Markdown uji dan penyedia yang sudah dapat diakses. Periksa berkas hasil sebelum memproses folder. Panggilan cloud mengirim isi tugas ke penyedia; model lokal tetap membutuhkan server berjalan dan model terunduh.</TLDR>

## Langkah 1: Siapkan penyedia pertama

1. [Pasang dan aktifkan](./installation), lalu buka **Settings → Notemd**.
2. Pilih penyedia, masukkan endpoint/kredensial yang diperlukan, dan pilih model yang tersedia bagi akun. Gunakan **Fetch models** jika didukung; model terdaftar tetap perlu tes generasi.
3. Jalankan **Uji koneksi**. Atasi kesalahan autentikasi, model, atau endpoint sebelum memulai alur.
4. Cari **Jalur folder catatan konsep**. Pilih folder khusus seperti `concepts` untuk berkas konsep. Nilai awalnya kosong; `concepts/` adalah contoh pilihan, bukan tujuan bawaan.

Untuk Ollama, unduh model dahulu dan masukkan nama lokal persis. Endpoint preset adalah `http://localhost:11434/api`. Untuk LM Studio, mulai server lokal dan gunakan preset `LMStudio`. Lihat [model lokal](../providers/local). Riset web tetap membutuhkan jaringan meskipun model peringkas lokal.

## Langkah 2: Coba tugas pertama

Buat `Notemd trial.md` dengan paragraf pendek yang boleh dikirim ke penyedia:

```text
Model pembelajaran mesin menggunakan jaringan saraf untuk mempelajari pola dari contoh.
```

Jalankan **Proses file (tambah tautan)** dari bilah samping atau palet. Secara bawaan, Notemd membuat `Notemd trial_processed.md` di folder sumber dan mempertahankan aslinya. Buka hasil dan periksa tautan; keluaran model bervariasi. Contoh:

```markdown
Model [[pembelajaran mesin]] menggunakan [[jaringan saraf]] untuk mempelajari pola dari contoh.
```

Folder konsep yang dipilih juga dapat menerima catatan. Periksa berkas dan tautan; pemrosesan tidak membuktikan semua konsep penting telah dikenali dengan benar.

## Langkah 3: Coba fitur lain

### Ekstraksi konsep

**Ekstrak konsep (file saat ini)** mengekstrak tanpa menulis ulang sumber dan memerlukan folder konsep. Catatan ekstraksi mandiri bawaan hanya berisi judul, tanpa tautan balik sumber. Aktifkan tautan balik jika perlu. [Catatan konsep](../features/concept-notes) membahas perbedaannya dengan hasil tambah tautan.

### Riset dan ringkasan

Pilih topik dalam editor Markdown terbuka atau gunakan judul, lalu jalankan **Riset & rangkum**. Pilih Tavily beserta kunci API atau DuckDuckGo secara eksplisit. Ringkasan ditambahkan ke catatan aktif. Buka sumber dan verifikasi sebelum mengandalkan klaim.

### Alur sekali klik

**One-Click Extract** bawaan menjalankan definisi persis berikut:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Alur menambah tautan, menghasilkan isi untuk catatan yang memenuhi syarat di folder konsep/pilihan, lalu memperbaiki blok Mermaid dalam folder complete hasil generasi. Catatan konsep lama juga dapat ikut diproses. Gunakan folder uji khusus. Riset web dan generasi diagram tidak otomatis ditambahkan.

## Pembatalan dan pemeriksaan hasil

Gunakan **Batal** untuk menghentikan pekerjaan lanjutan. Hasil selesai tetap ada; pembatalan bukan transaksi undo dan tidak menjamin penyedia berhenti menghasilkan atau menagih. Tunggu tugas selesai menangani pembatalan sebelum menjalankan lagi. Periksa tujuan dan konflik pemulihan, jangan menganggap tugas batal tidak menghasilkan apa pun.

## Pemecahan masalah

- Autentikasi/model: periksa profil persis dan ulangi **Uji koneksi**.
- Tidak ada konsep: pastikan folder sudah dipilih dan diaktifkan.
- Tautan tidak berguna: periksa respons dan prompt; tidak ada jumlah kata minimum yang menjamin ekstraksi.
- Batas laju: pertahankan konkurensi bawaan `1` saat memeriksa kuota.
