# Pemasangan

<TLDR>Pasang **Notemd** dari Community plugins, atau salin tiga berkas plugin dari satu GitHub Release ke Vault. Aktifkan, atur penyedia, lalu coba catatan uji. Server model dan alat ekspor native opsional memiliki prasyarat terpisah.</TLDR>

## Cara 1: Plugin komunitas (disarankan)

1. Buka **Settings → Community plugins** di Vault yang dituju.
2. Izinkan plugin komunitas bila perlu, lalu pilih **Browse**.
3. Cari **Notemd**, pastikan repositorinya `Jacobinwwey/obsidian-NotEMD`, lalu pilih **Install**.
4. Pilih **Enable**. Buka bilah samping Notemd melalui ikon ribbon atau palet perintah.

[Buka Notemd di Obsidian](obsidian://show-plugin?id=notemd). Jika tautan tidak dapat dibuka, gunakan langkah manual di atas; membaca panduan tidak memerlukan penangan protokol khusus.

## Cara 2: Pemasangan manual

### Prasyarat

Gunakan aplikasi Obsidian yang terpasang dan Vault yang dapat dicadangkan. Manifest menyatakan versi minimum `0.15.0`; deklarasi ini bukan bukti kandidat terbaru telah diuji pada versi lama tersebut.

### Langkah

1. Buka [GitHub Releases](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest) dan unduh **`main.js`**, **`manifest.json`**, serta **`styles.css`** dari rilis yang sama. `README.md` disertakan sebagai referensi, bukan persyaratan runtime.
2. Buat `<vault>/.obsidian/plugins/notemd/` dan salin ketiga berkas. `.obsidian` adalah direktori konfigurasi bawaan; gunakan lokasi sebenarnya jika Vault memakai direktori berbeda.
3. Muat ulang Obsidian, buka **Community plugins**, dan aktifkan Notemd.
4. Periksa versi sebelum menyiapkan penyedia. Jangan mencampur manifest baru dengan bundle lama.

## Alternatif: BRAT

Jika sudah memakai [BRAT](https://github.com/TfTHacker/obsidian42-brat), tambahkan `Jacobinwwey/obsidian-NotEMD` melalui alur plugin beta. Pilih rilis tertentu saat mereproduksi bug. BRAT adalah alat eksternal opsional, bukan dependensi pemasangan biasa.

## Verifikasi

Buka pengaturan Notemd, pilih penyedia/model yang dapat diakses, lalu jalankan **Uji koneksi**. Lanjutkan [panduan awal](./quick-start) dengan salinan catatan. Sebagian tes hanya membuktikan endpoint daftar model dapat diakses; tugas nyata menguji generasi dan penyimpanan hasil.

## Persyaratan sistem

| Bagian | Batas dukungan |
| --------- | ---------- |
| Manifest plugin | Minimum Obsidian `0.15.0`; `isDesktopOnly` bernilai false |
| Bukti verifikasi | Lihat catatan penerimaan bertanggal untuk rilis; perangkat seluler fisik dan Obsidian 0.15.0 belum terverifikasi |
| LLM hosted | Jaringan, akun/kunci berizin, dan model yang didukung |
| LLM lokal | Server terpisah yang berjalan serta model yang sudah diunduh/dimuat |
| Ekspor slide / sirkuit native | Alat desktop dan dependensi format; periksa lingkungan ekspor sebelum menjalankan |

Tidak ada jaminan versi OS yang mencakup semua alat ekspor opsional. Pratinjau sirkuit dalam Notemd bukan bukti kompilasi TeX native; tes desktop tidak membuktikan perilaku seluler.

## Menghapus plugin

Nonaktifkan atau hapus dari Community plugins. Catatan dan artefak hasil tetap menjadi berkas Vault biasa; periksa sebelum menghapusnya. Cadangkan pengaturan jika ingin memasang kembali. Menghapus plugin tidak membatalkan perubahan catatan yang sudah selesai.

## Memperbarui

Gunakan **Check for updates**, lalu perbarui Notemd. Untuk manual, hentikan tugas aktif, cadangkan Vault dan pengaturan, ganti tiga berkas runtime dari rilis yang sama, lalu muat ulang. Baca catatan rilis dan coba tugas kecil sebelum kembali ke batch.

Jangan mengganti berkas pengaturan Vault dengan aset rilis. Untuk kembali ke versi lama, simpan cadangan dan pasang versi kompatibel yang diketahui secara sengaja; pertahankan hasil yang masih diperlukan.
