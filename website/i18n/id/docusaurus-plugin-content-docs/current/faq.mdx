# Pertanyaan umum

<TLDR>Mulai dengan catatan uji, penyedia yang dapat diakses, dan tujuan eksplisit. Jawaban berikut menjelaskan batas tugas yang diimplementasikan; ikuti panduan tertaut untuk setup dan verifikasi lengkap.</TLDR>

## Pertanyaan

### Bagaimana memasang Notemd?

Buka Settings → Community plugins → Browse, cari Notemd, lalu pasang dan aktifkan. Pemasangan manual memakai main.js, manifest.json, dan styles.css dari GitHub Release yang sama. Manifest menyatakan minimum Obsidian 0.15.0; versi lama itu dan perangkat seluler fisik belum diverifikasi oleh bukti rilis saat ini.

### Penyedia LLM apa yang didukung?

Registry memiliki 36 preset dalam lima keluarga: kompatibel OpenAI, Anthropic, Google, Azure OpenAI, dan Ollama. API hosted, gateway, dan server lokal membutuhkan endpoint, kredensial, serta model sendiri. Preset atau model terdaftar tidak menjamin ketersediaan upstream atau izin generasi sekarang.

### Bisakah menggunakan LLM lokal?

Bisa. Atur server Ollama, LM Studio, OVMS yang berjalan, atau endpoint mandiri kompatibel. Unduh/muat model dahulu dan uji tugas yang dituju. Inferensi lokal tidak menjadikan riset web, pemasangan dependensi, atau tugas lain yang diarahkan ke cloud sebagai operasi offline.

### Apa bedanya dengan ChatGPT?

Notemd berfokus pada operasi berkas Obsidian eksplisit: menautkan catatan, membuat konsep, menambahkan riset, menerjemahkan, dan menghasilkan artefak. Pilih jika alur Vault itu sesuai. Evaluasi alat lain berdasarkan penyimpanan, ekspor, dan integrasi terkini; alat chat juga dapat menyimpan riwayat dan membuat berkas.

### Bagaimana dibandingkan Copilot atau Smart Connections?

Bandingkan tugas yang diperlukan beserta versi, konfigurasi, dan dokumentasi tiap proyek. Notemd menyediakan transformasi catatan dan jalur pengambilan lokal leksikal terbatas, bukan antarmuka chat-with-vault umum atau pencarian semantik embedding. Situs tidak memberikan peringkat fitur terkini proyek lain.

### Layanan pencarian apa yang tersedia?

Pilih Tavily dengan kunci API atau pilih DuckDuckGo secara eksplisit. Kunci Tavily kosong tidak otomatis berpindah. Keduanya memakai jaringan. LLM merangkum konteks web dan lokal opsional, lalu menambahkan ringkasan ke Markdown aktif. Verifikasi URL sumber dan klaim penting.

### Apakah mendukung Mandarin dan bahasa lain?

UI plugin memiliki 21 bahasa dan situs 34 rute bahasa. Bahasa isi generasi diatur terpisah, dengan override per tugas yang didukung. Kemampuan dan kualitas terjemahan bergantung model, bukan jumlah bahasa UI atau situs.

### Bisakah membantu membaca makalah atau PDF?

Konversikan makalah ke Markdown yang dapat dibaca dengan alat eksternal sesuai, lalu periksa kesalahan rumus, tabel, dan gambar. Gunakan Notemd untuk konsep, kutipan asli, riset pertanyaan, terjemahan, atau diagram. Alur catatan standar tidak menjanjikan OCR PDF native atau ekstraksi setia semua dokumen biner.

### Diagram apa yang bisa dibuat?

Katalog eksekusi memuat 33 entri dengan sumber dan jalur pratinjau kompatibel. Mermaid, JSON Canvas, Vega-Lite, HTML/SVG editable, Draw.io, Drawnix, dan CircuitikZ terbatas melayani kebutuhan berbeda. Gunakan pilihan yang didukung dan periksa di aplikasi tujuan; pratinjau tidak membuktikan kesetiaan penyuntingan atau kompilasi native.

### Apakah gratis dan sumber terbuka?

Notemd tersedia dengan lisensi MIT. Akun penyedia, inferensi, pencarian, dan alat eksternal memiliki biaya serta syarat sendiri. Repositori publik dan kontribusi diterima. Kebebasan lisensi tidak berarti semua layanan terkonfigurasi gratis.

### Bisakah sepenuhnya offline?

Sebagian tugas dapat memakai model lokal setelah server, model, dan dependensi terpasang. Riset web tetap memerlukan jaringan, termasuk DuckDuckGo. Periksa penyedia per tugas dan dependensi ekspor sebelum memutus koneksi. Tidak ada jaminan offline menyeluruh untuk semua fitur.

### Apakah data dikirim ke cloud?

Prompt dan isi dikirim ke endpoint LLM terkonfigurasi. Pencarian menerima kueri dan pengambilan halaman menghubungi situs. Kutipan Vault hasil pengambilan lokal dapat masuk prompt cloud. Preset lokal juga dapat diubah ke alamat remote. Periksa routing dan redaksi log; penyimpanan lokal saja tidak membuktikan batas data hanya perangkat.

### Apa yang dijalankan One-Click Extract?

Bawaannya menambah tautan ke catatan aktif, menghasilkan isi catatan yang memenuhi syarat dalam folder konsep/pilihan, lalu memperbaiki Mermaid dalam complete. Konsep lama dapat ikut diproses. Riset web dan generasi diagram tidak otomatis ditambahkan. Panduan alur menjelaskan sintaks name::action>action persis.

### Apakah membatalkan tugas mengembalikan perubahan?

Tidak. Pembatalan menghentikan kerja lanjutan yang didukung dan mempertahankan hasil selesai. Permintaan atau penulisan yang diterima bisa selesai; tagihan dikendalikan penyedia. Tunggu tugas menetap, periksa jalur serta konflik pemulihan, lalu ulangi hanya pekerjaan yang dimaksud.

### Bisakah Agent mengotomatisasi Notemd?

Empat ekspor publik terbatas menyediakan profil teredaksi, kemampuan, kontrak pemanggilan, dan permukaan CLI melalui host Obsidian serta Vault tersedia. Perintah dapat menulis berkas ekspor. Operasi pemelihara repositori adalah kontrak berbeda; jumlah operasi internal bukan API otomatisasi publik. Mulai dari panduan Agent.

### Dari mana pengembang mulai?

Panduan pengembang memuat setup, perintah build/tes lengkap, kepemilikan modul, dan aturan perluasan. AGENTS.md adalah otoritas eksekusi dalam repo. Laporkan masalah yang dapat direproduksi dengan versi serta bukti teredaksi, dan verifikasi perubahan sebelum mengusulkan integrasi.
