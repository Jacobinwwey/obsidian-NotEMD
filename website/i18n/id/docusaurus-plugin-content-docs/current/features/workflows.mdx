# Alur kerja

<TLDR>Alur menjalankan tindakan yang ada secara berurutan. Tiap tindakan dapat meminta folder atau editor aktif. Ini bukan pipa teks: masukan, keluaran, dan efek samping tetap milik tiap tindakan. Mulai dari catatan uji dan folder khusus.</TLDR>

## Gambaran umum

Definisi **One-Click Extract** bawaan:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Tambahkan tautan ke catatan aktif; buat konsep jika foldernya telah diatur.
2. Hasilkan isi untuk catatan yang memenuhi syarat dalam folder konsep atau folder pilihan langkah batch, termasuk catatan lama.
3. Perbaiki blok Mermaid dalam folder complete generasi batch.

Alur bawaan tidak melakukan riset web. Generasi hanya memakai riset jika pengaturan terpisahnya diaktifkan. Lihat [batch](../advanced/batch-processing).

## Cara kerja

### Eksekusi

Langkah berjalan berurutan dan bilah samping melaporkan status/kegagalan. Pembatalan menghentikan langkah lanjutan dan diteruskan ke jalur permintaan yang didukung. Penulisan selesai tetap ada; tidak ada rollback seluruh alur.

Folder konsep menjadi pilihan awal. Generasi batch merekam folder sumber dan complete; perbaikan Mermaid berikutnya memakai complete. Tindakan lain tetap memiliki syarat berkas aktif, pilihan teks, atau interaksi masing-masing.

### Format DSL

Satu tombol bernama per baris. `::` memisahkan nama dan daftar tindakan; `>` memisahkan ID. Baris kosong dan baris berawalan `#` diabaikan. ID tidak dikenal ditolak.

```text
Ekstraksi dan diagram::extract-concepts-current>summarize-as-mermaid
```

Pilih tindakan melalui pembangun atau sunting DSL. ID stabil, label mengikuti bahasa UI. Varian folder memiliki ID sendiri, bukan aturan penggantian string umum.

| ID | Tindakan / prasyarat |
| ------------ | ----------------------- |
| `process-current-add-links` | Tambah tautan catatan aktif |
| `process-folder-add-links` | Tambah tautan dalam folder pilihan |
| `extract-concepts-current` | Ekstrak konsep catatan aktif |
| `extract-concepts-folder` | Ekstrak konsep folder pilihan |
| `generate-from-title` | Hasilkan isi dari judul aktif |
| `batch-generate-from-titles` | Hasilkan isi catatan folder yang memenuhi syarat |
| `research-and-summarize` | Riset pilihan/judul dalam editor Markdown terbuka |
| `summarize-as-mermaid` | Ringkas masukan aktif yang didukung menjadi Mermaid |
| `generate-diagram` | Pilih beberapa jenis diagram dalam satu proses dan beberapa format keluaran secara terpisah untuk tiap jenis. Menghapus centang tetap menyimpan formatnya; tanpa pilihan, isi dianalisis otomatis. |
| `preview-diagram` | Pratinjau sumber atau artefak diagram yang didukung |
| `translate-current-file` | Terjemahkan berkas aktif yang didukung |
| `batch-translate-folder` | Terjemahkan folder pilihan |
| `extract-original-text` | Ekstrak kutipan asli tertentu |
| `batch-extract-original-text` | Ekstrak kutipan berkas folder yang memenuhi syarat |
| `split-note-by-chapters` | Pisahkan catatan aktif menurut bab |
| `batch-mermaid-fix` | Perbaiki blok Mermaid dalam folder |
| `fix-formula-current` | Normalkan pembatas rumus catatan aktif |
| `batch-fix-formula` | Normalkan pembatas rumus dalam folder |
| `check-duplicates-current` | Periksa duplikat catatan aktif |
| `check-remove-duplicate-concepts` | Tinjau dan hapus konsep duplikat secara interaktif |
| `test-llm-connection` | Uji penyedia terkonfigurasi |
| `probe-slide-export-env` | Periksa lingkungan ekspor slide lokal |
| `export-slides` | Ekspor berkas aktif menjadi slide |

### Bawaan dan alur khusus

One-Click Extract adalah bawaan. Tombol tambahan adalah definisi Anda. Cari pengaturan alur, beri nama, pilih dan urutkan tindakan, lalu periksa tooltip bilah samping sebelum menjalankan. Perbaiki kesalahan parser dahulu.

## Konfigurasi

| Pengaturan | Bawaan | Efek |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Berhenti pada kegagalan langkah pertama yang dilaporkan |
| `useMultiModelSettings` | `false` | Gunakan penyedia aktif sampai perutean per tugas diaktifkan |
| `enableResearchInGenerateContent` | `false` | Riset judul nonaktif kecuali diaktifkan terpisah |

`continue_on_error` memungkinkan langkah berikut berjalan setelah kegagalan. Gunakan hanya jika langkah itu dapat memakai masukan tersisa; melanjutkan tidak menjadikan alur parsial berhasil seluruhnya.

### Model per tugas

Penyedia/model tetap milik tugas. Penggantian model kosong memakai konfigurasi penyedia terkait. Periksa tiap pilihan sebelum alur menangani materi privat.

## Contoh

Siapkan `trial-concepts` kosong, proses satu sumber uji, lalu periksa konsep dan folder complete yang dilaporkan. Jalankan tindakan terpisah dahulu jika tujuan belum jelas. Perluas lingkup setelah memeriksa hasil.

## Saran

- Pertahankan rantai yang mudah ditelusuri kegagalan dan kepemilikan hasilnya.
- Hindari pembersihan/penghapusan pada alur tanpa pengawasan; konfirmasi interaktif tetap berlaku.
- Setelah pembatalan/konflik, periksa log dan berkas sebelum retry.
- Uji model dan folder persis; tes koneksi tidak membuktikan kuota cukup untuk batch panjang.
