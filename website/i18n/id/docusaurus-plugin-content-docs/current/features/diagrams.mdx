# Diagram

<TLDR>
Pilih beberapa jenis diagram dalam satu proses dan beberapa format keluaran secara terpisah untuk tiap jenis. Menghapus centang tetap menyimpan formatnya; tanpa pilihan, isi dianalisis otomatis.
</TLDR>


Setiap pratinjau diagram memiliki zoom, geser, penyesuaian dan ukuran asli yang independen. Ctrl/Command + roda mouse memperbesar; roda biasa menggulir. Ekspor PNG besar mempertahankan 72–600 PPI yang dipilih (bawaan 300). SVG berbasis vektor; PPI hanya berlaku untuk ekspor raster.

## Tiga pilihan yang berbeda

| Pilihan | Yang dikendalikan | Contoh |
| --- | --- | --- |
| Jenis diagram | Makna diagram | Flowchart, sequence, sirkuit, grafik data |
| Format sumber | Berkas yang dapat disunting/digunakan ulang | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Format ekspor | Gambar atau dokumen untuk berbagi | SVG, PNG, PDF |

HTML diagram berisi gambar yang dapat diperbesar; HTML ringkasan terstruktur berisi teks, struktur, dan rujukan. HTML/SVG yang dapat diedit adalah nama perender, bukan editor web. Gunakan sumber asli untuk mengedit. Ekspor presentasi, termasuk PPTX dan MP4, memiliki pengaturan dan dependensi terpisah.

## Pilih format sumber

| Format | Cocok untuk | Berkas sumber |
| --- | --- | --- |
| Mermaid | Diagram langsung dalam Markdown | Blok kode Mermaid |
| JSON Canvas | Alur canvas native Obsidian | `.canvas` |
| Draw.io | Penyuntingan lanjutan di diagrams.net atau alat kompatibel | `.drawio` |
| Drawnix | Penyuntingan gaya papan tulis/sketsa | `.drawnix` |
| CircuitikZ | Sirkuit listrik/transistor terstruktur | `.tex` |

Format yang didukung tampil dahulu; pilihan yang tidak kompatibel tetap terlihat tetapi dinonaktifkan. Permintaan tidak aktif yang sudah tersimpan dapat dihapus. Setiap jenis memiliki formatnya sendiri. Jika semuanya tidak dapat digunakan, sumber bawaan perender aktif dicoba dan permintaan yang tidak tersedia dilaporkan.

## Hasilkan dan ekspor

1. Buka sumber yang didukung. Untuk satu bagian, taruh dalam catatan terpisah; sorotan teks tidak membatasi tindakan berbasis berkas.
2. Pilih beberapa jenis diagram dalam satu proses dan beberapa format keluaran secara terpisah untuk tiap jenis. Menghapus centang tetap menyimpan formatnya; tanpa pilihan, isi dianalisis otomatis.
3. Kotak centang menyertakan jenis. Klik namanya untuk memilih dan mengatur format. Arahkan penunjuk atau fokus keyboard untuk mengganti pratinjau tanpa menyimpan pengaturan. Escape menutup menu dan mengembalikan fokus.
4. Jalankan **Buat diagram** dari bilah samping/palet.
5. File terpilih otomatis diekspor di samping catatan sumber atau langsung ke folder keluaran yang ditentukan. Nama menyertakan jenis, seperti `topic_drawnix.pdf` dan `topic_flowchart.svg`. Benturan nama menambahkan `-2`, `-3`, dan seterusnya tanpa menimpa file.
6. Tinjau pratinjau. Hasil multipanel mempertahankan papan Drawnix dan setiap Mermaid dalam urutan sumber pada satu permukaan gulir vertikal; tinggi Mermaid mengikuti hasil render agar tidak terpotong.
7. Gunakan **Ekspor SVG**, **Ekspor PNG**, atau **Export PDF** per panel, atau ekspor gambar tingkat atas untuk semua panel. Pilih folder sumber/tujuan relatif Vault; satu nama deterministik per panel ditulis dan kegagalan individual tidak menghentikan sisanya. Gunakan **Simpan file sumber** untuk artefak editable.

Atur folder perantara bersama relatif terhadap Vault, atau kosongkan untuk memakai `notemd_assert/` di samping tiap sumber. Catatan pemulihan, cache render, dan lampiran opsional disimpan di sana. Pertahankan file yang masih dirujuk; perubahan folder hanya berlaku untuk proses baru.

Jenis dibuat berurutan. Kegagalan satu jenis tidak menghentikan lainnya; pembatalan menghentikan jenis yang menunggu dan mempertahankan file selesai. Ulangi ekspor dari pratinjau atau riwayat tanpa permintaan model baru. Kegagalan pembuatan memerlukan pembuatan ulang jenis tersebut. Catatan v1/v2 tetap dapat dibaca.

Menu Export menyediakan ketiga format untuk visual aktif. Header tiap panel menyediakan tindakan sama bagi satu visual, sehingga pratinjau besar tidak harus menjadi satu gambar yang sulit diolah.

**History** membuka drawer riwayat Vault tanpa menyembunyikan diagram. Cari/filter diagram selesai, buka pratinjau atau artefak tersimpan. Riwayat juga tersedia melalui palet dan bilah samping tanpa catatan aktif.

SVG/PDF berasal dari geometri vektor. PDF memakai tata letak SVG dan metrik teks yang sama, bukan merasterkan semuanya. PPI hanya untuk PNG: 72-600, bawaan 300.

## Pratinjau padat yang terbaca

Diagram lane-grid HTML/SVG editable mengukur/membungkus ringkasan sebelum judul dan header lane. Header berada di bawah area ringkasan terlindungi; sel dilukis sebelum konektor/label. Tepi antarlane memakai rute grid ortogonal yang menghindari sel/label agar uraian panjang tidak menutup teks atau memaksa pan horizontal untuk memahami diagram.

Quadrant chart Mermaid menerima normalisasi khusus. Perbaikan kutip/bentuk khusus flowchart dilewati untuk `quadrantChart`; kurung pembuka salinan provider hanya dibuang bila menjadi karakter akhir tak berpasangan pada label titik. Kurung disengaja pada judul, sumbu, dan kuadran tetap ada.

Repo menyimpan set pembelajaran/bukti Vault nyata bagi tiap jenis eksekusi. Lihat [`docs/diagram-examples/`](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) untuk masukan bilingual, SVG/PNG, manifest. `passed` mengacu pada run dan bundle tercatat, bukan run baru seluruh jenis pada rilis berikutnya.

Katalog eksekusi memiliki 33 baris, UI 21 bahasa, situs 34 rute. Ini permukaan berbeda. Lima grammar referensi persis tetap di luar pemilih sampai kontrak layout memiliki bukti independen.

## Drawnix dengan Mermaid tertanam

Notemd menyaring SVG Mermaid dan menyimpan sumbernya dalam metadata `.drawnix`. Peta dapat menampilkan visual tanpa runtime Drawnix/Plait. Jalur bawaan mandiri tanpa `.assets` terpisah. Aktifkan **Also export complete Mermaid visuals** bila memerlukan sumber, SVG, manifest pendamping untuk serah terima/edit eksternal. Artefak lama dengan `.assets` tetap didukung; SVG lama hilang dapat dibangun ulang dari metadata sumber.

Embed gambar terselesaikan menerima pratinjau SVG berbasis data bila memungkinkan. Pemuatan memprioritaskan data tertanam, pendamping lama, lalu pembangunan dari teks sumber. Pertahankan pendamping yang masih dirujuk; ekspor baru mandiri tidak membuktikan direktori bersama lama tidak dipakai.

Permukaan gulir tunggal menampilkan canvas utama dahulu lalu panel Mermaid sesuai urutan sumber. Membuka kembali riwayat memulihkan daftar, ukuran, dan tindakan ekspor yang sama.

Drawnix mempertahankan semua hubungan berarah yang dinyatakan jelas, tanpa batas total atau batas per simpul. Hanya pernyataan identik yang dihapus sebagai duplikat; predikat berbeda dan arah terbalik tetap dipertahankan. Rute luar yang rentangnya bertumpang tindih memakai jalur terpisah, rute yang terpisah memakai ulang jalur. Label mendapat baris sesuai ukurannya dan kanvas meluas sesuai kebutuhan. Panah tanpa label, hubungan umum, atau pengulangan hierarki tetap disimpan dalam metadata beserta alasannya. Teks dalam kotak hubungan tampil di PDF, termasuk dari cache SVG lama. Panah lintas cabang tetap statis dan dapat terlepas setelah penataan ulang di Drawnix.

## Batas ekspor native

Sumber dan visual adalah hasil terpisah. Uji artefak representatif dalam aplikasi tujuan sebelum distribusi. PowerPoint mempertahankan struktur tabel editable yang didukung termasuk separator bawah sel gabungan yang diperbaiki; Mermaid/SVG dapat memakai gambar, bukan bentuk native. Pratinjau atau skor screenshot halaman bukan pengganti pemeriksaan aplikasi.

## Diagram sirkuit

Pilih **Circuit diagram** dan **CircuitikZ source file** untuk permintaan yang didukung. Notemd menghasilkan deskripsi terstruktur sebelum sumber CircuitikZ, lebih andal daripada meminta LaTeX tanpa batas.

Dukungan sengaja terbatas. Penguat NMOS common-source dan blok CMOS didukung paling sesuai. Tinjau pratinjau/sumber sebelum penggunaan teknik atau publikasi.

Pratinjau SVG adalah pendamping tinjauan Notemd, bukan bukti instalasi LaTeX/TikZJax lokal berhasil mengompilasi `.tex`.

**Kompilasi native opsional.** Pratinjau plugin, SVG, PNG, dan PDF pratinjau tidak memerlukan LaTeX. Untuk diagnostik atau PDF LaTeX native desktop, buka **CircuitikZ native compile environment** melalui pengaturan/palet. Gunakan `tectonic`/`pdflatex` sistem, executable khusus, atau pasang Tectonic terkelola dengan versi terkunci setelah memilih **Install**. Panel menampilkan progres/error dan dapat menghapus runtime terkelola kemudian.

## Pemecahan masalah

### Jenis diagram salah

Pilih jenis eksplisit, bukan Auto-detect. Untuk sirkuit gunakan **Circuit diagram** dan **Buat diagram**, bukan **Ringkas sebagai diagram Mermaid** lama.

### Format sumber tidak cocok

Format yang didukung tampil dahulu; pilihan yang tidak kompatibel tetap terlihat tetapi dinonaktifkan. Permintaan tidak aktif yang sudah tersimpan dapat dihapus. Setiap jenis memiliki formatnya sendiri. Jika semuanya tidak dapat digunakan, sumber bawaan perender aktif dicoba dan permintaan yang tidak tersedia dilaporkan.

### Menu Export hilang

SVG/PNG/PDF memerlukan pratinjau visual. Jika hanya teks sumber tersedia, simpan dan buka dengan alat eksternal sesuai.

### CircuitikZ gagal dikompilasi eksternal

Buka **CircuitikZ native compile environment** dan jalankan pemeriksaan. Perbaiki runtime terkelola atau pastikan compiler sistem/khusus memperoleh paket `circuitikz`. Plugin tidak membundel distribusi TeX lengkap.
