# Catatan konsep

<TLDR>Ekstraksi mandiri membaca catatan sumber dan membuat berkas Markdown konsep dalam folder pilihan. Pengaturan folder awalnya kosong. Catatan baru secara bawaan hanya berisi judul tanpa tautan balik. Pemrosesan tambah tautan memakai templat konsep yang berbeda.</TLDR>

## Gambaran umum

Atur **Jalur folder catatan konsep** sebelum ekstraksi. Folder khusus memudahkan pemeriksaan hasil, duplikat, dan cakupan generasi judul berikutnya. Ekstraksi membuat berkas, bukan otomatis mengisi penjelasan berbasis riset untuk setiap konsep.

## Cara kerja

### Alur ekstraksi

Isi dikirim ke LLM terpilih, entri `CONCEPT:` diuraikan, nama dideduplikasi dalam operasi, lalu berkas dibuat atau diperbarui. Catatan panjang dipotong. Periksa laporan untuk potongan gagal atau hasil parsial; respons model bukan inventaris konsep yang pasti lengkap.

### Prompt ekstraksi

Prompt bawaan meminta konsep spesifik yang relevan. Instruksi pembelajaran terfokus dan penekanan sinonim memengaruhi model tanpa menjamin kosakata kanonis. Prompt khusus harus mempertahankan kontrak `CONCEPT: Term`. Lihat [prompt khusus](../advanced/custom-prompts).

### Pemotongan

`chunkWordCount` bawaan 3000 adalah pembagian berbasis jumlah kata perkiraan, bukan anggaran token penyedia. Konteks lintas potongan terbatas; tinjau konsep terkait dan nama ambigu.

## Pembuatan catatan

### Aturan nama berkas

Karakter jalur yang tidak didukung dihapus, spasi dinormalisasi, dan nama panjang dipangkas. Hasil kosong dilewati. Frasa berbeda bisa menjadi nama berkas sama; periksa sebelum membuat koleksi besar.

### Templat

Catatan mandiri baru menggunakan bentuk minimal secara bawaan:

```markdown
# Nama Konsep
```

Untuk tautan balik dalam catatan mandiri baru, aktifkan **Add "Linked From" backlink** dan nonaktifkan **Create minimal concept notes**. Bentuk penuh yang didukung:

```markdown
# Nama Konsep

## Linked From
- [[Catatan Sumber]]
```

Tambah tautan membuat konsep bentuk penuh dengan tautan balik ketika keluaran folder konsep aktif. Sakelar ekstraksi mandiri tidak mengubah perilaku tambah tautan.

### Memperbarui catatan lama

Jika tautan balik aktif, catatan lama dapat menerima tautan sumber yang belum ada di `## Linked From`. Isi lama tetap dipertahankan dan tautan yang sama tidak ditambahkan lagi. Tautan sumber memakai basename; periksa ambiguitas ketika folder berbeda berisi sumber bernama sama.

### Konfigurasi

| Pengaturan | Bawaan | Efek |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Aktifkan keluaran konsep setelah folder dipilih |
| `conceptNoteFolder` | `''` | Belum ada folder terpilih |
| `extractConceptsMinimalTemplate` | `true` | Buat konsep mandiri hanya judul |
| `extractConceptsAddBacklink` | `false` | Aktifkan tautan balik ekstraksi mandiri |
| `extractConceptsProvider` | `DeepSeek` | Penyedia saat perutean per tugas aktif |
| `extractConceptsModel` | `''` | Jika kosong, gunakan model penyedia terpilih |
| `extractConceptsLanguage` | `en` | Bahasa saat pengaturan bahasa per tugas aktif |
| `replaceSynonymsDuringConceptExtraction` | `false` | Tambahkan instruksi penekanan sinonim |
| `generateConceptLogFile` | `false` | Aktifkan pembuatan log konsep |

## Deduplikasi

Pemeriksaan memakai heuristik nama berkas: tanpa membedakan huruf besar, bentuk jamak, normalisasi simbol, serta ketercakupan satu kata sesuai lingkup. Ini bukan bukti kesetaraan semantik; bentuk jamak tak beraturan dan makna teknis berbeda perlu tinjauan manual.

Pilih **Periksa & hapus duplikat**, periksa kandidat, dan setujui hanya berkas yang memang ingin dihapus. Item yang disetujui masuk melalui operasi sampah Obsidian. Folder konsep bukan cache sekali pakai; cadangkan sebelum pembersihan massal.

### Lingkup pemeriksaan

Bandingkan dengan Vault, folder konsep sendiri, folder yang disertakan, atau lingkup yang mengecualikan folder tertentu. Periksa pilihan sebelum menghapus. Lingkup mengubah kandidat, bukan arti duplikat.

## Penggunaan

### Ekstraksi mandiri

Buka Markdown, pastikan folder konsep, lalu jalankan **Ekstrak konsep (file saat ini)**. Sumber tetap utuh. Periksa nama, cakupan konsep, dan tautan balik opsional.

### Ekstraksi lalu generasi

Jalankan **Pembuatan massal dari judul** pada folder konsep untuk menambah penjelasan. Catatan lama yang memenuhi syarat juga bisa diproses. Periksa folder dahulu dan tujuan complete yang dilaporkan sesudahnya.

### Tautan dari pilihan teks

Tindakan pilihan teks dapat membungkus istilah menjadi wiki-link serta membuat catatannya jika tujuan diatur. Gunakan ketika ingin memilih istilah sendiri, bukan menyerahkan pemilihan seluruh catatan kepada model.

## Saran

- Mulai dari sumber kecil dan folder khusus.
- Tentukan bahasa sebelum membangun koleksi besar.
- Tinjau sinonim dan kandidat duplikat secara terpisah.
- Simpan log penting sebelum ditimpa proses berikutnya.
