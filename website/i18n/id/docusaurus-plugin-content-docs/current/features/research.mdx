# Riset dan pencarian web

<TLDR>Research & summarize mencari topik pilihan atau judul aktif, meminta LLM merangkum konteks tersedia, lalu menambahkan hasil ke Markdown aktif. Pilih Tavily atau DuckDuckGo secara eksplisit. Sumber pencarian dan kutipan model perlu ditinjau.</TLDR>

## Gambaran umum

Atur penyedia pencarian terpisah dari model peringkas. Tavily memerlukan kunci. DuckDuckGo tidak, tetapi tetap memakai jaringan dan dapat dibatasi. Model peringkas lokal tidak membuat riset web offline.

## Cara kerja

### Cari lalu rangkum

1. Buka tujuan dalam editor Markdown. Pilih topik singkat, atau kosongkan pilihan untuk memakai judul.
2. Jalankan **Riset & rangkum**.
3. Notemd menanyakan layanan pencarian: cuplikan Tavily menjadi konteks; hasil DuckDuckGo dapat memicu pengambilan halaman.
4. Jika pengambilan lokal aktif untuk tugas ini, kutipan dalam lingkup dapat masuk prompt.
5. Model riset menulis ringkasan yang ditambahkan di bawah `Research Summary` dengan topik dan sumber konteks.
6. Tinjau teks dan buka URL relevan. Pengambilan tidak membuktikan setiap klaim/kutipan didukung.

### Tavily dan DuckDuckGo

| Pilihan | Pengaturan | Batas operasi |
| -------- | ------- | ---------------------- |
| Tavily | Pilih Tavily dan masukkan kunci API | Menggunakan kuota akun dan cuplikan hasil |
| DuckDuckGo | Pilih DuckDuckGo secara eksplisit | Tanpa kunci; bergantung batas pencarian dan ketersediaan halaman |

Kunci Tavily kosong/salah tidak otomatis memilih DuckDuckGo. Jika konteks tidak berguna, periksa laporan. Konteks lokal yang diaktifkan dan tersedia masih dapat mendukung ringkasan; label sumber membedakannya dari hasil berbasis web.

### Riset saat generasi judul

Aktifkan **Enable research in "Generate from title"** untuk menyertakan riset, termasuk versi batch. Bawaannya nonaktif. Ini jalur generasi folder yang didukung; tidak ada tindakan Research Folder generik mandiri.

## Konfigurasi

| Pengaturan | Bawaan | Efek |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Pilih backend pencarian |
| `tavilyApiKey` | `''` | Isi kunci sebelum memakai Tavily |
| `tavilyMaxResults` | `5` | Jumlah hasil Tavily yang diminta |
| `tavilySearchDepth` | `basic` | Kedalaman pencarian Tavily |
| `ddgMaxResults` | `5` | Jumlah hasil DuckDuckGo yang diminta |
| `ddgFetchTimeout` | `15` | Batas waktu pengambilan halaman dalam detik |
| `maxResearchContentTokens` | `3000` | Anggaran konteks web perkiraan |
| `researchProvider` | `DeepSeek` | Penyedia peringkas ketika perutean per tugas aktif |
| `researchModel` | `''` | Jika kosong, gunakan model penyedia |
| `researchSummarizeLanguage` | `en` | Bahasa keluaran ketika bahasa per tugas aktif |
| `enableResearchInGenerateContent` | `false` | Aktifkan riset dalam generasi judul |
| `enableLocalKnowledgeRetrieval` | `false` | Aktifkan pengambilan lokal terlingkup secara terpisah |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Gunakan pengambilan lokal untuk tugas ini |

### Konteks dan model

Batas konteks memakai perkiraan, bukan tokenisasi persis penyedia. Pemangkasan dapat membuang bukti. Pilih model/anggaran sesuai sumber dan fokuskan pertanyaan. Indeks lokal bersifat leksikal, bukan pencarian semantik embedding atau jaminan recall lengkap.

## Contoh

Buat catatan berjudul `Relative positional encoding`, jalankan riset, lalu verifikasi terhadap makalah asli atau dokumentasi resmi tertaut. Simpan pertanyaan, URL nyata, dan koreksi agar kesimpulan dapat diaudit. Contoh panduan bukan hasil riset yang dijalankan untuk Vault Anda.

## Pembatalan dan privasi

Pembatalan menghentikan kerja lanjutan yang didukung; tambahan selesai tetap ada. Permintaan penyedia/pengambilan halaman yang berjalan dapat selesai. Layanan pencarian menerima kueri, situs menerima permintaan, dan LLM menerima konteks termasuk kutipan lokal jika aktif. Periksa diagnostik sebelum berbagi.

## Saran

- Bedakan sumber web, catatan lokal, dan inferensi model.
- Periksa kutipan, tanggal, dan klaim penting pada sumber asli.
- Gunakan kueri kecil untuk memisahkan kegagalan pencarian dan LLM.
- Tinjau ringkasan lama sebelum mengulang agar tidak menambah isi berulang.
