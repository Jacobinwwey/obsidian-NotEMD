# Terjemahan

<TLDR>Notemd menerjemahkan berkas aktif atau berkas folder yang memenuhi syarat melalui LLM terkonfigurasi. Bawaannya membuat berkas terpisah bersufiks bahasa. Cakupan/kualitas bahasa bergantung model; 21 bahasa UI dan 34 bahasa situs bukan batas atau jaminan terjemahan.</TLDR>

## Gambaran umum

Pilih bahasa keluaran dan penyedia terlebih dahulu. Gunakan salinan berisi istilah, tautan, dan kode representatif. Fitur memakai LLM pilihan, bukan integrasi Google Translate khusus.

Tindakan terdaftar bekerja pada berkas/folder. Untuk satu kutipan, salin ke catatan sementara dahulu. Menyorot teks tidak membatasi **Terjemahkan file saat ini** hanya pada pilihan.

## Cara kerja

### Perintah terjemahan

1. Pilih bahasa tujuan; bawaannya Inggris dan terpisah dari bahasa UI.
2. Buka sumber dan jalankan **Terjemahkan file saat ini**.
3. Isi panjang dipotong, dikirim ke model penerjemah, lalu respons digabung.
4. Buka jalur hasil dan periksa makna, istilah, kutipan, tautan Markdown, serta kode.

Secara bawaan, `Example.md` ke Prancis menjadi `Example_fr.md` di samping sumber. Aslinya tetap ada. Hasil dengan nama sama ditimpa; tidak ada mode bawaan menambahkan ke sumber atau judul `Translation` yang dijamin.

### Pasangan bahasa

Model menyimpulkan bahasa sumber. Pilihan bahasa dalam menu tidak membuktikan ketepatan pasangan. Uji istilah dan teks campuran. Pemotongan catatan panjang dapat kehilangan konteks antarbagian.

### Model per tugas

Aktifkan model per tugas untuk `translateProvider` dan `translateModel`; jika tidak, penyedia aktif dipakai. Model lokal perlu server/model siap, sedangkan cloud menerima prompt dan isi.

Jangan memilih hanya berdasarkan peringkat umum kecepatan/kualitas. Gunakan sampel bidang Anda dan bandingkan dengan sumber.

### Terjemahan folder

Jalankan **Terjemahkan folder secara massal**, pilih folder, dan periksa lingkup. Bawaannya hanya berkas anak langsung; profil pemilihan lanjutan dapat mengubahnya. Nama hasil memakai basename dan sufiks bahasa, sehingga sumber bernama sama yang menuju satu folder khusus dapat bertabrakan. Pilih tujuan dengan sengaja dan periksa hasil lama sebelum mengulang.

## Konfigurasi

| Pengaturan | Bawaan | Efek |
| --------- | --------- | -------- |
| `language` | `en` | Bahasa tujuan terpilih |
| `translateProvider` | `DeepSeek` | Penyedia terjemahan saat perutean per tugas aktif |
| `translateModel` | `''` | Model penyedia digunakan jika kosong |
| `useCustomTranslationSuffix` | `false` | Sufiks kode bahasa secara bawaan |
| `translationCustomSuffix` | `_translated` | Sufiks ketika opsi khusus aktif |
| `useCustomTranslationSavePath` | `false` | Simpan di samping sumber secara bawaan |
| `translationSavePath` | `''` | Folder tujuan relatif terhadap Vault |
| `batchConcurrency` | `1` | Konkurensi terjemahan folder yang diminta |

Jika folder khusus gagal dibuat, runtime dapat kembali ke folder sumber dan melaporkan jalur sebenarnya. Periksa jalur itu. Sufiks khusus kosong bisa menunjuk nama sumber; gunakan sufiks berbeda untuk hasil terpisah.

## Contoh

Pilih bahasa Inggris, salin catatan Mandarin pendek ke folder uji, lalu terjemahkan. Bandingkan `_en.md` dengan sumber, termasuk istilah, angka, persamaan, dan tautan sebelum menerjemahkan seluruh folder.

## Pembatalan dan tinjauan

Pembatalan menghentikan kerja lanjutan yang didukung, bukan mengembalikan berkas tertulis atau menjamin tagihan berhenti. Periksa laporan dan hasil. Instruksi mempertahankan Markdown adalah permintaan kepada model, bukan jaminan kesetaraan semantik tingkat parser.

## Saran

- Cadangkan sumber dan periksa benturan nama.
- Gunakan sufiks/folder terpisah saat mencoba.
- Verifikasi identifier kode, notasi matematika, URL, dan nama diri.
- Periksa isi privat dalam diagnostik sebelum membagikan.
