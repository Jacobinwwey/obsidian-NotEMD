# Penyedia Google

<TLDR>Preset Google memakai Gemini Generative Language API native. Gunakan kunci berizin dan model tersedia. Gemini yang disediakan lewat chat kompatibel OpenAI menggunakan preset gateway.</TLDR>

## Pengaturan

Pilih **Google**, isi kunci, pertahankan endpoint Generative Language, lalu pilih model pada versi API itu. Jalankan **Uji koneksi**, lalu terjemahkan/proses catatan uji. Preset tidak otomatis menyiapkan deployment Google Cloud atau Vertex sembarang.

## Endpoint dan autentikasi

| Bidang | Nilai preset |
| ------- | -------------- |
| Transport | `google` |
| Kunci API | Wajib |
| URL dasar | `https://generativelanguage.googleapis.com/v1` |
| Model bawaan | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| Tes koneksi | `chat-only` |

Runtime membentuk permintaan model `generateContent` native dengan autentikasi kunci. ID historis bukan jaminan ketersediaan. Periksa URL sebelum berbagi diagnostik karena detail permintaan dapat memuat autentikasi.

## Penemuan model

Gunakan discovery Google native jika tersedia. Pastikan model mendukung generasi pada versi API terkonfigurasi. Daftar kosong bisa berarti izin, endpoint, atau model bermasalah; uji konfigurasi, bukan mengganti protokol acak.

## Pemecahan masalah

- `400`: periksa ID, parameter, dan batas token/hasil.
- `401`/`403`: periksa pembatasan kunci, API aktif, dan hak model.
- `404`: apakah model ada pada versi API itu?
- Contoh gateway gagal: gunakan preset gateway kompatibel OpenAI terkait.

## Kapan digunakan

Gunakan untuk Gemini API native. Uji terjemahan, riset, atau diagram representatif. Panduan tidak menjanjikan kecepatan, biaya, atau kualitas terjemahan relatif.
