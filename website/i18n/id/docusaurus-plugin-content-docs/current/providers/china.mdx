# Penyedia Tiongkok

<TLDR>Gunakan preset sesuai akun dan deployment. Jalur regional, nama model, dan izin tidak saling menggantikan meski sama-sama kompatibel OpenAI. Uji tugas kecil dahulu.</TLDR>

## Pengaturan

Buat akun API, dapatkan kunci, dan pilih preset terkait. Pastikan wilayah endpoint dan izin model. Jalankan **Uji koneksi** serta tugas uji; nilai bawaan tidak menjamin model tersedia sekarang.

## Penemuan model

Gunakan discovery jika diizinkan. Huawei Cloud MaaS memakai penemuan sesuai deployment; preset lainnya memakai jalur kompatibel OpenAI jika didukung. Tidak bisa mendaftar belum tentu berarti model eksplisit tidak dapat menghasilkan.

Tes koneksi berbeda tiap preset. DeepSeek dapat sukses dari daftar saja, sementara beberapa preset regional melakukan chat pendek. Tugas nyata tetap diperlukan untuk kontrak prompt/hasil.

## Pemecahan masalah

- Kunci diterima tetapi generasi ditolak: periksa hak model, deployment, wilayah.
- Model Ark ditolak: konfirmasi kebutuhan deployment ID atau model ID.
- Respons reasoning terpotong: lihat batas keluaran dan thinking khusus penyedia.
- Jaringan: uji endpoint dari perangkat Obsidian dan baca kesalahan transport.

## Kapan digunakan

Pilih berdasarkan endpoint akun terjangkau, kebutuhan penanganan data, dan hasil tugas terukur. Wilayah/merek bukan jaminan kualitas, privasi, atau biaya. [Ikhtisar](./overview) juga mencantumkan gateway dan server lokal.
