# Penyedia OpenAI

<TLDR>Preset OpenAI memakai runtime Chat Completions kompatibel OpenAI bersama. Atur kunci API dan model yang menerima protokol tersebut. Model preset adalah titik awal, bukan jaminan akses akun sekarang atau rekomendasi semua tugas.</TLDR>

## Pengaturan

Pilih **OpenAI**, masukkan kunci, dan pertahankan `https://api.openai.com/v1` untuk layanan resmi. Pilih model yang tersedia bagi akun dan mendukung chat completions. Model khusus API lain tidak menjadi kompatibel hanya karena terdaftar.

Untuk gateway gunakan preset terkait agar endpoint/header sesuai. Untuk Azure gunakan **Azure OpenAI** dengan deployment dan versi API terpisah.

## Endpoint dan autentikasi

| Bidang | Nilai preset |
| ------- | -------------- |
| Transport | `openai-compatible` |
| Kunci API | Wajib |
| URL dasar | `https://api.openai.com/v1` |
| Model bawaan | `gpt-4o` |
| Temperature | `0.5` |
| Tes koneksi | `models-then-chat` |

Runtime menormalkan bentuk URL dasar yang dikenal sebelum membentuk rute daftar/chat. Mulai dari preset dan periksa rute hasil resolusi ketika debug, jangan menambah segmen berdasarkan tebakan.

## Penemuan model

**Fetch models** menanyakan endpoint terkonfigurasi. **Uji koneksi** dapat sukses dari daftar tanpa memvalidasi generasi chat. Coba catatan dengan penyedia/model persis setelah tes.

Reasoning, thinking, sampling, dan token keluaran bergantung aturan preset/model. Verifikasi kombinasi tugas; model terdaftar tidak menjamin setiap parameter diterima.

## Pemecahan masalah

- `401`/`403`: periksa kredensial, proyek, hak model, dan akun.
- `404`: periksa endpoint, ID, dan dukungan API.
- Daftar berhasil tetapi tugas gagal: baca kesalahan chat serta model/pengaturan yang diminta.
- Hasil panjang gagal/terpangkas: periksa batas keluaran, ukuran sumber, dan respons; tes pendek tidak mencakup semua kegagalan panjang.

## Kapan digunakan

Gunakan untuk model OpenAI langsung yang menerima Chat Completions yang diimplementasikan. Uji catatan representatif. Harga dan ketersediaan model berubah terpisah dari rilis Notemd.
