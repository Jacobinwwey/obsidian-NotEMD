# Penyedia Anthropic

<TLDR>Gunakan preset Anthropic untuk Messages API native. Claude melalui gateway kompatibel OpenAI memakai preset gateway tersebut. Pastikan akses model terkini; bawaan historis mungkin perlu diganti.</TLDR>

## Pengaturan

Pilih **Anthropic**, isi kunci Anthropic dan pertahankan endpoint native kecuali deployment secara eksplisit menyediakan protokol sama. Masukkan ID Claude tersedia, jalankan **Uji koneksi**, lalu tugas catatan uji.

## Endpoint dan autentikasi

| Bidang | Nilai preset |
| ------- | -------------- |
| Transport | `anthropic` |
| Kunci API | Wajib |
| URL dasar | `https://api.anthropic.com` |
| Model bawaan | `claude-3-5-sonnet-20240620` |
| Temperature | `0.5` |
| Tes koneksi | `chat-only` |

Runtime memakai `/v1/messages` dengan header kunci dan versi API native. Jangan memasukkan rute chat OpenAI. Model bawaan mencatat pengaturan repositori, bukan klaim penyedia masih melayaninya.

## Penemuan model

Discovery menggunakan rute daftar native jika tersedia. Jika dibatasi, masukkan ID berizin dan gunakan tes chat. Verifikasi tugas panjang/terstruktur secara terpisah.

## Pemecahan masalah

- `401`/`403`: periksa kunci, workspace/proyek, pembayaran, hak model.
- `404`: verifikasi endpoint dan model sekarang.
- ID gateway gagal: pilih preset dan identifier gateway terkait.
- Respons panjang gagal: periksa batas keluaran dan kesalahan sebelum menambah retry.

## Kapan digunakan

Pilih untuk endpoint Anthropic Messages. Bandingkan hasil pada sumber sendiri, bukan menganggap penyedia sebagai peringkat kualitas universal. Perutean per tugas membatasi penggunaannya pada kebutuhan yang cocok.
