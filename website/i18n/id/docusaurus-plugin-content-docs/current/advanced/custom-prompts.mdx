# Prompt khusus

<TLDR>Prompt khusus mengganti bawaan jika sakelar global dan tugas aktif serta teks tidak kosong. Pertahankan kontrak keluaran sendiri. Tidak ada sistem templat yang otomatis memulihkan semua instruksi format yang dihilangkan.</TLDR>

## Gambaran umum

Uji bawaan pada catatan representatif dahulu. Gunakan pembelajaran terfokus atau penekanan sinonim jika mencukupi. Tulis prompt khusus untuk kebijakan ekstraksi, struktur, atau gaya terjemahan tertentu, lalu bandingkan sebelum batch.

## Cara kerja

### Arsitektur prompt

Notemd memilih prompt bawaan/khusus aktif, menambah instruksi fokus dan bahasa yang berlaku, serta mengganti placeholder yang disediakan tugas. Isi dapat dikirim sebagai pesan terpisah. Masukan berbeda tiap tugas; variabel riset bukan variabel umum semua tugas.

Penggantian dapat membuang kontrak `CONCEPT:` atau konteks riset. Permintaan terbentuk sah tidak membuktikan hasil dapat diuraikan atau didukung bukti.

### Variabel

Gunakan huruf besar dan satu pasang kurung kurawal persis:

| Tugas | Placeholder tersedia |
| ------ | ----------------------- |
| Generasi judul | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Ringkasan riset | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Terjemahan | `{LANGUAGE}`, `{TEXT}` |
| Ekstraksi kutipan asli | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` mengikuti kebijakan bahasa tugas. Tambah tautan dan ekstraksi konsep mandiri mengirim teks sebagai isi tugas; jangan mengarang placeholder konten. Nama tak dikenal tidak terisi otomatis. Ini substitusi prompt, bukan templat berkas konsep.

### Bidang pembelajaran terfokus

Aktifkan dan masukkan bidang seperti `electrical engineering`. Prompt menerima instruksi `Relevant Fields`. Ini mengarahkan perhatian, bukan filter keras atau bukti semua konsep tak terkait akan dibuang.

## Konfigurasi

| Tugas | Sakelar | Bidang prompt |
| ------ | --------------- | -------------- |
| Tambah tautan | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Generasi judul | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Ringkasan riset | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Ringkasan Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Ekstraksi konsep | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Terjemahan | `useCustomPromptForTranslate` | `translatePrompt` |
| Ekstraksi kutipan asli | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Semua memerlukan `enableGlobalCustomPrompts`. Teks kosong kembali ke bawaan. Ekstraksi kutipan gabungan memiliki format bawaan sendiri dan tidak berbagi penggantian biasa. Generasi diagram memiliki persyaratan hasil bertipe; penggantian ringkasan Mermaid bukan prompt universal diagram.

## Contoh

Untuk catatan sirkuit, aktifkan sakelar global/ekstraksi dan pertahankan kontrak parser:

```text
Ekstrak konsep utama teknik elektro dari catatan yang diberikan.
Utamakan nama komponen spesifik dan mekanisme fisik dibanding kata benda umum.
Kembalikan satu konsep per baris dengan format persis:
CONCEPT: Nama Istilah
Jangan menambahkan penjelasan atau blok kode pembungkus.
```

Coba pada salinan. Periksa entri, nama berkas, konsep hilang, dan bandingkan dengan bawaan. Simpan prompt asal sebelum menyunting agar dapat dipulihkan.

## Saran

- Uji satu tugas; ubah cakupan sebelum ukuran batch.
- Pertahankan bukti sumber riset dan kutipan asli persis.
- Jaga identifier/penanda wajib saat menerjemahkan prosa prompt.
- Uji ulang setelah mengganti model/penyedia; instruksi bukan jaminan validasi.
