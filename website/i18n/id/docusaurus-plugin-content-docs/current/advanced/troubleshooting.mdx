# Pemecahan masalah

<TLDR>Reproduksi pada satu catatan uji dengan penyedia, model, dan pengaturan persis. Periksa log dan tujuan. Bedakan kegagalan autentikasi, generasi, parser, dan penulisan; tes koneksi sukses tidak memverifikasi seluruh alur.</TLDR>

## Gambaran umum

Catat versi Notemd/Obsidian, OS, tindakan, protokol, model, dan langkah minimal. Jangan memulai tugas baru saat pembatalan belum menetap. Pertahankan hasil dan pemulihan sampai asal operasinya diketahui.

## Diagnostik

### Tes koneksi

**Uji koneksi** pada sebagian preset bisa sukses dari daftar model tanpa chat; yang lain mengirim chat kecil. Lanjutkan dengan tugas nyata kecil untuk menguji model dan kontrak hasil.

### Progres dan diagnostik pengembang

Progres melaporkan status, kesalahan, tujuan. Aktivitas API membedakan menunggu dari selesai/gagal. Aktifkan debug bila perlu. Diagnostik pengembang menguji permintaan panjang dan dapat memakai kuota; gunakan ketika tes pendek lolos tetapi tugas nyata gagal.

Isi diagnostik dapat memuat catatan, respons parsial, endpoint, atau kredensial. Tinjau dan redaksi lokal sebelum berbagi. Ekspor profil teredaksi tetap memerlukan pemeriksaan metadata.

## Kesalahan umum

### Kunci salah atau hilang

401: pastikan kunci milik penyedia/endpoint yang dipilih tanpa spasi tak sengaja. 403: periksa izin akun/proyek, model, dan pembayaran. Retry tidak memperbaiki kredensial salah.

### Jaringan/koneksi

Periksa host, port, protokol, dan rute dari perangkat Obsidian. Ollama/LM Studio harus berjalan dengan model tersedia. `localhost` berarti perangkat itu, bukan komputer lain. Pilih preset benar; fallback runtime otomatis, bukan sakelar transport umum pengguna.

### Batas laju 429

Kurangi konkurensi, periksa kuota permintaan/token, dan klien lain dengan kunci sama. Retry dapat mengatasi beberapa gangguan sementara tetapi tidak menjamin semua batas kuota teratasi.

### Model tidak ditemukan

Gunakan **Fetch models** atau model/deployment yang diketahui tersedia. Periksa versi API/wilayah. Bawaan preset bisa historis, bukan bukti ketersediaan sekarang. Azure memerlukan nama deployment; Ark bisa memerlukan endpoint ID.

### Tidak ada tautan/konsep

Periksa hasil sebenarnya, sumber yang berguna, format respons, dan folder konsep terisi/aktif. Ekstraksi mandiri bawaan hanya judul tanpa tautan balik. Bandingkan dengan prompt bawaan jika prompt khusus menghapus penanda wajib.

### Hasil hilang atau salah folder

Baca tujuan yang dilaporkan: tambah tautan biasanya `_processed.md`, terjemahan `_<language>.md`, generasi batch melaporkan complete. Folder terjemahan gagal dapat kembali ke sumber. Periksa benturan tujuan dan izin sebelum mengulang.

### Tugas batal meninggalkan berkas

Kerja lanjutan dihentikan jika didukung, penulisan selesai tetap ada. Permintaan/penulisan yang telah diterima bisa selesai. Periksa hasil per berkas dan jalur konflik sebelum menghapus atau mengulang folder.

### Diagram/ekspor native gagal

Jenis dibuat berurutan. Kegagalan satu jenis tidak menghentikan lainnya; pembatalan menghentikan jenis yang menunggu dan mempertahankan file selesai. Ulangi ekspor dari pratinjau atau riwayat tanpa permintaan model baru. Kegagalan pembuatan memerlukan pembuatan ulang jenis tersebut. Catatan v1/v2 tetap dapat dibaca.

HTML diagram berisi gambar yang dapat diperbesar; HTML ringkasan terstruktur berisi teks, struktur, dan rujukan. HTML/SVG yang dapat diedit adalah nama perender, bukan editor web. Gunakan sumber asli untuk mengedit. Ekspor presentasi, termasuk PPTX dan MP4, memiliki pengaturan dan dependensi terpisah. [Panduan diagram](../features/diagrams).

## Melaporkan masalah

1. Reproduksi dengan catatan sintetis kecil dan folder khusus.
2. Sertakan versi, tindakan, model, pengaturan, hasil diharapkan dan aktual.
3. Lampirkan log/artefak minimal yang telah dibersihkan dari rahasia, isi privat, dan metadata endpoint tak perlu.
4. Nyatakan apakah terjadi pada satu berkas dan prompt bawaan.
5. Buka [GitHub Issues](https://github.com/Jacobinwwey/obsidian-NotEMD/issues).

Tangkapan layar saja jarang membuktikan masalah format/pembatalan. Sertakan pasangan sumber/hasil atau langkah minimal bila memungkinkan.
