# Mengenal Notemd

<TLDR>Notemd adalah plugin Obsidian berlisensi MIT yang mengubah catatan menjadi berkas yang bisa diperiksa dan disimpan: Markdown bertaut, catatan konsep, ringkasan riset, terjemahan, dan diagram. Anda memilih penyedia, tugas, serta lingkup. Tinjau hasil model sebelum menjadi bagian basis pengetahuan.</TLDR>

## Apa itu Notemd?

Notemd menghubungkan pekerjaan Vault dengan 36 preset penyedia, termasuk API hosted, gateway, dan server lokal. Setiap tugas menulis berkas atau mengubah catatan menurut kontrak keluarannya. Jalankan terpisah atau gabungkan dalam alur bilah samping.

Hasil tersimpan tetap di Vault. Dengan cloud, isi tugas dikirim ke endpoint; riset web juga memakai jaringan. Penyimpanan lokal dan inferensi lokal adalah keputusan berbeda.

## Kemampuan utama

### Wiki-link dan konsep

Minta model mengenali konsep dan menambah wiki-link. Tambah tautan membuat catatan terpisah secara bawaan. Folder konsep terpilih dapat menerima berkas; ekstraksi mandiri bawaan hanya judul tanpa tautan balik. [Tautan](./features/wiki-links) dan [konsep](./features/concept-notes) menjelaskan bedanya.

### Riset dan konteks lokal

Pilih Tavily/DuckDuckGo lalu tambahkan ringkasan model ke catatan aktif. Pengambilan lokal terlingkup opsional menambah kutipan untuk generasi. Indeks saat ini leksikal, bukan pencarian semantik embedding. Lihat [riset](./features/research).

### Terjemahan dan kutipan asli

Terjemahkan berkas/folder ke bahasa pilihan. Ekstraksi kutipan mengambil bagian sumber sesuai pertanyaan; bandingkan kutipannya. Menyorot teks tidak membatasi terjemahan berkas. [Terjemahan](./features/translation) mencakup nama dan penimpaan.

### Diagram dan ekspor

Pilih jenis dan sumber kompatibel, tinjau pratinjau, lalu simpan sumber/visual yang didukung. Katalog eksekusi memiliki 33 entri; format sumber berbeda dari format ekspor. Lihat [diagram](./features/diagrams) untuk Draw.io, Drawnix, Mermaid, CircuitikZ dan batas aplikasi tujuan.

### Alur kerja

**One-Click Extract** menambah tautan, menghasilkan isi catatan yang memenuhi syarat dalam folder konsep/pilihan, lalu memperbaiki Mermaid di complete. Catatan lama dapat ikut. Alur khusus mempertahankan prasyarat/keluaran tiap tindakan. [Panduan alur](./features/workflows) memberikan DSL persis.

## Memulai

1. [Pasang](./getting-started/installation) di Vault yang dituju.
2. Siapkan penyedia/model dan catatan uji.
3. Pilih folder konsep, periksa tujuan.
4. Tinjau hasil sebelum memperbesar batch.

Tidak ada waktu selesai atau panjang minimum catatan yang menjamin hasil berguna. Mulai cukup kecil untuk diperiksa.

## Arah kemampuan diagram

Pipeline menggunakan spesifikasi bertipe dan renderer khusus target untuk katalog didukung. Kontrak seperti `DiagramSpec` menjelaskan batas, bukan janji semua sintaks atau tata letak referensi.

Sirkuit dibatasi struktur `circuitikz` yang didukung. TikZJax eksternal; pratinjau plugin bukan bukti kompilasi native. Hubungan statis Drawnix tidak menjamin panah lintas cabang tetap melekat setelah penataan ulang.

## Arsitektur

Tugas diarahkan ke penyedia, hasil divalidasi/diuraikan, lalu catatan atau artefak ditulis. Pencarian/pengambilan lokal menyediakan konteks opsional. Pratinjau/ekspor memiliki batas format tambahan.

Lihat [pengembang](./developers/overview) untuk kepemilikan sumber dan verifikasi, serta [Agent](./agents/overview) untuk ekspor publik terbatas. Registry internal bukan API otomatisasi umum.

## Membandingkan alat {#notemd-vs-other-obsidian-ai-plugins}

Pilih berdasarkan pekerjaan: transformasi berkas, percakapan, tautan deterministik, pengambilan, atau penyuntingan native. Periksa dokumentasi terkini dan sampel representatif. Catat versi, fitur aktif, dan tugas sama saat membandingkan.

## Data dan kompatibilitas

Cloud menerima masukan; pencarian menerima kueri; kutipan lokal masuk prompt ketika aktif. Periksa perutean sebelum menganggap lokal. Pembatalan menghentikan kerja lanjutan yang didukung dan mempertahankan hasil; tidak menjamin generasi/tagihan remote berhenti.

Manifest menyatakan minimum `0.15.0` dan mengizinkan pemuatan seluler. Perangkat seluler fisik dan versi minimum belum divalidasi bukti rilis saat ini. Ekspor native dapat memerlukan desktop. Situs memiliki 34 rute bahasa, UI 21; kemampuan terjemahan model terpisah.
