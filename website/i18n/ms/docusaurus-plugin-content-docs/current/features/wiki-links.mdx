# Pautan wiki

<TLDR>Process file (add links) meminta LLM pilihan mengenal pasti konsep dan menambah pautan wiki Obsidian. Lalainya mencipta fail `_processed.md` berasingan serta mengekalkan sumber. Fail konsep pilihan memerlukan folder konsep ditetapkan. Periksa hasil sebelum memproses folder.</TLDR>

## Gambaran keseluruhan

Tugas ini mencadangkan pautan berdasarkan makna nota. Istilah boleh berubah antara pelaksanaan dan mungkin belum mempunyai fail. Pautan wiki ialah sasaran navigasi, bukan bukti kesetaraan konsep atau ketepatan huraian yang dijana.

## Cara kerja

### Proses

Nota dipecahkan, setiap cebisan dihantar kepada penyedia/model, respons digabungkan dan hasil ditulis. Nota konsep juga boleh dicipta atau dikemas kini dalam folder pilihan. Semak kegagalan separa dan laluan sebenar dalam laporan kemajuan.

### Contoh

Sumber:

```text
Model pembelajaran mesin menggunakan rangkaian neural untuk mempelajari corak daripada contoh.
```

Satu kemungkinan hasil:

```markdown
Model [[pembelajaran mesin]] menggunakan [[rangkaian neural]] untuk mempelajari corak daripada contoh.
```

Ini hanya ilustrasi. Istilah dipautkan bergantung pada sumber, model dan prompt.

## Penggunaan

### Asas: tambah pautan pada nota semasa

Buka salinan nota Markdown dan jalankan **Process file (add links)** melalui bar sisi atau palet arahan. Dengan tetapan lalai, periksa fail `_processed.md` di sebelah sumber. Akhiran tersuai, folder hasil dan pemindahan asal boleh mengubah destinasi.

### Kelompok: proses beberapa nota

Pilih **Process folder (add links)**, sahkan folder/skop dan mulakan dengan sampel kecil. Tiada suis tulis ganti/langkau sejagat untuk semua tugas folder. Baca [pemprosesan kelompok](../advanced/batch-processing) sebelum mengulang.

### Pilihan: pautkan teks tertentu

Gunakan **Create wiki link and generate note from selection** untuk memilih istilah sendiri. Ini tindakan berasingan; ia tidak mengehadkan tambah pautan seluruh fail kepada pilihan teks. Periksa nota konsep dan kandungan yang dijana.

## Memilih kaedah pautan

Pautan dibantu model sesuai untuk menemui calon konsep daripada kandungan. Padanan tajuk deterministik sesuai apabila hasil boleh ulang berdasarkan nama nota sedia ada lebih penting. Nilai pemalam lain berdasarkan dokumentasi semasanya; panduan ini tidak mendakwa perbandingan ciri atau prestasi tanpa penanda aras bertarikh.

## Ciri

### Penindasan sinonim

`replaceSynonymsDuringConceptExtraction` menambah arahan mengelakkan konsep sinonim atau terlalu bertindih. Tetapan Boolean ini dimatikan secara lalai; ia bukan ambang keserupaan bernombor. Semak singkatan dan hampir sinonim sendiri.

### Integriti pautan

Obsidian mengurus kemas kini pautan dalaman ketika penamaan semula mengikut tetapan dan operasi yang digunakan. Memadam sasaran boleh meninggalkan pautan wiki yang tidak dapat diselesaikan, berbeza daripada sebutan tanpa pautan. Semak nama asas sama dalam folder berlainan.

### Ekstraksi tanpa penulisan semula

Gunakan **Extract concepts (current file)** untuk mencipta konsep tanpa menulis semula sumber. Kawalan templat minimum dan pautan baliknya berbeza daripada tambah pautan. Lihat [nota konsep](./concept-notes).

## Penjanaan nota konsep

### Penciptaan automatik

Apabila keluaran folder konsep diaktifkan dan laluannya ditetapkan, tambah pautan boleh mencipta tajuk dan pautan balik `Linked From`. Ia tidak terus menghasilkan huraian penyelidikan, bahagian konsep berkaitan atau templat frontmatter tersuai. Jalankan penjanaan tajuk secara berasingan untuk isi lebih lengkap.

### Konfigurasi

Cari tetapan folder konsep, folder hasil diproses, akhiran tambah pautan dan pemindahan asal. Folder konsep pada awalnya kosong. Semasa menguji, asingkan destinasi daripada koleksi sumber.

## Pilihan lanjutan

### Konteks dan prompt

`chunkWordCount` mengawal saiz cebisan anggaran. Pembelajaran tertumpu dan prompt tambah pautan tersuai boleh memperincikan konsep yang diminta. Tugas ini tidak mendokumenkan pemilih konteks ayat/perenggan, ambang kekerapan minimum atau pemboleh ubah templat konsep umum.

## Petua dan amalan

- Bandingkan hasil dengan sumber, termasuk petikan, formula dan kod.
- Tentukan sama ada istilah baharu memerlukan nota konsep.
- Uji perubahan prompt pada sampel tetap sebelum folder.
- Sandarkan sebelum mengaktifkan pemindahan sumber atau menulis semula ke destinasi sedia ada.

## Prestasi

Kependaman dan kos bergantung pada penyedia, model, saiz prompt, panjang keluaran serta percubaan semula. Tiada janji saat setiap nota atau kos setiap 100 nota. Ukur sampel perwakilan dan semak penggunaan sebenar penyedia sebelum meluaskan skop.

## Penyelesaian masalah

### Tiada pautan ditambah

Semak hasil permintaan, respons model, nota yang diproses dan fail hasil dilaporkan. Tiada jumlah perkataan minimum menjamin pautan berguna.

### Terlalu banyak pautan

Perincikan prompt atau aktifkan pembelajaran tertumpu, kemudian semak hasil. Penindasan sinonim membimbing model tetapi tidak menguatkuasakan kosa kata.

### Pautan rosak selepas penamaan semula

Semak tetapan kemas kini pautan Obsidian dan kekaburan pautan asal. Pulihkan atau baiki sasaran dengan sengaja; mengulang tugas LLM bukan pembaikan pautan deterministik.
