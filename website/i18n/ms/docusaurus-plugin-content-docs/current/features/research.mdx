# Penyelidikan dan carian web

<TLDR>Research & summarize mencari topik terpilih atau tajuk nota semasa, meminta LLM meringkaskan konteks tersedia dan menambah hasil ke nota Markdown aktif. Pilih Tavily atau DuckDuckGo secara jelas. Hasil carian serta rujukan yang dijana model perlu disemak.</TLDR>

## Gambaran keseluruhan

Tetapkan penyedia carian secara berasingan daripada LLM peringkas. Tavily memerlukan kunci. DuckDuckGo tidak memerlukan kunci tetapi tetap menggunakan rangkaian dan boleh dihadkan. Model peringkas setempat tidak menjadikan penyelidikan web luar talian.

## Cara kerja

### Cari kemudian ringkaskan

1. Buka nota sasaran dalam editor Markdown. Pilih topik pendek atau biarkan pilihan kosong untuk menggunakan tajuk.
2. Jalankan **Research & summarize** melalui bar sisi atau palet arahan.
3. Notemd menyoal penyedia carian. Petikan Tavily menjadi konteks; hasil DuckDuckGo boleh mencetuskan pengambilan halaman.
4. Jika dapatan pengetahuan setempat diaktifkan untuk tugas ini, petikan setempat dalam skop juga boleh memasuki prompt.
5. Penyedia/model penyelidikan menulis ringkasan. Hasil ditambah di bawah tajuk `Research Summary` yang mengenal pasti topik serta sumber konteks.
6. Baca hasil dan buka URL sumber. Dapatan carian tidak membuktikan setiap dakwaan atau rujukan yang dijana disokong.

### Tavily dan DuckDuckGo

| Pilihan | Persediaan | Batas operasi |
| -------- | ------- | ---------------------- |
| Tavily | Pilih Tavily dan masukkan kunci APInya | Menggunakan kuota akaun dan petikan yang dikembalikan |
| DuckDuckGo | Pilih DuckDuckGo secara jelas | Tanpa kunci; tertakluk pada had carian dan ketersediaan halaman hasil |

Kunci Tavily kosong atau tidak sah tidak memilih DuckDuckGo secara automatik. Jika tiada konteks carian berguna, semak laporan. Konteks setempat yang diaktifkan dan tersedia masih boleh menyokong ringkasan; label sumber membezakannya daripada penyelidikan berasaskan web.

### Penyelidikan ketika penjanaan tajuk

Aktifkan **Enable research in "Generate from title"** untuk menyertakan penyelidikan dalam penjanaan tajuk, termasuk kelompok. Lalainya dimatikan. Inilah laluan penjanaan folder yang disokong; tiada tindakan Research Folder umum kendiri.

## Konfigurasi

| Tetapan | Lalai | Kesan |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Pilih penyedia carian |
| `tavilyApiKey` | `''` | Masukkan kunci sebelum menggunakan Tavily |
| `tavilyMaxResults` | `5` | Bilangan hasil Tavily diminta |
| `tavilySearchDepth` | `basic` | Kedalaman carian Tavily |
| `ddgMaxResults` | `5` | Bilangan hasil DuckDuckGo diminta |
| `ddgFetchTimeout` | `15` | Had masa pengambilan halaman dalam saat |
| `maxResearchContentTokens` | `3000` | Bajet anggaran konteks web |
| `researchProvider` | `DeepSeek` | Penyedia ringkasan apabila penghalaan khusus tugas diaktifkan |
| `researchModel` | `''` | Gunakan model penyedia itu jika kosong |
| `researchSummarizeLanguage` | `en` | Bahasa keluaran apabila tetapan bahasa khusus tugas aktif |
| `enableResearchInGenerateContent` | `false` | Sertakan penyelidikan dalam penjanaan tajuk |
| `enableLocalKnowledgeRetrieval` | `false` | Aktifkan dapatan setempat berskop secara berasingan |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Gunakan dapatan setempat untuk tugas ini |

### Pemilihan konteks dan model

Had konteks menggunakan anggaran, bukan penokenan tepat penyedia. Pemotongan boleh menggugurkan bukti. Pilih model dan bajet keluaran sesuai dengan bahan, serta fokuskan soalan. Indeks setempat bersifat leksikal; ia bukan carian semantik berasaskan embedding atau jaminan dapatan lengkap.

## Contoh

Cipta nota bertajuk `Relative positional encoding`. Jalankan penyelidikan, kemudian sahkan huraian dengan kertas asal atau dokumentasi rasmi yang dipautkan. Simpan soalan, URL sebenar dan pembetulan dalam nota untuk audit pembaca lain. Teks contoh panduan bukan hasil penyelidikan untuk Vault anda.

## Pembatalan dan privasi

Cancel menghentikan kerja seterusnya apabila disokong; penambahan yang selesai kekal. Permintaan penyedia atau halaman yang sedang berjalan mungkin selesai. Perkhidmatan carian menerima kueri, laman menerima permintaan dan LLM menerima konteks prompt terkumpul, termasuk petikan setempat apabila aktif. Periksa diagnostik sebelum berkongsi.

## Petua

- Bezakan sumber web, nota setempat dan inferens model.
- Semak petikan, tarikh dan dakwaan berimpak besar pada sumber asal.
- Gunakan kueri kecil untuk mendiagnosis carian dan LLM secara berasingan.
- Periksa ringkasan sedia ada sebelum mengulang supaya bahan tidak bertambah berulang kali.
