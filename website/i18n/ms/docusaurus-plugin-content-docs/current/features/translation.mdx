# Terjemahan

<TLDR>Notemd menterjemah fail aktif atau fail layak dalam folder melalui LLM pilihan. Lalainya mencipta fail berasingan dengan akhiran bahasa. Liputan dan mutu bergantung pada model; 21 bahasa UI dan 34 bahasa laman bukan had atau jaminan terjemahan.</TLDR>

## Gambaran keseluruhan

Pilih bahasa keluaran dan penyedia terjemahan sebelum menjalankan tugas. Gunakan salinan nota ujian yang mengandungi istilah, pautan dan kod perwakilan. Ciri ini menggunakan LLM pilihan, bukan integrasi khusus Google Translate.

Tindakan berdaftar beroperasi pada fail dan folder. Untuk satu petikan, salin ke nota sementara dahulu. Memilih teks dalam editor tidak mengehadkan **Translate current file** kepada pilihan tersebut.

## Cara kerja

### Arahan terjemahan

1. Pilih bahasa sasaran dalam kawalan bahasa Notemd; lalainya Inggeris dan berasingan daripada UI.
2. Buka sumber dan jalankan **Translate current file**.
3. Kandungan panjang dipecah, dihantar kepada penyedia/model terjemahan dan respons digabungkan.
4. Buka laluan hasil dilaporkan. Semak makna, istilah, rujukan, pautan Markdown dan kod sebelum menggunakannya.

Dengan lalai, `Example.md` yang diterjemah ke Perancis menjadi `Example_fr.md` di sebelah sumber. Fail asal kekal. Hasil sedia ada yang sepadan ditulis ganti; tiada mod lalai tambah-ke-sumber atau tajuk `Translation` yang dijamin.

### Pasangan bahasa

Model menyimpulkan bahasa sumber. Bahasa sasaran dalam menu tidak membuktikan ketepatan pasangan bahasa. Uji istilah dan teks campuran pada sampel. Nota panjang dipecah dan boleh kehilangan konteks antara cebisan.

### Pemilihan model khusus tugas

Aktifkan tetapan model khusus tugas untuk menggunakan `translateProvider` dan `translateModel`; selain itu penyedia aktif digunakan. Model setempat memerlukan pelayan berjalan serta model dimuat turun. Penyedia awan menerima prompt dan kandungan terjemahan.

Jangan memilih hanya berdasarkan kedudukan kelajuan atau mutu umum. Gunakan sampel kecil bidang sebenar dan bandingkan hasil dengan sumber.

### Terjemahan folder berkelompok

Jalankan **Batch translate folder**, pilih folder dan periksa skop. Pilihan lalai merangkumi fail anak langsung sahaja; profil pemilihan lanjutan boleh mengubahnya. Nama hasil menggunakan nama asas sumber dan akhiran bahasa. Dua sumber bernama sama ke satu folder tersuai boleh bertembung. Pilih destinasi dengan sengaja dan semak terjemahan lama sebelum mengulang.

## Konfigurasi

| Tetapan | Lalai | Kesan |
| --------- | --------- | -------- |
| `language` | `en` | Bahasa sasaran pilihan |
| `translateProvider` | `DeepSeek` | Penyedia apabila penghalaan khusus tugas diaktifkan |
| `translateModel` | `''` | Gunakan model penyedia itu jika kosong |
| `useCustomTranslationSuffix` | `false` | Gunakan akhiran kod bahasa secara lalai |
| `translationCustomSuffix` | `_translated` | Akhiran apabila pilihan tersuai diaktifkan |
| `useCustomTranslationSavePath` | `false` | Simpan di sebelah sumber secara lalai |
| `translationSavePath` | `''` | Folder hasil tersuai relatif kepada Vault |
| `batchConcurrency` | `1` | Keserentakan terjemahan folder yang diminta |

Jika folder tersuai yang diminta tidak dapat dicipta, masa jalan boleh kembali ke folder sumber dan melaporkan laluan sebenar. Periksa laluan tersebut, jangan anggap destinasi diminta telah digunakan. Akhiran tersuai kosong boleh menyasarkan nama sumber; gunakan akhiran berbeza untuk terjemahan berasingan.

## Contoh

Pilih bahasa keluaran Inggeris, salin nota Cina pendek ke folder ujian dan jalankan terjemahan fail. Bandingkan `_en.md` dengan sumber. Pastikan istilah teknikal, nombor, persamaan dan pautan kekal betul sebelum menterjemah seluruh folder.

## Pembatalan dan semakan

Cancel menghentikan kerja seterusnya apabila disokong; ia tidak membatalkan penulisan yang sudah selesai atau menjamin caj penyedia dihentikan. Semak laporan serta fail selepas pembatalan. Arahan model untuk mengekalkan Markdown ialah permintaan, bukan jaminan kesetaraan makna pada aras penghurai.

## Petua

- Sandarkan sumber dan semak pertembungan nama hasil.
- Gunakan akhiran serta folder berbeza semasa bereksperimen.
- Semak pengecam kod, notasi matematik, URL sumber dan nama khas secara manual.
- Periksa kandungan peribadi dalam diagnostik sebelum berkongsi.
