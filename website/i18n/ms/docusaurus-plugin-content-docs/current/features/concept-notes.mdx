# Nota konsep

<TLDR>Ekstraksi konsep kendiri membaca nota sumber dan mencipta fail Markdown konsep dalam folder pilihan. Tetapan folder pada awalnya kosong. Nota baharu lalai hanya mengandungi tajuk, tanpa pautan balik. Pemprosesan tambah pautan menggunakan templat konsep yang berbeza.</TLDR>

## Gambaran keseluruhan

Tetapkan **Concept note folder path** sebelum mengekstrak. Folder khusus memudahkan pemeriksaan nota, pendua dan skop penjanaan daripada tajuk. Ekstraksi mencipta fail konsep; ia tidak mengisi setiap fail dengan huraian hasil penyelidikan secara automatik.

## Cara kerja

### Aliran ekstraksi

Kandungan dihantar kepada LLM pilihan, entri `CONCEPT:` dihuraikan, nama dinyahgandakan dalam operasi, kemudian fail konsep dicipta atau dikemas kini. Nota panjang dipecah kepada cebisan. Semak laporan kemajuan untuk kegagalan cebisan dan hasil tidak lengkap; respons model bukan senarai konsep yang menyeluruh.

### Prompt ekstraksi

Prompt terbina meminta konsep khusus yang berkaitan dengan topik. Arahan pembelajaran tertumpu dan penindasan sinonim boleh mempengaruhi model, tetapi tidak menjamin istilah piawai. Prompt tersuai mesti mengekalkan kontrak keluaran `CONCEPT: Term`. Lihat [prompt tersuai](../advanced/custom-prompts).

### Pemecahan cebisan

`chunkWordCount` lalai ialah 3000. Ini anggaran berdasarkan perkataan, bukan bajet token penyedia. Konteks antara cebisan terhad; semak konsep berkaitan dan nama kabur selepas pemprosesan.

## Penciptaan nota konsep

### Peraturan nama fail

Nama disesuaikan untuk fail Vault: aksara laluan yang tidak disokong dibuang, ruang dinormalkan dan nama panjang dipendekkan. Nama kosong dilangkau. Frasa berlainan boleh menjadi nama fail yang sama; semak sebelum mencipta koleksi besar.

### Templat

Nota kendiri baharu menggunakan templat minimum secara lalai:

```markdown
# Nama Konsep
```

Untuk menyertakan pautan balik dalam nota kendiri baharu, aktifkan **Add "Linked From" backlink** dan matikan **Create minimal concept notes**. Bentuk penuh yang disokong:

```markdown
# Nama Konsep

## Linked From
- [[Nota Sumber]]
```

Tambah pautan mencipta nota konsep bentuk penuh dengan pautan balik apabila keluaran folder konsep diaktifkan. Suis ekstraksi kendiri tidak mengubah tingkah laku tambah pautan ini.

### Mengemas kini nota sedia ada

Apabila pautan balik diaktifkan, pautan sumber yang belum ada boleh ditambah ke `## Linked From`. Isi sedia ada dikekalkan dan pautan sama tidak ditambah berulang kali. Pautan menggunakan nama asas nota sumber; semak kekaburan jika beberapa nota mempunyai nama sama.

### Konfigurasi

| Tetapan | Lalai | Kesan |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Aktifkan keluaran konsep setelah folder ditetapkan |
| `conceptNoteFolder` | `''` | Tiada folder dipilih pada awal |
| `extractConceptsMinimalTemplate` | `true` | Cipta nota konsep kendiri dengan tajuk sahaja |
| `extractConceptsAddBacklink` | `false` | Aktifkan pautan balik bagi ekstraksi kendiri |
| `extractConceptsProvider` | `DeepSeek` | Penyedia apabila penghalaan khusus tugas diaktifkan |
| `extractConceptsModel` | `''` | Gunakan model penyedia pilihan jika kosong |
| `extractConceptsLanguage` | `en` | Bahasa apabila bahasa keluaran khusus tugas diaktifkan |
| `replaceSynonymsDuringConceptExtraction` | `false` | Tambah arahan untuk mengurangkan sinonim |
| `generateConceptLogFile` | `false` | Pilih untuk menjana log konsep |

## Semakan pendua

Semakan menggunakan heuristik nama fail seperti padanan tanpa beza huruf besar, bentuk jamak, penormalan simbol dan kandungan satu perkataan apabila skop membenarkannya. Ini tidak membuktikan kesetaraan makna; bentuk jamak tidak teratur dan makna teknikal berlainan memerlukan semakan manusia.

Pilih **Check & remove duplicates**, semak calon dan sahkan hanya fail yang hendak dibuang. Item diluluskan melalui operasi tong sampah Obsidian. Folder konsep bukan cache sementara; sandarkan sebelum pembersihan pukal.

### Mod skop

Bandingkan dengan seluruh Vault, folder konsep, folder yang disertakan atau skop yang mengecualikan folder tertentu. Semak skop sebelum meluluskan pemadaman. Skop menentukan calon, bukan makna pendua.

## Penggunaan

### Ekstraksi konsep kendiri

Buka nota Markdown, sahkan folder konsep dan jalankan **Extract concepts (current file)**. Nota sumber tidak berubah. Semak nama fail, liputan konsep dan pautan balik pilihan.

### Ekstrak kemudian jana kandungan

Jalankan **Batch generate from titles** pada folder konsep untuk menambah huraian. Nota layak yang sudah ada juga boleh diproses, bukan hanya hasil ekstraksi terkini. Semak folder dahulu dan destinasi folder complete yang dilaporkan selepasnya.

### Cipta pautan wiki daripada pilihan

Tindakan pilihan boleh membalut istilah terpilih sebagai pautan wiki dan mencipta nota konsep apabila destinasi ditetapkan. Gunakan apabila mahu memilih istilah sendiri, bukannya meminta model memilih daripada seluruh nota.

## Petua

- Mulakan dengan sumber kecil dan folder konsep khusus.
- Pilih bahasa sebelum membina koleksi besar.
- Semak cadangan sinonim dan calon pendua secara berasingan.
- Simpan log yang diperlukan sebelum pelaksanaan kemudian menulis gantinya.
