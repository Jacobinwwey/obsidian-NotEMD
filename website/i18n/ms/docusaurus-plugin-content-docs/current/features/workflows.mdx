# Aliran kerja

<TLDR>Aliran kerja menjalankan tindakan bar sisi sedia ada mengikut urutan. Ia mungkin meminta folder atau memerlukan editor aktif. Ia bukan paip teks: setiap tindakan mengekalkan input, hasil dan kesan sampingannya sendiri. Mulakan dengan nota ujian dan folder khusus.</TLDR>

## Gambaran keseluruhan

Definisi **One-Click Extract** yang dibekalkan ialah:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Tambah pautan pada nota aktif; cipta konsep apabila folder konsep ditetapkan.
2. Jana kandungan nota layak dalam folder konsep yang ditetapkan atau folder pilihan langkah kelompok, termasuk nota yang sudah ada.
3. Baiki blok Mermaid dalam folder complete hasil penjanaan kelompok.

Aliran lalai tidak menjalankan penyelidikan web. Penjanaan hanya menggunakan penyelidikan apabila tetapan berasingan itu diaktifkan. Lihat [pemprosesan kelompok](../advanced/batch-processing) untuk skop dan destinasi.

## Cara kerja

### Pelaksanaan aliran

Langkah berjalan berurutan. Bar sisi melaporkan langkah aktif dan kegagalan. Pembatalan menghentikan langkah berikutnya dan disebarkan ke laluan permintaan yang disokong. Penulisan selesai kekal; tiada pengunduran menyeluruh semua-atau-tiada.

Konteks folder ditentukan dengan jelas: folder konsep menjadi pilihan awal, penjanaan kelompok merekodkan sumber dan folder complete, kemudian pembaikan Mermaid menggunakan folder complete itu. Tindakan lain masih memerlukan fail aktif, pilihan atau interaksi masing-masing.

### Format DSL

Gunakan satu butang bernama setiap baris. `::` memisahkan nama paparan daripada senarai tindakan; `>` memisahkan tindakan. Baris kosong dan baris bermula `#` diabaikan. ID tidak dikenali ditolak.

```text
Ekstrak dan rajah::extract-concepts-current>summarize-as-mermaid
```

Pilih tindakan melalui pembina aliran dalam tetapan atau sunting DSL. ID stabil; label mengikut bahasa UI. Varian folder mempunyai ID sendiri, bukan peraturan penggantian rentetan umum.

| Pengecam | Tindakan / prasyarat |
| ------------ | ----------------------- |
| `process-current-add-links` | Tambah pautan pada nota aktif |
| `process-folder-add-links` | Tambah pautan dalam folder pilihan |
| `extract-concepts-current` | Ekstrak konsep daripada nota aktif |
| `extract-concepts-folder` | Ekstrak konsep dalam folder pilihan |
| `generate-from-title` | Jana kandungan menggunakan tajuk nota aktif |
| `batch-generate-from-titles` | Jana kandungan nota folder yang layak |
| `research-and-summarize` | Selidik pilihan atau tajuk dalam editor Markdown terbuka |
| `summarize-as-mermaid` | Ringkaskan input aktif yang disokong sebagai Mermaid |
| `generate-diagram` | Jana artifak rajah daripada input disokong |
| `preview-diagram` | Buka pratonton sumber atau artifak rajah disokong |
| `translate-current-file` | Terjemah fail aktif yang disokong |
| `batch-translate-folder` | Terjemah folder pilihan |
| `extract-original-text` | Ekstrak petikan asal yang diminta |
| `batch-extract-original-text` | Ekstrak petikan daripada fail folder yang layak |
| `split-note-by-chapters` | Pisahkan nota aktif mengikut bab |
| `batch-mermaid-fix` | Baiki blok Mermaid dalam folder pilihan |
| `fix-formula-current` | Normalkan pembatas formula dalam nota aktif |
| `batch-fix-formula` | Normalkan pembatas formula dalam folder pilihan |
| `check-duplicates-current` | Semak pendua pada nota aktif |
| `check-remove-duplicate-concepts` | Semak dan buang konsep pendua secara interaktif |
| `test-llm-connection` | Uji penyedia yang ditetapkan |
| `probe-slide-export-env` | Periksa persekitaran eksport slaid setempat |
| `export-slides` | Eksport fail aktif sebagai slaid |

### Aliran lalai dan tersuai

One-Click Extract ialah aliran lalai. Butang tambahan ialah definisi anda sendiri. Cari konfigurasi aliran, beri nama, pilih dan susun tindakan, kemudian semak petua butang bar sisi sebelum menjalankan. Baiki ralat penghurai sebelum bergantung pada rantaian yang dimaksudkan.

## Konfigurasi

| Tetapan | Lalai | Kesan |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Berhenti pada kegagalan langkah pertama yang dilaporkan |
| `useMultiModelSettings` | `false` | Gunakan penyedia aktif sehingga penghalaan khusus tugas diaktifkan |
| `enableResearchInGenerateContent` | `false` | Tiada penyelidikan web dalam penjanaan tajuk kecuali diaktifkan |

Dengan `continue_on_error`, langkah seterusnya mungkin berjalan selepas kegagalan. Gunakan hanya jika langkah itu boleh beroperasi pada input yang tinggal; meneruskan tidak menjadikan aliran separa berjaya sepenuhnya.

### Model khusus tugas dalam aliran

Pemilihan penyedia/model kekal milik tugas. Apabila diaktifkan, medan model gantian kosong menggunakan model yang ditetapkan pada penyedia pilihan. Semak penyedia setiap tugas sebelum memproses bahan peribadi.

## Contoh

Tetapkan folder kosong `trial-concepts`, proses satu nota ujian dan periksa nota konsep serta folder complete dilaporkan. Jalankan tindakan secara berasingan dahulu jika perlu memahami destinasi. Luaskan skop hanya selepas hasil disemak.

## Petua

- Pastikan aliran cukup pendek agar kegagalan dan pemilik hasil jelas.
- Elakkan pembersihan/pemadaman dalam rantaian tanpa pengawasan; pengesahan interaktifnya masih diperlukan.
- Semak log dan fail selepas pembatalan atau konflik pemulihan sebelum mengulang.
- Uji penyedia/model serta folder sebenar; ujian sambungan lulus tidak membuktikan kelompok panjang mematuhi kuota.
