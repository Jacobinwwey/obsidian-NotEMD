# Penyedia Anthropic

<TLDR>Gunakan pratetap Anthropic untuk API Messages natif. Claude yang dilayan gerbang serasi OpenAI menggunakan pratetap gerbang itu. Sahkan akses model semasa sebelum tugas; model lalai lama mungkin perlu diganti.</TLDR>

## Persediaan

Pilih **Anthropic**, masukkan kunci Anthropic dan kekalkan titik akhir natif kecuali deployment jelas menyediakan protokol sama. Masukkan ID Claude yang tersedia kini, jalankan **Test connection** dan cuba tugas pada nota ujian.

## Titik akhir dan pengesahan

| Medan | Nilai pratetap |
| ------- | -------------- |
| Penghantaran | `anthropic` |
| Kunci API | Diperlukan |
| URL asas | `https://api.anthropic.com` |
| Model lalai | `claude-3-5-sonnet-20240620` |
| Suhu | `0.5` |
| Ujian sambungan | `chat-only` |

Masa jalan menggunakan `/v1/messages` dengan pengepala kunci API dan versi API natif. Jangan letakkan laluan sembang OpenAI dalam pratetap ini. Model lalai merekodkan tetapan repositori, bukan dakwaan penyedia masih melayannya.

## Penemuan model

Penemuan menggunakan laluan senarai natif Anthropic apabila tersedia. Jika senarai disekat, masukkan ID boleh akses dan gunakan ujian sambungan berasaskan sembang. Uji tugas panjang atau berstruktur secara berasingan daripada ujian pendek.

## Penyelesaian masalah

- `401` / `403`: semak kunci, akses ruang kerja/projek, bil dan izin model.
- `404`: sahkan titik akhir serta ketersediaan model.
- ID model gerbang gagal: gunakan pratetap gerbang dan pengecam yang dijangkakan.
- Respons panjang gagal: periksa had keluaran dan ralat penyedia sebelum menambah ulangan.

## Bila digunakan

Pilih apabila titik akhir menggunakan Anthropic Messages. Bandingkan hasil pada sumber sendiri, bukan kedudukan mutu sejagat penyedia. Penghalaan khusus tugas membolehkan penyedia digunakan hanya pada tugas yang memenuhi keperluan.
