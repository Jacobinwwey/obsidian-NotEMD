# Penyedia OpenAI

<TLDR>Pratetap OpenAI menggunakan masa jalan Chat Completions serasi OpenAI yang dikongsi. Sediakan kunci API dan model yang menerima protokol itu. Model pratetap ialah nilai permulaan, bukan jaminan akses akaun semasa atau saranan untuk setiap tugas.</TLDR>

## Persediaan

Pilih **OpenAI**, masukkan kunci dan kekalkan `https://api.openai.com/v1` bagi titik akhir rasmi. Pilih model yang tersedia untuk akaun serta serasi dengan chat completions. Model yang hanya tersedia melalui API lain tidak menjadi serasi hanya kerana muncul dalam senarai.

Bagi gerbang, gunakan pratetap sepadan agar titik akhir dan pengepala betul. Bagi Azure, pilih **Azure OpenAI** serta tetapkan deployment dan versi API secara berasingan.

## Titik akhir dan pengesahan

| Medan | Nilai pratetap |
| ------- | -------------- |
| Penghantaran | `openai-compatible` |
| Kunci API | Diperlukan |
| URL asas | `https://api.openai.com/v1` |
| Model lalai | `gpt-4o` |
| Suhu | `0.5` |
| Ujian sambungan | `models-then-chat` |

Masa jalan menormalkan bentuk URL asas yang dikenali sebelum membina laluan senarai atau sembang. Mulakan dengan URL pratetap dan periksa laluan diselesaikan ketika diagnosis, bukannya menambah segmen berdasarkan tekaan.

## Penemuan model

**Fetch models** menyoal titik akhir pilihan. **Test connection** boleh berjaya melalui senarai tanpa mengesahkan penjanaan. Selepas sambungan diuji, proses nota ujian dengan penyedia/model tepat.

Kawalan penaakulan, pemikiran, pensampelan dan token keluaran bergantung pada pratetap serta peraturan model masa jalan. Uji gabungan tugas; model tersenarai tidak menjamin setiap parameter diterima.

## Penyelesaian masalah

- `401` / `403`: semak kelayakan, izin projek, akses model dan keadaan akaun.
- `404`: semak titik akhir, ID model dan sokongan API terhadap model itu.
- Senarai berjaya tetapi tugas gagal: baca ralat sembang sebenar serta model/tetapan diminta.
- Hasil panjang gagal atau terpotong: semak had keluaran, saiz sumber dan respons; ujian sambungan pendek tidak menghasilkan semula semua kegagalan panjang.

## Bila digunakan

Gunakan bagi model OpenAI langsung yang menerima protokol Chat Completions dilaksanakan. Nilai nota perwakilan sebelum memilih untuk beban kerja. Harga dan ketersediaan boleh berubah berasingan daripada keluaran Notemd.
