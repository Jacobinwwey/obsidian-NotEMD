# Penyedia China

<TLDR>Gunakan pratetap yang sepadan dengan akaun dan deployment. Laluan serantau, nama model serta izin tidak boleh ditukar ganti walaupun protokol serasi OpenAI sama. Uji tugas kecil sebelum memilih penyedia untuk beban kerja.</TLDR>

## Persediaan

Cipta akaun API penyedia, dapatkan kunci dan pilih pratetap Notemd sepadan. Sahkan rantau titik akhir akaun serta hak akses model. Jalankan **Test connection** dan tugas nota ujian; lalai tidak menjamin model tersedia kini.

Gantikan pemegang tempat Doubao dengan ID titik akhir Ark atau ID model yang disokong deployment. GLM dan Z AI mempunyai pratetap serantau berbeza. Kunci satu rantau/langganan mungkin tidak berfungsi pada titik akhir lain; ikut arahan akaun penyedia, bukan lokasi fizikal semata-mata.

## Penemuan model

Gunakan penemuan apabila dibenarkan. Huawei Cloud MaaS menggunakan penemuan berasaskan deployment; pratetap lain menggunakan laluan serasi OpenAI apabila disokong. Tiada izin senarai tidak semestinya bermakna model yang ditetapkan jelas tidak boleh menjana.

Ujian sambungan berbeza mengikut pratetap. DeepSeek boleh lulus daripada senarai sahaja, sementara beberapa pratetap serantau menjalankan sembang pendek. Tugas sebenar tetap perlu untuk mengesahkan prompt dan hasil.

## Penyelesaian masalah

- Kunci diterima tetapi penjanaan ditolak: semak hak model, deployment dan rantau akaun.
- Model Ark ditolak: sahkan titik akhir menjangkakan ID deployment atau model.
- Respons penaakulan terpotong: semak had keluaran dan tetapan pemikiran khusus penyedia.
- Ralat rangkaian: uji titik akhir daripada peranti Obsidian dan baca ralat penghantaran.

## Bila digunakan

Pilih berdasarkan titik akhir akaun boleh dicapai, keperluan pengendalian data dan hasil tugas terukur. Rantau atau jenama model bukan jaminan mutu, privasi atau kos. [Gambaran penyedia](./overview) juga menyenaraikan gerbang dan pelayan setempat.
