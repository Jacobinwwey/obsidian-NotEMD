# Penyedia Google

<TLDR>Pratetap Google menggunakan API Generative Language Gemini natif. Tetapkan kunci yang dibenarkan untuk titik akhir itu dan model yang tersedia kini. Gemini melalui sembang gerbang serasi OpenAI menggunakan pratetap gerbang.</TLDR>

## Persediaan

Pilih **Google**, masukkan kunci, kekalkan titik akhir Generative Language natif dan pilih model yang dilayan versi API itu. Jalankan **Test connection**, kemudian terjemah atau proses nota ujian. Pratetap tidak mengkonfigurasi sebarang deployment Google Cloud atau Vertex secara automatik.

## Titik akhir dan pengesahan

| Medan | Nilai pratetap |
| ------- | -------------- |
| Penghantaran | `google` |
| Kunci API | Diperlukan |
| URL asas | `https://generativelanguage.googleapis.com/v1` |
| Model lalai | `gemini-2.0-flash-exp` |
| Suhu | `0.5` |
| Ujian sambungan | `chat-only` |

Masa jalan membina permintaan model `generateContent` natif dengan pengesahan kunci API. ID model lama pratetap bukan jaminan tersedia kini. Periksa URL sebelum berkongsi diagnostik kerana butiran permintaan boleh mengandungi pengesahan.

## Penemuan model

Gunakan penemuan natif Google apabila tersedia. Pastikan model menyokong penjanaan pada versi API yang ditetapkan. Senarai kosong boleh menandakan masalah izin, titik akhir atau ketersediaan; uji konfigurasi sebenar, jangan menukar protokol secara rawak.

## Penyelesaian masalah

- `400`: periksa ID model, parameter serta had token/keluaran.
- `401` / `403`: semak sekatan kunci, pengaktifan API dan akses model.
- `404`: semak model wujud pada versi API pilihan.
- Contoh gerbang gagal: gunakan pratetap gerbang serasi OpenAI yang sepadan.

## Bila digunakan

Gunakan untuk API Gemini natif. Nilai tugas terjemahan, penyelidikan atau rajah sebenar pada sampel perwakilan. Panduan ini tidak menjanjikan kelajuan relatif, kos atau mutu terjemahan model.
