# Prompt tersuai

<TLDR>Prompt tersuai menggantikan prompt terbina apabila suis global dan tugas aktif serta teks tersuai tidak kosong. Anda perlu mengekalkan kontrak keluaran tugas. Tiada sistem templat automatik yang memulihkan setiap arahan format yang digugurkan.</TLDR>

## Gambaran keseluruhan

Uji prompt lalai pada nota perwakilan dahulu. Gunakan pembelajaran tertumpu atau penindasan sinonim jika mencukupi. Tulis prompt tersuai apabila memerlukan dasar ekstraksi, struktur atau gaya terjemahan khusus, kemudian bandingkan hasil sebelum kelompok.

## Cara kerja

### Struktur prompt

Notemd memilih prompt terbina atau tersuai yang diaktifkan, menambah arahan bidang/bahasa yang berkenaan dan menggantikan pemegang tempat yang dibekalkan tugas. Kandungan nota juga boleh dihantar dalam mesej berasingan. Input berbeza antara tugas; pemboleh ubah penyelidikan bukan tersedia di mana-mana.

Mengganti prompt ekstraksi boleh menggugurkan `CONCEPT:`. Mengganti prompt penyelidikan boleh menghilangkan konteks dapatan. Permintaan yang terbentuk dengan baik tidak membuktikan hasil boleh dihuraikan atau disokong bukti.

### Pemboleh ubah prompt

Gunakan huruf besar dan satu pasang kurungan berombak tepat seperti berikut:

| Tugas | Pemegang tempat dibekalkan |
| ------ | ----------------------- |
| Penjanaan tajuk | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Ringkasan penyelidikan | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Terjemahan | `{LANGUAGE}`, `{TEXT}` |
| Ekstraksi teks asal | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` diselesaikan melalui dasar bahasa tugas. Tambah pautan dan ekstraksi konsep kendiri menghantar teks sebagai kandungan tugas; jangan mencipta pemegang tempat kandungan untuknya. Nama tidak dikenali tidak diisi secara automatik. Ini penggantian prompt tugas, bukan templat fail nota konsep.

### Bidang pembelajaran tertumpu

Aktifkan pembelajaran tertumpu dan masukkan bidang seperti `electrical engineering`. Prompt menerima arahan `Relevant Fields`. Ini membimbing perhatian model, bukan penapis mutlak atau bukti konsep luar bidang akan dikecualikan.

## Konfigurasi

| Tugas | Suis pengaktifan | Medan prompt |
| ------ | --------------- | -------------- |
| Tambah pautan | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Penjanaan tajuk | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Ringkasan penyelidikan | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Ringkasan Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Ekstraksi konsep | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Terjemahan | `useCustomPromptForTranslate` | `translatePrompt` |
| Ekstraksi teks asal | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Semuanya memerlukan `enableGlobalCustomPrompts`. Teks tersuai kosong kembali kepada prompt terbina. Ekstraksi teks asal tergabung mempunyai format terbina sendiri dan tidak berkongsi gantian ekstraksi biasa. Penjanaan rajah mempunyai keperluan keluaran berjenis sendiri; gantian ringkasan Mermaid bukan prompt rajah sejagat.

## Contoh

Untuk konsep nota litar, aktifkan suis global dan ekstraksi, lalu kekalkan kontrak penghurai dalam arahan tertumpu:

```text
Ekstrak konsep utama kejuruteraan elektrik daripada nota yang dibekalkan.
Utamakan nama komponen khusus dan mekanisme fizikal berbanding kata nama umum.
Kembalikan satu konsep setiap baris dengan format tepat berikut:
CONCEPT: Nama Istilah
Jangan tambah huraian atau blok kod pembungkus.
```

Uji pada salinan nota. Semak entri, nama fail dan konsep yang hilang, kemudian bandingkan dengan lalai. Simpan prompt asal sebelum menyunting agar boleh dipulihkan.

## Petua

- Uji satu tugas pada satu masa; perincikan skop sebelum membesarkan kelompok.
- Kekalkan bukti sumber dalam penyelidikan dan petikan tepat dalam ekstraksi.
- Kekalkan pengecam boleh laku dan penanda keluaran ketika menterjemah arahan.
- Uji semula selepas menukar model/penyedia; arahan bukan jaminan pengesahan.
