# Pemprosesan kelompok

<TLDR>Tindakan folder berkongsi kawalan pemilihan dan kemajuan, tetapi hasil serta penulisan gantinya berbeza. Keserentakan lalai ialah satu. Mulakan dengan folder ujian khusus, periksa skop dan destinasi, kemudian luaskan kelompok.</TLDR>

## Gambaran keseluruhan

Gunakan tindakan folder bar sisi atau menu penjelajah fail yang sepadan. Tugas meliputi tambah pautan, ekstraksi konsep, penjanaan tajuk, terjemahan, ekstraksi teks asal serta pembaikan Mermaid dan formula. Tiada tindakan penyelidikan folder umum; penjanaan tajuk boleh menyertakan penyelidikan pilihan.

Kelompok bukan transaksi seluruh folder. Hasil yang berjaya ditulis kekal jika fail lain gagal atau operasi dibatalkan.

## Cara kerja

### Model pelaksanaan kelompok

1. Pilih tugas dan folder yang hanya mengandungi fail yang dimaksudkan.
2. Tugas mengumpulkan fail layak, menggunakan peraturan sambungan/pemilihan dan mengecualikan hasil khusus tugas.
3. Penyedia/model tugas digunakan; kemajuan, kegagalan dan destinasi dilaporkan.
4. Selepas selesai atau batal, semak laporan dan fail sebelum mengulang.

Skop lalai menyertakan subfolder untuk tambah pautan, konsep, penjanaan tajuk, ekstraksi asal, pembaikan Mermaid dan formula. **Terjemahan folder lalai hanya fail anak langsung.** Profil pemilihan lanjutan boleh mengubah skop/penapis apabila mod pembangun dan pemilihan fail lanjutan kedua-duanya aktif. Semak profil sebenar; jangan anggap semua tugas menelusuri subfolder secara sama.

### Tingkah laku tulis ganti

| Tugas | Perkara diperiksa sebelum mengulang |
| ------ | ------------------------------------ |
| Tambah pautan | Hasil berasingan secara lalai; semak akhiran, folder hasil dan pemindahan asal |
| Ekstraksi konsep | Nota sedia ada boleh menerima pautan balik apabila aktif; semakan pendua berasingan |
| Penjanaan tajuk | Kandungan ditulis ke nota sumber layak; hasil berjaya dipindah ke folder complete dilaporkan jika destinasi kosong |
| Terjemahan | Hasil terjemahan sepadan boleh ditulis ganti; nama lalai menggunakan `_<language>.md` |
| Pembaikan Mermaid / formula | Mengubah nota pilihan; semak sampel kecil dan simpan sandaran |

Tiada tetapan langkau/tambah/ganti sejagat. Bagi penjanaan tajuk kelompok, destinasi folder complete sedia ada menghalang pemindahan; ini tidak bermakna penjanaan sebelumnya dilangkau. Hasil membezakan jumlah dijana dan dipindahkan.

### Kawalan keserentakan

Kekalkan `batchConcurrency` pada `1` sehingga sampel perwakilan berjaya. Sesetengah laluan juga memerlukan `enableBatchParallelism`; terjemahan folder menggunakan keserentakannya secara langsung. Nilai lebih tinggi menambah tekanan penyedia, memori dan pelayan setempat, bukan jaminan lebih pantas.

Sela API dan lengah antara kelompok mengurangkan lonjakan, tetapi tidak menjamin pematuhan kuota permintaan/token, had akaun atau penggunaan aplikasi lain pada titik akhir sama.

## Konfigurasi

| Tetapan | Lalai | Kesan |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Keserentakan diminta pada laluan kelompok berkenaan |
| `enableBatchParallelism` | `false` | Aktifkan penjadualan selari apabila disokong |
| `batchSize` | `50` | Saiz kumpulan pada laluan penjadualan kelompok |
| `batchInterDelayMs` | `1000` | Lengah antara kumpulan apabila berkenaan |
| `apiCallIntervalMs` | `500` | Sela penjadualan permintaan serentak |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Kekalkan skop subfolder lalai setiap tugas |
| `enableStableApiCall` | `false` | Mod permintaan stabil yang dipilih jelas |

### Model khusus tugas dalam kelompok

Tindakan folder menggunakan pilihan penyedia/model yang sama seperti tugas satu fail berkaitan. Semak sebelum bahan peribadi. Dapatan pengetahuan setempat pilihan untuk penjanaan tajuk kelompok menggunakan satu petikan keadaan indeks pada permulaan; suntingan ketika berjalan tidak dicampur ke hasil dapatan kemudian. Mulakan kelompok baharu untuk memasukkannya.

## Contoh

Cipta `trial-titles` dengan dua nota tajuk tanpa fail lain. Jalankan **Batch generate from titles**, semak kandungan dan destinasi `trial-titles_complete`, kemudian jumlah dijana/dipindah/ralat. Diagnosis fail gagal sebelum mengulang; menjalankan folder asal semula bukan sambungan automatik tepat bagi kerja belum siap.

## Pembatalan dan pemulihan

Cancel menghentikan penjadualan baharu dan menghantar pembatalan kepada permintaan disokong. Panggilan atau penulisan yang sudah diterima sistem luaran mungkin selesai; bil jauh dikawal penyedia. Tunggu kelompok stabil, periksa fail selesai dan laluan pemulihan/konflik. Kekalkan hasil pemulihan sehingga dibandingkan dengan nota semasa.

## Petua

- Sahkan fail padanan sebenar sebelum menggunakan profil pemilihan.
- Kurangkan keserentakan dan semak kuota untuk ralat 429.
- Bezakan batal, gagal dan selesai.
- Simpan sampel asal serta sandaran sebelum operasi yang mengubah nota.
