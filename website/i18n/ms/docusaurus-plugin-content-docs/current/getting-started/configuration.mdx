# Konfigurasi

<TLDR>Buka **Settings → Notemd** dan gunakan carian tetapan. Sediakan penyedia dan destinasi sebelum memproses. Uji perubahan pada satu nota dahulu; operasi berjalan boleh mengekalkan tetapan ketika ia bermula.</TLDR>

## Gambaran tetapan

Penyedia aktif lalai ialah DeepSeek dengan kelayakan awal kosong. Memilih pratetap tidak mencipta akaun, memasang model atau memberi akses. [Panduan penyedia](../providers/overview) menerangkan protokol dan penemuan model.

## Carian tetapan dan kegemaran

- **Search settings** memadankan nama, penerangan, alias dan kategori terlihat, kemudian menuju medan pilihan.
- **★ Favorites** membuka tetapan tersimpan dengan penerangan, kategori dan sasaran navigasi. Ia milik Vault semasa, kekal selepas mula semula dan membuang ID lapuk.
- Tutup bar carian dengan chevron untuk menjimatkan ruang; membukanya semula memulihkan kueri.
- Senarai kegemaran berasingan daripada penapis carian kegemaran sahaja.

**Diagram preview export PPI** lalai **300 PPI**, julat **72-600**. Ia mempengaruhi raster PNG; SVG/PDF mengekalkan geometri vektor apabila disokong. **Also export complete Mermaid visuals** mengawal fail pendamping, bukan keterlihatan Mermaid dalam pratonton Drawnix.

Pilih beberapa jenis rajah dalam satu pelaksanaan dan beberapa format output secara berasingan bagi setiap jenis. Nyahpilih jenis masih mengekalkan formatnya; tanpa pilihan, kandungan dianalisis secara automatik.

Tetapkan folder perantaraan bersama relatif kepada Vault, atau kosongkan untuk menggunakan `notemd_assert/` di sebelah setiap sumber. Rekod pemulihan, cache pemaparan dan lampiran pilihan disimpan di situ. Kekalkan fail yang masih dirujuk; perubahan folder hanya terpakai pada pelaksanaan baharu.

## 1. Penyedia

Pilih penyedia, isi kelayakan jika perlu, kekalkan titik akhir sesuai protokol dan pilih model boleh dicapai. Gunakan **Fetch models** jika tersedia, kemudian **Test connection**. Senarai model dan kejayaan penjanaan ialah pemeriksaan berasingan.

Model setempat memerlukan pelayan berjalan dan model dimuatkan. Awan/gateway menerima kandungan tugas. Semak penyedia khusus tugas dan yang aktif sebelum kerja peribadi.

## 2. Model mengikut tugas

Aktifkan `useMultiModelSettings` untuk penyedia/model berasingan bagi pautan, penjanaan tajuk, penyelidikan, terjemahan, konsep, ekstraksi teks asal dan ringkasan Mermaid. Medan model kosong menggunakan model penyedia berkenaan. Jika tidak aktif, tugas menggunakan penyedia aktif.

Bandingkan dengan nota perwakilan, ketepatan hasil, kependaman dan harga akaun sebenar. Dokumentasi tidak menentukan kedudukan model atau menjamin ketersediaan.

## 3. Keluaran

| Tugas | Tingkah laku lalai |
| ------ | ------------------------- |
| Tambah pautan | Fail `_processed.md` di sebelah sumber; pemindahan asal dimatikan |
| Ekstraksi konsep kendiri | Memerlukan folder konsep; nota tajuk sahaja tanpa pautan balik |
| Terjemahan | Fail `_<language>.md` di sebelah sumber; destinasi sedia ada boleh ditulis ganti |
| Penyelidikan | Menambah ringkasan ke Markdown aktif |
| Penjanaan tajuk berkelompok | Menulis kandungan dan memindahkan nota layak ke `<folder>_complete` sejajar yang dilaporkan jika destinasi mengizinkan |
| Pratonton/eksport rajah | Fail terpilih dieksport secara automatik di sebelah nota sumber atau terus ke folder output yang ditetapkan. Nama menyertakan jenis, seperti `topic_drawnix.pdf` dan `topic_flowchart.svg`. Konflik nama menambah `-2`, `-3` dan seterusnya tanpa menulis ganti fail. |
Folder konsep awalnya kosong. `concepts` ialah contoh nama, bukan lalai. Ekstraksi kendiri menyokong bentuk minimum/penuh, bukan enjin pemboleh ubah templat umum. Lihat [konsep](../features/concept-notes).

Akhiran pautan, folder hasil, akhiran terjemahan dan laluan terjemahan ialah tetapan berasingan. Periksa destinasi sebelum mengulang penulisan. Mesej pemulihan/konflik mengenal pasti hasil yang perlu diperiksa; pembatalan tidak mengundur penulisan selesai.

## 4. Bahasa

Pemalam mempunyai **21 bahasa UI**, laman mempunyai **34 laluan bahasa**. `uiLocale: auto` mengikut pemetaan tersedia; bahasa UI tidak disokong menggunakan bahasa Inggeris.

Bahasa kandungan berasingan dan lalainya Inggeris. Aktifkan bahasa setiap tugas jika pautan, tajuk, penyelidikan, konsep atau Mermaid memerlukan bahasa berlainan. Terjemahan memakai bahasa keluaran pilihan (`language`), tidak bergantung UI. Keupayaan model berasingan daripada jumlah bahasa UI/laman.

## 5. Carian

Pilih **Tavily** dengan kunci API atau **DuckDuckGo** secara jelas. Kunci Tavily kosong tidak bertukar secara automatik. Kedua-duanya menggunakan rangkaian; DuckDuckGo juga boleh mendapatkan halaman hasil.

Penjanaan tajuk tidak menyelidik secara lalai. Aktifkan `enableResearchInGenerateContent` jika diperlukan. Dapatan pengetahuan setempat juga dimatikan secara lalai, dengan skop folder/tugas berasingan. Petikan yang digunakan sebagai konteks dihantar ke LLM tugas walaupun indeks dibina setempat.

## 6. Aliran kerja

Gunakan pembina aliran atau satu definisi DSL bernama bagi setiap baris. Lalai:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` memisahkan nama butang dan tindakan, `>` memisahkan ID. Dasar lalai berhenti pada ralat langkah dilaporkan. [Aliran](../features/workflows) menerangkan ID, konteks folder dan akibat meneruskan selepas ralat.

## 7. Tetapan lanjutan

| Tetapan | Lalai | Kesan |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Penyedia tanpa penghalaan khusus tugas |
| `useMultiModelSettings` | `false` | Aktifkan pilihan model/penyedia berasingan |
| `useCustomConceptNoteFolder` | `true` | Benarkan fail konsep selepas folder dipilih |
| `conceptNoteFolder` | `''` | Tiada folder konsep dipilih pada awal |
| `extractConceptsMinimalTemplate` | `true` | Nota konsep kendiri tajuk sahaja |
| `extractConceptsAddBacklink` | `false` | Pautan balik hanya apabila diaktifkan |
| `moveOriginalFileOnProcess` | `false` | Kekalkan sumber semasa tambah pautan |
| `chunkWordCount` | `3000` | Saiz cebisan anggaran, bukan had token penyedia |
| `batchConcurrency` | `1` | Keserentakan kelompok lalai |
| `enableBatchParallelism` | `false` | Aktifkan selari pada laluan yang menggunakan suis ini |
| `enableStableApiCall` | `false` | Mod permintaan stabil yang dipilih jelas |
| `customWorkflowErrorStrategy` | `stop_on_error` | Hentikan aliran pada ralat dilaporkan |

Pemecahan cebisan dan bajet token keluaran berbeza. Cebisan kecil tidak menjamin had konteks dipatuhi. Keserentakan rendah mengurangkan tekanan kuota tetapi tidak mencegah semua 429.

## Profil konfigurasi

Tetapan tersimpan dalam data pemalam Vault. Sandarkan sebelum menukar konfigurasi yang berfungsi. Eksport profil mempunyai kontrak penyamaran sendiri, bukan sandaran Vault penuh. Semak URL/metadata sebelum berkongsi walaupun telah disamarkan. Jangan terbitkan tetapan mentah atau diagnostik berisi nota peribadi.

## Masalah konfigurasi

Uji **Test connection** untuk penyedia/model tepat, kemudian satu nota kecil. Jika tetapan hilang, cari nama, semak kategori serta mod pembangun dan pastikan Vault betul. Laporkan versi dan butiran yang telah dibersihkan.

## 1.9.10 — Pratonton selamat dan tetapan setempat Vault

Pratonton SVG yang diimport membuang kandungan aktif dan sumber luar, sambil mengekalkan label Cina serta gaya panel. Pembekal setempat diasingkan mengikut Vault; import senarai lama secara jelas melalui tetapan dengan mengekalkan senarai asal dan konfigurasi sedia ada. Persembahan menggunakan pelayan loopback yang mengurus pengguna bersama. Kegagalan menyimpan kegemaran dan menyalin dilaporkan; pemadaman mengikut pilihan Vault. Keserasian PNG kekal aktif: imej asal disimpan dan salinan PPI lebih rendah yang disahkan ditambah hanya jika perlu. Drawnix tiada had hubungan tetap; persembahan kekal dengan tetapan berasingan. Pasang fail versi yang sama, muat semula dan uji satu nota sebelum pemprosesan kelompok.
