# Mula pantas

<TLDR>Mulakan dengan satu nota Markdown ujian dan penyedia yang sudah boleh dicapai. Periksa fail hasil sebelum folder. Panggilan awan menghantar kandungan tugas; model setempat masih memerlukan pelayan berjalan dan model dimuat turun.</TLDR>

## Langkah 1: Sediakan penyedia pertama

1. [Pasang dan aktifkan](./installation), kemudian buka **Settings → Notemd**.
2. Pilih penyedia, masukkan titik akhir serta kelayakan jika perlu, dan pilih model tersedia untuk akaun. Gunakan **Fetch models** jika disokong; tersenarai belum membuktikan penjanaan berjaya.
3. Jalankan **Test connection**. Selesaikan ralat pengesahan, model atau titik akhir sebelum aliran.
4. Cari **Concept note folder path**. Pilih folder khusus seperti `concepts` jika mahu fail konsep. Tetapan awal kosong; `concepts/` ialah contoh pilihan, bukan destinasi prakonfigurasi.

Untuk Ollama, muat turun model dahulu dan masukkan nama setempat tepat. Titik akhir pratetap `http://localhost:11434/api`. Untuk LM Studio, mulakan pelayan dan gunakan `LMStudio`. Lihat [model setempat](../providers/local). Penyelidikan web tetap memerlukan rangkaian walaupun model peringkas setempat.

## Langkah 2: Cuba tugas pertama

Cipta `Notemd trial.md` dengan perenggan pendek yang dibenarkan dihantar kepada penyedia:

```text
Model pembelajaran mesin menggunakan rangkaian neural untuk mempelajari corak daripada contoh.
```

Jalankan **Process file (add links)** daripada bar sisi atau palet. Secara lalai, fail `Notemd trial_processed.md` dicipta di sebelah sumber dan sumber dikekalkan. Periksa pautan sebenar; hasil model berbeza-beza. Contoh:

```markdown
Model [[pembelajaran mesin]] menggunakan [[rangkaian neural]] untuk mempelajari corak daripada contoh.
```

Folder konsep terpilih juga boleh menerima nota. Periksa fail dan pautan; proses ini tidak menjamin setiap konsep penting dikenal pasti dengan betul.

## Langkah 3: Cuba ciri lain

### Ekstrak konsep

**Extract concepts (current file)** mengekstrak tanpa menulis semula sumber dan memerlukan folder konsep. Nota ekstraksi kendiri lalai hanya tajuk, tanpa pautan balik sumber. Aktifkan pautan balik jika perlu. [Nota konsep](../features/concept-notes) menjelaskan perbezaan dengan tambah pautan.

### Selidik dan ringkaskan

Pilih topik dalam editor Markdown terbuka atau gunakan tajuk, lalu **Research & summarize**. Pilih Tavily dengan kunci API atau DuckDuckGo secara jelas. Ringkasan ditambah kepada nota aktif. Buka dan sahkan sumber sebelum bergantung pada dakwaan.

### Aliran satu klik

**One-Click Extract** lalai menggunakan definisi tepat:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Ia menambah pautan, menjana kandungan nota layak dalam folder konsep/pilihan, kemudian membaiki Mermaid dalam folder complete penjanaan. Nota konsep sedia ada boleh terlibat. Gunakan folder ujian khusus dahulu. Penyelidikan web atau penjanaan rajah tidak ditambah secara automatik.

## Pembatalan dan pemeriksaan hasil

Gunakan **Cancel** untuk menghentikan kerja seterusnya. Hasil selesai dikekalkan; pembatalan bukan transaksi undur dan tidak menjamin penyedia berhenti menjana atau mengenakan caj. Tunggu tugas stabil sebelum mula semula. Semak destinasi dan konflik pemulihan, bukan anggap proses batal tiada hasil.

## Penyelesaian masalah

- Pengesahan/model: semak profil tepat dan ulang **Test connection**.
- Tiada konsep: pastikan folder dipilih dan diaktifkan.
- Pautan tidak berguna: periksa respons/prompt; tiada jumlah perkataan minimum menjamin ekstraksi.
- Had kadar: kekalkan keserentakan lalai `1` semasa memeriksa kuota.
