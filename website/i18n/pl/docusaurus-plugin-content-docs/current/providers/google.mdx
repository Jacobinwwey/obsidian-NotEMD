# Google

<TLDR>Google używa natywnego Gemini Generative Language. Ustaw dozwolony klucz i dostępny model. Gemini za kompatybilną bramką wymaga profilu bramki.</TLDR>

## Przygotowanie

Wybierz **Google**, klucz, natywny endpoint i model danej wersji API. Sprawdź połączenie i notatkę. Nie konfiguruje to automatycznie dowolnego wdrożenia Google Cloud/Vertex.

## Endpoint i uwierzytelnianie

| Pole | Wartość początkowa |
| ------- | -------------- |
| Transport | `google` |
| Klucz API | Wymagany |
| Bazowy URL | `https://generativelanguage.googleapis.com/v1` |
| Model | `gemini-2.0-flash-exp` |
| Temperatura | `0.5` |
| Test połączenia | `chat-only` |

Żądanie używa `generateContent` i klucza. Historyczne ID nie gwarantują dostępu. Sprawdź URL-e diagnostyczne przed udostępnieniem; mogą zawierać dane uwierzytelniające.

## Modele

Użyj natywnego odkrywania i zweryfikuj generację na wybranym API. Pusta lista może oznaczać problem praw, adresu lub modelu. Zdiagnozuj przyczynę przed zmianą protokołu.

## Problemy

- 400: ID, parametry i limity wejścia/wyjścia.
- 401/403: ograniczenia klucza, aktywne API i prawa.
- 404: czy model istnieje w tej wersji API?
- Przykłady bramki: użyj właściwego profilu OpenAI-compatible.

## Kiedy wybrać

Dla natywnego Gemini. Testuj tłumaczenie, badanie lub diagramy na własnym materiale. Bez ogólnych gwarancji szybkości, ceny i jakości.
