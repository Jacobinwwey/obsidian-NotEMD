# Dostawcy chińscy

<TLDR>Wybierz profil konta i wdrożenia. Nawet przy wspólnym protokole OpenAI-compatible regiony, ścieżki, modele i prawa nie są zamienne. Zweryfikuj małe zadanie.</TLDR>

## Przygotowanie

Przygotuj konto/klucz, wybierz profil, potwierdź region i prawa modelu. Domyślne wartości nie gwarantują aktualnej dostępności. Testuj połączenie i notatkę.

## Modele

Korzystaj z list, gdzie wolno. Huawei Cloud MaaS wymaga znajomości wdrożenia; inne profile używają obsługiwanego odkrywania OpenAI-compatible. Brak prawa listowania nie zawsze wyklucza generowanie z dokładnym ID. DeepSeek może przejść test połączenia na liście; część profili regionalnych generuje krótką odpowiedź. Rzeczywiste zadanie nadal wymaga sprawdzenia.

## Problemy

- Klucz przyjęty, generowanie odrzucone: prawa modelu, wdrożenie i region.
- Ark odrzuca ID: potrzebny endpoint czy model?
- Rozumowanie obcięte: budżet i modelowy thinking.
- Sieć: sprawdź adres z Obsidiana i przeczytaj błąd transportu.

## Kiedy wybrać

Gdy prawa konta, dostępność i zasady danych odpowiadają potrzebom. Geografia nie dowodzi jakości języka ani niskiej ceny. Porównaj tę samą próbkę i zapisz ustawienia.
