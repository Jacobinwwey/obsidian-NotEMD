# Anthropic

<TLDR>Użyj tego profilu dla natywnego Messages. Claude przez bramkę OpenAI-compatible używa profilu bramki. Historyczny model początkowy może wymagać zastąpienia modelem dostępnym na koncie.</TLDR>

## Przygotowanie

Wybierz **Anthropic**, klucz i dostępny model. Zachowaj natywny adres, chyba że wdrożenie dostarcza identyczny protokół. Testuj połączenie i notatkę.

## Endpoint i uwierzytelnianie

| Pole | Wartość początkowa |
| ------- | -------------- |
| Transport | `anthropic` |
| Klucz API | Wymagany |
| Bazowy URL | `https://api.anthropic.com` |
| Model | `claude-3-5-sonnet-20240620` |
| Temperatura | `0.5` |
| Test połączenia | `chat-only` |

Obsługa używa `/v1/messages` z natywnymi nagłówkami klucza i wersji. Nie dodawaj ścieżki czatu OpenAI. Wartości początkowe opisują konfigurację repozytorium, nie aktualną dostępność.

## Modele

Używaj natywnego odkrywania, gdy jest dozwolone. Gdy lista jest chroniona, wpisz dozwolone ID i przetestuj generowanie. Długie i strukturalne zadania wymagają osobnej kontroli.

## Problemy

- 401/403: klucz, projekt, rozliczenia i prawa do modelu.
- 404: adres i dostępność.
- ID bramki odrzucone: dobierz profil i identyfikator.
- Błędy długich żądań: zbadaj limity przed zwiększeniem ponowień.

## Kiedy wybrać

Dla natywnych endpointów Messages. Porównuj wyniki ze źródłami zamiast uniwersalnej listy najlepszych dostawców. Trasy zadań pozwalają ograniczyć użycie do konkretnej funkcji.
