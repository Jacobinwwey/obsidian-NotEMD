# OpenAI

<TLDR>Profil korzysta ze wspólnej obsługi OpenAI Chat Completions. Wybierz klucz i model tego protokołu. Model początkowy nie gwarantuje obecnego dostępu ani uniwersalnej jakości.</TLDR>

## Przygotowanie

Dla oficjalnej usługi użyj **OpenAI**, klucza i `https://api.openai.com/v1`. Model na liście może wymagać innego API. Bramki mają własne profile/nagłówki; Azure używa **Azure OpenAI**, deploymentu i wersji API.

## Endpoint i uwierzytelnianie

| Pole | Wartość początkowa |
| ------- | -------------- |
| Transport | `openai-compatible` |
| Klucz API | Wymagany |
| Bazowy URL | `https://api.openai.com/v1` |
| Model | `gpt-4o` |
| Temperatura | `0.5` |
| Test połączenia | `models-then-chat` |

Znane postaci URL są normalizowane przed budowaniem ścieżek żądań. Zacznij od profilu i sprawdź wynikowy adres zamiast losowo dopisywać segmenty.

## Modele

**Fetch models** pobiera dostępne modele. **Testuj połączenie** może przejść na samej liście. Sprawdź konkretny model na notatce. Reasoning, thinking, próbkowanie i budżety muszą pasować do profilu/modelu.

## Problemy

- 401/403: klucz, projekt, prawa i konto.
- 404: endpoint, ID modelu i obsługa API.
- Lista działa, generacja nie: błąd czatu i parametry.
- Długa odpowiedź przerwana: wejście, budżet i odpowiedź; krótki test tego nie sprawdza.

## Kiedy wybrać

Dla bezpośrednich endpointów OpenAI obsługujących Chat Completions. Oceniaj własne notatki; ceny i dostępność zmieniają się niezależnie od Notemd.
