# Przepływy pracy

<TLDR>Przepływ wykonuje działania panelu bocznego po kolei. Działanie może wymagać wyboru folderu lub aktywnego edytora. Nie jest to potok tekstu: każdy etap zachowuje własne wejście, wynik i skutki uboczne. Zacznij od testowej notatki i osobnego folderu.</TLDR>

## Przegląd

Dostarczany **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Dodaje linki do aktywnej notatki i tworzy pojęcia, jeśli wybrano folder.
2. Generuje treść odpowiednich notatek z tytułów w folderze pojęć/wybranym folderze, również istniejących.
3. Naprawia Mermaid w folderze complete z tej generacji.

Domyślny łańcuch nie prowadzi badań internetowych. Generowanie z tytułów może je włączyć osobnym ustawieniem. Zobacz [przetwarzanie wsadowe](../advanced/batch-processing).

## Jak to działa

### Wykonanie

Etapy są sekwencyjne; panel pokazuje bieżący etap i błędy. Anulowanie zatrzymuje następne działania i dociera do obsługiwanych żądań. Ukończone pliki pozostają, więc całość nie jest transakcją. Folder pojęć jest początkowo preferowany. Generowanie wsadowe zapamiętuje folder źródłowy i complete, a Mermaid używa complete. Inne działania zachowują wymagania pliku, zaznaczenia i interakcji.

### DSL

Jedna nazwana linia na przycisk. `::` oddziela nazwę od działań, `>` rozdziela ich ID. Linie puste oraz zaczynające się od `#` są ignorowane; nieznane ID odrzucane.

```text
Wyodrębnij i narysuj::extract-concepts-current>summarize-as-mermaid
```

Użyj kreatora lub edytuj DSL. ID pozostają stałe, etykiety zależą od języka UI. Warianty folderowe mają własne ID; nie wywodź ich przez dowolną zamianę tekstu.

| ID | Działanie / wymaganie |
| ------------ | ----------------------- |
| `process-current-add-links` | Linki w aktywnej notatce |
| `process-folder-add-links` | Linki w wybranym folderze |
| `extract-concepts-current` | Pojęcia z aktywnej notatki |
| `extract-concepts-folder` | Pojęcia z wybranego folderu |
| `generate-from-title` | Treść z aktywnego tytułu |
| `batch-generate-from-titles` | Treść odpowiednich notatek folderu |
| `research-and-summarize` | Badanie zaznaczenia/tytułu w otwartym edytorze Markdown |
| `summarize-as-mermaid` | Podsumowanie obsługiwanego aktywnego wejścia jako Mermaid |
| `generate-diagram` | Diagram z obsługiwanego wejścia |
| `preview-diagram` | Podgląd obsługiwanego źródła lub diagramu |
| `translate-current-file` | Tłumaczenie aktywnego obsługiwanego pliku |
| `batch-translate-folder` | Tłumaczenie wybranego folderu |
| `extract-original-text` | Wyodrębnienie wskazanych oryginalnych fragmentów |

### Łańcuch domyślny lub własny

One-Click Extract jest predefiniowany. Inne przyciski definiujesz sam: nazwa, kolejność i ustawienia. Sprawdź podpowiedź w panelu i usuń błędy parsera przed użyciem.

## Ustawienia

| Ustawienie | Wartość początkowa | Działanie |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Zatrzymanie po pierwszym zgłoszonym błędzie etapu |
| `useMultiModelSettings` | `false` | Aktywny dostawca do czasu włączenia tras zadań |
| `enableResearchInGenerateContent` | `false` | Brak badania przy generowaniu z tytułu, dopóki go nie włączysz |

`continue_on_error` uruchamia dalsze kroki mimo błędu. Stosuj tylko, gdy potrafią obsłużyć pozostałe wejście. Kontynuowanie nie oznacza sukcesu częściowego przepływu.

### Modele etapów

Wybór modelu należy do zadania. Puste nadpisanie używa modelu wybranego dostawcy. Sprawdź wszystkie trasy przed prywatnym materiałem.

## Przykład

Ustaw pusty `trial-concepts` i źródło testowe. Sprawdź pojęcia oraz raportowany folder complete. Uruchom działania osobno, jeśli cele są niejasne. Zwiększ zakres po przeglądzie.

## Wskazówki

- Utrzymuj czytelne łańcuchy, aby rozumieć błędy i pochodzenie plików.
- Operacje usuwania zachowują interaktywne potwierdzenie; unikaj ich w przepływach bez nadzoru.
- Sprawdź logi i pliki po anulowaniu lub konflikcie odzyskiwania.
- Testuj konkretny model i folder; połączenie nie dowodzi wystarczających kwot długiej partii.
