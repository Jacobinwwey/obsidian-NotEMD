# Notatki pojęciowe

<TLDR>Samodzielna ekstrakcja czyta źródło i tworzy pojęcia Markdown w wybranym folderze. Początkowo żaden folder nie jest ustawiony. Nowe notatki zawierają tylko tytuł, bez linku zwrotnego. Dodawanie linków używa innej postaci pojęć.</TLDR>

## Przegląd

Najpierw ustaw **Ścieżka folderu notatek pojęciowych**. Osobny folder ułatwia kontrolę plików, duplikatów i późniejszego generowania z tytułów. Ekstrakcja nie wypełnia automatycznie notatek zbadanymi wyjaśnieniami.

## Jak to działa

### Ekstrakcja

Wybrany LLM otrzymuje tekst. Zadanie odczytuje linie `CONCEPT:`, usuwa powtórzenia nazw w obrębie operacji i tworzy lub aktualizuje pliki. Długie notatki są dzielone. Sprawdź części zakończone błędem; odpowiedź nie gwarantuje pełnego katalogu pojęć.

### Prompt ekstrakcji

Domyślna instrukcja wymaga konkretnych, istotnych pojęć. Domena i ograniczanie synonimów nie gwarantują kanonicznego słownika. Własny prompt musi zachować `CONCEPT: Term`. Zobacz [prompty](../advanced/custom-prompts).

### Fragmenty

`chunkWordCount` zaczyna od około 3000 słów, nie tokenów dostawcy. Kontekst pomiędzy fragmentami jest ograniczony; sprawdź relacje i niejednoznaczne nazwy.

## Tworzenie plików

### Reguły nazw

Nieprawidłowe znaki ścieżki są usuwane, odstępy normalizowane, długie nazwy skracane, a puste pomijane. Różne terminy mogą przez to otrzymać tę samą ścieżkę. Sprawdź nazwy przed masowym tworzeniem.

### Szablony

Minimalna nowa notatka:

```markdown
# Nazwa pojęcia
```

Aby dodać link zwrotny do nowej samodzielnej notatki, włącz **Add "Linked From" backlink** i wyłącz **Create minimal concept notes**:

```markdown
# Nazwa pojęcia

## Linked From
- [[Notatka źródłowa]]
```

Dodawanie linków używa pełnej postaci z odniesieniem do źródła, gdy wyniki pojęciowe są włączone. Przełączniki samodzielnej ekstrakcji nie zmieniają tej ścieżki.

### Istniejące notatki

Przy włączonych linkach zwrotnych brakujące źródło może zostać dopisane pod `## Linked From`. Istniejący tekst pozostaje, a ten sam link nie jest dublowany. Bazowa nazwa źródła może być niejednoznaczna między folderami.

### Ustawienia

| Ustawienie | Wartość początkowa | Działanie |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Wyniki pojęciowe po wybraniu folderu |
| `conceptNoteFolder` | `''` | Brak ustawionego folderu |
| `extractConceptsMinimalTemplate` | `true` | Samodzielne pojęcia z samym tytułem |
| `extractConceptsAddBacklink` | `false` | Linki zwrotne w samodzielnej ekstrakcji |
| `extractConceptsProvider` | `DeepSeek` | Dostawca przy trasach zadań |
| `extractConceptsModel` | `''` | Puste używa modelu dostawcy |
| `extractConceptsLanguage` | `en` | Język przy ustawieniach dla zadań |
| `replaceSynonymsDuringConceptExtraction` | `false` | Instrukcja ograniczania synonimów |
| `generateConceptLogFile` | `false` | Opcjonalny dziennik pojęć |

## Duplikaty

Kontrola opiera się na heurystykach nazw: wielkości liter, liczbie mnogiej, normalizacji symboli i, gdzie dopuszczalne, pojedynczym słowie w innej nazwie. To nie dowód tożsamości znaczeń. Sprawdź nieregularne formy i różnice techniczne w **Sprawdź i usuń duplikaty**; zatwierdzaj tylko zamierzone usunięcia. Koszem zarządza Obsidian. Folder pojęć nie jest jednorazowym cache; wykonaj kopię.

### Zakres porównania

Porównuj ze skarbcem, samym folderem pojęć, folderami uwzględnionymi albo zakresem z wyłączeniami. Zakres zmienia kandydatów, nie definicję duplikatu.

## Użycie

### Samodzielna ekstrakcja

Otwórz Markdown, sprawdź folder i wybierz **Wyodrębnij pojęcia (bieżący plik)**. Źródło pozostaje. Sprawdź nazwy, kompletność i linki zwrotne.

### Ekstrakcja i treść

**Generowanie wsadowe z tytułów** uzupełnia pojęcia, ale może objąć wcześniejsze odpowiednie notatki. Przejrzyj folder przed uruchomieniem i raportowany folder complete po zakończeniu.

### Link z zaznaczenia

Osobna operacja tworzy wiki-link z wybranego terminu i może utworzyć plik pojęcia, jeśli ustawiono miejsce docelowe.

## Wskazówki

- Krótkie źródło i osobny folder.
- Wybór języka przed tworzeniem wielu plików.
- Osobna ocena synonimów i duplikatów.
- Zachowanie potrzebnych logów przed kolejnym nadpisującym uruchomieniem.
