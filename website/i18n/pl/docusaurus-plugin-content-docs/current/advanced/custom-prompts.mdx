# Własne prompty

<TLDR>Niepusty własny prompt zastępuje wbudowany, gdy włączono przełącznik globalny i danego zadania. Zachowaj kontrakt wyniku: system szablonów nie przywraca automatycznie usuniętych wymagań formatu.</TLDR>

## Przegląd

Najpierw sprawdź domyślny prompt na reprezentatywnej notatce. Domena lub instrukcja synonimów może wystarczyć. Dostosuj strukturę, politykę lub styl tłumaczenia, jeśli potrzeba, i porównaj przed partią.

## Jak to działa

### Składanie instrukcji

Notemd wybiera prompt wbudowany/własny, dodaje właściwe instrukcje domeny/języka i podstawia zmienne dostarczone przez zadanie. Notatka może być osobną wiadomością. Zmienne nie są uniwersalne. Zastąpienie może pominąć `CONCEPT:` lub kontekst badania; poprawne żądanie nie gwarantuje parsowalnego ani uzasadnionego wyniku.

### Zmienne

Używaj dokładnej wielkości liter i pojedynczych nawiasów klamrowych:

| Zadanie | Dostępne zmienne |
| ------ | ----------------------- |
| Generowanie z tytułu | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Podsumowanie badania | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Tłumaczenie | `{LANGUAGE}`, `{TEXT}` |
| Oryginalne fragmenty | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` stosuje politykę języka zadania. Linki i samodzielne pojęcia wysyłają tekst jako treść zadania; nie dopisuj wymyślonych zmiennych. Nieznane nazwy nie są podstawiane. To zmienne promptów, nie szablony plików pojęć.

### Domena tematyczna

Włącz naukę ukierunkowaną i podaj np. `elektrotechnika`. `Relevant Fields` kieruje uwagą, ale nie zapewnia twardego filtra ani dowodu wykluczenia treści.

## Ustawienia

| Zadanie | Przełącznik | Pole promptu |
| ------ | --------------- | -------------- |
| Linki | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Tytuły | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Badanie | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Podsumowanie Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Pojęcia | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Tłumaczenie | `useCustomPromptForTranslate` | `translatePrompt` |
| Tekst oryginalny | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Wszystkie wymagają `enableGlobalCustomPrompts`. Pusty tekst przywraca instrukcję wbudowaną. Scalona ekstrakcja oryginalnego tekstu ma własną stałą postać; zwykłe nadpisanie tam nie działa. Generowanie diagramów wymaga typowanego wyniku; prompt Mermaid nie jest uniwersalny.

## Przykład

Włącz przełącznik globalny i ekstrakcji pojęć, zachowując znacznik parsera:

```text
Wyodrębnij najważniejsze pojęcia elektrotechniczne z notatki.
Preferuj konkretne elementy i mechanizmy fizyczne zamiast ogólnych rzeczowników.
Zapisz każde pojęcie w osobnej linii dokładnie w tej postaci:
CONCEPT: Nazwa pojęcia
Nie dodawaj objaśnień ani otaczającego bloku kodu.
```

Na kopii porównaj linie, nazwy plików i pominięte pojęcia z ustawieniem domyślnym. Zachowaj poprzedni prompt do powrotu.

## Wskazówki

- Testuj jedno zadanie przed powiększeniem partii.
- Zachowuj źródła i dosłowne cytaty.
- Tłumacz instrukcje, zachowując ID oraz znaczniki wyników.
- Testuj po zmianie modelu; instrukcja nie zastępuje walidacji.
