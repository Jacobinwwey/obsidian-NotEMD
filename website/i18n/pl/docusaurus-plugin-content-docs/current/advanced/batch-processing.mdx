# Przetwarzanie wsadowe

<TLDR>Działania folderowe dzielą wybór i raportowanie postępu, ale nie zasady nadpisywania. Domyślna współbieżność to jeden. Zacznij w małym folderze testowym, sprawdź zakres i cele, potem zwiększ skalę.</TLDR>

## Przegląd

Panel/eksplorator oferuje folderowe linki, pojęcia, tytuły, tłumaczenia, fragmenty źródłowe oraz naprawy Mermaid i wzorów. Nie ma ogólnego badania folderu; można dodać badanie do generowania z tytułów. Partia nie jest transakcją folderu: gotowe wyniki pozostają po błędach i anulowaniu.

## Jak to działa

### Model wykonania

1. Wybierz zadanie i folder z właściwymi plikami.
2. Rozszerzenia, wybór i filtry wynikowe zadania określają kandydatów.
3. Zadanie używa własnego dostawcy/modelu i raportuje stan, błędy oraz ścieżki.
4. Sprawdź raport i pliki po zakończeniu/anulowaniu, przed ponowieniem.

Linki, pojęcia, tytuły, fragmenty oryginalne, Mermaid i wzory domyślnie obejmują podfoldery. **Tłumaczenie folderu domyślnie bierze tylko bezpośrednie dzieci.** Tryb deweloperski oraz zaawansowane profile wyboru mogą zmienić zakres i filtry. Sprawdź rzeczywiste dopasowania.

### Nadpisywanie

| Zadanie | Kontrola przed ponowieniem |
| ------ | ------------------------------------ |
| Linki | Domyślnie osobny wynik; sprawdź sufiks, folder i przeniesienie źródła |
| Pojęcia | Włączone linki zwrotne mogą uzupełnić istniejące notatki; duplikaty są osobną operacją |
| Generowanie z tytułów | Zapis odpowiednich źródeł i przeniesienie, jeśli cel complete jest wolny |
| Tłumaczenie | Istniejące tłumaczenie może zostać zastąpione; domyślnie `_<language>.md` |
| Mermaid / wzory | Zmienia wybrane notatki; sprawdź i wykonaj kopię |

Brak uniwersalnego przełącznika pomiń/dopisz/zastąp. Zajęty cel complete blokuje przeniesienie po generowaniu z tytułu, nie wcześniejsze generowanie. Wygenerowane i przeniesione liczone są osobno.

### Współbieżność

Zachowaj `batchConcurrency: 1`, aż próbka się powiedzie. Część tras wymaga również `enableBatchParallelism`; tłumaczenie folderu używa współbieżności bezpośrednio. Większa równoległość obciąża dostawcę, pamięć i lokalny serwer, nie gwarantując szybkości. Odstępy żądań/grup nie usuwają wszystkich limitów ani innego użycia konta.

## Ustawienia

| Ustawienie | Wartość początkowa | Działanie |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Żądana współbieżność odpowiednich tras |
| `enableBatchParallelism` | `false` | Włączenie obsługiwanego równoległego planowania |
| `batchSize` | `50` | Wielkość grupy w planowaniu partiami |
| `batchInterDelayMs` | `1000` | Przerwa między zaplanowanymi grupami |
| `apiCallIntervalMs` | `500` | Odstęp współbieżnych żądań API |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Zachowanie reguł podfolderów właściwych zadaniu |
| `enableStableApiCall` | `false` | Jawny stabilny tryb żądań |

### Modele zadań

Operacja folderu podąża za wyborem modelu odpowiedniego zadania plikowego. Sprawdź prywatne trasy danych. Lokalny kontekst w partii tytułów używa jednego obrazu ze startu; edycje w trakcie nie mieszają się z późniejszymi wyszukiwaniami. Uruchom nową partię, by je uwzględnić.

## Przykład

Utwórz `trial-titles` z dwiema notatkami tytułowymi. Uruchom **Generowanie wsadowe z tytułów** i sprawdź treść, sąsiedni `trial-titles_complete` oraz liczbę wygenerowanych/przeniesionych/błędów. Najpierw zbadaj nieudany plik. Ponowne uruchomienie folderu źródeł nie wznawia automatycznie dokładnie pozostałej pracy.

## Anulowanie i odzyskiwanie

Anulowanie zatrzymuje nowe planowanie i obsługiwane żądania. System zewnętrzny może dokończyć zaakceptowane wywołanie/zapis; dostawca rozlicza użycie. Poczekaj, porównaj gotowe pliki ze ścieżkami odzyskiwania/konfliktów i dopiero potem sprzątaj.

## Wskazówki

- Sprawdź faktyczny wybór plików profilu.
- Przy 429 ogranicz współbieżność i sprawdź kwoty.
- Oddzielaj anulowane, błędne i ukończone.
- Zachowaj niezmienioną próbkę i kopię zapasową.
