# Konfiguracja

<TLDR>Otwórz Settings → Notemd i wyszukaj pole. Wybierz dostawcę i miejsce wyników przed uruchomieniem zadania. Sprawdź zmianę na jednej notatce; trwające zadanie może zachować ustawienia z chwili startu.</TLDR>

## Przegląd

Początkowym dostawcą jest DeepSeek bez danych uwierzytelniających. Wybranie profilu nie tworzy konta, nie instaluje modelu ani nie daje uprawnień. Zobacz [dostawców](../providers/overview).

## Wyszukiwanie i ulubione

**Search settings** przeszukuje nazwy, opisy, aliasy i widoczne kategorie, a następnie prowadzi do pola. **★ Favorites** pokazuje zapisane ustawienia z opisem, kategorią i miejscem docelowym. Są przechowywane dla skarbca, przetrwają restart i usuwają stare ID. Zapytanie pozostaje po zwinięciu paska. Lista ulubionych i filtr wyszukiwania tylko w ulubionych to osobne funkcje.

**Diagram preview export PPI** zaczyna od 300, zakres 72–600, i wpływa wyłącznie na PNG. SVG/PDF zachowują obsługiwaną geometrię wektorową. **Also export complete Mermaid visuals** steruje plikami towarzyszącymi, nie widocznością Mermaid w podglądzie Drawnix.

## 1. Dostawca

Podaj endpoint właściwego protokołu, potrzebny klucz i dostępny model. Lista modeli i udane generowanie są odrębnymi testami. Przygotuj lokalny serwer/model; chmura i gateway otrzymują treść. Sprawdź też trasy poszczególnych zadań przed użyciem prywatnych danych.

## 2. Modele dla zadań

`useMultiModelSettings` pozwala ustawić osobnych dostawców/modele dla linków, tytułów, badania, tłumaczenia, pojęć, oryginalnego tekstu i Mermaid. Puste nadpisanie używa modelu dostawcy; wyłączenie używa aktywnego dostawcy. Porównuj dokładność, opóźnienie i realny koszt na tym samym materiale.

## 3. Wyniki

| Zadanie | Wynik domyślny |
| ------ | ------------------------- |
| Dodawanie linków | Osobny `_processed.md` obok źródła; przenoszenie oryginału wyłączone |
| Samodzielne wyodrębnianie pojęć | Wybrany folder pojęć; tylko tytuł, linki zwrotne wyłączone |
| Tłumaczenie | Obok jako `_<language>.md`; istniejący cel może zostać zastąpiony |
| Badanie | Podsumowanie dopisywane do aktywnego Markdown |
| Generowanie wsadowe z tytułów | Zapis odpowiednich źródeł, potem przeniesienie do sąsiedniego `<folder>_complete`, jeśli cel pozwala |
| Podgląd/eksport diagramów | Wybór obsługiwanego źródła lub eksportu wizualnego; kontrola raportowanej ścieżki |

Folder pojęć jest początkowo pusty; `concepts` to przykład. Samodzielne notatki mają formę minimalną/pełną, bez ogólnego silnika szablonów. [Pojęcia](../features/concept-notes). Przetwarzanie i tłumaczenie mają oddzielne sufiksy oraz foldery. Sprawdź cele i konflikty odzyskiwania; anulowanie nie cofa ukończonych zapisów.

## 4. Języki

UI ma 21 wersji językowych, witryna 34 trasy językowe. `uiLocale: auto` wybiera obsługiwane mapowanie, w przeciwnym razie angielski. Język generowania jest osobny, początkowo angielski. Obsługiwane zadania mogą mieć własny język; tłumaczenie używa `language`. Liczby nie dowodzą umiejętności językowych modelu.

## 5. Wyszukiwanie

Wybierz jawnie Tavily z kluczem lub DuckDuckGo. Pusty klucz Tavily nie przełącza usługi. Obie używają sieci; DuckDuckGo może pobierać strony wynikowe. Badanie w generowaniu z tytułu jest wyłączone: `enableResearchInGenerateContent`. Pobieranie lokalne również jest wyłączone, z osobnymi zakresami folderów/zadań. Lokalne fragmenty kontekstu trafiają do wybranego LLM.

## 6. Przepływy pracy

Użyj kreatora albo jednej nazwanej linii DSL na przycisk:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` oddziela nazwę od działań, `>` oddziela ID działań. Domyślna polityka zatrzymuje się przy zgłoszonym błędzie. Zobacz [przepływy](../features/workflows): zakres i konsekwencje kontynuowania mimo błędu.

## 7. Ustawienia zaawansowane

| Ustawienie | Wartość początkowa | Działanie |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Dostawca bez osobnej trasy zadania |
| `useMultiModelSettings` | `false` | Dostawca/model dla zadania |
| `useCustomConceptNoteFolder` | `true` | Zezwolenie na wyniki pojęciowe po wybraniu folderu |
| `conceptNoteFolder` | `''` | Początkowo brak folderu pojęć |
| `extractConceptsMinimalTemplate` | `true` | Tylko tytuł w samodzielnych pojęciach |
| `extractConceptsAddBacklink` | `false` | Linki zwrotne w samodzielnej ekstrakcji |
| `moveOriginalFileOnProcess` | `false` | Zachowanie oryginału przy linkowaniu |
| `chunkWordCount` | `3000` | Przybliżone części tekstu, nie limit tokenów |
| `batchConcurrency` | `1` | Domyślna współbieżność partii |
| `enableBatchParallelism` | `false` | Równoległe planowanie na trasach używających przełącznika |
| `enableStableApiCall` | `false` | Jawnie wybierany stabilny tryb żądań |
| `customWorkflowErrorStrategy` | `stop_on_error` | Zatrzymanie przepływu przy zgłoszonym błędzie |

Rozmiar części tekstu i budżet tokenów odpowiedzi są różne. Mniejsze części nie rozwiązują wszystkich limitów kontekstu, a niska współbieżność nie zapobiega każdemu 429.

## Profile ustawień

Ustawienia są danymi wtyczki w skarbcu. Wykonaj kopię przed zmianą. Eksport dostawców ma własny kontrakt maskowania danych, nie stanowi pełnego backupu skarbca. Sprawdź adresy i metadane także w zamaskowanym wyniku. Nie publikuj surowych ustawień ani diagnostyki z prywatnymi notatkami.

## Problemy z konfiguracją

Przetestuj dokładnego dostawcę/model na krótkiej notatce. Gdy pola brak, sprawdź wyszukiwanie, kategorię, widoczność w trybie deweloperskim i skarbiec. Zgłoś wersję oraz minimalne ustawienia bez sekretów.
