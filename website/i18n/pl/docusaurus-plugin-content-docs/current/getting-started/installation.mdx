# Instalacja

<TLDR>Zainstaluj Notemd przez Community plugins albo umieść trzy pliki wykonawcze z tego samego wydania GitHub w skarbcu (vault). Włącz wtyczkę, wybierz dostawcę i przetestuj notatkę. Serwery modeli oraz opcjonalne narzędzia eksportu natywnego przygotowuje się osobno.</TLDR>

## Metoda 1: Community plugins, zalecana

1. W docelowym skarbcu otwórz **Settings → Community plugins**.
2. W razie potrzeby zezwól na wtyczki społeczności i wybierz **Browse**.
3. Wyszukaj **Notemd**, sprawdź `Jacobinwwey/obsidian-NotEMD` i wybierz **Install**.
4. Wybierz **Enable** i otwórz panel boczny z paska narzędzi lub palety poleceń.

[Otwórz Notemd w Obsidianie](obsidian://show-plugin?id=notemd). Jeśli przeglądarka nie obsługuje odnośnika, użyj powyższego menu. Czytanie dokumentacji nie wymaga obsługi tego protokołu.

## Metoda 2: Instalacja ręczna

### Wymagania

Potrzebujesz Obsidiana i skarbca, którego kopię zapasową możesz wykonać. Minimum `0.15.0` w manifeście jest deklaracją, a nie dowodem świeżych testów na tej wersji.

### Kroki

1. Pobierz `main.js`, `manifest.json` i `styles.css` z tego samego [wydania GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` jest instrukcją, nie wymaganym plikiem wykonawczym.
2. Umieść trzy pliki w `<vault>/.obsidian/plugins/notemd/`. Uwzględnij rzeczywisty katalog konfiguracji, jeżeli go zmieniono.
3. Uruchom ponownie Obsidiana i włącz wtyczkę.
4. Sprawdź wersję; nie łącz nowego manifestu ze starym pakietem.

## Alternatywa: BRAT

Jeśli używasz już [BRAT](https://github.com/TfTHacker/obsidian42-brat), dodaj repozytorium jego procedurą instalacji wtyczek beta. Do odtwarzania błędów wybierz konkretne wydanie. BRAT jest opcjonalnym narzędziem zewnętrznym.

## Weryfikacja

Skonfiguruj dostępny model, uruchom **Testuj połączenie**, a potem [szybki start](./quick-start). Lista modeli nie dowodzi uprawnień do generowania; sprawdź rzeczywisty plik wynikowy.

## Granice systemowe

| Element | Granica |
| --------- | ---------- |
| Manifest | Minimum Obsidian `0.15.0`; `isDesktopOnly` ma wartość false |
| Dowody testowe | Patrz datowane raporty; fizyczne urządzenia mobilne i 0.15.0 nie mają aktualnej weryfikacji |
| Model chmurowy | Sieć, uprawnione konto/klucz i dostępny model |
| Model lokalny | Osobno zainstalowany aktywny serwer oraz pobrany/załadowany model |
| Natywny eksport slajdów lub obwodów | Narzędzia desktopowe i zależności formatu; najpierw sprawdź środowisko |

Nie ma wspólnej gwarancji wersji systemu dla wszystkich eksporterów. Podgląd obwodu nie dowodzi kompilacji TeX, a test desktopowy nie potwierdza działania na telefonie.

## Odinstalowanie

Wyłącz lub odinstaluj przez Community plugins. Utworzone notatki i artefakty pozostają zwykłymi plikami skarbca. Przejrzyj je przed usunięciem i zachowaj ustawienia, jeśli będą potrzebne. Odinstalowanie nie cofa wykonanych zmian.

## Aktualizacja

Użyj **Check for updates**. Ręcznie: zatrzymaj zadania, wykonaj kopię skarbca i ustawień, wymień trzy pliki wykonawcze z jednego wydania i przeładuj aplikację. Przeczytaj opis wydania i wykonaj mały test przed pracą wsadową. Nie zastępuj pliku ustawień zasobem wydania. Powrót wymaga świadomie wybranej zgodnej wersji i kopii zapasowej.
