# Szybki start

<TLDR>Zacznij od testowej notatki Markdown i dostawcy, do którego masz dostęp. Sprawdź plik wynikowy przed przetwarzaniem folderu. Zadania chmurowe wysyłają treść; modele lokalne także wymagają działającego serwera i przygotowanego modelu.</TLDR>

## 1. Skonfiguruj model

1. [Zainstaluj i włącz](./installation), otwórz **Settings → Notemd**.
2. Wybierz profil, endpoint, wymagane dane uwierzytelniające i dostępny model. **Fetch models** nie zastępuje testu generowania.
3. Uruchom **Testuj połączenie** i usuń problemy z kontem, modelem lub adresem.
4. Znajdź **Ścieżka folderu notatek pojęciowych** i wybierz osobny folder, np. `concepts`. Wartość początkowa jest pusta; ta nazwa jest Twoim wyborem.

Najpierw pobierz model Ollama i podaj jego dokładną nazwę; domyślny adres to `http://localhost:11434/api`. Uruchom serwer LM Studio i wybierz `LMStudio`. Zobacz [modele lokalne](../providers/local). Badanie internetu potrzebuje sieci również z lokalnym modelem podsumowującym.

## 2. Pierwsze zadanie

W `Notemd trial.md` zapisz krótki tekst, który wolno wysłać dostawcy:

```text
Uczenie maszynowe wykorzystuje sieci neuronowe do rozpoznawania wzorców.
```

Uruchom **Przetwórz plik (dodaj linki)** z panelu lub palety. Zwykle oryginał pozostaje, a obok powstaje `Notemd trial_processed.md`. Otwórz wynik. Możliwy przykład:

```markdown
[[Uczenie maszynowe]] wykorzystuje [[sieci neuronowe]] do rozpoznawania wzorców.
```

Notatki mogą powstać także w wybranym folderze pojęć. Sprawdź pliki i linki; model nie gwarantuje kompletnej ani poprawnej listy pojęć.

## 3. Inne funkcje

### Wyodrębnianie pojęć

**Wyodrębnij pojęcia (bieżący plik)** nie zmienia źródła i wymaga folderu pojęć. Nowe samodzielne notatki zawierają początkowo tylko tytuł, bez linku zwrotnego. Włącz go jawnie, jeśli jest potrzebny. [Notatki pojęciowe](../features/concept-notes).

### Badanie i podsumowanie

Zaznacz temat w edytorze Markdown albo użyj tytułu i uruchom **Badanie i podsumowanie**. Jawnie wybierz Tavily z kluczem lub DuckDuckGo. Podsumowanie zostanie dopisane do aktywnej notatki. Otwórz źródła i sprawdź twierdzenia.

### Przepływ jednym kliknięciem

Domyślny **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Dodaje linki, uzupełnia odpowiednie notatki z tytułów w folderze pojęć/wybranym folderze i naprawia Mermaid w folderze complete. Może objąć istniejące notatki. Zacznij od folderu testowego. Badanie internetu i ogólne generowanie diagramów nie są dodawane automatycznie.

## Anulowanie i kontrola

**Anuluj** zatrzymuje obsługiwaną dalszą pracę. Gotowe wyniki pozostają; nie jest to transakcja cofająca zmiany ani gwarancja zatrzymania pracy lub rozliczeń po stronie dostawcy. Poczekaj na zakończenie, sprawdź ścieżki i konflikty odzyskiwania przed ponowieniem.

## Problemy

- Konto/model: sprawdź profil i połączenie.
- Brak pojęć: ustaw aktywną, niepustą ścieżkę folderu.
- Brak przydatnych linków: sprawdź odpowiedź i prompt; minimalna długość tekstu niczego nie gwarantuje.
- Limity: zachowaj współbieżność `1`, sprawdzając kwoty.
