# Batchbehandling

<TLDR>Mappehandlinger deler utvalg og framdriftsvisning, men ikke overskrivingsregler. Standard samtidighet er én. Begynn i en liten testmappe, kontroller omfang og mål, og utvid etterpå.</TLDR>

## Oversikt

Sidepanel/filutforsker har mappehandlinger for lenker, begreper, titler, oversettelse, originalpassasjer, Mermaid og formler. Ingen generell undersøkelseshandling for mapper finnes; tittelgenerering kan legge til undersøkelser. En batch er ingen mappetransaksjon: fullførte resultater beholdes ved feil/avbrudd.

## Slik fungerer det

### Kjøremodell

1. Velg oppgave og mappe med ønskede filer.
2. Filtyper, utvalg og oppgavespesifikke resultatfiltre bestemmer kandidatene.
3. Oppgaven bruker sin modell/leverandør og viser status, feil og stier.
4. Kontroller rapport og resultater etter fullføring eller avbrudd, før ny kjøring.

Lenker, begreper, titler, originalpassasjer, Mermaid og formler tar vanligvis med undermapper. **Mappeoversettelse tar som standard bare direkte barn.** Utviklermodus og avanserte utvalgsprofiler kan endre omfang og filtre. Se faktiske treff.

### Overskriving

| Oppgave | Kontroll før ny kjøring |
| ------ | ------------------------------------ |
| Lenker | Separat standardresultat; se eget suffiks, mappe og kildeflytting |
| Begreper | Aktive tilbakekoblinger kan supplere eksisterende notater; duplikater håndteres separat |
| Tittelgenerering | Skriver egnede kilder og flytter hvis complete-målet er ledig |
| Oversettelse | Eksisterende oversettelse kan erstattes; normalt `_<language>.md` |
| Mermaid / formler | Endrer valgte notater; gjennomgå og ta backup |

Ingen felles hopp over/legg til/erstatt-innstilling. Et opptatt complete-mål stopper flytting etter tittelgenerering, ikke genereringen selv. Generert og flyttet telles separat.

### Samtidighet

Behold `batchConcurrency: 1` til en prøve lykkes. Noen ruter krever også `enableBatchParallelism`; mappeoversettelse bruker samtidigheten direkte. Mer parallellitet belaster leverandør, minne og lokal server uten fartsgaranti. Mellomrom mellom forespørsler/grupper hindrer ikke alle kvoter eller annen kontobruk.

## Innstillinger

| Innstilling | Startverdi | Virkning |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Ønsket samtidighet på relevante ruter |
| `enableBatchParallelism` | `false` | Aktiver støttet parallell planlegging |
| `batchSize` | `50` | Gruppestørrelse i gruppevis planlegging |
| `batchInterDelayMs` | `1000` | Pause mellom planlagte grupper |
| `apiCallIntervalMs` | `500` | Intervall mellom samtidige API-forespørsler |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Behold hver oppgaves undermapperegler |
| `enableStableApiCall` | `false` | Eksplisitt stabil forespørselsmodus |

### Oppgavemodeller

Mappehandlingene følger den tilsvarende filoppgavens modellvalg. Kontroller private dataruter. Lokal kontekst ved batchtitler bruker ett startsnapshot; redigering under kjøring blandes ikke inn i senere oppslag. Start en ny batch for å ta med endringene.

## Eksempel

Opprett `trial-titles` med to tittelnotater. Kjør **Batch generate from titles** og se innhold, tilstøtende `trial-titles_complete` og antall generert/flyttet/feil. Undersøk den mislykkede filen først. Ny kjøring av kildemappen gjenopptar ikke automatisk bare gjenstående arbeid.

## Avbrudd og gjenoppretting

Avbrudd stopper ny planlegging og støttede forespørsler. Eksterne systemer kan fullføre aksepterte kall/skrivninger; leverandøren styrer fakturering. Vent, sammenlign ferdige filer med gjenopprettings-/konfliktstier, og rydd etter gjennomgang.

## Tips

- Kontroller profilens faktiske utvalg.
- Senk samtidighet og undersøk kvoter ved 429.
- Skill avbrutt, mislykket og fullført.
- Bevar uendret prøve og sikkerhetskopi.
