# Egne instruksjoner

<TLDR>En ikke-tom egendefinert instruksjon erstatter standarden når både global og oppgavespesifikk bryter er på. Bevar resultatkontrakten: malsystemet legger ikke automatisk tilbake formatkrav du utelater.</TLDR>

## Oversikt

Test standarden på et representativt notat først. Et fagområde eller synonymkrav kan være nok. Endre struktur, policy eller oversettelsesstil ved behov og sammenlign før batchkjøring.

## Slik fungerer det

### Sammensetting

Notemd velger standard/egen instruksjon, legger til relevante fagområde-/språkkrav og fyller oppgavens variabler. Notattekst kan sendes separat. Variabler gjelder ikke universelt. En erstatning kan utelate `CONCEPT:` eller undersøkelseskontekst; gyldig kall beviser ikke parsebart eller underbygd resultat.

### Variabler

Bruk nøyaktig store/små bokstaver og enkle klammeparenteser:

| Oppgave | Tilgjengelige variabler |
| ------ | ----------------------- |
| Tittelgenerering | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Undersøkelsesoppsummering | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Oversettelse | `{LANGUAGE}`, `{TEXT}` |
| Originalpassasjer | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` følger språkpolicyen til oppgaven. Lenker og selvstendig begrepsuttrekk sender teksten som oppgaveinnhold; ikke finn på ekstra plassholdere. Ukjente navn fylles ikke inn. Dette er instruksjonsvariabler, ikke maler for begrepsfiler.

### Avgrenset fagområde

Aktiver fokusert læring og angi for eksempel `elektroteknikk`. `Relevant Fields` styrer oppmerksomhet uten et hardt filter eller bevis på utelatelse.

## Innstillinger

| Oppgave | Bryter | Instruksjonsfelt |
| ------ | --------------- | -------------- |
| Lenker | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titler | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Undersøkelser | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid-oppsummering | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Begreper | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Oversettelse | `useCustomPromptForTranslate` | `translatePrompt` |
| Originaltekst | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Alle krever `enableGlobalCustomPrompts`. Tom tekst bruker innebygd instruksjon. Sammenslått originaltekstuttrekk har eget fast format, der vanlig overstyring ikke gjelder. Diagramgenerering krever typet resultat; Mermaid-instruksjonen er ikke generell.

## Eksempel

Aktiver global og begrepsspesifikk bryter og behold parsermarkøren:

```text
Hent de viktigste elektrotekniske begrepene fra notatet.
Prioriter konkrete komponenter og fysiske mekanismer fremfor generelle substantiver.
Skriv ett begrep per linje i nøyaktig denne formen:
CONCEPT: Begrepets navn
Ikke legg til forklaringer eller omsluttende kodeblokk.
```

Sammenlign linjer, filnavn og manglende begreper med standarden på en kopi. Behold forrige instruksjon for tilbakerulling.

## Tips

- Test én oppgave før større batch.
- Bevar kilder og ordrette sitater.
- Oversett instruksjoner med uendrede ID-er og markører.
- Test etter modellbytte; instruksjoner er ingen valideringsgaranti.
