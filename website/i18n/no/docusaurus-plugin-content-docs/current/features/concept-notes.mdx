# Begrepsnotater

<TLDR>Selvstendig uttrekk leser kilden og oppretter Markdown-begreper i valgt mappe. Ingen mappe er satt fra start. Nye notater har bare tittel og ingen tilbakekobling. Lenking bruker en annen begrepsform.</TLDR>

## Oversikt

Velg **Concept note folder path** først. En separat mappe gjør resultater, duplikater og senere tittelgenerering lettere å kontrollere. Uttrekk fyller ikke filene automatisk med undersøkte forklaringer.

## Slik fungerer det

### Uttrekk

Valgt LLM mottar tekst; oppgaven leser `CONCEPT:`-linjer, fjerner gjentatte navn innenfor kjøringen og oppretter/oppdaterer filer. Lange notater deles. Kontroller mislykkede deler; et modellsvar er ingen fullstendig begrepsoversikt.

### Instruksjon for uttrekk

Standarden ber om konkrete, relevante begreper. Fagområde-/synonyminstruksjoner sikrer ikke kanonisk ordforråd. Behold `CONCEPT: Term` i egne instruksjoner. Se [instruksjoner](../advanced/custom-prompts).

### Tekstbiter

`chunkWordCount` begynner på omtrent 3000 ord og er ikke leverandørens tokenbudsjett. Kontekst over bitgrenser er begrenset; se relasjoner og tvetydige navn.

## Opprette filer

### Navneregler

Ugyldige stitegn fjernes, mellomrom normaliseres og lange navn kortes; tomme resultater hoppes over. Ulike termer kan ende på samme sti. Kontroller navn før masseoppretting.

### Maler

Minimal ny form:

```markdown
# Begrepsnavn
```

For tilbakekobling i nye selvstendige filer: slå **Add "Linked From" backlink** på og **Create minimal concept notes** av:

```markdown
# Begrepsnavn

## Linked From
- [[Kildenotat]]
```

Lenking lager full form med kildereferanse når begrepsresultater er aktivert. Brytere for selvstendig uttrekk endrer ikke denne ruten.

### Eksisterende notater

Med tilbakekoblinger på kan manglende kilde legges til under `## Linked From`. Eksisterende tekst bevares og samme lenke gjentas ikke. Kildens basename kan være tvetydig mellom mapper.

### Innstillinger

| Innstilling | Startverdi | Virkning |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Begrepsresultater etter mappevalg |
| `conceptNoteFolder` | `''` | Ingen mappe valgt |
| `extractConceptsMinimalTemplate` | `true` | Bare tittel i selvstendige begreper |
| `extractConceptsAddBacklink` | `false` | Tilbakekoblinger ved selvstendig uttrekk |
| `extractConceptsProvider` | `DeepSeek` | Leverandør med oppgaveruting |
| `extractConceptsModel` | `''` | Tomt bruker leverandørens modell |
| `extractConceptsLanguage` | `en` | Språk med oppgavespesifikke språk |
| `replaceSynonymsDuringConceptExtraction` | `false` | Instruksjon mot synonymer |
| `generateConceptLogFile` | `false` | Valgfri begrepslogg |

## Duplikater

Kontrollen bruker filnavnheuristikk: store/små bokstaver, flertall, symbolnormalisering og der tillatt ett ord inne i et annet navn. Dette beviser ikke samme betydning. Se uregelmessige former og tekniske forskjeller i **Check & remove duplicates**, og bekreft bare tilsiktet sletting. Obsidian styrer papirkurven. Begrepsmappen er ikke en engangscache; ta backup.

### Sammenligningsomfang

Sammenlign med hvelvet, begrepsmappen, inkluderte mapper eller et omfang med utelatelser. Omfang endrer kandidater, ikke hva et duplikat betyr.

## Bruk

### Selvstendig uttrekk

Åpne Markdown, kontroller mappe og velg **Extract concepts (current file)**. Kilden beholdes. Se navn, dekning og tilbakekoblinger.

### Uttrekk og innhold

**Batch generate from titles** fyller begrepsnotater, men kan inkludere eldre egnede filer. Se mappen først og rapportert complete-mappe etterpå.

### Lenke fra markering

Markeringshandlingen lager wiki-lenke for termen du velger, og kan opprette begrepsfil dersom målet er konfigurert.

## Tips

- Liten kilde og separat mappe.
- Velg språk før masseoppretting.
- Vurder synonymer og duplikater separat.
- Bevar nødvendige logger før neste kjøring erstatter dem.
