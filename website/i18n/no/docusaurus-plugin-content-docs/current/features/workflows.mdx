# Arbeidsflyter

<TLDR>En arbeidsflyt kjører sidepanelhandlinger etter hverandre. En handling kan kreve mappevalg eller aktiv editor. Dette er ikke en tekstpipeline: hvert trinn har egne inndata, resultater og sideeffekter. Begynn med testnotat og separat mappe.</TLDR>

## Oversikt

Medfølgende **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Legg lenker til aktivt notat og opprett begreper hvis mappe er valgt.
2. Generer innhold fra titler for egnede notater i begreps-/valgt mappe, også eksisterende.
3. Reparer Mermaid i genereringens complete-mappe.

Standardkjeden gjør ikke nettundersøkelser. Tittelgenerering kan legge det til med separat innstilling. Se [batcher](../advanced/batch-processing).

## Slik fungerer det

### Kjøring

Trinn kjører sekvensielt; sidepanelet viser aktivt trinn og feil. Avbrudd stopper kommende trinn og når støttede forespørsler. Ferdige filer blir liggende; kjeden er ingen transaksjon. Begrepsmappen er første mappevalg. Batchgenerering husker kilde-/complete-mappe og Mermaid bruker complete. Andre handlinger beholder krav til fil, markering og interaksjon.

### DSL

Én navngitt knapp per linje. `::` skiller navn fra handlinger, `>` skiller handlings-ID-er. Tomme linjer og linjer som starter med `#` ignoreres; ukjente ID-er avvises.

```text
Hent ut og tegn::extract-concepts-current>summarize-as-mermaid
```

Bruk byggeren eller rediger DSL. ID-er er stabile; etiketter følger UI-språket. Mappevarianter har egne ID-er og utledes ikke med vilkårlig teksterstatning.

| ID | Handling / krav |
| ------------ | ----------------------- |
| `process-current-add-links` | Lenker i aktivt notat |
| `process-folder-add-links` | Lenker i valgt mappe |
| `extract-concepts-current` | Begreper fra aktivt notat |
| `extract-concepts-folder` | Begreper fra valgt mappe |
| `generate-from-title` | Innhold fra aktiv tittel |
| `batch-generate-from-titles` | Innhold for egnede mappenotater |
| `research-and-summarize` | Undersøk markering/tittel i åpen Markdown-editor |
| `summarize-as-mermaid` | Oppsummer støttet aktivt innhold som Mermaid |
| `generate-diagram` | Velg flere diagramtyper i samme kjøring og flere utdataformater for hver type. Når du fjerner avkrysningen, beholdes typens formater. Uten valgte typer analyseres innholdet automatisk. |
| `preview-diagram` | Forhåndsvis støttet kilde eller diagram |
| `translate-current-file` | Oversett aktiv støttet fil |
| `batch-translate-folder` | Oversett valgt mappe |
| `extract-original-text` | Hent etterspurte originalpassasjer |
| `batch-extract-original-text` | Passasjer fra egnede mappefiler |
| `split-note-by-chapters` | Del aktivt notat i kapitler |
| `batch-mermaid-fix` | Reparer Mermaid-kodeblokker i valgt mappe |
| `fix-formula-current` | Normaliser formelavgrensere i aktivt notat |
| `batch-fix-formula` | Normaliser formelavgrensere i mappe |
| `check-duplicates-current` | Se etter duplikater i aktivt notat |
| `check-remove-duplicate-concepts` | Gjennomgå og fjern begrepsduplikater interaktivt |
| `test-llm-connection` | Test konfigurert leverandør |
| `probe-slide-export-env` | Kontroller lokalt lysbildeeksportmiljø |
| `export-slides` | Eksporter aktiv fil til lysbilder |

### Standard eller egen kjede

One-Click Extract er forhåndsdefinert. Andre knapper velger du selv: navn og rekkefølge. Se verktøytipset i sidepanelet og rett parserfeil før kjøring.

## Innstillinger

| Innstilling | Startverdi | Virkning |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stopp ved første rapporterte trinnfeil |
| `useMultiModelSettings` | `false` | Aktiv leverandør inntil oppgaveruting aktiveres |
| `enableResearchInGenerateContent` | `false` | Ingen undersøkelser ved tittelgenerering før aktivering |

`continue_on_error` tillater videre kjøring etter feil. Bruk bare når senere handlinger kan håndtere resterende inndata. Fortsettelse gjør ikke en delvis arbeidsflyt vellykket.

### Modell per trinn

Modellvalget tilhører oppgaven. Tom overstyring bruker den valgte leverandørens modell. Kontroller alle ruter før privat materiale.

## Eksempel

Velg tom `trial-concepts` og et engangsnotat. Se begrepene og rapportert complete-mappe. Kjør trinnene separat hvis målene er uklare. Utvid omfang etter kontroll.

## Tips

- Hold kjeder oversiktlige slik at feil og filenes opphav kan spores.
- Sletting beholder interaktiv bekreftelse; unngå det i uovervåkede kjeder.
- Se logger og filer etter avbrudd eller gjenopprettingskonflikt.
- Test nøyaktig modell/mappe; forbindelsestest beviser ikke kvoter til lang batch.
