# 图表

<TLDR>
先选择**您需要的图表类型**，再挑选其**可编辑的源文件格式**。在 Obsidian 中预览完整的最终效果，其中包含 Drawnix 平板以及嵌入其中的 Mermaid 可视化内容，并可将每个面板导出为 SVG、PNG 或 PDF 格式。
</TLDR>

## 了解三种可选方案

| 选项 | 控制的内容 | 示例 |
|---|---|---|
| 图表类型 | 图表的含义 | 流程图、时序图、电路图、数据图表 |
| 源文件格式 | Notemd 生成的可供编辑或重复使用的文件 | Mermaid、JSON Canvas、Draw.io、Drawnix、CircuitikZ |
| 导出格式 | 用于分享的图像或文档格式 | SVG、PNG、PDF |

Draw.io 和 Drawnix 属于**源文件格式**，而非图表类型。CircuitikZ 是专为电路图设计的源文件格式。同一个预览内容可以导出为多种可视化格式，因此选择 CircuitikZ 并不会限制您只能得到 SVG 格式。

## 选择源文件格式

| 格式 | 最适合的场景 | 源文件 |
|---|---|---|
| Mermaid | 直接保存在 Markdown 中的图表 | Mermaid 代码块 |
| JSON Canvas | 基于 Obsidian 原生画布的工作流程 | `.canvas` |
| Draw.io | 后续在 diagrams.net 或兼容工具中进行编辑 | `.drawio` |
| Drawnix | 手绘或白板风格的编辑 | `.drawnix` |
| CircuitikZ | 结构化的电气及晶体管电路 | `.tex` |

如果您不需要特定的编辑器，可将**首选源文件格式**设置为**自动选择**。Notemd 会针对所选的图表类型自动挑选兼容的格式。

## 生成并导出图表

1. 打开笔记或选中您希望可视化的文本。
2. 在 Notemd 侧边栏或命令面板中选择**生成图表**。
3. 选择一个**图表类型**，或者保持为**自动检测**。
4. 选择一个**源文件格式**，或者保持为**自动选择**。如果您想要包含可编辑节点及嵌入 Mermaid 可视化内容的知识图谱，请选择**Drawnix**。
5. 查看预览效果。多面板的结果会将 Drawnix 平板以及按原始顺序排列的所有 Mermaid 面板整合在一个垂直滚动的预览窗口中；Mermaid 面板会使用其实际渲染后的高度，而不会被裁剪。
6. 为单个可视化内容选择面板的**导出 SVG**、**导出 PNG**或**导出 PDF**操作，或者为所有面板执行顶层图像导出。对于多个面板，可选择源文件所在文件夹或 Vault 相对路径下的自定义文件夹；Notemd 会为每个面板生成一个确定的文件，并在某个单独的导出失败后继续处理后续面板。
7. 如果您还需要可编辑的原始文件，请使用**保存源文件**功能。

“导出”菜单提供了针对当前可视化预览的**导出 SVG**、**导出 PNG**和**导出 PDF**操作。每个面板标题也提供了相同的操作选项，用于单独的 Mermaid 或 Drawnix 可视化内容，因此无需将大型预览整体作为一张不透明的图像进行导出。

在预览界面中选择**历史记录**，即可在不隐藏图表的情况下打开 Vault 历史记录抽屉。您可以搜索和筛选已完成的图表、重新打开某个预览，或查看已保存的原始文件。即使没有激活任何笔记，也可以直接通过命令面板和 Notemd 侧边栏访问图表历史记录。

SVG 和 PDF 是基于矢量几何图形生成的；PDF 使用与 SVG 相同的布局和文本度量标准，而非对整个预览进行光栅化处理。Notemd 设置中的图像导出 PPI 仅控制 PNG 的光栅化程度（范围为 72-600 PPI，默认值为 300）。

## 包含嵌入 Mermaid 的 Drawnix 预览

当 Drawnix 原始文件中包含 Mermaid 可视化内容时，Notemd 会对渲染后的 SVG 进行净化处理，并将对应的 Mermaid 源代码保留在 `.drawnix` 元数据中。因此，预览界面能够在 Drawnix 知识图谱中直接显示 Mermaid 图像，而无需依赖 Drawnix 或 Plait 运行时环境。那些被安全嵌入的纯 Mermaid 可视化内容不会生成单独的 `.assets` 目录；而对于外部二进制媒体或尚未解析完成的可视化内容，则会保留配套文件，从而避免数据丢失。

该预览界面刻意设计为单一的可滚动区域：首先显示主要的 Drawnix 画布，随后按原始顺序依次呈现每个嵌入的 Mermaid 面板。关闭并重新打开已保存的历史记录条目时，面板的列表、尺寸以及导出选项都会保持不变。

## 电路图

对于支持的电路相关需求，请选择**电路图**并使用**CircuitikZ 源文件**。Notemd 会先生成结构化的电路描述，然后再编写 CircuitikZ 源代码。这种方式比让模型直接编写不受限制的 LaTeX 代码更为可靠。

目前对 CircuitikZ 的支持是有意限定的。基于通用源码的 NMOS 放大器以及部分受支持的 CMOS 构件效果最佳。在将生成的电路用于技术文档或出版物之前，务必仔细检查预览效果及源代码。

SVG 预览是由 Notemd 生成、用于辅助审阅的工具。它并不能证明本地安装的 LaTeX 或 TikZJax 已成功编译了对应的 `.tex` 文件。

**可选的原生编译功能**。对于插件内的预览显示，以及 SVG、PNG 和预览 PDF 的导出功能，您并不需要使用 LaTeX。在桌面端，当您需要查看编译诊断信息或生成原生 LaTeX PDF 时，可以通过图表设置或命令面板打开**CircuitikZ 原生编译环境**。Notemd 可以复用系统自带的 `tectonic` 或 `pdflatex` 工具，也可以使用自定义的可执行文件；如果您明确选择**安装**选项，它还会自动安装已固定的管理型 Tectonic 运行时环境。环境面板会实时显示处理进度和错误信息，同时允许您日后移除该管理型运行时。

## 故障排除

### 生成的图表类型有误

请直接手动选择图表类型，而不要依赖“自动检测”功能。对于电路图，请选择**电路图**，并使用**生成图表**命令，而非旧版的**总结为 Mermaid 图表**命令。

### 源文件格式不合适

将源文件格式恢复为**自动选择**，或者挑选适合该图表类型的格式。CircuitikZ 仅适用于电路图；Draw.io 和 Drawnix 则适用于特定类型的结构化图表。

### 缺少“导出”菜单

SVG、PNG 和 PDF 格式的导出需要先有可视化预览。如果只有源文本可用，请先将源文件保存下来，再在对应的外部工具中打开处理。

### CircuitikZ 文件无法在外部环境中编译

请打开**CircuitikZ 原生编译环境**并运行环境检测功能。修复管理型运行时问题，或确认您的自定义/系统级编译器能够获取 `circuitikz` 包。Notemd 并未在插件文件中内置完整的 TeX 分发包。
