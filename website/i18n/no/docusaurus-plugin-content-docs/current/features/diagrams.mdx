# Diagrammer

<TLDR>
Velg flere diagramtyper i samme kjøring og flere utdataformater for hver type. Når du fjerner avkrysningen, beholdes typens formater. Uten valgte typer analyseres innholdet automatisk.
</TLDR>

## Tre forskjellige valg

| Valg | Bestemmer | Eksempler |
| --- | --- | --- |
| Diagramtype | Hva diagrammet betyr | Flyt, sekvens, krets, graf |
| Kildeformat | Redigerbar eller gjenbrukbar fil | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Eksportformat | Bilde eller dokument for deling | SVG, PNG, PDF |

Diagram-HTML inneholder grafikk med zoom; HTML med strukturert sammendrag inneholder tekst, struktur og referanser. Redigerbar HTML/SVG er en renderer, ikke en nettredigerer. Bruk den opprinnelige kildefilen for redigering. Presentasjonseksport, inkludert PPTX og MP4, har egne innstillinger og avhengigheter.

## Velg kilde

| Format | Passer til | Kildefil |
| --- | --- | --- |
| Mermaid | Diagrammer i Markdown | Mermaid-kodeblokk |
| JSON Canvas | Native Obsidian-canvas | `.canvas` |
| Draw.io | Redigering i diagrams.net eller kompatible verktøy | `.drawio` |
| Drawnix | Håndtegnet/tavleredigering | `.drawnix` |
| CircuitikZ | Strukturerte elektriske kretser og transistorkretser | `.tex` |

Støttede formater vises først; inkompatible valg forblir synlige og deaktiverte. Eksisterende inaktive ønsker kan fjernes. Hver type beholder sine formater. Hvis ingen kan brukes, forsøkes standardkilden til den aktive rendereren, og utilgjengelige ønsker rapporteres.

## Generer og eksporter

1. Åpne støttet kildenotat. Flytt passasjer til eget notat; markering avgrenser ikke filoppgaver.
2. Velg flere diagramtyper i samme kjøring og flere utdataformater for hver type. Når du fjerner avkrysningen, beholdes typens formater. Uten valgte typer analyseres innholdet automatisk.
3. Avkrysningsboksen tar med typen. Klikk på navnet for å velge den og redigere formatene. Pekeren over typen eller tastaturfokus bytter forhåndsvisning uten å lagre innstillinger. Escape lukker menyen og gjenoppretter fokus.
4. Velg **Generate diagram**.
5. Valgte filer eksporteres automatisk ved siden av kildenotatet eller rett til den angitte utdatamappen. Navnene inneholder typen, for eksempel `topic_drawnix.pdf` og `topic_flowchart.svg`. Navnekollisjoner får `-2`, `-3` osv. uten å overskrive filer.
6. Kontroller tavle og Mermaid-paneler i kildeorden i én loddrett rullbar visning med faktisk panelhøyde.
7. Bruk **Export SVG**, **Export PNG** eller **Export PDF** per panel, eller eksporter alle øverst. Velg kildemappe eller egen hvelvrelativ mappe. Navn er deterministiske per panel, og én panelfeil stopper ikke de andre. Bevar redigerbar fil med **Save source file**.

Angi en felles Vault-relativ mappe for mellomfiler, eller la feltet stå tomt for `notemd_assert/` ved hver kilde. Her lagres gjenopprettingsposter, rendringscache og valgfrie vedlegg. Behold filer som fortsatt refereres; endringer gjelder bare nye kjøringer.

Typer genereres etter hverandre. Én feil stopper ikke de andre. Avbryting stopper ventende typer og beholder ferdige filer. Prøv eksport på nytt fra forhåndsvisning eller historikk uten en ny modellforespørsel. Genereringsfeil krever at typen genereres på nytt. v1/v2-poster kan fortsatt leses.

Eksportmeny og paneloverskrifter gir de samme tre handlingene. **History** åpner søk, filtre, gjenåpning og lagrede filer uten å skjule forhåndsvisningen. Historikk finnes også via palett/sidepanel uten aktivt notat.

SVG/PDF kommer fra vektorgeometri. PDF bevarer SVG-layout og tekstmål fremfor å gjøre alt til bitmap. PPI gjelder bare PNG: 72–600, standard 300.

## Lesbare tette diagrammer

Redigerbare HTML/SVG-baner måler og bryter opp oppsummeringen før tittel og radoverskrifter. Celler tegnes før forbindelser/etiketter; ortogonale ruter unngår opptatte celler og reserverer tekstplass.

`quadrantChart` får egen normalisering uten flytdiagrammets retting av anførselstegn/former. En kopiert åpningsparentes fjernes bare hvis den er uparet sist i en punktetikett. Tilsiktede parenteser i tittel, akser og kvadranter beholdes.

[Eksempelkatalogen](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) har tospråklige inndata, SVG/PNG og manifest. `passed` gjelder registrert kjøring/bundle, ikke en fersk test av alle typer i senere versjoner. Det er 33 kjørbare rader, 21 UI-språkversjoner og 34 nettspråk. Fem eksakte referansegrammatikker holdes utenfor velgeren til layout er bevist separat.

## Drawnix med innebygd Mermaid

Notemd renser SVG og bevarer Mermaid-kilde i `.drawnix`-metadata. Forhåndsvisningen trenger ikke Drawnix/Plait-runtime. Standardfilen er selvstendig uten `.assets`. **Also export complete Mermaid visuals** oppretter kilde-, SVG- og manifestfølgefiler. Eldre `.assets` støttes; manglende SVG kan bygges fra bevart kilde.

Bilder får der det er mulig forhåndsvisning med innebygde data. Rekkefølge: innebygd innhold, eldre følgefiler, tilgjengelig kildetekst. Behold fortsatt refererte filer: ny selvstendig eksport beviser ikke at en gammel delt mappe er overflødig.

Drawnix bevarer alle eksplisitte rettede relasjoner uten en fast totalgrense eller grense per node. Identiske utsagn fjernes som duplikater; ulike predikater og motsatte retninger beholdes. Overlappende ytre ruter får separate spor, adskilte ruter gjenbruker spor. Etiketter får rader etter målene sine, og tegneflaten vokser ved behov. Piler uten etikett, generelle forbindelser og piler som gjentar hierarkiet, blir liggende i metadata med årsak. Tekst i relasjonsbokser vises i PDF, også fra eldre SVG-cache. Piler mellom grener er statiske og kan løsne etter omplassering i Drawnix.

## Native eksportgrenser

Kilde og visuell eksport er separate leveranser. Test en representativ fil i målprogrammet. PowerPoint bevarer støttede redigerbare tabeller, inkludert rettede skillelinjer under sammenslåtte celler; Mermaid/SVG kan bli bilder. Forhåndsvisning eller helbildescore erstatter ikke native kontroll.

## Kretser

Velg **Circuit diagram** og **CircuitikZ source file**. Notemd genererer først strukturert beskrivelse og så kilde; det avgrenser vilkårlig LaTeX. Støtten er bevisst begrenset, særlig common-source NMOS og støttede CMOS-blokker. Kontroller kilde og forhåndsvisning før teknisk bruk eller publisering.

SVG-forhåndsvisning er et kontrollverktøy, ikke bevis for lokal LaTeX/TikZJax-kompilering. Forhåndsvisning, SVG/PNG og forhåndsvisnings-PDF trenger ikke LaTeX. Åpne **CircuitikZ native compile environment** på skrivebord for diagnostikk/native PDF: systemets `tectonic`/`pdflatex`, egen kjørbar fil eller versjonslåst administrert Tectonic etter eksplisitt **Install**. Panelet viser framdrift/feil og kan fjerne administrert runtime.

## Problemer

### Feil diagramtype

Velg typen eksplisitt. Kretser bruker **Circuit diagram** og **Generate diagram**, ikke eldre **Summarise as Mermaid diagram**.

### Uegnet kilde

Støttede formater vises først; inkompatible valg forblir synlige og deaktiverte. Eksisterende inaktive ønsker kan fjernes. Hver type beholder sine formater. Hvis ingen kan brukes, forsøkes standardkilden til den aktive rendereren, og utilgjengelige ønsker rapporteres.

### Eksportmeny mangler

SVG/PNG/PDF krever visuell forhåndsvisning. Hvis bare tekst er tilgjengelig, lagre kilden og åpne den i passende eksternt verktøy.

### CircuitikZ kompilerer ikke

Se **CircuitikZ native compile environment**. Reparer administrert runtime eller kontroller at egen/systemkompilator kan hente `circuitikz`. Pluginbundlen inneholder ingen full TeX-distribusjon.
