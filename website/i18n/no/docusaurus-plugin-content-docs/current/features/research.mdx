# Undersøkelser og nettsøk

<TLDR>Research & summarize søker fra markering eller notattittel, ber LLM oppsummere tilgjengelig kontekst og legger resultatet til aktiv Markdown. Velg Tavily eller DuckDuckGo eksplisitt og kontroller kildereferansene.</TLDR>

## Oversikt

Søkeleverandør og oppsummeringsmodell er separate. Tavily krever nøkkel; DuckDuckGo trenger ikke nøkkel, men bruker nettverk og kan begrenses. Lokal modell gjør ikke nettundersøkelser frakoblet.

## Slik fungerer det

### Søk og oppsummer

1. Åpne målnotatet i Markdown-editoren; velg emne eller bruk tittel.
2. Kjør **Research & summarize**.
3. Tavily gir utdrag; DuckDuckGo kan hente resultatsider.
4. Tillatt lokal kontekst kan legges til fra valgt omfang.
5. Modellen skriver under `Research Summary` med emne og kildetype.
6. Åpne relevante URL-er og kontroller påstandene. Hentet kontekst beviser ikke alle genererte sitater.

### Tavily eller DuckDuckGo

| Valg | Forberedelse | Driftsgrense |
| -------- | ------- | ---------------------- |
| Tavily | Velg Tavily og angi nøkkel | Kontokvoter og returnerte utdrag |
| DuckDuckGo | Velg DuckDuckGo eksplisitt | Ingen nøkkel; søkebegrensning og sidetilgjengelighet |

Tom eller feil Tavily-nøkkel bytter ikke automatisk tjeneste. Se rapport ved lite nettgrunnlag. Aktiverte lokale utdrag kan fortsatt støtte oppsummeringen; kildemerket skiller dette fra nettbasert tekst.

### Undersøkelser ved tittelgenerering

**Enable research in "Generate from title"** legger til undersøkelser også for batch, og er av som standard. Dette er mapperuten; ingen selvstendig generell Research Folder-handling finnes.

## Innstillinger

| Innstilling | Startverdi | Virkning |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Søketjeneste |
| `tavilyApiKey` | `''` | Tavily-nøkkel |
| `tavilyMaxResults` | `5` | Ønsket antall Tavily-resultater |
| `tavilySearchDepth` | `basic` | Tavily-søkedybde |
| `ddgMaxResults` | `5` | Ønsket antall DuckDuckGo-resultater |
| `ddgFetchTimeout` | `15` | Tidsavbrudd for resultatsider i sekunder |
| `maxResearchContentTokens` | `3000` | Omtrentlig nettkontekstbudsjett |
| `researchProvider` | `DeepSeek` | Oppsummeringsleverandør med oppgaveruting |
| `researchModel` | `''` | Tomt bruker leverandørens modell |
| `researchSummarizeLanguage` | `en` | Resultatspråk ved oppgavespesifikke språk |
| `enableResearchInGenerateContent` | `false` | Tillat undersøkelser ved tittelgenerering |
| `enableLocalKnowledgeRetrieval` | `false` | Aktiver lokalt søk separat |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Lokalt søk for denne oppgaven |

### Kontekst og modell

Kontekstgrenser er anslag, ikke nøyaktige leverandørtokens. Avkorting kan fjerne bevis. Avgrens spørsmål og modell-/svarbudsjett. Den lokale indeksen er leksikal uten implisitte embeddings eller fullstendighetsgaranti.

## Eksempel

Opprett `Relativ posisjonskoding`, kjør undersøkelse og sammenlign med originalpublikasjoner eller offisiell dokumentasjon. Bevar spørsmål, faktiske URL-er og rettelser for etterprøving. Eksemplet er ikke et allerede utført søk i hvelvet ditt.

## Avbrudd og personvern

Ferdige tillegg beholdes. Aksepterte modell-/sideforespørsler kan fullføres. Søk får spørsmålet, nettsider får forespørsler og LLM får hele konteksten, inkludert tillatte lokale utdrag. Se diagnostikk før deling.

## Tips

- Skill nettkilde, lokalt notat og modellslutning.
- Kontroller sitater, datoer og viktige påstander i originalen.
- Test søk og modell separat med et lite spørsmål.
- Les eksisterende oppsummeringer for å unngå doble tillegg.
