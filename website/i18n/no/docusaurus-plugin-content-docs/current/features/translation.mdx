# Oversettelse

<TLDR>Notemd oversetter aktiv fil eller egnede mappefiler med valgt LLM. Standardresultatet er en separat fil med språksuffiks. Kvaliteten avhenger av modellen; 21 UI-språk og 34 nettspråk er ingen oversettelsesgrenser eller garantier.</TLDR>

## Oversikt

Velg målspråk og leverandør, og test en kopi med fagtermer, lenker og kode. Dette bruker valgt LLM, ikke en særskilt Google Translate-integrasjon. Handlingene gjelder filer/mapper. Flytt en passasje til midlertidig notat; markering avgrenser ikke **Translate current file**.

## Slik fungerer det

### Oversettelsesoppgaven

1. Velg målspråk, innledningsvis engelsk og skilt fra UI.
2. Åpne kilden og kjør **Translate current file**.
3. Lang tekst deles, sendes til modell og settes sammen.
4. Åpne rapportert fil og se betydning, termer, sitater, Markdown-lenker og kode.

Fransk fra `Example.md` blir vanligvis `Example_fr.md` ved bevart kilde. Eksisterende resultat overskrives. Tillegg i originalen eller fast overskrift `Translation` er ingen standardgaranti.

### Språkpar

Modellen utleder kildespråket. Et menyvalg beviser ikke kvalitet for paret. Test blandede språk og fagtermer; oppdeling kan miste kontekst.

### Modell per oppgave

Oppgaveruting bruker `translateProvider`/`translateModel`, ellers aktiv leverandør. Lokalt trengs server/modell, sky mottar innhold og instruksjon. Vurder en fagspesifikk prøve.

### Mappeoversettelse

**Batch translate folder** tar som standard bare direkte barn; avanserte profiler kan endre dette. Like kildenavn til felles resultatmappe kan kollidere. Se tidligere oversettelser og mål før ny kjøring.

## Innstillinger

| Innstilling | Startverdi | Virkning |
| --------- | --------- | -------- |
| `language` | `en` | Valgt målspråk |
| `translateProvider` | `DeepSeek` | Leverandør med oppgaveruting |
| `translateModel` | `''` | Tomt bruker leverandørens modell |
| `useCustomTranslationSuffix` | `false` | Språkkode som standardsuffiks |
| `translationCustomSuffix` | `_translated` | Suffiks når eget alternativ er på |
| `useCustomTranslationSavePath` | `false` | Standardlagring ved kilden |
| `translationSavePath` | `''` | Egen hvelvrelativ resultatmappe |
| `batchConcurrency` | `1` | Ønsket samtidighet for mappeoversettelse |

Hvis egen mappe ikke kan opprettes, kan kildemappen brukes. Les den faktiske stien. Tomt egendefinert suffiks kan peke på kilden; bruk eget suffiks for separat oversettelse.

## Eksempel

Kopier et kort kinesisk notat til testmappe, velg engelsk og oversett. Sammenlign `_en.md` med kilden: fagtermer, tall, formler og lenker. Utvid deretter.

## Avbrudd og kontroll

Avbrudd stopper støttet videre arbeid, ikke tidligere oversettelser eller garantert fakturering. Se rapport og filer. Markdown-bevaring er en modellinstruksjon, ingen parsergaranti for lik betydning.

## Tips

- Sikkerhetskopi og navnekontroll.
- Separat testsuffiks og mappe.
- Kontroller kode, matematikk, URL-er og egennavn.
- Gjennomgå diagnostikk før deling.
