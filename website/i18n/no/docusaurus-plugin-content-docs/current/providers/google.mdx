# Google

<TLDR>Google bruker native Gemini Generative Language. Angi tillatt nøkkel og tilgjengelig modell. Gemini via kompatibel gateway bruker gatewayprofilen.</TLDR>

## Forberedelse

Velg **Google**, nøkkel, native endepunkt og modell for valgt API-versjon. Test forbindelse og notat. Dette konfigurerer ikke vilkårlige Google Cloud-/Vertex-deployments automatisk.

## Endepunkt og autentisering

| Felt | Startverdi |
| ------- | -------------- |
| Transport | `google` |
| API-nøkkel | Påkrevd |
| Basis-URL | `https://generativelanguage.googleapis.com/v1` |
| Modell | `gemini-2.0-flash-exp` |
| Temperatur | `0.5` |
| Forbindelsestest | `chat-only` |

Det gjøres et `generateContent`-kall med nøkkel. Historiske ID-er garanterer ikke tilgang. Se diagnostikk-URL-er før deling; de kan inneholde autentisering.

## Modeller

Bruk native oppdagelse og kontroller generering på valgt API. Tom liste kan skyldes rettigheter, adresse eller manglende modell. Finn årsaken før protokollbytte.

## Problemer

- 400: ID, parametere og grenser for inn-/utdata.
- 401/403: nøkkelbegrensninger, aktivert API og rettigheter.
- 404: er modellen tilgjengelig i denne API-versjonen?
- Gatewayeksempler: bruk rett OpenAI-kompatibel profil.

## Når passer profilen?

For native Gemini. Test oversettelse, undersøkelser eller diagrammer med eget materiale. Ingen generelle løfter om hastighet, pris eller kvalitet.
