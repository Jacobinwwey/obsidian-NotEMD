# Anthropic

<TLDR>Bruk profilen for native Messages. Claude gjennom OpenAI-kompatibel gateway bruker gatewayprofilen. Historisk startmodell kan måtte erstattes med en tilgjengelig modell.</TLDR>

## Forberedelse

Velg **Anthropic**, nøkkel og modell du har tilgang til. Behold native-adressen med mindre din deployment tilbyr samme protokoll. Test forbindelse og notat.

## Endepunkt og autentisering

| Felt | Startverdi |
| ------- | -------------- |
| Transport | `anthropic` |
| API-nøkkel | Påkrevd |
| Basis-URL | `https://api.anthropic.com` |
| Modell | `claude-3-5-sonnet-20240620` |
| Temperatur | `0.5` |
| Forbindelsestest | `chat-only` |

Runtime bruker `/v1/messages` med native nøkkel-/versjonsheadere. Ikke legg til OpenAI-chatruter. Startverdiene beskriver repositoriets konfigurasjon, ikke dagens modelltilgang.

## Modeller

Bruk native oppdagelse der det er tillatt. Hvis listen er sperret, angi tillatt ID og test generering. Lange og strukturerte oppgaver trenger egne kontroller.

## Problemer

- 401/403: nøkkel, prosjekt, betaling og modelltilgang.
- 404: adresse og tilgjengelighet.
- Gateway-ID avvises: rett profil/ID.
- Lange feil: undersøk grenser før flere forsøk.

## Når passer profilen?

For native Messages-endepunkter. Sammenlign med egne kilder fremfor generell leverandørrangering. Oppgaveruting gir avgrenset bruk.
