# OpenAI

<TLDR>Profilen bruker den delte OpenAI Chat Completions-kjørebanen. Velg nøkkel og modell for protokollen. Startmodellen garanterer ikke aktuell tilgang eller generell kvalitet.</TLDR>

## Forberedelse

Bruk **OpenAI**, nøkkel og `https://api.openai.com/v1` for offisiell tjeneste. En modell i listen kan kreve en annen API. Gatewayer har egne profiler/headere; Azure bruker **Azure OpenAI**, deployment og API-versjon.

## Endepunkt og autentisering

| Felt | Startverdi |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API-nøkkel | Påkrevd |
| Basis-URL | `https://api.openai.com/v1` |
| Modell | `gpt-4o` |
| Temperatur | `0.5` |
| Forbindelsestest | `models-then-chat` |

Kjente URL-former normaliseres før ruter bygges. Start fra profilen og kontroller den endelige adressen fremfor å legge til tilfeldige stisegmenter.

## Modeller

**Fetch models** henter tilgjengelige modeller. **Test connection** kan lykkes med bare listen. Kontroller nøyaktig modell med et notat. Reasoning, thinking, sampling og budsjetter må passe profil/modell.

## Problemer

- 401/403: nøkkel, prosjekt, rettigheter og konto.
- 404: endepunkt, modell-ID og API-støtte.
- Liste fungerer, generering ikke: se chatfeil og parametere.
- Langt svar avbrytes: inndata, budsjett og svar; kort test dekker ikke dette.

## Når passer profilen?

For direkte OpenAI-endepunkter med Chat Completions. Vurder egne notater; priser og tilgang endres uavhengig av Notemd.
