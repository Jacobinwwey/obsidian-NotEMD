# Hurtigstart

<TLDR>Begynn med et Markdown-testnotat og en leverandør du har tilgang til. Kontroller resultatfilen før en hel mappe. Skyoppgaver sender innhold; lokale modeller krever også aktiv server og klargjort modell.</TLDR>

## 1. Velg modell

1. [Installer og aktiver](./installation), åpne **Settings → Notemd**.
2. Velg profil, endepunkt, nødvendige påloggingsopplysninger og tilgjengelig modell. **Fetch models** erstatter ikke en genereringstest.
3. Kjør **Test connection** og rett konto-, modell- eller adressefeil.
4. Finn **Concept note folder path** og velg en egen mappe, for eksempel `concepts`. Standardverdien er tom; navnet er ditt valg.

Hent Ollama-modellen først og bruk nøyaktig navn; standardadressen er `http://localhost:11434/api`. Start LM Studio-serveren og velg `LMStudio`. Se [lokale modeller](../providers/local). Nettundersøkelser krever nettverk også med lokal oppsummeringsmodell.

## 2. Første oppgave

Skriv en kort tekst som kan sendes til leverandøren i `Notemd trial.md`:

```text
Maskinlæring bruker nevrale nettverk til å lære mønstre.
```

Kjør **Process file (add links)** fra sidepanelet eller paletten. Vanligvis bevares originalen og `Notemd trial_processed.md` opprettes ved siden av. Åpne resultatet. Et mulig eksempel:

```markdown
[[Maskinlæring]] bruker [[nevrale nettverk]] til å lære mønstre.
```

Notater kan også opprettes i begrepsmappen. Kontroller filer og lenker; modellen garanterer ikke fullstendig eller korrekt begrepsutvalg.

## 3. Flere funksjoner

### Hent ut begreper

**Extract concepts (current file)** bevarer kilden og krever begrepsmappe. Nye selvstendige notater får bare tittel, uten tilbakekobling. Aktiver dette uttrykkelig ved behov. [Begrepsnotater](../features/concept-notes).

### Undersøk og oppsummer

Velg emne i Markdown-editoren eller bruk tittelen og kjør **Research & summarize**. Velg Tavily med nøkkel eller DuckDuckGo uttrykkelig. Oppsummeringen legges til i aktivt notat. Åpne kildene og kontroller påstandene.

### Arbeidsflyt med ett klikk

Standard **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Den legger til lenker, fyller egnede notater fra titler i begreps-/valgt mappe og reparerer Mermaid i complete-mappen. Eksisterende notater kan inngå. Begynn i testmappe. Nettundersøkelser og generell diagramgenerering legges ikke automatisk til.

## Avbryt og kontroller

**Cancel** stopper støttet videre arbeid. Ferdige resultater beholdes; dette er ingen angretransaksjon og garanterer ikke stoppet fjernarbeid eller fakturering. Vent til avslutning, kontroller stier og gjenopprettingskonflikter før ny kjøring.

## Problemer

- Konto/modell: kontroller profil og forbindelse.
- Ingen begreper: angi aktiv, ikke-tom mappesti.
- Ingen nyttige lenker: se svar og instruksjon; minste tekstlengde garanterer ingenting.
- Begrensninger: behold samtidighet `1` mens kvotene undersøkes.
