# Installasjon

<TLDR>Installer Notemd via Community plugins, eller legg de tre programfilene fra samme GitHub-utgivelse i hvelvet. Aktiver utvidelsen, velg leverandør og prøv et notat. Modellservere og valgfrie native eksportverktøy klargjøres separat.</TLDR>

## Metode 1: Community plugins, anbefalt

1. Åpne **Settings → Community plugins** i riktig hvelv.
2. Tillat fellesskapsutvidelser ved behov og velg **Browse**.
3. Søk etter **Notemd**, kontroller `Jacobinwwey/obsidian-NotEMD` og velg **Install**.
4. Velg **Enable** og åpne sidepanelet fra verktøylinjen eller kommandopaletten.

[Åpne Notemd i Obsidian](obsidian://show-plugin?id=notemd). Bruk menyen over hvis nettleseren ikke åpner lenken. Dokumentasjonen kan leses uten en protokollbehandler.

## Metode 2: Manuell installasjon

### Forutsetninger

Du trenger Obsidian og et hvelv som kan sikkerhetskopieres. Manifestets minimum `0.15.0` er en deklarasjon, ikke bevis på en fersk test på den versjonen.

### Trinn

1. Hent `main.js`, `manifest.json` og `styles.css` fra samme [GitHub-utgivelse](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` er referansemateriale, ingen påkrevd programfil.
2. Legg de tre filene i `<vault>/.obsidian/plugins/notemd/`. Tilpass hvis konfigurasjonsmappen er endret.
3. Last Obsidian på nytt og aktiver utvidelsen.
4. Kontroller versjonen; ikke kombiner nytt manifest med gammel bundle.

## Alternativ: BRAT

Bruker du allerede [BRAT](https://github.com/TfTHacker/obsidian42-brat), kan du legge til repositoriet gjennom beta-flyten der. Velg en bestemt utgivelse for feilreproduksjon. BRAT er et valgfritt eksternt verktøy.

## Verifisering

Konfigurer en tilgjengelig modell, kjør **Test connection** og deretter [hurtigstart](./quick-start). En modelliste beviser ikke genereringsrettigheter; kontroller faktisk resultat.

## Systemgrenser

| Del | Grense |
| --------- | ---------- |
| Manifest | Minst Obsidian `0.15.0`; `isDesktopOnly` er false |
| Testbevis | Se daterte rapporter; fysiske mobilenheter og 0.15.0 er ikke verifisert i gjeldende akseptanse |
| Skymodell | Nettverk, autorisert konto/nøkkel og tilgjengelig modell |
| Lokal modell | Separat installert, aktiv server og hentet/lastet modell |
| Native lysbilde- eller kretseksport | Skrivebordsverktøy og formatavhengigheter; kontroller miljøet først |

Det finnes ingen felles OS-versjonsgaranti for alle eksportører. Kretsforhåndsvisning beviser ikke TeX-kompilering; skrivebordstesting beviser ikke mobilatferd.

## Avinstallering

Deaktiver eller avinstaller via Community plugins. Genererte notater og artefakter blir vanlige filer i hvelvet. Gjennomgå dem før sletting og behold innstillingene ved behov. Avinstallering tilbakestiller ikke tidligere endringer.

## Oppdatering

Bruk **Check for updates**. Manuelt: stopp oppgaver, sikkerhetskopier hvelv/innstillinger, erstatt tre programfiler fra samme utgivelse og last på nytt. Les utgivelsesnotatene og test smått før batchkjøring. Ikke erstatt innstillingsfilen med en utgivelsesfil. Tilbakerulling krever en bevisst valgt kompatibel versjon og sikkerhetskopi.
