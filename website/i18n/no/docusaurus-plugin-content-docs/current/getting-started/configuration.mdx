# Konfigurasjon

<TLDR>Åpne Settings → Notemd og søk etter feltet. Velg leverandør og resultatplassering før kjøring. Test endringer på ett notat; en aktiv oppgave kan beholde innstillingene fra start.</TLDR>

## Oversikt

Standardleverandøren er DeepSeek uten påloggingsopplysninger. En profil oppretter ingen konto, installerer ingen modell og gir ingen rettigheter. Se [leverandører](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Søk og favoritter

**Search settings** søker i navn, beskrivelser, aliaser og synlige kategorier og fører til feltet. **★ Favorites** viser lagrede innstillinger med beskrivelse, kategori og mål. De lagres per hvelv, overlever omstart og fjerner gamle ID-er. Søket bevares når verktøylinjen foldes sammen. Favorittlisten er skilt fra søkefilteret for bare favoritter.

**Diagram preview export PPI** starter på 300, område 72–600, og påvirker bare PNG. SVG/PDF bevarer støttet vektorgeometri. **Also export complete Mermaid visuals** styrer følgefiler, ikke om Mermaid vises i Drawnix-forhåndsvisningen.

Velg flere diagramtyper i samme kjøring og flere utdataformater for hver type. Når du fjerner avkrysningen, beholdes typens formater. Uten valgte typer analyseres innholdet automatisk.

Angi en felles Vault-relativ mappe for mellomfiler, eller la feltet stå tomt for `notemd_assert/` ved hver kilde. Her lagres gjenopprettingsposter, rendringscache og valgfrie vedlegg. Behold filer som fortsatt refereres; endringer gjelder bare nye kjøringer.

## 1. Leverandør

Angi endepunkt med rett protokoll, nødvendig nøkkel og tilgjengelig modell. Liste og vellykket generering er to tester. Klargjør lokal server/modell; sky/gateway mottar innhold. Kontroller også oppgavespesifikke ruter før privat materiale.

## 2. Modell per oppgave

`useMultiModelSettings` tillater ulike leverandører/modeller for lenker, titler, undersøkelser, oversettelse, begreper, originaltekst og Mermaid. Tom overstyring bruker leverandørens modell; deaktivert bruker aktiv leverandør. Sammenlign kvalitet, ventetid og faktiske kostnader med samme notat.

## 3. Resultater

| Oppgave | Standardresultat |
| ------ | ------------------------- |
| Lenker | Egen `_processed.md` ved kilden; flytting av original av |
| Selvstendig begrepsuttrekk | Valgt begrepsmappe; bare tittel, tilbakekoblinger av |
| Oversettelse | Ved siden av som `_<language>.md`; eksisterende mål kan overskrives |
| Undersøkelse | Oppsummering legges til i aktiv Markdown |
| Batchgenerering fra titler | Skriver egnede kilder og flytter til tilstøtende `<folder>_complete` hvis målet tillater det |
| Diagramforhåndsvisning/eksport | Valgte filer eksporteres automatisk ved siden av kildenotatet eller rett til den angitte utdatamappen. Navnene inneholder typen, for eksempel `topic_drawnix.pdf` og `topic_flowchart.svg`. Navnekollisjoner får `-2`, `-3` osv. uten å overskrive filer. |
Begrepsmappen er tom fra start; `concepts` er et eksempel. Selvstendige notater har minimal/full form, ingen generell malmotor. [Begreper](../features/concept-notes). Behandling og oversettelse har egne suffikser/mapper. Kontroller mål og gjenopprettingskonflikter; avbrudd angrer ikke ferdige skrivninger.

## 4. Språk

UI har 21 språkversjoner, nettstedet 34 språkruter. `uiLocale: auto` velger støttet mapping, ellers engelsk. Generert språk velges separat, innledningsvis engelsk. Støttede oppgaver kan ha eget språk; oversettelse bruker `language`. Tallene beviser ikke modellens språkferdigheter.

## 5. Søk

Velg Tavily med nøkkel eller DuckDuckGo eksplisitt. Tom Tavily-nøkkel bytter ikke tjeneste. Begge bruker nettverk; DuckDuckGo kan hente resultatsider. Undersøkelser ved tittelgenerering er av: `enableResearchInGenerateContent`. Lokal henting er også av med egne mappe-/oppgavegrenser. Lokale utdrag som brukes i konteksten sendes til valgt LLM.

## 6. Arbeidsflyter

Bruk byggeren eller én navngitt DSL-linje per knapp:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` skiller navn fra handlinger, `>` skiller handlings-ID-er. Standardpolicy stopper ved rapportert feil. Se [arbeidsflyter](../features/workflows) for omfang og fortsettelse etter feil.

## 7. Avanserte innstillinger

| Innstilling | Startverdi | Virkning |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Leverandør uten egen oppgaverute |
| `useMultiModelSettings` | `false` | Leverandør/modell per oppgave |
| `useCustomConceptNoteFolder` | `true` | Tillat begrepsresultater etter mappevalg |
| `conceptNoteFolder` | `''` | Ingen begrepsmappe fra start |
| `extractConceptsMinimalTemplate` | `true` | Bare tittel i selvstendige begreper |
| `extractConceptsAddBacklink` | `false` | Tilbakekoblinger ved selvstendig uttrekk |
| `moveOriginalFileOnProcess` | `false` | Bevar original under lenking |
| `chunkWordCount` | `3000` | Omtrentlige tekstbiter, ingen tokengrense |
| `batchConcurrency` | `1` | Standard batchsamtidighet |
| `enableBatchParallelism` | `false` | Parallell planlegging på ruter som bruker bryteren |
| `enableStableApiCall` | `false` | Eksplisitt stabil forespørselsmodus |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stopp arbeidsflyt ved rapportert feil |

Størrelsen på tekstbiter og tokenbudsjettet for svar er ulike. Mindre biter løser ikke alle kontekstgrenser, og lav samtidighet hindrer ikke alle 429-feil.

## Innstillingsprofiler

Innstillinger er plugin-data i hvelvet. Ta sikkerhetskopi før endring. Leverandøreksport har egen maskeringskontrakt, ikke full hvelvbackup. Kontroller adresser og metadata også i maskert resultat. Ikke del rå innstillinger eller diagnostikk med private notater.

## Konfigurasjonsproblemer

Test nøyaktig leverandør/modell på et lite notat. Mangler et felt, kontroller søk, kategori, utviklermodus og hvelv. Rapporter versjon og minimale innstillinger uten hemmeligheter.
