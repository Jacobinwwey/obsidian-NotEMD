# Vanlige spørsmål

<TLDR>Begynn med et testnotat, tilgjengelig leverandør og tydelige mål. Svarene beskriver implementerte grenser; veiledningene viser forberedelser og kontroll av resultater.</TLDR>

## Spørsmål

### Hvordan installerer jeg Notemd?

Åpne Settings → Community plugins → Browse, finn Notemd, installer og aktiver. Manuelt brukes main.js, manifest.json og styles.css fra samme GitHub-utgivelse. Manifestet angir Obsidian 0.15.0; den gamle versjonen og fysiske mobilenheter er ikke nå verifisert.

### Hvilke LLM-leverandører støttes?

36 profiler i fem familier: OpenAI-compatible, Anthropic, Google, Azure OpenAI og Ollama. Sky, gatewayer og lokale servere krever eget endepunkt, nøkkel og modell. Profil eller modelliste garanterer ikke aktuell tilgang eller genereringsrett.

### Kan jeg bruke lokale modeller?

Ja, med Ollama, LM Studio, OVMS eller en aktiv kompatibel egen server. Klargjør modellen og test en oppgave. Lokal inferens gjør ikke nettsøk, avhengighetsinstallasjon eller separat skyrettede oppgaver frakoblet.

### Hva skiller dette fra ChatGPT?

Notemd retter seg mot dokumentoppgaver i Obsidian: lenker, begreper, undersøkelser som legges til, oversettelse og diagrammer. Velg ut fra arbeidet i hvelvet. Sammenlign gjeldende lagring, eksport og integrasjon; samtaleverktøy kan også bevare historikk og produsere dokumenter.

### Hvordan sammenligner jeg med Copilot eller Smart Connections?

Sammenlign konkrete oppgaver med aktuelle versjoner, innstillinger og dokumentasjon. Notemd behandler notater og gir avgrenset leksikal henting, ikke generell hvelvsamtale eller embeddingbasert semantisk søk. Ingen aktuell rangering av andre prosjekter hevdes.

### Hvilke søkemotorer brukes?

Velg Tavily med nøkkel eller DuckDuckGo eksplisitt. Tom Tavily-nøkkel bytter ikke tjeneste. Begge bruker nettverk. LLM oppsummerer nettkontekst og valgfrie lokale utdrag og legger tekst til aktiv Markdown. Kontroller URL-er og viktige påstander.

### Hvilke språk finnes?

UI har 21 språkversjoner og nettstedet 34 språkruter. Genereringsspråk velges separat og kan justeres per støttet oppgave. Oversettelsesomfang og kvalitet avhenger av modellen, ikke disse tallene.

### Kan jeg bruke forskningsartikler eller PDF?

Konverter først til Markdown med egnet eksternt verktøy og kontroller formler, tabeller og figurer. Bruk deretter begreper, originalpassasjer, undersøkelser, oversettelse eller diagrammer. Native PDF-OCR eller feilfritt uttrekk fra alle binære dokumenter loves ikke.

### Hvilke diagrammer finnes?

Den kjørbare katalogen har 33 oppføringer med passende kilder/forhåndsvisninger. Mermaid, JSON Canvas, Vega-Lite, redigerbar HTML/SVG, Draw.io, Drawnix og avgrenset CircuitikZ har ulike bruksområder. Velg støttede kombinasjoner og test målappen; forhåndsvisning beviser ikke native redigering eller kompilering.

### Er Notemd gratis og åpen kildekode?

Notemd har MIT-lisens, offentlig repositorium og tar imot bidrag. Leverandører, inferens, søk og eksterne verktøy har egne kostnader/vilkår. Pluginlisensen gjør ikke alle tilkoblede tjenester gratis.

### Fungerer alt uten nett?

Noen oppgaver bruker lokal modell etter at server, modeller og avhengigheter er klargjort. Nettsøk, også DuckDuckGo, krever fortsatt nett. Se oppgaveruting og eksportavhengigheter før frakobling. Ingen generell frakoblingsgaranti gis.

### Sendes data til skyen?

Instruksjon og innhold sendes til konfigurert LLM-endepunkt. Søketjenester får spørsmål, nettsider får forespørsler. Lokale utdrag kan inngå i skyinstruksjoner, og lokal profil kan peke på ekstern vert. Se ruter og diagnostikk. Lokal lagring garanterer ikke lokal behandling.

### Hva gjør One-Click Extract?

Standardkjeden legger til lenker, genererer egnede notater fra titler i begreps-/valgt mappe og reparerer Mermaid i complete. Eksisterende begreper kan inngå. Nettundersøkelser og diagramgenerering legges ikke automatisk til. Guiden viser nøyaktig DSL name::action>action.

### Angrer avbrudd endringene?

Nei. Støttet videre arbeid stopper og ferdige resultater beholdes. Aksepterte kall/skrivninger kan fullføres, og leverandøren styrer fakturering. Vent, kontroller stier og konflikter, og gjenta bare nødvendig arbeid.

### Kan en Agent automatisere Notemd?

Fire avgrensede offentlige kommandoer eksporterer maskerte profiler, funksjoner, kallkontrakt og offentlig CLI-grensesnitt via fungerende Obsidian og hvelv. De skriver resultatfiler. Repositoriets vedlikeholdsoperasjoner er separate; internt antall er ikke et offentlig API. Begynn med Agentguiden.

### Hvor begynner jeg som utvikler?

Utviklerguiden beskriver miljø, bygg, fulle tester, kildeansvar og utvidelseskontrakter. AGENTS.md er versjonert arbeidsautoritet. Rapporter reproduksjoner med presise versjoner og renset dokumentasjon og valider før integrasjon.
