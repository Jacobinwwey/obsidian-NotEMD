# Diagrams

<TLDR>
Choose **which type of diagram you need**, then select its **editable source format**. Preview the final output in Obsidian, which includes a Drawnix board alongside any embedded Mermaid visuals, and export each individual panel as SVG, PNG, or PDF.
</TLDR>

## Understand the three options

| Option | What it controls | Examples |
|---|---|---|
| Diagram type | The meaning of the diagram | Flowchart, sequence diagram, circuit diagram, data chart |
| Source format | The editable or reusable file created by Notemd | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Export format | The image or document format used for sharing | SVG, PNG, PDF |

Draw.io and Drawnix are **source formats**, not diagram types. CircuitikZ is a source format specifically designed for creating circuit diagrams. Since the same preview can be exported in several different visual formats, selecting CircuitikZ does not restrict you to exporting only as SVG.

## Choose a source format

| Format | Best for | Source file |
|---|---|---|
| Mermaid | Diagrams that should remain directly inside Markdown files | Mermaid code block |
| JSON Canvas | Workflow diagrams created using Obsidian’s native canvas feature | `.canvas` |
| Draw.io | Editing diagrams later in diagrams.net or compatible software | `.drawio` |
| Drawnix | Hand‑drawn or whiteboard‑style diagram creation | `.drawnix` |
| CircuitikZ | Structured electrical and transistor circuit designs | `.tex` |

Leave **Preferred source format** set to **Auto** if you don’t require a specific editor. Notemd will automatically select a compatible format based on the chosen diagram type.

## Generate and export a diagram

1. Open the note or select the text you want to turn into a visual.
2. Choose **Generate diagram** from the Notemd sidebar or command palette.
3. Select a **diagram type**, or leave it set to **Auto‑detect**.
4. Pick a **source format**, or keep it on **Auto**. Choose **Drawnix** if you want a knowledge map with editable nodes and embedded Mermaid visuals.
5. Review the preview. For multi‑panel results, the Drawnix board together with every Mermaid panel appear in their original order inside one vertically scrollable preview window; Mermaid panels retain their rendered height rather than being truncated.
6. Select **Export SVG**, **Export PNG**, or **Export PDF** for each individual visual, or use a top‑level export option to generate images for all panels at once. For multiple panels, specify the source folder or a custom folder relative to your Vault; Notemd creates one deterministic file per panel and continues processing even if one export fails.
7. Use **Save source file** if you also need the editable version of the diagram.

The Export menu provides **Export SVG**, **Export PNG**, and **Export PDF** options for the current visual preview. Each panel header also offers these same actions for individual Mermaid or Drawnix visuals, so you don’t have to export a large preview as a single opaque image.

To view the Vault history without hiding the diagram, select **History** in the preview area. You can search for and filter previously created diagrams, reopen existing previews, or access saved artifacts. Diagram history is also accessible directly from the command palette and Notemd sidebar, even when no note is currently open.

SVG and PDF files are generated using vector geometry; PDFs use the same SVG layout and text metrics rather than rasterising the entire preview. The PPI setting for image export in Notemd settings only controls PNG rasterisation (ranging from 72 to 600 PPI, with 300 PPI as the default).

## Drawnix previews with embedded Mermaid

When a Drawnix file contains Mermaid visuals, Notemd sanitises the resulting SVG and stores the original Mermaid source code alongside it in the `.drawnix` metadata. This allows the preview to display the Mermaid image directly inside the Drawnix knowledge map without needing the Drawnix or Plait runtime. Mermaid visuals that are safely embedded do not create a separate `.assets` directory; external binary media or unresolved visuals are kept with their accompanying files to ensure no data is lost.

The preview is intentionally designed as a single scrollable area: the main Drawnix canvas appears first, followed by each embedded Mermaid panel in their original order. Closing and reopening a saved history entry restores the exact same list of panels, dimensions, and export options.

## Circuit diagrams

For circuit‑related requests, select **Circuit diagram** together with a **CircuitikZ source file**. Notemd first generates a structured description of the circuit before writing the CircuitikZ source code. This approach is more reliable than asking the model to generate unrestricted LaTeX code.

Current CircuitikZ support is intentionally limited. Common NMOS amplifier designs and certain supported CMOS building blocks work best. Always examine both the preview and the source file before using a generated circuit in technical documents or publications.

The SVG preview provided by Notemd is meant as a review aid only; it does not guarantee that a local LaTeX or TikZJax installation successfully compiled the underlying `.tex` file.

**Optional native compilation.** You do not need LaTeX to view the diagram within the plugin, nor to export SVG, PNG, or PDF versions. On desktop devices, open **CircuitikZ native compile environment** from the diagram settings or command palette if you require compilation diagnostics or a native LaTeX PDF output. Notemd can reuse the system’s `tectonic` or `pdflatex` tools, use a custom executable, or install the managed Tectonic runtime after you explicitly select **Install**. The environment panel displays progress and errors inline and allows you to remove the managed runtime at any time.

## Troubleshooting

### The result is the wrong diagram type

Manually select the desired diagram type instead of relying on Auto‑detect. For circuit diagrams, choose **Circuit diagram** and use the **Generate diagram** command rather than the older **Summarise as Mermaid diagram** option.

### A source format is unsuitable

Reset the source format to **Auto**, or pick a format that matches the type of diagram you are creating. CircuitikZ is intended for circuit diagrams only; Draw.io and Drawnix are designed for specific structured diagram types.

### The Export menu is missing

SVG, PNG, and PDF exports require a visual preview. If only source text is available, save the source file and open it in the appropriate external tool.

### A CircuitikZ file does not compile externally

Open **CircuitikZ native compile environment** and run the environment check. Fix any issues with the managed runtime or confirm that your custom/system compiler can retrieve the `circuitikz` package. Notemd does not include a full TeX distribution within its plugin files.
