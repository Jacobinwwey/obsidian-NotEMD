# Нотатки понять

<TLDR>Самостійне виділення читає джерело й створює Markdown-нотатки понять у вибраній папці. Початково папку не задано. Нові нотатки мають лише назву без зворотного посилання. Додавання посилань використовує іншу форму результату.</TLDR>

## Огляд

Спочатку задайте **Шлях до папки нотаток-концептів**. Окрема папка спрощує перевірку результатів, дублікатів і генерації за назвами. Виділення не заповнює поняття дослідженими поясненнями автоматично.

## Як це працює

### Виділення

Вибраний LLM отримує текст. Завдання читає рядки `CONCEPT:`, прибирає повторні назви всередині операції та створює/оновлює файли. Довгі нотатки діляться. Перевірте невдалі частини; відповідь не є повним переліком понять.

### Інструкція виділення

Типовий запит просить конкретні релевантні поняття. Тема та правила синонімів не гарантують канонічного словника. У власній інструкції збережіть `CONCEPT: Term`. [Власні запити](../advanced/custom-prompts).

### Частини

`chunkWordCount` типово близько 3000 слів, а не токенів провайдера. Контекст між частинами обмежений; перевіряйте зв’язки й неоднозначні назви.

## Створення файлів

### Назви

Недопустимі символи шляхів вилучаються, пробіли нормалізуються, довгі назви скорочуються; порожні результати пропускаються. Різні терміни можуть утворити однаковий шлях. Перед великою колекцією перевірте назви.

### Шаблони

Мінімальна нова нотатка:

```markdown
# Назва поняття
```

Для зворотного посилання в новій самостійній нотатці ввімкніть **Add "Linked From" backlink** і вимкніть **Create minimal concept notes**:

```markdown
# Назва поняття

## Linked From
- [[Нотатка-джерело]]
```

Додавання посилань створює повнішу форму з посиланням на джерело, якщо файли понять дозволені. Перемикачі самостійного виділення цей шлях не змінюють.

### Наявні нотатки

За ввімкнених зворотних посилань відсутнє джерело може додатися під `## Linked From`. Текст зберігається, те саме посилання не дублюється. Базова назва джерела може бути неоднозначною між папками.

### Параметри

| Параметр | Початкове значення | Вплив |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Результати понять після вибору папки |
| `conceptNoteFolder` | `''` | Папку не вибрано |
| `extractConceptsMinimalTemplate` | `true` | Лише назва в самостійних поняттях |
| `extractConceptsAddBacklink` | `false` | Зворотні посилання самостійного виділення |
| `extractConceptsProvider` | `DeepSeek` | Провайдер за маршрутизації завдань |
| `extractConceptsModel` | `''` | Порожнє поле бере модель провайдера |
| `extractConceptsLanguage` | `en` | Мова з перевизначеннями завдань |
| `replaceSynonymsDuringConceptExtraction` | `false` | Інструкція зменшення синонімів |
| `generateConceptLogFile` | `false` | Необов’язковий журнал понять |

## Дублікати

Перевірка евристична: регістр, множина, символи та, де дозволено, входження слова в іншу назву. Це не доказ однакового змісту. У **Перевірити й видалити дублікати** перегляньте нерегулярні форми й технічні відмінності та підтвердіть лише потрібні видалення. Кошиком керує Obsidian. Папка понять не тимчасовий кеш; робіть копію.

### Область порівняння

Порівнюйте зі сховищем, папкою понять, включеними папками чи областю з виключеннями. Область змінює кандидатів, не значення дубліката.

## Використання

### Самостійне виділення

Відкрийте Markdown, перевірте папку та запустіть **Витягти концепти (поточний файл)**. Джерело незмінне. Перевірте назви, охоплення й зворотні посилання.

### Виділення та вміст

**Пакетна генерація з назв** заповнює поняття, але може взяти наявні придатні нотатки. Перевірте папку перед запуском і повідомлену complete після нього.

### Посилання з виділення

Дія для виділення перетворює ваш термін на вікіпосилання й може створити файл поняття, якщо ціль задана.

## Рекомендації

- Мале джерело й окрема папка.
- Виберіть мову перед масовим створенням.
- Окремо оцінюйте синоніми та дублікати.
- Збережіть потрібні журнали перед наступним перезаписом.
