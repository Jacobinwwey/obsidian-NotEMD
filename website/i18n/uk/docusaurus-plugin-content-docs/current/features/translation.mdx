# Переклад

<TLDR>Notemd перекладає активний файл або придатні файли папки вибраним LLM. Типово записує окремий файл із суфіксом мови. Якість залежить від моделі; 21 мова UI й 34 маршрути сайту не є межами чи гарантіями перекладу.</TLDR>

## Огляд

Виберіть цільову мову й провайдера, перевірте копію з термінами, посиланнями й кодом. Працює LLM, не окрема інтеграція Google Translate. Команди стосуються файлів/папок. Для уривка створіть тимчасову нотатку; виділення не обмежує **Перекласти поточний файл**.

## Як це працює

### Завдання перекладу

1. Виберіть цільову мову, типово англійську, окремо від UI.
2. Відкрийте джерело й запустіть **Перекласти поточний файл**.
3. Довгий текст ділиться, надсилається й об’єднується.
4. Відкрийте повідомлений шлях, перевірте значення, терміни, цитати, Markdown і код.

Французький переклад `Example.md` типово створює `Example_fr.md` поруч зі збереженим джерелом. Наявний результат перезаписується. Додавання в оригінал чи фіксований розділ `Translation` не є типовою гарантією.

### Мовні пари

Мову джерела визначає модель. Пункт меню не доводить точності пари. Перевіряйте змішані мови й термінологію; поділ може втрачати контекст.

### Модель завдання

Маршрутизація використовує `translateProvider`/`translateModel`, інакше активного провайдера. Локально потрібні сервер і модель; хмара отримує текст та інструкцію. Оцініть власний предметний зразок.

### Переклад папки

**Пакетний переклад теки** типово включає лише безпосередні дочірні файли. Розширені профілі можуть це змінити. Однакові назви джерел у спільній папці результатів можуть конфліктувати. Перевірте старі переклади й цілі до повтору.

## Параметри

| Параметр | Початкове значення | Вплив |
| --------- | --------- | -------- |
| `language` | `en` | Цільова мова |
| `translateProvider` | `DeepSeek` | Провайдер за маршрутизації завдань |
| `translateModel` | `''` | Порожнє поле бере модель провайдера |
| `useCustomTranslationSuffix` | `false` | Код мови як типовий суфікс |
| `translationCustomSuffix` | `_translated` | Суфікс за ввімкненого власного налаштування |
| `useCustomTranslationSavePath` | `false` | Типове збереження поруч із джерелом |
| `translationSavePath` | `''` | Папка результатів відносно сховища |
| `batchConcurrency` | `1` | Бажана одночасність перекладу папки |

Якщо власну папку не вдається підготувати, може використовуватися папка джерела. Читайте фактичний шлях. Порожній власний суфікс може націлитися на оригінал; для окремого перекладу задайте відмінний.

## Приклад

Скопіюйте коротку китайську нотатку до тестової папки, виберіть англійську та перекладіть. Зіставте `_en.md` із джерелом за термінами, числами, формулами й посиланнями. Лише тоді збільшуйте обсяг.

## Скасування та перевірка

Скасування зупиняє підтримуване продовження; готові переклади залишаються, зупинка оплати не гарантована. Перевірте звіт і файли. Збереження Markdown — інструкція моделі, а не гарантія однакового значення з боку парсера.

## Рекомендації

- Збережіть джерело й перевірте конфлікти.
- Тестуйте окремий суфікс або папку.
- Вручну перевіряйте код, математику, URL і назви.
- Очистіть діагностику перед поширенням.
