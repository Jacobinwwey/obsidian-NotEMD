# Робочі процеси

<TLDR>Процес послідовно запускає дії бічної панелі. Кожній можуть бути потрібні папка чи активний редактор. Це не текстовий конвеєр: кроки зберігають власні входи, виходи й побічні ефекти. Почніть із тестової нотатки й окремої папки.</TLDR>

## Огляд

Типовий **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Додає посилання до активної нотатки й створює поняття, якщо задано папку.
2. Генерує вміст за назвами придатних нотаток папки понять/вибраної папки, включно з наявними.
3. Виправляє Mermaid у папці complete цієї генерації.

Типовий ланцюжок не досліджує веб. Дослідження під час генерації за назвами можна ввімкнути окремо. [Пакетна обробка](../advanced/batch-processing).

## Як це працює

### Виконання

Кроки йдуть послідовно, панель показує стан і помилки. Скасування зупиняє наступні кроки й підтримувані запити. Готові файли залишаються; спільної транзакції немає. Першою обирається папка понять. Пакетна генерація запам’ятовує джерело й complete; Mermaid використовує complete. Інші дії зберігають вимоги до файла, виділення та взаємодії.

### DSL

Один іменований процес на рядок. `::` відокремлює назву, `>` — ID дій. Порожні рядки та рядки з початковим `#` ігноруються; невідомі ID відхиляються.

```text
Поняття й діаграма::extract-concepts-current>summarize-as-mermaid
```

Скористайтеся конструктором або редагуйте DSL. ID сталі, підписи залежать від UI. Варіанти для папок мають власні ID; не утворюйте їх довільною заміною назв.

| ID | Дія / вимога |
| ------------ | ----------------------- |
| `process-current-add-links` | Посилання в активній нотатці |
| `process-folder-add-links` | Посилання у вибраній папці |
| `extract-concepts-current` | Поняття з активної нотатки |
| `extract-concepts-folder` | Поняття з вибраної папки |
| `generate-from-title` | Вміст за активною назвою |
| `batch-generate-from-titles` | Вміст придатних нотаток папки |
| `research-and-summarize` | Дослідження виділення/назви у відкритому редакторі Markdown |
| `summarize-as-mermaid` | Mermaid-підсумок підтримуваного активного входу |
| `generate-diagram` | Виберіть кілька типів діаграм за один запуск і кілька форматів для кожного типу окремо. Зняття позначки зберігає формати типу; без вибраних типів вміст аналізується автоматично. |
| `preview-diagram` | Перегляд підтримуваного джерела чи діаграми |
| `translate-current-file` | Переклад активного підтримуваного файла |
| `batch-translate-folder` | Переклад вибраної папки |
| `extract-original-text` | Виділення потрібних оригінальних уривків |
| `batch-extract-original-text` | Уривки з придатних файлів папки |
| `split-note-by-chapters` | Поділ активної нотатки на розділи |
| `batch-mermaid-fix` | Виправлення Mermaid-блоків у папці |
| `fix-formula-current` | Нормалізація роздільників формул активної нотатки |
| `batch-fix-formula` | Нормалізація роздільників формул у папці |
| `check-duplicates-current` | Перевірка дублікатів активної нотатки |
| `check-remove-duplicate-concepts` | Інтерактивний огляд і видалення дублікатів понять |
| `test-llm-connection` | Тест налаштованого провайдера |
| `probe-slide-export-env` | Перевірка локального середовища експорту слайдів |
| `export-slides` | Експорт активного файла в слайди |

### Типовий чи власний ланцюжок

One-Click Extract попередньо заданий. Інші кнопки визначайте назвою й порядком та переглядайте опис у панелі. Виправте помилки парсера до використання.

## Параметри

| Параметр | Початкове значення | Вплив |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Зупинка на першій повідомленій помилці кроку |
| `useMultiModelSettings` | `false` | Активний провайдер до ввімкнення маршрутів завдань |
| `enableResearchInGenerateContent` | `false` | Без дослідження за назвами, доки не ввімкнено |

`continue_on_error` дозволяє продовжити після помилки. Використовуйте лише якщо наступні кроки працюють із залишком входів. Продовження не робить частковий процес успішним.

### Модель кожного кроку

Модель належить завданню. Порожнє поле бере модель його провайдера. Перед приватним матеріалом перевірте всі маршрути.

## Приклад

Виберіть порожню `trial-concepts` і тестове джерело. Перевірте поняття й повідомлену папку complete. Якщо ціль неясна, запускайте кроки окремо. Збільшуйте обсяг після перевірки.

## Рекомендації

- Зберігайте зрозумілі ланцюжки для діагностики й походження файлів.
- Дії видалення залишають інтерактивне підтвердження; не додавайте їх до роботи без нагляду.
- Після скасування чи конфлікту читайте журнали та файли.
- Перевіряйте точну модель/папку; тест з’єднання не доводить достатніх квот для великого пакета.
