# Власні запити

<TLDR>Непорожній власний запит замінює вбудований, якщо ввімкнені загальний та відповідний перемикачі. Зберігайте контракт результату: шаблонізація автоматично не поверне пропущених правил формату.</TLDR>

## Огляд

Спочатку перевірте типовий запит на показовій нотатці. Може вистачити тематичного фокуса чи правила синонімів. Власну політику, структуру або стиль перекладу порівняйте перед пакетним застосуванням.

## Як це працює

### Складання

Notemd вибирає вбудовану/власну інструкцію, додає відповідні правила теми/мови та підставляє змінні завдання. Текст нотатки може надсилатися окремо. Змінні не універсальні. Заміна може пропустити `CONCEPT:` або дослідницький контекст; чинний запит не доводить придатності відповіді до парсингу чи її обґрунтованості.

### Змінні

Дотримуйтеся регістру й одинарних фігурних дужок:

| Завдання | Доступні змінні |
| ------ | ----------------------- |
| Генерація за назвами | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Підсумок дослідження | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Переклад | `{LANGUAGE}`, `{TEXT}` |
| Оригінальні уривки | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` відповідає мовній політиці завдання. Посилання та самостійні поняття отримують текст як вміст завдання; не вигадуйте додаткових підстановок. Невідомі назви не заповнюються. Це заміни інструкцій, не шаблони файлів понять.

### Тематичний фокус

Увімкніть цільове навчання й задайте, наприклад, `електротехніка`. `Relevant Fields` спрямовує увагу, але не є жорстким фільтром або доказом вилучення іншого матеріалу.

## Параметри

| Завдання | Перемикач | Поле інструкції |
| ------ | --------------- | -------------- |
| Посилання | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Назви | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Дослідження | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid-підсумок | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Поняття | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Переклад | `useCustomPromptForTranslate` | `translatePrompt` |
| Оригінальний текст | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Усі потребують `enableGlobalCustomPrompts`. Порожній текст використовує вбудований запит. Об’єднане виділення оригінального тексту має власний фіксований формат там, де загальна заміна не діє. Створення діаграм потребує типізованого результату; Mermaid-запит не універсальний.

## Приклад

Увімкніть загальний перемикач і перемикач понять, зберігши маркер парсера:

```text
Виділи головні електротехнічні поняття в нотатці.
Обирай конкретні компоненти й фізичні механізми замість загальних іменників.
Запиши кожне поняття окремим рядком точно так:
CONCEPT: Назва поняття
Не додавай пояснень чи зовнішнього блока коду.
```

На копії порівняйте рядки, назви файлів і пропущені поняття з типовим запитом. Збережіть попередню інструкцію для повернення.

## Рекомендації

- Перевіряйте одне завдання до великого пакета.
- Зберігайте джерела й точні цитати.
- Перекладайте інструкції без змін ID та маркерів.
- Повторіть тест після зміни моделі; інструкція не замінює валідацію.
