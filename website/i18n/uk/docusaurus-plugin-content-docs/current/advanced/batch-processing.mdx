# Пакетна обробка

<TLDR>Дії папок мають спільні вибір і прогрес, але не єдину політику перезапису. Типово одночасно виконується одне завдання. Перевірте малу папку, область і цілі, а потім розширюйте пакет.</TLDR>

## Огляд

Панель і файловий оглядач пропонують посилання, поняття, назви, переклад, оригінальні уривки, Mermaid і формули для папок. Загального окремого дослідження папки немає; воно додається до генерації за назвами. Пакет не є транзакцією папки: готові файли лишаються після помилки чи скасування.

## Як це працює

### Модель виконання

1. Виберіть завдання й папку з потрібними файлами.
2. Розширення, вибір та особливі фільтри результатів визначають кандидатів.
3. Завдання використовує свого провайдера/модель і повідомляє стан, помилки й шляхи.
4. Після завершення чи скасування перевірте звіт і файли до повтору.

Посилання, поняття, назви, оригінальні уривки, Mermaid і формули типово включають вкладені папки. **Переклад папки типово включає лише безпосередні дочірні файли.** Режим розробника й розширені профілі можуть змінити область/фільтри. Перевіряйте фактичний набір.

### Перезапис

| Завдання | Що перевірити перед повтором |
| ------ | ------------------------------------ |
| Посилання | Типово окремий результат; перевірте суфікс, папку й переміщення джерела |
| Поняття | Увімкнені зворотні посилання доповнюють наявні нотатки; дублікати окремо |
| Генерація за назвами | Записує придатні джерела й переміщує за вільної цілі complete |
| Переклад | Може перезаписати переклад; типовий `_<language>.md` |
| Mermaid / формули | Змінює вибрані нотатки; створіть копію й перевірте |

Універсального пропустити/додати/перезаписати немає. Зайнята ціль complete блокує переміщення після генерації, не попередній запис вмісту. Кількість згенерованих і переміщених файлів — різні показники.

### Одночасність

Залиште `batchConcurrency: 1` до успішної вибірки. Деяким шляхам потрібен і `enableBatchParallelism`; переклад папки використовує одночасність прямо. Більше одночасних запитів навантажує провайдера, пам’ять і локальний сервер без гарантії прискорення. Інтервали запитів/груп не усувають усіх квот чи трафіку інших клієнтів облікового запису.

## Параметри

| Параметр | Початкове значення | Вплив |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Бажана одночасність підтримуваних шляхів |
| `enableBatchParallelism` | `false` | Дозволяє підтримуване паралельне планування |
| `batchSize` | `50` | Розмір групи при груповому виконанні |
| `batchInterDelayMs` | `1000` | Пауза між запланованими групами |
| `apiCallIntervalMs` | `500` | Інтервал одночасних API-запитів |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Зберігає правила вкладених папок завдання |
| `enableStableApiCall` | `false` | Явний стабільний режим запитів |

### Моделі завдань

Папка використовує модель відповідної файлової дії. Перевірте приватні маршрути. Локальний контекст пакета назв шукається в одному знімку на початок; проміжні зміни не потрапляють до наступних пошуків. Для їх включення запустіть новий пакет.

## Приклад

Створіть `trial-titles` із двома нотатками-назвами. Запустіть **Пакетна генерація з назв**, перевірте вміст, сусідню `trial-titles_complete` та кількість генерацій/переміщень/помилок. Спочатку дослідіть невдалий файл. Повтор джерельної папки не є автоматичним точним продовженням незавершених елементів.

## Скасування й відновлення

Скасування зупиняє нове планування та підтримувані запити. Зовнішні системи можуть завершити прийняті виклики/записи; оплатою керує провайдер. Дочекайтеся, зіставте завершені файли з шляхами відновлення/конфліктів і лише тоді очищуйте.

## Рекомендації

- Перевіряйте фактичний вибір профілю.
- За 429 зменшуйте одночасність і перевіряйте квоти.
- Розрізняйте скасоване, помилкове й завершене.
- Зберігайте сталу вибірку й резервну копію.
