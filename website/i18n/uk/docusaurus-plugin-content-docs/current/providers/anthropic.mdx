# Anthropic

<TLDR>Профіль призначений для нативного Messages API. Claude через шлюз OpenAI-compatible потребує профілю шлюзу. Історичну початкову модель, можливо, слід замінити доступною.</TLDR>

## Підготовка

Виберіть **Anthropic**, ключ і доступну модель. Зберігайте нативний endpoint, якщо альтернативне розгортання не надає такого самого протоколу. Перевірте з’єднання й нотатку.

## Endpoint та автентифікація

| Поле | Початкове значення |
| ------- | -------------- |
| Транспорт | `anthropic` |
| Ключ API | Обов’язковий |
| Базовий URL | `https://api.anthropic.com` |
| Модель | `claude-3-5-sonnet-20240620` |
| Температура | `0.5` |
| Тест з’єднання | `chat-only` |

Реалізація використовує `/v1/messages` із власними заголовками ключа/версії. Не додавайте шлях OpenAI chat. Початкові значення описують конфігурацію репозиторію, не сьогоднішню доступність.

## Моделі

Використовуйте нативний пошук, де дозволено. Якщо список захищений, укажіть авторизований ID і перевірте генерацію. Довгі чи структуровані завдання потребують окремої проби.

## Проблеми

- 401/403: ключ, проєкт, оплата й права моделі.
- 404: адреса та доступність.
- ID шлюзу відхилено: потрібні відповідні профіль і ID.
- Помилки довгих запитів: перевірте обмеження перед збільшенням повторів.

## Коли підходить

Для нативного Messages. Порівнюйте результати на власних джерелах, не за загальним рейтингом провайдерів. Маршрутизація завдань дозволяє цільове використання.
