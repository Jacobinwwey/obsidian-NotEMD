# Google

<TLDR>Google використовує нативний Gemini Generative Language. Задайте дозволений ключ і доступну модель. Для Gemini через сумісний шлюз оберіть його профіль.</TLDR>

## Підготовка

Виберіть **Google**, ключ, нативний endpoint і модель вибраної версії API. Перевірте з’єднання й нотатку. Профіль не налаштовує автоматично довільне Google Cloud/Vertex розгортання.

## Endpoint та автентифікація

| Поле | Початкове значення |
| ------- | -------------- |
| Транспорт | `google` |
| Ключ API | Обов’язковий |
| Базовий URL | `https://generativelanguage.googleapis.com/v1` |
| Модель | `gemini-2.0-flash-exp` |
| Температура | `0.5` |
| Тест з’єднання | `chat-only` |

Складається запит `generateContent` із ключем. Історичні ID не гарантують доступу. Перед поширенням перегляньте діагностичні URL: вони можуть містити секрети.

## Моделі

Використовуйте пошук провайдера й перевірте генерацію у вибраному API. Порожній список може означати права, неправильний endpoint або відсутню модель. З’ясуйте причину перед зміною протоколу.

## Проблеми

- 400: ID, параметри й обмеження входу/виходу.
- 401/403: обмеження ключа, увімкнення API та права.
- 404: чи є модель у цій версії API?
- Приклад шлюзу: виберіть відповідний OpenAI-compatible профіль.

## Коли підходить

Для нативного Gemini. Переклад, дослідження чи діаграми перевіряйте на власному матеріалі. Загальних гарантій швидкості, ціни чи якості немає.
