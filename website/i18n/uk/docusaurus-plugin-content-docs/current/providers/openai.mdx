# OpenAI

<TLDR>Профіль використовує спільну реалізацію OpenAI Chat Completions. Виберіть ключ і модель для цього протоколу. Початкова модель не гарантує поточного доступу чи універсальної якості.</TLDR>

## Підготовка

Для офіційного сервісу виберіть **OpenAI**, ключ і `https://api.openai.com/v1`. Модель зі списку може потребувати іншого API. Шлюзи мають власні профілі/заголовки; Azure використовує **Azure OpenAI**, deployment і версію API.

## Endpoint та автентифікація

| Поле | Початкове значення |
| ------- | -------------- |
| Транспорт | `openai-compatible` |
| Ключ API | Обов’язковий |
| Базовий URL | `https://api.openai.com/v1` |
| Модель | `gpt-4o` |
| Температура | `0.5` |
| Тест з’єднання | `models-then-chat` |

Відомі варіанти URL нормалізуються до складання шляхів. Почніть із профілю та перевірте кінцеву адресу, а не додавайте випадкові сегменти.

## Моделі

**Fetch models** отримує список. **Перевірити підключення** може пройти лише з ним. Випробуйте точну модель на нотатці. Reasoning, thinking, семплінг і бюджети мають відповідати профілю/моделі.

## Проблеми

- 401/403: ключ, проєкт, права й обліковий запис.
- 404: endpoint, ID моделі та підтримка API.
- Список працює, генерація ні: дослідіть помилку chat і параметри.
- Довга відповідь перервана: вхід, бюджет і тіло відповіді; короткий тест цього не покриває.

## Коли підходить

Для прямих endpoint-ів OpenAI з Chat Completions. Оцінюйте власні нотатки; ціни й доступність змінюються незалежно від Notemd.
