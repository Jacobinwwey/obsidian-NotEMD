# Оновлення до Notemd 1.9.8

<TLDR>1.9.8 поліпшує скасування, належність результатів, узгоджений пошук контексту в пакеті, експорт і документацію. Перевірте доступність у публічному GitHub Release й беріть файли одного випуску. Кількість провайдерів і діаграм описує вже наявні можливості.</TLDR>

## Від 1.9.7

| Область | Зміна |
| ------ | ------------- |
| Скасування | Спільний стан планування, транспорту й повторів; пізня відповідь не починає захищений запис |
| Надійність файлів | Власність однойменних джерел і спільних супровідних файлів за перекриття збережень/відновлень |
| Локальний пошук | Один знімок на пакет назв; сталий корпус і вимірювання пам’яті |
| Експорт у програми | Виправлені роздільники PowerPoint під об’єднаними комірками, проводка й підписи CircuitikZ |
| Перевірка | CI Linux/Windows, lint окремих діагностик, процесні й прикладні докази |
| Документація | Справжні типові значення, чотири входи для читачів, прямі переклади й перевірена публікація |

Пошук історії зберігає безперервне введення й курсор під час асинхронного оновлення. Шухляда утримує Tab усередині, отримує фокус при завантаженні й закривається Escape без закриття головного перегляду. Повтори й застарілі відповіді покриті браузерними тестами.

Дослідження та переклад перевіряють скасування після останнього читання чи підготовки папки й до додавання/створення/перезапису. Прийняті сховищем записи залишаються завершеними. Папка перекладу, створена паралельним завданням, повторно використовується без привласнення її створення. Конфлікт із файлом чи досі відсутня папка зберігають повідомлену помилку й перехід до папки джерела.

36 профілів і 33 виконувані записи діаграм існували вже у 1.9.7. Зміни коду, документів і merge-коміти враховуються окремо.

## Контрольоване оновлення

1. Зупиніть завдання та скопіюйте сховище/налаштування.
2. Оновіть через Community plugins або завантажте `main.js`, `manifest.json`, `styles.css` з одного [публічного 1.9.8](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/tag/1.9.8).
3. Вручну міняйте лише файли виконання, збережіть налаштування й результати.
4. Перезавантажте й перевірте версію.
5. Випробуйте тимчасову нотатку та малу папку перед великими пакетами.

ID команд і налаштування зберігаються. One-Click Extract лишається посиланнями, генерацією за назвами й ремонтом Mermaid. Виправлення документації не додає дослідження до типової послідовності.

## Скасування й відновлення

Скасування — не зворотна транзакція. Готові файли зберігаються, прийняті запити/записи можуть завершитися, оплату контролює провайдер. Дочекайтеся та перевірте. До очищення зіставте видимі конфлікти й файли відновлення. Зберігайте супровідні папки, які використовують старі артефакти.

## Межі експорту й сумісності

- PowerPoint має цільові перевірки в програмі; попередня оцінка цілого зображення пропустила дефект.
- Mermaid/SVG у PPTX можуть бути зображеннями.
- Прикріплення статичних стрілок Drawnix між гілками після перестановки не перевірене.
- Перегляд CircuitikZ і компіляція TeX перевіряються окремо.
- Фізичні мобільні пристрої та Obsidian 0.15.0 лишаються неперевіреними.
- Лексичний пошук на сталому корпусі не доводить семантичного пошуку чи продуктивності кожного сховища.

## Цілісність випуску

Publisher перевіряє версію та ідентичність локального/віддаленого тегу, збирає чисте джерело тегу, завантажує draft-файли й порівнює завантажені назад хеші перед публікацією. Обов’язкові `main.js`, `manifest.json`, `styles.css`, `README.md`. Повтор не може підмінити публічні байти результатом іншого походження.

Pages публікується після перевірки публічного випуску. Codex безпосередньо пише й перевіряє без LM Studio чи рушія перекладу. Незалежна перевірка носієм мови не заявляється.
