# Notemd 1.9.13 — Керування попереднім переглядом та експорт презентацій

<TLDR>
Журнали успішного експорту типово згорнуті. Заблокуйте кожен попередній перегляд, щоб виділяти текст SVG/HTML без переміщення чи масштабування. Виправлено попередній перегляд PNG/PDF та експорт презентацій у кілька форматів. Установлення браузера у Windows перевіряє фактичний запуск і дає час на перший старт. Slidev використовує виправлений форк Jacobinwwey.
</TLDR>

Установіть відповідні main.js, manifest.json і styles.css з версії 1.9.13 та перезавантажте плагін. Наявні нотатки й налаштування збережуться. Замініть старий пакет форку Slidev через інсталятор середовища експорту.
