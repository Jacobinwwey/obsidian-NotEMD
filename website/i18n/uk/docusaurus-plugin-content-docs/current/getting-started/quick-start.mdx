# Перші кроки

<TLDR>Почніть із тестової Markdown-нотатки та доступного провайдера. Перевірте вихідний файл перед обробкою папки. Хмарні завдання надсилають вміст; локальним моделям також потрібні запущений сервер і підготовлена модель.</TLDR>

## 1. Налаштуйте модель

1. [Встановіть і ввімкніть](./installation), відкрийте **Settings → Notemd**.
2. Виберіть профіль, endpoint, потрібні облікові дані й доступну модель. **Fetch models** не замінює перевірку генерації.
3. Запустіть **Перевірити підключення** та виправте проблеми облікового запису, моделі чи адреси.
4. У **Шлях до папки нотаток-концептів** виберіть окрему папку, наприклад `concepts`. Спочатку поле порожнє; назву обираєте ви.

Для Ollama спочатку завантажте модель та вкажіть точну назву; типова адреса `http://localhost:11434/api`. Для LM Studio запустіть сервер і виберіть `LMStudio`. Дивіться [локальні моделі](../providers/local). Вебдослідження потребує мережі навіть із локальною моделлю для підсумку.

## 2. Перше завдання

У `Notemd trial.md` напишіть короткий текст, який дозволено надсилати провайдеру:

```text
Машинне навчання використовує нейронні мережі для розпізнавання закономірностей.
```

Запустіть **Обробити файл (додати посилання)** з панелі чи палітри. Типово джерело зберігається, а поруч створюється `Notemd trial_processed.md`. Відкрийте результат. Приклад:

```markdown
[[Машинне навчання]] використовує [[нейронні мережі]] для розпізнавання закономірностей.
```

У папці понять можуть з’явитися інші нотатки. Перевірте файли й посилання; модель не гарантує повного чи правильного переліку понять.

## 3. Інші завдання

### Виділення понять

**Витягти концепти (поточний файл)** не змінює джерело та потребує папки понять. Нові самостійні нотатки спочатку містять лише назву без зворотного посилання. Увімкніть його явно за потреби. [Нотатки понять](../features/concept-notes).

### Дослідження та підсумок

Виділіть тему в редакторі Markdown або використайте назву та запустіть **Дослідити й підсумувати**. Явно виберіть Tavily з ключем чи DuckDuckGo. Підсумок додається до активної нотатки. Відкрийте джерела й перевірте твердження.

### Один клік

Типовий **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Додає посилання, заповнює придатні нотатки за назвами в папці понять/вибраній папці та виправляє Mermaid у complete. Може охоплювати старі нотатки. Почніть із тестової папки. Вебдослідження й загальне створення діаграм автоматично не додаються.

## Скасування та перевірка

**Скасувати** зупиняє підтримувану подальшу роботу. Завершені результати залишаються; це не відкат і не гарантія зупинки віддаленої генерації чи оплати. Дочекайтеся завершення зупинки, перевірте шляхи та конфлікти відновлення перед повтором.

## Проблеми

- Обліковий запис/модель: перевірте профіль і з’єднання.
- Немає понять: задайте ввімкнену непорожню папку.
- Некорисні посилання: дослідіть відповідь і запит; мінімальна довжина не гарантує результату.
- Ліміти: залиште одночасність `1`, доки перевіряєте квоти.
