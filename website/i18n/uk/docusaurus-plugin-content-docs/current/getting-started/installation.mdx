# Встановлення

<TLDR>Встановіть Notemd через Community plugins або скопіюйте три файли виконання одного випуску до сховища. Увімкніть розширення, налаштуйте провайдера й перевірте одну нотатку. Сервери моделей і додаткові засоби експорту готуються окремо.</TLDR>

## Спосіб 1: Community plugins, рекомендовано

1. У потрібному сховищі відкрийте **Settings → Community plugins**.
2. За потреби дозвольте розширення спільноти та виберіть **Browse**.
3. Знайдіть **Notemd**, перевірте репозиторій `Jacobinwwey/obsidian-NotEMD` і натисніть **Install**.
4. Виберіть **Enable** і відкрийте бічну панель через значок або палітру команд.

[Відкрити Notemd в Obsidian](obsidian://show-plugin?id=notemd). Якщо браузер не передає посилання програмі, скористайтеся меню вище. Для читання документації обробник протоколу не потрібний.

## Спосіб 2: вручну

### Передумови

Потрібні Obsidian і сховище, яке можна безпечно скопіювати. Мінімум `0.15.0` у manifest — декларація сумісності, а не доказ нещодавньої перевірки цієї старої версії.

### Кроки

1. Завантажте `main.js`, `manifest.json` і `styles.css` з одного [випуску GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` — документація, а не обов’язковий файл виконання.
2. Покладіть їх у `<vault>/.obsidian/plugins/notemd/`; змініть шлях, якщо каталог конфігурації інший.
3. Перезавантажте Obsidian та увімкніть розширення.
4. Перевірте версію; не поєднуйте новий manifest зі старим bundle.

## Альтернатива: BRAT

Якщо вже користуєтеся [BRAT](https://github.com/TfTHacker/obsidian42-brat), додайте репозиторій його способом для бета-розширень. Для відтворення помилки зафіксуйте випуск. BRAT — необов’язковий зовнішній засіб.

## Перевірка

Налаштуйте доступну модель, запустіть **Перевірити підключення**, потім виконайте [перші кроки](./quick-start). Список моделей не доводить права генерувати вибраною моделлю; перевірте справжній результат.

## Системні межі

| Область | Межа |
| --------- | ---------- |
| Manifest | Щонайменше Obsidian `0.15.0`; `isDesktopOnly` false |
| Докази перевірки | Дивіться датовані записи; фізичні мобільні пристрої та 0.15.0 наразі не перевірені |
| Хмарна модель | Мережа, авторизований обліковий запис/ключ і доступна модель |
| Локальна модель | Окремо встановлений запущений сервер і завантажена/підготовлена модель |
| Експорт презентацій або схем | Настільні засоби та залежності формату; спочатку перевірте середовище |

Єдиної гарантованої версії ОС для всіх експортерів немає. Перегляд схеми не доводить компіляції TeX, а настільна перевірка — поведінки на телефоні.

## Видалення

Вимкніть або видаліть через Community plugins. Нотатки й створені файли залишаються звичайними файлами сховища. Перевірте їх перед видаленням і за потреби збережіть налаштування. Видалення розширення не скасовує завершених змін.

## Оновлення

Скористайтеся **Check for updates**. Вручну: зупиніть завдання, збережіть сховище/налаштування, замініть три файли одного випуску та перезавантажте. Прочитайте примітки й перевірте невелику вибірку до пакетного запуску. Не замінюйте файл налаштувань файлом дистрибуції. Повернення потребує свідомо вибраної сумісної версії й резервної копії.
