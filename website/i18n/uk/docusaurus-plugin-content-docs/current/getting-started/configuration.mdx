# Налаштування

<TLDR>Відкрийте Settings → Notemd і знайдіть потрібне поле. Виберіть провайдера й місце результату до запуску. Перевіряйте зміни на одній нотатці; запущене завдання може зберігати початкові налаштування.</TLDR>

## Огляд

Початковий провайдер — DeepSeek із порожніми обліковими даними. Вибір профілю не створює облікового запису, не встановлює моделі й не надає прав. Дивіться [провайдери](../providers/overview).

## Пошук та обране

**Search settings** шукає назви, описи, псевдоніми й видимі категорії та переходить до поля. **★ Favorites** показує збережені параметри з описом, категорією та місцем. Вони зберігаються окремо для сховища після перезапуску; застарілі ID очищуються. Запит не зникає при згортанні панелі. Список обраного відрізняється від фільтра пошуку лише в обраному.

**Diagram preview export PPI** типово має 300, діапазон 72–600 і впливає лише на PNG. SVG/PDF зберігають підтримувану векторну геометрію. **Also export complete Mermaid visuals** керує супровідними файлами, а не показом Mermaid у перегляді Drawnix.

## 1. Провайдер

Укажіть endpoint потрібного протоколу, обов’язковий ключ і доступну модель. Список і генерацію перевіряйте окремо. Локальний сервер/модель мають бути готові; хмара та шлюз отримують вміст. Перед приватними даними перевірте й маршрути окремих завдань.

## 2. Моделі для завдань

`useMultiModelSettings` дозволяє окремі профілі/моделі для посилань, назв, дослідження, перекладу, понять, оригінальних уривків і Mermaid. Порожня модель бере модель провайдера; якщо опцію вимкнено, використовується активний профіль. На однаковій нотатці порівняйте точність, затримку й фактичну вартість.

## 3. Результати

| Завдання | Типовий результат |
| ------ | ------------------------- |
| Додавання посилань | Окремий `_processed.md` поруч; переміщення оригіналу вимкнено |
| Самостійне виділення понять | Вибрана папка понять; лише назва, без зворотного посилання |
| Переклад | Поруч як `_<language>.md`; наявний файл може перезаписуватися |
| Дослідження | Підсумок додається до активної Markdown-нотатки |
| Пакетна генерація за назвами | Записує придатні джерела й переміщує до сусідньої `<folder>_complete`, якщо ціль дозволяє |
| Перегляд/експорт діаграм | Виберіть підтримуване джерело чи візуальний експорт і перевірте повідомлений шлях |

Папка понять спочатку порожня; `concepts` — приклад. Самостійні поняття мають мінімальну/повну форму, а не загальний рушій шаблонів. [Поняття](../features/concept-notes). Обробка та переклад мають власні суфікси/папки. Перевірте конфлікти; скасування не відкочує завершені записи.

## 4. Мови

Інтерфейс має 21 локалізацію, сайт — 34 мовні маршрути. `uiLocale: auto` вибирає підтримувану відповідність, інакше англійську. Мова генерації окрема, типово англійська; підтримувані завдання можуть перевизначати її. Переклад використовує `language`. Кількість мов не доводить мовної здатності моделі.

## 5. Пошук

Явно виберіть Tavily з ключем чи DuckDuckGo. Порожній ключ не перемикає сервіс. Обидва використовують мережу; DuckDuckGo може завантажувати сторінки результатів. Дослідження під час генерації за назвою вимкнене: `enableResearchInGenerateContent`. Локальний пошук також вимкнений і має власні межі папок/завдань. Додані локальні уривки надсилаються вибраному LLM.

## 6. Робочі процеси

Скористайтеся конструктором або одним іменованим рядком DSL на кнопку:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` відокремлює назву від дій, `>` — ID дій. Типово процес зупиняється на повідомленій помилці. Дивіться [процеси](../features/workflows) про контекст і продовження після помилок.

## 7. Додаткові значення

| Параметр | Початкове значення | Вплив |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Провайдер без окремого маршруту завдання |
| `useMultiModelSettings` | `false` | Провайдер/модель для кожного завдання |
| `useCustomConceptNoteFolder` | `true` | Дозволяє файли понять після вибору папки |
| `conceptNoteFolder` | `''` | Папку понять не вибрано |
| `extractConceptsMinimalTemplate` | `true` | Лише назва в самостійних поняттях |
| `extractConceptsAddBacklink` | `false` | Зворотні посилання самостійного виділення |
| `moveOriginalFileOnProcess` | `false` | Збереження джерела під час додавання посилань |
| `chunkWordCount` | `3000` | Приблизний розмір частини, не ліміт токенів |
| `batchConcurrency` | `1` | Початкова кількість одночасних завдань пакета |
| `enableBatchParallelism` | `false` | Паралельне планування там, де використовується перемикач |
| `enableStableApiCall` | `false` | Явний стабільний режим запитів |
| `customWorkflowErrorStrategy` | `stop_on_error` | Зупинка процесу на повідомленій помилці |

Розмір частини тексту не дорівнює бюджету вихідних токенів. Менші частини не розв’язують усіх обмежень контексту, а мала одночасність не запобігає кожному 429.

## Профілі налаштувань

Налаштування — дані розширення у сховищі. Збережіть їх перед змінами. Експорт провайдерів має окремий контракт вилучення секретних полів, це не повна резервна копія. Очищені профілі можуть містити приватні endpoint-и й метадані. Не публікуйте сирих налаштувань або діагностики з приватними нотатками.

## Проблеми налаштувань

Перевірте точний профіль/модель на малій нотатці. Якщо поля немає, перевірте пошук, категорію, видимість у режимі розробника й активне сховище. Повідомте версію та мінімальні налаштування без секретів.
