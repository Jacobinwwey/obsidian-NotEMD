# Omat kehotteet

<TLDR>Ei-tyhjä oma kehote korvaa oletuksen, kun yleinen ja tehtäväkohtainen kytkin ovat päällä. Säilytä tulossopimus: mallipohjajärjestelmä ei automaattisesti palauta pois jätettyjä muoto-ohjeita.</TLDR>

## Yleiskuva

Kokeile ensin oletusta edustavalla muistiinpanolla. Aihealue- tai synonyymiohje voi riittää. Muuta rakennetta, käytäntöä tai käännöstyyliä tarvittaessa ja vertaa ennen eräajoa.

## Toiminta

### Koostaminen

Notemd valitsee oletus-/oman kehotteen, lisää soveltuvat aihealue-/kieliohjeet ja korvaa tehtävän antamat muuttujat. Muistiinpano voi kulkea erillisessä viestissä. Muuttujat eivät ole yleisiä. Korvaava kehote voi unohtaa `CONCEPT:`-muodon tai tutkimuskontekstin; kelvollinen pyyntö ei todista jäsennettävää tai perusteltua tulosta.

### Muuttujat

Käytä täsmällistä kirjainkokoa ja yksinkertaisia aaltosulkeita:

| Tehtävä | Saatavilla olevat muuttujat |
| ------ | ----------------------- |
| Otsikkogenerointi | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Tutkimusyhteenveto | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Käännös | `{LANGUAGE}`, `{TEXT}` |
| Alkuperäiskatkelmat | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` seuraa tehtävän kielisääntöä. Linkitys ja erillinen käsitepoiminta lähettävät tekstin tehtäväsisältönä; älä keksi lisämuuttujia. Tuntemattomia nimiä ei korvata. Nämä ovat kehotevaihtoja, eivät käsitetiedostojen mallipohjia.

### Rajattu aihealue

Ota kohdennettu oppiminen käyttöön ja anna esimerkiksi `sähkötekniikka`. `Relevant Fields` ohjaa huomion, ei pakota suodatinta tai todista ulkopuolisen sisällön poistamista.

## Asetukset

| Tehtävä | Kytkin | Kehotekenttä |
| ------ | --------------- | -------------- |
| Linkit | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Otsikot | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Tutkimus | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid-yhteenveto | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Käsitteet | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Käännös | `useCustomPromptForTranslate` | `translatePrompt` |
| Alkuperäisteksti | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Kaikki edellyttävät `enableGlobalCustomPrompts`-asetusta. Tyhjä teksti käyttää oletusohjetta. Yhdistetyllä alkuperäistekstipoiminnalla on oma kiinteä muoto, johon tavallinen ohitus ei ulotu. Kaaviogenerointi vaatii tyypitetyn vastauksen; Mermaid-kehote ei ole yleiskäyttöinen.

## Esimerkki

Ota yleinen ja käsitepoiminnan kytkin käyttöön ja säilytä jäsennysmerkki:

```text
Poimi muistiinpanon tärkeimmät sähkötekniikan käsitteet.
Suosi konkreettisia komponentteja ja fysikaalisia mekanismeja yleisten substantiivien sijaan.
Kirjoita kukin käsite omalle rivilleen täsmälleen tässä muodossa:
CONCEPT: Käsitteen nimi
Älä lisää selityksiä tai ympäröivää koodilohkoa.
```

Vertaa kopiolla rivejä, tiedostonimiä ja puuttuvia käsitteitä oletusajoon. Säilytä aiempi kehote palautusta varten.

## Vinkit

- Testaa yksi tehtävä ennen suurempaa erää.
- Säilytä tutkimuslähteet ja tarkat lainaukset.
- Käännä ohjeet mutta säilytä tunnisteet ja tulosmerkit.
- Testaa mallinvaihdon jälkeen; ohje ei takaa validointia.
