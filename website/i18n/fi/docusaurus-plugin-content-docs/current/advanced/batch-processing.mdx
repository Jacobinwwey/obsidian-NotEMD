# Eräajo

<TLDR>Kansiotoiminnot jakavat valinnan ja edistymisraportoinnin, mutta eivät samoja ylikirjoitussääntöjä. Oletusrinnakkaisuus on yksi. Kokeile pientä testikansiota, tarkista rajaus ja kohteet, laajenna sitten.</TLDR>

## Yleiskuva

Sivupaneeli/tiedostoselain tarjoaa linkit, käsitteet, otsikot, käännökset, alkuperäiskatkelmat sekä Mermaid-/kaavakorjaukset kansioille. Yleistä tutkimuskansiotoimintoa ei ole; otsikkogenerointi voi lisätä tutkimuksen. Eräajo ei ole kansiotransaktio: valmiit tulokset säilyvät virheissä ja peruutuksessa.

## Toiminta

### Suoritusmalli

1. Valitse tehtävä ja vain halutut tiedostot sisältävä kansio.
2. Päätteet, valinta ja tehtäväkohtaiset tulossuodattimet määräävät ehdokkaat.
3. Tehtävä käyttää omaa tarjoajaansa/malliaan ja raportoi tilan, virheet ja polut.
4. Tarkista raportti ja tuotokset päättymisen/peruutuksen jälkeen ennen uusintaa.

Linkit, käsitteet, otsikot, alkuperäiskatkelmat, Mermaid ja kaavat sisältävät oletuksena alikansiot. **Kansiokäännös käsittelee oletuksena vain suorat lapset.** Kehittäjätila ja tiedostovalinnan lisäprofiilit voivat muuttaa rajausta ja suodattimia. Tarkista todelliset osumat.

### Ylikirjoittaminen

| Tehtävä | Tarkistus ennen uusintaa |
| ------ | ------------------------------------ |
| Linkit | Erillinen oletustulos; tarkista oma jälkiliite, kansio ja lähteen siirto |
| Käsitteet | Paluulinkit voivat täydentää nykyisiä tiedostoja; duplikaatit käsitellään erikseen |
| Otsikkogenerointi | Kirjoittaa sopiviin lähteisiin ja siirtää, jos complete-kohde on vapaa |
| Käännös | Nykyinen käännös voi korvautua; oletus `_<language>.md` |
| Mermaid / kaavat | Muokkaa valittuja muistiinpanoja; tarkista ja varmuuskopioi |

Yhteistä ohita/lisää/korvaa-vaihtoehtoa ei ole. Varattu complete-kohde estää siirron, ei sitä edeltävää generointia. Generoidut ja siirretyt lasketaan erikseen.

### Rinnakkaisuus

Pidä `batchConcurrency: 1`, kunnes otos toimii. Osa reiteistä vaatii myös `enableBatchParallelism`; kansiokäännös käyttää rinnakkaisuutta suoraan. Lisärinnakkaisuus kuormittaa tarjoajaa, muistia ja paikallista palvelinta eikä takaa nopeutta. Pyyntö-/ryhmävälit eivät poista kaikkia kiintiöitä tai saman tilin muuta käyttöä.

## Asetukset

| Asetus | Alkuarvo | Vaikutus |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Pyydetty rinnakkaisuus soveltuvilla reiteillä |
| `enableBatchParallelism` | `false` | Ota tuettu rinnakkaisajastus käyttöön |
| `batchSize` | `50` | Ryhmäkoko eräajastuksessa |
| `batchInterDelayMs` | `1000` | Tauko ajastettujen ryhmien välillä |
| `apiCallIntervalMs` | `500` | Samanaikaisten API-pyyntöjen väli |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Säilytä kunkin tehtävän oma alikansiokäytäntö |
| `enableStableApiCall` | `false` | Erikseen valittu vakaa pyyntötila |

### Tehtävämallit

Kansiotoiminto seuraa vastaavan tiedostotehtävän mallivalintaa. Tarkista reitit ennen yksityistä aineistoa. Paikallinen konteksti käyttää otsikkoerässä yhtä aloitushetken tilannekuvaa: ajon aikana tehdyt muutokset eivät sekoitu myöhempiin hakuihin. Aloita uusi erä niiden mukaan saamiseksi.

## Esimerkki

Luo `trial-titles` ja kaksi otsikkomuistiinpanoa. Suorita **Batch generate from titles** ja tarkista sisältö, viereinen `trial-titles_complete` sekä generoitujen/siirrettyjen/virheiden määrät. Selvitä epäonnistunut tiedosto ensin. Lähdekansion uusinta ei automaattisesti jatka juuri keskeneräistä työtä.

## Peruutus ja palautuminen

Peruutus estää uuden ajastuksen ja tuetut pyynnöt. Ulkoinen järjestelmä voi viimeistellä hyväksytyt pyynnöt/kirjoitukset; tarjoaja päättää laskutuksesta. Odota, vertaa tuloksia palautus-/ristiriitapolkuihin ja poista palautustiedostot vasta tarkistettuasi ne.

## Vinkit

- Tarkista profiilin todellinen tiedostovalinta.
- Vähennä rinnakkaisuutta ja selvitä kiintiöt 429-virheessä.
- Erota peruutettu, epäonnistunut ja valmis.
- Säilytä muuttamaton näyte ja varmuuskopio.
