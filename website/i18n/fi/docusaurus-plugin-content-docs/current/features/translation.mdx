# Kääntäminen

<TLDR>Notemd kääntää aktiivisen tiedoston tai sopivat kansiotiedostot valitulla LLM:llä. Oletustulos on erillinen kielijälkiliitteinen tiedosto. Laatu riippuu mallista; käyttöliittymän 21 ja sivuston 34 kieltä eivät rajaa tai takaa käännöskykyä.</TLDR>

## Yleiskuva

Valitse tuloskieli ja tarjoaja. Testaa kopiolla ammattitermit, linkit ja koodi. Toiminto käyttää valittua LLM:ää, ei erillistä Google Translate -integraatiota. Komennot koskevat tiedostoja/kansioita. Siirrä yksittäinen katkelma tilapäiseen muistiinpanoon; valinta ei rajaa **Translate current file** -toimintoa.

## Toiminta

### Käännöstehtävä

1. Valitse kohdekieli; aluksi englanti, erillään UI-kielestä.
2. Avaa lähde ja suorita **Translate current file**.
3. Pitkä teksti jaetaan, lähetetään mallille ja yhdistetään.
4. Avaa raportoitu polku ja tarkista merkitys, termit, lainaukset, Markdown-linkit ja koodi.

`Example.md` kääntyy ranskaksi oletuksena viereiseen `Example_fr.md`-tiedostoon, alkuperäinen säilyy. Nykyinen tulos korvataan. Lähteeseen lisääminen tai vakio-otsikko `Translation` eivät ole oletuslupauksia.

### Kieliparit

Malli päättelee lähdekielen. Valikon kieli ei todista kieliparin tarkkuutta. Testaa sekakieli ja erikoistermit; osiin jako voi kadottaa kontekstia.

### Tehtäväkohtainen malli

Reititys käyttää `translateProvider`/`translateModel`, muuten aktiivista tarjoajaa. Paikallinen malli edellyttää palvelinta; pilvi saa kehotteen ja sisällön. Arvioi omaa alakohtaista esimerkkiä yleisen rankingin sijaan.

### Kansion kääntäminen

**Batch translate folder** ottaa oletuksena vain suorat lapset; lisäprofiilit voivat muuttaa rajausta. Samannimiset lähteet samassa tuloskansiossa voivat törmätä. Tarkista vanhat käännökset ja kohteet ennen uusintaa.

## Asetukset

| Asetus | Alkuarvo | Vaikutus |
| --------- | --------- | -------- |
| `language` | `en` | Valittu kohdekieli |
| `translateProvider` | `DeepSeek` | Tarjoaja tehtäväkohtaisen reitityksen ollessa päällä |
| `translateModel` | `''` | Tyhjä käyttää tarjoajan mallia |
| `useCustomTranslationSuffix` | `false` | Kielikoodi oletusjälkiliitteenä |
| `translationCustomSuffix` | `_translated` | Jälkiliite oman vaihtoehdon ollessa päällä |
| `useCustomTranslationSavePath` | `false` | Oletuksena lähteen viereen |
| `translationSavePath` | `''` | Oma holvisuhteinen tuloskansio |
| `batchConcurrency` | `1` | Pyydetty rinnakkaisuus kansiokäännöksessä |

Jos omaa kansiota ei voi luoda, toiminto voi käyttää lähdekansiota. Lue todellinen polku. Tyhjä oma jälkiliite voi osoittaa lähdetiedostoon; käytä erottuvaa jälkiliitettä erilliselle käännökselle.

## Esimerkki

Kopioi lyhyt kiinankielinen muistiinpano testikansioon, valitse englanti ja käännä tiedosto. Vertaa `_en.md`:n termejä, numeroita, kaavoja ja linkkejä lähteeseen. Laajenna vasta sitten.

## Peruutus ja tarkistus

Peruutus pysäyttää tuetun jatkotyön, ei aiempia käännöksiä tai taatusti laskutusta. Tarkista raportti ja tiedostot. Markdownin säilyminen on malliohje, ei jäsentimen takaama merkitysvastaavuus.

## Vinkit

- Varmuuskopioi lähde ja tarkista nimiristiriidat.
- Erillinen testijälkiliite ja tuloskansio.
- Tarkista koodi, matematiikka, URL:t ja erisnimet.
- Tarkista diagnostiikka ennen jakamista.
