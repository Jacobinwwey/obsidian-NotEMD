# Anthropic

<TLDR>Käytä profiilia natiiviin Messages-rajapintaan. OpenAI-yhteensopivan yhdyskäytävän Claude käyttää yhdyskäytävän profiilia. Historiallinen alkumalli voi vaatia korvaamista saatavilla olevalla mallilla.</TLDR>

## Valmistelu

Valitse **Anthropic**, avain ja käytettävä malli. Säilytä natiivi osoite, ellei oma käyttöönotto tarjoa samaa protokollaa. Testaa yhteys ja muistiinpano.

## Osoite ja tunnistautuminen

| Kenttä | Alkuarvo |
| ------- | -------------- |
| Siirtoprotokolla | `anthropic` |
| API-avain | Pakollinen |
| Perusosoite | `https://api.anthropic.com` |
| Malli | `claude-3-5-sonnet-20240620` |
| Lämpötila | `0.5` |
| Yhteystesti | `chat-only` |

Ajopolku käyttää `/v1/messages`-reittiä natiiveine avain-/versio-otsakkeineen. Älä lisää OpenAI-chat-reittiä. Alkuarvot kuvaavat repositorion asetuksia, eivät tämänhetkistä mallisaatavuutta.

## Mallit

Käytä natiivia löytämistä, jos sallittu. Jos lista estetään, anna sallittu tunniste ja testaa generointi. Pitkät ja rakenteiset tehtävät vaativat omat tarkistuksensa.

## Ongelmat

- 401/403: avain, projekti, laskutus ja mallioikeudet.
- 404: osoite ja saatavuus.
- Yhdyskäytävän tunniste hylätään: oikea profiili ja nimi.
- Pitkät virheet: selvitä rajat ennen lisäuusintoja.

## Milloin käyttää

Natiiveille Messages-osoitteille. Vertaa tuloksia omiin lähteisiin yleisen paremmuusjärjestyksen sijaan. Tehtäväreititys sallii kohdennetun käytön.
