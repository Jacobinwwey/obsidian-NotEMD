# OpenAI

<TLDR>Profiili käyttää yhteistä OpenAI Chat Completions -ajopolkua. Valitse protokollan avain ja malli. Alkuarvo ei takaa nykyistä pääsyä tai yleistä laatua.</TLDR>

## Valmistelu

Käytä viralliselle palvelulle **OpenAI**-profiilia, avainta ja osoitetta `https://api.openai.com/v1`. Listattu malli voi tarvita eri API:n. Yhdyskäytävillä on omat profiilit/otsakkeet; Azure käyttää **Azure OpenAI** -profiilia, deploymentia ja API-versiota.

## Osoite ja tunnistautuminen

| Kenttä | Alkuarvo |
| ------- | -------------- |
| Siirtoprotokolla | `openai-compatible` |
| API-avain | Pakollinen |
| Perusosoite | `https://api.openai.com/v1` |
| Malli | `gpt-4o` |
| Lämpötila | `0.5` |
| Yhteystesti | `models-then-chat` |

Tunnetut URL-muodot normalisoidaan ennen reittien koostamista. Aloita profiilista ja tarkista lopullinen osoite sen sijaan, että lisäät polkuosia arvaamalla.

## Mallit

**Fetch models** pyytää saatavilla olevat mallit. **Test connection** voi onnistua pelkällä listalla. Tarkista täsmällinen malli muistiinpanolla. Reasoning, thinking, otanta ja budjetit on sovitettava profiiliin/malliin.

## Ongelmat

- 401/403: avain, projekti, oikeudet ja tili.
- 404: osoite, mallitunniste ja API-tuki.
- Lista toimii, generointi ei: chat-virhe ja parametrit.
- Pitkä vastaus katkeaa: syöte, budjetti ja vastaus; lyhyt testi ei kata tätä.

## Milloin käyttää

Suorille OpenAI-osoitteille, jotka tukevat Chat Completionsia. Arvioi oma aineisto; hinnat ja saatavuus muuttuvat Notemdistä riippumatta.
