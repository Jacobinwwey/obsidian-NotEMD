# Google

<TLDR>Google käyttää natiivia Gemini Generative Language -rajapintaa. Aseta sallittu avain ja käytettävä malli. Yhteensopivan yhdyskäytävän Gemini käyttää yhdyskäytäväprofiilia.</TLDR>

## Valmistelu

Valitse **Google**, avain, natiivi osoite ja valitun API-version malli. Testaa yhteys ja muistiinpano. Tämä ei määritä mielivaltaista Google Cloud-/Vertex-käyttöönottoa automaattisesti.

## Osoite ja tunnistautuminen

| Kenttä | Alkuarvo |
| ------- | -------------- |
| Siirtoprotokolla | `google` |
| API-avain | Pakollinen |
| Perusosoite | `https://generativelanguage.googleapis.com/v1` |
| Malli | `gemini-2.0-flash-exp` |
| Lämpötila | `0.5` |
| Yhteystesti | `chat-only` |

Pyyntö käyttää `generateContent`-reittiä ja avainta. Historiallinen tunniste ei takaa pääsyä. Tarkista diagnostiikka-URL:t ennen jakamista: ne voivat sisältää tunnistetietoja.

## Mallit

Käytä natiivia hakua ja varmista generointi valitulla API:lla. Tyhjä lista voi kertoa oikeuksista, osoitteesta tai puuttuvasta mallista. Selvitä syy ennen protokollan vaihtoa.

## Ongelmat

- 400: tunniste, parametrit ja syöte-/vastausrajat.
- 401/403: avainrajoitukset, aktivoitu API ja oikeudet.
- 404: onko malli saatavilla tässä API-versiossa?
- Yhdyskäytäväesimerkit: käytä oikeaa OpenAI-yhteensopivaa profiilia.

## Milloin käyttää

Natiiville Geminille. Testaa käännös, tutkimus tai kaaviot omalla aineistolla. Ei yleisiä nopeus-, kustannus- tai laatutakuita.
