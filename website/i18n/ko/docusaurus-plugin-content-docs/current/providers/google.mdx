# Google provider

<TLDR>Google 프로필은 네이티브 Gemini Generative Language를 사용합니다. 허용된 키와 사용 가능한 모델을 설정하세요. 호환 gateway의 Gemini에는 gateway 프로필을 사용합니다.</TLDR>

## 준비

**Google**, 키, 네이티브 endpoint와 해당 API 버전의 모델을 선택하고 연결/실제 노트를 시험합니다. 임의의 Google Cloud나 Vertex deployment를 자동 구성하는 프로필은 아닙니다.

## Endpoint와 인증

| 항목 | 초기 값 |
| ------- | -------------- |
| 전송 프로토콜 | `google` |
| API 키 | 필수 |
| 기본 URL | `https://generativelanguage.googleapis.com/v1` |
| 모델 | `gemini-2.0-flash-exp` |
| 온도 | `0.5` |
| 연결 시험 | `chat-only` |

키를 사용해 `generateContent` 요청을 만듭니다. 초기 ID는 현재 지원을 보장하지 않습니다. 진단 URL에 인증 정보가 있을 수 있으므로 공유 전에 확인하세요.

## 모델

네이티브 목록과 선택 API의 생성을 확인합니다. 빈 목록은 권한·endpoint·모델 문제일 수 있습니다. 진단 없이 프로토콜부터 바꾸지 마세요.

## 문제 해결

- 400: ID·파라미터·token/출력 한도.
- 401/403: 키 제한·API 활성화·권한.
- 404: 해당 API 버전에서 모델 지원 확인.
- gateway 예제: 대응하는 OpenAI-compatible 프로필 사용.

## 적합한 용도

네이티브 Gemini용입니다. 번역·연구·도표를 자신의 표본으로 평가하세요. 속도·비용·품질에 대한 범용 보장은 없습니다.
