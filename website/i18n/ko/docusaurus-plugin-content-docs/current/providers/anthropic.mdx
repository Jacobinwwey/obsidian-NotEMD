# Anthropic provider

<TLDR>이 프로필은 네이티브 Messages용입니다. OpenAI-compatible gateway를 통해 Claude를 쓰면 gateway 프로필을 선택하세요. 초기의 역사적 모델명은 교체가 필요할 수 있습니다.</TLDR>

## 준비

**Anthropic**, 키와 접근 가능한 모델을 선택합니다. 같은 프로토콜의 별도 deployment가 아니라면 네이티브 endpoint를 유지하고 작은 노트로 시험하세요.

## Endpoint와 인증

| 항목 | 초기 값 |
| ------- | -------------- |
| 전송 프로토콜 | `anthropic` |
| API 키 | 필수 |
| 기본 URL | `https://api.anthropic.com` |
| 모델 | `claude-3-5-sonnet-20240620` |
| 온도 | `0.5` |
| 연결 시험 | `chat-only` |

`/v1/messages`와 네이티브 키/버전 header를 사용합니다. OpenAI chat 경로를 넣지 마세요. 표는 저장소의 초기 설정이지 현재 가용성 약속이 아닙니다.

## 모델

가능하면 네이티브 모델 목록을 사용합니다. 목록 접근이 제한되면 허용된 ID로 생성 시험을 하세요. 긴 작업과 구조화 출력은 별도로 검증합니다.

## 문제 해결

- 401/403: 키·프로젝트·과금·권한.
- 404: endpoint와 현재 모델.
- gateway ID 거부: 프로필/식별자를 맞춥니다.
- 긴 요청 실패: 재시도 확대 전 한도와 오류를 확인합니다.

## 적합한 용도

Messages 네이티브 endpoint에 사용합니다. 동일한 원문으로 결과를 비교하며 보편적 순위를 가정하지 마세요. 작업별 경로로 필요한 곳에만 선택할 수 있습니다.
