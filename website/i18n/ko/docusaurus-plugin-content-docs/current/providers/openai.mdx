# OpenAI provider

<TLDR>OpenAI 프로필은 공통 OpenAI Chat Completions 호환 runtime을 사용합니다. 해당 프로토콜을 받는 모델과 키를 선택하세요. 초기 모델은 현재 접근권이나 보편적 품질을 보장하지 않습니다.</TLDR>

## 준비

공식 서비스는 **OpenAI**, 키, `https://api.openai.com/v1`을 설정합니다. 목록에 있어도 다른 API 전용 모델이면 호환되지 않을 수 있습니다. gateway는 자신의 프로필/header를, Azure는 **Azure OpenAI**와 deployment/API 버전을 사용하세요.

## Endpoint와 인증

| 항목 | 초기 값 |
| ------- | -------------- |
| 전송 프로토콜 | `openai-compatible` |
| API 키 | 필수 |
| 기본 URL | `https://api.openai.com/v1` |
| 모델 | `gpt-4o` |
| 온도 | `0.5` |
| 연결 시험 | `models-then-chat` |

runtime은 알려진 URL 형태를 정규화해 경로를 구성합니다. 프로필에서 시작해 해석된 주소를 확인하고 임의로 경로를 덧붙이지 마세요.

## 모델

**Fetch models**는 목록을 요청합니다. **연결 테스트**은 목록만으로 성공할 수 있으므로 정확한 모델로 노트를 시험하세요. 추론·thinking·샘플링·출력 한도는 모델/프로필 규칙에 맞춰야 합니다.

## 문제 해결

- 401/403: 키·프로젝트·권한·계정.
- 404: endpoint·ID·API 호환성.
- 목록 성공 후 생성 실패: chat 오류와 파라미터.
- 긴 응답 중단: 입력/출력 예산과 실제 응답을 확인합니다. 짧은 시험은 전부를 검증하지 않습니다.

## 적합한 용도

Chat Completions를 지원하는 OpenAI 직접 endpoint에 사용하세요. 실제 노트로 평가합니다. 가격과 모델 가용성은 Notemd와 독립적으로 바뀝니다.
