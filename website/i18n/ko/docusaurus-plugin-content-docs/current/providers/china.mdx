# 중국 provider

<TLDR>계정과 deployment에 맞는 프로필을 선택하세요. 같은 OpenAI-compatible 프로토콜이어도 지역·경로·모델·권한을 서로 바꿔 쓸 수는 없습니다. 작은 실제 작업으로 확인합니다.</TLDR>

## 준비

계정과 키를 준비하고 프로필·지역·모델 권한을 확인하세요. 초기 값은 현재 가용성 보장이 아닙니다. 연결 성공 후 노트를 시험합니다.

## Endpoint와 인증

| 프로필 | 초기 모델 | 초기 URL |
| -------- | --------------- | ------------------ |
| DeepSeek | `deepseek-v4-pro` | `https://api.deepseek.com` |
| Qwen | `qwen3-235b-a22b` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Qwen Code | `qwen3-coder-plus` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |

Doubao 예시는 실제 Ark endpoint ID나 지원 모델로 바꾸세요. GLM과 Z AI는 다른 지역 프로필입니다. 다른 지역/요금제의 키는 호환되지 않을 수 있습니다. 물리적 위치만으로 판단하지 말고 계정 안내를 따르세요.

## 모델

허용되는 목록을 사용합니다. Huawei Cloud MaaS는 deployment에 맞추고 다른 프로필은 지원되는 호환 목록을 사용합니다. 목록 권한이 없어도 명시적 모델 생성은 가능할 수 있습니다. DeepSeek 연결 시험은 목록만으로 통과할 수 있고 일부 지역 프로필은 짧은 생성을 합니다. 실제 작업 검증은 필요합니다.

## 문제 해결

- 키는 통과하지만 생성 거부: 모델 권한·deployment·지역.
- Ark ID 거부: endpoint와 모델 중 요구 형식 확인.
- 추론 잘림: 예산·모델별 thinking 설정.
- 네트워크: Obsidian 장치에서 endpoint와 전송 오류 확인.

## 적합한 용도

접근권, 가용성과 데이터 요구에 맞을 때 선택하세요. 지리적 분류로 언어 품질이나 비용을 추정하지 말고 설정을 기록한 표본으로 비교합니다.
