# Notemd 소개

<TLDR>Notemd는 MIT 라이선스 Obsidian 플러그인으로 위키 링크 Markdown, 개념 노트, 연구 요약, 번역과 도표를 파일로 만듭니다. provider·작업·출력 범위를 선택하고 생성 결과를 검토한 뒤 지식 기반에 보관하세요.</TLDR>

## Notemd란?

Vault 작업을 클라우드 API, gateway, 로컬 서버를 포함한 36개 프로필에 연결합니다. 각 작업의 계약에 따라 파일을 만들거나 노트를 수정하며 단독 실행 또는 사이드바 체인이 가능합니다. 출력은 Vault에 남지만 클라우드 provider는 작업 내용을 받습니다. 웹 연구도 네트워크를 사용합니다. 로컬 저장과 로컬 추론은 별도 선택입니다.

## 주요 기능

### 위키 링크와 개념

모델에 개념 선택과 링크를 요청합니다. 기본 링크 출력은 별도 파일입니다. 개념 폴더를 선택해야 파일을 만들며 독립 추출의 기본은 제목만, 역링크 없음입니다. [링크](./features/wiki-links)와 [개념](./features/concept-notes)을 비교하세요.

### 연구와 로컬 문맥

Tavily/DuckDuckGo 결과를 요약해 활성 노트에 추가합니다. 범위가 있는 로컬 발췌를 선택적으로 제공할 수 있습니다. 현재 색인은 어휘 기반이며 embedding 의미 검색이 아닙니다. [연구](./features/research).

### 번역과 원문 추출

파일·폴더를 번역하거나 질문에 해당하는 원문 구절을 추출합니다. 인용은 원문과 대조하세요. 편집기의 선택 영역이 파일 번역을 선택 번역으로 바꾸지는 않습니다. [번역](./features/translation).

### 도표와 내보내기

도표 종류와 호환 원본 형식을 선택하고 미리본 뒤 원본/시각 export를 저장합니다. 실행 카탈로그는 33개입니다. 원본 형식과 export 형식은 다릅니다. [도표](./features/diagrams).

### 워크플로

기본 **One-Click Extract**는 링크, 개념/선택 폴더의 적격 노트 제목 생성, complete 폴더 Mermaid 복구입니다. 기존 개념 노트도 포함할 수 있습니다. 각 동작의 요구와 출력은 유지됩니다. [정확한 DSL](./features/workflows).

## 시작하기

1. 원하는 Vault에 [설치](./getting-started/installation)합니다.
2. 접근 가능한 모델로 임시 노트를 시험합니다.
3. 개념 폴더와 출력 목적지를 확인합니다.
4. 결과를 검토한 뒤 배치를 늘립니다.

고정 처리 시간이나 유용한 출력을 보장하는 최소 길이는 없습니다. 직접 검토할 수 있는 크기로 시작하세요.

## 도표 지원 방향

타입이 있는 명세와 대상별 renderer를 사용합니다. `DiagramSpec`는 모든 문법/배치를 지원한다는 약속이 아닙니다. `circuitikz`는 지원 구조로 한정됩니다. 외부 TikZJax나 네이티브 컴파일 성공은 미리보기로 증명하지 않습니다. Drawnix의 정적 가지 간 화살표는 재배치 후 연결 유지가 보장되지 않습니다.

## 구조

작업을 선택 provider로 보내고 출력을 분석/검증해 노트 또는 산출물로 씁니다. 검색과 로컬 검색은 선택 문맥이며 preview/export에는 형식별 제한이 있습니다. [개발자](./developers/overview)는 소유 모듈과 검증, [Agent](./agents/overview)는 제한된 공개 export를 안내합니다. 내부 registry는 범용 공개 자동화 API가 아닙니다.

## 도구 비교 {#notemd-vs-other-obsidian-ai-plugins}

파일 변환·대화·결정적 연결·검색·네이티브 편집 중 필요한 작업을 기준으로 고르세요. 각 프로젝트의 현재 문서를 보고 동일 표본, 버전, 활성 기능을 기록해 비교합니다.

## 데이터와 호환성

클라우드는 작업 입력, 검색 provider는 query, LLM은 활성화된 로컬 발췌를 받습니다. 작업별 경로를 확인하세요. 취소는 지원 후속 작업을 중지하나 완료 출력과 원격 생성/과금은 남을 수 있습니다.

manifest는 최소 Obsidian `0.15.0`과 모바일 로드를 선언하지만 해당 버전과 실제 모바일 기기는 현재 검증되지 않았습니다. 선택적 네이티브 export는 desktop 도구가 필요할 수 있습니다. 웹 언어 경로 34개, UI 21개, 모델 번역 능력은 별개입니다.
