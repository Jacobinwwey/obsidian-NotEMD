## 질문

### 어떻게 설치하나요?

Settings → Community plugins → Browse에서 Notemd를 찾아 설치하고 활성화합니다. 수동 설치는 같은 GitHub Release의 main.js, manifest.json, styles.css를 사용합니다. 최소 선언은 Obsidian 0.15.0이지만 그 버전과 실제 모바일 기기는 현재 검증되지 않았습니다.

### 어떤 LLM provider를 지원하나요?

36개 프로필이 OpenAI-compatible, Anthropic, Google, Azure OpenAI, Ollama 다섯 계열을 사용합니다. 클라우드·gateway·로컬은 각각 endpoint, 인증과 모델이 필요합니다. 프로필이나 목록은 현재 가용성이나 생성 권한을 보장하지 않습니다.

### 로컬 모델을 쓸 수 있나요?

Ollama, LM Studio, OVMS나 실행 중인 호환 endpoint를 사용할 수 있습니다. 모델을 준비하고 실제 작업을 시험하세요. 로컬 추론이 웹 검색, 의존성 설치나 별도로 cloud에 보내는 작업까지 오프라인으로 만들지는 않습니다.

### ChatGPT와 어떻게 다른가요?

Notemd는 Obsidian 문서에 명시적 파일 작업을 수행합니다. 링크·개념·연구 추가·번역·도표 중 필요한 Vault 작업으로 판단하세요. 현재 저장·내보내기·통합 능력을 비교해야 하며 채팅 도구도 기록 저장과 문서 생성을 할 수 있습니다.

### Copilot이나 Smart Connections와 비교하려면?

현재 버전·설정·문서와 같은 작업으로 비교하세요. Notemd는 노트 변환과 범위가 있는 어휘 검색을 제공하며 범용 Vault 채팅이나 embedding 의미 검색은 아닙니다. 다른 프로젝트의 현재 기능 순위를 주장하지 않습니다.

### 어떤 검색 엔진을 사용하나요?

키가 있는 Tavily 또는 DuckDuckGo를 명시적으로 고릅니다. 빈 Tavily 키가 자동 전환하지 않습니다. 둘 다 네트워크를 사용합니다. LLM이 웹 및 선택적 로컬 문맥을 요약해 활성 Markdown 노트에 추가합니다. URL과 중요한 주장은 직접 확인하세요.

### 몇 개 언어를 지원하나요?

UI는 21개 locale, 사이트는 34개 언어 경로입니다. 생성 언어는 별도이며 지원 작업에는 개별 언어 설정이 있습니다. 번역 품질과 가능 여부는 모델에 달려 있고 이 개수로 증명되지 않습니다.

### 논문이나 PDF도 사용할 수 있나요?

적합한 외부 도구로 먼저 Markdown으로 변환하고 수식·표·그림을 검토하세요. 이후 개념·원문 추출·연구·번역·도표 작업을 적용합니다. 네이티브 PDF OCR이나 모든 바이너리 문서의 정확한 추출을 약속하지 않습니다.
