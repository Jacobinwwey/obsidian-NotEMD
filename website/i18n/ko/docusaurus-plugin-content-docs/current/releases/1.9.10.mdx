# Notemd 1.9.10 — 안전한 미리보기와 Vault별 로컬 설정

<TLDR>
가져온 SVG 미리보기는 활성 콘텐츠와 외부 리소스를 제거하면서 중국어 라벨과 패널 스타일을 보존합니다. 기기 전용 공급자는 Vault별로 분리됩니다. 설정에서 이전 목록을 명시적으로 가져오면 원래 목록과 기존 구성이 보존됩니다. 프레젠테이션은 공유 사용자의 수명을 관리하는 loopback 서버를 사용합니다. 즐겨찾기 저장과 복사 실패를 알리며 삭제는 Vault 환경설정을 따릅니다. PNG 호환성은 기본으로 켜져 있습니다. 요청한 원본을 보존하고 필요할 때만 검증된 낮은 PPI 사본을 추가합니다. Drawnix 관계에 고정 상한은 없으며 프레젠테이션 설정은 별도로 유지됩니다. 같은 버전의 파일을 설치하고 다시 로드한 뒤 일괄 처리 전에 노트 하나를 테스트하세요.
</TLDR>
