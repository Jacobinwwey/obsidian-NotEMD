# 배치 처리

<TLDR>폴더 작업은 선택/진행 UI를 공유하지만 출력과 덮어쓰기 방식은 다릅니다. 기본 동시성은 1입니다. 전용 시험 폴더에서 실제 범위와 목적지를 확인한 뒤 확장하세요.</TLDR>

## 개요

사이드바나 파일 탐색기 메뉴를 사용합니다. 링크, 개념, 제목 생성, 번역, 원문 추출, Mermaid/수식 복구를 지원합니다. 범용 폴더 연구는 없고 제목 생성에 선택적으로 연구를 추가합니다. 폴더 전체 트랜잭션이 아니므로 다른 파일이 실패/취소되어도 완료 출력은 남습니다.

## 동작 방식

### 실행 모델

1. 작업과 의도한 파일만 있는 폴더를 선택합니다.
2. 확장자·선택 규칙에 따라 적격 파일을 수집하고 작업별 출력을 제외합니다.
3. 작업의 provider/모델로 실행해 진행·실패·목적지를 보고합니다.
4. 종료 또는 취소 후 보고서와 파일을 검토한 뒤 재실행합니다.

링크, 개념, 제목, 원문, Mermaid/수식 작업은 기본적으로 하위 폴더를 포함하지만 **폴더 번역은 바로 아래 파일만** 포함합니다. 개발자 모드와 고급 파일 선택을 모두 켜면 선택 프로필이 범위/필터를 바꿀 수 있습니다. 모든 작업의 재귀 범위가 같다고 가정하지 마세요.

### 덮어쓰기

| 작업 | 재실행 전 확인 |
| ------ | ------------------------------------ |
| 링크 | 기본 별도 출력; 접미사·폴더·원본 이동 설정 확인 |
| 개념 | 켜진 경우 기존 노트에 역링크 추가; 중복 검사는 별도 |
| 제목 생성 | 적격 원본에 내용을 쓰고 complete 대상이 비어 있으면 이동 |
| 번역 | 일치하는 번역 대상 덮어쓰기 가능; 기본 `_<language>.md` |
| Mermaid/수식 | 선택 노트 직접 수정; 표본과 백업 보관 |

공통 건너뛰기/추가/교체 스위치는 없습니다. 제목 배치의 complete 대상이 존재하면 이동을 막지만 이미 수행한 생성까지 건너뛴 것은 아닙니다. 생성 수와 이동 수를 구분하세요.

### 동시성

대표 표본이 성공할 때까지 `batchConcurrency: 1`을 유지하세요. 일부 경로는 `enableBatchParallelism`도 필요하지만 번역은 동시성 설정을 직접 사용합니다. 병렬화는 provider·메모리·서버 부하를 늘리며 속도를 보장하지 않습니다. 요청 간격과 그룹 지연도 공유 계정의 모든 요청/token 한도를 예방하지는 못합니다.

## 설정

| 설정 | 초기 값 | 효과 |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | 해당 배치 경로에서 요청할 동시성 |
| `enableBatchParallelism` | `false` | 지원 경로의 병렬 스케줄링 |
| `batchSize` | `50` | 그룹 스케줄링의 크기 |
| `batchInterDelayMs` | `1000` | 해당 그룹 사이 지연 |
| `apiCallIntervalMs` | `500` | 동시 요청 스케줄링 간격 |
| `folderTaskIncludeSubfoldersMode` | `legacy` | 작업별 기존 하위 폴더 범위 유지 |
| `enableStableApiCall` | `false` | 명시적 안정 요청 모드 |

### 배치의 작업별 모델

관련 단일 파일 작업과 같은 경로를 사용합니다. 개인정보 처리 전 확인하세요. 제목 배치의 선택적 로컬 검색은 시작 시 한 스냅샷을 사용해 실행 중 편집을 뒤쪽 결과에 섞지 않습니다. 편집을 포함하려면 새 배치를 시작합니다.

## 예시

제목 노트 두 개만 있는 `trial-titles`에서 **제목에서 일괄 생성**를 실행합니다. 생성 내용과 형제 `trial-titles_complete`, 생성/이동/오류 수를 검토하세요. 실패 파일을 먼저 진단합니다. 원래 폴더의 재실행이 미완료 작업만 자동 재개하는 것은 아닙니다.

## 취소와 복구

취소는 새 작업을 중지하고 지원 요청으로 전파됩니다. 외부 시스템이 이미 받은 호출/쓰기와 과금은 끝날 수 있습니다. 종료 후 완료 파일과 복구/충돌 경로를 대조하기 전에는 삭제하지 마세요.

## 권장 사항

- 선택 프로필의 실제 매칭 파일을 확인하세요.
- 429는 동시성과 할당량을 점검하세요.
- 취소·실패·완료를 구분하세요.
- 기존 파일 수정 전 원본 표본과 백업을 유지하세요.
