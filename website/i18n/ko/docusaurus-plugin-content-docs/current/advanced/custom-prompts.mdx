# 사용자 prompt

<TLDR>전체 스위치와 작업 스위치가 켜져 있고 사용자 문구가 비어 있지 않으면 기본 prompt를 교체합니다. 누락한 형식 지시를 자동 복원하지 않으므로 작업의 출력 계약을 직접 유지하세요.</TLDR>

## 개요

대표 노트로 기본 prompt부터 시험하세요. 집중 학습이나 동의어 억제로 충분할 수 있습니다. 추출 기준·구조·번역 문체가 필요할 때 바꾸고 배치 전에 비교합니다.

## 동작 방식

### 구성

선택된 기본/사용자 prompt에 필요한 분야·언어 지시를 추가하고 해당 작업이 제공한 변수를 치환합니다. 본문은 별도 메시지로 전달될 수도 있습니다. 작업마다 입력이 다릅니다. 교체하면서 `CONCEPT:`나 연구 문맥을 빼면 정상 요청이어도 파싱 또는 근거가 실패할 수 있습니다.

### 변수

대문자 이름과 단일 중괄호를 그대로 사용하세요:

| 작업 | 제공 변수 |
| ------ | ----------------------- |
| 제목 생성 | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| 연구 요약 | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| 번역 | `{LANGUAGE}`, `{TEXT}` |
| 원문 추출 | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}`는 작업 언어 정책을 따릅니다. 링크와 독립 개념 추출은 본문을 내용으로 보내므로 존재하지 않는 변수를 만들지 마세요. 알 수 없는 이름은 채워지지 않으며 개념 파일 템플릿과도 다릅니다.

### 집중 분야

집중 학습과 `전기공학` 같은 분야를 설정하면 `Relevant Fields` 지시가 들어갑니다. 모델의 주의를 유도할 뿐 강제 필터가 아닙니다.

## 설정

| 작업 | 활성 스위치 | prompt 필드 |
| ------ | --------------- | -------------- |
| 링크 | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| 제목 | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| 연구 | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid 요약 | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| 개념 | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| 번역 | `useCustomPromptForTranslate` | `translatePrompt` |
| 원문 | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

모두 `enableGlobalCustomPrompts`가 필요합니다. 빈 문구는 기본값을 사용합니다. 병합 원문 추출은 별도 내장 형식이고 일반 override를 공유하지 않습니다. 도표 생성은 형식별 계약이 있으므로 Mermaid 요약 prompt가 범용 도표 prompt는 아닙니다.

## 예시

전체/개념 스위치를 켜고 파서 표식을 유지하세요:

```text
주어진 노트에서 핵심 전기공학 개념을 추출하세요.
일반 명사보다 구체적인 부품과 물리적 원리를 우선하세요.
개념마다 다음 형식 한 줄로 출력하세요:
CONCEPT: 용어 이름
설명이나 바깥 코드 블록은 추가하지 마세요.
```

복사 노트에서 항목·파일명·누락을 기본 prompt와 비교합니다. 되돌릴 수 있도록 이전 문구를 보관하세요.

## 권장 사항

- 한 작업씩 시험하고 범위를 검증한 후 배치를 늘리세요.
- 연구 근거와 원문 인용을 보존하세요.
- 번역해도 ID와 출력 표식은 유지하세요.
- 모델 변경 후 재검증하세요. 지시는 검증 보장이 아닙니다.
