# 개념 노트

<TLDR>독립 추출은 원문을 읽고 지정한 폴더에 Markdown 개념 파일을 만듭니다. 폴더 설정은 처음에 비어 있고 새 노트는 기본적으로 제목만 있으며 역링크가 없습니다. 링크 추가는 다른 개념 형식을 사용합니다.</TLDR>

## 개요

먼저 **개념 노트 폴더 경로**를 설정하세요. 전용 폴더는 출력·중복 검토·후속 제목 생성 범위를 확인하기 쉽습니다. 추출은 파일 생성이며 연구된 설명을 자동으로 채우지 않습니다.

## 동작 방식

### 추출 과정

LLM에 내용을 보내 `CONCEPT:` 항목을 분석하고 작업 내부 이름을 중복 제거해 파일을 생성/갱신합니다. 긴 노트는 분할됩니다. 실패한 청크와 누락을 확인하세요. 모델 응답은 완전한 개념 목록이 아닙니다.

### 추출 prompt

기본 prompt는 주제 관련 구체적 개념을 요청합니다. 집중 학습과 동의어 억제는 표준 어휘를 보장하지 않습니다. 사용자 prompt도 `CONCEPT: Term` 형식을 유지해야 합니다. [사용자 prompt](../advanced/custom-prompts).

### 청크

`chunkWordCount` 기본값은 3000으로 단어 기반 근사치이며 provider의 token 예산과 다릅니다. 청크 간 문맥이 제한되므로 연관 용어와 모호한 이름을 검토하세요.

## 파일 생성

### 파일 이름

금지 경로 문자를 제거하고 공백을 정규화하며 긴 이름을 줄입니다. 빈 결과는 건너뜁니다. 서로 다른 문구가 같은 파일명이 될 수 있으므로 대량 생성 전 확인하세요.

### 형식

새 독립 노트의 기본 형식:

```markdown
# 개념 이름
```

새 파일에 역링크를 넣으려면 **Add "Linked From" backlink**를 켜고 **Create minimal concept notes**를 끄세요:

```markdown
# 개념 이름

## Linked From
- [[원본 노트]]
```

링크 추가는 폴더 출력이 켜지면 역링크를 포함한 전체 형식 개념 파일을 만듭니다. 독립 추출 스위치는 그 동작을 바꾸지 않습니다.

### 기존 노트 갱신

역링크를 켜면 기존 내용은 유지하면서 `## Linked From`에 없는 원본 링크를 추가할 수 있습니다. 같은 역링크를 반복 추가하지 않습니다. 원본 basename을 사용하므로 같은 이름의 원본이 여러 폴더에 있으면 검토하세요.

### 설정

| 설정 | 초기 값 | 효과 |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | 폴더를 설정하면 개념 출력 허용 |
| `conceptNoteFolder` | `''` | 처음에는 폴더 없음 |
| `extractConceptsMinimalTemplate` | `true` | 독립 추출 노트는 제목만 생성 |
| `extractConceptsAddBacklink` | `false` | 독립 추출 역링크 활성화 |
| `extractConceptsProvider` | `DeepSeek` | 작업별 모델 설정을 켰을 때 provider |
| `extractConceptsModel` | `''` | 비어 있으면 해당 provider 모델 |
| `extractConceptsLanguage` | `en` | 작업별 언어를 켰을 때 출력 언어 |
| `replaceSynonymsDuringConceptExtraction` | `false` | 동의어 억제 지시 추가 |
| `generateConceptLogFile` | `false` | 개념 로그 생성 선택 |

## 중복 검토

파일명 휴리스틱은 대소문자, 복수형, 기호 정규화 및 허용 범위의 단일 단어 포함 관계를 사용합니다. 의미 동등성 증거가 아니므로 불규칙 복수형과 다른 기술적 의미를 직접 검토하세요. **중복 확인 및 제거**에서 삭제할 후보만 승인하면 Obsidian 휴지통 동작을 사용합니다. 개념 폴더는 캐시가 아니므로 정리 전에 백업하세요.

### 비교 범위

Vault, 개념 폴더 자체, 포함 폴더 또는 제외 폴더를 둔 범위를 비교할 수 있습니다. 승인 전 선택을 확인하세요. 범위는 후보를 바꾸지만 중복의 의미를 바꾸지는 않습니다.

## 사용법

### 독립 개념 추출

Markdown 노트와 폴더를 확인하고 **개념 추출 (현재 파일)**을 실행합니다. 원문은 유지됩니다. 파일명·개념 범위·선택적 역링크를 확인하세요.

### 추출 후 설명 생성

개념 폴더에서 **제목에서 일괄 생성**를 실행하면 기존 적격 노트도 처리될 수 있습니다. 폴더 내용을 먼저 검토하고 complete 목적지를 확인하세요.

### 선택 영역으로 위키 링크 생성

직접 고른 용어를 링크로 감싸고 설정된 목적지에 개념 노트를 만들 수 있습니다. 전체 원문에서 모델이 용어를 고르는 동작과 구분하세요.

## 권장 사항

- 작은 원문과 전용 폴더로 시작하세요.
- 대량 생성 전 언어를 정하세요.
- 동의어 제안과 중복 후보를 별도로 검토하세요.
- 다음 실행이 덮어쓸 수 있는 필요한 로그를 보관하세요.
