# 번역

<TLDR>활성 파일이나 폴더의 적격 파일을 설정한 LLM으로 번역합니다. 기본 출력은 언어 접미사가 붙은 별도 파일입니다. 언어 품질은 모델에 달려 있으며 UI 21개와 사이트 34개 locale은 번역의 한계나 보장이 아닙니다.</TLDR>

## 개요

언어와 provider를 먼저 선택하고 용어·링크·코드가 있는 복사 노트로 시험하세요. 선택한 LLM을 사용하며 Google Translate 전용 통합은 아닙니다. 파일/폴더 동작이므로 한 구절만 번역하려면 임시 노트에 복사하세요. 선택 영역은 **현재 파일 번역** 범위를 줄이지 않습니다.

## 동작 방식

### 번역 명령

1. UI와 별도인 출력 언어를 선택합니다. 기본은 영어입니다.
2. 원본에서 **현재 파일 번역**을 실행합니다.
3. 긴 내용을 나눠 provider/모델로 보내고 응답을 합칩니다.
4. 보고된 출력에서 의미·용어·인용·Markdown 링크·코드를 대조합니다.

기본 설정으로 `Example.md`를 프랑스어로 번역하면 원본 옆 `Example_fr.md`가 생깁니다. 원본은 보존하지만 기존 출력은 덮어씁니다. 원문에 추가하거나 `Translation` 제목을 넣는 것이 기본 동작은 아닙니다.

### 언어 쌍

모델이 원문 언어를 추론합니다. 메뉴에 언어가 있어도 해당 언어 쌍의 정확도를 증명하지 않습니다. 혼합 언어와 전문 용어를 검토하세요. 분할로 청크 간 문맥을 잃을 수 있습니다.

### 작업별 모델

작업별 모델을 켜면 `translateProvider`/`translateModel`, 아니면 활성 provider를 사용합니다. 로컬은 실행 서버와 모델이 필요하고 클라우드는 prompt와 내용을 받습니다. 일반 순위보다 분야별 표본으로 판단하세요.

### 폴더 번역

**폴더 일괄 번역**에서 범위를 확인합니다. 기본은 바로 아래 파일만이며 고급 선택 프로필로 바뀔 수 있습니다. 같은 이름의 원본을 단일 사용자 출력 폴더로 보내면 충돌할 수 있습니다. 재실행 전 목적지와 기존 번역을 확인하세요.

## 설정

| 설정 | 초기 값 | 효과 |
| --------- | --------- | -------- |
| `language` | `en` | 목표 출력 언어 |
| `translateProvider` | `DeepSeek` | 작업별 설정을 켰을 때 번역 provider |
| `translateModel` | `''` | 비어 있으면 해당 provider 모델 |
| `useCustomTranslationSuffix` | `false` | 기본은 언어 코드 접미사 |
| `translationCustomSuffix` | `_translated` | 사용자 접미사를 켰을 때 값 |
| `useCustomTranslationSavePath` | `false` | 기본은 원본 옆 저장 |
| `translationSavePath` | `''` | Vault 상대 출력 폴더 |
| `batchConcurrency` | `1` | 요청한 폴더 번역 동시성 |

사용자 폴더를 만들 수 없으면 원본 폴더로 돌아갈 수 있으므로 보고된 실제 경로를 확인하세요. 빈 사용자 접미사는 원본 이름을 가리킬 수 있습니다. 별도 번역을 원하면 구분되는 접미사를 사용하세요.

## 예시

짧은 중국어 노트를 시험 폴더에 복사하고 영어 출력으로 파일 번역을 실행합니다. `_en.md`를 원문 옆에서 열어 용어·숫자·수식·링크를 확인한 다음 폴더로 확장하세요.

## 취소와 검토

지원되는 후속 작업을 멈추지만 이미 쓴 번역이나 원격 과금을 되돌리지 않습니다. 보고서와 파일을 확인하세요. Markdown 보존 지시는 요청이지 파서 수준 의미 동등성 보장이 아닙니다.

## 권장 사항

- 원본을 백업하고 이름 충돌을 확인하세요.
- 시험에는 별도 접미사/폴더를 사용하세요.
- 코드 식별자, 수학 표기, URL, 고유명사를 확인하세요.
- 진단 공유 전 비공개 내용을 제거하세요.
