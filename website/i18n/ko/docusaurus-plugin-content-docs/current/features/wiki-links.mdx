# 위키 링크

<TLDR>Process file (add links)는 선택한 LLM에 개념 식별과 Obsidian 위키 링크 삽입을 요청합니다. 기본 출력은 별도 `_processed.md`이며 원본은 유지합니다. 개념 파일은 폴더를 선택해야 생성됩니다. 폴더 전체 실행 전 결과를 검토하세요.</TLDR>

## 개요

내용의 의미를 바탕으로 후보 링크를 제안합니다. 실행마다 용어가 달라지거나 아직 없는 개념을 가리킬 수 있습니다. 링크는 탐색 대상이지 개념의 동등성이나 설명의 정확성을 증명하지 않습니다.

## 동작 방식

### 처리 과정

노트를 청크로 나누어 provider/모델로 보내고 응답을 합쳐 처리 파일을 씁니다. 설정된 폴더에 개념 파일을 생성하거나 갱신할 수 있습니다. 부분 실패와 실제 경로는 진행 보고서로 확인하세요.

### 예시

원문:

```text
기계 학습 모델은 신경망으로 예제의 패턴을 학습합니다.
```

가능한 출력:

```markdown
[[기계 학습]] 모델은 [[신경망]]으로 예제의 패턴을 학습합니다.
```

이는 예시이며 실제 용어는 원문·모델·prompt에 따라 달라집니다.

## 사용법

### 현재 노트에 링크 추가

복사한 Markdown 노트에서 **파일 처리 (링크 추가)**를 실행하고 기본 형제 `_processed.md`를 확인합니다. 접미사, 처리 폴더와 원본 이동 설정은 경로 동작을 바꿉니다.

### 여러 노트 처리

**폴더 처리 (링크 추가)**에서 폴더와 범위를 확인하고 작은 표본으로 시작하세요. 모든 폴더 작업이 공유하는 덮어쓰기/건너뛰기 스위치는 없습니다. [배치](../advanced/batch-processing)를 읽고 재실행하세요.

### 선택한 용어 연결

**Create wiki link and generate note from selection**은 직접 고른 용어를 위한 별도 동작입니다. 파일 전체 링크 작업을 선택 영역으로 제한하는 지시가 아닙니다. 생성 노트와 내용을 확인하세요.

## 연결 방식 선택

내용에서 개념 후보를 찾을 때 모델 방식이 유용합니다. 기존 노트 이름에 대해 재현성이 중요하면 결정적 제목 매칭을 고려하세요. 다른 플러그인은 현재 문서와 날짜가 있는 동일 표본으로 비교합니다.

## 기능

### 동의어 억제

`replaceSynonymsDuringConceptExtraction`은 동의어나 겹치는 개념을 줄이라는 지시를 추가합니다. 기본 꺼짐인 불리언 설정이며 수치 유사도 임계값이 아닙니다. 약어와 유사어는 직접 검토하세요.

### 링크 무결성

이름 변경 시 링크 갱신은 Obsidian의 설정과 사용한 동작에 속합니다. 대상 삭제로 남은 미해결 위키 링크는 링크되지 않은 언급과 다릅니다. 다른 폴더의 같은 basename도 확인하세요.

### 독립 추출

원문을 다시 쓰지 않고 개념 파일만 만들려면 **개념 추출 (현재 파일)**을 사용합니다. 최소 형식과 역링크 설정은 링크 추가와 다릅니다. [개념 노트](./concept-notes).

## 개념 파일 생성

### 자동 생성

폴더 출력이 켜져 있고 경로가 정해지면 제목과 `Linked From` 역링크가 있는 노트를 만들 수 있습니다. 조사된 설명, 관련 개념 절이나 범용 frontmatter 템플릿은 자동 생성하지 않습니다. 내용 확장은 제목 생성을 별도로 실행하세요.

### 설정

개념 폴더, 처리 폴더, 링크 접미사, 원본 이동 옵션을 검색하세요. 개념 폴더 초기 값은 비어 있습니다. 시험 중에는 원본과 목적지를 구분하세요.

## 고급 옵션

### 문맥과 prompt

`chunkWordCount`는 대략적 청크 크기입니다. 집중 학습과 사용자 prompt로 주제를 좁힐 수 있습니다. 문장/문단 문맥 선택기, 최소 출현 횟수, 범용 개념 템플릿 변수는 문서화된 기능이 아닙니다.

## 권장 사항

- 인용문·수식·코드를 원문과 대조합니다.
- 연결 용어에 개념 노트가 필요한지 검토합니다.
- 고정 표본에서 prompt를 비교합니다.
- 원본 이동이나 기존 대상 재실행 전에 백업합니다.

## 성능

지연과 비용은 provider, 모델, prompt/출력 길이와 재시도에 좌우됩니다. 노트당 시간이나 100개당 비용을 고정 보장하지 않습니다. 표본과 실제 사용량을 측정하세요.

## 문제 해결

### 링크가 없음

요청 결과·모델 응답·처리한 원문·보고된 출력 파일을 확인합니다. 유용한 링크를 보장하는 최소 단어 수는 없습니다.

### 링크가 너무 많음

prompt나 집중 학습으로 범위를 좁히세요. 동의어 억제는 지시이지 강제 어휘집이 아닙니다.

### 이름 변경 후 링크 오류

Obsidian 링크 갱신 설정과 기존 모호성을 확인하고 대상을 복구하세요. LLM 재실행은 결정적 링크 복구가 아닙니다.
