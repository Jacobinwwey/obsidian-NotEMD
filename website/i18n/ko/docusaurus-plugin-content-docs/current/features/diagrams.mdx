# 도표

<TLDR>먼저 필요한 도표 종류, 다음에 편집 가능한 원본 형식을 선택하세요. Obsidian에서 Drawnix 보드와 포함된 Mermaid를 함께 검토하고 각 패널을 SVG·PNG·PDF로 내보냅니다.</TLDR>

## 세 가지 선택

| 선택 | 결정하는 것 | 예시 |
| --- | --- | --- |
| 도표 종류 | 도표의 의미 | 흐름·시퀀스·회로·데이터 차트 |
| 원본 형식 | 편집/재사용할 파일 | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| 내보내기 형식 | 공유할 이미지나 문서 | SVG, PNG, PDF |

Draw.io/Drawnix는 종류가 아니라 원본 형식입니다. CircuitikZ는 회로용 source이며 선택했다고 시각 export가 SVG로만 제한되지는 않습니다.

## 원본 형식

| 형식 | 용도 | 원본 파일 |
| --- | --- | --- |
| Mermaid | Markdown 안의 도표 | Mermaid 코드 블록 |
| JSON Canvas | Obsidian 네이티브 canvas | `.canvas` |
| Draw.io | diagrams.net 또는 호환 editor에서 편집 | `.drawio` |
| Drawnix | 손그림/화이트보드 방식 편집 | `.drawnix` |
| CircuitikZ | 구조화된 전기·트랜지스터 회로 | `.tex` |

특정 editor가 필요 없으면 **Preferred source format: Auto**를 유지해 종류에 맞는 형식을 사용하세요.

## 생성과 내보내기

1. 지원되는 원문 노트를 엽니다. 한 구절은 별도 노트로 만드세요. 선택 영역은 파일 동작을 제한하지 않습니다.
2. 종류 또는 **Auto-detect**를 선택합니다.
3. 원본 형식 또는 **Auto**를 선택합니다. Drawnix는 편집 노드와 Mermaid 포함 지식 맵을 지원합니다.
4. **다이어그램 생성**을 실행합니다.
5. 하나의 세로 scroll shell에서 보드와 source 순서의 Mermaid 패널을 검토합니다. 패널은 실제 렌더 높이를 사용합니다.
6. 패널별 **SVG 내보내기**, **PNG 내보내기**, **Export PDF** 또는 상단 전체 export를 선택합니다. 여러 패널은 원문 폴더/사용자 Vault 상대 폴더에 결정적 이름으로 각각 저장하며 개별 실패 후 계속합니다.
7. 편집 원본이 필요하면 **소스 파일 저장**을 사용합니다.

Export 메뉴와 패널 머리글에서 같은 세 형식을 제공합니다. **History** drawer로 미리보기를 유지한 채 검색·필터·재열기·저장 파일 열기가 가능합니다. 활성 노트 없이도 팔레트/사이드바에서 히스토리를 엽니다.

SVG/PDF는 벡터 기하를 사용하며 PDF는 SVG 배치/문자 치수를 재사용합니다. PNG PPI는 72–600, 기본 300이고 벡터 출력에는 영향을 주지 않습니다.

## 밀도 높은 도표

HTML/SVG lane-grid는 요약을 먼저 측정하고 줄바꿈하여 title/header 공간을 확보합니다. 셀 후 connector/label을 그리며 직교 경로가 차지한 셀과 label 영역을 피해 텍스트가 가려지지 않게 합니다.

`quadrantChart`는 전용 정규화를 사용해 flowchart용 따옴표/shape 복구를 건너뜁니다. 점 label 끝의 대응 없는 복사 괄호만 제거하며 제목·축·분면의 의도된 괄호는 유지합니다.

[예제 집합](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples)은 영어/중국어 입력, SVG/PNG와 manifest를 보관합니다. `passed`는 기록된 실행/bundle에 대한 것이지 후속 릴리스의 모든 종류를 새로 시험한 결과가 아닙니다. 실행 목록 33개, UI locale 21개와 웹 34개는 별개입니다. 다섯 정확한 참조 문법은 독립 배치 증거 전까지 선택기에 없습니다.

## Mermaid를 포함한 Drawnix

렌더 SVG를 정제하고 Mermaid 원문을 `.drawnix` 메타데이터에 보관하여 Drawnix/Plait runtime 없이 표시합니다. 기본은 자체 완결형으로 `.assets`를 만들지 않습니다. **Also export complete Mermaid visuals**를 켜면 source·SVG·manifest companion을 추가합니다. 이전 `.assets`도 지원하며 없는 SVG는 보관된 source로 복구할 수 있습니다.

가능하면 image embed에 data-backed SVG를 사용합니다. embedded data, 이전 companion, source 재생성 순으로 로드합니다. 참조 중인 기존 파일은 보존하세요. 새 자체 완결형 export는 공유된 예전 폴더가 불필요함을 증명하지 않습니다.

하나의 scroll surface에서 보드 다음 Mermaid 패널을 원본 순으로 배치하며 히스토리 재열기도 같은 목록·치수·동작을 복원합니다. 제목·요약·관계 label 공간을 예약하고 지원되는 읽기 쉬운 배치가 불가능하면 형식 오류를 보고합니다. 가지 간 화살표는 정적 관계로 저장되며 Drawnix 재배치 후 부착은 지원 증거가 없습니다. 실제 editor에서 확인하세요.

## 네이티브 export 경계

원본과 시각 export는 별도 결과입니다. 배포 전 대상 앱에서 표본을 시험하세요. PowerPoint는 지원되는 편집 표 구조와 병합 아래 교정 구분선을 보존하지만 Mermaid/SVG는 이미지일 수 있습니다. preview나 전체 페이지 screenshot 점수는 native 검증을 대신하지 않습니다.

## 회로

**Circuit diagram**과 **CircuitikZ source file**을 고르면 구조 설명부터 만든 뒤 source로 출력합니다. 무제한 LaTeX 요청보다 범위가 분명합니다. 지원은 제한적이며 common-source NMOS와 지원 CMOS 블록을 중심으로 합니다. 기술/출판용 사용 전 source와 preview를 검토하세요.

SVG는 검토 보조물이며 로컬 LaTeX/TikZJax 컴파일 성공의 증거가 아닙니다. preview·SVG·PNG·preview PDF에는 LaTeX가 필요 없습니다. desktop에서 native PDF/진단이 필요하면 **CircuitikZ native compile environment**를 엽니다. 시스템 `tectonic`/`pdflatex`, 사용자 실행 파일 또는 명시적 **Install** 후 고정된 관리형 Tectonic을 사용합니다. 패널에 진행/오류와 관리형 제거 기능이 있습니다.

## 문제 해결

### 도표 종류가 틀림

자동 감지 대신 종류를 정하세요. 회로에는 **Circuit diagram**과 **다이어그램 생성**을 사용하며 예전 **Mermaid 다이어그램으로 요약**과 구분합니다.

### 원본 형식이 부적합

**Auto**로 돌아가거나 종류에 맞는 형식을 고르세요. CircuitikZ는 회로, Draw.io/Drawnix는 지원 구조에 사용합니다.

### Export 메뉴가 없음

시각 preview가 있어야 SVG/PNG/PDF가 가능합니다. 텍스트만 있으면 source를 저장하고 맞는 외부 도구로 엽니다.

### CircuitikZ 컴파일 실패

환경 panel에서 검사하고 관리형 runtime을 복구하거나 시스템/사용자 compiler가 `circuitikz`를 가져올 수 있는지 확인하세요. 플러그인은 전체 TeX 배포판을 내장하지 않습니다.
