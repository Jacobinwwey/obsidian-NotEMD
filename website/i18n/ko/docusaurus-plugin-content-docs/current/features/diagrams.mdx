# 도표

<TLDR>
한 번에 여러 차트 유형을 선택하고 유형마다 여러 출력 형식을 따로 지정하세요. 유형 선택을 해제해도 형식 설정은 유지됩니다. 모두 해제하면 내용을 자동으로 분석합니다.
</TLDR>


각 다이어그램 미리보기는 확대·축소, 이동, 화면 맞춤, 실제 크기를 독립적으로 지원합니다. Ctrl/Command + 휠로 확대·축소하고 일반 휠로 스크롤합니다. 큰 PNG 내보내기도 선택한 72–600 PPI를 유지합니다(기본값 300). SVG는 벡터 형식이며 PPI는 래스터 내보내기에만 적용됩니다.


**Obsidian 호환 이미지 생성** — 기본적으로 켜져 있습니다. Obsidian에서 PNG 디코딩을 확인하고 실패하면 요청한 원본을 보존하면서 PPI가 낮은 사본을 추가합니다. 두 파일 이름에 PPI를 표시합니다. 끄면 요청한 원본만 내보냅니다. (`note_drawnix_300ppi.png`, `note_drawnix_obsidian_87ppi.png`).

## 세 가지 선택

| 선택 | 결정하는 것 | 예시 |
| --- | --- | --- |
| 도표 종류 | 도표의 의미 | 흐름·시퀀스·회로·데이터 차트 |
| 원본 형식 | 편집/재사용할 파일 | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| 내보내기 형식 | 공유할 이미지나 문서 | SVG, PNG, PDF |

차트 HTML은 확대 가능한 그림을, 구조화된 요약 HTML은 텍스트·구조·인용을 담습니다. 편집 가능한 HTML/SVG는 렌더러 이름이며 브라우저 편집기가 아닙니다. 편집하려면 기본 소스 파일을 사용하세요. PPTX와 MP4를 포함한 프레젠테이션 내보내기는 별도 설정과 의존성을 유지합니다.

## 원본 형식

| 형식 | 용도 | 원본 파일 |
| --- | --- | --- |
| Mermaid | Markdown 안의 도표 | Mermaid 코드 블록 |
| JSON Canvas | Obsidian 네이티브 canvas | `.canvas` |
| Draw.io | diagrams.net 또는 호환 editor에서 편집 | `.drawio` |
| Drawnix | 손그림/화이트보드 방식 편집 | `.drawnix` |
| CircuitikZ | 구조화된 전기·트랜지스터 회로 | `.tex` |

지원 형식이 먼저 표시되며 호환되지 않는 항목은 보이지만 비활성화됩니다. 기존의 비활성 요청은 제거할 수 있습니다. 각 유형은 자체 형식을 유지합니다. 요청한 형식을 모두 사용할 수 없으면 실제 렌더러의 기본 소스 형식을 시도하고 사용할 수 없는 요청을 보고합니다.

## 생성과 내보내기

1. 지원되는 원문 노트를 엽니다. 한 구절은 별도 노트로 만드세요. 선택 영역은 파일 동작을 제한하지 않습니다.
2. 한 번에 여러 차트 유형을 선택하고 유형마다 여러 출력 형식을 따로 지정하세요. 유형 선택을 해제해도 형식 설정은 유지됩니다. 모두 해제하면 내용을 자동으로 분석합니다.
3. 체크박스로 생성할 유형을 포함합니다. 이름을 클릭하면 해당 유형을 선택하고 형식 설정을 엽니다. 마우스를 올리거나 키보드 포커스를 주면 설정을 저장하지 않고 미리보기만 전환합니다. Escape는 메뉴를 닫고 포커스를 돌려줍니다.
4. **다이어그램 생성**을 실행합니다.
5. 선택한 파일은 원본 노트 옆이나 설정한 출력 폴더에 직접 자동 저장됩니다. 이름에 `topic_drawnix.pdf`, `topic_flowchart.svg`처럼 유형이 포함됩니다. 충돌 시 `-2`, `-3` 등을 붙이며 기존 파일을 덮어쓰지 않습니다.
6. 하나의 세로 scroll shell에서 보드와 source 순서의 Mermaid 패널을 검토합니다. 패널은 실제 렌더 높이를 사용합니다.
7. 패널별 **SVG 내보내기**, **PNG 내보내기**, **Export PDF** 또는 상단 전체 export를 선택합니다. 여러 패널은 원문 폴더/사용자 Vault 상대 폴더에 결정적 이름으로 각각 저장하며 개별 실패 후 계속합니다. 편집 원본이 필요하면 **소스 파일 저장**을 사용합니다.

중간 파일 폴더를 공통 Vault 상대 경로로 지정하거나 비워 두어 각 원본 옆의 `notemd_assert/`를 사용하세요. 복구 기록, 렌더링 캐시, 선택적 첨부 파일이 저장됩니다. 기존 출력이 참조하는 파일은 유지하세요. 폴더 변경은 새 실행에만 적용됩니다.

유형은 순서대로 생성됩니다. 하나가 실패해도 나머지는 진행하며, 취소하면 대기 중인 유형을 중단하고 완료된 파일은 유지합니다. 내보내기 실패는 미리보기나 기록에서 모델 재요청 없이 재시도할 수 있습니다. 생성 실패는 해당 유형을 다시 생성해야 합니다. v1/v2 복구 기록도 계속 읽을 수 있습니다.

Export 메뉴와 패널 머리글에서 같은 세 형식을 제공합니다. **History** drawer로 미리보기를 유지한 채 검색·필터·재열기·저장 파일 열기가 가능합니다. 활성 노트 없이도 팔레트/사이드바에서 히스토리를 엽니다.

SVG/PDF는 벡터 기하를 사용하며 PDF는 SVG 배치/문자 치수를 재사용합니다. PNG PPI는 72–600, 기본 300이고 벡터 출력에는 영향을 주지 않습니다.

## 밀도 높은 도표

HTML/SVG lane-grid는 요약을 먼저 측정하고 줄바꿈하여 title/header 공간을 확보합니다. 셀 후 connector/label을 그리며 직교 경로가 차지한 셀과 label 영역을 피해 텍스트가 가려지지 않게 합니다.

`quadrantChart`는 전용 정규화를 사용해 flowchart용 따옴표/shape 복구를 건너뜁니다. 점 label 끝의 대응 없는 복사 괄호만 제거하며 제목·축·분면의 의도된 괄호는 유지합니다.

[예제 집합](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples)은 영어/중국어 입력, SVG/PNG와 manifest를 보관합니다. `passed`는 기록된 실행/bundle에 대한 것이지 후속 릴리스의 모든 종류를 새로 시험한 결과가 아닙니다. 실행 목록 33개, UI locale 21개와 웹 34개는 별개입니다. 다섯 정확한 참조 문법은 독립 배치 증거 전까지 선택기에 없습니다.

## Mermaid를 포함한 Drawnix

렌더 SVG를 정제하고 Mermaid 원문을 `.drawnix` 메타데이터에 보관하여 Drawnix/Plait runtime 없이 표시합니다. 기본은 자체 완결형으로 `.assets`를 만들지 않습니다. **Also export complete Mermaid visuals**를 켜면 source·SVG·manifest companion을 추가합니다. 이전 `.assets`도 지원하며 없는 SVG는 보관된 source로 복구할 수 있습니다.

가능하면 image embed에 data-backed SVG를 사용합니다. embedded data, 이전 companion, source 재생성 순으로 로드합니다. 참조 중인 기존 파일은 보존하세요. 새 자체 완결형 export는 공유된 예전 폴더가 불필요함을 증명하지 않습니다.

Drawnix는 명시적인 방향 관계를 모두 유지하며 전체 개수나 노드별 개수를 제한하지 않습니다. 동일한 관계만 중복 제거하고 다른 술어와 반대 방향은 유지합니다. 외부 경로 구간이 겹치면 별도 트랙을 배정하고 겹치지 않으면 재사용합니다. 라벨은 실제 크기에 맞춰 행을 확보하며 캔버스는 필요에 따라 확장됩니다. 라벨 없는 화살표, 일반적인 연관, 계층과 중복되는 화살표는 사유와 함께 메타데이터에 남습니다. PDF의 관계 상자 텍스트는 이전 SVG 캐시에서도 표시됩니다. 가지 사이 화살표는 정적이며 Drawnix에서 재배치하면 연결이 떨어질 수 있습니다.

## 네이티브 export 경계

원본과 시각 export는 별도 결과입니다. 배포 전 대상 앱에서 표본을 시험하세요. PowerPoint는 지원되는 편집 표 구조와 병합 아래 교정 구분선을 보존하지만 Mermaid/SVG는 이미지일 수 있습니다. preview나 전체 페이지 screenshot 점수는 native 검증을 대신하지 않습니다.

## 회로

**Circuit diagram**과 **CircuitikZ source file**을 고르면 구조 설명부터 만든 뒤 source로 출력합니다. 무제한 LaTeX 요청보다 범위가 분명합니다. 지원은 제한적이며 common-source NMOS와 지원 CMOS 블록을 중심으로 합니다. 기술/출판용 사용 전 source와 preview를 검토하세요.

SVG는 검토 보조물이며 로컬 LaTeX/TikZJax 컴파일 성공의 증거가 아닙니다. preview·SVG·PNG·preview PDF에는 LaTeX가 필요 없습니다. desktop에서 native PDF/진단이 필요하면 **CircuitikZ native compile environment**를 엽니다. 시스템 `tectonic`/`pdflatex`, 사용자 실행 파일 또는 명시적 **Install** 후 고정된 관리형 Tectonic을 사용합니다. 패널에 진행/오류와 관리형 제거 기능이 있습니다.

## 문제 해결

### 도표 종류가 틀림

자동 감지 대신 종류를 정하세요. 회로에는 **Circuit diagram**과 **다이어그램 생성**을 사용하며 예전 **Mermaid 다이어그램으로 요약**과 구분합니다.

### 원본 형식이 부적합

지원 형식이 먼저 표시되며 호환되지 않는 항목은 보이지만 비활성화됩니다. 기존의 비활성 요청은 제거할 수 있습니다. 각 유형은 자체 형식을 유지합니다. 요청한 형식을 모두 사용할 수 없으면 실제 렌더러의 기본 소스 형식을 시도하고 사용할 수 없는 요청을 보고합니다.

### Export 메뉴가 없음

시각 preview가 있어야 SVG/PNG/PDF가 가능합니다. 텍스트만 있으면 source를 저장하고 맞는 외부 도구로 엽니다.

### CircuitikZ 컴파일 실패

환경 panel에서 검사하고 관리형 runtime을 복구하거나 시스템/사용자 compiler가 `circuitikz`를 가져올 수 있는지 확인하세요. 플러그인은 전체 TeX 배포판을 내장하지 않습니다.

## 1.9.10 — 안전한 미리보기와 Vault별 로컬 설정

가져온 SVG 미리보기는 활성 콘텐츠와 외부 리소스를 제거하면서 중국어 라벨과 패널 스타일을 보존합니다. 기기 전용 공급자는 Vault별로 분리됩니다. 설정에서 이전 목록을 명시적으로 가져오면 원래 목록과 기존 구성이 보존됩니다. 프레젠테이션은 공유 사용자의 수명을 관리하는 loopback 서버를 사용합니다. 즐겨찾기 저장과 복사 실패를 알리며 삭제는 Vault 환경설정을 따릅니다. PNG 호환성은 기본으로 켜져 있습니다. 요청한 원본을 보존하고 필요할 때만 검증된 낮은 PPI 사본을 추가합니다. Drawnix 관계에 고정 상한은 없으며 프레젠테이션 설정은 별도로 유지됩니다. 같은 버전의 파일을 설치하고 다시 로드한 뒤 일괄 처리 전에 노트 하나를 테스트하세요.
