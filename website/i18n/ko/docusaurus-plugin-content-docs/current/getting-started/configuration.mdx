# 설정

<TLDR>Settings → Notemd에서 검색으로 항목을 찾으세요. 노트 처리 전 provider와 출력 경로를 정하고 하나의 노트로 검증합니다. 실행 중인 작업은 시작 시점의 설정을 계속 사용할 수 있습니다.</TLDR>

## 설정 개요

기본 provider는 DeepSeek이며 인증 정보는 비어 있습니다. 프로필 선택은 계정 생성, 모델 설치나 접근 권한 부여가 아닙니다. [Provider 설정](../providers/overview)을 참고하세요.

## 설정 검색과 즐겨찾기

**Search settings**는 이름·설명·별칭·보이는 분류를 검색하고 선택 항목으로 이동합니다. **★ Favorites**는 설명, 분류, 이동 대상을 보여 주며 Vault에 저장되어 재시작 후에도 유지됩니다. 오래된 설정 ID는 제거됩니다. 도구 모음을 접었다 다시 열면 검색어가 유지됩니다. 즐겨찾기 목록과 즐겨찾기만 검색하는 필터는 별도 기능입니다.

**Diagram preview export PPI**는 기본 300, 범위 72–600이며 PNG 래스터화에만 적용됩니다. SVG/PDF는 지원되는 벡터를 유지합니다. **Also export complete Mermaid visuals**는 companion 파일 설정으로 Drawnix 미리보기의 Mermaid 표시를 켜고 끄지 않습니다.

한 번에 여러 차트 유형을 선택하고 유형마다 여러 출력 형식을 따로 지정하세요. 유형 선택을 해제해도 형식 설정은 유지됩니다. 모두 해제하면 내용을 자동으로 분석합니다.

중간 파일 폴더를 공통 Vault 상대 경로로 지정하거나 비워 두어 각 원본 옆의 `notemd_assert/`를 사용하세요. 복구 기록, 렌더링 캐시, 선택적 첨부 파일이 저장됩니다. 기존 출력이 참조하는 파일은 유지하세요. 폴더 변경은 새 실행에만 적용됩니다.

## 1. Provider

프로토콜에 맞는 endpoint, 필요한 키, 접근 가능한 모델을 설정하세요. 지원 시 **Fetch models** 후 **연결 테스트**을 실행합니다. 목록과 생성은 다른 검증입니다. 로컬은 준비된 모델/서버가 필요하고 클라우드/게이트웨이는 작업 내용을 받습니다. 비공개 작업은 개별 작업의 provider도 확인하세요.

## 2. 작업별 모델

`useMultiModelSettings`를 켜면 링크, 제목, 연구, 번역, 개념, 원문 추출, Mermaid 요약에 별도 provider/모델을 사용합니다. 빈 override는 해당 provider의 모델을 사용합니다. 꺼져 있으면 활성 provider를 사용합니다. 대표 노트의 정확도, 지연, 실제 가격으로 비교하세요. 가용성이나 순위는 보장하지 않습니다.

## 3. 출력

| 작업 | 기본 출력 |
| ------ | ------------------------- |
| 링크 추가 | 원본 옆 `_processed.md`; 원본 이동 꺼짐 |
| 독립 개념 추출 | 선택한 개념 폴더에 제목만 생성; 역링크 꺼짐 |
| 번역 | 원본 옆 `_<language>.md`; 기존 대상 덮어쓰기 가능 |
| 연구 | 활성 Markdown 노트에 연구 요약 추가 |
| 제목 기반 배치 생성 | 생성 내용을 쓰고 허용되는 경우 형제 `<folder>_complete` 폴더로 적격 노트 이동 |
| 도표 미리보기/내보내기 | 선택한 파일은 원본 노트 옆이나 설정한 출력 폴더에 직접 자동 저장됩니다. 이름에 `topic_drawnix.pdf`, `topic_flowchart.svg`처럼 유형이 포함됩니다. 충돌 시 `-2`, `-3` 등을 붙이며 기존 파일을 덮어쓰지 않습니다. |
개념 폴더는 처음에 비어 있습니다. `concepts`는 직접 선택하는 예시입니다. 독립 추출은 최소/전체 형식을 지원하며 일반 템플릿 변수 엔진은 없습니다. [개념 노트](../features/concept-notes)를 참고하세요. 링크 접미사·처리 폴더·번역 접미사·저장 경로는 별도 설정입니다. 재실행 전 기존 대상과 복구 충돌을 확인하세요.

## 4. 언어

UI는 21개 locale, 사이트는 34개 언어 경로입니다. `uiLocale: auto`는 지원 매핑을 따르고 없는 언어는 영어로 표시합니다. 생성 언어는 별도이며 기본 영어입니다. 지원 작업은 작업별 언어를 설정할 수 있습니다. 번역은 UI와 독립적인 `language`를 사용합니다. 모델의 언어 품질은 이 개수와 별개입니다.

## 5. 검색

Tavily와 키 또는 DuckDuckGo를 명시적으로 선택합니다. 빈 Tavily 키는 자동 전환하지 않습니다. 둘 다 네트워크를 쓰며 DuckDuckGo는 결과 페이지도 가져올 수 있습니다. 제목 생성의 연구는 기본 꺼짐이며 `enableResearchInGenerateContent`로 추가합니다. 로컬 검색도 기본 꺼짐이고 폴더/작업 범위가 따로 있습니다. 로컬에서 찾은 발췌도 선택한 LLM의 prompt로 전송됩니다.

## 6. 워크플로

빌더 또는 줄마다 이름이 있는 DSL을 사용하세요. 기본 정의:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::`는 이름과 동작을, `>`는 동작 ID를 구분합니다. 기본 정책은 보고된 오류에서 중지합니다. [워크플로](../features/workflows)에서 ID·폴더 문맥·오류 후 계속하기의 영향을 확인하세요.

## 7. 고급 설정

| 설정 | 초기 값 | 효과 |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | 작업별 경로가 없을 때 사용할 provider |
| `useMultiModelSettings` | `false` | 작업마다 별도 provider/모델 사용 |
| `useCustomConceptNoteFolder` | `true` | 폴더 선택 후 개념 파일 생성 허용 |
| `conceptNoteFolder` | `''` | 처음에는 개념 폴더 미선택 |
| `extractConceptsMinimalTemplate` | `true` | 독립 개념 추출은 제목만 사용 |
| `extractConceptsAddBacklink` | `false` | 활성화해야 독립 추출 역링크 추가 |
| `moveOriginalFileOnProcess` | `false` | 링크 추가 중 원본 유지 |
| `chunkWordCount` | `3000` | 대략적 텍스트 청크 크기; token 제한 아님 |
| `batchConcurrency` | `1` | 기본 배치 동시성 |
| `enableBatchParallelism` | `false` | 이 스위치를 사용하는 배치 경로의 병렬 처리 허용 |
| `enableStableApiCall` | `false` | 명시적 안정 요청 모드 |
| `customWorkflowErrorStrategy` | `stop_on_error` | 보고된 오류에서 워크플로 중지 |

청크 크기와 출력 token 예산은 다릅니다. 청크를 줄여도 모든 문맥 제한을 만족하지는 않습니다. 동시성을 낮춰도 모든 429를 예방할 수는 없습니다.

## 설정 프로필

설정은 Vault의 플러그인 데이터입니다. 변경 전 백업하세요. Provider export는 별도 마스킹 계약이며 전체 Vault 백업이 아닙니다. 마스킹한 파일도 endpoint와 메타데이터를 검토하세요. 원시 설정이나 비공개 노트가 있는 진단 본문은 공개하지 마세요.

## 설정 문제 해결

정확한 provider/모델 연결 시험 후 작은 노트를 재실행합니다. 항목이 안 보이면 검색, 현재 분류, 개발자 모드, 선택 Vault를 확인하세요. 버전과 민감 정보를 제거한 설정으로 재현을 보고합니다.

## 1.9.10 — 안전한 미리보기와 Vault별 로컬 설정

가져온 SVG 미리보기는 활성 콘텐츠와 외부 리소스를 제거하면서 중국어 라벨과 패널 스타일을 보존합니다. 기기 전용 공급자는 Vault별로 분리됩니다. 설정에서 이전 목록을 명시적으로 가져오면 원래 목록과 기존 구성이 보존됩니다. 프레젠테이션은 공유 사용자의 수명을 관리하는 loopback 서버를 사용합니다. 즐겨찾기 저장과 복사 실패를 알리며 삭제는 Vault 환경설정을 따릅니다. PNG 호환성은 기본으로 켜져 있습니다. 요청한 원본을 보존하고 필요할 때만 검증된 낮은 PPI 사본을 추가합니다. Drawnix 관계에 고정 상한은 없으며 프레젠테이션 설정은 별도로 유지됩니다. 같은 버전의 파일을 설치하고 다시 로드한 뒤 일괄 처리 전에 노트 하나를 테스트하세요.

## 1.9.11

플러그인 세션 동안 작업 단계와 미리보기 다시 열기에 걸쳐 로그가 누적됩니다. 로그 지우기로 초기화할 수 있으며 플러그인을 다시 로드하면 이전 로그는 유지되지 않습니다.

진단은 태그별로 그룹화되며 기본적으로 접혀 있습니다. 그룹을 펼치면 모든 메시지와 제안을 읽을 수 있으며 심각도별 개수는 계속 표시됩니다.
