# 설치

<TLDR>커뮤니티 플러그인에서 Notemd를 설치하거나 같은 GitHub Release의 실행 파일 세 개를 Vault에 복사하세요. 활성화 후 provider를 설정하고 시험용 노트로 확인합니다. 모델 서버와 선택적 네이티브 내보내기 도구는 별도로 준비해야 합니다.</TLDR>

## 방법 1: 커뮤니티 플러그인 권장

1. 사용할 Vault에서 **Settings → Community plugins**를 엽니다.
2. 필요하면 커뮤니티 플러그인을 허용하고 **Browse**를 누릅니다.
3. **Notemd**를 검색하고 저장소가 `Jacobinwwey/obsidian-NotEMD`인지 확인한 뒤 **Install**을 누릅니다.
4. **Enable** 후 리본 아이콘이나 명령 팔레트로 사이드바를 엽니다.

[Obsidian에서 Notemd 열기](obsidian://show-plugin?id=notemd). 브라우저가 처리하지 못하면 위 메뉴를 이용하세요. 문서를 읽는 데 전용 프로토콜 연결은 필요하지 않습니다.

## 방법 2: 수동 설치

### 준비

설치된 Obsidian과 백업 가능한 Vault가 필요합니다. manifest의 최소 버전 `0.15.0`은 선언이며 최신 후보를 그 버전에서 시험했다는 뜻은 아닙니다.

### 절차

1. [GitHub Releases](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest)에서 같은 릴리스의 `main.js`, `manifest.json`, `styles.css`를 받습니다. `README.md`는 참고 문서이며 실행 필수 파일은 아닙니다.
2. `<vault>/.obsidian/plugins/notemd/`에 세 파일을 넣습니다. 설정 폴더를 바꾼 Vault는 실제 경로를 사용하세요.
3. Obsidian을 다시 불러오고 Community plugins에서 활성화합니다.
4. 표시 버전을 확인합니다. 새 manifest와 오래된 bundle을 섞지 마세요.

## 대안: BRAT

이미 [BRAT](https://github.com/TfTHacker/obsidian42-brat)를 사용한다면 베타 플러그인 절차로 저장소를 추가할 수 있습니다. 버그 재현 시 버전을 고정하세요. BRAT는 외부 선택 도구로 일반 설치의 의존성이 아닙니다.

## 검증

접근 가능한 provider와 모델을 설정하고 **연결 테스트** 후 [빠른 시작](./quick-start)의 복사 노트를 실행하세요. 일부 연결 시험은 모델 목록에만 접근합니다. 실제 생성과 저장은 별도 작업으로 검증해야 합니다.

## 실행 조건

| 대상 | 범위 |
| --------- | ---------- |
| 플러그인 manifest | 최소 Obsidian `0.15.0`, `isDesktopOnly`는 false |
| 검증 근거 | 릴리스별 날짜가 있는 검증 기록 참고; 실제 모바일 기기와 0.15.0은 현재 미검증 |
| 클라우드 LLM | 네트워크, 허용된 계정/키, 지원 모델 |
| 로컬 LLM | 별도로 설치해 실행 중인 서버와 내려받거나 로드한 모델 |
| 네이티브 슬라이드·회로 내보내기 | 데스크톱 도구와 형식별 의존성; 먼저 환경 확인 |

모든 선택적 내보내기에 통용되는 OS 버전 보장은 없습니다. 회로 미리보기는 TeX 컴파일 증거가 아니며 데스크톱 시험은 모바일 시험을 대신하지 않습니다.

## 제거

커뮤니티 플러그인에서 비활성화하거나 제거하세요. 생성 노트와 산출물은 일반 Vault 파일로 남습니다. 삭제 전 확인하고 재설치할 계획이면 설정을 백업하세요. 플러그인 제거는 이미 수행한 편집을 되돌리지 않습니다.

## 업데이트

Community plugins의 **Check for updates**로 업데이트하세요. 수동 업데이트는 작업 중지, Vault/설정 백업, 같은 릴리스의 실행 파일 세 개 교체, 재시작 순서입니다. 릴리스 노트와 작은 시험 결과를 확인한 후 배치를 재개하세요.

릴리스 파일로 Vault 설정을 덮어쓰지 마세요. 되돌릴 때는 백업과 호환되는 알려진 버전을 사용하고 필요한 생성 파일을 보존합니다.
