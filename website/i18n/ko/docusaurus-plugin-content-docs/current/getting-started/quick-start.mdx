# 빠른 시작

<TLDR>이미 접근 가능한 provider와 시험용 Markdown 노트 하나로 시작하세요. 폴더를 처리하기 전에 생성 파일을 확인합니다. 클라우드 호출은 작업 내용을 전송하며 로컬 모델도 실행 중인 서버와 준비된 모델이 필요합니다.</TLDR>

## 1. 첫 LLM 설정

1. [설치 및 활성화](./installation) 후 **Settings → Notemd**를 엽니다.
2. provider, endpoint, 필요한 인증 정보와 접근 가능한 모델을 선택합니다. **Fetch models**가 지원되어도 생성 가능 여부는 별도 확인합니다.
3. **연결 테스트**을 실행하고 인증·모델·주소 오류부터 해결합니다.
4. **개념 노트 폴더 경로**를 검색해 필요한 경우 `concepts` 같은 전용 폴더를 선택합니다. 초기 값은 비어 있으며 `concepts/`가 자동 설정되는 것은 아닙니다.

Ollama는 모델을 먼저 받고 정확한 이름을 입력합니다. 초기 주소는 `http://localhost:11434/api`입니다. LM Studio는 서버를 시작하고 `LMStudio` 프로필을 선택하세요. [로컬 모델](../providers/local)을 참고하세요. 요약 모델이 로컬이어도 웹 연구에는 네트워크가 필요합니다.

## 2. 첫 작업 실행

선택한 provider로 보내도 되는 내용으로 `Notemd trial.md`를 만드세요:

```text
기계 학습 모델은 신경망을 이용해 예제에서 패턴을 학습합니다.
```

사이드바나 명령 팔레트에서 **파일 처리 (링크 추가)**를 실행합니다. 기본적으로 원본은 유지하고 같은 폴더에 `Notemd trial_processed.md`를 만듭니다. 실제 링크를 열어 확인하세요. 다음은 가능한 예시일 뿐입니다:

```markdown
[[기계 학습]] 모델은 [[신경망]]을 이용해 예제에서 패턴을 학습합니다.
```

선택한 개념 폴더에도 노트가 생길 수 있습니다. 파일과 링크를 검토하세요. 모든 핵심 개념을 정확히 찾았다는 보장은 아닙니다.

## 3. 다른 기능 살펴보기

### 개념 노트 추출

**개념 추출 (현재 파일)**은 원문을 다시 쓰지 않습니다. 개념 폴더를 설정해야 하며 기본 결과는 제목만 있는 노트, 원문 역링크 없음입니다. 역링크는 명시적으로 켜세요. [개념 노트](../features/concept-notes).

### 연구와 요약

Markdown 편집기에서 주제를 선택하거나 노트 제목을 사용해 **조사 및 요약**를 실행합니다. Tavily와 키 또는 DuckDuckGo를 명시적으로 선택하세요. 현재 노트에 요약을 추가합니다. 출처를 열어 주장과 대조하세요.

### 원클릭 워크플로

기본 **One-Click Extract** 정의는 다음과 같습니다:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

링크를 추가하고 개념 또는 선택 폴더의 적격 노트를 제목으로 생성한 다음 complete 폴더의 Mermaid를 복구합니다. 기존 개념 노트도 처리할 수 있습니다. 첫 실행은 전용 시험 폴더를 사용하세요. 웹 연구나 일반 도표 생성이 자동 추가되지는 않습니다.

## 취소와 출력 확인

진행 화면의 **취소**로 후속 작업을 중지합니다. 완료 출력은 남으며 취소는 실행 취소 트랜잭션이 아닙니다. 서버 생성이나 과금 중지를 보장하지 않습니다. 종료를 기다리고 출력 경로·복구 충돌을 확인한 뒤 다시 실행하세요.

## 문제 해결

- 인증/모델 오류: 정확한 프로필과 연결 시험을 확인합니다.
- 개념 파일 없음: 폴더 설정과 활성화를 확인합니다.
- 유용한 링크 없음: 응답과 사용자 prompt를 확인합니다. 추출을 보장하는 최소 단어 수는 없습니다.
- 사용량 제한: 계정 한도를 확인하는 동안 배치 동시성은 기본 `1`로 유지합니다.
