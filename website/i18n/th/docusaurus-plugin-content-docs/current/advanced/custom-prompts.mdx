# พรอมป์ต์กำหนดเอง

<TLDR>พรอมป์ต์กำหนดเองที่ไม่ว่างจะแทนค่าเริ่มต้นเมื่อเปิดทั้งตัวเลือกส่วนกลางและตัวเลือกของงาน ต้องรักษาสัญญาผลลัพธ์ ระบบแม่แบบไม่เติมข้อกำหนดรูปแบบที่คุณลบออกกลับให้อัตโนมัติ</TLDR>

## ภาพรวม

ลองค่าเริ่มต้นกับโน้ตที่เป็นตัวแทนก่อน การระบุสาขาหรือคำสั่งลดคำพ้องอาจเพียงพอ หากจำเป็นจึงปรับนโยบาย โครงสร้าง หรือสไตล์แปล แล้วเปรียบเทียบก่อนทำเป็นชุด

## วิธีทำงาน

### การประกอบคำสั่ง

Notemd เลือกพรอมป์ต์เริ่มต้นหรือที่กำหนดเอง เพิ่มคำสั่งภาษา/สาขาที่เกี่ยวข้อง แล้วแทนตัวแปรที่งานนั้นจัดให้ เนื้อหาโน้ตอาจส่งเป็นข้อความอีกส่วน ตัวแปรไม่ได้ใช้ได้กับทุกงาน การแทนอาจลืม `CONCEPT:` หรือบริบทค้นคว้า คำขอที่ถูกต้องจึงไม่พิสูจน์ว่าผลจะแยกวิเคราะห์ได้หรือมีหลักฐานรองรับ

### ตัวแปร

ใช้ตัวพิมพ์ตรงตามที่ระบุและวงเล็บปีกกาชั้นเดียว

| งาน | ตัวแปรที่มี |
| ------ | ----------------------- |
| สร้างจากชื่อเรื่อง | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| สรุปการค้นคว้า | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| แปล | `{LANGUAGE}`, `{TEXT}` |
| ข้อความต้นฉบับ | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` ใช้นโยบายภาษาของงาน งานลิงก์และแยกแนวคิดอิสระส่งข้อความเป็นเนื้อหางาน อย่าสร้าง placeholder เพิ่มเอง ชื่อที่ไม่รู้จักจะไม่ถูกแทน สิ่งนี้เป็นการแทนตัวแปรในพรอมป์ต์ ไม่ใช่แม่แบบไฟล์แนวคิด

### สาขาที่เน้น

เปิดการเรียนรู้แบบเน้นสาขาและระบุ เช่น `วิศวกรรมไฟฟ้า` ค่า `Relevant Fields` ชี้นำความสนใจ ไม่ใช่ตัวกรองตายตัวหรือหลักฐานว่าเนื้อหาอื่นถูกตัดออก

## การตั้งค่า

| งาน | สวิตช์ | ฟิลด์พรอมป์ต์ |
| ------ | --------------- | -------------- |
| ลิงก์ | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| ชื่อเรื่อง | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| ค้นคว้า | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| สรุป Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| แนวคิด | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| แปล | `useCustomPromptForTranslate` | `translatePrompt` |
| ข้อความต้นฉบับ | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

ทุกตัวเลือกต้องเปิด `enableGlobalCustomPrompts` ข้อความว่างจะใช้คำสั่งเริ่มต้น การแยกข้อความต้นฉบับแบบรวมมีรูปแบบคงที่ของตน การแทนทั่วไปไม่ใช้กับส่วนนั้น การสร้างแผนภาพต้องการผลแบบมีชนิดกำหนด จึงใช้พรอมป์ต์ Mermaid แทนทุกประเภทไม่ได้

## ตัวอย่าง

เปิดตัวเลือกส่วนกลางและการแยกแนวคิด โดยคงเครื่องหมายสำหรับตัวแยกวิเคราะห์ไว้

```text
แยกแนวคิดวิศวกรรมไฟฟ้าที่สำคัญที่สุดจากโน้ต
ให้ความสำคัญกับส่วนประกอบที่เป็นรูปธรรมและกลไกทางกายภาพแทนคำนามทั่วไป
เขียนแต่ละแนวคิดในบรรทัดแยกโดยใช้รูปแบบนี้เท่านั้น:
CONCEPT: ชื่อแนวคิด
ไม่เพิ่มคำอธิบายหรือบล็อกโค้ดครอบข้อความ
```

ใช้สำเนาเปรียบเทียบบรรทัด ชื่อไฟล์ และแนวคิดที่ตกหล่นกับค่าเริ่มต้น เก็บพรอมป์ต์ก่อนหน้าไว้สำหรับย้อนกลับ

## ข้อแนะนำ

- ทดสอบหนึ่งงานก่อนขยายชุด
- รักษาแหล่งค้นคว้าและข้อความอ้างอิงตรงต้นฉบับ
- แปลคำสั่งโดยไม่เปลี่ยน ID หรือเครื่องหมายผลลัพธ์
- ทดสอบใหม่หลังเปลี่ยนโมเดล คำสั่งไม่ใช่การรับประกันการตรวจสอบ
