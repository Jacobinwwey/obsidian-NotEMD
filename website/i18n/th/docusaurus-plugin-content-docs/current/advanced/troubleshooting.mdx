# แก้ปัญหา

<TLDR>ทำซ้ำบนโน้ตทดลองหนึ่งไฟล์โดยใช้ผู้ให้บริการ โมเดล และการตั้งค่างานเดิม ตรวจสถานะและพาธผลลัพธ์ แยกการยืนยันตัวตน การสร้างข้อความ การแยกวิเคราะห์ และการเขียนไฟล์ การทดสอบเชื่อมต่อไม่ได้ครอบคลุมทั้งเวิร์กโฟลว์</TLDR>

## ภาพรวม

จดเวอร์ชัน Notemd/Obsidian ระบบปฏิบัติการ การทำงาน โพรโทคอล โมเดล และขั้นตอนขั้นต่ำ อย่าเริ่มใหม่ระหว่างที่การยกเลิกยังไม่จบ เก็บผลลัพธ์และไฟล์กู้คืนจนกว่าจะทราบที่มา

## การวินิจฉัย

### ทดสอบการเชื่อมต่อ

**ทดสอบการเชื่อมต่อ** อาจตรวจเพียงรายชื่อโมเดลหรือการสร้างข้อความสั้น ๆ หลังจากนั้นให้ลองงานจริงขนาดเล็กด้วยโมเดลและรูปแบบผลลัพธ์ที่เลือก

### ความคืบหน้าและการวินิจฉัยนักพัฒนา

รายงานแสดงสถานะ ข้อผิดพลาด และตำแหน่งไฟล์ ส่วนกิจกรรม API แยกคำขอที่รอกับที่เสร็จ เปิด debug เมื่อจำเป็น การวินิจฉัยคำขอยาวอาจใช้โควตา รายงานอาจมีโน้ต คำตอบบางส่วน รายละเอียด endpoint และคีย์ ตรวจและปิดบังภายในเครื่องก่อนแบ่งปัน แม้โปรไฟล์ที่ปิดบังแล้วก็ต้องตรวจ metadata

## ข้อผิดพลาดที่พบบ่อย

### คีย์หายหรือไม่ถูกต้อง

401: ตรวจโปรไฟล์/endpoint และช่องว่างที่ไม่ตั้งใจ 403: ตรวจบัญชี โปรเจกต์ สิทธิ์โมเดล และการชำระเงิน การลองซ้ำไม่แก้ข้อมูลยืนยันตัวตนที่ผิด

### เครือข่าย

ตรวจ host พอร์ต โพรโทคอล และพาธจากอุปกรณ์ที่รัน Obsidian ต้องเปิด Ollama/LM Studio พร้อมโมเดล `localhost` คืออุปกรณ์นี้ ไม่ใช่คอมพิวเตอร์อีกเครื่อง เลือกโปรไฟล์ให้ถูก ระบบเลือก fallback เอง ไม่ได้มีปุ่มเลือก transport

### ขีดจำกัด 429

ลดงานพร้อมกันและตรวจโควตาคำขอ/token รวมถึงการใช้คีย์เดียวกันจากที่อื่น การลองใหม่ช่วยได้เฉพาะปัญหาชั่วคราวบางชนิด

### ไม่พบโมเดล

ใช้ **Fetch models** หรือ ID โมเดล/deployment ที่ทราบ ตรวจเวอร์ชัน API และภูมิภาค ชื่อตัวอย่างอาจเก่า Azure ต้องมี deployment และ Ark อาจต้องใช้ endpoint ID

### ไม่มีลิงก์หรือแนวคิด

ตรวจไฟล์ผลลัพธ์จริง ต้นฉบับที่มีเนื้อหา รูปแบบคำตอบ และโฟลเดอร์แนวคิดที่เลือกและเปิดใช้ การแยกอิสระเริ่มด้วยชื่อเรื่องอย่างเดียวและไม่มีลิงก์ย้อนกลับ หากเครื่องหมายหายให้เทียบกับพรอมป์ต์เริ่มต้น

### ผลลัพธ์หายหรือไปที่อื่น

อ่านพาธ `_processed.md`, `_<language>.md` หรือ complete ที่รายงาน หากสร้างโฟลเดอร์แปลไม่ได้อาจใช้โฟลเดอร์ต้นฉบับ ตรวจการชนกันและสิทธิ์ก่อนรันซ้ำ

### ยังมีไฟล์หลังยกเลิก

การเขียนที่เสร็จแล้วคงอยู่ และคำขอที่รับไปแล้วอาจทำจนจบ ตรวจไฟล์และข้อขัดแย้งการกู้คืนก่อนลบหรือรันโฟลเดอร์ทั้งหมดใหม่

### แผนภาพหรือส่งออกเข้าแอปภายนอก

ประเภทต่าง ๆ สร้างตามลำดับ ความล้มเหลวหนึ่งไม่ขัดขวางประเภทอื่น การยกเลิกหยุดประเภทที่รอและเก็บไฟล์ที่เสร็จแล้ว ลองส่งออกซ้ำจากตัวอย่างหรือประวัติโดยไม่ต้องขอโมเดลใหม่ หากขั้นสร้างล้มเหลวต้องสร้างประเภทนั้นใหม่ บันทึก v1/v2 ยังอ่านได้

HTML แผนภาพมีภาพที่ซูมได้ ส่วน HTML สรุปแบบมีโครงสร้างมีข้อความ โครงสร้าง และแหล่งอ้างอิง HTML/SVG ที่แก้ไขได้เป็นชื่อตัวเรนเดอร์ ไม่ใช่เครื่องมือแก้ไขในเบราว์เซอร์ ให้ใช้ไฟล์ต้นฉบับสำหรับแก้ไข การส่งออกงานนำเสนอรวมถึง PPTX และ MP4 มีการตั้งค่าและส่วนพึ่งพาแยกกัน [คู่มือแผนภาพ](../features/diagrams).

## แจ้งข้อผิดพลาด

1. ทำซ้ำด้วยโน้ตสังเคราะห์ในโฟลเดอร์ทดลอง
2. ระบุเวอร์ชัน งาน โมเดล การตั้งค่าที่จำเป็น และผลที่คาด/เกิดจริง
3. แนบไฟล์หรือล็อกขั้นต่ำโดยไม่มีคีย์ เนื้อหาส่วนตัว หรือข้อมูล endpoint เกินจำเป็น
4. บอกว่าเกิดกับไฟล์เดียวและพรอมป์ต์เริ่มต้นหรือไม่
5. เปิด [GitHub Issue](https://github.com/Jacobinwwey/obsidian-NotEMD/issues)

ภาพหน้าจออย่างเดียวมักไม่พิสูจน์ปัญหารูปแบบหรือการยกเลิก หากทำได้ให้แนบต้นฉบับ/ผลลัพธ์ หรือขั้นตอนสั้นที่สุดที่ทำซ้ำได้
