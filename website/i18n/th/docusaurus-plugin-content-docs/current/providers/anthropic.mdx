# Anthropic

<TLDR>เลือกโปรไฟล์นี้สำหรับ Messages API โดยตรง ถ้าใช้ Claude ผ่าน gateway แบบ OpenAI-compatible ให้ใช้โปรไฟล์ gateway ค่าโมเดลเริ่มต้นจากอดีตอาจต้องเปลี่ยนเป็นโมเดลที่ยังใช้ได้</TLDR>

## เตรียมการ

เลือก **Anthropic** ใส่คีย์และโมเดลที่เข้าถึงได้ ใช้ URL ของ API โดยตรง เว้นแต่ deployment ของคุณรองรับโพรโทคอลเดียวกัน ทดสอบเชื่อมต่อและโน้ต

## Endpoint และการยืนยันตัวตน

| ฟิลด์ | ค่าเริ่มต้น |
| ------- | -------------- |
| โพรโทคอลรับส่ง | `anthropic` |
| คีย์ API | จำเป็น |
| URL ฐาน | `https://api.anthropic.com` |
| โมเดล | `claude-3-5-sonnet-20240620` |
| อุณหภูมิ | `0.5` |
| การทดสอบเชื่อมต่อ | `chat-only` |

เส้นทางทำงานใช้ `/v1/messages` พร้อม headers คีย์และเวอร์ชันเฉพาะ อย่าเพิ่มพาธ chat ของ OpenAI ค่าเริ่มต้นอธิบายการตั้งค่าใน repository ไม่ใช่สถานะเปิดให้ใช้โมเดลวันนี้

## โมเดล

ใช้การค้นหาโมเดลของผู้ให้บริการเมื่อมีสิทธิ์ หากรายการถูกป้องกัน ให้ใส่ ID ที่อนุญาตและทดลองสร้าง งานยาวหรือผลลัพธ์แบบมีโครงสร้างต้องตรวจแยก

## ปัญหา

- 401/403: คีย์ โปรเจกต์ การชำระเงิน และสิทธิ์โมเดล
- 404: ที่อยู่และความพร้อมของโมเดล
- ID ของ gateway ถูกปฏิเสธ: เลือกโปรไฟล์และ ID ให้เหมาะ
- คำขอยาวผิดพลาด: ตรวจขีดจำกัดก่อนเพิ่มจำนวนลองใหม่

## เหมาะกับกรณีใด

ใช้กับ endpoint Messages โดยตรง เปรียบเทียบผลกับต้นฉบับของคุณแทนการเชื่ออันดับผู้ให้บริการทั่วไป การกำหนดผู้ให้บริการแยกตามงานช่วยให้เลือกใช้เฉพาะงานได้
