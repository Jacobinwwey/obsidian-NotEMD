# ผู้ให้บริการจีน

<TLDR>เลือกโปรไฟล์ตามบัญชีและ deployment แม้ใช้โพรโทคอล OpenAI-compatible ร่วมกัน ภูมิภาค พาธ โมเดล และสิทธิ์ก็ใช้แทนกันไม่ได้ ตรวจด้วยงานขนาดเล็กก่อน</TLDR>

## เตรียมการ

เตรียมบัญชีและคีย์ เลือกโปรไฟล์ และยืนยันภูมิภาค/สิทธิ์โมเดล ค่าเริ่มต้นไม่รับประกันความพร้อมปัจจุบัน ทดสอบทั้งการเชื่อมต่อและโน้ต

## Endpoint และการยืนยันตัวตน

| โปรไฟล์ | โมเดลเริ่มต้น | URL ฐาน |
| -------- | --------------- | ------------------ |
| DeepSeek | `deepseek-v4-pro` | `https://api.deepseek.com` |
| Qwen | `qwen3-235b-a22b` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Qwen Code | `qwen3-coder-plus` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |

แทนตัวอย่าง Doubao ด้วย Ark endpoint ID จริงหรือโมเดลที่รองรับ GLM และ Z AI เป็นโปรไฟล์ต่างภูมิภาค คีย์จากอีกภูมิภาคหรือรูปแบบสมาชิกอาจใช้ไม่ได้ ปฏิบัติตามคำแนะนำบัญชี ไม่ใช่อาศัยที่ตั้งของคุณอย่างเดียว

## โมเดล

ใช้รายการเมื่อได้รับอนุญาต Huawei Cloud MaaS ต้องอาศัยข้อมูล deployment ส่วนโปรไฟล์อื่นใช้การค้นหา OpenAI-compatible ที่รองรับ การไม่มีสิทธิ์ดูรายการไม่ได้แปลว่าสร้างข้อความด้วย ID ชัดเจนไม่ได้เสมอไป DeepSeek อาจผ่านการทดสอบด้วยรายการ ขณะที่หลายโปรไฟล์ภูมิภาคสร้างคำตอบสั้น งานจริงยังต้องตรวจ

## ปัญหา

- คีย์ยอมรับแต่สร้างไม่ได้: สิทธิ์โมเดล deployment และภูมิภาค
- Ark ปฏิเสธ ID: ต้องใช้ endpoint ID หรือ model ID
- การให้เหตุผลถูกตัด: งบและ thinking ของโมเดลนั้น
- เครือข่าย: ตรวจที่อยู่จาก Obsidian และอ่านข้อความผิดพลาดการรับส่ง

## เหมาะกับกรณีใด

เมื่อสิทธิ์บัญชี ความพร้อม และเงื่อนไขข้อมูลตรงความต้องการ ภูมิศาสตร์ไม่ได้พิสูจน์คุณภาพภาษาหรือราคาต่ำ เปรียบเทียบตัวอย่างเดียวกันและบันทึกการตั้งค่า
