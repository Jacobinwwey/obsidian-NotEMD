# OpenAI

<TLDR>โปรไฟล์นี้ใช้การทำงาน OpenAI Chat Completions ร่วมกัน เลือกคีย์และโมเดลที่ตรงโพรโทคอล ค่าโมเดลเริ่มต้นไม่รับประกันว่ายังเข้าถึงได้หรือเหมาะที่สุดกับทุกงาน</TLDR>

## เตรียมการ

สำหรับบริการทางการให้เลือก **OpenAI** ใส่คีย์ และใช้ `https://api.openai.com/v1` โมเดลในรายการอาจต้องใช้ API อีกแบบ Gateway มีโปรไฟล์/headers ของตน ส่วน Azure ใช้ **Azure OpenAI** พร้อม deployment และเวอร์ชัน API

## Endpoint และการยืนยันตัวตน

| ฟิลด์ | ค่าเริ่มต้น |
| ------- | -------------- |
| โพรโทคอลรับส่ง | `openai-compatible` |
| คีย์ API | จำเป็น |
| URL ฐาน | `https://api.openai.com/v1` |
| โมเดล | `gpt-4o` |
| อุณหภูมิ | `0.5` |
| การทดสอบเชื่อมต่อ | `models-then-chat` |

ระบบปรับ URL รูปแบบที่รู้จักก่อนประกอบพาธ เริ่มจากโปรไฟล์แล้วตรวจที่อยู่หลังปรับ แทนการเติมส่วนของพาธโดยเดา

## โมเดล

**Fetch models** ขอรายชื่อโมเดลที่ใช้ได้ **ทดสอบการเชื่อมต่อ** อาจผ่านจากรายการเพียงอย่างเดียว ให้ลองโน้ตกับโมเดลจริง Reasoning, thinking, การสุ่ม และงบ token ต้องตรงกับโปรไฟล์/โมเดล

## ปัญหา

- 401/403: คีย์ โปรเจกต์ สิทธิ์ และบัญชี
- 404: endpoint ชื่อโมเดล และ API ที่รองรับ
- รายการใช้ได้แต่สร้างไม่ได้: อ่านข้อผิดพลาด chat และพารามิเตอร์
- คำตอบยาวถูกตัด: ตรวจข้อมูลเข้า งบ และคำตอบ การทดสอบสั้นไม่ครอบคลุมกรณีนี้

## เหมาะกับกรณีใด

ใช้กับ OpenAI โดยตรงที่รองรับ Chat Completions ประเมินด้วยโน้ตของคุณ ราคาและความพร้อมเปลี่ยนได้โดยไม่ขึ้นกับ Notemd
