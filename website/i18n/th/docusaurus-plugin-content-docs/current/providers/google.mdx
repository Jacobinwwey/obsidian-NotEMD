# Google

<TLDR>Google ใช้ Gemini Generative Language API โดยตรง ระบุคีย์ที่ได้รับอนุญาตและโมเดลที่เข้าถึงได้ หากใช้ Gemini ผ่าน gateway ที่เข้ากันได้ ให้เลือกโปรไฟล์ gateway</TLDR>

## เตรียมการ

เลือก **Google** คีย์ endpoint API โดยตรง และโมเดลของเวอร์ชัน API นั้น ทดสอบเชื่อมต่อและโน้ต การตั้งค่านี้ไม่ทำให้ Google Cloud หรือ Vertex deployment ใด ๆ ใช้งานได้โดยอัตโนมัติ

## Endpoint และการยืนยันตัวตน

| ฟิลด์ | ค่าเริ่มต้น |
| ------- | -------------- |
| โพรโทคอลรับส่ง | `google` |
| คีย์ API | จำเป็น |
| URL ฐาน | `https://generativelanguage.googleapis.com/v1` |
| โมเดล | `gemini-2.0-flash-exp` |
| อุณหภูมิ | `0.5` |
| การทดสอบเชื่อมต่อ | `chat-only` |

ระบบส่งคำขอ `generateContent` พร้อมคีย์ ID เก่าไม่รับประกันการเข้าถึง ตรวจ URL ในข้อมูลวินิจฉัยก่อนแชร์ เพราะอาจมีข้อมูลยืนยันตัวตน

## โมเดล

ใช้การค้นหาโมเดลของ API และยืนยันการสร้างบน API ที่เลือก รายการว่างอาจเกิดจากสิทธิ์ endpoint หรือโมเดลที่ไม่มี ตรวจสาเหตุก่อนเปลี่ยนโพรโทคอล

## ปัญหา

- 400: ID พารามิเตอร์ และขีดจำกัดข้อมูลเข้า/ผลลัพธ์
- 401/403: ข้อจำกัดคีย์ API ที่เปิดใช้ และสิทธิ์
- 404: โมเดลมีอยู่ใน API เวอร์ชันนี้หรือไม่
- ตัวอย่าง gateway: ใช้โปรไฟล์ OpenAI-compatible ที่ถูกต้อง

## เหมาะกับกรณีใด

สำหรับ Gemini API โดยตรง ทดลองการแปล ค้นคว้า หรือแผนภาพด้วยข้อมูลของคุณ ไม่มีคำรับประกันทั่วไปเรื่องความเร็ว ราคา หรือคุณภาพ
