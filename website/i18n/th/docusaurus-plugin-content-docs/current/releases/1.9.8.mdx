# อัปเกรดเป็น Notemd 1.9.8

<TLDR>1.9.8 เน้นการยกเลิก ความเป็นเจ้าของผลลัพธ์ ความสม่ำเสมอของการค้นข้อมูลในงานชุด การส่งออกเข้าแอปจริง และเอกสารที่ถูกต้อง ตรวจความพร้อมที่ GitHub Release สาธารณะและใช้ไฟล์จาก release เดียวกัน จำนวนผู้ให้บริการและแผนภาพเป็นความสามารถที่มีอยู่ก่อน</TLDR>

## สิ่งที่เปลี่ยนจาก 1.9.7

| ด้าน | ผล |
| ------ | ------------- |
| การยกเลิก | สถานะร่วมใน scheduler การรับส่ง และการลองใหม่ คำตอบที่มาช้าไม่เริ่มการเขียนที่มีการป้องกัน |
| ความคงทนของไฟล์ | ความเป็นเจ้าของต้นฉบับชื่อเดียวกันและไฟล์ประกอบร่วมเมื่อบันทึก/กู้คืนทับซ้อน |
| ค้นข้อมูลในเครื่อง | ใช้ snapshot เดียวในงานชื่อเรื่องแบบชุด มี corpus คงที่และการวัดหน่วยความจำ |
| ผลลัพธ์สำหรับแอปจริง | แก้เส้นคั่น PowerPoint ใต้เซลล์รวม และสาย/ป้าย CircuitikZ |
| การตรวจสอบ | CI Linux/Windows, lint รายข้อวินิจฉัย, process tests และหลักฐานจากแอปปลายทาง |
| เอกสาร | ค่าเริ่มต้นจริง ทางเข้า 4 กลุ่มผู้อ่าน การเขียนคำแปลโดยตรง และการเผยแพร่ที่มีการตรวจ |

ช่องค้นหาประวัติรักษาการพิมพ์ต่อเนื่องและ caret เมื่ออัปเดตแบบ asynchronous แผงประวัติกัก Tab ภายใน รับ focus ขณะโหลด และให้ Escape ปิดแผงโดยไม่ปิด preview หลัก มี browser regressions สำหรับการลองใหม่และคำตอบที่ล้าสมัย

การค้นคว้า/แปลตรวจการยกเลิกหลังอ่านข้อมูลครั้งสุดท้ายหรือเตรียมโฟลเดอร์ และก่อนเพิ่ม/สร้าง/เขียนทับ การเขียนที่ Vault รับแล้วคงนับเป็นผลเสร็จ หากงานอื่นสร้างโฟลเดอร์แปลระหว่างรอ จะใช้โฟลเดอร์นั้นโดยไม่อ้างว่าเป็นผู้สร้างเอง หากพาธชนกับไฟล์หรือยังไม่มีไดเรกทอรี จะคงรายงานข้อผิดพลาดและใช้โฟลเดอร์ต้นฉบับตาม fallback

36 โปรไฟล์และรายการแผนภาพที่เรียกใช้ได้ 33 รายการมีอยู่ใน 1.9.7 แล้ว การเปลี่ยน runtime เอกสาร และ merge commits นับแยกกัน

## อัปเกรดอย่างควบคุมได้

1. หยุดงานและสำรอง vault/การตั้งค่า
2. อัปเดตผ่าน Community plugins หรือดาวน์โหลด `main.js`, `manifest.json`, `styles.css` จาก [1.9.8 สาธารณะ](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/tag/1.9.8) เดียวกัน
3. ถ้าเปลี่ยนเองให้แทนเฉพาะไฟล์ทำงาน เก็บการตั้งค่าและผลลัพธ์
4. โหลดใหม่และตรวจเวอร์ชัน
5. ทดลองโน้ตทิ้งได้และโฟลเดอร์เล็กก่อนทำชุดใหญ่

ID คำสั่งและการตั้งค่ายังคงเดิม One-Click Extract ยังเป็นเพิ่มลิงก์ สร้างจากชื่อเรื่องเป็นชุด และซ่อม Mermaid การแก้เอกสารไม่ได้เพิ่มงานค้นคว้าให้ชุดเริ่มต้น

## การยกเลิกและกู้คืน

การยกเลิกไม่ใช่ธุรกรรมย้อนคืน ไฟล์ที่เสร็จแล้วยังอยู่ คำขอ/การเขียนที่รับไปแล้วอาจเสร็จภายหลัง และผู้ให้บริการควบคุมค่าบริการ รอแล้วตรวจผล เปรียบเทียบข้อขัดแย้งที่แสดงและไฟล์กู้คืนก่อนเก็บกวาด รักษาโฟลเดอร์ประกอบที่ผลลัพธ์เก่ายังอ้างอิง

## ข้อจำกัดการส่งออกและความเข้ากันได้

- PowerPoint มีการตรวจเฉพาะจุดในแอปจริง คะแนนทั้งสไลด์ครั้งก่อนเคยพลาดข้อบกพร่อง
- Mermaid/SVG ใน PPTX อาจเป็นภาพ
- ลูกศร Drawnix ข้ามกิ่งที่เป็นพิกัดคงที่ยังไม่พิสูจน์ว่าเชื่อมติดหลังจัดวางใหม่
- Preview CircuitikZ และคอมไพล์ TeX เป็นคนละการตรวจ
- อุปกรณ์มือถือจริงและ Obsidian 0.15.0 ยังไม่ยืนยัน
- ผลทดสอบการค้นตามคำบน corpus คงที่ไม่พิสูจน์ semantic search หรือประสิทธิภาพในทุก vault

## ความสมบูรณ์ของ release

ผู้เผยแพร่ตรวจเวอร์ชันและตัวตน tag ในเครื่อง/remote สร้างใหม่จาก source สะอาดที่ตรง tag อัปโหลด draft แล้วเปรียบเทียบ hash ของไฟล์ที่ดาวน์โหลดกลับก่อนเปิดเผย ต้องมี `main.js`, `manifest.json`, `styles.css`, `README.md` การลองใหม่ห้ามนำผลที่ไม่เกี่ยวข้องมาแทน bytes ที่เผยแพร่แล้ว

Deploy Pages หลังตรวจว่า Release เป็นสาธารณะ Codex เขียนและตรวจคำแปลโดยตรงโดยไม่ใช้ LM Studio หรือเครื่องมือแปล นี่ไม่ได้อ้างว่าได้รับการตรวจโดยเจ้าของภาษาอิสระ
