# Notemd 1.9.9 — หลายแผนภาพ ส่งออกแยกตามประเภท

<TLDR>
เลือกแผนภาพหลายประเภทในการทำงานครั้งเดียว และเลือกหลายรูปแบบผลลัพธ์แยกกันสำหรับแต่ละประเภท ยกเลิกการเลือกแล้วค่ารูปแบบยังคงอยู่ หากไม่เลือกเลย ระบบจะวิเคราะห์เนื้อหาอัตโนมัติ
</TLDR>

## หลายแผนภาพ ส่งออกแยกตามประเภท

ช่องทำเครื่องหมายใช้รวมประเภทในการสร้าง คลิกชื่อเพื่อเลือกประเภทและแก้ไขรูปแบบ วางเมาส์หรือโฟกัสด้วยแป้นพิมพ์เพื่อเปลี่ยนตัวอย่างโดยไม่บันทึกการตั้งค่า Escape ปิดเมนูและคืนโฟกัส

รูปแบบที่รองรับแสดงก่อน ตัวเลือกที่ไม่เข้ากันยังมองเห็นแต่ถูกปิดใช้งาน สามารถนำคำขอเดิมที่ไม่ทำงานออกได้ แต่ละประเภทเก็บรูปแบบของตนเอง หากใช้คำขอใดไม่ได้เลย ระบบจะลองรูปแบบต้นฉบับเริ่มต้นของตัวเรนเดอร์ที่ใช้งานและรายงานคำขอที่ไม่พร้อมใช้

HTML แผนภาพมีภาพที่ซูมได้ ส่วน HTML สรุปแบบมีโครงสร้างมีข้อความ โครงสร้าง และแหล่งอ้างอิง HTML/SVG ที่แก้ไขได้เป็นชื่อตัวเรนเดอร์ ไม่ใช่เครื่องมือแก้ไขในเบราว์เซอร์ ให้ใช้ไฟล์ต้นฉบับสำหรับแก้ไข การส่งออกงานนำเสนอรวมถึง PPTX และ MP4 มีการตั้งค่าและส่วนพึ่งพาแยกกัน

Drawnix แสดงความสัมพันธ์หลักแบบมีทิศทางและป้ายกำกับสูงสุดหกรายการ ไม่เกินสามรายการต่อโหนด ความสัมพันธ์ที่ละไว้ยังอยู่ในเมทาดาทา ข้อความในกรอบแสดงใน PDF รวมถึงจากแคช SVG เก่า ลูกศรข้ามกิ่งเป็นแบบคงที่และอาจหลุดเมื่อจัดเรียงใหม่ใน Drawnix

## ไฟล์และการกู้คืน

ไฟล์ที่เลือกจะส่งออกอัตโนมัติข้างโน้ตต้นฉบับหรือเข้าสู่โฟลเดอร์ผลลัพธ์ที่ตั้งไว้โดยตรง ชื่อระบุประเภท เช่น `topic_drawnix.pdf` และ `topic_flowchart.svg` หากชื่อซ้ำจะเติม `-2`, `-3` เป็นต้น โดยไม่เขียนทับไฟล์เดิม

กำหนดโฟลเดอร์ไฟล์ระหว่างทางร่วมกันด้วยพาธสัมพัทธ์ต่อ Vault หรือเว้นว่างเพื่อใช้ `notemd_assert/` ข้างแต่ละต้นฉบับ ที่นี่เก็บบันทึกการกู้คืน แคชการเรนเดอร์ และไฟล์แนบเสริม เก็บไฟล์ที่ยังถูกอ้างอิงไว้ การเปลี่ยนโฟลเดอร์มีผลเฉพาะงานใหม่

ประเภทต่าง ๆ สร้างตามลำดับ ความล้มเหลวหนึ่งไม่ขัดขวางประเภทอื่น การยกเลิกหยุดประเภทที่รอและเก็บไฟล์ที่เสร็จแล้ว ลองส่งออกซ้ำจากตัวอย่างหรือประวัติโดยไม่ต้องขอโมเดลใหม่ หากขั้นสร้างล้มเหลวต้องสร้างประเภทนั้นใหม่ บันทึก v1/v2 ยังอ่านได้

## อัปเกรด

หยุดงานและสำรอง Vault ติดตั้ง `main.js`, `manifest.json` และ `styles.css` จาก Release 1.9.9 เดียวกัน เก็บการตั้งค่าและไฟล์ แล้วโหลด Obsidian ใหม่ ตรวจโน้ตหนึ่งรายการก่อนทำงานชุดใหญ่ ค่ากำหนดเดิมจะย้ายเมื่อแก้ไข คำแปลเขียนโดยตรงโดยไม่ใช้ API แปลภาษาหรือ LM Studio
