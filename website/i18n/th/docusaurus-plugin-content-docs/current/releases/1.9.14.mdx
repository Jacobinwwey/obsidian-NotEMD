# Notemd 1.9.14 — ตัวอย่าง PDF คมชัดและการส่งออกหลายรูปแบบ

<TLDR>
PNG/PDF เปิดในหน้าต่างตัวอย่างแผนภาพ โดยแต่ละหน้า PDF มีตัวควบคุมแยกกัน เมื่อซูมจะวาดพื้นที่ที่มองเห็นใหม่ตามความหนาแน่นพิกเซลของหน้าจอและจำกัดการใช้หน่วยความจำ ภาพบิตแมปที่ฝังอยู่ยังคงถูกจำกัดด้วยความละเอียดต้นฉบับ
</TLDR>

กด Alt ค้างไว้เพื่อหยุดการเลื่อนและซูมขณะเลือกข้อความที่เลือกได้ใน SVG/HTML/PDF เมื่อปล่อยจะกลับสู่สถานะล็อกเดิม PNG ไม่มีชั้นข้อความที่เลือกได้

เลือก SVG, PNG และ/หรือ PDF พร้อมโฟลเดอร์ปลายทาง แล้วยืนยันครั้งเดียว การส่งออกหลักครอบคลุมทุกแผง ส่วนคำสั่งของแผงครอบคลุมเฉพาะแผงนั้น รูปแบบงานนำเสนอใช้ช่องทำเครื่องหมายและต้องเลือกอย่างน้อยหนึ่งรายการ ความคืบหน้าและความล้มเหลวบางส่วนยังคงแสดงอยู่

ติดตั้ง main.js, manifest.json และ styles.css ของ 1.9.14 ให้ตรงกัน แล้วโหลดปลั๊กอินใหม่ บันทึกและการตั้งค่าเดิมยังคงอยู่
