# Notemd 1.9.15 — แผนภาพอ่านง่ายและตัวอย่างที่เชื่อถือได้

<TLDR>
แผนภาพ ER เก็บชนิดฟิลด์ คีย์ PK/FK/UK ความคิดเห็น และจำนวนความสัมพันธ์ การวัดตารางร่วมกันช่วยปรับปรุงการส่งออก HTML/SVG และ Draw.io ส่วน Mermaid แยกรหัสคลาสและผู้เข้าร่วมไม่ให้ซ้ำกัน
</TLDR>

เมื่อเปิด .drawnix ที่บันทึกไว้ จะกู้คืนกระดานหลักก่อนภาพ Mermaid ที่แนบมา ตัวอย่าง Mermaid เริ่มต้นด้วยภาพรวมทั้งแผนภาพ สามารถเลือกและคัดลอกข้อความในบันทึกการส่งออกได้ Slidev บน Windows ตรวจสอบคอมโพเนนต์ Mermaid แบบเนทีฟและตรวจจับแผนภาพที่หายไป

ปัญหาการอ้างอิงต้นไม้และเลนที่กู้คืนได้ยังคงสร้างภาพพร้อมข้อมูลวินิจฉัย เส้นเชื่อมสั้นและการจัดวางกระชับช่วยให้อ่านง่าย ตัวอย่างลำดับที่ตรวจแล้วไม่เปลี่ยนแปลง รวมถึงผู้เข้าร่วมด้านล่าง เนื้อหาที่ไม่ถูกต้องหรือไม่ปลอดภัยอาจต้องแก้ไข

ติดตั้ง main.js, manifest.json และ styles.css ที่ตรงกันจาก 1.9.15 แล้วโหลดใหม่ บันทึกและการตั้งค่ายังคงอยู่ ลูกศร Drawnix ระหว่างกิ่งยังเป็นแบบคงที่หลังจัดเรียงใหม่ภายนอก
