# การตั้งค่า

<TLDR>เปิด Settings → Notemd แล้วค้นหาฟิลด์ ตั้งผู้ให้บริการและตำแหน่งผลลัพธ์ก่อนเริ่มงาน ทดลองการเปลี่ยนแปลงกับโน้ตเดียวก่อน งานที่กำลังทำอยู่อาจยังใช้ค่าที่อ่านเมื่อเริ่มงาน</TLDR>

## ภาพรวม

ผู้ให้บริการเริ่มต้นคือ DeepSeek และข้อมูลยืนยันตัวตนยังว่าง การเลือกโปรไฟล์ไม่ได้สร้างบัญชี ติดตั้งโมเดล หรือให้สิทธิ์ใช้งาน ดู [ผู้ให้บริการ](../providers/overview)

## ค้นหาและรายการโปรด

**Search settings** ค้นชื่อ คำอธิบาย ชื่ออื่น และหมวดที่มองเห็น แล้วนำไปยังฟิลด์ **★ Favorites** แสดงการตั้งค่าที่บันทึกไว้พร้อมคำอธิบาย หมวด และตำแหน่ง รายการถูกเก็บแยกตาม vault อยู่ต่อหลังเปิดโปรแกรมใหม่ และลบ ID เก่าที่ใช้ไม่ได้ คำค้นยังอยู่เมื่อยุบแถบเครื่องมือ รายการโปรดกับตัวกรองค้นหาเฉพาะรายการโปรดเป็นคนละส่วน

**Diagram preview export PPI** เริ่มที่ 300 ช่วง 72–600 และมีผลเฉพาะ PNG ส่วน SVG/PDF เก็บรูปทรงเวกเตอร์ที่รองรับ **Also export complete Mermaid visuals** ควบคุมไฟล์ประกอบ ไม่ได้ควบคุมว่า Mermaid จะแสดงในตัวอย่าง Drawnix หรือไม่

เลือกแผนภาพหลายประเภทในการทำงานครั้งเดียว และเลือกหลายรูปแบบผลลัพธ์แยกกันสำหรับแต่ละประเภท ยกเลิกการเลือกแล้วค่ารูปแบบยังคงอยู่ หากไม่เลือกเลย ระบบจะวิเคราะห์เนื้อหาอัตโนมัติ

กำหนดโฟลเดอร์ไฟล์ระหว่างทางร่วมกันด้วยพาธสัมพัทธ์ต่อ Vault หรือเว้นว่างเพื่อใช้ `notemd_assert/` ข้างแต่ละต้นฉบับ ที่นี่เก็บบันทึกการกู้คืน แคชการเรนเดอร์ และไฟล์แนบเสริม เก็บไฟล์ที่ยังถูกอ้างอิงไว้ การเปลี่ยนโฟลเดอร์มีผลเฉพาะงานใหม่

## 1. ผู้ให้บริการ

ระบุ endpoint ของโพรโทคอลที่ถูกต้อง คีย์ที่จำเป็น และโมเดลที่ใช้ได้ การดูรายชื่อกับการสร้างข้อความสำเร็จเป็นการตรวจคนละอย่าง ต้องเตรียมเซิร์ฟเวอร์/โมเดลภายในเครื่อง ส่วนคลาวด์หรือ gateway จะได้รับเนื้อหา ตรวจเส้นทางแยกตามงานด้วยก่อนใช้ข้อมูลส่วนตัว

## 2. โมเดลแยกตามงาน

`useMultiModelSettings` ให้เลือกผู้ให้บริการ/โมเดลสำหรับลิงก์ ชื่อเรื่อง การค้นคว้า การแปล แนวคิด ข้อความต้นฉบับ และ Mermaid แยกกัน ฟิลด์โมเดลที่ว่างใช้โมเดลของผู้ให้บริการ หากปิดตัวเลือกนี้จะใช้ผู้ให้บริการที่กำลังเลือก เปรียบเทียบความถูกต้อง เวลา และค่าใช้จ่ายจริงบนโน้ตเดียวกัน

## 3. ผลลัพธ์

| งาน | ผลลัพธ์เริ่มต้น |
| ------ | ------------------------- |
| เพิ่มลิงก์ | ไฟล์ `_processed.md` แยกข้างต้นฉบับ ปิดการย้ายต้นฉบับ |
| แยกแนวคิดแบบอิสระ | โฟลเดอร์แนวคิดที่เลือก มีเพียงชื่อเรื่องและปิดลิงก์ย้อนกลับ |
| แปล | ไฟล์ `_<language>.md` ข้างต้นฉบับ อาจเขียนทับปลายทางที่มีอยู่ |
| ค้นคว้า | เพิ่มสรุปใน Markdown ที่กำลังใช้งาน |
| สร้างจากชื่อเรื่องเป็นชุด | เขียนลงต้นฉบับที่เข้าเงื่อนไข แล้วจึงย้ายไป `<folder>_complete` ข้างกันเมื่อปลายทางอนุญาต |
| ตัวอย่าง/ส่งออกแผนภาพ | ไฟล์ที่เลือกจะส่งออกอัตโนมัติข้างโน้ตต้นฉบับหรือเข้าสู่โฟลเดอร์ผลลัพธ์ที่ตั้งไว้โดยตรง ชื่อระบุประเภท เช่น `topic_drawnix.pdf` และ `topic_flowchart.svg` หากชื่อซ้ำจะเติม `-2`, `-3` เป็นต้น โดยไม่เขียนทับไฟล์เดิม |
โฟลเดอร์แนวคิดเริ่มเป็นค่าว่าง `concepts` เป็นเพียงตัวอย่าง โน้ตที่แยกอิสระมีรูปแบบขั้นต่ำ/เต็ม ไม่ใช่ระบบตัวแปรแม่แบบทั่วไป ดู [แนวคิด](../features/concept-notes) การประมวลผลกับการแปลมี suffix และโฟลเดอร์แยกกัน ตรวจปลายทางและความขัดแย้งการกู้คืน การยกเลิกไม่ย้อนการเขียนที่เสร็จแล้ว

## 4. ภาษา

UI มี 21 ภาษา เว็บไซต์มี 34 เส้นทางภาษา `uiLocale: auto` เลือกการจับคู่ที่รองรับ มิฉะนั้นใช้ภาษาอังกฤษ ภาษาของเนื้อหาที่สร้างแยกต่างหากและเริ่มที่อังกฤษ งานที่รองรับอาจตั้งภาษาของตน ส่วนการแปลใช้ `language` ตัวเลขภาษาเหล่านี้ไม่พิสูจน์ความสามารถของโมเดล

## 5. การค้นหา

เลือก Tavily พร้อมคีย์ หรือ DuckDuckGo อย่างชัดเจน คีย์ Tavily ว่างไม่เปลี่ยนบริการ ทั้งคู่ใช้เครือข่าย และ DuckDuckGo อาจดึงหน้าผลลัพธ์ด้วย การค้นคว้าระหว่างสร้างจากชื่อเรื่องเริ่มปิดไว้ที่ `enableResearchInGenerateContent` การค้นข้อมูลในเครื่องก็ปิดไว้และมีขอบเขตโฟลเดอร์/งานแยก ส่วนข้อความภายในเครื่องที่นำมาเป็นบริบทจะถูกส่งให้ LLM ที่เลือก

## 6. เวิร์กโฟลว์

ใช้ตัวสร้างหรือ DSL หนึ่งบรรทัดพร้อมชื่อต่อหนึ่งปุ่ม

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` แยกชื่อจากการกระทำ และ `>` แยก ID การกระทำ นโยบายเริ่มต้นหยุดเมื่อมีรายงานข้อผิดพลาด ดู [เวิร์กโฟลว์](../features/workflows) สำหรับขอบเขตและผลของการทำต่อหลังผิดพลาด

## 7. การตั้งค่าขั้นสูง

| การตั้งค่า | ค่าเริ่มต้น | ผล |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | ผู้ให้บริการเมื่อไม่มีเส้นทางงานแยก |
| `useMultiModelSettings` | `false` | ผู้ให้บริการ/โมเดลแยกตามงาน |
| `useCustomConceptNoteFolder` | `true` | อนุญาตผลลัพธ์แนวคิดหลังเลือกโฟลเดอร์ |
| `conceptNoteFolder` | `''` | ยังไม่มีโฟลเดอร์แนวคิดเริ่มต้น |
| `extractConceptsMinimalTemplate` | `true` | เฉพาะชื่อเรื่องในแนวคิดแบบอิสระ |
| `extractConceptsAddBacklink` | `false` | ลิงก์ย้อนกลับในการแยกแบบอิสระ |
| `moveOriginalFileOnProcess` | `false` | รักษาต้นฉบับขณะเพิ่มลิงก์ |
| `chunkWordCount` | `3000` | ส่วนข้อความโดยประมาณ ไม่ใช่ขีดจำกัด token |
| `batchConcurrency` | `1` | การทำงานพร้อมกันเริ่มต้นของงานชุด |
| `enableBatchParallelism` | `false` | จัดตารางขนานบนเส้นทางที่ใช้ตัวเลือกนี้ |
| `enableStableApiCall` | `false` | โหมดคำขอแบบเสถียรที่เลือกอย่างชัดเจน |
| `customWorkflowErrorStrategy` | `stop_on_error` | หยุดเวิร์กโฟลว์เมื่อมีรายงานข้อผิดพลาด |

ขนาดส่วนข้อความกับงบ token ของคำตอบเป็นคนละค่า ส่วนที่เล็กลงไม่แก้ทุกขีดจำกัดบริบท และการทำงานพร้อมกันน้อยลงไม่ป้องกันทุกข้อผิดพลาด 429

## โปรไฟล์การตั้งค่า

การตั้งค่าเป็นข้อมูลปลั๊กอินใน vault ควรสำรองก่อนเปลี่ยน การส่งออกผู้ให้บริการมีสัญญาการปิดบังข้อมูลของตน ไม่ใช่ข้อมูลสำรองทั้ง vault ตรวจ endpoint และ metadata แม้ในผลที่ปิดบังแล้ว อย่าเผยแพร่การตั้งค่าดิบหรือข้อมูลวินิจฉัยที่มีโน้ตส่วนตัว

## ปัญหาการตั้งค่า

ทดสอบผู้ให้บริการ/โมเดลที่ระบุจริงกับโน้ตเล็ก หากไม่พบฟิลด์ ให้ตรวจการค้นหา หมวด การมองเห็นในโหมดนักพัฒนา และ vault แจ้งเวอร์ชันกับค่าขั้นต่ำที่ไม่มีความลับ

## 1.9.10 — ตัวอย่างที่ปลอดภัยและการตั้งค่าเฉพาะ Vault

ตัวอย่าง SVG ที่นำเข้าจะลบเนื้อหาที่ทำงานได้และทรัพยากรภายนอก โดยคงป้ายภาษาจีนและรูปแบบของแผงไว้ ผู้ให้บริการเฉพาะอุปกรณ์แยกตาม Vault แล้ว ให้นำเข้ารายการเก่าอย่างชัดเจนจากการตั้งค่า โดยรายการเดิมและการกำหนดค่าปัจจุบันจะยังอยู่ ตัวอย่างงานนำเสนอใช้เซิร์ฟเวอร์ loopback ที่จัดการผู้ใช้ร่วมกัน หากบันทึกรายการโปรดหรือคัดลอกล้มเหลวจะแจ้งข้อผิดพลาด การลบทำตามการตั้งค่า Vault ความเข้ากันได้ของ PNG ยังเปิดอยู่ โดยเก็บต้นฉบับและเพิ่มสำเนา PPI ต่ำที่ตรวจสอบแล้วเฉพาะเมื่อจำเป็น Drawnix ไม่มีเพดานความสัมพันธ์ตายตัว และงานนำเสนอยังใช้การตั้งค่าแยก ติดตั้งไฟล์รุ่นเดียวกัน โหลดใหม่ และทดสอบหนึ่งบันทึกก่อนทำงานเป็นชุด
