# การติดตั้ง

<TLDR>ติดตั้ง Notemd ผ่าน Community plugins หรือวางไฟล์ทำงานสามไฟล์จาก GitHub Release เดียวกันใน vault เปิดใช้ปลั๊กอิน เลือกผู้ให้บริการ แล้วทดลองกับโน้ตหนึ่งไฟล์ ส่วนเซิร์ฟเวอร์โมเดลและเครื่องมือส่งออกภายนอกต้องเตรียมแยกต่างหาก</TLDR>

## วิธีที่ 1: Community plugins ซึ่งเป็นวิธีแนะนำ

1. เปิด **Settings → Community plugins** ใน vault ที่ต้องการ
2. อนุญาตปลั๊กอินชุมชนหากจำเป็น แล้วเลือก **Browse**
3. ค้นหา **Notemd** ตรวจสอบว่าเป็น `Jacobinwwey/obsidian-NotEMD` แล้วเลือก **Install**
4. เลือก **Enable** และเปิดแถบด้านข้างจากแถบเครื่องมือหรือ command palette

[เปิด Notemd ใน Obsidian](obsidian://show-plugin?id=notemd) หากเบราว์เซอร์เปิดลิงก์ไม่ได้ ให้ใช้เมนูข้างต้น การอ่านคู่มือนี้ไม่จำเป็นต้องติดตั้งตัวจัดการโพรโทคอล

## วิธีที่ 2: ติดตั้งด้วยตนเอง

### สิ่งที่ต้องเตรียม

ต้องมี Obsidian และ vault ที่สำรองข้อมูลได้ เวอร์ชันขั้นต่ำ `0.15.0` ใน manifest เป็นข้อกำหนดที่ประกาศไว้ ไม่ใช่หลักฐานว่าได้ทดสอบรุ่นปัจจุบันบนเวอร์ชันเก่านั้นแล้ว

### ขั้นตอน

1. ดาวน์โหลด `main.js`, `manifest.json` และ `styles.css` จาก [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest) เดียวกัน ส่วน `README.md` เป็นเอกสารอ้างอิง ไม่ใช่ไฟล์ที่จำเป็นต่อการทำงาน
2. วางไฟล์ทั้งสามใน `<vault>/.obsidian/plugins/notemd/` หากเปลี่ยนโฟลเดอร์การตั้งค่า ให้ใช้พาธจริง
3. โหลด Obsidian ใหม่แล้วเปิดใช้ปลั๊กอิน
4. ตรวจสอบเวอร์ชัน อย่านำ manifest ใหม่ไปใช้กับ bundle เก่า

## ทางเลือก: BRAT

หากใช้งาน [BRAT](https://github.com/TfTHacker/obsidian42-brat) อยู่แล้ว สามารถเพิ่ม repository ผ่านขั้นตอนติดตั้งปลั๊กอินเบตาของ BRAT ได้ ควรเลือก release ที่แน่นอนเมื่อทำซ้ำข้อผิดพลาด BRAT เป็นเครื่องมือภายนอกที่ไม่จำเป็นต้องใช้

## ตรวจสอบการติดตั้ง

ตั้งค่าโมเดลที่เข้าถึงได้ เรียก **ทดสอบการเชื่อมต่อ** แล้วทำตาม [เริ่มต้นอย่างรวดเร็ว](./quick-start) การดึงรายชื่อโมเดลได้ไม่ยืนยันสิทธิ์ในการสร้างข้อความด้วยโมเดลนั้น ต้องตรวจสอบผลลัพธ์จริงด้วย

## ขอบเขตของระบบ

| ส่วน | ขอบเขต |
| --------- | ---------- |
| Manifest | Obsidian อย่างน้อย `0.15.0`; `isDesktopOnly` เป็น false |
| หลักฐานการทดสอบ | ดูรายงานที่ระบุวันที่ ยังไม่ได้ยืนยันบนอุปกรณ์มือถือจริงและเวอร์ชัน 0.15.0 ในการตรวจรับปัจจุบัน |
| โมเดลคลาวด์ | เครือข่าย บัญชี/คีย์ที่มีสิทธิ์ และโมเดลที่ใช้ได้ |
| โมเดลภายในเครื่อง | เซิร์ฟเวอร์ที่ติดตั้งและทำงานแยกต่างหาก พร้อมโมเดลที่ดาวน์โหลด/โหลดแล้ว |
| ส่งออกสไลด์หรือวงจรผ่านแอปภายนอก | เครื่องมือเดสก์ท็อปและ dependency ของแต่ละรูปแบบ ควรตรวจสอบสภาพแวดล้อมก่อน |

ไม่มีการรับประกันเวอร์ชันระบบปฏิบัติการเดียวที่ครอบคลุมเครื่องมือส่งออกทั้งหมด ภาพตัวอย่างวงจรไม่พิสูจน์ว่าคอมไพล์ TeX ได้ และการทดสอบบนเดสก์ท็อปไม่ยืนยันพฤติกรรมบนมือถือ

## ถอนการติดตั้ง

ปิดใช้หรือถอนผ่าน Community plugins โน้ตและไฟล์ที่สร้างไว้จะยังเป็นไฟล์ปกติใน vault ตรวจสอบก่อนลบ และเก็บสำเนาการตั้งค่าหากต้องการกลับมาใช้ การถอนปลั๊กอินไม่ได้ย้อนคืนการแก้ไขที่เสร็จแล้ว

## อัปเดต

ใช้ **Check for updates** หากอัปเดตด้วยตนเอง ให้หยุดงาน สำรอง vault และการตั้งค่า เปลี่ยนไฟล์ทำงานสามไฟล์จาก release เดียวกัน แล้วโหลดใหม่ อ่านบันทึกรุ่นและทดลองงานเล็กก่อนประมวลผลเป็นชุด อย่าแทนไฟล์การตั้งค่าด้วยไฟล์จาก release การย้อนรุ่นต้องเลือกเวอร์ชันที่เข้ากันได้และใช้ข้อมูลสำรองอย่างตั้งใจ
