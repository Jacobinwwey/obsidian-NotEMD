# เริ่มต้นอย่างรวดเร็ว

<TLDR>เริ่มจากโน้ต Markdown สำหรับทดลองและผู้ให้บริการที่คุณมีสิทธิ์ใช้ ตรวจสอบไฟล์ผลลัพธ์ก่อนทำทั้งโฟลเดอร์ งานบนคลาวด์จะส่งเนื้อหาออกไป ส่วนโมเดลภายในเครื่องก็ต้องมีเซิร์ฟเวอร์ที่ทำงานและโมเดลที่พร้อมแล้ว</TLDR>

## 1. ตั้งค่าโมเดล

1. [ติดตั้งและเปิดใช้](./installation) แล้วเปิด **Settings → Notemd**
2. เลือกโปรไฟล์ endpoint ข้อมูลยืนยันตัวตนที่จำเป็น และโมเดลที่เข้าถึงได้ **Fetch models** ไม่แทนการทดสอบสร้างข้อความ
3. เรียก **ทดสอบการเชื่อมต่อ** และแก้ปัญหาบัญชี โมเดล หรือที่อยู่
4. ค้นหา **เส้นทางโฟลเดอร์โน้ตแนวคิด** และเลือกโฟลเดอร์แยก เช่น `concepts` ค่าเริ่มต้นว่าง ชื่อนี้เป็นตัวอย่างที่คุณเลือกเอง

สำหรับ Ollama ให้ดาวน์โหลดโมเดลก่อนและใช้ชื่อที่ตรงกัน endpoint เริ่มต้นคือ `http://localhost:11434/api` สำหรับ LM Studio ให้เปิดเซิร์ฟเวอร์และเลือก `LMStudio` ดู [โมเดลภายในเครื่อง](../providers/local) แม้โมเดลสรุปจะอยู่ในเครื่อง การค้นคว้าเว็บก็ยังใช้เครือข่าย

## 2. งานแรก

สร้าง `Notemd trial.md` ด้วยข้อความสั้นที่อนุญาตให้ส่งแก่ผู้ให้บริการ เช่น

```text
การเรียนรู้ของเครื่องใช้โครงข่ายประสาทเทียมเพื่อเรียนรู้รูปแบบ
```

เรียก **ประมวลผลไฟล์ (เพิ่มลิงก์)** จากแถบด้านข้างหรือ palette โดยปกติต้นฉบับจะคงอยู่ และเกิด `Notemd trial_processed.md` ข้างกัน เปิดไฟล์จริงเพื่อตรวจสอบ ตัวอย่างผลที่เป็นไปได้คือ

```markdown
[[การเรียนรู้ของเครื่อง]]ใช้[[โครงข่ายประสาทเทียม]]เพื่อเรียนรู้รูปแบบ
```

อาจมีโน้ตเกิดขึ้นในโฟลเดอร์แนวคิดที่เลือกด้วย ตรวจสอบไฟล์และลิงก์ โมเดลไม่ได้รับประกันว่าจะพบทุกแนวคิดอย่างครบถ้วนและถูกต้อง

## 3. ฟังก์ชันอื่น

### แยกแนวคิด

**ดึงแนวคิด (ไฟล์ปัจจุบัน)** ไม่แก้ต้นฉบับและต้องมีโฟลเดอร์แนวคิด โน้ตที่แยกโดยอิสระจะมีเพียงชื่อเรื่องในตอนแรก และปิดลิงก์ย้อนกลับไว้ เปิดใช้โดยชัดเจนหากต้องการ ดู [โน้ตแนวคิด](../features/concept-notes)

### ค้นคว้าและสรุป

เลือกหัวข้อในตัวแก้ไข Markdown หรือใช้ชื่อโน้ต แล้วเรียก **ค้นคว้าและสรุป** เลือก Tavily พร้อมคีย์ หรือ DuckDuckGo อย่างชัดเจน ระบบเพิ่มสรุปในโน้ตปัจจุบัน เปิดแหล่งข้อมูลเพื่อตรวจสอบข้อกล่าวอ้าง

### เวิร์กโฟลว์คลิกเดียว

ค่าเริ่มต้นของ **One-Click Extract** คือ

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

ขั้นตอนนี้เพิ่มลิงก์ สร้างเนื้อหาจากชื่อเรื่องให้โน้ตที่เข้าเงื่อนไขในโฟลเดอร์แนวคิด/โฟลเดอร์ที่เลือก และซ่อม Mermaid ในโฟลเดอร์ complete อาจรวมโน้ตที่มีอยู่แล้ว จึงควรเริ่มด้วยโฟลเดอร์ทดสอบ การค้นคว้าเว็บและการสร้างแผนภาพทั่วไปไม่ได้ถูกเพิ่มโดยอัตโนมัติ

## ยกเลิกและตรวจสอบ

**ยกเลิก** หยุดงานถัดไปที่รองรับการยกเลิก ผลลัพธ์ที่เสร็จแล้วจะยังอยู่ นี่ไม่ใช่ธุรกรรมย้อนคืน และไม่รับประกันว่าการสร้างหรือการคิดค่าบริการฝั่งผู้ให้บริการจะหยุด รอให้จบ แล้วตรวจพาธและข้อขัดแย้งการกู้คืนก่อนเรียกใหม่

## ปัญหา

- บัญชี/โมเดล: ตรวจโปรไฟล์และการเชื่อมต่อ
- ไม่มีแนวคิด: ระบุพาธโฟลเดอร์ที่ไม่ว่างและเปิดใช้งาน
- ไม่มีลิงก์ที่มีประโยชน์: ตรวจคำตอบและพรอมป์ต์ ไม่มีความยาวขั้นต่ำที่รับประกันผล
- ข้อจำกัด: คงการทำงานพร้อมกันไว้ที่ `1` ขณะตรวจโควตา
