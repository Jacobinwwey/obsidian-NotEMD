# แผนภาพ

<TLDR>
เลือก **ประเภทของแผนภาพที่คุณต้องการ** จากนั้นเลือก **รูปแบบไฟล์ต้นฉบับที่สามารถแก้ไขได้** ดูตัวอย่างผลลัพธ์สุดท้ายใน Obsidian ซึ่งรวมถึงกระดาน Drawnix พร้อมภาพ Mermaid ที่ฝังอยู่ และสามารถส่งออกแต่ละหน้าต่างเป็นรูปแบบ SVG, PNG หรือ PDF ได้
</TLDR>

## เข้าใจตัวเลือกทั้งสามประเภท

| ตัวเลือก | ควบคุมอะไร | ตัวอย่าง |
|---|---|---|
| ประเภทแผนภาพ | ความหมายของแผนภาพ | แผนภาพกระแสงาน, แผนภาพลำดับเหตุการณ์, แผนภาพวงจรไฟฟ้า, แผนภูมิข้อมูล |
| รูปแบบไฟล์ต้นฉบับ | ไฟล์ที่สามารถแก้ไขหรือนำกลับมาใช้ใหม่ได้ซึ่ง Notemd จะสร้างขึ้น | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| รูปแบบการส่งออก | รูปภาพหรือเอกสารที่ใช้สำหรับแชร์ | SVG, PNG, PDF |

Draw.io และ Drawnix เป็น **รูปแบบไฟล์ต้นฉบับ** ไม่ใช่ประเภทของแผนภาพ CircuitikZ เป็นรูปแบบไฟล์ต้นฉบับที่ออกแบบมาสำหรับแผนภาพวงจรไฟฟ้า คุณสามารถส่งออกตัวอย่างเดียวกันในหลายรูปแบบภาพได้ ดังนั้นการเลือก CircuitikZ จึงไม่ได้จำกัดคุณให้ส่งออกเป็น SVG เท่านั้น

## เลือกรูปแบบไฟล์ต้นฉบับ

| รูปแบบ | เหมาะสำหรับ | ไฟล์ต้นฉบับ |
|---|---|---|
| Mermaid | แผนภาพที่เก็บอยู่ใน Markdown โดยตรง | บล็อกโค้ด Mermaid |
| JSON Canvas | กระบวนการทำงานบน canvas ของ Obsidian แบบดั้งเดิม | `.canvas` |
| Draw.io | การแก้ไขต่อใน diagrams.net หรือเครื่องมือที่สอดคล้องกัน | `.drawio` |
| Drawnix | การแก้ไขแบบวาดด้วยมือหรือแบบกระดานไวท์บอร์ด | `.drawnix` |
| CircuitikZ | วงจรไฟฟ้าและวงจรทรานซิสเตอร์ที่มีโครงสร้างชัดเจน | `.tex` |

หากคุณไม่ต้องการใช้โปรแกรมแก้ไขเฉพาะ ให้ตั้งค่า **Preferred source format** เป็น **Auto** Notemd จะเลือกรูปแบบที่เหมาะสมกับประเภทแผนภาพที่คุณเลือกให้โดยอัตโนมัติ

## สร้างและส่งออกแผนภาพ

1. เปิดบันทึกหรือเลือกข้อความที่คุณต้องการแสดงในรูปแบบแผนภาพ
2. เลือก **Generate diagram** จากแถบข้าง Notemd หรือ palette คำสั่ง
3. เลือก **ประเภทแผนภาพ** หรือปล่อยให้เป็น **Auto-detect**
4. เลือก **รูปแบบไฟล์ต้นฉบับ** หรือปล่อยให้เป็น **Auto** หากคุณต้องการแผนที่ความรู้ที่มีโหนดสามารถแก้ไขได้พร้อมภาพ Mermaid ที่ฝังอยู่ ให้เลือก **Drawnix**
5. ตรวจสอบตัวอย่างผลลัพธ์ สำหรับแผนภาพหลายหน้าต่าง จะมีกระดาน Drawnix และแต่ละหน้าต่าง Mermaid ในลำดับเดียวกันอยู่ภายในกล่องตัวอย่างที่สามารถเลื่อนขึ้นลงได้ โดยหน้าต่าง Mermaid จะแสดงความสูงที่ประมวลผลแล้ว ไม่ถูกตัดออก
6. เลือกการดำเนินการ **Export SVG**, **Export PNG** หรือ **Export PDF** สำหรับแต่ละหน้าต่างเพื่อส่งออกรูปภาพแยกกัน หรือใช้การส่งออกรูปภาพระดับบนสุดสำหรับทั้งหมด สำหรับหลายหน้าต่าง ให้เลือกโฟลเดอร์ต้นฉบับหรือโฟลเดอร์ที่กำหนดเองภายใน Vault Notemd จะสร้างไฟล์ที่มีค่าแน่นอนหนึ่งไฟล์ต่อหน้าต่าง และจะทำการสร้างต่อไปแม้ว่าจะเกิดข้อผิดพลาดในบางหน้าต่าง
7. ใช้ **Save source file** เมื่อคุณต้องการไฟล์ต้นฉบับที่สามารถแก้ไขได้ด้วย

เมนู Export จะมีตัวเลือก **Export SVG**, **Export PNG** และ **Export PDF** สำหรับตัวอย่างผลลัพธ์ที่กำลังดูอยู่ หัวข้อของแต่ละหน้าต่างจะมีตัวเลือกเดียวกันสำหรับ Mermaid หรือ Drawnix แต่ละชิ้น ดังนั้นจึงไม่จำเป็นต้องส่งออกตัวอย่างขนาดใหญ่เป็นรูปภาพที่มีความโปร่งใสเพียงชิ้นเดียว

เลือก **History** ในตัวอย่างผลลัพธ์เพื่อเปิดหน้าต่างประวัติ Vault โดยไม่ทำให้แผนภาพหายไป คุณสามารถค้นหาและกรองแผนภาพที่สร้างเสร็จแล้ว เปิดตัวอย่างใหม่ หรือเปิดไฟล์ที่บันทึกไว้ได้ นอกจากนี้ยังสามารถเข้าถึงประวัติแผนภาพได้โดยตรงจาก palette คำสั่งและแถบข้าง Notemd แม้ในขณะที่ไม่มีบันทึกใดเปิดอยู่ก็ตาม

SVG และ PDF จะถูกสร้างขึ้นจากเรขาคณิตเวกเตอร์ โดย PDF จะใช้โครงสร้าง SVG และมาตรวัดข้อความเดียวกัน ไม่ได้ทำการ rasterize ตัวอย่างทั้งหมด PPI สำหรับการส่งออกรูปภาพในการตั้งค่า Notemd จะควบคุมเฉพาะการ rasterize ของ PNG เท่านั้น (72-600 PPI โดยค่าเริ่มต้นคือ 300)

## ตัวอย่าง Drawnix ที่มีภาพ Mermaid ฝังอยู่

เมื่อไฟล์ Drawnix มีภาพ Mermaid อยู่ Notemd จะทำการปรับแต่ง SVG ที่ประมวลผลแล้ว และเก็บโค้ด Mermaid ไว้ใน metadata ของไฟล์ `.drawnix` ดังนั้นตัวอย่างผลลัพธ์จึงสามารถแสดงภาพ Mermaid ภายในแผนที่ความรู้ Drawnix ได้โดยไม่จำเป็นต้องมี Drawnix หรือ Plait runtime ส่วนภาพ Mermaid ที่ถูกฝังอย่างปลอดภัยจะไม่สร้างไฟล์ `.assets` แยกต่างหาก ในขณะที่สื่อบิตแบบภายนอกหรือภาพที่ยังไม่ได้ประมวลผลจะมีไฟล์ประกอบเพื่อให้ข้อมูลไม่สูญหาย

ตัวอย่างผลลัพธ์ถูกออกแบบมาให้เป็นพื้นที่เดียวที่สามารถเลื่อนขึ้นลงได้ โดยจะแสดงกระดาน Drawnix หลักก่อน ตามด้วยแต่ละหน้าต่าง Mermaid ที่ถูกฝังอยู่ในลำดับเดียวกัน การปิดและเปิดรายการประวัติที่บันทึกไว้ใหม่จะสร้างรายการหน้าต่าง ขนาด และตัวเลือกการส่งออกเดียวกันกลับมา

## แผนภาพวงจรไฟฟ้า

สำหรับคำขอที่เกี่ยวกับวงจรไฟฟ้าที่รองรับ Notemd จะให้เลือก **Circuit diagram** พร้อมใช้ **ไฟล์ต้นฉบับ CircuitikZ** โดย Notemd จะสร้างคำอธิบายวงจรที่มีโครงสร้างก่อน แล้วจึงเขียนไฟล์ต้นฉบับ CircuitikZ ตามมา วิธีนี้จะน่าเชื่อถือกว่าการให้โมเดลเขียน LaTeX แบบไม่มีข้อจำกัด

ปัจจุบันความสามารถในการรองรับ CircuitikZ ถูกจำกัดไว้โดยเจตนา โดยแอมพลิฟายเออร์ NMOS ที่มีโค้ดสาธารณะและบล็อก CMOS ที่รองรับจะให้ผลลัพธ์ที่ดีที่สุด เสมอต้องตรวจสอบตัวอย่างผลลัพธ์และโค้ดต้นฉบับก่อนนำวงจรที่สร้างขึ้นไปใช้ในงานทางเทคนิคหรือการเผยแพร่

ตัวอย่าง SVG คือไฟล์ที่ Notemd สร้างขึ้นมาเพื่อช่วยในการตรวจสอบเท่านั้น ไม่ใช่หลักฐานว่าการติดตั้ง LaTeX หรือ TikZJax ในเครื่องของคุณสามารถประมวลผลไฟล์ `.tex` ได้สำเร็จ

**การคอมไพล์แบบดั้งเดิม (Optional)** คุณไม่จำเป็นต้องใช้ LaTeX สำหรับการดูตัวอย่างภายในปลั๊กอิน หรือสำหรับการส่งออก SVG, PNG และ PDF ของตัวอย่าง บนเดสก์ท็อป คุณสามารถเปิด **CircuitikZ native compile environment** จากการตั้งค่าแผนภาพหรือ palette คำสั่ง เมื่อคุณต้องการดูข้อมูลการวินิจฉัยการคอมไพล์ หรือต้องการ PDF ที่ถูกสร้างโดย LaTeX แบบดั้งเดิม Notemd สามารถใช้ `tectonic` หรือ `pdflatex` ของระบบได้ หรือใช้ไฟล์คำสั่งที่กำหนดเอง หรือติดตั้ง Tectonic runtime แบบ managed ที่ถูกกำหนดไว้หลังจากที่คุณเลือก **Install** โดยตรง แผงการตั้งค่าสภาพแวดล้อมจะแสดงความคืบหน้าและข้อผิดพลาดแบบแทรกไว้ในเนื้อหา และยังช่วยให้คุณสามารถลบ runtime ที่ถูกจัดการออกได้ในภายหลัง

## การแก้ไขปัญหา

### ผลลัพธ์เป็นประเภทแผนภาพที่ไม่ถูกต้อง

ให้เลือกประเภทแผนภาพโดยตรงแทนการใช้ Auto-detect สำหรับวงจรไฟฟ้า ให้เลือก **Circuit diagram** และใช้คำสั่ง **Generate diagram** ไม่ใช่คำสั่งเก่า **Summarise as Mermaid diagram**

### รูปแบบไฟล์ต้นฉบับไม่เหมาะสม

ให้กลับไปตั้งค่ารูปแบบไฟล์ต้นฉบับเป็น **Auto** หรือเลือกรูปแบบที่เหมาะสมกับประเภทแผนภาพนั้น CircuitikZ เหมาะสำหรับแผนภาพวงจรไฟฟ้า ส่วน Draw.io และ Drawnix เหมาะสำหรับแผนภาพที่มีโครงสร้างที่รองรับ

### เมนู Export ไม่ปรากฏ

SVG, PNG และ PDF ต้องการตัวอย่างผลลัพธ์ที่เป็นรูปภาพ หากมีเพียงข้อความต้นฉบับเท่านั้น ให้บันทึกไฟล์ต้นฉบับแล้วเปิดในเครื่องมือภายนอกที่เหมาะสม

### ไฟล์ CircuitikZ ไม่สามารถคอมไพล์ภายนอกได้

ให้เปิด **CircuitikZ native compile environment** แล้วทำการตรวจสอบสภาพแวดล้อม ซ่อมแซม runtime ที่ถูกจัดการ หรือตรวจสอบให้แน่ใจว่าคอมไพเลอร์ของคุณสามารถดาวน์โหลด package `circuitikz` ได้ Notemd ไม่ได้รวม distribution TeX ที่สมบูรณ์ไว้ในไฟล์ปลั๊กอิน
