# การแปล

<TLDR>Notemd แปลไฟล์ปัจจุบันหรือไฟล์ที่เข้าเงื่อนไขในโฟลเดอร์ด้วย LLM ที่เลือก โดยปกติสร้างไฟล์แยกพร้อม suffix ภาษา คุณภาพขึ้นกับโมเดล จำนวน 21 ภาษา UI และ 34 ภาษาของไซต์ไม่ใช่ขอบเขตหรือคำรับประกันการแปล</TLDR>

## ภาพรวม

เลือกภาษาปลายทางและผู้ให้บริการ แล้วลองสำเนาที่มีศัพท์เฉพาะ ลิงก์ และโค้ด ฟังก์ชันนี้ใช้ LLM ไม่ใช่การเชื่อมต่อ Google Translate โดยเฉพาะ คำสั่งทำงานระดับไฟล์/โฟลเดอร์ หากจะแปลเพียงบางส่วนให้ย้ายไปโน้ตชั่วคราว การเลือกข้อความไม่จำกัดขอบเขตของ **แปลไฟล์ปัจจุบัน**

## วิธีทำงาน

### งานแปล

1. เลือกภาษาปลายทาง ซึ่งเริ่มที่อังกฤษและแยกจากภาษา UI
2. เปิดต้นฉบับแล้วเรียก **แปลไฟล์ปัจจุบัน**
3. ข้อความยาวจะถูกแบ่ง ส่งให้โมเดล แล้วรวมกลับ
4. เปิดพาธที่รายงาน ตรวจความหมาย คำศัพท์ ข้อความอ้างอิง ลิงก์ Markdown และโค้ด

การแปล `Example.md` เป็นฝรั่งเศสโดยปกติสร้าง `Example_fr.md` ข้างต้นฉบับที่ยังคงอยู่ หากไฟล์ผลลัพธ์มีอยู่แล้วจะเขียนทับ การเพิ่มท้ายต้นฉบับหรือสร้างหัวข้อคงที่ชื่อ `Translation` ไม่ใช่คำรับประกันของค่าเริ่มต้น

### คู่ภาษา

โมเดลอนุมานภาษาต้นทาง การมีภาษาในเมนูไม่พิสูจน์ความแม่นยำของคู่ภาษา ควรทดสอบข้อความหลายภาษาและศัพท์เฉพาะ การแบ่งส่วนอาจสูญเสียบริบท

### โมเดลตามงาน

เมื่อใช้เส้นทางตามงาน ระบบใช้ `translateProvider`/`translateModel` มิฉะนั้นใช้ผู้ให้บริการที่กำลังเลือก โมเดลภายในเครื่องต้องมีเซิร์ฟเวอร์/โมเดลพร้อม ส่วนคลาวด์ได้รับเนื้อหาและพรอมป์ต์ ประเมินด้วยตัวอย่างในสาขาของคุณแทนอันดับทั่วไป

### แปลโฟลเดอร์

**แปลโฟลเดอร์แบบกลุ่ม** ใช้เฉพาะไฟล์ลูกโดยตรงเป็นค่าเริ่มต้น โปรไฟล์ขั้นสูงอาจเปลี่ยนขอบเขตได้ ต้นฉบับชื่อเดียวกันที่ไปยังโฟลเดอร์เดียวอาจชนกัน ตรวจคำแปลเก่าและปลายทางก่อนทำซ้ำ

## การตั้งค่า

| การตั้งค่า | ค่าเริ่มต้น | ผล |
| --------- | --------- | -------- |
| `language` | `en` | ภาษาปลายทางที่เลือก |
| `translateProvider` | `DeepSeek` | ผู้ให้บริการเมื่อเปิดเส้นทางตามงาน |
| `translateModel` | `''` | ค่าว่างใช้โมเดลของผู้ให้บริการ |
| `useCustomTranslationSuffix` | `false` | ใช้รหัสภาษาเป็น suffix เริ่มต้น |
| `translationCustomSuffix` | `_translated` | suffix เมื่อเปิดตัวเลือกกำหนดเอง |
| `useCustomTranslationSavePath` | `false` | บันทึกข้างต้นฉบับเป็นค่าเริ่มต้น |
| `translationSavePath` | `''` | โฟลเดอร์ผลลัพธ์ที่กำหนดสัมพันธ์กับ vault |
| `batchConcurrency` | `1` | จำนวนงานพร้อมกันที่ขอสำหรับการแปลโฟลเดอร์ |

หากสร้างโฟลเดอร์กำหนดเองไม่ได้ อาจกลับไปใช้โฟลเดอร์ต้นฉบับ ให้อ่านพาธจริง suffix กำหนดเองที่ว่างอาจชี้กลับไปยังชื่อไฟล์ต้นฉบับ ใช้ suffix ที่แยกได้หากต้องการคำแปลเป็นอีกไฟล์

## ตัวอย่าง

คัดลอกโน้ตภาษาจีนสั้น ๆ ไปยังโฟลเดอร์ทดสอบ เลือกอังกฤษแล้วแปลไฟล์ เปรียบเทียบ `_en.md` กับต้นฉบับในด้านคำศัพท์ ตัวเลข สูตร และลิงก์ แล้วจึงเพิ่มขอบเขต

## การยกเลิกและตรวจสอบ

ยกเลิกเพื่อหยุดงานถัดไปที่รองรับ ไม่ได้ย้อนคำแปลที่เสร็จแล้วหรือรับประกันว่าจะหยุดการคิดค่าบริการ ตรวจรายงานและไฟล์ การคง Markdown เป็นคำสั่งให้โมเดล ไม่ใช่การรับประกันจากตัวแยกวิเคราะห์ว่าความหมายเท่ากัน

## ข้อแนะนำ

- สำรองต้นฉบับและตรวจชื่อชนกัน
- ใช้ suffix ทดสอบและโฟลเดอร์ผลลัพธ์แยก
- ตรวจโค้ด คณิตศาสตร์ URL และชื่อเฉพาะด้วยตนเอง
- ตรวจข้อมูลวินิจฉัยก่อนแบ่งปัน
