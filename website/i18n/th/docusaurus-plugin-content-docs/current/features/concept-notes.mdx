# โน้ตแนวคิด

<TLDR>การแยกแนวคิดแบบอิสระอ่านต้นฉบับและสร้างโน้ต Markdown ในโฟลเดอร์ที่เลือก เริ่มต้นยังไม่ได้กำหนดโฟลเดอร์ โน้ตใหม่มีเพียงชื่อเรื่องและไม่มีลิงก์ย้อนกลับ งานเพิ่มลิงก์ใช้รูปแบบโน้ตแนวคิดอีกแบบหนึ่ง</TLDR>

## ภาพรวม

ตั้ง **เส้นทางโฟลเดอร์โน้ตแนวคิด** ก่อน โฟลเดอร์แยกช่วยให้ตรวจผลลัพธ์ รายการซ้ำ และการสร้างจากชื่อเรื่องภายหลังได้ง่าย การแยกแนวคิดไม่ได้เติมคำอธิบายจากการค้นคว้าให้ไฟล์โดยอัตโนมัติ

## วิธีทำงาน

### การแยก

LLM ที่เลือกได้รับข้อความ จากนั้นงานอ่านบรรทัด `CONCEPT:` ตัดชื่อซ้ำภายในงาน และสร้างหรืออัปเดตไฟล์ โน้ตยาวถูกแบ่งเป็นส่วน ตรวจส่วนที่ล้มเหลวด้วย คำตอบจากโมเดลไม่ใช่รายการแนวคิดที่ครบถ้วนเสมอไป

### พรอมป์ต์สำหรับการแยก

ค่าเริ่มต้นขอแนวคิดที่เป็นรูปธรรมและเกี่ยวข้อง การระบุสาขาหรือคำพ้องไม่รับประกันศัพท์มาตรฐาน หากใช้พรอมป์ต์เองต้องคง `CONCEPT: Term` ดู [พรอมป์ต์](../advanced/custom-prompts)

### ส่วนข้อความ

`chunkWordCount` เริ่มที่ประมาณ 3000 คำ ไม่ใช่งบ token ของผู้ให้บริการ บริบทข้ามส่วนมีจำกัด จึงต้องตรวจความสัมพันธ์และชื่อที่กำกวม

## การสร้างไฟล์

### กฎการตั้งชื่อ

ระบบลบอักขระที่ใช้ในพาธไม่ได้ ปรับช่องว่างให้สม่ำเสมอ และตัดชื่อยาว ส่วนผลที่ว่างจะถูกข้าม คำต่างกันจึงอาจลงท้ายที่พาธเดียวกัน ตรวจชื่อก่อนสร้างจำนวนมาก

### แม่แบบ

รูปแบบขั้นต่ำของโน้ตใหม่คือ

```markdown
# ชื่อแนวคิด
```

หากต้องการลิงก์ย้อนกลับในโน้ตอิสระที่สร้างใหม่ ให้เปิด **Add "Linked From" backlink** และปิด **Create minimal concept notes**

```markdown
# ชื่อแนวคิด

## Linked From
- [[โน้ตต้นฉบับ]]
```

งานเพิ่มลิงก์ใช้รูปแบบเต็มพร้อมอ้างอิงต้นทางเมื่อเปิดผลลัพธ์แนวคิด ตัวเลือกของการแยกแบบอิสระไม่เปลี่ยนเส้นทางนี้

### โน้ตที่มีอยู่

เมื่อเปิดลิงก์ย้อนกลับ อาจเพิ่มอ้างอิงต้นทางที่ยังไม่มีใน `## Linked From` โดยรักษาเนื้อหาเดิมและไม่เพิ่มลิงก์เดิมซ้ำ ชื่อฐานของไฟล์ต้นทางอาจกำกวมเมื่อหลายโฟลเดอร์มีไฟล์ชื่อเดียวกัน

### การตั้งค่า

| การตั้งค่า | ค่าเริ่มต้น | ผล |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | สร้างผลลัพธ์แนวคิดหลังเลือกโฟลเดอร์ |
| `conceptNoteFolder` | `''` | ยังไม่กำหนดโฟลเดอร์ |
| `extractConceptsMinimalTemplate` | `true` | โน้ตแนวคิดอิสระมีเพียงชื่อเรื่อง |
| `extractConceptsAddBacklink` | `false` | ลิงก์ย้อนกลับในการแยกอิสระ |
| `extractConceptsProvider` | `DeepSeek` | ผู้ให้บริการเมื่อเปิดเส้นทางแยกตามงาน |
| `extractConceptsModel` | `''` | ค่าว่างใช้โมเดลของผู้ให้บริการ |
| `extractConceptsLanguage` | `en` | ภาษาเมื่อเปิดภาษาแยกตามงาน |
| `replaceSynonymsDuringConceptExtraction` | `false` | คำสั่งจำกัดคำพ้อง |
| `generateConceptLogFile` | `false` | สร้างบันทึกแนวคิดตามต้องการ |

## รายการซ้ำ

การตรวจใช้หลักประมาณจากชื่อไฟล์ ได้แก่ ตัวพิมพ์ใหญ่เล็ก พหูพจน์ การปรับสัญลักษณ์ และในกรณีที่อนุญาต การมีคำเดียวอยู่ในชื่ออื่น สิ่งนี้ไม่พิสูจน์ว่าความหมายเหมือนกัน ตรวจรูปคำผิดปกติและความต่างทางเทคนิคใน **ตรวจและลบรายการซ้ำ** และยืนยันเฉพาะการลบที่ตั้งใจ Obsidian จัดการการย้ายลงถังขยะ โฟลเดอร์แนวคิดไม่ใช่แคชที่ทิ้งได้ ควรสำรองก่อน

### ขอบเขตเปรียบเทียบ

เปรียบเทียบกับทั้ง vault โฟลเดอร์แนวคิดเอง โฟลเดอร์ที่รวมไว้ หรือขอบเขตที่มีรายการยกเว้น ขอบเขตเปลี่ยนกลุ่มผู้เข้าข่าย ไม่ได้เปลี่ยนความหมายของคำว่าซ้ำ

## การใช้

### แยกแบบอิสระ

เปิด Markdown ตรวจโฟลเดอร์ แล้วเรียก **ดึงแนวคิด (ไฟล์ปัจจุบัน)** ต้นฉบับคงเดิม ตรวจชื่อ ความครอบคลุม และลิงก์ย้อนกลับ

### แยกแล้วสร้างเนื้อหา

**สร้างแบบกลุ่มจากชื่อเรื่อง** เติมเนื้อหาให้แนวคิด แต่อาจรวมโน้ตเดิมที่เข้าเงื่อนไข ตรวจโฟลเดอร์ก่อน และตรวจโฟลเดอร์ complete ที่รายงานหลังจบ

### ลิงก์จากส่วนที่เลือก

การทำงานจากส่วนที่เลือกสร้าง wiki-link ให้คำที่คุณระบุ และอาจสร้างไฟล์แนวคิดหากกำหนดปลายทางแล้ว วิธีนี้ให้คุณเลือกคำเอง

## ข้อแนะนำ

- ใช้ต้นฉบับเล็กและโฟลเดอร์แนวคิดแยก
- เลือกภาษาก่อนสร้างไฟล์จำนวนมาก
- ประเมินคำพ้องกับรายการซ้ำแยกกัน
- เก็บบันทึกที่จำเป็นก่อนการเรียกครั้งถัดไปแทนที่
