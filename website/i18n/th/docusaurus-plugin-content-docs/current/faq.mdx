# คำถามที่พบบ่อย

<TLDR>เริ่มด้วยโน้ตทดลอง ผู้ให้บริการที่เข้าถึงได้ และปลายทางชัดเจน คำตอบต่อไปนี้อธิบายขอบเขตที่มีจริง ส่วนคู่มือให้ขั้นเตรียมและตรวจผลลัพธ์</TLDR>

## คำถาม

### ติดตั้ง Notemd อย่างไร

เปิด Settings → Community plugins → Browse ค้น Notemd ติดตั้งแล้วเปิดใช้ หากติดตั้งเองให้ใช้ main.js, manifest.json และ styles.css จาก GitHub Release เดียวกัน Manifest กำหนด Obsidian 0.15.0 แต่เวอร์ชันเก่านี้และอุปกรณ์มือถือจริงยังไม่ผ่านการยืนยันปัจจุบัน

### รองรับผู้ให้บริการ LLM ใดบ้าง

มี 36 โปรไฟล์ในห้ากลุ่ม ได้แก่ OpenAI-compatible, Anthropic, Google, Azure OpenAI และ Ollama คลาวด์ gateway และเซิร์ฟเวอร์ในเครื่องต้องมี endpoint คีย์ และโมเดลของตน การมีโปรไฟล์หรือรายการโมเดลไม่รับประกันความพร้อมปัจจุบันหรือสิทธิ์สร้างข้อความ

### ใช้โมเดลในเครื่องได้ไหม

ได้ ผ่าน Ollama, LM Studio, OVMS หรือเซิร์ฟเวอร์ของคุณที่ทำงานและเข้ากันได้ เตรียมโมเดลแล้วทดสอบงาน การรันในเครื่องไม่ได้ทำให้การค้นเว็บ การติดตั้ง dependency หรืองานที่แยกส่งไปคลาวด์ทำงานออฟไลน์

### ต่างจาก ChatGPT อย่างไร

Notemd เน้นงานเอกสารที่ชัดเจนใน Obsidian ได้แก่ ลิงก์ แนวคิด เพิ่มผลการค้นคว้า แปล และแผนภาพ เลือกตามงานใน vault ของคุณ เปรียบเทียบการเก็บข้อมูล การส่งออก และการเชื่อมต่อเวอร์ชันปัจจุบัน เครื่องมือสนทนาก็เก็บประวัติและสร้างเอกสารได้เช่นกัน

### เปรียบเทียบกับ Copilot หรือ Smart Connections อย่างไร

เปรียบเทียบงานจริงโดยใช้เวอร์ชัน การตั้งค่า และเอกสารปัจจุบัน Notemd ประมวลผลโน้ตและให้การค้นตามคำในขอบเขตจำกัด ไม่ใช่แชตทั้ง vault หรือ semantic search ด้วย embeddings ไม่ได้อ้างอันดับปัจจุบันเหนือโครงการอื่น

### Notemd ใช้เครื่องมือค้นหาใด

เลือก Tavily พร้อมคีย์ หรือ DuckDuckGo อย่างชัดเจน คีย์ Tavily ที่ว่างไม่เปลี่ยนบริการ ทั้งคู่ใช้เครือข่าย LLM สรุปบริบทจากเว็บและข้อความในเครื่องที่เลือกเปิด แล้วเพิ่มใน Markdown ปัจจุบัน ตรวจ URL และข้อกล่าวอ้างสำคัญ

### มีภาษาใดบ้าง

UI มี 21 ภาษาและเว็บไซต์มี 34 เส้นทางภาษา ภาษาที่ให้โมเดลสร้างเลือกแยกต่างหากและกำหนดต่อบางงานได้ ขอบเขตและคุณภาพการแปลขึ้นกับโมเดล ไม่ใช่จำนวนเหล่านี้

### ใช้บทความวิจัยหรือ PDF ได้ไหม

แปลงเป็น Markdown ด้วยเครื่องมือภายนอกที่เหมาะก่อน แล้วตรวจสูตร ตาราง และภาพ จากนั้นใช้การแยกแนวคิด ข้อความต้นฉบับ ค้นคว้า แปล หรือแผนภาพ ไม่ได้รับรอง PDF OCR ในตัวหรือการดึงข้อมูลจากทุกไฟล์ไบนารีอย่างไร้ข้อผิดพลาด

### มีแผนภาพแบบใดบ้าง

รายการที่รันได้มี 33 รายการพร้อมแหล่งข้อมูลและ preview ที่เข้ากัน Mermaid, JSON Canvas, Vega-Lite, HTML/SVG ที่แก้ได้, Draw.io, Drawnix และ CircuitikZ ที่จำกัดขอบเขตเหมาะกับงานต่างกัน เลือกคู่ที่รองรับและทดสอบแอปปลายทาง Preview ไม่พิสูจน์การแก้ไขหรือคอมไพล์ในแอปจริง

### Notemd ฟรีและเป็นโอเพนซอร์สไหม

Notemd ใช้ MIT license มี repository สาธารณะและเปิดรับการมีส่วนร่วม ผู้ให้บริการ การรันโมเดล การค้นหา และเครื่องมือภายนอกมีค่าใช้จ่ายและเงื่อนไขของตน ใบอนุญาตปลั๊กอินไม่ได้ทำให้บริการที่เชื่อมทั้งหมดฟรี

### ทุกอย่างทำงานออฟไลน์ไหม

บางงานใช้โมเดลในเครื่องได้หลังเตรียมเซิร์ฟเวอร์ โมเดล และ dependency การค้นเว็บรวม DuckDuckGo ยังต้องออนไลน์ ตรวจเส้นทางงานและสิ่งที่การส่งออกต้องใช้ก่อนตัดเครือข่าย ไม่มีการรับประกันออฟไลน์ทุกกรณี

### ข้อมูลส่งไปคลาวด์หรือไม่

พรอมป์ต์และเนื้อหาถูกส่งไปยัง LLM endpoint ที่ตั้งไว้ ผู้ให้บริการค้นหาได้คำค้น เว็บไซต์ได้คำขอ ข้อความในเครื่องอาจรวมในพรอมป์ต์คลาวด์ และโปรไฟล์ในเครื่องอาจชี้ไป host ระยะไกล ตรวจเส้นทางกับข้อมูลวินิจฉัย การเก็บไฟล์ในเครื่องไม่รับประกันการประมวลผลในเครื่องทั้งหมด

### One-Click Extract ทำอะไร

ชุดเริ่มต้นเพิ่มลิงก์ สร้างเนื้อหาจากชื่อเรื่องให้โน้ตที่เข้าเงื่อนไขในโฟลเดอร์แนวคิด/โฟลเดอร์ที่เลือก และซ่อม Mermaid ใน complete อาจรวมแนวคิดที่มีอยู่แล้ว ไม่เพิ่มการค้นคว้าเว็บหรือสร้างแผนภาพโดยอัตโนมัติ คู่มือแสดง DSL ตรงจริงแบบ name::action>action

### การยกเลิกย้อนการเปลี่ยนแปลงหรือไม่

ไม่ ยกเลิกหยุดงานต่อไปที่รองรับและคงผลลัพธ์ที่เสร็จ คำขอหรือการเขียนที่รับแล้วอาจทำจนจบ ผู้ให้บริการกำหนดการคิดค่าบริการ รอ ตรวจพาธและข้อขัดแย้ง แล้วทำซ้ำเฉพาะที่จำเป็น

### Agent ใช้ Notemd อัตโนมัติได้ไหม

มีคำสั่งสาธารณะที่จำกัดสี่รายการสำหรับส่งออกโปรไฟล์ที่ปิดบังข้อมูล ความสามารถ สัญญาการเรียก และอินเทอร์เฟซ CLI สาธารณะ ผ่าน Obsidian และ vault ที่ใช้งานได้ คำสั่งเขียนไฟล์ผลลัพธ์ Operations สำหรับผู้ดูแลใน repository เป็นอีกส่วน จำนวนภายในไม่ใช่ API สาธารณะ เริ่มที่คู่มือ Agent

### นักพัฒนาควรเริ่มจากไหน

คู่มือนักพัฒนาบอกสภาพแวดล้อม build การทดสอบทั้งหมด เจ้าของโมดูล และสัญญาสำหรับขยายงาน AGENTS.md เป็นข้อกำหนดการทำงานที่อยู่ในการควบคุมเวอร์ชัน รายงานกรณีทำซ้ำพร้อมเวอร์ชันชัดเจนและหลักฐานที่ลบข้อมูลส่วนตัว แล้วตรวจให้ผ่านก่อนรวมโค้ด
