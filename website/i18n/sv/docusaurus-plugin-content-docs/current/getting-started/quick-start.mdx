# Snabbstart

<TLDR>Börja med en testanteckning i Markdown och en leverantör du har tillgång till. Granska resultatfilen innan du kör en hel mapp. Molnuppgifter skickar innehåll; lokala modeller kräver en aktiv server och en förberedd modell.</TLDR>

## 1. Konfigurera modellen

1. [Installera och aktivera](./installation), öppna **Settings → Notemd**.
2. Välj profil, endpoint, nödvändiga autentiseringsuppgifter och tillgänglig modell. **Fetch models** ersätter inte ett genereringstest.
3. Kör **Test connection** och åtgärda konto-, modell- eller adressfel.
4. Sök efter **Concept note folder path** och välj en separat mapp, exempelvis `concepts`. Standardvärdet är tomt; namnet är ditt val.

Hämta först Ollama-modellen och använd dess exakta namn; standardadressen är `http://localhost:11434/api`. Starta LM Studios server och välj `LMStudio`. Se [lokala modeller](../providers/local). Webbforskning kräver nätverk även med lokal sammanfattningsmodell.

## 2. Första uppgiften

Skriv en kort text som får skickas till leverantören i `Notemd trial.md`:

```text
Maskininlärning använder neurala nätverk för att lära sig mönster.
```

Kör **Process file (add links)** från sidopanelen eller paletten. Som standard bevaras originalet och `Notemd trial_processed.md` skapas intill. Öppna resultatet. Ett möjligt exempel:

```markdown
[[Maskininlärning]] använder [[neurala nätverk]] för att lära sig mönster.
```

Anteckningar kan också skapas i den valda begreppsmappen. Kontrollera filer och länkar; modellen garanterar inte en fullständig eller korrekt begreppslista.

## 3. Andra funktioner

### Extrahera begrepp

**Extract concepts (current file)** ändrar inte källan och kräver en begreppsmapp. Nya fristående anteckningar får initialt bara en titel, utan bakåtlänk. Aktivera den uttryckligen vid behov. [Begreppsanteckningar](../features/concept-notes).

### Undersök och sammanfatta

Välj ämne i Markdown-redigeraren eller använd titeln och kör **Research & summarize**. Välj uttryckligen Tavily med nyckel eller DuckDuckGo. Sammanfattningen läggs till i aktuell anteckning. Öppna källorna och kontrollera påståendena.

### Arbetsflöde med ett klick

Standardflödet **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Det lägger till länkar, fyller lämpliga anteckningar i begreppsmappen/vald mapp från titlar och reparerar Mermaid i complete-mappen. Befintliga anteckningar kan ingå. Börja i en testmapp. Webbforskning och generell diagramgenerering ingår inte automatiskt.

## Avbryt och granska

**Cancel** stoppar efterföljande arbete där det stöds. Färdiga resultat ligger kvar; det är ingen återställningstransaktion och garanterar inte stoppad fjärrgenerering eller debitering. Vänta på avslut och kontrollera sökvägar och återställningskonflikter före omkörning.

## Problem

- Konto/modell: kontrollera profil och anslutning.
- Inga begrepp: ange en aktiverad, icke-tom mappsökväg.
- Inga användbara länkar: granska svar och prompt; ingen minsta textlängd garanterar resultat.
- Begränsningar: behåll samtidighet `1` medan du undersöker kvoter.
