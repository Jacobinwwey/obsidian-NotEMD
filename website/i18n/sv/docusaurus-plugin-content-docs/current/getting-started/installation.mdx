# Installation

<TLDR>Installera Notemd via Community plugins eller lägg de tre körningsfilerna från samma GitHub Release i valvet. Aktivera tillägget, välj leverantör och testa en anteckning. Modellservrar och valfria inbyggda exportverktyg förbereds separat.</TLDR>

## Metod 1: Community plugins, rekommenderad

1. Öppna **Settings → Community plugins** i avsett valv.
2. Tillåt community-tillägg vid behov och välj **Browse**.
3. Sök efter **Notemd**, kontrollera `Jacobinwwey/obsidian-NotEMD` och välj **Install**.
4. Välj **Enable** och öppna sidopanelen via verktygsfältet eller kommandopaletten.

[Öppna Notemd i Obsidian](obsidian://show-plugin?id=notemd). Använd menyn ovan om webbläsaren inte kan öppna länken; dokumentationen kräver ingen protokollhanterare.

## Metod 2: Manuell installation

### Förutsättningar

Du behöver Obsidian och ett valv som kan säkerhetskopieras. Manifestets minimiversion `0.15.0` är en deklaration, inte bevis på färsk verifiering på den versionen.

### Steg

1. Hämta `main.js`, `manifest.json` och `styles.css` från samma [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` är referensmaterial, ingen obligatorisk körningsfil.
2. Lägg filerna i `<vault>/.obsidian/plugins/notemd/`; anpassa sökvägen om konfigurationsmappen har ändrats.
3. Ladda om Obsidian och aktivera tillägget.
4. Kontrollera versionen. Blanda inte ett nytt manifest med en gammal bundle.

## Alternativ: BRAT

Använder du redan [BRAT](https://github.com/TfTHacker/obsidian42-brat), lägg till projektet genom dess flöde för betatillägg. Använd en bestämd release vid felsökning. BRAT är ett valfritt externt verktyg.

## Verifiering

Konfigurera en tillgänglig modell, kör **Test connection** och sedan [snabbstarten](./quick-start). En modellförteckning bevisar inte rätt att generera med en viss modell; granska faktisk utdata.

## Systemgränser

| Del | Gräns |
| --------- | ---------- |
| Manifest | Minst Obsidian `0.15.0`; `isDesktopOnly` är false |
| Verifiering | Se daterade rapporter; fysiska mobiler och 0.15.0 är inte verifierade i den aktuella acceptansen |
| Molnmodell | Nätverk, behörigt konto/nyckel och tillgänglig modell |
| Lokal modell | Separat installerad, aktiv server och hämtad/laddad modell |
| Inbyggd bildspels- eller kretsexport | Skrivbordsverktyg och formatberoenden; kontrollera miljön först |

Det finns ingen gemensam OS-garanti för alla valfria exportörer. En kretsförhandsvisning bevisar inte TeX-kompilering; skrivbordstester bevisar inte mobilbeteende.

## Avinstallera

Inaktivera eller avinstallera via Community plugins. Skapade anteckningar och artefakter ligger kvar som vanliga valvfiler. Granska dem före borttagning och spara inställningarna vid behov. Avinstallation återställer inte tidigare ändringar.

## Uppdatera

Använd **Check for updates**. Vid manuell uppdatering: stoppa uppgifter, säkerhetskopiera valv och inställningar, ersätt de tre körningsfilerna från samma release och ladda om. Testa smått före batcher. Ersätt inte inställningsfilen med releasefiler. Återgång kräver en avsiktligt vald kompatibel version och säkerhetskopia.
