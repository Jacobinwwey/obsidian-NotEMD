# Konfiguration

<TLDR>Öppna Settings → Notemd och sök efter fältet. Välj leverantör och utdatasökväg före körning. Testa ändringar på en anteckning; en pågående uppgift kan behålla inställningarna från start.</TLDR>

## Översikt

Standardleverantören är DeepSeek utan autentiseringsuppgifter. Att välja profil skapar inget konto, installerar ingen modell och ger inga rättigheter. Se [leverantörer](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Sökning och favoriter

**Search settings** söker namn, beskrivningar, alias och synliga kategorier och leder till fältet. **★ Favorites** visar sparade inställningar med beskrivning, kategori och destination. De sparas per valv, överlever omstart och rensar gamla ID:n. Sökningen bevaras när verktygsfältet fälls ihop. Favoritlistan är skild från filtret som bara söker favoriter.

**Diagram preview export PPI** börjar på 300, tillåter 72–600 och påverkar bara PNG. SVG/PDF bevarar stödd vektorgeometri. **Also export complete Mermaid visuals** styr följeslagarfiler, inte om Mermaid visas i Drawnix-förhandsvisningen.

## 1. Leverantör

Ange endpoint för rätt protokoll, nödvändig nyckel och tillgänglig modell. Modellista och lyckad generering är skilda kontroller. Förbered lokal server/modell; moln/gateway tar emot innehåll. Kontrollera även uppgiftsspecifika vägar innan privat material används.

## 2. Modell per uppgift

`useMultiModelSettings` ger separata leverantörer/modeller för länkar, titlar, forskning, översättning, begrepp, originaltext och Mermaid. Tom override använder vald leverantörs modell; avstängt använder aktiv leverantör. Jämför noggrannhet, latens och verklig kostnad på samma anteckning.

## 3. Utdata

| Uppgift | Standardresultat |
| ------ | ------------------------- |
| Länkar | Separat `_processed.md` intill källan; flytt av original avstängd |
| Fristående begreppsextraktion | Vald begreppsmapp; bara titel, bakåtlänkar av |
| Översättning | Intilliggande `_<language>.md`; befintligt mål kan skrivas över |
| Forskning | Sammanfattning läggs till i aktiv Markdown |
| Batchgenerering från titlar | Skriver lämpliga källor och flyttar till intilliggande `<folder>_complete` om målet tillåter |
| Diagramförhandsvisning/export | Välj stödd källa eller visuell export och kontrollera rapporterad sökväg |

Begreppsmappen är tom från början; `concepts` är ett exempel. Fristående extraktion har minimal/full form, ingen generell mallmotor. [Begrepp](../features/concept-notes). Bearbetning och översättning har separata suffix och mappar. Kontrollera mål och återställningskonflikter; avbrott ångrar inte slutförda skrivningar.

## 4. Språk

UI har 21 språkversioner, webbplatsen 34 språkrutter. `uiLocale: auto` väljer stödd mappning; annars används engelska. Genereringsspråk är separat, initialt engelska. Stödda uppgifter kan ha eget språk; översättning använder `language`. Antalen bevisar inte modellens språkförmåga.

## 5. Sökning

Välj Tavily med nyckel eller DuckDuckGo uttryckligen. Tom Tavily-nyckel växlar inte leverantör. Båda använder nätverk; DuckDuckGo kan hämta resultatsidor. Forskning vid titelgenerering är av: `enableResearchInGenerateContent`. Lokal hämtning är också av, med egna mapp-/uppgiftsgränser. Inkluderade lokala utdrag skickas till vald LLM.

## 6. Arbetsflöden

Använd byggaren eller en namngiven DSL-rad per knapp:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` skiljer namn från åtgärder, `>` skiljer åtgärds-ID:n. Standardpolicyn stoppar vid rapporterat fel. Se [arbetsflöden](../features/workflows) för omfång och fortsatt körning efter fel.

## 7. Avancerade inställningar

| Inställning | Standard | Effekt |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Leverantör utan separat uppgiftsväg |
| `useMultiModelSettings` | `false` | Leverantör/modell per uppgift |
| `useCustomConceptNoteFolder` | `true` | Tillåt begreppsutdata när en mapp valts |
| `conceptNoteFolder` | `''` | Ingen begreppsmapp initialt |
| `extractConceptsMinimalTemplate` | `true` | Endast titel i fristående begrepp |
| `extractConceptsAddBacklink` | `false` | Aktivera bakåtlänkar vid fristående extraktion |
| `moveOriginalFileOnProcess` | `false` | Behåll original vid länkning |
| `chunkWordCount` | `3000` | Ungefärliga textdelar, ingen tokengräns |
| `batchConcurrency` | `1` | Standard för batchsamtidighet |
| `enableBatchParallelism` | `false` | Parallell schemaläggning på vägar som använder omkopplaren |
| `enableStableApiCall` | `false` | Uttryckligt stabilt anropsläge |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stoppa arbetsflödet vid rapporterat fel |

Textdelarnas storlek är skild från utdatas tokenbudget. Mindre delar löser inte alla kontextgränser; lägre samtidighet förhindrar inte alla 429-fel.

## Inställningsprofiler

Inställningar är tilläggsdata i valvet. Säkerhetskopiera före ändringar. Leverantörsexport har ett eget kontrakt för maskering, inte en fullständig säkerhetskopia. Granska endpoints och metadata även i maskerad utdata. Publicera inte råa inställningar eller diagnostik med privata anteckningar.

## Konfigurationsproblem

Testa exakt leverantör/modell med en liten anteckning. Saknas ett fält, kontrollera sökning, kategori, utvecklarläge och valv. Rapportera version och minimala inställningar utan hemligheter.
