# Anthropic

<TLDR>Använd profilen för native Messages. Claude genom OpenAI-kompatibel gateway använder gatewayprofilen. Den historiska standardmodellen kan behöva ersättas med en tillgänglig modell.</TLDR>

## Förberedelse

Välj **Anthropic**, nyckel och modell du har åtkomst till. Behåll native-adressen om deploymenten inte uttryckligen erbjuder samma protokoll. Testa anslutning och anteckning.

## Endpoint och autentisering

| Fält | Standard |
| ------- | -------------- |
| Transport | `anthropic` |
| API-nyckel | Obligatorisk |
| Bas-URL | `https://api.anthropic.com` |
| Modell | `claude-3-5-sonnet-20240620` |
| Temperatur | `0.5` |
| Anslutningstest | `chat-only` |

Runtime använder `/v1/messages` och native nyckel-/versionsheaders. Lägg inte till OpenAI-chatvägar. Standardvärden beskriver projektets konfiguration, inte aktuell modellåtkomst.

## Modeller

Använd native modellupptäckt där den tillåts. Om listan blockeras, ange behörigt ID och testa generering. Långa och strukturerade uppgifter kräver separata kontroller.

## Problem

- 401/403: nyckel, projekt, betalning och modellrättigheter.
- 404: adress och tillgänglighet.
- Gateway-ID avvisas: välj rätt profil och identifierare.
- Långa anrop misslyckas: undersök gränser före fler omförsök.

## När profilen passar

För native Messages-endpoints. Jämför med egna källor utan generell leverantörsrankning; använd uppgiftsstyrning för avgränsat modellval.
