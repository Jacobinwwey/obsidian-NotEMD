# Google

<TLDR>Google-profilen använder native Gemini Generative Language. Ange behörig nyckel och tillgänglig modell. Gemini genom kompatibel gateway använder gatewayprofilen.</TLDR>

## Förberedelse

Välj **Google**, nyckel, native endpoint och modell för vald API-version. Testa anslutning och anteckning. Detta konfigurerar inte godtyckliga Google Cloud-/Vertex-deployments automatiskt.

## Endpoint och autentisering

| Fält | Standard |
| ------- | -------------- |
| Transport | `google` |
| API-nyckel | Obligatorisk |
| Bas-URL | `https://generativelanguage.googleapis.com/v1` |
| Modell | `gemini-2.0-flash-exp` |
| Temperatur | `0.5` |
| Anslutningstest | `chat-only` |

Runtime gör `generateContent`-anrop med nyckel. Historiska ID:n garanterar inte åtkomst. Granska diagnostik-URL:er före delning; de kan innehålla autentisering.

## Modeller

Använd native upptäckt och verifiera generering på vald API. Tom lista kan bero på rättigheter, endpoint eller saknad modell. Felsök före protokollbyte.

## Problem

- 400: ID, parametrar och in-/utdatagränser.
- 401/403: nyckelbegränsningar, aktiverad API och behörighet.
- 404: finns modellen i denna API-version?
- Gatewayexempel: använd rätt OpenAI-kompatibel profil.

## När profilen passar

För native Gemini. Testa översättning, forskning eller diagram med eget material. Inga generella löften om hastighet, kostnad eller kvalitet.
