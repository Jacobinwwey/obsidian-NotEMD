# Kinesiska leverantörer

<TLDR>Välj profil för kontot och deploymenten. Även med gemensamt OpenAI-kompatibelt protokoll är regioner, sökvägar, modeller och rättigheter inte utbytbara. Verifiera en liten uppgift.</TLDR>

## Förberedelse

Ordna konto/nyckel, välj profil och kontrollera region och modellåtkomst. Standarder garanterar inte aktuell tillgänglighet. Testa både anslutning och anteckning.

## Modeller

Använd listor där de tillåts. Huawei Cloud MaaS kräver deploymentkunskap; övriga använder stödd OpenAI-kompatibel upptäckt. Saknad listrätt utesluter inte alltid generering med exakt ID. DeepSeek kan klara anslutningstest på lista; flera regionala profiler genererar kort. Verifiera faktisk uppgift.

## Problem

- Nyckel godtas men generering nekas: modellrätt, deployment och region.
- Ark-ID nekas: krävs endpoint-ID eller modell-ID?
- Resonemang kapas: budget och modellspecifik thinking.
- Nätverk: kontrollera adress från Obsidian och läs transportfelet.

## När profilen passar

När kontoåtkomst, tillgänglighet och datavillkor passar. Geografi bevisar inte språkkvalitet eller låga priser. Jämför samma exempel och dokumentera inställningarna.
