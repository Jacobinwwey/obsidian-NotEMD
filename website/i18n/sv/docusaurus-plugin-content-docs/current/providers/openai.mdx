# OpenAI

<TLDR>Profilen använder den delade OpenAI Chat Completions-runtimevägen. Välj nyckel och modell för det protokollet. Standardmodellen garanterar inte aktuell åtkomst eller generell kvalitet.</TLDR>

## Förberedelse

Välj **OpenAI**, nyckel och `https://api.openai.com/v1` för officiell tjänst. En listad modell kan kräva annan API. Gateways har egna profiler/headers; Azure använder **Azure OpenAI**, deployment och API-version.

## Endpoint och autentisering

| Fält | Standard |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API-nyckel | Obligatorisk |
| Bas-URL | `https://api.openai.com/v1` |
| Modell | `gpt-4o` |
| Temperatur | `0.5` |
| Anslutningstest | `models-then-chat` |

Kända URL-former normaliseras före konstruktion av anropsvägar. Utgå från profilen och kontrollera den upplösta adressen i stället för att godtyckligt lägga till segment.

## Modeller

**Fetch models** listar tillgängliga modeller. **Test connection** kan lyckas med enbart listan. Kör en anteckning med exakt modell. Reasoning, thinking, sampling och budget måste passa profil/modell.

## Problem

- 401/403: nyckel, projekt, rättigheter och konto.
- 404: endpoint, modell-ID och API-stöd.
- Lista fungerar men inte generering: kontrollera chatfelet och parametrar.
- Långt svar avbryts: granska indata, budget och svar; kort test täcker inte detta.

## När profilen passar

För direkta OpenAI-endpoints som stöder Chat Completions. Bedöm egna anteckningar; priser och tillgänglighet förändras oberoende av Notemd.
