# Arbetsflöden

<TLDR>Ett arbetsflöde kör sidopanelsåtgärder i följd. En åtgärd kan kräva mappval eller aktiv redigerare. Det är ingen textpipeline: varje steg behåller egna indata, utdata och sidoeffekter. Börja med en testanteckning och separat mapp.</TLDR>

## Översikt

Medföljande **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Lägg till länkar i aktiv anteckning och skapa begrepp om mapp är vald.
2. Generera innehåll för lämpliga anteckningar i begrepps- eller vald mapp, inklusive befintliga filer.
3. Reparera Mermaid i genereringens complete-mapp.

Standardkedjan gör ingen webbforskning. Titelgenerering kan lägga till den via separat inställning. Se [batcher](../advanced/batch-processing).

## Så fungerar det

### Körning

Stegen körs sekventiellt med status och fel i sidopanelen. Avbrott stoppar kommande steg och når stödda anrop. Färdiga filer bevaras; kedjan är ingen transaktion. Begreppsmappen är första mappval. Batchgenerering sparar käll- och complete-kontext, och Mermaid använder complete. Övriga åtgärder behåller krav på fil, markering och interaktion.

### DSL

En namngiven knapp per rad. `::` skiljer namn från åtgärder och `>` skiljer ID:n. Tomma rader och rader som börjar med `#` ignoreras; okända ID:n avvisas.

```text
Extrahera och rita::extract-concepts-current>summarize-as-mermaid
```

Använd byggaren eller redigera DSL. ID:n är stabila, etiketter följer UI-språket. Mappvarianter har egna ID:n; härled dem inte med godtycklig textersättning.

| ID | Åtgärd / krav |
| ------------ | ----------------------- |
| `process-current-add-links` | Länkar i aktiv anteckning |
| `process-folder-add-links` | Länkar i vald mapp |
| `extract-concepts-current` | Begrepp ur aktiv anteckning |
| `extract-concepts-folder` | Begrepp ur vald mapp |
| `generate-from-title` | Innehåll från aktiv titel |
| `batch-generate-from-titles` | Innehåll för lämpliga mappanteckningar |
| `research-and-summarize` | Undersök markering/titel i öppen Markdown-redigerare |
| `summarize-as-mermaid` | Sammanfatta stödd aktiv indata som Mermaid |
| `generate-diagram` | Välj flera diagramtyper i samma körning och flera utdataformat för varje typ. När en typ avmarkeras sparas dess format; utan val analyseras innehållet automatiskt. |
| `preview-diagram` | Förhandsvisa stödd källa eller diagram |
| `translate-current-file` | Översätt aktiv stödd fil |
| `batch-translate-folder` | Översätt vald mapp |
| `extract-original-text` | Extrahera efterfrågade originalpassager |
| `batch-extract-original-text` | Passager ur lämpliga mappfiler |

### Standardkedja eller egen

One-Click Extract är förinställt. Definiera andra knappar själv: namn, ordning och inställningar. Kontrollera sidopanelens verktygstips och åtgärda parserfel före körning.

## Inställningar

| Inställning | Standard | Effekt |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stoppa vid första rapporterade stegfel |
| `useMultiModelSettings` | `false` | Aktiv leverantör tills uppgiftsstyrning aktiveras |
| `enableResearchInGenerateContent` | `false` | Ingen forskning vid titelgenerering förrän den slås på |

`continue_on_error` fortsätter efter fel. Använd bara när senare steg kan hantera kvarvarande indata. Fortsatt körning gör inte ett delvis misslyckat flöde lyckat.

### Modell per steg

Modellval ägs av uppgiften. Tom override använder vald leverantörs modell. Kontrollera alla vägar innan privat innehåll skickas.

## Exempel

Välj tom `trial-concepts` och en testkälla. Granska begreppen och rapporterad complete-mapp. Kör först stegen separat om destinationerna är oklara. Öka omfånget efter granskning.

## Tips

- Håll kedjor begripliga så att fel och filernas ursprung kan följas.
- Raderingsåtgärder behåller interaktiv bekräftelse; undvik dem i obevakade flöden.
- Granska logg och filer efter avbrott eller återställningskonflikt.
- Testa exakt modell och mapp; anslutningstest bevisar inte batchkvoter.
