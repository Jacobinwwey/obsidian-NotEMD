# Översättning

<TLDR>Notemd översätter aktiv fil eller lämpliga mappfiler med vald LLM. Standardutdata är en separat fil med språksuffix. Modellens kvalitet avgör resultatet; 21 UI-språk och 34 webbplatsspråk är inga översättningsgarantier eller begränsningar.</TLDR>

## Översikt

Välj målspråk och leverantör. Testa en kopia med facktermer, länkar och kod. Detta använder LLM, ingen särskild Google Translate-integration. Åtgärderna gäller filer/mappar. Lägg en passage i en tillfällig anteckning; markering begränsar inte **Translate current file**.

## Så fungerar det

### Översättningsuppgift

1. Välj målspråk, initialt engelska och skilt från UI.
2. Öppna källan och kör **Translate current file**.
3. Lång text delas, skickas och sammanfogas.
4. Öppna rapporterad fil och kontrollera betydelse, termer, citat, länkar och kod.

Franska från `Example.md` blir normalt `Example_fr.md` intill bevarad källa. Befintlig utdata skrivs över. Tillägg i originalet eller en fast rubrik `Translation` är ingen standardgaranti.

### Språkpar

Modellen härleder källspråket. En menyoption bevisar inte språkparets kvalitet. Testa blandade språk och facktermer; delning kan förlora kontext.

### Modell per uppgift

Uppgiftsstyrning använder `translateProvider`/`translateModel`, annars aktiv leverantör. Lokal användning kräver server/modell; molnet tar emot prompt och innehåll. Bedöm ett relevant exempel.

### Mappöversättning

**Batch translate folder** tar som standard bara direkta barn; avancerade profiler kan ändra det. Lika källnamn i en gemensam utdatamapp kan kollidera. Kontrollera befintliga översättningar före omkörning.

## Inställningar

| Inställning | Standard | Effekt |
| --------- | --------- | -------- |
| `language` | `en` | Valt målspråk |
| `translateProvider` | `DeepSeek` | Leverantör med uppgiftsstyrning |
| `translateModel` | `''` | Tomt använder leverantörens modell |
| `useCustomTranslationSuffix` | `false` | Språkkod som standardsuffix |
| `translationCustomSuffix` | `_translated` | Suffix när eget alternativ är på |
| `useCustomTranslationSavePath` | `false` | Spara intill källan som standard |
| `translationSavePath` | `''` | Egen valvrelativ utdatamapp |
| `batchConcurrency` | `1` | Begärd samtidighet för mappöversättning |

Om den egna mappen inte kan skapas kan källmappen användas i stället. Läs faktisk sökväg. Tomt eget suffix kan peka på källfilen; använd ett särskiljande suffix för separat översättning.

## Exempel

Kopiera en kort kinesisk anteckning till en testmapp, välj engelska och översätt filen. Jämför `_en.md` med originalet: termer, siffror, formler och länkar. Utöka därefter.

## Avbryt och kontrollera

Avbrott stoppar stödd fortsatt bearbetning, inte färdiga översättningar eller garanterat debitering. Granska rapport och filer. Markdown-bevarande är en modellinstruktion, ingen parsergaranti för identisk betydelse.

## Tips

- Säkerhetskopiera och kontrollera namnkonflikter.
- Använd särskilt testsuffix och mapp.
- Granska kod, matematik, URL:er och egennamn.
- Kontrollera diagnostik före delning.
