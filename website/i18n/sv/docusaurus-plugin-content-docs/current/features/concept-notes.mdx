# Begreppsanteckningar

<TLDR>Fristående extraktion läser källan och skapar begreppsanteckningar i en vald mapp. Ingen mapp är inställd från början. Nya anteckningar får bara titel och saknar bakåtlänk. Länkning använder en annan begreppsform.</TLDR>

## Översikt

Välj **Concept note folder path** först. En separat mapp underlättar granskning av filer, dubbletter och titelgenerering. Extraktion skapar filer, inte automatiskt forskningsbaserade förklaringar.

## Så fungerar det

### Extraktion

Vald LLM tar emot texten. Uppgiften tolkar `CONCEPT:`-rader, tar bort upprepade namn inom körningen och skapar eller uppdaterar filer. Långa texter delas. Kontrollera misslyckade delar; ett modellsvar garanterar inte full täckning.

### Extraktionsprompt

Standardprompten begär konkreta relevanta begrepp. Domän- och synonyminstruktioner ger ingen kanonisk vokabulär. Behåll `CONCEPT: Term` i egna prompter. Se [prompter](../advanced/custom-prompts).

### Textdelar

`chunkWordCount` börjar på cirka 3000 ord och är ingen tokenbudget. Kontext över delgränser är begränsad; granska relationer och tvetydigheter.

## Skapa filer

### Namnregler

Ogiltiga sökvägstecken tas bort, blanksteg normaliseras och långa namn kortas. Tomma resultat hoppas över. Olika termer kan därmed få samma sökväg; granska större mängder.

### Mallar

Minimal ny anteckning:

```markdown
# Begreppsnamn
```

För bakåtlänk i nya fristående anteckningar: aktivera **Add "Linked From" backlink** och stäng av **Create minimal concept notes**:

```markdown
# Begreppsnamn

## Linked From
- [[Källanteckning]]
```

Länkning använder full form med källreferens när begreppsutdata är aktiverad. Inställningarna för fristående extraktion ändrar inte den vägen.

### Befintliga anteckningar

Med bakåtlänkar på kan saknad källreferens läggas under `## Linked From`. Befintlig text bevaras och samma bakåtlänk dubbleras inte. Källans basename kan vara tvetydigt mellan mappar.

### Inställningar

| Inställning | Standard | Effekt |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Begreppsutdata efter mappval |
| `conceptNoteFolder` | `''` | Ingen mapp vald |
| `extractConceptsMinimalTemplate` | `true` | Fristående begrepp med bara titel |
| `extractConceptsAddBacklink` | `false` | Bakåtlänkar vid fristående extraktion |
| `extractConceptsProvider` | `DeepSeek` | Leverantör med uppgiftsstyrning |
| `extractConceptsModel` | `''` | Tomt använder leverantörens modell |
| `extractConceptsLanguage` | `en` | Språk med uppgiftsspecifika språk |
| `replaceSynonymsDuringConceptExtraction` | `false` | Instruktion som begränsar synonymer |
| `generateConceptLogFile` | `false` | Valfri begreppslogg |

## Dubbletter

Kontrollen använder filnamnsheuristik: skiftläge, plural, symbolnormalisering och där tillåtet enstaka ord inuti andra namn. Det bevisar inte samma betydelse. Granska tekniska skillnader i **Check & remove duplicates** och bekräfta endast avsedda borttagningar. Obsidian hanterar papperskorgen. Begreppsmappen är ingen förbrukningscache; säkerhetskopiera.

### Jämförelseomfång

Jämför med valvet, begreppsmappen, inkluderade mappar eller ett omfång med undantag. Omfånget ändrar kandidater, inte vad en dubblett betyder.

## Användning

### Fristående extraktion

Öppna Markdown, kontrollera mapp och välj **Extract concepts (current file)**. Källan bevaras. Granska namn, täckning och bakåtlänkar.

### Extraktion och innehåll

**Batch generate from titles** fyller anteckningar men kan även ta befintliga lämpliga filer. Granska mappen före körning och rapporterad complete-mapp efteråt.

### Länk från markering

Markeringsåtgärden skapar en wiki-länk för din term och kan skapa en begreppsfil om destinationen är konfigurerad.

## Tips

- Börja med liten källa och separat mapp.
- Välj språk före massgenerering.
- Bedöm synonymer och dubbletter separat.
- Spara loggar som nästa körning kan ersätta.
