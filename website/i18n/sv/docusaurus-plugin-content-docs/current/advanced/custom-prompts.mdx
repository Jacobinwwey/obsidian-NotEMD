# Egna prompter

<TLDR>En icke-tom egen prompt ersätter standarden när både global och uppgiftsspecifik omkopplare är på. Behåll utdatakontraktet: mallhanteringen återställer inte automatiskt utelämnade formatinstruktioner.</TLDR>

## Översikt

Testa standarden på en representativ anteckning först. Domän- eller synonyminstruktion kan räcka. Anpassa struktur, policy eller översättningsstil när det behövs och jämför före batchkörning.

## Så fungerar det

### Sammansättning

Notemd väljer standard/egen prompt, lägger till tillämpliga domän-/språkinstruktioner och ersätter variabler som uppgiften tillhandahåller. Anteckningstext kan vara ett separat meddelande. Variabler är inte universella. En ersättning kan tappa `CONCEPT:` eller forskningskontext; giltigt anrop bevisar inte tolkningsbar eller underbyggd utdata.

### Variabler

Använd exakt skiftläge och enkla klamrar:

| Uppgift | Tillgängliga variabler |
| ------ | ----------------------- |
| Titelgenerering | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Forskningssammanfattning | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Översättning | `{LANGUAGE}`, `{TEXT}` |
| Originalpassager | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` följer uppgiftens språkpolicy. Länkar och fristående begrepp skickar text som uppgiftsinnehåll; hitta inte på fler platshållare. Okända namn fylls inte i. Promptvariabler är inga mallar för begreppsfiler.

### Avgränsad domän

Aktivera fokuserat lärande och ange exempelvis `elektroteknik`. `Relevant Fields` styr uppmärksamheten utan att ge ett hårt filter eller bevis på uteslutning.

## Inställningar

| Uppgift | Omkopplare | Promptfält |
| ------ | --------------- | -------------- |
| Länkar | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titlar | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Forskning | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid-sammanfattning | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Begrepp | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Översättning | `useCustomPromptForTranslate` | `translatePrompt` |
| Originaltext | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Alla kräver `enableGlobalCustomPrompts`. Tom text använder standard. Sammanslagen originaltextsextraktion har separat fast format; den vanliga override gäller inte där. Diagramgenerering kräver typad utdata, så Mermaid-prompten är inte generell.

## Exempel

Aktivera global och begreppsspecifik omkopplare och behåll parsermarkören:

```text
Extrahera anteckningens viktigaste elektrotekniska begrepp.
Prioritera konkreta komponenter och fysikaliska mekanismer framför allmänna substantiv.
Skriv ett begrepp per rad i exakt denna form:
CONCEPT: Begreppets namn
Lägg inte till förklaringar eller ett omgivande kodblock.
```

Jämför rader, filnamn och saknade begrepp med standarden på en kopia. Spara föregående prompt för återgång.

## Tips

- Testa en uppgift före större batcher.
- Bevara källor och exakta citat.
- Översätt instruktioner men behåll ID:n och markörer.
- Testa efter modellbyte; instruktioner ersätter inte validering.
