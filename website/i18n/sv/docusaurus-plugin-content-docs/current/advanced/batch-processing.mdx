# Batchbearbetning

<TLDR>Mappåtgärder delar urval och förloppsrapportering, men inte överskrivningsregler. Standardsamtidighet är ett. Testa en liten mapp och kontrollera omfång och destinationer före uppskalning.</TLDR>

## Översikt

Mappåtgärder för länkar, begrepp, titlar, översättning, originalpassager, Mermaid och formler finns i sidopanel/filutforskare. Ingen generell forskningsåtgärd för mappar finns; titelgenerering kan lägga till forskning. Färdiga resultat bevaras vid fel och avbrott; batchen är ingen mapptransaktion.

## Så fungerar det

### Körningsmodell

1. Välj uppgift och mapp med avsedda filer.
2. Filändelse, urval och uppgiftsspecifika utdatafilter bestämmer kandidaterna.
3. Uppgiften använder sin modell/leverantör och rapporterar status, fel och sökvägar.
4. Granska rapport och utdata efter avslut eller avbrott innan du kör igen.

Länkar, begrepp, titlar, originalpassager, Mermaid och formler inkluderar normalt undermappar. **Mappöversättning använder normalt bara direkta barn.** Utvecklarläge och avancerade urvalsprofiler kan ändra omfång och filter. Kontrollera faktiska träffar.

### Överskrivning

| Uppgift | Kontroll före omkörning |
| ------ | ------------------------------------ |
| Länkar | Separat resultat som standard; kontrollera eget suffix, mapp och originalflytt |
| Begrepp | Aktiva bakåtlänkar kan komplettera befintliga filer; dubbletter hanteras separat |
| Titelgenerering | Skriver lämpliga källor och flyttar om complete-målet är ledigt |
| Översättning | Befintlig översättning kan ersättas; normalt `_<language>.md` |
| Mermaid / formler | Ändrar valda anteckningar; granska och säkerhetskopiera |

Ingen gemensam hoppa över/lägg till/ersätt-inställning finns. Upptaget complete-mål hindrar flytten efter titelgenerering, inte den föregående genereringen. Genererade och flyttade filer räknas separat.

### Samtidighet

Behåll `batchConcurrency: 1` tills ett urval fungerar. Vissa vägar kräver också `enableBatchParallelism`; mappöversättning använder samtidigheten direkt. Parallellitet belastar leverantör, minne och lokal server och garanterar inte högre hastighet. Intervall mellan anrop/grupper förhindrar inte alla kvotproblem eller annan kontoanvändning.

## Inställningar

| Inställning | Standard | Effekt |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Begärd samtidighet på tillämpliga vägar |
| `enableBatchParallelism` | `false` | Aktivera stödd parallell schemaläggning |
| `batchSize` | `50` | Gruppstorlek vid gruppvis schemaläggning |
| `batchInterDelayMs` | `1000` | Paus mellan schemalagda grupper |
| `apiCallIntervalMs` | `500` | Intervall mellan samtidiga API-anrop |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Behåll respektive uppgifts undermappsbeteende |
| `enableStableApiCall` | `false` | Uttryckligt stabilt anropsläge |

### Uppgiftsmodeller

Mappåtgärder följer motsvarande filuppgifts modellval. Kontrollera privata datavägar. Lokal kontext vid batchtitelgenerering använder en ögonblicksbild från start: ändringar under körningen blandas inte in i senare sökningar. Starta ny batch för att inkludera dem.

## Exempel

Skapa `trial-titles` med två titelanteckningar. Kör **Batch generate from titles** och granska innehåll, intilliggande `trial-titles_complete` samt antal genererade, flyttade och fel. Undersök misslyckad fil först. Omkörning av källmappen återupptar inte automatiskt exakt återstående arbete.

## Avbrott och återställning

Avbrott stoppar ny schemaläggning och stödda anrop. Redan accepterade externa anrop/skrivningar kan slutföras, och leverantören styr debiteringen. Vänta och jämför färdiga filer med återställnings- och konfliktsökvägar före borttagning.

## Tips

- Kontrollera profilens verkliga urval.
- Sänk samtidigheten och undersök kvoter vid 429.
- Skilj avbrutet, misslyckat och slutfört.
- Bevara originalexempel och säkerhetskopia.
