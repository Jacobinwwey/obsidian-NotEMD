# Configuração

<TLDR>
Abrir **Settings → Notemd** e pesquisar o campo. Definir fornecedor e destinos antes de processar. Testar alterações numa nota: uma operação ativa pode conservar os ajustes capturados ao iniciar.
</TLDR>

## Visão geral

DeepSeek é o fornecedor ativo inicial, sem credenciais preenchidas. Um perfil não cria conta, instala modelo ou concede acesso. Ver [fornecedores](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Pesquisa de ajustes e favoritos

- **Search settings** pesquisa nomes, descrições, aliases e categorias visíveis e conduz ao campo.
- **★ Favorites** mostra ajustes guardados com descrição, categoria e destino. Persistem no cofre; IDs obsoletos são descartados.
- A seta recolhe a barra e conserva a consulta ao reabrir.
- Lista de favoritos e filtro apenas de favoritos são controlos separados.

**Diagram preview export PPI**: **300** por padrão, intervalo **72–600**. Controla PNG; SVG/PDF mantêm geometria vetorial quando suportada. **Also export complete Mermaid visuals** controla componentes acompanhantes, não a visibilidade Mermaid em Drawnix.

## 1. Fornecedor

Escolher perfil, endereço adequado ao protocolo, credenciais e modelo acessível. Usar **Fetch models** quando disponível e **Testar conexão**. Listagem e geração são verificações diferentes.

Modelos locais exigem servidor e modelo prontos. Endpoints cloud recebem o texto enviado. Verificar também rotas por tarefa antes de tratar notas privadas.

## 2. Modelos por tarefa

`useMultiModelSettings` separa fornecedor/modelo para links, títulos, pesquisa, tradução, conceitos, texto original e resumo Mermaid. Um modelo específico vazio usa o configurado no fornecedor. Sem essa opção aplica-se o fornecedor ativo.

Comparar precisão, latência e preço real com uma amostra representativa. Não se garante classificação ou disponibilidade de modelos.

## 3. Saídas

| Tarefa | Saída por padrão |
| ------ | ------------------------- |
| Adicionar links | Documento vizinho `_processed.md`; sem mover a origem |
| Conceitos independentes | Pasta escolhida obrigatória; títulos sem backlinks |
| Tradução | Documento vizinho `_<language>.md`; destino existente pode ser substituído |
| Pesquisa | Resumo acrescentado à nota Markdown ativa |
| Geração por títulos em lote | Escreve conteúdo e move notas elegíveis para `<folder>_complete` quando o destino permite |
| Pré-visualização/exportação | Escolher fonte ou visual compatível e verificar caminho anunciado |

A pasta de conceitos começa vazia; `concepts` é uma escolha possível. As [formas de nota](../features/concept-notes) são mínima/completa, sem motor geral de variáveis de modelo para documentos.

Sufixos e pastas de processados e traduções são independentes. Verificar destinos e mensagens de recuperação. Cancelar não desfaz escritas concluídas.

## 4. Idiomas

A interface tem **21 idiomas** e o site **34 rotas linguísticas**. `uiLocale: auto` segue o mapeamento disponível, com retorno ao inglês quando não há suporte.

O idioma gerado é independente e inicialmente inglês. Idiomas por tarefa aplicam-se a links, títulos, pesquisa, conceitos e Mermaid onde suportado. Tradução usa a saída `language`, não o idioma da interface. Capacidade do modelo é outra questão.

## 5. Pesquisa

Escolher **Tavily** com chave ou **DuckDuckGo** explicitamente. Chave Tavily vazia não muda de motor. Ambos usam rede; DuckDuckGo pode ler páginas encontradas.

Títulos não pesquisam por padrão; ativar `enableResearchInGenerateContent` se necessário. Pesquisa local também começa desligada e tem âmbitos próprios de pasta/tarefa. Excertos utilizados são enviados ao LLM como contexto.

## 6. Fluxos

Usar o construtor ou uma definição DSL por linha:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` separa nome e ações, `>` separa IDs. O padrão interrompe perante erro comunicado. Ver [fluxos](../features/workflows).

## 7. Ajustes avançados

| Ajuste | Padrão | Efeito |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Fornecedor sem rota específica |
| `useMultiModelSettings` | `false` | Separar modelos por tarefa |
| `useCustomConceptNoteFolder` | `true` | Permitir conceitos após escolher pasta |
| `conceptNoteFolder` | `''` | Nenhuma pasta inicial |
| `extractConceptsMinimalTemplate` | `true` | Conceitos independentes apenas com título |
| `extractConceptsAddBacklink` | `false` | Backlinks apenas após ativação |
| `moveOriginalFileOnProcess` | `false` | Preservar origem ao acrescentar links |
| `chunkWordCount` | `3000` | Tamanho aproximado em palavras, não limite de tokens |
| `batchConcurrency` | `1` | Concorrência inicial |
| `enableBatchParallelism` | `false` | Agendamento paralelo em caminhos compatíveis |
| `enableStableApiCall` | `false` | Modo estável explícito |
| `customWorkflowErrorStrategy` | `stop_on_error` | Parar após erro de etapa comunicado |

Divisão do texto e orçamento de saída são diferentes. Fragmentos menores não garantem caber no contexto; concorrência menor não evita todo erro 429.

## Perfis

A configuração pertence ao cofre. Fazer cópias antes de mudar um perfil funcional. Exportações de fornecedores com dados ocultados não são backup completo; verificar URL e metadados antes de partilhar. Não publicar ajustes brutos ou notas privadas nos diagnósticos.

## Diagnóstico

Testar fornecedor/modelo exatos e depois uma nota. Para campos ausentes, pesquisar nome e verificar categoria, modo de desenvolvimento e cofre correto. Relatar falhas reproduzíveis com versão e detalhes sem dados sensíveis.
