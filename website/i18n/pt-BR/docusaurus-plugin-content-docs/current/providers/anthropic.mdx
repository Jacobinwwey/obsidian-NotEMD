# Fornecedor Anthropic

<TLDR>
Usar este perfil para Messages nativo. Claude por gateway OpenAI-compatible usa o perfil desse gateway. Confirmar modelo disponível; o nome histórico pode precisar de substituição.
</TLDR>

## Preparação

Escolher **Anthropic**, chave e modelo acessível. Conservar endpoint nativo salvo deployment que exponha o mesmo protocolo. Testar conexão e tarefa numa nota descartável.

## Endpoint e autenticação

| Campo | Valor inicial |
| ------- | -------------- |
| Transporte | `anthropic` |
| Chave API | Obrigatória |
| URL base | `https://api.anthropic.com` |
| Modelo | `claude-3-5-sonnet-20240620` |
| Temperatura | `0.5` |
| Teste de conexão | `chat-only` |

A execução usa `/v1/messages` com cabeçalhos nativos de chave e versão. Não inserir rota OpenAI chat. O padrão descreve a configuração do repositório, não disponibilidade atual garantida.

## Modelos

Usar descoberta nativa quando disponível. Se a lista estiver restrita, indicar ID autorizado e executar teste chat. Validar tarefas longas e estruturadas separadamente.

## Problemas

- `401`/`403`: chave, espaço/projeto, cobrança e direitos.
- `404`: endereço e disponibilidade atual.
- ID de gateway rejeitado: usar perfil e identificador esperados.
- Falhas longas: verificar limites e erros antes de aumentar tentativas.

## Quando utilizar

Para endpoints Messages nativos. Comparar resultados com as próprias fontes, sem classificação universal de fornecedores. Rotas por tarefa permitem uso específico.
