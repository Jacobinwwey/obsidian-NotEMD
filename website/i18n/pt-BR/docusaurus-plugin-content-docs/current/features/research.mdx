# Pesquisa Web e resumos

<TLDR>
**Pesquisar e resumir** pesquisa o tema selecionado ou título da nota, pede ao LLM um resumo do contexto disponível e acrescenta-o à nota Markdown ativa. Escolher Tavily ou DuckDuckGo explicitamente e verificar fontes e citações.
</TLDR>

## Visão geral

Motor de pesquisa e LLM de resumo são configurados separadamente. Tavily exige chave; DuckDuckGo não, mas pode limitar pedidos. Modelo local não torna pesquisa Web offline.

## Funcionamento

### Pesquisar e resumir

1. Abrir a nota no editor Markdown, selecionar tema curto ou usar o título.
2. Executar **Pesquisar e resumir**.
3. Tavily fornece excertos; DuckDuckGo pode levar à leitura das páginas encontradas.
4. Pesquisa local ativada para a tarefa pode acrescentar excertos do cofre.
5. O modelo gera texto acrescentado sob `Research Summary`, com tema e origem do contexto.
6. Rever e abrir URLs originais. Encontrar uma fonte não comprova cada afirmação ou citação.

### Tavily ou DuckDuckGo

| Escolha | Preparação | Limite |
| -------- | ------- | ---------------------- |
| Tavily | Selecionar Tavily e fornecer chave | Quota da conta e excertos devolvidos |
| DuckDuckGo | Selecionar DuckDuckGo explicitamente | Sem chave; limites de pedidos e disponibilidade de páginas |

Chave Tavily vazia ou inválida não seleciona DuckDuckGo. Sem contexto Web útil, consultar relatório. Excertos locais ativos e disponíveis podem sustentar um resumo, identificado pela etiqueta de origem.

### Pesquisa durante geração por títulos

Ativar **Enable research in "Generate from title"** para incluir pesquisa, também em lote. Está desligado por padrão. É o percurso suportado para pastas; não há uma ação genérica independente Research Folder.

## Ajustes

| Ajuste | Padrão | Efeito |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Selecionar motor de pesquisa |
| `tavilyApiKey` | `''` | Chave necessária para Tavily |
| `tavilyMaxResults` | `5` | Quantidade pedida de resultados Tavily |
| `tavilySearchDepth` | `basic` | Profundidade Tavily |
| `ddgMaxResults` | `5` | Quantidade pedida de resultados DuckDuckGo |
| `ddgFetchTimeout` | `15` | Tempo de leitura de páginas em segundos |
| `maxResearchContentTokens` | `3000` | Orçamento aproximado de contexto Web |
| `researchProvider` | `DeepSeek` | Fornecedor de resumo com rota por tarefa |
| `researchModel` | `''` | Modelo do fornecedor se vazio |
| `researchSummarizeLanguage` | `en` | Idioma com opções por tarefa |
| `enableResearchInGenerateContent` | `false` | Acrescentar pesquisa à geração por títulos |
| `enableLocalKnowledgeRetrieval` | `false` | Ativar pesquisa local delimitada |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Usar contexto local nesta tarefa |

### Contexto e modelo

Os limites usam estimativas, não tokenização exata do fornecedor. Truncar pode omitir provas. Focar a pergunta e ajustar modelo e saída. O índice local é lexical, sem embeddings nem recuperação completa garantida.

## Exemplo

Criar nota `Codificação posicional relativa`, pesquisar e comparar com artigos originais ou documentação oficial. Guardar pergunta, URLs reais e correções para tornar a conclusão verificável. Um exemplo do guia não é resultado executado no cofre.

## Cancelamento e privacidade

Anexos concluídos ficam; pedidos em curso podem terminar. O motor recebe a consulta, sites recebem pedidos e o LLM recebe contexto, incluindo excertos locais ativos. Rever diagnósticos antes de partilhar.

## Conselhos

- Separar fonte Web, nota local e inferência do modelo.
- Verificar citações, datas e afirmações importantes no original.
- Diagnosticar pesquisa e LLM separadamente com pergunta pequena.
- Rever resumos existentes antes de repetir anexos.
