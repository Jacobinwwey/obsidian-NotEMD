# OpenAI प्रदाता

<TLDR>यह profile साझा OpenAI Chat Completions runtime उपयोग करता है। उसी protocol को स्वीकारने वाला model और key चुनें। प्रारंभिक model वर्तमान पहुँच या सामान्य गुणवत्ता की गारंटी नहीं है।</TLDR>

## तैयारी

आधिकारिक सेवा में **OpenAI**, key और `https://api.openai.com/v1` चुनें। सूची का model किसी दूसरी API के लिए हो सकता है। Gateway का अपना profile/header लें; Azure हेतु **Azure OpenAI**, deployment और API version दें।

## Endpoint और authentication

| फ़ील्ड | प्रारंभिक मान |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API कुंजी | आवश्यक |
| Base URL | `https://api.openai.com/v1` |
| मॉडल | `gpt-4o` |
| Temperature | `0.5` |
| कनेक्शन टेस्ट | `models-then-chat` |

Runtime ज्ञात URL रूप normalise करके route बनाता है। Profile से शुरू करें और resolved URL देखें; मनमाने path segments न जोड़ें।

## मॉडल

**Fetch models** सूची माँगता है। **Test connection** सिर्फ सूची से सफल हो सकता है; सही model पर नोट चलाएँ। Reasoning, thinking, sampling और budgets profile/model नियमों से मिलें।

## समस्याएँ

- 401/403: key, project, rights और account।
- 404: endpoint, ID और API support।
- List सफल, generation असफल: chat error और parameters।
- लंबा उत्तर टूटा: input, budget और वास्तविक response देखें; छोटा test पर्याप्त नहीं।

## कब उपयोग करें

Direct OpenAI Chat Completions endpoints के लिए। अपने नोटों पर जाँचें; कीमत और उपलब्धता Notemd से अलग बदलती हैं।
