# Google प्रदाता

<TLDR>Google profile native Gemini Generative Language उपयोग करता है। अधिकृत key और उपलब्ध model चाहिए। Compatible gateway पर Gemini के लिए उस gateway का profile लें।</TLDR>

## तैयारी

**Google**, key, native endpoint और चुने API version का model सेट करें; connection तथा नोट टेस्ट करें। यह मनमाने Google Cloud या Vertex deployment को अपने-आप नहीं सेट करता।

## Endpoint और authentication

| फ़ील्ड | प्रारंभिक मान |
| ------- | -------------- |
| Transport | `google` |
| API कुंजी | आवश्यक |
| Base URL | `https://generativelanguage.googleapis.com/v1` |
| मॉडल | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| कनेक्शन टेस्ट | `chat-only` |

API key से `generateContent` request बनती है। पुराना model ID उपलब्धता नहीं सुनिश्चित करता। Diagnosis URLs में authentication हो सकता है; साझा करने से पहले देखें।

## मॉडल

Native list और चुनी API पर generation जाँचें। खाली list अधिकार, endpoint या गायब model का संकेत हो सकती है। Protocol बदलने से पहले कारण जाँचें।

## समस्याएँ

- 400: ID, parameters और input/output सीमा।
- 401/403: key restrictions, API enablement और rights।
- 404: क्या model इसी API version में है?
- Gateway example: संबंधित OpenAI-compatible profile लें।

## कब उपयोग करें

Native Gemini के लिए। Translation, research या diagrams अपने उदाहरण पर जाँचें; गति, लागत और गुणवत्ता की सामान्य गारंटी नहीं है।
