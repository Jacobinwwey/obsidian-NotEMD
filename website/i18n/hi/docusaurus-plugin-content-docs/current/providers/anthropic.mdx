# Anthropic प्रदाता

<TLDR>यह profile native Messages के लिए है। OpenAI-compatible gateway के Claude को gateway profile चाहिए। पुराना प्रारंभिक नाम वर्तमान उपलब्ध model से बदलना पड़ सकता है।</TLDR>

## तैयारी

**Anthropic**, key और accessible model चुनें। समान protocol वाला अन्य deployment न हो तो native endpoint रखें। Connection और एक नोट चलाएँ।

## Endpoint और authentication

| फ़ील्ड | प्रारंभिक मान |
| ------- | -------------- |
| Transport | `anthropic` |
| API कुंजी | आवश्यक |
| Base URL | `https://api.anthropic.com` |
| मॉडल | `claude-3-5-sonnet-20240620` |
| Temperature | `0.5` |
| कनेक्शन टेस्ट | `chat-only` |

`/v1/messages` तथा native key/version headers लगते हैं। OpenAI chat route न जोड़ें। ये repository defaults हैं, current availability का वादा नहीं।

## मॉडल

Native discovery उपलब्ध हो तो लें। List access सीमित हो तो अधिकृत ID देकर chat जाँचें। लंबी तथा structured-output tasks अलग टेस्ट करें।

## समस्याएँ

- 401/403: key, project, billing और model rights।
- 404: endpoint और वर्तमान model।
- Gateway ID अस्वीकृत: profile तथा identifier मिलाएँ।
- लंबे failures: retries बढ़ाने से पहले limits पढ़ें।

## कब उपयोग करें

Native Messages endpoints में। अपनी स्रोत सामग्री से तुलना करें, universal ranking न मानें। Task routing से चुनिंदा काम अलग मॉडल पर जा सकता है।
