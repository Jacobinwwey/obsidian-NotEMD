# चीनी प्रदाता

<TLDR>अपने account और deployment का profile चुनें। साझा OpenAI-compatible protocol के बावजूद region, paths, model और rights विनिमेय नहीं हैं। एक छोटा वास्तविक कार्य जाँचें।</TLDR>

## तैयारी

Account/key लेकर profile, region और model अनुमति की पुष्टि करें। शुरुआती values current availability नहीं सुनिश्चित करतीं। Connection के बाद नोट जाँचें।

## मॉडल

अनुमति हो तो सूची लें। Huawei Cloud MaaS deployment knowledge रखता है; अन्य profiles समर्थित compatible discovery करते हैं। List rights न होना explicit model generation पर रोक ज़रूरी नहीं। DeepSeek test केवल सूची से सफल हो सकता है; कई regional profiles छोटी generation करते हैं। वास्तविक task अब भी चाहिए।

## समस्याएँ

- Key स्वीकार, generation denied: model rights, deployment, region।
- Ark ID अस्वीकृत: endpoint या model ID अपेक्षित?
- Reasoning कटा: budget और model-specific thinking।
- Network: Obsidian उपकरण से endpoint और transport error देखें।

## कब उपयोग करें

अधिकार, पहुँच और data terms उपयुक्त हों तो। भौगोलिक श्रेणी से भाषा गुणवत्ता या कीमत न निकालें। दर्ज settings के साथ नमूना तुलना करें।
