# अपने prompts

<TLDR>Global और task switch चालू तथा custom text गैरखाली हो तो अपना prompt आंतरिक निर्देश बदलता है। आवश्यक output format बचाएँ; हटाई गई हर शर्त स्वतः लौटाने वाला template system नहीं है।</TLDR>

## अवलोकन

पहले नमूने पर default prompt देखें। Focused domain या समानार्थी रोक पर्याप्त हो सकती है। extraction नीति, संरचना या अनुवाद शैली चाहिए तो बदलकर बैच से पहले तुलना करें।

## काम कैसे होता है

### Prompt संरचना

आंतरिक या अपना prompt चुना, संबंधित domain/भाषा निर्देश जुड़ते और कार्य के variables भरे जाते हैं। सामग्री अलग message भी हो सकती है। Variables सार्वभौमिक नहीं हैं। `CONCEPT:` हटाने से parsing और research context हटाने से प्रमाण बिगड़ सकता है; सही request सही output नहीं सिद्ध करती।

### Variables

सही uppercase नाम और एकल braces रखें:

| कार्य | उपलब्ध placeholders |
| ------ | ----------------------- |
| शीर्षक जनरेशन | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| शोध सारांश | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| अनुवाद | `{LANGUAGE}`, `{TEXT}` |
| मूल पाठ निष्कर्षण | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` कार्य की भाषा नीति से आता है। लिंक और स्वतंत्र अवधारणा काम पाठ को content की तरह भेजते हैं; उनके लिए नया placeholder न गढ़ें। अज्ञात नाम नहीं भरते। ये prompt substitutions हैं, concept-file templates नहीं।

### केंद्रित क्षेत्र

Focused learning में `इलेक्ट्रिकल इंजीनियरिंग` जैसे domain से `Relevant Fields` निर्देश आता है। यह ध्यान निर्देशित करता है, कठोर filter या अप्रासंगिक अवधारणाओं के हटने का प्रमाण नहीं।

## सेटिंग्स

| कार्य | सक्रिय switch | Prompt field |
| ------ | --------------- | -------------- |
| लिंक | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| शीर्षक | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| शोध | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid सारांश | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| अवधारणा | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| अनुवाद | `useCustomPromptForTranslate` | `translatePrompt` |
| मूल पाठ | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

सभी को `enableGlobalCustomPrompts` चाहिए। खाली text आंतरिक prompt लेता है। Merged original-text extraction का अलग built-in रूप है और सामान्य override लागू नहीं। Diagram generation के typed output नियम हैं; Mermaid summary prompt सभी diagram का नहीं है।

## उदाहरण

Global और concept switches चालू करके parser marker रखें:

```text
दिए नोट से मुख्य इलेक्ट्रिकल इंजीनियरिंग अवधारणाएँ निकालें।
सामान्य संज्ञाओं के बजाय ठोस घटक और भौतिक तंत्र चुनें।
हर अवधारणा अलग पंक्ति में इस सटीक रूप में दें:
CONCEPT: शब्द का नाम
अतिरिक्त व्याख्या या बाहर का code block न जोड़ें।
```

कॉपी पर entries, फ़ाइलनाम और छूटी अवधारणाएँ default से मिलाएँ। वापस लौटने को पुराना prompt रखें।

## सुझाव

- बैच बढ़ाने से पहले एक कार्य जाँचें।
- शोध प्रमाण और मूल उद्धरण रखें।
- निर्देश अनुवाद करें, ID और markers नहीं।
- मॉडल बदलने पर फिर टेस्ट करें; prompt validation की गारंटी नहीं।
