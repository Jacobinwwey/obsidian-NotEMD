# अक्सर पूछे जाने वाले प्रश्न

<TLDR>परीक्षण नोट, उपलब्ध प्रदाता और स्पष्ट गंतव्य से शुरू करें। ये उत्तर लागू व्यवहार की सीमाएँ बताते हैं; पूरी तैयारी और output verification अलग guides में है।</TLDR>

## प्रश्न

### Notemd कैसे स्थापित करें?

Settings → Community plugins → Browse में Notemd खोजें, स्थापित और सक्रिय करें। Manual installation में एक GitHub Release की main.js, manifest.json और styles.css लें। न्यूनतम घोषित Obsidian 0.15.0 है; वह पुराना संस्करण और वास्तविक मोबाइल उपकरण अभी सत्यापित नहीं हैं।

### कौन से LLM प्रदाता समर्थित हैं?

36 profiles पाँच परिवारों में हैं: OpenAI-compatible, Anthropic, Google, Azure OpenAI और Ollama। Cloud, gateway और local server के अपने endpoint, key और model चाहिए। Profile या model list वर्तमान उपलब्धता तथा generation अधिकार नहीं सुनिश्चित करती।

### क्या स्थानीय मॉडल चल सकते हैं?

हाँ, Ollama, LM Studio, OVMS या सक्रिय compatible endpoint के साथ। Model तैयार करके वास्तविक task जाँचें। Local inference से web search, dependency installation या अलग cloud tasks offline नहीं हो जातीं।

### ChatGPT से क्या अंतर है?

Notemd Obsidian documents पर स्पष्ट फ़ाइल काम करता है: links, concepts, research append, translation और diagrams। अपने वॉल्ट के काम से चुनाव करें। वर्तमान persistence, export और integration capabilities देखें; chat tools भी history रखकर documents बना सकते हैं।

### Copilot या Smart Connections से कैसे तुलना करें?

वर्तमान versions, settings और docs के साथ समान ठोस task जाँचें। Notemd note transformation तथा सीमित lexical retrieval देता है, सामान्य vault chat या embedding semantic search नहीं। अन्य projects की वर्तमान ranking का दावा नहीं किया जाता।

### कौन से search engines हैं?

Tavily और key या DuckDuckGo स्पष्ट चुनें। खाली Tavily key अपने-आप engine नहीं बदलती। दोनों network उपयोग करते हैं। LLM web और optional local context का सारांश active Markdown में जोड़ती है। URLs और महत्वपूर्ण दावे सत्यापित करें।

### कितनी भाषाएँ उपलब्ध हैं?

UI में 21 locales और website में 34 भाषा routes हैं। Generated content की भाषा अलग चुनी जाती है, समर्थित कार्यों में प्रति-task भी। अनुवाद गुणवत्ता तथा भाषा जोड़े model पर निर्भर हैं, इन संख्याओं पर नहीं।

### क्या papers या PDF पर काम हो सकता है?

पहले उपयुक्त बाहरी tool से Markdown में बदलकर equations, tables और figures जाँचें। फिर concepts, original excerpts, research, translation या diagrams उपयोग करें। Native PDF OCR या किसी भी binary document से पूर्ण सही extraction का वादा नहीं है।

### कौन से diagrams बन सकते हैं?

Executable catalog में 33 entries, उनके supported sources और previews हैं। Mermaid, JSON Canvas, Vega-Lite, editable HTML/SVG, Draw.io, Drawnix और सीमित CircuitikZ अलग जरूरतें पूरी करते हैं। सही combination चुनकर target app में जाँचें; preview native editability या compilation सिद्ध नहीं करता।

### क्या Notemd मुफ्त और open source है?

Notemd MIT license और public repository रखता है तथा योगदान स्वीकारता है। Providers, inference, search और बाहरी tools की अपनी कीमत और शर्तें हैं। Plugin license सभी configured services मुफ्त नहीं करता।

### क्या यह पूरी तरह offline है?

Server, model और dependencies तैयार होने के बाद कुछ tasks local चल सकती हैं। DuckDuckGo सहित web search online रहती है। Disconnect से पहले task routes और export dependencies देखें। कोई पूरे उत्पाद की offline गारंटी नहीं है।

### क्या डेटा cloud को भेजा जाता है?

Prompt और content configured LLM endpoint तक, query search service तक और requests websites तक जाती हैं। Local excerpts cloud prompt में आ सकती हैं; local profile remote address भी रख सकती है। Routing और diagnostics देखें। Local storage केवल उपकरण पर processing की गारंटी नहीं है।

### One-Click Extract क्या करता है?

डिफ़ॉल्ट chain links जोड़ती, concept या चुने folder की पात्र notes titles से भरती और complete folder में Mermaid repair करती है। पुराने concepts भी शामिल हो सकते हैं। Web research या diagram generation स्वतः नहीं जुड़ता। Guide सटीक name::action>action DSL देती है।

### Cancel करने से बदलाव वापस होते हैं?

नहीं। समर्थित आगे का काम रुकता और पूरे results रहते हैं। Accepted requests/writes समाप्त हो सकती हैं और billing remote provider का निर्णय है। समाप्ति का इंतज़ार करके paths/conflicts देखें और केवल ज़रूरी काम दोहराएँ।

### क्या Agent Notemd automate कर सकता है?

चार bounded public commands redacted profiles, capabilities, invocation contract और public CLI surface को working Obsidian/vault से export करते और output लिखते हैं। Repository maintainer operations अलग हैं; internal count public API नहीं है। Agent guide से शुरू करें।

### विकास कहाँ से शुरू करें?

Developer guide setup, build, full tests, modules और extension contracts बताती है। AGENTS.md versioned execution authority है। सही versions और निजी सामग्री से मुक्त evidence के साथ reproduction दें और integration से पहले verify करें।
