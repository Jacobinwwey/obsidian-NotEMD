# अनुवाद

<TLDR>Notemd सक्रिय फ़ाइल या फ़ोल्डर की पात्र फ़ाइलें आपकी LLM से अनुवाद करता है। डिफ़ॉल्ट अलग भाषा-suffix फ़ाइल है। गुणवत्ता मॉडल पर निर्भर है; UI की 21 और साइट की 34 भाषाएँ अनुवाद की सीमा या गारंटी नहीं हैं।</TLDR>

## अवलोकन

लक्ष्य भाषा और प्रदाता चुनकर शब्दावली, लिंक और कोड वाला कॉपी नोट जाँचें। यह चुनी LLM उपयोग करता है, विशेष Google Translate integration नहीं। पंजीकृत कार्य फ़ाइल/फ़ोल्डर पर हैं; एक अंश के लिए अस्थायी नोट बनाएँ। चयन **Translate current file** को सीमित नहीं करता।

## काम कैसे होता है

### आदेश

1. लक्ष्य भाषा चुनें; प्रारंभ में अंग्रेज़ी, UI से अलग।
2. मूल खोलकर **Translate current file** चलाएँ।
3. लंबा पाठ बाँटकर मॉडल तक जाता और उत्तर जुड़ते हैं।
4. बताए पथ पर अर्थ, शब्दावली, उद्धरण, Markdown लिंक और कोड जाँचें।

`Example.md` का फ्रेंच अनुवाद सामान्यतः पास का `Example_fr.md` है। मूल रहता है, पहले से मौजूद आउटपुट बदलता है। मूल में append या स्थिर `Translation` शीर्षक डिफ़ॉल्ट नहीं है।

### भाषा जोड़े

मॉडल स्रोत भाषा पहचानता है। मेनू में भाषा होना उस जोड़े की शुद्धता सिद्ध नहीं करता। मिश्रित भाषा और तकनीकी शब्द जाँचें; chunking संदर्भ खो सकती है।

### कार्य का मॉडल

अलग model settings पर `translateProvider`/`translateModel`, अन्यथा सक्रिय प्रदाता लागू है। स्थानीय सर्वर/मॉडल चाहिए; cloud को prompt और सामग्री जाती है। सामान्य ranking के बजाय विषय-विशिष्ट नमूना जाँचें।

### फ़ोल्डर अनुवाद

**Batch translate folder** पहले केवल सीधे child files लेता है; advanced profiles दायरा बदल सकते हैं। समान basename वाले स्रोत एक output folder में टकरा सकते हैं। दोहराने से पहले लक्ष्य और पुरानी translations जाँचें।

## सेटिंग्स

| सेटिंग | प्रारंभिक मान | प्रभाव |
| --------- | --------- | -------- |
| `language` | `en` | लक्ष्य आउटपुट भाषा |
| `translateProvider` | `DeepSeek` | कार्य routing पर अनुवाद प्रदाता |
| `translateModel` | `''` | खाली तो उसी प्रदाता का मॉडल |
| `useCustomTranslationSuffix` | `false` | डिफ़ॉल्ट भाषा-code suffix |
| `translationCustomSuffix` | `_translated` | अपना suffix सक्रिय होने पर मान |
| `useCustomTranslationSavePath` | `false` | डिफ़ॉल्ट मूल के पास बचाना |
| `translationSavePath` | `''` | वॉल्ट-सापेक्ष output folder |
| `batchConcurrency` | `1` | फ़ोल्डर अनुवाद की माँगी concurrency |

अपना फ़ोल्डर न बन सके तो मूल फ़ोल्डर में वापसी हो सकती है। बताया वास्तविक पथ देखें। खाली custom suffix मूल फ़ाइलनाम को लक्ष्य बना सकता है; अलग अनुवाद के लिए अलग suffix रखें।

## उदाहरण

छोटा चीनी नोट परीक्षण फ़ोल्डर में रखें, अंग्रेज़ी चुनकर फ़ाइल अनुवाद चलाएँ। `_en.md` को मूल से शब्द, संख्या, सूत्र और लिंक के लिए मिलाएँ; फिर फ़ोल्डर बढ़ाएँ।

## रद्द करना और समीक्षा

Cancel समर्थित आगे का काम रोकता है, पूरे हुए अनुवाद या provider बिलिंग को वापस नहीं करता। रिपोर्ट और फ़ाइलें देखें। Markdown बचाने का निर्देश अनुरोध है, parser-स्तर की अर्थ-समानता गारंटी नहीं।

## सुझाव

- मूल का बैकअप और नाम टकराव जाँचें।
- प्रयोग के लिए अलग suffix/फ़ोल्डर रखें।
- कोड ID, गणित, URL और व्यक्तिवाचक नाम मिलाएँ।
- साझा करने से पहले diagnostics में निजी सामग्री हटाएँ।
