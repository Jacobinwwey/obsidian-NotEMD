# वर्कफ़्लो

<TLDR>वर्कफ़्लो मौजूदा साइडबार कार्य क्रम से चलाता है। कोई चरण फ़ोल्डर या सक्रिय editor माँग सकता है। यह text pipe नहीं: हर कार्रवाई अपनी input, output और side effects रखती है। परीक्षण नोट और अलग फ़ोल्डर से शुरू करें।</TLDR>

## अवलोकन

डिफ़ॉल्ट **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. सक्रिय नोट में लिंक जोड़ता और सेट फ़ोल्डर में अवधारणाएँ बनाता है।
2. अवधारणा या चुने फ़ोल्डर के पात्र नोटों में शीर्षक से सामग्री बनाता है; पुराने नोट भी शामिल हैं।
3. जनरेशन की complete जगह में Mermaid सुधारता है।

डिफ़ॉल्ट में वेब शोध नहीं है। अलग generation setting सक्षम हो तो वह शोध ले सकती है। [बैच](../advanced/batch-processing) देखें।

## काम कैसे होता है

### क्रमिक निष्पादन

चरण एक के बाद एक चलते और साइडबार वर्तमान चरण/त्रुटि बताता है। रद्द करना अगले चरणों और समर्थित requests तक पहुँचता है। पूरे लिखे फ़ाइल रहते; पूरी chain का rollback नहीं है। पहले अवधारणा फ़ोल्डर प्राथमिक है, generation स्रोत तथा complete फ़ोल्डर याद रखता और बाद का Mermaid complete लेता है। अन्य कार्यों की फ़ाइल, चयन और संवाद आवश्यकताएँ रहती हैं।

### DSL रूप

हर पंक्ति में एक नामयुक्त बटन लिखें। `::` नाम और actions, `>` action ID अलग करता है। खाली या `#` से शुरू पंक्तियाँ अनदेखी और अज्ञात ID अस्वीकृत होते हैं।

```text
अवधारणा और आरेख::extract-concepts-current>summarize-as-mermaid
```

Builder से चुनें या DSL संपादित करें। ID स्थिर और labels UI-भाषा के होते हैं। फ़ोल्डर संस्करण अपने ID रखते हैं; उन्हें सामान्य string replacement से न बनाएँ।

| ------------ | ----------------------- |
| `process-current-add-links` | सक्रिय नोट में लिंक |

| `research-and-summarize` | खुले Markdown में चयन या शीर्षक पर शोध |
| `summarize-as-mermaid` | समर्थित सक्रिय input का Mermaid सारांश |
| `generate-diagram` | एक बार में कई आरेख प्रकार चुनें और हर प्रकार के लिए अलग-अलग कई आउटपुट प्रारूप तय करें। प्रकार का चयन हटाने पर उसके प्रारूप सुरक्षित रहते हैं; कोई प्रकार न चुना हो तो सामग्री का अपने-आप विश्लेषण होता है। |
| `preview-diagram` | समर्थित स्रोत या diagram preview |
| `translate-current-file` | सक्रिय समर्थित फ़ाइल का अनुवाद |
| `batch-translate-folder` | चुने फ़ोल्डर का अनुवाद |
| `extract-original-text` | बताए गए मूल अंश निकालना |
| `batch-extract-original-text` | पात्र फ़ोल्डर फ़ाइलों से अंश |

### डिफ़ॉल्ट और निजी workflow

One-Click Extract तैयार मिलता है। बाकी बटन अपनी परिभाषाएँ हैं। सेटिंग खोजकर नाम और क्रम दें तथा sidebar tooltip जाँचें। parser error ठीक करने के बाद ही chain पर भरोसा करें।

## सेटिंग्स

| सेटिंग | प्रारंभिक मान | प्रभाव |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | पहली बताई गई चरण-त्रुटि पर रुकना |
| `useMultiModelSettings` | `false` | अलग routing तक सक्रिय प्रदाता |
| `enableResearchInGenerateContent` | `false` | सक्षम किए बिना शीर्षक में शोध नहीं |

`continue_on_error` पिछली त्रुटि पर भी आगे चलाता है। तभी चुनें जब अगले चरण बची input पर काम कर सकें। आगे चलना अधूरे workflow को पूरा सफल नहीं बनाता।

### चरण के मॉडल

Provider/model चयन कार्य के पास रहता है। खाली override चुने प्रदाता का मॉडल लेता है। निजी सामग्री से पहले हर मार्ग देखें।

## उदाहरण

खाली `trial-concepts` सेट करके अस्थायी मूल नोट चलाएँ और अवधारणा फ़ाइलें तथा complete फ़ोल्डर देखें। पथ समझने के लिए पहले अलग-अलग actions चलाएँ। समीक्षा के बाद ही scope बढ़ाएँ।

## सुझाव

- इतनी छोटी chain रखें कि त्रुटि और output ownership स्पष्ट हों।
- सफ़ाई/हटाने के काम interactive पुष्टि रखते हैं; unattended chain से बचाएँ।
- रद्द या recovery conflict के बाद log और फ़ाइलें देखें।
- ठीक मॉडल और फ़ोल्डर से टेस्ट करें; छोटा connection test लंबे batch की quota नहीं सिद्ध करता।
