# Diagrams

<TLDR>
உங்களுக்கு எந்த வகையான படம் தேவை என்பதைத் தேர்ந்தெடுத்து, அதற்கான **திருத்தக்கூடிய மூல வடிவத்தை**த் தேர்ந்தெடுக்கவும். Obsidian-இல் முழு முடிவையும் முன்னோட்டமாகப் பாருங்கள்; இதில் Drawnix போர்டு மற்றும் அதில் உள்ள Mermaid காட்சிகளும் அடங்கும். பின்னர், ஒவ்வொரு பேனலையும் SVG, PNG அல்லது PDF வடிவத்தில் ஏற்றுமதி செய்யவும்.
</TLDR>

## மூன்று தேர்வுகளைப் புரிந்துகொள்ளுங்கள்

| தேர்வு | அது எதைக் கட்டுப்படுத்துகிறது | உதாரணங்கள் |
|---|---|---|
| படம் வகை | படம் என்ன அர்த்தம் கொண்டுள்ளது | Flowchart, sequence diagram, circuit diagram, data chart |
| மூல வடிவம் | Notemd உருவாக்கும் திருத்தக்கூடிய அல்லது மீண்டும் பயன்படுத்தக்கூடிய கோப்பு | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| ஏற்றுமதி வடிவம் | பகிர்வுக்குப் பயன்படுத்தப்படும் படம் அல்லது ஆவணம் | SVG, PNG, PDF |

Draw.io மற்றும் Drawnix ஆகியவை **மூல வடிவங்கள்** தான்; படம் வகைகள் அல்ல. CircuitikZ என்பது சுற்றுப்பாதை படங்களுக்காக வடிவமைக்கப்பட்ட ஒரு மூல வடிவம் ஆகும். அதே முன்னோட்டத்தைப் பல்வேறு காட்சி வடிவங்களிலும் ஏற்றுமதி செய்ய முடியும்; எனவே CircuitikZ-ஐத் தேர்ந்தெடுத்தாலும் SVG-க்கு மட்டுமே கட்டுப்படுவீர்கள் என்று அர்த்தமில்லை.

## ஒரு மூல வடிவத்தைத் தேர்ந்தெடுக்கவும்

| வடிவம் | எதற்கு சிறந்தது | மூல கோப்பு |
|---|---|---|
| Mermaid | Markdown-இலேயே நேரடியாக வைக்கப்படும் படங்களுக்கு | Mermaid code block |
| JSON Canvas | Obsidian-இன் உள்ளூர் canvas வேலைப்பாடுகளுக்கு | `.canvas` |
| Draw.io | diagrams.net அல்லது ஒத்த கருவிகளில் பின்னர் திருத்துவதற்கு | `.drawio` |
| Drawnix | கையால் வரையப்பட்ட அல்லது வைட்போர்ட்-போன்ற திருத்தங்களுக்கு | `.drawnix` |
| CircuitikZ | கட்டமைக்கப்பட்ட மின்சுற்று மற்றும் டிரான்சிஸ்டர் சுற்றுகளுக்கு | `.tex` |

நீங்கள் குறிப்பிட்ட எந்த எடிட்டரையும் தேவைப்படுத்தவில்லை என்றால், **Preferred source format**-ஐ **Auto** என்ற நிலையிலேயே விட்டுவிடுங்கள். தேர்ந்தெடுக்கப்பட்ட படம் வகைக்கு ஏற்ற ஒரு பொருந்தக்கூடிய வடிவத்தை Notemd தானாகவே தேர்ந்தெடுக்கும்.

## படத்தை உருவாக்கி ஏற்றுமதி செய்யுங்கள்

1. நோட்டைத் திறக்கவும் அல்லது காட்சிப்படுத்த விரும்பும் உரையைத் தேர்ந்தெடுக்கவும்.
2. Notemd sidebar அல்லது command palette-இலிருந்து **Generate diagram** என்பதைத் தேர்ந்தெடுக்கவும்.
3. ஒரு **படம் வகை**-ஐத் தேர்ந்தெடுக்கவும், அல்லது அதை **Auto-detect** என்ற நிலையிலேயே விட்டுவிடவும்.
4. ஒரு **மூல வடிவம்**-ஐத் தேர்ந்தெடுக்கவும், அல்லது அதை **Auto** என்ற நிலையிலேயே விட்டுவிடவும். திருத்தக்கூடிய நோடுகள் மற்றும் Mermaid காட்சிகள் உள்ள ஒரு knowledge map-ஐ விரும்பினால் **Drawnix**-ஐத் தேர்ந்தெடுக்கவும்.
5. முன்னோட்டத்தைச் சரிபார்க்கவும். பல பேனல்கள் கொண்ட முடிவு, Drawnix போர்டு மற்றும் Mermaid பேனல்கள் அனைத்தையும் ஒரே செங்குத்தாக ஸ்க்ரோல் செய்யக்கூடிய முன்னோட்ட ஷெல்லில், அவற்றின் மூல வரிசைப்படி காட்டும்; Mermaid பேனல்கள் அவற்றின் உண்மையான உயரத்தைப் பயன்படுத்தி, வெட்டப்படாமல் இருக்கும்.
6. ஒரு காட்சிக்காக ஒவ்வொரு பேனலுக்கும் **Export SVG**, **Export PNG** அல்லது **Export PDF** என்ற செயல்களைத் தேர்ந்தெடுக்கவும், அல்லது அனைத்து பேனல்களுக்கும் ஒரு உயர்நிலை படம் ஏற்றுமதி செய்யவும். பல பேனல்கள் இருந்தால், மூல folder-ஐ அல்லது Vault-உடன் தொடர்புடைய ஒரு கஸ்டம் folder-ஐத் தேர்ந்தெடுக்கவும்; Notemd ஒவ்வொரு பேனலுக்கும் ஒரு துல்லியமான கோப்பை உருவாக்கி, ஒரு செயலில் தோல்வி ஏற்பட்டாலும் தொடர்ந்து செயல்படும்.
7. நீங்கள் திருத்தக்கூடிய அசல் கோப்பையும் தேவைப்பட்டால், **Save source file** என்பதைப் பயன்படுத்தவும்.

Export menu-இல் தற்போதைய காட்சி முன்னோட்டத்திற்காக **Export SVG**, **Export PNG** மற்றும் **Export PDF** என்ற செயல்கள் கிடைக்கின்றன. ஒவ்வொரு பேனல் தலைப்பிலும், ஒரு Mermaid அல்லது Drawnix காட்சிக்கான அதே செயல்கள் கிடைக்கின்றன; எனவே பெரிய முன்னோட்டத்தை ஒரே ஒரு அப்ளூட் படமாக ஏற்றுமதி செய்ய வேண்டிய அவசியமில்லை.

படத்தை மறைக்காமல் Vault history drawer-ஐத் திறக்க, முன்னோட்டத்தில் **History** என்பதைத் தேர்ந்தெடுக்கவும். நீங்கள் ஏற்கனவே உருவாக்கப்பட்ட படங்களைத் தேடி, ஃபில்டர் செய்யவும்; ஒரு முன்னோட்டத்தை மீண்டும் திறக்கவும், அல்லது சேமிக்கப்பட்ட அசல் கோப்புகளைத் திறக்கவும். Diagram history-ஐ command palette மற்றும் Notemd sidebar-இலிருந்தும், எந்த நோட்டும் செயலில் இல்லாத போதும் நேரடியாகப் பெறலாம்.

SVG மற்றும் PDF ஆகியவை வெக்டர் ஜியோமெட்ரி அடிப்படையில் உருவாக்கப்படுகின்றன; PDF, முழு முன்னோட்டத்தையும் rasterize செய்யாமல், SVG-இன் அதே லேஅவுட் மற்றும் உரை அளவீடுகளைப் பயன்படுத்துகிறது. Notemd settings-இல் உள்ள image export PPI, PNG-இன் rasterization-ஐ மட்டுமே கட்டுப்படுத்துகிறது (72-600 PPI, 300 என்பது டிஃபால்ட்).

## Drawnix முன்னோட்டங்களில் Mermaid உள்ளடக்கம்

Drawnix அசல் கோப்புகளில் Mermaid காட்சிகள் இருந்தால், Notemd உருவாக்கப்பட்ட SVG-ஐ sanitize செய்து, Mermaid மூலத்தை `.drawnix` metadata-இல் அதனுடன் வைத்திருக்கும். எனவே, Drawnix knowledge map-இன் உள்ளே Mermaid படங்களைக் காட்டுவதற்கு Drawnix அல்லது Plait runtime-ஐப் பயன்படுத்த வேண்டிய அவசியமில்லை. பாதுகாப்பாக உள்ளடக்கப்பட்ட Mermaid-ஐ மட்டும் கொண்ட காட்சிகள், தனி `.assets` directory-ஐ உருவாக்காது; வெளிப்புற binary media அல்லது தீர்க்கப்படாத காட்சிகளுக்கு, தகவல் இழக்காமல் ஒரு துணை கோப்பு வைக்கப்படும்.

முன்னோட்டம் திட்டமிட்டபடி ஒரே ஸ்க்ரோல் செய்யக்கூடிய பரப்பாக உள்ளது: முதலில் Drawnix முக்கிய canvas காட்டப்படும், அதன் பிறகு Mermaid பேனல்கள் அவற்றின் மூல வரிசைப்படி ஒவ்வொன்றாகக் காட்டப்படும். ஏற்கனவே சேமிக்கப்பட்ட history entry-ஐ மீண்டும் திறந்தால், அதே பேனல் பட்டியல், அளவுகள் மற்றும் ஏற்றுமதி செயல்கள் மீண்டும் உருவாகும்.

## சுற்றுப்பாதை படங்கள்

ஆதரிக்கப்படும் சுற்றுப்பாதை தொடர்பான கோரிக்கைகளுக்கு, **Circuit diagram**-ஐ **CircuitikZ source file**-உடன் தேர்ந்தெடுக்கவும். Notemd முதலில் ஒரு கட்டமைக்கப்பட்ட சுற்றுப்பாதை விவரணையை உருவாக்கி, அதன் பிறகு CircuitikZ மூலத்தை எழுதும். இது, மாடலை கட்டுப்பாடுகள் இல்லாமல் LaTeX எழுதச் சொல்வதை விட நம்பகமானது.

தற்போதைய CircuitikZ ஆதரவு திட்டமிடப்பட்ட வகையில் மட்டுமே உள்ளது. Common-source NMOS amplifiers மற்றும் ஆதரிக்கப்படும் CMOS building blocks-கள் சிறந்த முடிவுகளைத் தரும். தொழில்நுட்ப அல்லது வெளியீட்டுப் பணிகளில் உருவாக்கப்பட்ட சுற்றுப்பாதைகளைப் பயன்படுத்துவதற்கு முன், எப்போதும் முன்னோட்டம் மற்றும் அசல் கோப்பை சரிபார்க்கவும்.

SVG முன்னோட்டம் என்பது Notemd உருவாக்கும் ஒரு மதிப்பாய்வு உதவி மட்டுமே. இது, உங்கள் சிஸ்டத்தில் LaTeX அல்லது TikZJax நிறுவப்பட்டு `.tex` கோப்பு வெற்றிகரமாக கம்பைல் செய்யப்பட்டதற்கான சான்று அல்ல.

**தேர்வுசெய்யக்கூடிய உள்ளூர் கம்பைல்.** Plugin-இல் உள்ள முன்னோட்டம், SVG, PNG அல்லது முன்னோட்ட PDF ஏற்றுமதிகளுக்கு LaTeX-ஐப் பயன்படுத்த வேண்டிய அவசியமில்லை. Desktop-இல், compile diagnostics அல்லது உள்ளூர் LaTeX PDF தேவைப்பட்டால், diagram settings அல்லது command palette-இலிருந்து **CircuitikZ native compile environment**-ஐத் திறக்கவும். Notemd, system `tectonic` அல்லது `pdflatex`-ஐ மீண்டும் பயன்படுத்தலாம்; ஒரு கஸ்டம் executable-ஐப் பயன்படுத்தலாம், அல்லது **Install** என்பதைத் தேர்ந்தெடுத்த பிறகு pinned managed Tectonic runtime-ஐ நிறுவலாம். Environment panel-இல் முன்னேற்றம் மற்றும் பிழைகள் inline-ஆகக் காட்டப்படும், மேலும் பின்னர் managed runtime-ஐ நீக்கவும் முடியும்.

## பிரச்சினைகளைத் தீர்த்தல்

### முடிவு தவறான படம் வகையாக இருக்கிறது

Auto-detect-ஐப் பயன்படுத்துவதற்குப் பதிலாக, படம் வகையை நேரடியாகத் தேர்ந்தெடுக்கவும். சுற்றுப்பாதை படங்களுக்கு, **Circuit diagram**-ஐத் தேர்ந்தெடுத்து, **Generate diagram** என்ற command-ஐப் பயன்படுத்தவும்; பழைய **Summarise as Mermaid diagram** command-ஐப் பயன்படுத்த வேண்டாம்.

### ஒரு மூல வடிவம் பொருந்தாது

மூல வடிவத்தை **Auto** என்ற நிலைக்கு மாற்றவும், அல்லது அந்த படம் வகைக்கு ஏற்ற ஒரு வடிவத்தைத் தேர்ந்தெடுக்கவும். CircuitikZ என்பது சுற்றுப்பாதை படங்களுக்கானது; Draw.io மற்றும் Drawnix ஆகியவை ஆதரிக்கப்படும் கட்டமைக்கப்பட்ட படங்களுக்கானவை.

### Export menu கிடைக்கவில்லை

SVG, PNG மற்றும் PDF-க்கு ஒரு காட்சி முன்னோட்டம் தேவை. மூல உரை மட்டுமே கிடைத்தால், அந்த மூல கோப்பைச் சேமித்து, அதைப் பொருந்தக்கூடிய வெளிப்புற கருவியில் திறக்கவும்.

### CircuitikZ கோப்பு வெளிப்புறத்தில் கம்பைல் செய்யப்படவில்லை

**CircuitikZ native compile environment**-ஐத் திறந்து environment check-ஐ இயக்கவும். Managed runtime-ஐ சரிசெய்யவும், அல்லது உங்கள் கஸ்டம்/system compiler-இல் `circuitikz` package கிடைக்கிறதா என்பதை உறுதி செய்யவும். Notemd, plugin file-இல் முழு TeX distribution-ஐயும் உள்ளடக்கியிருக்காது.
