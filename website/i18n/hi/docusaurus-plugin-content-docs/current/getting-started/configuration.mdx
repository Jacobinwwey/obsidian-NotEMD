# कॉन्फ़िगरेशन

<TLDR>Settings → Notemd खोलकर फ़ील्ड खोजें। नोट संसाधित करने से पहले प्रदाता और गंतव्य तय करें। एक नोट पर परिवर्तन जाँचें; चालू कार्य आरंभ के समय की सेटिंग्स रख सकता है।</TLDR>

## अवलोकन

डिफ़ॉल्ट प्रदाता DeepSeek है और प्रमाण खाली हैं। प्रोफ़ाइल चुनना खाता बनाना, मॉडल स्थापित करना या अधिकार देना नहीं है। [प्रदाता](../providers/overview) देखें।

## खोज और पसंदीदा सेटिंग्स

**Search settings** नाम, विवरण, alias और दिख रही श्रेणियाँ खोजकर फ़ील्ड तक ले जाता है। **★ Favorites** विवरण, श्रेणी और नेविगेशन सहित सहेजी सेटिंग्स दिखाता है। सूची वॉल्ट में रहती और पुराने ID हटाती है। टूलबार बंद करके खोलने पर query बचती है। पसंदीदा सूची और केवल पसंदीदा खोज फ़िल्टर अलग नियंत्रण हैं।

**Diagram preview export PPI** का प्रारंभिक मान 300 और दायरा 72–600 है; प्रभाव केवल PNG rasterization पर है। SVG/PDF समर्थित vector geometry रखते हैं। **Also export complete Mermaid visuals** साथी फ़ाइलों को नियंत्रित करता है, Drawnix में Mermaid दिखने को नहीं।

एक बार में कई आरेख प्रकार चुनें और हर प्रकार के लिए अलग-अलग कई आउटपुट प्रारूप तय करें। प्रकार का चयन हटाने पर उसके प्रारूप सुरक्षित रहते हैं; कोई प्रकार न चुना हो तो सामग्री का अपने-आप विश्लेषण होता है।

मध्यवर्ती फ़ाइलों के लिए Vault के सापेक्ष साझा फ़ोल्डर तय करें, या हर स्रोत के पास `notemd_assert/` इस्तेमाल करने के लिए खाली छोड़ें। इसमें पुनर्प्राप्ति रिकॉर्ड, रेंडर कैश और वैकल्पिक संलग्नक रहते हैं। जिन फ़ाइलों के संदर्भ अभी उपयोग में हैं उन्हें रखें; फ़ोल्डर बदलने का असर केवल नए रन पर है।

## 1. प्रदाता

सही प्रोटोकॉल का endpoint, ज़रूरी कुंजी और उपलब्ध मॉडल चुनें। सूची और सफल जनरेशन अलग परीक्षण हैं। स्थानीय मॉडल को सर्वर/मॉडल चाहिए; क्लाउड और gateway सामग्री लेते हैं। निजी काम में प्रत्येक task provider भी जाँचें।

## 2. प्रत्येक कार्य का मॉडल

`useMultiModelSettings` लिंक, शीर्षक, शोध, अनुवाद, अवधारणा, मूल पाठ और Mermaid के लिए अलग चयन देता है। खाली model override उस प्रदाता का मॉडल लेता है; विकल्प बंद हो तो सक्रिय प्रदाता लागू है। समान नोट पर शुद्धता, विलंब और असली कीमत तुलना करें; सार्वभौमिक ranking नहीं है।

## 3. आउटपुट

| कार्य | डिफ़ॉल्ट व्यवहार |
| ------ | ------------------------- |
| लिंक जोड़ना | मूल के पास अलग `_processed.md`; मूल को खिसकाना बंद |
| स्वतंत्र अवधारणा निष्कर्षण | चुना फ़ोल्डर, केवल शीर्षक और backlinks बंद |
| अनुवाद | पास में `_<language>.md`; मौजूद लक्ष्य बदल सकता है |
| शोध | सक्रिय Markdown में शोध सारांश जोड़ना |
| शीर्षक से बैच जनरेशन | पात्र मूल नोट लिखना और गंतव्य अनुमति दे तो साथ के `<folder>_complete` में ले जाना |
| आरेख पूर्वावलोकन/निर्यात | चुनी फ़ाइलें अपने-आप स्रोत नोट के पास या सीधे तय आउटपुट फ़ोल्डर में निर्यात होती हैं। नाम में प्रकार होता है, जैसे `topic_drawnix.pdf` और `topic_flowchart.svg`। नाम टकराने पर `-2`, `-3` आदि जुड़ते हैं; पुरानी फ़ाइल नहीं बदलती। |
अवधारणा फ़ोल्डर पहले खाली है। `concepts` आपका चयन है। स्वतंत्र निष्कर्षण न्यूनतम/पूर्ण रूप देता है, सामान्य template-variable engine नहीं। [अवधारणाएँ](../features/concept-notes) देखें। प्रक्रिया और अनुवाद के suffix तथा फ़ोल्डर अलग हैं। मौजूद लक्ष्य और recovery conflicts जाँचें; रद्द करना पूरा लेखन वापस नहीं करता।

## 4. भाषा

प्लगइन UI में 21 locales और साइट में 34 भाषा मार्ग हैं। `uiLocale: auto` समर्थित mapping अपनाता है; अनुपलब्ध UI भाषा अंग्रेज़ी पर लौटती है। जनरेशन भाषा स्वतंत्र और पहले अंग्रेज़ी है। समर्थित कार्य अलग भाषा चुन सकते हैं; अनुवाद `language` लेता है। मॉडल की भाषा गुणवत्ता इन संख्याओं से प्रमाणित नहीं होती।

## 5. खोज

Tavily तथा कुंजी या DuckDuckGo स्पष्ट चुनें। खाली Tavily कुंजी स्वतः नहीं बदलती। दोनों नेटवर्क उपयोग करते हैं और DuckDuckGo पृष्ठ भी ला सकता है। शीर्षक में शोध पहले बंद है: `enableResearchInGenerateContent`। स्थानीय retrieval भी बंद और अपनी folder/task scope वाला है। संदर्भ में इस्तेमाल स्थानीय अंश चुनी LLM तक भेजे जाते हैं।

## 6. वर्कफ़्लो

Builder या हर पंक्ति में नामयुक्त DSL उपयोग करें:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` नाम और कार्य, `>` कार्य ID अलग करता है। डिफ़ॉल्ट नीति बताई गई त्रुटि पर रुकती है। [वर्कफ़्लो](../features/workflows) में scope और त्रुटि के बाद जारी रखने के प्रभाव देखें।

## 7. उन्नत सेटिंग्स

| सेटिंग | प्रारंभिक मान | प्रभाव |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | अलग routing न हो तो प्रदाता |
| `useMultiModelSettings` | `false` | कार्यवार मॉडल और प्रदाता |
| `useCustomConceptNoteFolder` | `true` | फ़ोल्डर चुनने के बाद अवधारणा आउटपुट की अनुमति |
| `conceptNoteFolder` | `''` | शुरुआत में फ़ोल्डर नहीं |
| `extractConceptsMinimalTemplate` | `true` | स्वतंत्र नोटों में केवल शीर्षक |
| `extractConceptsAddBacklink` | `false` | स्वतंत्र निष्कर्षण में backlinks चालू करना |
| `moveOriginalFileOnProcess` | `false` | लिंक जोड़ते समय मूल बचाना |
| `chunkWordCount` | `3000` | अनुमानित पाठ टुकड़ा, token सीमा नहीं |
| `batchConcurrency` | `1` | डिफ़ॉल्ट बैच concurrency |
| `enableBatchParallelism` | `false` | इस विकल्प वाले समर्थित paths पर parallel scheduling |
| `enableStableApiCall` | `false` | स्पष्ट stable request mode |
| `customWorkflowErrorStrategy` | `stop_on_error` | बताई गई त्रुटि पर chain रोकना |

टुकड़े का आकार और आउटपुट token बजट अलग हैं। छोटा टुकड़ा सभी context limits की गारंटी नहीं और कम concurrency हर 429 नहीं रोकती।

## कॉन्फ़िगरेशन प्रोफ़ाइल

सेटिंग्स वॉल्ट के प्लगइन डेटा में रहती हैं। बदलने से पहले बैकअप लें। Provider export का अपना redaction contract है, यह पूरा वॉल्ट बैकअप नहीं। साफ़ किए export में भी endpoint और metadata देखें; raw settings या निजी नोट वाले diagnostic body प्रकाशित न करें।

## सेटिंग समस्या

ठीक प्रदाता/मॉडल को जाँचकर छोटा नोट चलाएँ। फ़ील्ड न मिले तो search, category, developer mode और वॉल्ट देखें। संस्करण और निजी सामग्री से रहित न्यूनतम कॉन्फ़िगरेशन से समस्या रिपोर्ट करें।

## 1.9.10 — सुरक्षित पूर्वावलोकन और Vault स्थानीय सेटिंग

आयातित SVG पूर्वावलोकन सक्रिय सामग्री और बाहरी संसाधन हटाता है, लेकिन चीनी लेबल और पैनल शैली बनाए रखता है। स्थानीय प्रदाता अब प्रत्येक Vault में अलग हैं; सेटिंग में पुरानी सूची स्पष्ट रूप से आयात करें, जिससे मूल सूची और मौजूदा कॉन्फ़िगरेशन सुरक्षित रहें। प्रस्तुति पूर्वावलोकन साझा उपयोगकर्ताओं का प्रबंधन करने वाला loopback सर्वर उपयोग करता है। पसंदीदा सहेजने और कॉपी करने की विफलता बताई जाती है; हटाना Vault की प्राथमिकताओं का पालन करता है। PNG संगतता चालू रहती है: मूल चित्र सुरक्षित रहता है और आवश्यकता पर ही सत्यापित कम PPI प्रति जुड़ती है। Drawnix संबंधों की निश्चित सीमा नहीं है; प्रस्तुति सेटिंग अलग रहती हैं। समान संस्करण की फ़ाइलें इंस्टॉल करके पुनः लोड करें और बैच से पहले एक नोट जाँचें।

## 1.9.11

प्लगइन सत्र के दौरान कार्य के चरणों और पूर्वावलोकन दोबारा खोलने के बीच लॉग जमा रहते हैं। रीसेट करने के लिए लॉग साफ़ करें का उपयोग करें; प्लगइन दोबारा लोड करने पर इतिहास नहीं रहता।

निदान टैग के अनुसार समूहों में होते हैं और डिफ़ॉल्ट रूप से बंद रहते हैं। प्रत्येक संदेश और सुझाव पढ़ने के लिए समूह खोलें; गंभीरता के अनुसार गिनती दिखाई देती रहती है।
