# स्थापना

<TLDR>Community plugins से Notemd स्थापित करें या एक ही GitHub Release की तीन रनटाइम फ़ाइलें अपने वॉल्ट में रखें। प्लगइन चालू करके प्रदाता चुनें और परीक्षण नोट चलाएँ। मॉडल सर्वर और वैकल्पिक नेटिव निर्यात उपकरण अलग से तैयार करने होते हैं।</TLDR>

## तरीका 1: Community plugins, अनुशंसित

1. इच्छित वॉल्ट में **Settings → Community plugins** खोलें।
2. आवश्यक हो तो समुदाय प्लगइन की अनुमति देकर **Browse** चुनें।
3. **Notemd** खोजें, रिपॉज़िटरी `Jacobinwwey/obsidian-NotEMD` जाँचें और **Install** चुनें।
4. **Enable** करें और रिबन या कमांड पैलेट से साइडबार खोलें।

[Obsidian में Notemd खोलें](obsidian://show-plugin?id=notemd)। ब्राउज़र यह लिंक न खोल सके तो ऊपर दिए मेनू का उपयोग करें; दस्तावेज़ पढ़ने के लिए प्रोटोकॉल हैंडलर आवश्यक नहीं है।

## तरीका 2: मैन्युअल स्थापना

### आवश्यकताएँ

स्थापित Obsidian और बैकअप लेने योग्य वॉल्ट चाहिए। Manifest में न्यूनतम `0.15.0` घोषित है; यह पुराने संस्करण पर नए उम्मीदवार की ताज़ा जाँच का प्रमाण नहीं है।

### चरण

1. एक ही [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest) से `main.js`, `manifest.json` और `styles.css` लें। `README.md` संदर्भ है, रनटाइम की आवश्यकता नहीं।
2. तीनों फ़ाइलें `<vault>/.obsidian/plugins/notemd/` में रखें। कॉन्फ़िगरेशन फ़ोल्डर बदला हो तो वास्तविक पथ अपनाएँ।
3. Obsidian पुनः लोड करके प्लगइन चालू करें।
4. संस्करण जाँचें; नया manifest पुराने bundle के साथ न मिलाएँ।

## विकल्प: BRAT

पहले से [BRAT](https://github.com/TfTHacker/obsidian42-brat) उपयोग करते हों तो उसकी बीटा-प्लगइन प्रक्रिया से रिपॉज़िटरी जोड़ें। बग दोहराने के लिए निश्चित रिलीज़ चुनें। यह वैकल्पिक बाहरी उपकरण है।

## सत्यापन

उपलब्ध प्रदाता और मॉडल चुनकर **Test connection** चलाएँ, फिर [त्वरित शुरुआत](./quick-start) का वास्तविक कार्य करें। केवल मॉडल सूची मिलना जनरेशन अधिकार सिद्ध नहीं करता। आउटपुट फ़ाइल भी देखें।

## सिस्टम सीमाएँ

| भाग | सीमा |
| --------- | ---------- |
| Manifest | न्यूनतम Obsidian `0.15.0`; `isDesktopOnly` false |
| परीक्षण प्रमाण | दिनांकित रिलीज़ रिकॉर्ड देखें; वास्तविक मोबाइल उपकरण और 0.15.0 अभी सत्यापित नहीं |
| क्लाउड मॉडल | नेटवर्क, अधिकृत खाता/कुंजी और समर्थित मॉडल |
| स्थानीय मॉडल | अलग स्थापित चालू सर्वर और डाउनलोड/लोड किया मॉडल |
| नेटिव स्लाइड या सर्किट निर्यात | डेस्कटॉप उपकरण तथा प्रारूप की निर्भरताएँ; पहले वातावरण जाँचें |

सभी वैकल्पिक निर्यातकों के लिए एक समान OS-संस्करण गारंटी नहीं है। सर्किट पूर्वावलोकन TeX संकलन सिद्ध नहीं करता; डेस्कटॉप परीक्षण मोबाइल व्यवहार नहीं सिद्ध करता।

## हटाना

Community plugins में Notemd बंद करें या हटाएँ। बने नोट और आर्टिफ़ैक्ट साधारण वॉल्ट फ़ाइलें रहते हैं। हटाने से पहले देखें और दोबारा स्थापना के लिए सेटिंग्स का बैकअप रखें। प्लगइन हटाना पूरे हो चुके संपादन वापस नहीं करता।

## अपडेट

**Check for updates** चुनें। मैन्युअल अपडेट में सक्रिय काम रोकें, वॉल्ट/सेटिंग्स का बैकअप लें, एक रिलीज़ की तीन रनटाइम फ़ाइलें बदलें और पुनः लोड करें। नोट्स तथा छोटा परीक्षण देखकर बैच फिर शुरू करें। सेटिंग्स फ़ाइल को रिलीज़ एसेट से न बदलें। वापसी के लिए ज्ञात संगत रिलीज़ और बैकअप का सचेत उपयोग करें।
