# त्वरित शुरुआत

<TLDR>एक परीक्षण Markdown नोट और पहले से उपलब्ध प्रदाता से शुरू करें। फ़ोल्डर संसाधित करने से पहले आउटपुट जाँचें। क्लाउड कार्य सामग्री भेजते हैं; स्थानीय मॉडल के लिए भी चालू सर्वर और तैयार मॉडल चाहिए।</TLDR>

## 1. मॉडल सेट करें

1. [स्थापित और सक्रिय](./installation) करके **Settings → Notemd** खोलें।
2. प्रोफ़ाइल, endpoint, आवश्यक प्रमाण और सुलभ मॉडल चुनें। **Fetch models** जनरेशन परीक्षण का विकल्प नहीं है।
3. **Test connection** चलाकर खाता, मॉडल या पते की त्रुटि सुधारें।
4. **Concept note folder path** खोजें और अवधारणाओं के लिए `concepts` जैसी अलग जगह चुनें। प्रारंभिक मान खाली है; यह स्वयं चुना उदाहरण है।

Ollama में मॉडल पहले डाउनलोड करें और सही नाम दें। प्रारंभिक पता `http://localhost:11434/api` है। LM Studio सर्वर शुरू करके `LMStudio` प्रोफ़ाइल चुनें। [स्थानीय मॉडल](../providers/local) देखें। सारांश मॉडल स्थानीय होने पर भी वेब शोध को नेटवर्क चाहिए।

## 2. पहला कार्य

`Notemd trial.md` में ऐसा छोटा पाठ रखें जिसे प्रदाता को भेज सकते हैं:

```text
मशीन लर्निंग उदाहरणों से पैटर्न सीखने के लिए न्यूरल नेटवर्क का उपयोग करती है।
```

साइडबार या कमांड पैलेट में **Process file (add links)** चलाएँ। डिफ़ॉल्ट रूप से मूल सुरक्षित रहता है और पास में `Notemd trial_processed.md` बनता है। वास्तविक फ़ाइल खोलें। संभावित उदाहरण:

```markdown
[[मशीन लर्निंग]] उदाहरणों से पैटर्न सीखने के लिए [[न्यूरल नेटवर्क]] का उपयोग करती है।
```

चुना अवधारणा फ़ोल्डर नए नोट भी पा सकता है। फ़ाइलें और लिंक जाँचें; मॉडल सभी महत्वपूर्ण अवधारणाओं की सही पहचान की गारंटी नहीं देता।

## 3. अन्य सुविधाएँ

### अवधारणा निकालना

**Extract concepts (current file)** मूल को नहीं लिखता और अवधारणा फ़ोल्डर माँगता है। नए स्वतंत्र नोट पहले केवल शीर्षक रखते हैं, स्रोत backlinks बंद हैं। आवश्यकता पर स्पष्ट रूप से चालू करें। [अवधारणा नोट](../features/concept-notes)।

### शोध और सारांश

Markdown संपादक में विषय चुनें या नोट शीर्षक लें और **Research & summarize** चलाएँ। Tavily तथा कुंजी या DuckDuckGo स्पष्ट रूप से चुनें। सारांश वर्तमान नोट में जुड़ता है; स्रोत खोलकर दावे सत्यापित करें।

### एक-क्लिक वर्कफ़्लो

डिफ़ॉल्ट **One-Click Extract** की सटीक परिभाषा:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

यह लिंक जोड़ता है, अवधारणा/चुने फ़ोल्डर के पात्र नोट शीर्षक से भरता है और complete फ़ोल्डर का Mermaid सुधारता है। पुराने पात्र नोट भी शामिल हो सकते हैं। पहले परीक्षण फ़ोल्डर लें। वेब शोध या सामान्य आरेख जनरेशन स्वतः नहीं जुड़ते।

## रद्द करना और आउटपुट

**Cancel** समर्थित आगे का काम रोकता है। पूरे हुए परिणाम रहते हैं; यह undo transaction नहीं और प्रदाता की जनरेशन या बिलिंग रुकने की गारंटी नहीं। समाप्ति का इंतज़ार करके पथ और recovery conflicts देखें, फिर दोहराएँ।

## समस्याएँ

- खाता/मॉडल त्रुटि: सही प्रोफ़ाइल और कनेक्शन जाँचें।
- अवधारणा फ़ाइल नहीं: गैरखाली सक्रिय फ़ोल्डर सेट करें।
- उपयोगी लिंक नहीं: उत्तर और prompt देखें; कोई निश्चित न्यूनतम शब्दसंख्या गारंटी नहीं देती।
- सीमा: quota जाँचते समय concurrency `1` रखें।
