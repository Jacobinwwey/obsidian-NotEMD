# Notemd परिचय

<TLDR>Notemd MIT-लाइसेंस वाला Obsidian प्लगइन है जो जाँचने और रखने योग्य फ़ाइलें बनाता है: विकी-लिंक Markdown, अवधारणा नोट, शोध सारांश, अनुवाद और आरेख। प्रदाता, कार्य और scope चुनें; मॉडल का परिणाम ज्ञान-संग्रह में रखने से पहले जाँचें।</TLDR>

## Notemd क्या है?

यह वॉल्ट कार्य को 36 cloud, gateway और local-server profiles से जोड़ता है। हर कार्य अपने output contract के अनुसार फ़ाइल बनाता या नोट बदलता है। कार्रवाई अलग या sidebar chain में चलती है। Output वॉल्ट में रहता है, लेकिन cloud को input और web research में नेटवर्क requests जाती हैं। Local storage और local inference अलग चुनाव हैं।

## मुख्य क्षमताएँ

### लिंक और अवधारणाएँ

मॉडल से शब्द चुनवाकर wiki-link जोड़ें। डिफ़ॉल्ट processed note अलग है। अवधारणा फ़ाइल को चुना folder चाहिए; स्वतंत्र extraction पहले title-only और backlinks बंद रखता है। [लिंक](./features/wiki-links), [अवधारणाएँ](./features/concept-notes)।

### शोध और स्थानीय संदर्भ

Tavily/DuckDuckGo से संदर्भ लेकर सारांश active note में जोड़ें। Optional scoped local retrieval जनरेशन में excerpts दे सकती है। Index lexical है, embedding-based semantic search नहीं। [शोध](./features/research)।

### अनुवाद और मूल अंश

फ़ाइल/फ़ोल्डर अनुवाद करें या सवाल से संबंधित मूल passages निकालें। उद्धरण मूल से मिलाएँ। Selection file-based translation का scope अपने-आप छोटा नहीं करता। [अनुवाद](./features/translation)।

### आरेख और निर्यात

एक बार में कई आरेख प्रकार चुनें और हर प्रकार के लिए अलग-अलग कई आउटपुट प्रारूप तय करें। प्रकार का चयन हटाने पर उसके प्रारूप सुरक्षित रहते हैं; कोई प्रकार न चुना हो तो सामग्री का अपने-आप विश्लेषण होता है। [आरेख मार्गदर्शिका: Draw.io, Drawnix, Mermaid, CircuitikZ](./features/diagrams).

### वर्कफ़्लो

**One-Click Extract** लिंक जोड़ता, concept/चुने folder में पात्र नोट titles से बनाता और complete folder में Mermaid ठीक करता है। पुराने concepts भी शामिल हो सकते हैं। प्रत्येक action की आवश्यकताएँ और outputs कायम हैं। [सटीक DSL](./features/workflows)।

## शुरुआत

1. सही वॉल्ट में [स्थापित](./getting-started/installation) करें।
2. Accessible model से अस्थायी नोट टेस्ट करें।
3. Concept folder और output paths चुनें।
4. बड़े batch से पहले फ़ाइलें देखें।

निश्चित समय या उपयोगी नोट की न्यूनतम लंबाई की गारंटी नहीं है। इतना छोटा शुरू करें कि समीक्षा कर सकें।

## आरेख क्षमता की दिशा

Typed specifications और target-specific rendering सीमा तय करते हैं। `DiagramSpec` हर grammar या reference layout का वादा नहीं करता। `circuitikz` समर्थित संरचनाओं तक सीमित है। TikZJax बाहरी है और preview native compile proof नहीं। Drawnix की static cross-branch arrows rearrangement के बाद attachment नहीं सिद्ध करतीं।

## आर्किटेक्चर

कार्य selected provider तक जाता, output parse/validate होकर note/artifact में लिखा जाता है। Search optional context देती है; preview/export की format-specific सीमाएँ हैं। [डेवलपर गाइड](./developers/overview) ownership और checks, [Agent गाइड](./agents/overview) bounded public exports बताती है। Internal registry सामान्य public automation API नहीं है।

## उपकरण तुलना {#notemd-vs-other-obsidian-ai-plugins}

ज़रूरी काम के अनुसार चुनें: file transformation, conversation, deterministic linking, retrieval या native editing। वर्तमान दस्तावेज़ तथा समान sample से, versions और enabled features लिखकर तुलना करें।

## डेटा और अनुकूलता

Cloud को input, search को query और LLM को सक्षम local excerpts मिलते हैं। Task-specific routing जाँचें। Cancel समर्थित आगे का काम रोकता और पूरे output बचाता है; remote generation/billing रुकना सुनिश्चित नहीं।

Manifest न्यूनतम Obsidian `0.15.0` और mobile loading घोषित करता है। उस संस्करण और वास्तविक मोबाइल उपकरण का वर्तमान प्रमाण नहीं है। Optional native exports desktop tools माँग सकते हैं। Website में 34 locale routes, plugin UI में 21 locales हैं; मॉडल की भाषा क्षमता अलग है।
