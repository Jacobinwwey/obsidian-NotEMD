# 自訂提示詞

<TLDR>
全域與任務開關皆啟用且自訂文字非空時，才替換內置提示詞。須自行保留輸出契約；沒有自動模板系統補回所有遺漏的格式指令。
</TLDR>

## 概覽

先用代表性筆記測預設提示詞。聚焦學習或同義詞抑制能解決時先用現有設定。需要特定擷取策略、輸出結構或翻譯風格時再自訂，批次前比較結果。

## 工作原理

### 提示詞結構

選擇內置或啟用的自訂任務提示詞，加入適用領域與語言要求，再替換該任務提供的變數。源文可能另以訊息傳送，研究可用變數不代表各處都可用。

覆寫可能移除 `CONCEPT:` 標記或研究上下文。請求格式合法不保證輸出可解析或有證據支持。

### 變數

使用精確大寫名稱及單層大括號：

| 任務 | 支援佔位符 |
| ------ | ----------------------- |
| 標題生成 | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| 研究摘要 | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| 翻譯 | `{LANGUAGE}`, `{TEXT}` |
| 原文擷取 | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` 依任務語言策略解析。添加連結和獨立概念擷取將原文作為任務內容，不要虛構內容變數；未知名稱不會自動填入。這不是概念檔案模板系統。

### 聚焦學習領域

啟用後填寫例如 `electrical engineering`，提示詞加入 `Relevant Fields` 指令。它是引導，不是排除無關概念的硬性過濾或證據。

## 設定

| 任務 | 開關 | 提示詞欄位 |
| ------ | --------------- | -------------- |
| 添加連結 | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| 標題生成 | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| 研究摘要 | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid 摘要 | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| 概念擷取 | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| 翻譯 | `useCustomPromptForTranslate` | `translatePrompt` |
| 原文擷取 | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

全部依賴 `enableGlobalCustomPrompts`。文字空白時回退預設。合併原文擷取有自身內置格式，不共享一般擷取覆寫。圖表能力生成也有型別輸出要求，Mermaid 摘要覆寫不等於通用圖表提示詞。

## 範例

電路筆記可啟用全域與概念擷取開關，保留解析器標記：

```text
從筆記擷取核心電機工程概念。
優先選具體元件名稱與物理機制，避免通用名詞。
每行一個概念，嚴格使用格式：
CONCEPT: 術語名稱
不要解釋，也不要包裹程式碼區塊。
```

在副本測試，審核條目、檔名與遺漏概念，和預設結果比較。保留原提示詞以便還原。

## 建議

- 一次測一個任務，先縮範圍再擴大批次。
- 研究保留來源證據，擷取保留精確原文。
- 本地化指令時保留可執行標識符與必要標記。
- 換模型／provider 後重測，提示詞不是校驗保證。
