# 安裝

<TLDR>
從 Obsidian 社群外掛安裝 **Notemd**，或將同一個 GitHub Release 的三個外掛檔案複製至 Vault。啟用後設定 provider，再以可捨棄筆記試跑。模型伺服器與選用原生匯出工具各有先決條件。
</TLDR>

## 方法一：社群外掛（建議）

1. 在目標 Vault 開啟**設定 → 社群外掛**。
2. 視需要啟用社群外掛，選擇**瀏覽**。
3. 搜尋 **Notemd**，確認儲存庫為 `Jacobinwwey/obsidian-NotEMD`，按下**安裝**。
4. **啟用**後，透過側邊圖示或命令面板開啟 Notemd。

[在 Obsidian 開啟 Notemd](obsidian://show-plugin?id=notemd)。瀏覽器無法開啟連結時，採用上述手動步驟；閱讀本指南不需要自訂通訊協定處理程式。

## 方法二：手動安裝

### 先決條件

準備已安裝的 Obsidian，以及可備份的 Vault。manifest 宣告最低版本 `0.15.0`，不表示最新候選版本已在該舊版本測試。

### 步驟

1. 從同一份 [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest) 下載 `main.js`、`manifest.json`、`styles.css`。附帶的 `README.md` 供查閱，不是執行所需檔案。
2. 建立 `<vault>/.obsidian/plugins/notemd/` 並複製三個檔案；若 Vault 使用其他設定目錄，請改用實際路徑。
3. 重新載入 Obsidian，從社群外掛啟用 Notemd。
4. 核對顯示版本後再設定 provider，勿混用新 manifest 與舊 bundle。

## 其他方式：BRAT

已使用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 時，可透過其測試外掛流程加入 `Jacobinwwey/obsidian-NotEMD`。重現問題時指定明確版本。BRAT 是選用外部工具，不是一般安裝的相依項目。

## 驗證

選擇可存取的 provider/model，執行 **測試連線**，再依[快速開始](./quick-start)處理筆記副本。有些連線測試只證明模型清單端點可達；實際任務才能驗證生成與檔案輸出。

## 系統需求

| 範圍 | 邊界 |
|---|---|
| 外掛 manifest | 宣告最低 Obsidian `0.15.0`；`isDesktopOnly` 為 false |
| 驗證證據 | 參考當前版本的具日期驗收紀錄；實體行動裝置與 Obsidian 0.15.0 尚未驗證 |
| 雲端 LLM | 網路、有效帳號／金鑰和受支援模型 |
| 本地 LLM | 另行安裝並執行的伺服器，以及已下載／載入模型 |
| 原生投影片／電路匯出 | 桌面工具與格式專用相依項目；執行前檢查環境 |

沒有涵蓋所有選用匯出器的統一作業系統版本保證。外掛電路預覽不等於原生 TeX 編譯成功，桌面測試也不能證明行動端行為。

## 解除安裝

在社群外掛停用或解除安裝。生成的筆記與產物仍是一般 Vault 檔案，刪除前請核對。如需重裝，先備份設定；解除安裝不會回復已完成的筆記修改。

## 更新

透過社群外掛檢查更新。手動升級先停止任務、備份 Vault 與設定，再以同一版本的三個執行檔案替換並重新載入。閱讀版本說明，先小規模試跑再恢復批次工作。

勿以 Release 附件替換 Vault 設定檔。回退時保留備份，明確安裝已知相容版本，並保留需要的生成輸出。
