# 研究與網路搜尋

<TLDR>
研究與摘要搜尋所選主題或目前筆記標題，交由設定的 LLM 總結可用上下文，再附加至活動 Markdown 筆記。明確選擇 Tavily 或 DuckDuckGo，並審核結果與引用。
</TLDR>

## 概覽

搜尋 provider 與摘要模型分別配置。Tavily 需金鑰，DuckDuckGo 無須金鑰但仍連網且可限流。本地摘要模型不使網路研究離線。

## 工作原理

### 先搜尋再摘要

1. 在 Markdown 編輯器開啟目標筆記，選短主題；未選文字時使用標題。
2. 執行 **研究並摘要**。
3. 查詢所選服務；Tavily 提供片段，DuckDuckGo 可能抓取結果網頁。
4. 任務啟用本地檢索時，限定範圍片段也可加入。
5. 研究 provider/model 生成摘要，附加於標示主題與上下文來源的 `Research Summary` 下。
6. 審核文字並打開來源 URL；檢索不保證所有陳述／引用有證據。

### Tavily 與 DuckDuckGo

| 選項 | 設定 | 執行邊界 |
|---|---|---|
| Tavily | 選 Tavily 並提供 API key | 使用帳號配額及回傳片段 |
| DuckDuckGo | 明確選 DuckDuckGo | 無金鑰，受限流與結果頁可用性影響 |

Tavily 金鑰無效或空白不自動切換。沒有有用網路上下文時檢查報告；已啟用且可用的本地知識仍可支持摘要，來源標籤會區分。

### 標題生成中的研究

開啟 **在「從標題生成」中啟用研究** 可為標題生成及批次版本加入研究，預設關閉。這是支援的目錄生成路徑，沒有獨立通用 Research Folder 動作。

## 設定

| 設定 | 預設 | 作用 |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | 搜尋後端 |
| `tavilyApiKey` | `''` | 使用 Tavily 前提供金鑰 |
| `tavilyMaxResults` | `5` | Tavily 要求結果數 |
| `tavilySearchDepth` | `basic` | Tavily 搜尋深度 |
| `ddgMaxResults` | `5` | DuckDuckGo 要求結果數 |
| `ddgFetchTimeout` | `15` | 結果頁抓取逾時，秒 |
| `maxResearchContentTokens` | `3000` | 近似網路上下文預算 |
| `researchProvider` | `DeepSeek` | 任務路由啟用時的摘要 provider |
| `researchModel` | `''` | 空白時使用該 provider 模型 |
| `researchSummarizeLanguage` | `en` | 專用語言啟用時的輸出語言 |
| `enableResearchInGenerateContent` | `false` | 選擇在標題生成中研究 |
| `enableLocalKnowledgeRetrieval` | `false` | 另行啟用限定範圍本地檢索 |
| `enableLocalKnowledgeForResearchSummarize` | `false` | 為研究摘要使用本地檢索 |

### 上下文與模型

限制以估算而非 provider 精確 token 化計算，截斷可能漏掉證據。依材料選擇模型和輸出預算，保持問題聚焦。本地索引為詞法，不表示 embedding 語意搜尋或完整召回。

## 範例

建立 `Relative positional encoding` 筆記，執行研究後用引用原論文或官方文件核對。保留問題、實際 URL 和修正，便於他人稽核。指南範例不代表已在你的 Vault 取得研究結果。

## 取消與隱私

取消於支援處停止後續工作，完成的附加保留，已開始的請求／抓取仍可能完成。搜尋服務收到查詢、網站收到抓取請求、LLM 收到收集上下文及啟用的本地片段。分享診斷前審核。

## 建議

- 區分網路來源、本地筆記與模型推論。
- 回到原文核對引文、日期和重要結論。
- 用短查詢分別診斷搜尋與 LLM。
- 重跑前檢查既有摘要，避免重複附加。
