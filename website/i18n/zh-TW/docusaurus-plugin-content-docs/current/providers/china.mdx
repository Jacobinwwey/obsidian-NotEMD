# 中國地區 Provider

<TLDR>
使用匹配帳號與部署的預設。即使提供同一 OpenAI-compatible 協定，地區路徑、模型名與權限也不可互換。選擇工作負載前先驗證小任務。
</TLDR>

## 設定

建立 API 帳號、取得金鑰，選對應 Notemd 預設，確認地區與模型授權。測連線並跑可捨棄筆記；預設不保證目前模型可用。

## 端點與認證

Doubao 佔位值需換成部署支援的 Ark endpoint ID 或模型 ID。GLM、Z AI 有不同地區預設。某地區或訂閱路徑金鑰未必能用於另一端點，依帳號說明而非僅按所在地配置。

## 模型探索

允許時使用模型探索。Huawei Cloud MaaS 採部署感知發現；其他列出預設在支援時採 OpenAI-compatible 路徑。沒有清單權限不等於顯式模型無法生成。

測試方式依預設不同，DeepSeek 可只憑清單成功，部分地區預設執行短聊天。仍須實際任務驗證提示詞及輸出。

## 疑難排解

- 金鑰接受但生成拒絕：核對模型權限、部署與地區。
- Ark 模型拒絕：確認要求 deployment ID 或 model ID。
- 推理截斷：檢查輸出上限與專用 thinking 設定。
- 網路錯誤：由執行 Obsidian 的裝置測試精確端點並看傳輸錯誤。

## 適用情境

按端點可達性、資料處理要求和實測輸出選擇。地區或品牌不保證品質、隱私及費用。[Provider 概覽](./overview)也列出可能更適合的閘道與本地伺服器。
