# Anthropic 提供方

<TLDR>
原生 Messages API 使用 Anthropic 預設。經 OpenAI-compatible 閘道提供的 Claude 應用閘道預設。執行前核對目前模型存取權，歷史預設值可能要更新。
</TLDR>

## 設定

選 **Anthropic**，填寫其 API key，保留原生端點，除非部署明確提供同一協定。填入目前可用 Claude ID，執行 **測試連線**，再以可捨棄筆記驗證目標任務。

## 端點與認證

| 欄位 | 預設值 |
| ------- | -------------- |
| 傳輸協定 | `anthropic` |
| API key | 必填 |
| 基礎 URL | `https://api.anthropic.com` |
| 預設模型 | `claude-3-5-sonnet-20240620` |
| Temperature | `0.5` |
| 連線測試 | `chat-only` |

執行時使用 `/v1/messages` 與原生 API key、API version 標頭。不要填入 OpenAI 風格聊天路由。預設模型記錄儲存庫設定，不表示上游仍提供該模型。

## 模型探索

支援時使用原生 Anthropic 模型清單。權限受限時填入可存取模型 ID，以聊天連線測試核對。長內容及結構化任務需另外驗證。

## 疑難排解

- `401`／`403`：核對金鑰、workspace／project 權限、計費和模型授權。
- `404`：檢查端點與當前模型可用性。
- 閘道模型 ID 失敗：改用匹配閘道預設和標識符。
- 長回應失敗：先檢查輸出限制及錯誤，再考慮重試。

## 適用情境

端點採 Anthropic Messages 協定時使用此預設。以自身源文比較結果，不把 provider 選擇視為品質排名；可用任務專用路由限定適用範圍。
