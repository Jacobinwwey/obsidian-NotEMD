# المعالجة على دفعات

<TLDR>
تشترك أفعال المجلد في الاختيار والتقدم، لكنها تختلف في الكتابة والاستبدال. التزامن الافتراضي واحد. ابدأ بمجلد اختبار وافحص الملفات والوجهات ثم وسّع الدفعة.
</TLDR>

## نظرة عامة

استخدم فعل المجلد من الشريط الجانبي أو قائمة مستكشف الملفات. تشمل المهام الربط واستخراج المفاهيم والتوليد من العنوان والترجمة واستخراج الأصل وإصلاح Mermaid والصيغ. لا يوجد بحث مجلد عام؛ التوليد من العنوان يمكن أن يضم بحثًا اختياريًا.

ليست الدفعة معاملة تشمل المجلد كله. تبقى النتائج المكتوبة إذا فشل ملف آخر أو أُلغي التشغيل.

## آلية العمل

### نموذج التنفيذ

1. اختر المهمة والمجلد وتأكد من أنه يحتوي الملفات المقصودة.
2. تُجمع الملفات المؤهلة حسب الامتداد وقواعد الاختيار وتُستبعد مخرجات خاصة بالمهمة.
3. يُستخدم مزوّد المهمة ونموذجها ويُبلّغ عن التقدم والفشل والمسار.
4. افحص التقرير والملفات عند الانتهاء أو الإلغاء قبل التكرار.

تشمل المهام افتراضيًا المجلدات الفرعية للربط والمفاهيم والتوليد واستخراج الأصل وإصلاح Mermaid والصيغ. **ترجمة المجلد تشمل الملفات المباشرة فقط افتراضيًا.** يمكن لملفات الاختيار تغيير ذلك عند تفعيل وضع المطوّر والاختيار المتقدم معًا؛ لا تفترض تطابق النطاق بين المهام.

### سلوك الاستبدال

| المهمة | ما تفحصه قبل التكرار |
| ------ | ------------------------------------ |
| إضافة الروابط | ناتج مستقل افتراضيًا؛ افحص اللاحقة والمجلد ونقل الأصل |
| استخراج المفاهيم | قد تضاف روابط مصدر لملفات موجودة عند تفعيلها؛ مراجعة التكرار منفصلة |
| التوليد من العنوان | تُكتب الملاحظات المؤهلة وتنقل إلى complete إن كانت الوجهة متاحة |
| الترجمة | يمكن استبدال ترجمة موجودة؛ الأسماء الافتراضية `_<language>.md` |
| إصلاح Mermaid والصيغ | تُعدّل الملفات المختارة؛ افحص عينة واحتفظ بنسخة |

لا توجد سياسة موحدة للتجاوز أو الإلحاق أو الاستبدال. وجود ملف في complete يمنع نقل ناتج التوليد إليه، ولا يعني تجاوز التوليد السابق. يميز التقرير أعداد التوليد والنقل.

### التحكم بالتزامن

احتفظ بـ`batchConcurrency: 1` حتى تنجح عينة. بعض المسارات تحتاج `enableBatchParallelism` أيضًا، بينما تستخدم ترجمة المجلد التزامن مباشرة. زيادته تضغط المزوّد والذاكرة والخادم المحلي ولا تضمن سرعة أعلى.

يمكن للفاصل بين الطلبات والمجموعات تخفيف الاندفاع، لكن لا يضمن تجنب حدود الطلبات أو token أو الحساب أو العملاء الآخرين.

## الإعدادات

| الإعداد | الافتراضي | الأثر |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | التزامن المطلوب للمسارات المناسبة |
| `enableBatchParallelism` | `false` | تفعيل الجدولة المتوازية حيث تُدعم |
| `batchSize` | `50` | حجم مجموعة الجدولة |
| `batchInterDelayMs` | `1000` | الفاصل بين المجموعات عند انطباقه |
| `apiCallIntervalMs` | `500` | فاصل جدولة الطلبات المتزامنة |
| `folderTaskIncludeSubfoldersMode` | `legacy` | الحفاظ على نطاق المجلدات الافتراضي لكل مهمة |
| `enableStableApiCall` | `false` | وضع الطلب المستقر الصريح |

### نماذج المهام في الدفعة

يستخدم فعل المجلد اختيار المزوّد والنموذج نفسه للمهمة الفردية. افحصه قبل معالجة الخصوصيات. يستخدم الاسترجاع المحلي في دفعة التوليد لقطة تُبنى عند البداية؛ لا تُخلط تعديلات أثناء التشغيل في النتائج اللاحقة. ابدأ دفعة جديدة لإدخالها.

## مثال

أنشئ `trial-titles` بملاحظتي عنوان فقط، ونفّذ **إنشاء جماعي من العناوين**. راجع المحتوى و`trial-titles_complete` وعدد الملفات المولدة والمنقولة والأخطاء. شخّص الملف الفاشل أولًا؛ تكرار المجلد الأصلي ليس استئنافًا دقيقًا للعمل الناقص وحده.

## الإلغاء والاسترداد

يوقف الإلغاء جدولة عمل جديد وينتقل إلى الطلبات المدعومة. قد تكمل الأنظمة الخارجية طلبًا أو كتابة قبلتها بالفعل، والفوترة بيد المزوّد. انتظر استقرار الدفعة وافحص الملفات المكتملة ومسارات التعارض والاسترداد. لا تزل نسخة الاسترداد قبل مقارنتها بالملاحظة الحالية.

## إرشادات

- تحقق من الملفات المطابقة لملف الاختيار قبل استخدامه.
- خفّض التزامن وافحص الحصص عند 429.
- ميّز الإلغاء والفشل والإكمال.
- احتفظ بعينة أصلية ونسخة احتياطية قبل تعديل ملفات موجودة.
