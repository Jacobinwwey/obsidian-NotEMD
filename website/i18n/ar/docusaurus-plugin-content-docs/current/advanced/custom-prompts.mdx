# المطالبات المخصصة

<TLDR>
تستبدل المطالبة المخصصة الأصل المدمج عند تفعيل المفتاح العام ومفتاح المهمة ووجود نص غير فارغ. حافظ بنفسك على عقد الإخراج؛ لا يوجد قالب عام يعيد تلقائيًا كل تعليمات التنسيق المحذوفة.
</TLDR>

## نظرة عامة

اختبر الافتراضي على ملاحظة ممثلة أولًا. استخدم مجال التعلم أو تقليل المرادفات إذا كفيا، وخصص عند الحاجة إلى سياسة استخراج أو بنية أو أسلوب ترجمة محدد. قارن قبل تشغيل دفعة.

## آلية العمل

### بنية المطالبة

يختار Notemd النص المدمج أو المخصص المفعّل، ويضيف تعليمات المجال واللغة المناسبة ثم يستبدل متغيرات تلك المهمة. قد يُرسل المحتوى كرسالة منفصلة؛ متغير صالح للبحث ليس متاحًا في كل موضع.

قد يزيل التخصيص عقد `CONCEPT:` أو يسقط سياق البحث. الطلب الصحيح شكليًا لا يثبت قابلية تحليل الناتج أو دعمه بالأدلة.

### المتغيرات

استخدم الأسماء الكبيرة والأقواس المفردة كما يلي:

| المهمة | المتغيرات المتاحة |
| ------ | ----------------------- |
| التوليد من العنوان | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| خلاصة البحث | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| الترجمة | `{LANGUAGE}`, `{TEXT}` |
| استخراج الأصل | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

تُحل `{LANGUAGE}` وفق سياسة لغة المهمة. ترسل إضافة الروابط واستخراج المفاهيم النص كمحتوى مهمة؛ لا تخترع متغير محتوى لهما. لا تُملأ الأسماء المجهولة تلقائيًا. هذه بدائل للمطالبات لا قوالب لملفات المفاهيم.

### مجال التعلم

فعّل التركيز وأدخل مجالًا مثل `electrical engineering`، فتُضاف تعليمات `Relevant Fields`. هي توجيه للانتباه لا مرشح صارم أو دليل استبعاد المفاهيم غير المرتبطة.

## الإعدادات

| المهمة | مفتاح التفعيل | حقل النص |
| ------ | --------------- | -------------- |
| إضافة الروابط | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| التوليد من العنوان | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| خلاصة البحث | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| خلاصة Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| استخراج المفاهيم | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| الترجمة | `useCustomPromptForTranslate` | `translatePrompt` |
| استخراج النص الأصلي | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

تتطلب جميعها `enableGlobalCustomPrompts`. النص الفارغ يعيد المطالبة المدمجة. للاستخراج المدمج للنص الأصلي شكله الخاص ولا يشارك تجاوز الاستخراج العادي. ولتوليد الرسوم متطلبات محددة النوع؛ تخصيص تلخيص Mermaid ليس مطالبة عامة لجميع الرسوم.

## مثال

لمفاهيم الدارات، فعّل المفتاحين العام والخاص مع الحفاظ على علامة المحلل:

```text
استخرج المفاهيم المركزية في الهندسة الكهربائية من الملاحظة.
فضّل أسماء المكونات المحددة والآليات الفيزيائية على الأسماء العامة.
أعد مفهومًا واحدًا في كل سطر بهذه الصيغة بالضبط:
CONCEPT: اسم المصطلح
لا تضف شروحًا أو سياج شيفرة يحيط بالإجابة.
```

اختبر نسخة وافحص العناصر والأسماء والمفاهيم المفقودة، وقارن مع الافتراضي. احفظ المطالبة القديمة لتتمكن من إعادتها.

## إرشادات

- اختبر مهمة واحدة واضبط النطاق قبل توسيع الدفعة.
- احتفظ بسياق الأدلة للبحث وبالنصوص الدقيقة للاستخراج.
- حافظ على المعرّفات والعلامات المطلوبة عند تعريب الشرح.
- أعد الفحص عند تغيير المزوّد أو النموذج؛ التعليمات ليست ضمان تحقق.
