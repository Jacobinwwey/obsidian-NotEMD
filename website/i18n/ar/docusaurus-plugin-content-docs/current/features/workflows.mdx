# سير العمل

<TLDR>
ينفذ سير العمل أفعال الشريط الجانبي بالتتابع. قد يطلب مجلدًا أو محررًا نشطًا. ليس أنبوب نص: يحتفظ كل فعل بمدخله ومخرجه وآثاره. ابدأ بملاحظة قابلة للحذف ومجلد مخصص.
</TLDR>

## نظرة عامة

التعريف المشحون لـ **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. إضافة روابط إلى الملاحظة النشطة، وإنشاء مفاهيم عند ضبط مجلدها.
2. توليد محتوى للملفات المؤهلة في مجلد المفاهيم أو المجلد المحدد للدفعة، بما فيها ملفات سابقة.
3. إصلاح Mermaid في مجلد complete الناتج.

لا ينفذ الافتراضي بحث ويب. يمكن للتوليد استخدامه فقط إذا فُعّل إعداد البحث المنفصل. راجع [الدفعات](../advanced/batch-processing) للنطاق والمخرجات.

## آلية العمل

### التنفيذ

تعمل الخطوات بالتتابع وتعرض الحالة والأخطاء. يوقف الإلغاء الخطوات اللاحقة ويصل إلى الطلبات المدعومة. تبقى الكتابات المكتملة ولا يوجد تراجع شامل للدفعة.

مجلد المفاهيم هو التفضيل الأولي؛ يسجل التوليد مجلد المصدر وcomplete ليستخدمه إصلاح Mermaid التالي. وتحتفظ الأفعال الأخرى بمتطلبات الملف النشط أو التحديد أو التفاعل.

### صيغة DSL

تعريف مسمى في كل سطر؛ يفصل `::` الاسم عن قائمة الأفعال و`>` بين المعرّفات. تُهمل الأسطر الفارغة والتي تبدأ بـ`#`، وتُرفض المعرّفات المجهولة.

```text
استخراج ورسم::extract-concepts-current>summarize-as-mermaid
```

استخدم المنشئ أو حرر DSL. المعرّفات ثابتة وتسميات العرض تتبع لغة الواجهة. لنسخ المجلد معرّفات خاصة وليست قاعدة عامة لاستبدال الكلمات.

| المعرّف | الفعل أو المتطلب |
| ------------ | ----------------------- |
| `process-current-add-links` | إضافة روابط للملف النشط |
| `process-folder-add-links` | إضافة روابط لمجلد مختار |
| `extract-concepts-current` | استخراج مفاهيم الملف النشط |
| `extract-concepts-folder` | استخراج مفاهيم مجلد |
| `generate-from-title` | توليد محتوى من عنوان الملف |
| `batch-generate-from-titles` | توليد للملفات المؤهلة في مجلد |
| `research-and-summarize` | بحث تحديد أو عنوان داخل محرر Markdown |
| `summarize-as-mermaid` | تلخيص الإدخال النشط المدعوم بصيغة Mermaid |
| `generate-diagram` | إنشاء رسم من إدخال مدعوم |
| `preview-diagram` | فتح معاينة مصدر رسم أو منتج مدعوم |
| `translate-current-file` | ترجمة الملف النشط المدعوم |
| `batch-translate-folder` | ترجمة مجلد مختار |
| `extract-original-text` | استخراج مقاطع أصلية محددة |
| `batch-extract-original-text` | استخراج الأصل من ملفات مجلد مؤهلة |
| `split-note-by-chapters` | تقسيم الملف حسب الفصول |
| `batch-mermaid-fix` | إصلاح كتل Mermaid في مجلد |
| `fix-formula-current` | توحيد فواصل الصيغ في الملف |
| `batch-fix-formula` | توحيد فواصل الصيغ في مجلد |
| `check-duplicates-current` | فحص التكرار في الملف |
| `check-remove-duplicate-concepts` | مراجعة وإزالة المفاهيم المتكررة تفاعليًا |
| `test-llm-connection` | اختبار المزوّد |
| `probe-slide-export-env` | فحص بيئة تصدير الشرائح المحلية |
| `export-slides` | تصدير الملف النشط كشرائح |

### الافتراضي والمخصص

One-Click Extract هو الافتراضي. الأزرار الأخرى تعريفاتك. ابحث عن إعداد سير العمل، سمّه واختر الأفعال ورتبها، وافحص تلميح الزر قبل التشغيل. أصلح خطأ التحليل قبل الاعتماد على السلسلة.

## الإعدادات

| الإعداد | الافتراضي | الأثر |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | التوقف عند أول فشل مُبلّغ عنه |
| `useMultiModelSettings` | `false` | استخدام المزوّد النشط حتى تفعيل نماذج المهام |
| `enableResearchInGenerateContent` | `false` | إبقاء البحث خارج توليد العنوان ما لم يُفعّل |

يسمح `continue_on_error` للخطوات اللاحقة بالعمل بعد فشل سابق. استخدمه فقط حين يمكنها الاستفادة من المدخلات الباقية؛ المتابعة لا تجعل سيرًا ناقصًا ناجحًا.

### نماذج المهام

اختيار المزوّد والنموذج تابع للمهمة. التجاوز الفارغ يستخدم نموذج المزوّد المحدد. راجع كل مهمة قبل معالجة معلومات خاصة.

## مثال

حدد مجلد `trial-concepts` فارغًا وعالج مصدرًا تجريبيًا، ثم افحص المفاهيم ومجلد complete المبلّغ عنه. شغّل الأفعال منفردة أولًا إن أردت فهم وجهاتها. وسّع النطاق بعد المراجعة.

## إرشادات

- اجعل السلاسل قصيرة ليسهل فهم الفشل وملكية المخرجات.
- تجنب التنظيف والحذف في سلاسل بلا إشراف؛ تبقى شروط التأكيد التفاعلي.
- افحص السجل والملفات بعد الإلغاء أو تعارض الاسترداد.
- اختبر النموذج والمجلد نفسيهما؛ اتصال قصير ناجح لا يضمن ملاءمة حصة دفعة طويلة.
