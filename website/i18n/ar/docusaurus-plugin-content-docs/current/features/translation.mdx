# الترجمة

<TLDR>
يترجم Notemd الملف النشط أو ملفات المجلد المؤهلة باستخدام LLM المحدد، ويكتب افتراضيًا ملفًا مستقلًا بلاحقة اللغة. تعتمد التغطية والجودة على النموذج؛ لغات الواجهة الـ21 ومسارات الموقع الـ34 ليست حدودًا أو ضمانات للترجمة.
</TLDR>

## نظرة عامة

اختر لغة الهدف والمزوّد قبل التنفيذ. جرّب نسخة تحتوي مصطلحات وروابط وشيفرة ممثلة. تستخدم الوظيفة LLM المختار وليست تكاملًا خاصًا مع Google Translate.

الأفعال المسجلة تعمل على الملفات والمجلدات. لترجمة فقرة فقط انسخها إلى ملاحظة مؤقتة؛ تحديدها في المحرر لا يغيّر نطاق **ترجمة الملف الحالي**.

## آلية العمل

### أمر الترجمة

1. اختر لغة الإخراج من عنصر اللغة؛ الافتراضي الإنجليزية وهو مستقل عن لغة الواجهة.
2. افتح المصدر ونفّذ **ترجمة الملف الحالي**.
3. تُجزّأ النصوص الطويلة وتُرسل إلى نموذج الترجمة ثم تُدمج.
4. افتح المسار المبلّغ عنه وراجع المعنى والمصطلحات والاستشهادات والروابط والشيفرة.

افتراضيًا تصبح ترجمة `Example.md` إلى الفرنسية `Example_fr.md` بجواره مع إبقاء الأصل. يُستبدل إخراج مطابق موجود؛ لا توجد إضافة افتراضية للمصدر ولا عنوان `Translation` مضمون.

### أزواج اللغات

يستنتج النموذج لغة المصدر. وجود لغة هدف في القائمة لا يثبت دقة الزوج اللغوي. اختبر المصطلحات والمقاطع المختلطة؛ وقد يفقد النص الطويل سياقًا بين الأجزاء.

### نموذج خاص بالترجمة

فعّل نماذج المهام لاستخدام `translateProvider` و`translateModel`، وإلا يُستخدم المزوّد النشط. يحتاج المحلي خادمًا ونموذجًا جاهزين؛ وتتلقى السحابة المحتوى والمطالبة.

اختر بعينة من مجالك ومقارنة مع الأصل، لا بترتيب عام للسرعة أو الجودة فقط.

### ترجمة مجلد

نفّذ **ترجمة مجلد دفعة واحدة** وافحص الاختيار. يشمل الافتراضي الملفات المباشرة فقط؛ ويمكن لملفات اختيار متقدمة تغيير ذلك. يستخدم كل إخراج اسم المصدر الأساسي ولاحقة اللغة؛ لذلك قد تتصادم ملفات متطابقة الاسم في مجلد إخراج مخصص واحد. اختر الوجهات وراجع الترجمات القائمة قبل التكرار.

## الإعدادات

| الإعداد | الافتراضي | الأثر |
| --------- | --------- | -------- |
| `language` | `en` | لغة الإخراج المختارة |
| `translateProvider` | `DeepSeek` | مزوّد الترجمة عند توجيه المهام |
| `translateModel` | `''` | استخدام نموذج المزوّد عند الفراغ |
| `useCustomTranslationSuffix` | `false` | استخدام لاحقة رمز اللغة افتراضيًا |
| `translationCustomSuffix` | `_translated` | اللاحقة عند تفعيل التخصيص |
| `useCustomTranslationSavePath` | `false` | الحفظ بجوار المصدر افتراضيًا |
| `translationSavePath` | `''` | مجلد إخراج نسبة للخزنة |
| `batchConcurrency` | `1` | التزامن المطلوب لترجمة المجلد |

عند تعذر إنشاء المجلد المخصص يمكن العودة إلى مجلد المصدر، ويُعرض المسار الفعلي. افحصه بدل افتراض استخدام المطلوب. اللاحقة المخصصة الفارغة قد تستهدف ملف المصدر؛ استخدم لاحقة مميزة لإخراج مستقل.

## مثال

اختر الإنجليزية، وانسخ ملاحظة صينية قصيرة إلى مجلد تجريبي، ونفّذ ترجمة الملف. قارن `_en.md` بالمصدر، وافحص المصطلحات والأرقام والمعادلات والروابط قبل توسيع المجلد.

## الإلغاء والمراجعة

يوقف الإلغاء العمل اللاحق حيث يُدعم، ولا يحذف الترجمات المكتوبة أو يضمن إلغاء الفوترة. راجع تقرير المهمة وملفاتها. طلب حفظ Markdown توجيه للنموذج، لا ضمان من المحلل لتكافؤ المعنى.

## إرشادات

- احتفظ بالأصل وافحص تصادم الأسماء.
- جرّب بلاحقة ومجلد مستقلين.
- تحقق يدويًا من المعرّفات والرياضيات وURLs والأسماء الخاصة.
- افحص البيانات الخاصة في التشخيص قبل المشاركة.
