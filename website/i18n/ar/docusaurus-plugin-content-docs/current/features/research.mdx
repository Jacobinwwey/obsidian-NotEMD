# البحث على الويب والتلخيص

<TLDR>
تبحث المهمة عن الموضوع المحدد أو عنوان الملاحظة، وتطلب من LLM تلخيص السياق المتاح، ثم تلحق الناتج بملاحظة Markdown النشطة. اختر Tavily أو DuckDuckGo صراحة وراجع النتائج والاستشهادات المولّدة.
</TLDR>

## نظرة عامة

خدمة البحث منفصلة عن نموذج كتابة الخلاصة. Tavily يحتاج مفتاحًا، وDuckDuckGo لا يحتاجه لكنه يتصل بالشبكة وقد يُقيّد. نموذج تلخيص محلي لا يجعل بحث الويب دون اتصال.

## آلية العمل

### البحث ثم التلخيص

1. افتح الملاحظة في محرر Markdown وحدد موضوعًا قصيرًا، أو اترك التحديد فارغًا لاستخدام العنوان.
2. نفّذ **بحث وتلخيص**.
3. تستعلم الإضافة من خدمة البحث؛ تستخدم مقاطع Tavily، وقد تجلب صفحات نتائج DuckDuckGo.
4. يمكن إضافة مقتطفات محلية ضمن النطاق إن فُعّل الاسترجاع لهذه المهمة.
5. يكتب نموذج البحث خلاصة وتلحق تحت عنوان `Research Summary` يبين الموضوع ومصدر السياق.
6. افتح عناوين المصادر وراجع النص؛ استرجاع نتائج لا يثبت دعم كل جملة أو استشهاد.

### مقارنة طريقتي البحث

| الخيار | الإعداد | الحد التشغيلي |
|---|---|---|
| Tavily | اختياره وإدخال API key | حصة الحساب والمقاطع التي تعيدها الخدمة |
| DuckDuckGo | اختياره صراحة | بلا مفتاح، مع قيود بحث وتوافر صفحات النتائج |

مفتاح Tavily الفارغ أو غير الصالح لا يحوّل تلقائيًا إلى DuckDuckGo. إذا غاب سياق مفيد، افحص التقرير. قد تكفي مقتطفات الخزنة عند تفعيلها وتوفرها، ويميز وسم المصدر ذلك عن البحث المدعوم بالويب.

### البحث أثناء التوليد من العنوان

فعّل **Enable research in "Generate from title"** لإضافة البحث إلى التوليد الفردي والدفعي؛ هو معطل افتراضيًا. هذا المسار المدعوم للتوليد على مجلد، ولا يوجد فعل مستقل عام باسم Research Folder.

## الإعدادات

| الإعداد | الافتراضي | الأثر |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | خدمة البحث |
| `tavilyApiKey` | `''` | مفتاح مطلوب قبل استخدام Tavily |
| `tavilyMaxResults` | `5` | عدد نتائج Tavily المطلوبة |
| `tavilySearchDepth` | `basic` | عمق بحث Tavily |
| `ddgMaxResults` | `5` | عدد نتائج DuckDuckGo المطلوبة |
| `ddgFetchTimeout` | `15` | مهلة جلب الصفحة بالثواني |
| `maxResearchContentTokens` | `3000` | ميزانية تقريبية لسياق الويب |
| `researchProvider` | `DeepSeek` | مزوّد التلخيص عند تفعيل التوجيه الخاص |
| `researchModel` | `''` | استخدام نموذج المزوّد إذا كان الحقل فارغًا |
| `researchSummarizeLanguage` | `en` | لغة الإخراج عند تخصيص اللغات |
| `enableResearchInGenerateContent` | `false` | تفعيل البحث في توليد العنوان |
| `enableLocalKnowledgeRetrieval` | `false` | تفعيل الاسترجاع المحلي المحدد بالنطاق |
| `enableLocalKnowledgeForResearchSummarize` | `false` | استخدام الاسترجاع لهذه المهمة |

### السياق واختيار النموذج

تقدير السياق ليس تقطيع token المطابق لكل مزوّد، وقد يحذف الاقتطاع أدلة. اختر نموذجًا وميزانية تناسب المصدر وضيّق السؤال. الفهرس المحلي لفظي؛ لا يعني بحثًا دلاليًا قائمًا على embeddings أو استرجاعًا كاملًا.

## مثال

أنشئ ملاحظة بعنوان `Relative positional encoding` وشغّل البحث، ثم طابق الشرح مع الأوراق الأصلية أو الوثائق الرسمية المرتبطة. احتفظ بالسؤال وURLs الفعلية والتصحيحات كي يمكن تدقيق الاستنتاج. مثال الدليل ليس نتيجة بحث أُجريت لخزنتك.

## الإلغاء والخصوصية

يوقف الإلغاء العمل اللاحق حيث يدعمه التنفيذ وتبقى الإضافات المكتملة. قد يكتمل طلب جارٍ أو جلب صفحة. تتلقى خدمة البحث الاستعلام، والمواقع طلبات الجلب، وLLM السياق المجمع مع المقتطفات المحلية عند تفعيلها. راجع التشخيص قبل مشاركته.

## إرشادات

- فرّق بين مصدر ويب وملاحظة محلية واستنتاج النموذج.
- تحقق من الاقتباسات والتواريخ والادعاءات المهمة في الأصل.
- استخدم سؤالًا صغيرًا لفصل فشل البحث عن LLM.
- راجع الخلاصات السابقة قبل التكرار لتجنب الإلحاق المكرر.
