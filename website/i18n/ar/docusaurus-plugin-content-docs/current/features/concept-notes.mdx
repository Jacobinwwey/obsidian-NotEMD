# ملاحظات المفاهيم

<TLDR>
يقرأ الاستخراج المستقل ملاحظة ويكتب ملفات مفاهيم في مجلد تختاره. إعداد المجلد فارغ في البداية؛ الملاحظات الجديدة عناوين فقط وروابط المصدر معطلة افتراضيًا. تستخدم إضافة الروابط قالبًا مختلفًا.
</TLDR>

## نظرة عامة

حدد **مسار مجلد ملاحظات المفاهيم** قبل الاستخراج. يسهل المجلد المخصص فحص الناتج والتكرار ونطاق التوليد اللاحق. الاستخراج ينشئ الملفات ولا يملأ كل مفهوم تلقائيًا بشرح قائم على البحث.

## آلية العمل

### مسار الاستخراج

ترسل المهمة المحتوى إلى النموذج، وتحلل عناصر `CONCEPT:` وتزيل تكرار الأسماء داخل العملية ثم تنشئ أو تحدث الملفات. تُجزّأ الملاحظات الطويلة. افحص المقاطع الفاشلة والناتج الناقص؛ ليست الاستجابة جردًا شاملًا.

### مطالبة الاستخراج

تطلب المطالبة المدمجة مفاهيم محددة مرتبطة بالموضوع. تعليمات المجال وتقليل المرادفات لا تضمن معجمًا معياريًا. يجب أن يحفظ التخصيص عقد `CONCEPT: Term`؛ راجع [المطالبات](../advanced/custom-prompts).

### التجزئة

القيمة الافتراضية `chunkWordCount: 3000` تقريبية بالكلمات وليست ميزانية token للمزوّد. سياق المقاطع محدود؛ راجع الأسماء الغامضة والمفاهيم المرتبطة بعد المعالجة.

## إنشاء الملفات

### قواعد الاسم

تزال محارف المسار غير المدعومة وتُنظّم المسافات وتُختصر الأسماء الطويلة، وتتجاوز النتائج الفارغة. قد تصير عبارتان مختلفتان اسمًا واحدًا؛ افحص الأسماء قبل توليد مجموعة كبيرة.

### القوالب

القالب المستقل الافتراضي:

```markdown
# Concept Name
```

لإضافة رابط مصدر إلى ملف مستقل جديد، فعّل **Add "Linked From" backlink** وعطّل **Create minimal concept notes**. الشكل الكامل:

```markdown
# Concept Name

## Linked From
- [[Source Note]]
```

تنشئ إضافة الروابط قالبًا كاملًا مع رابط مصدر حين يُفعّل إخراج المفاهيم. مفاتيح الاستخراج المستقل لا تغير ذلك السلوك.

### تحديث ملف موجود

عند تفعيل الروابط الخلفية، يُضاف المصدر الناقص إلى `## Linked From` مع إبقاء النص وعدم تكرار الرابط نفسه. يستخدم اسم المصدر الأساسي؛ راجع الغموض إن وُجدت مصادر متطابقة الأسماء.

### الإعدادات

| الإعداد | الافتراضي | الأثر |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | إتاحة ملفات المفاهيم بعد تحديد المجلد |
| `conceptNoteFolder` | `''` | لا مجلد مختار أولًا |
| `extractConceptsMinimalTemplate` | `true` | عناوين فقط للاستخراج المستقل |
| `extractConceptsAddBacklink` | `false` | تفعيل روابط المصدر في الاستخراج المستقل |
| `extractConceptsProvider` | `DeepSeek` | المزوّد عند تفعيل التوجيه الخاص |
| `extractConceptsModel` | `''` | استخدام نموذج المزوّد إذا كان فارغًا |
| `extractConceptsLanguage` | `en` | اللغة عند تفعيل لغات المهام |
| `replaceSynonymsDuringConceptExtraction` | `false` | تعليمات تقليل المرادفات |
| `generateConceptLogFile` | `false` | إنشاء سجل مفاهيم اختياري |

## مراجعة التكرار

الفحص قائم على قرائن أسماء الملفات: تجاهل حالة الحروف وصيغ الجمع وتوحيد الرموز واحتواء كلمة حيث يسمح النطاق. ليست براهين تكافؤ دلالي؛ الجمع غير المنتظم والمعاني التقنية المختلفة يحتاجان مراجعة.

اختر **فحص وإزالة التكرارات** وراجع القائمة واعتمد فقط ما تريد إزالته. تمر العناصر المعتمدة عبر سلة Obsidian. مجلد المفاهيم ليس ذاكرة مؤقتة قابلة للإتلاف؛ انسخه احتياطيًا قبل التنظيف.

### نطاق المقارنة

يمكن المقارنة مع الخزنة أو مجلد المفاهيم أو مجلدات مشمولة أو نطاق يستثني مسارات. تحقق منه قبل الموافقة. تغيير النطاق يغير المرشحين لا معنى التكرار.

## الاستخدام

### استخراج مستقل

افتح Markdown وحدد مجلد المفاهيم ونفّذ **استخراج المفاهيم (الملف الحالي)**. يبقى المصدر دون تعديل؛ افحص الأسماء والتغطية والروابط الاختيارية.

### الاستخراج ثم التوليد

شغّل **إنشاء جماعي من العناوين** في مجلد المفاهيم لإضافة شروح. قد يشمل ملفات سابقة مؤهلة لا آخر استخراج فقط. راجع المجلد أولًا ووجهة complete بعده.

### إنشاء رابط من التحديد

يمكن لفعل التحديد إحاطة مصطلح برابط ويكي وإنشاء ملاحظته عند ضبط الوجهة. استخدمه لاختيار المصطلح بنفسك بدل طلب اختيار مفاهيم النص كله.

## إرشادات

- ابدأ بمصدر صغير ومجلد مخصص.
- حدد اللغة قبل إنشاء مجموعة واسعة.
- راجع المرادفات والتكرارات كلًا على حدة.
- احفظ السجلات اللازمة قبل استبدالها بتشغيل لاحق.
