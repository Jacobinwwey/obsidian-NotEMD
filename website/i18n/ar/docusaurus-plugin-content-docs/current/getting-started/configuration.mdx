# الإعدادات

<TLDR>
افتح إعدادات Notemd واستخدم البحث للوصول إلى الحقل. حدد المزوّد ووجهات الإخراج قبل المعالجة. اختبر التغيير على ملاحظة واحدة قبل تعميمه؛ قد تحتفظ العملية الجارية بالإعدادات الملتقطة عند بدئها.
</TLDR>

## نظرة عامة

المزوّد النشط الافتراضي DeepSeek، وبيانات الاعتماد الأولية فارغة. اختيار إعداد جاهز لا ينشئ حسابًا أو يثبّت نموذجًا أو يمنح صلاحية. يشرح [دليل المزوّدين](../providers/overview) البروتوكولات والاكتشاف.

## اكتشاف الإعدادات والمفضلة

- يطابق البحث الأسماء والأوصاف والأسماء البديلة والفئات المرئية ثم ينتقل إلى الحقل.
- تعرض **★ Favorites** الإعدادات المحفوظة مع أوصافها وفئاتها وروابطها. تحفظ في الخزنة وتبقى بعد إعادة التشغيل، وتزال المعرّفات القديمة.
- اطوِ شريط الاكتشاف بالسهم لتوفير المساحة؛ إعادة فتحه تستعيد الاستعلام.
- قائمة المفضلة ومرشح البحث داخل المفضلة عنصران مختلفان.

دقة تصدير معاينة الرسوم افتراضيًا **300 PPI** وبنطاق **72–600**. تؤثر في PNG؛ وتحافظ SVG وPDF على الهندسة المتجهية حيث تدعمها الصيغة. **Also export complete Mermaid visuals** يحدد الملفات المصاحبة ولا يتحكم في ظهور Mermaid داخل Drawnix.

اختر عدة أنواع من الرسوم في تشغيل واحد، وعدة صيغ إخراج لكل نوع بصورة مستقلة. إلغاء تحديد النوع يحفظ صيغه؛ وإذا لم تحدد أي نوع يُحلّل المحتوى تلقائيًا.

حدد مجلدًا مشتركًا للملفات الوسيطة بمسار نسبي إلى Vault، أو اترك الحقل فارغًا لاستخدام `notemd_assert/` بجانب كل مصدر. تُحفظ فيه سجلات الاسترداد وذاكرة العرض والمرفقات الاختيارية. احتفظ بالملفات التي لا تزال مرتبطة بالمخرجات؛ يؤثر تغيير المجلد في التشغيلات الجديدة فقط.

## 1. إعداد المزوّد

اختر المزوّد وأدخل بيانات الاعتماد المطلوبة، واحتفظ بعنوان مناسب للبروتوكول واختر نموذجًا متاحًا. استخدم قائمة النماذج حيث تُدعم ثم اختبر الاتصال. الوصول إلى القائمة ونجاح التوليد فحصان منفصلان.

المزوّد المحلي يحتاج خادمًا يعمل ونموذجًا محمّلًا. تستقبل الخدمات السحابية والبوابات المحتوى المرسل. عند معالجة مواد خاصة، راجع مزوّد كل مهمة أيضًا.

## 2. نماذج خاصة بالمهام

فعّل `useMultiModelSettings` لاختيار مزوّد ونموذج مستقلين للروابط والتوليد من العنوان والبحث والترجمة واستخراج المفاهيم والنص الأصلي وتلخيص Mermaid. تجاوز النموذج الفارغ يستخدم نموذج المزوّد المحدد؛ وعند تعطيل التخصيص يستخدم المزوّد النشط.

قارن بملاحظة ممثلة والدقة والمدة والسعر الفعلي للحساب. لا يقدم هذا الدليل ترتيب جودة أو ضمان توافر للنماذج.

## 3. إعداد المخرجات

| المهمة | السلوك الافتراضي |
| ------ | ------------------------- |
| إضافة الروابط | ملف `_processed.md` مستقل بجوار المصدر؛ لا يُنقل الأصل |
| استخراج مفاهيم مستقل | مجلد مفاهيم محدد، وعناوين فقط دون روابط رجوع |
| الترجمة | ملف `_<language>.md` مستقل؛ يمكن استبدال وجهة موجودة |
| البحث | إلحاق خلاصة بالملاحظة النشطة |
| توليد دفعة من العناوين | كتابة المحتوى ونقل الملفات المؤهلة إلى `<folder>_complete` المجاور حيث تسمح الوجهة |
| المعاينة والتصدير | تُصدّر الملفات المختارة تلقائيًا بجانب ملاحظة المصدر أو مباشرة إلى مجلد الإخراج المحدد. تتضمن الأسماء النوع، مثل `topic_drawnix.pdf` و`topic_flowchart.svg`. عند تعارض الأسماء تُضاف `-2` ثم `-3` وهكذا دون الكتابة فوق الملفات. |
مجلد المفاهيم يبدأ فارغًا؛ `concepts` اسم مقترح لا مسار افتراضي. القوالب المستقلة لها الشكل المختصر والكامل فقط، ولا يوجد محرك متغيرات عام لقوالب الملفات. راجع [ملاحظات المفاهيم](../features/concept-notes).

لاحقة المعالجة ومجلدها، ولاحقة الترجمة ومسارها، إعدادات منفصلة. افحص الملفات الموجودة قبل التكرار. تحدد رسائل الاسترداد والتعارض ما يحتاج المراجعة؛ الإلغاء لا يعكس الكتابات المكتملة.

## 4. اللغات

توجد **21 لغة لواجهة الإضافة** و**34 مسار لغة للموقع**. يتبع `uiLocale: auto` خريطة اللغات المتاحة، ويعود إلى الإنجليزية إن لم تدعم الواجهة اللغة.

لغة المحتوى مستقلة وافتراضيًا إنجليزية. يمكن تخصيصها للروابط والتوليد والبحث والمفاهيم وMermaid. تستخدم الترجمة لغة الإخراج المختارة `language` لا لغة الواجهة. قدرة النموذج على اللغات منفصلة عن أعداد لغات الواجهة والموقع.

## 5. تكامل البحث

اختر **Tavily** وأدخل المفتاح أو اختر **DuckDuckGo** صراحة. لا يؤدي المفتاح الفارغ إلى التحويل الآلي. كلاهما يتصل بالشبكة، وقد يجلب DuckDuckGo صفحات النتائج.

التوليد من العنوان لا يبحث افتراضيًا؛ فعّل `enableResearchInGenerateContent` فقط عند الحاجة. الاسترجاع المحلي أيضًا معطل افتراضيًا وله نطاقات مجلدات ومهام مستقلة. الفهرس محلي لكن المقاطع المستخدمة كسياق تُرسل إلى LLM.

## 6. إعداد سير العمل

استخدم المنشئ أو تعريف DSL مسمى لكل سطر. التعريف الافتراضي:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

يفصل `::` الاسم عن الأفعال، و`>` بين المعرّفات. الافتراضي التوقف عند فشل خطوة مُبلّغ عنه. يشرح [سير العمل](../features/workflows) النطاق والخيارات وعواقب متابعة الأخطاء.

## 7. الإعدادات المتقدمة

| الإعداد | القيمة الافتراضية | الأثر |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | المزوّد دون توجيه خاص للمهمة |
| `useMultiModelSettings` | `false` | تفعيل نماذج ومزوّدين مستقلين |
| `useCustomConceptNoteFolder` | `true` | السماح بملفات المفاهيم بعد اختيار مجلد |
| `conceptNoteFolder` | `''` | لم يُحدد مجلد بعد |
| `extractConceptsMinimalTemplate` | `true` | عناوين فقط للاستخراج المستقل |
| `extractConceptsAddBacklink` | `false` | إضافة روابط الرجوع عند التفعيل |
| `moveOriginalFileOnProcess` | `false` | الاحتفاظ بالأصل أثناء إضافة الروابط |
| `chunkWordCount` | `3000` | حجم مقطع تقريبي وليس حد token لدى المزوّد |
| `batchConcurrency` | `1` | عدد التنفيذ المتزامن الافتراضي |
| `enableBatchParallelism` | `false` | تفعيل الجدولة المتوازية في المسارات التي تستخدم المفتاح |
| `enableStableApiCall` | `false` | وضع الطلب المستقر الصريح |
| `customWorkflowErrorStrategy` | `stop_on_error` | إيقاف سير العمل بعد خطأ مُبلّغ عنه |

تقسيم النص وميزانية token للإخراج مختلفان. المقاطع الأصغر لا تضمن الالتزام بحد السياق، وخفض التزامن لا يمنع كل أخطاء 429.

## ملفات الإعداد والنسخ الاحتياطي

تخص الإعدادات بيانات الإضافة في الخزنة. انسخها قبل تعديل إعداد يعمل. تصدير ملفات المزوّد له عقد تنقيح مستقل وليس نسخة خزنة كاملة. راجع العناوين والبيانات الوصفية حتى بعد إخفاء المفاتيح؛ لا تشارك الإعدادات الخام أو أجسام التشخيص التي تتضمن ملاحظات خاصة.

## تشخيص الإعدادات

اختبر المزوّد والنموذج الفعليين ثم ملاحظة صغيرة. عند غياب حقل، ابحث عن اسمه وافحص الفئة وشروط وضع المطوّر وتأكد من الخزنة. أرفق النسخة والتفاصيل المنقحة عند الإبلاغ.

## 1.9.10 — معاينات أكثر أمانًا وإعدادات خاصة بالخزنة

تزيل معاينات SVG المستوردة المحتوى النشط والموارد الخارجية مع الحفاظ على النص الصيني وأنماط اللوحات. يُعزل مزوّدو الجهاز حسب الخزنة؛ استورد القائمة القديمة صراحةً من الإعدادات مع إبقاء القائمة والتكوينات الحالية. تستخدم معاينات العروض خادم loopback يدير المستهلكين المشتركين. تظهر أخطاء حفظ المفضلة والنسخ، ويتبع الحذف تفضيلات الخزنة. توافق PNG مفعّل افتراضيًا: يُحفظ الأصل وتُضاف نسخة أقل PPI بعد التحقق عند الحاجة فقط. لا يوجد حد ثابت لعلاقات Drawnix، وتبقى إعدادات العروض مستقلة. ثبّت ملفات الإصدار المتطابقة وأعد التحميل واختبر ملاحظة قبل المعالجة الجماعية.

## 1.9.11

تتراكم السجلات عبر مراحل المهمة وإعادة فتح المعاينة خلال جلسة الإضافة. استخدم مسح السجل لإعادة ضبطها؛ لا تُحفظ السجلات عند إعادة تحميل الإضافة.

تُجمع التشخيصات حسب الوسم وتكون مطوية افتراضيًا. وسّع المجموعة لقراءة كل رسالة واقتراح؛ تبقى الأعداد حسب درجة الخطورة ظاهرة.

## 1.9.12 — معاينة تشخيصية أكثر بساطة

عند عدم وجود أخطاء، تُطوى لوحة التشخيص بالكامل افتراضيًا، ولا يظهر سوى العنوان والأعداد حسب درجة الخطورة. تفتح الأخطاء اللوحة تلقائيًا. وسّع اللوحة ومجموعات الوسوم لقراءة كل رسالة واقتراح. لا تُحذف أي سجلات تشخيصية. تُفتح مجموعات الأخطاء فقط تلقائيًا؛ وتبقى التحذيرات والمعلومات مطوية حتى إن اشتركت في الوسم نفسه.
