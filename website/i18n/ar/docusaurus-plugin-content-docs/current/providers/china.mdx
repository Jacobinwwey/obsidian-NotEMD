# مزوّدون إقليميون في الصين

<TLDR>
اختر إعدادًا يطابق الحساب والنشر. المسارات الإقليمية وأسماء النماذج والصلاحيات ليست قابلة للتبادل حتى مع بروتوكول OpenAI-compatible المشترك. اختبر مهمة صغيرة قبل اختيار المزوّد للعمل.
</TLDR>

## الإعداد

أنشئ حساب API واحصل على مفتاحه واختر الإعداد الموافق. تحقق من المنطقة واستحقاق النموذج، ثم اختبر الاتصال وملاحظة مؤقتة. لا تضمن القيم الجاهزة توافر النموذج الحالي.

## اكتشاف النماذج

استخدم الاكتشاف عندما يسمح به المزوّد. Huawei Cloud MaaS له اكتشاف واعٍ بالنشر، والبقية تستعمل المسارات المتوافقة حيث تُدعم. منع القائمة لا يعني بالضرورة منع التوليد بنموذج محدد صراحة.

يختلف اختبار الاتصال أيضًا؛ قد ينجح DeepSeek من القائمة، بينما تنفذ إعدادات إقليمية أخرى محادثة قصيرة. تبقى المهمة الفعلية ضرورية لفحص المطالبة والإخراج.

## استكشاف الأخطاء

- المفتاح مقبول والتوليد مرفوض: افحص صلاحية النموذج والنشر والمنطقة.
- رفض Ark: تحقق هل المطلوب endpoint ID أم model ID.
- انقطاع استدلال: راجع حد الإخراج وخيارات thinking الخاصة.
- خطأ شبكة: جرّب العنوان من جهاز Obsidian واقرأ خطأ النقل.

## متى تختاره

اختر وفق العنوان المتاح وسياسة معالجة البيانات والنتيجة المقاسة. المنطقة أو العلامة ليست ضمان جودة أو خصوصية أو تكلفة. يعرض [الدليل العام](./overview) بوابات وخوادم محلية قد تناسب النشر أكثر.
