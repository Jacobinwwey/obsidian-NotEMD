# مزوّد Google

<TLDR>
يستخدم إعداد Google بروتوكول Gemini Generative Language API الأصلي. أدخل مفتاحًا مخوّلًا ونموذجًا متاحًا. إن قدمت بوابة Gemini عبر محادثة متوافقة مع OpenAI، فاستخدم إعداد البوابة.
</TLDR>

## الإعداد

اختر **Google** وأدخل المفتاح واحتفظ بعنوان Generative Language، وحدد نموذجًا متاحًا في إصدار API هذا. اختبر الاتصال ثم الترجمة أو المعالجة على نسخة تجريبية. لا يهيئ الإعداد تلقائيًا نشر Google Cloud أو Vertex اعتباطيًا.

## العنوان والمصادقة

| الحقل | القيمة الجاهزة |
| ------- | -------------- |
| بروتوكول النقل | `google` |
| API key | مطلوب |
| العنوان الأساسي | `https://generativelanguage.googleapis.com/v1` |
| النموذج الافتراضي | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| اختبار الاتصال | `chat-only` |

يركب التنفيذ طلب `generateContent` للنموذج مع مصادقة API key. القيمة التاريخية ليست ضمان التوافر. راجع URLs قبل مشاركة التشخيص لأن تفاصيل الطلب قد تتضمن بيانات المصادقة.

## اكتشاف النماذج

استخدم اكتشاف Google الأصلي عند توفره، وتحقق من دعم النموذج للتوليد عبر إصدار API المحدد. القائمة الفارغة قد تعني خطأ صلاحيات أو عنوان أو توافر؛ اختبر الإعداد بدل تبديل البروتوكولات عشوائيًا.

## استكشاف الأخطاء

- `400`: راجع النموذج والمعاملات وحدود token والإخراج.
- `401` أو `403`: افحص قيود المفتاح وتفعيل API وصلاحية النموذج.
- `404`: تحقق من وجود النموذج في إصدار API المحدد.
- فشل مثال بوابة: استخدم إعداد OpenAI-compatible الموافق.

## متى تختاره

هذا الإعداد لواجهة Gemini الأصلية. قيّم الترجمة أو البحث أو الرسم على عينة ممثلة. لا نضمن سرعة نسبية أو تكلفة أو جودة ترجمة لنموذج معين.
