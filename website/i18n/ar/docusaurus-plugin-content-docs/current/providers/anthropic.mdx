# مزوّد Anthropic

<TLDR>
اختر Anthropic لواجهة Messages الأصلية. نموذج Claude المقدم عبر بوابة OpenAI-compatible يستخدم إعداد البوابة. تحقق من النموذج المتاح حاليًا؛ قد يلزم تغيير القيمة التاريخية الافتراضية.
</TLDR>

## الإعداد

اختر **Anthropic** وأدخل مفتاحه، واحتفظ بعنوانه الأصلي إلا إذا كان نشر خاص يقدم البروتوكول نفسه. أدخل معرّف Claude متاحًا الآن، واختبر الاتصال ثم المهمة المطلوبة على ملاحظة تجريبية.

## العنوان والمصادقة

| الحقل | القيمة الجاهزة |
| ------- | -------------- |
| بروتوكول النقل | `anthropic` |
| API key | مطلوب |
| العنوان الأساسي | `https://api.anthropic.com` |
| النموذج الافتراضي | `claude-3-5-sonnet-20240620` |
| Temperature | `0.5` |
| اختبار الاتصال | `chat-only` |

يستخدم التنفيذ `/v1/messages` وترويسات المفتاح وإصدار API الأصلية. لا تدخل مسار محادثة بأسلوب OpenAI هنا. قيمة النموذج في المستودع ليست إعلانًا بأن الخدمة ما زالت تقدمه.

## اكتشاف النماذج

اكتشاف النماذج يستخدم مسار Anthropic الأصلي عند السماح به. إذا قُيّدت القائمة، أدخل معرّفًا متاحًا واختبر الاتصال القائم على محادثة. افحص المهام الطويلة والمخرجات المنظمة مستقلًا.

## استكشاف الأخطاء

- `401` أو `403`: راجع المفتاح ومساحة العمل والمشروع والفوترة وصلاحيات النموذج.
- `404`: تحقق من العنوان وتوافر النموذج الحالي.
- فشل اسم نموذج من بوابة: استخدم إعداد البوابة ومعرّفها.
- فشل استجابة طويلة: افحص حدود الإخراج والخطأ قبل زيادة المحاولات.

## متى تختاره

اختره عندما يقدم العنوان بروتوكول Anthropic Messages. قارن على مصادرك بدل افتراض ترتيب جودة عام؛ يتيح توجيه المهام استخدامه فقط في المواضع التي تناسب متطلباتك.
