# Întrebări frecvente

<TLDR>Începeți cu o notă de test, un furnizor accesibil și destinații explicite. Răspunsurile descriu limitele implementate; ghidurile legate explică integral pregătirea și verificarea.</TLDR>

## Întrebări

### Cum instalez Notemd în Obsidian?

Deschideți Settings → Community plugins → Browse, căutați Notemd, instalați-l și activați-l. Instalarea manuală utilizează main.js, manifest.json și styles.css din aceeași versiune GitHub. Manifestul declară minimum Obsidian 0.15.0; acea versiune veche și dispozitivele mobile fizice nu sunt verificate de dovezile actuale ale publicării.

### Ce furnizori LLM sunt suportați?

Registrul conține 36 de profiluri din cinci familii: OpenAI-compatible, Anthropic, Google, Azure OpenAI și Ollama. API-urile găzduite, gateway-urile și serverele locale cer endpoint, autentificare și model proprii. Un profil sau model listat nu garantează disponibilitate actuală ori permisiunea de generare.

### Pot folosi LLM-uri locale?

Da. Configurați un server Ollama, LM Studio sau OVMS pornit ori un endpoint propriu compatibil. Descărcați sau încărcați modelul înainte și testați sarcina. Inferența locală nu face offline cercetarea web, instalarea dependențelor sau sarcinile rutate separat în cloud.

### Cum diferă Notemd de ChatGPT?

Notemd se concentrează pe operații explicite de fișiere Obsidian: linkuri, note de concepte, adăugarea cercetării, traduceri și artefacte. Alegeți-l când aceste fluxuri se potrivesc vault-ului dvs. Evaluați alte instrumente după funcțiile actuale de păstrare, export și integrare; aplicațiile de chat pot păstra istoric și produce fișiere.

### Cum se compară cu Copilot sau Smart Connections?

Comparați sarcinile exacte cu versiunea, configurația și documentația actuală a fiecărui proiect. Notemd oferă transformări de note și căutare locală lexicală limitată. Nu oferă o interfață generală chat-with-vault sau căutare semantică bazată pe embeddings. Site-ul nu prezintă un clasament actual de funcții pentru alte proiecte.

### Ce servicii de căutare funcționează cu cercetarea?

Alegeți explicit Tavily cu cheia API sau DuckDuckGo. Cheia Tavily goală nu comută automat serviciul. Ambele folosesc rețeaua. LLM-ul ales rezumă contextul web disponibil și cel local opțional și adaugă rezumatul notei Markdown active. Verificați URL-urile și afirmațiile importante.

### Sunt suportate chineza și alte limbi?

UI-ul extensiei are 21 de localizări, iar site-ul 34 de rute lingvistice. Limba generării este configurată separat, cu suprascrieri per sarcină unde există suport. Capacitatea și calitatea traducerii depind de model, nu de numărul limbilor UI sau ale site-ului.

### Pot utiliza Notemd pentru articole sau PDF-uri?

Convertiți articolul în Markdown lizibil cu un instrument extern potrivit și verificați erorile din ecuații, tabele și figuri. Folosiți Notemd pentru concepte, pasaje originale, cercetarea întrebărilor, traduceri sau diagrame. Fluxul standard de note nu promite OCR PDF nativ sau extragere fidelă din orice document binar.

### Ce tipuri de diagrame poate genera?

Catalogul executabil are 33 de intrări cu surse și previzualizări compatibile. Mermaid, JSON Canvas, Vega-Lite, HTML/SVG editabil, Draw.io, Drawnix și CircuitikZ limitat servesc nevoi diferite. Alegeți opțiunile suportate și verificați rezultatul în aplicația țintă; previzualizarea nu dovedește fidelitatea editării native sau compilării.

### Notemd este gratuit și open source?

Notemd este disponibil sub licență MIT. Conturile furnizorilor, inferența, căutarea și instrumentele externe opționale au propriile costuri și condiții. Depozitul este public și acceptă contribuții. Libertatea licenței nu înseamnă că orice serviciu configurat este gratuit.

### Poate funcționa complet offline?

Unele sarcini de note pot utiliza un model local după instalarea serverului, fișierelor modelului și dependențelor. Cercetarea web, inclusiv DuckDuckGo, cere rețea. Verificați furnizorii per sarcină și dependențele opționale de export înainte de deconectare. Nu există garanție offline pentru fiecare funcție.

### Datele mele sunt trimise în cloud?

Prompturile și conținutul merg la endpoint-ul LLM configurat. Motoarele primesc interogări, iar descărcarea rezultatelor contactează site-uri. Căutarea locală poate adăuga fragmente din vault unui prompt cloud. Chiar și un profil local poate avea adresă remote. Verificați rutarea și curățați jurnalele înainte de partajare; stocarea locală singură nu limitează datele la dispozitiv.

### Ce rulează de fapt One-Click Extract?

Secvența implicită adaugă linkuri notei active, generează conținut pentru note eligibile din folderul de concepte/selectat și repară Mermaid în folderul complete. Poate procesa note de concepte existente. Nu adaugă automat cercetare web sau generare de diagrame. Ghidul fluxurilor oferă sintaxa exactă name::action>action.

### Anularea sarcinii inversează modificările?

Nu. Anularea oprește lucrul ulterior suportat și păstrează ieșirile finalizate. O cerere sau scriere acceptată poate termina, iar furnizorul controlează facturarea. Așteptați încheierea, verificați căile și conflictele de recuperare și reluați numai lucrul dorit.

### Poate un Agent automatiza Notemd?

Patru comenzi de export limitate oferă profiluri curățate, capabilități, contracte de invocare și interfața publică CLI prin Obsidian și un vault disponibil. Pot scrie fișiere exportate. Operațiile de întreținere au contract separat; numărul operațiilor interne nu este API public de automatizare. Începeți cu ghidul Agent.

### De unde încep dezvoltatorii și contributorii?

Ghidul dezvoltatorilor descrie configurarea depozitului, buildul, testele complete, responsabilitatea modulelor și regulile de extindere. AGENTS.md este autoritatea de execuție versionată. Raportați probleme reproductibile cu versiuni exacte și dovezi curățate și verificați schimbările înainte de integrare.
