# Anthropic

<TLDR>Profilul deservește API-ul nativ Messages. Claude prin gateway OpenAI-compatible cere profilul gateway-ului. Modelul implicit istoric poate necesita înlocuire cu unul disponibil.</TLDR>

## Pregătire

Alegeți **Anthropic**, cheia și modelul accesibil. Păstrați endpoint-ul nativ dacă instalarea alternativă nu oferă același protocol. Verificați conexiunea și o notă.

## Endpoint și autentificare

| Câmp | Valoare implicită |
| ------- | -------------- |
| Transport | `anthropic` |
| Cheie API | Obligatorie |
| URL de bază | `https://api.anthropic.com` |
| Model | `claude-3-5-sonnet-20240620` |
| Temperatură | `0.5` |
| Test de conexiune | `chat-only` |

Implementarea utilizează `/v1/messages` cu antete proprii de cheie/versiune. Nu adăugați calea OpenAI chat. Valorile implicite descriu configurația depozitului, nu disponibilitatea de azi.

## Modele

Utilizați descoperirea nativă unde aveți drepturi. Dacă lista este protejată, introduceți un ID autorizat și testați generarea. Sarcinile lungi sau structurate necesită verificare separată.

## Depanare

- 401/403: cheie, proiect, facturare și acces la model.
- 404: adresă și disponibilitate.
- ID de gateway respins: profilul și ID-ul corect.
- Erori la cereri lungi: verificați limitele înainte de a crește reîncercările.

## Când se potrivește

Pentru Messages nativ. Comparați rezultate pe propriile surse, nu un clasament general al furnizorilor. Rutarea per sarcină permite folosirea selectivă.
