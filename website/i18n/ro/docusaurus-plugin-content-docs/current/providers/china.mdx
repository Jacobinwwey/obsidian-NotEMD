# Furnizori chinezi

<TLDR>Alegeți profilul contului și instalării dvs. Chiar cu protocol OpenAI-compatible comun, regiunile, căile, modelele și drepturile nu sunt interschimbabile. Verificați o sarcină mică reală.</TLDR>

## Pregătire

Pregătiți contul/cheia, selectați profilul și verificați regiunea și accesul modelului. Valorile implicite nu garantează disponibilitatea actuală. Testați conexiunea și nota.

## Modele

Folosiți listarea unde este permisă. Huawei Cloud MaaS necesită cunoașterea instalării; alte profiluri folosesc descoperirea OpenAI-compatible suportată. Lipsa dreptului de listare nu exclude întotdeauna generarea cu ID explicit. DeepSeek poate trece testul prin listă, în timp ce unele profiluri regionale generează scurt. Testul sarcinii reale rămâne necesar.

## Depanare

- Cheie acceptată, generare eșuată: drepturi de model, deployment și regiune.
- Ark respinge ID-ul: se cere endpoint sau model?
- Raționament trunchiat: buget și thinking specific modelului.
- Rețea: verificați adresa din Obsidian și citiți eroarea transportului.

## Când se potrivește

Când accesul, disponibilitatea și condițiile datelor sunt potrivite. Geografia nu dovedește calitate lingvistică sau cost redus. Comparați același eșantion cu setări înregistrate.
