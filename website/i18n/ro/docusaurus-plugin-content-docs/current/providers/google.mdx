# Google

<TLDR>Google folosește Gemini Generative Language nativ. Configurați o cheie autorizată și un model accesibil. Pentru Gemini printr-un gateway compatibil, alegeți profilul acelui gateway.</TLDR>

## Pregătire

Alegeți **Google**, cheia, endpoint-ul nativ și un model al versiunii API selectate. Testați conexiunea și nota. Profilul nu configurează automat orice instalare Google Cloud/Vertex.

## Endpoint și autentificare

| Câmp | Valoare implicită |
| ------- | -------------- |
| Transport | `google` |
| Cheie API | Obligatorie |
| URL de bază | `https://generativelanguage.googleapis.com/v1` |
| Model | `gemini-2.0-flash-exp` |
| Temperatură | `0.5` |
| Test de conexiune | `chat-only` |

Se construiește o cerere `generateContent` cu cheie. ID-urile istorice nu garantează accesul. Examinați URL-urile de diagnostic înainte de partajare; pot conține date de autentificare.

## Modele

Folosiți descoperirea furnizorului și testați generarea în API-ul ales. O listă goală poate indica drepturi, endpoint greșit sau model absent. Investigați înainte de schimbarea protocolului.

## Depanare

- 400: ID, parametri și limite de intrare/ieșire.
- 401/403: restricțiile cheii, API activ și permisiuni.
- 404: model disponibil în versiunea API aleasă?
- Exemple de gateway: alegeți profilul OpenAI-compatible corespunzător.

## Când se potrivește

Pentru Gemini nativ. Testați traducerea, cercetarea sau diagramele pe materialul propriu. Nu sunt promise viteză, cost sau calitate universală.
