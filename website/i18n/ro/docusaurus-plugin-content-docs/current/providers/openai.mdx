# OpenAI

<TLDR>Profilul folosește implementarea comună OpenAI Chat Completions. Selectați cheia și modelul pentru acest protocol. Modelul implicit nu garantează acces actual sau calitate universală.</TLDR>

## Pregătire

Pentru serviciul oficial folosiți **OpenAI**, cheia și `https://api.openai.com/v1`. Un model listat poate cere alt API. Gateway-urile au profiluri/antete proprii; Azure folosește **Azure OpenAI**, deployment și versiune API.

## Endpoint și autentificare

| Câmp | Valoare implicită |
| ------- | -------------- |
| Transport | `openai-compatible` |
| Cheie API | Obligatorie |
| URL de bază | `https://api.openai.com/v1` |
| Model | `gpt-4o` |
| Temperatură | `0.5` |
| Test de conexiune | `models-then-chat` |

Variantele URL cunoscute sunt normalizate înainte de construirea căilor. Porniți de la profil și verificați adresa finală în loc să adăugați segmente la întâmplare.

## Modele

**Fetch models** obține modelele. **Test connection** poate trece doar cu lista. Testați modelul exact pe o notă. Reasoning, thinking, eșantionarea și bugetele trebuie să corespundă profilului/modelului.

## Depanare

- 401/403: cheie, proiect, drepturi și cont.
- 404: endpoint, ID de model și API suportat.
- Lista funcționează, generarea nu: eroarea chat și parametrii.
- Răspuns lung întrerupt: intrare, buget și corpul răspunsului; testul scurt nu acoperă acest caz.

## Când se potrivește

Pentru endpoint-uri OpenAI directe cu Chat Completions. Evaluați propriile note; prețurile și disponibilitatea se schimbă independent de Notemd.
