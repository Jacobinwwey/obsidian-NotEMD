# Prompturi personalizate

<TLDR>Un prompt propriu nevid îl înlocuiește pe cel integrat când sunt active comutatoarele global și specific sarcinii. Păstrați contractul de ieșire: sistemul nu readaugă automat regulile de format omise.</TLDR>

## Prezentare

Testați mai întâi promptul implicit pe o notă reprezentativă. Un domeniu sau regula de sinonime poate fi suficientă. Modificați politica, structura ori stilul traducerii când este nevoie și comparați înainte de loturi.

## Cum funcționează

### Compunere

Notemd alege promptul integrat/propriu, adaugă regulile aplicabile de domeniu/limbă și înlocuiește variabilele sarcinii. Textul notei poate fi transmis separat. Variabilele nu sunt universale. O înlocuire poate omite `CONCEPT:` sau contextul cercetării; o cerere validă nu dovedește un răspuns parsabil ori fundamentat.

### Variabile

Păstrați majusculele/minusculele și acoladele simple:

| Sarcină | Variabile disponibile |
| ------ | ----------------------- |
| Generare din titluri | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Rezumat de cercetare | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Traducere | `{LANGUAGE}`, `{TEXT}` |
| Pasaje originale | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` urmează politica sarcinii. Linkurile și conceptele independente primesc textul ca conținut al sarcinii; nu inventați alte variabile. Numele necunoscute nu sunt completate. Sunt înlocuiri de prompt, nu șabloane de fișiere pentru concepte.

### Domeniu de interes

Activați învățarea focalizată și introduceți, de exemplu, `inginerie electrică`. `Relevant Fields` orientează atenția, nu impune un filtru strict și nu dovedește excluderea altui conținut.

## Setări

| Sarcină | Comutator | Câmp de prompt |
| ------ | --------------- | -------------- |
| Linkuri | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titluri | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Cercetare | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Rezumat Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Concepte | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Traducere | `useCustomPromptForTranslate` | `translatePrompt` |
| Text original | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Toate cer `enableGlobalCustomPrompts`. Textul gol folosește promptul integrat. Extragerea unificată de text original are format fix propriu acolo unde înlocuirea comună nu se aplică. Generarea de diagrame cere rezultat tipizat; promptul Mermaid nu este universal.

## Exemplu

Activați comutatorul global și cel pentru concepte și păstrați marcajul parserului:

```text
Extrage cele mai importante concepte de inginerie electrică din notă.
Preferă componente concrete și mecanisme fizice, nu substantive generale.
Scrie fiecare concept pe o linie separată, exact astfel:
CONCEPT: Numele conceptului
Nu adăuga explicații sau un bloc exterior de cod.
```

Pe o copie, comparați liniile, numele fișierelor și conceptele lipsă cu varianta implicită. Păstrați promptul anterior pentru revenire.

## Recomandări

- Verificați o sarcină înainte de un lot mai mare.
- Păstrați sursele și citatele exacte.
- Traduceți instrucțiunile, nu ID-urile și marcajele.
- Retestați după schimbarea modelului; promptul nu înlocuiește validarea.
