# Introducere în Notemd

<TLDR>Notemd este o extensie Obsidian sub licență MIT pentru Markdown conectat, note de concepte, rezumate de cercetare, traduceri și diagrame pe care le puteți verifica și păstra. Alegeți furnizorul, sarcina și domeniul și examinați răspunsul înainte să îl integrați în baza de cunoștințe.</TLDR>

## Ce este Notemd?

Leagă sarcinile din vault de 36 de profiluri cloud, gateway și servere locale. Fiecare sarcină scrie conform propriului contract. Acțiunile rulează separat sau în fluxuri din panou. Rezultatele rămân în vault, dar sarcinile cloud trimit conținut, iar cercetarea web folosește rețeaua. Stocarea locală și inferența locală sunt alegeri diferite.

## Capabilități principale

### Linkuri wiki și concepte

Cereți concepte și legături. Adăugarea implicită de linkuri produce o notă separată. Fișierele de concepte necesită un folder ales; extragerea independentă începe cu titluri fără backlinkuri. [Linkuri](./features/wiki-links), [concepte](./features/concept-notes).

### Cercetare și context local

Tavily/DuckDuckGo furnizează context pentru rezumatele adăugate notei active. Căutarea locală opțională și limitată poate adăuga fragmente. Indexul este lexical, nu căutare semantică cu embeddings. [Cercetare](./features/research).

### Traducere și pasaje originale

Traduceți fișiere/foldere sau găsiți pasaje originale pentru întrebări. Comparați citatele cu sursa. Selecția nu restrânge traducerea întregului fișier. [Traducere](./features/translation).

### Diagrame și export

Alegeți tipul și sursa compatibilă, verificați previzualizarea și salvați sursa sau exportul vizual suportat. Catalogul executabil are 33 de intrări. Formatul sursă diferă de formatul de export. [Diagrame](./features/diagrams).

### Fluxuri

**One-Click Extract** adaugă linkuri, generează din titluri pentru notele eligibile din folderul de concepte/selectat și repară Mermaid în complete. Poate include concepte vechi. Pașii păstrează condițiile și rezultatele proprii. [DSL exact](./features/workflows).

## Începeți

1. [Instalați](./getting-started/installation) în vault-ul potrivit.
2. Testați o notă temporară cu un model accesibil.
3. Verificați folderul de concepte și căile rezultatelor.
4. Examinați rezultatul înaintea unui lot mare.

Nu există durată fixă sau lungime minimă universală. Alegeți o sarcină mică, verificabilă.

## Limitele diagramelor

Specificațiile tipizate și randarea pentru fiecare țintă determină suportul. `DiagramSpec` nu promite orice sintaxă sau desen de referință exact. `circuitikz` acoperă structuri limitate. TikZJax este extern; previzualizarea nu dovedește compilarea. Săgețile statice Drawnix dintre ramuri nu garantează atașarea după rearanjare.

## Structură

Sarcina ajunge la furnizorul ales; răspunsul este parsat/validat și scris într-o notă sau un artefact. Căutarea adaugă context opțional; previzualizarea/exportul au limite de format. [Ghidul dezvoltatorului](./developers/overview) indică proprietarii codului și verificările, iar [ghidul Agent](./agents/overview) descrie exporturile publice limitate. Registrul intern nu este API general de automatizare.

## Compararea instrumentelor {#notemd-vs-other-obsidian-ai-plugins}

Alegeți după sarcină: transformări de fișiere, chat, linkuri deterministe, recuperare de context ori editare în aplicația țintă. Folosiți documentația actuală și același eșantion cu versiuni/setări înregistrate.

## Date și compatibilitate

Sarcinile cloud primesc intrări, întrebări și fragmente locale permise. Verificați rutele datelor private. Anularea oprește continuarea suportată și păstrează rezultate finalizate, fără garanția opririi generării sau facturării la distanță.

Manifestul declară Obsidian minimum `0.15.0` și permite încărcarea mobilă. Acea versiune și dispozitivele mobile fizice nu sunt verificate în prezent. Exporturi opționale pot cere instrumente desktop. Webul are 34 de rute lingvistice, UI 21 de limbi; competența modelului este separată.
