# Traducere

<TLDR>Notemd traduce fișierul activ sau fișierele eligibile ale unui folder prin LLM-ul selectat. Implicit scrie separat, cu sufix de limbă. Calitatea depinde de model; 21 de limbi UI și 34 de rute web nu sunt limite sau garanții de traducere.</TLDR>

## Prezentare

Alegeți limba și furnizorul, apoi testați o copie cu termeni, linkuri și cod. Se utilizează un LLM, nu o integrare dedicată Google Translate. Comenzile vizează fișiere/foldere. Pentru un pasaj, folosiți o notă temporară; selecția nu restrânge **Translate current file**.

## Cum funcționează

### Sarcina de traducere

1. Alegeți limba țintă, implicit engleza, independent de UI.
2. Deschideți sursa și rulați **Translate current file**.
3. Textul lung este fragmentat, trimis și reasamblat.
4. Deschideți calea raportată și verificați sensul, termenii, citatele, Markdownul și codul.

Traducerea în franceză a `Example.md` creează de regulă `Example_fr.md` lângă sursa păstrată. Rezultatul existent este suprascris. Adăugarea în original sau o secțiune fixă `Translation` nu sunt garanții implicite.

### Perechi de limbi

Modelul deduce limba sursă. O opțiune de meniu nu dovedește precizia perechii. Verificați limbile amestecate și terminologia; fragmentarea poate pierde context.

### Modelul sarcinii

Rutarea utilizează `translateProvider`/`translateModel`, altfel furnizorul activ. Local sunt necesare serverul și modelul; în cloud se trimit conținutul și promptul. Evaluați un eșantion propriu.

### Traducerea folderului

**Batch translate folder** include implicit numai copiii direcți. Profilurile avansate pot schimba acest lucru. Surse cu același nume într-o singură destinație pot intra în conflict. Verificați traducerile vechi și căile înainte de repetare.

## Setări

| Setare | Valoare implicită | Efect |
| --------- | --------- | -------- |
| `language` | `en` | Limba țintă |
| `translateProvider` | `DeepSeek` | Furnizor la rutare per sarcină |
| `translateModel` | `''` | Gol preia modelul furnizorului |
| `useCustomTranslationSuffix` | `false` | Codul limbii ca sufix implicit |
| `translationCustomSuffix` | `_translated` | Sufix când personalizarea este activată |
| `useCustomTranslationSavePath` | `false` | Salvare implicită lângă sursă |
| `translationSavePath` | `''` | Folder de ieșire relativ la vault |
| `batchConcurrency` | `1` | Concurența cerută pentru traducerea folderului |

Dacă folderul personalizat nu poate fi pregătit, poate fi utilizat folderul sursei. Citiți calea reală. Un sufix personalizat gol poate viza originalul; folosiți unul distinct pentru traducere separată.

## Exemplu

Copiați o notă scurtă în chineză într-un folder de test, selectați engleza și traduceți. Comparați `_en.md` cu sursa: termeni, numere, formule și linkuri. Extindeți abia apoi.

## Anulare și control

Anularea oprește continuarea suportată; traducerile finalizate rămân, iar oprirea facturării nu este garantată. Verificați raportul și fișierele. Păstrarea Markdownului este instrucțiune pentru model, nu garanție de echivalență semantică impusă de parser.

## Recomandări

- Salvați sursa și verificați coliziunile.
- Folosiți sufix/folder de test separat.
- Controlați manual codul, matematica, URL-urile și numele.
- Curățați diagnosticele înainte de partajare.
