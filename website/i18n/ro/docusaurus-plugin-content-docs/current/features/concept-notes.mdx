# Note de concepte

<TLDR>Extragerea independentă citește sursa și creează concepte Markdown într-un folder ales. Inițial folderul nu este configurat. Notele noi au doar titlu, fără backlink. Adăugarea linkurilor utilizează o formă diferită de rezultat.</TLDR>

## Prezentare

Alegeți mai întâi **Concept note folder path**. Un folder dedicat simplifică verificarea, analiza duplicatelor și generarea din titluri. Extragerea nu umple automat notele cu explicații documentate.

## Cum funcționează

### Extragere

LLM-ul ales primește textul. Sarcina citește liniile `CONCEPT:`, elimină nume repetate în aceeași operație și creează/actualizează fișiere. Notele lungi sunt fragmentate. Verificați fragmentele eșuate; răspunsul nu este un inventar complet al conceptelor.

### Prompt de extragere

Instrucțiunea implicită cere concepte concrete și relevante. Domeniul și regulile de sinonime nu impun un vocabular canonic. Păstrați `CONCEPT: Term` în promptul propriu. [Prompturi](../advanced/custom-prompts).

### Fragmente

`chunkWordCount` începe la circa 3000 de cuvinte, nu tokenuri ale furnizorului. Contextul dintre fragmente este limitat; verificați relațiile și numele ambigue.

## Crearea fișierelor

### Denumiri

Caracterele invalide în căi sunt eliminate, spațiile normalizate și numele lungi scurtate; rezultatele goale sunt omise. Termeni diferiți pot ajunge la aceeași cale. Verificați numele înaintea colecțiilor mari.

### Șabloane

Notă nouă minimă:

```markdown
# Numele conceptului
```

Pentru backlink într-o notă independentă nouă, activați **Add "Linked From" backlink** și opriți **Create minimal concept notes**:

```markdown
# Numele conceptului

## Linked From
- [[Nota sursă]]
```

Adăugarea linkurilor creează forma completă cu referința la sursă când ieșirea de concepte este activă. Comutatoarele extragerii independente nu schimbă acea cale.

### Note existente

Cu backlinkuri active, o sursă lipsă poate fi adăugată sub `## Linked From`. Conținutul rămâne și același link nu este duplicat. Numele simplu al sursei poate fi ambiguu între foldere.

### Setări

| Setare | Valoare implicită | Efect |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Rezultate de concepte după selectarea folderului |
| `conceptNoteFolder` | `''` | Folder neconfigurat |
| `extractConceptsMinimalTemplate` | `true` | Doar titlu pentru concepte independente |
| `extractConceptsAddBacklink` | `false` | Backlinkuri la extragere independentă |
| `extractConceptsProvider` | `DeepSeek` | Furnizor când rutarea per sarcină este activă |
| `extractConceptsModel` | `''` | Gol înseamnă modelul furnizorului |
| `extractConceptsLanguage` | `en` | Limbă cu suprascriere per sarcină |
| `replaceSynonymsDuringConceptExtraction` | `false` | Instrucțiune de reducere a sinonimelor |
| `generateConceptLogFile` | `false` | Fișier opțional de jurnal pentru concepte |

## Duplicate

Verificarea folosește euristici de nume: majuscule/minuscule, plural, simboluri și, unde este permis, un cuvânt inclus în alt nume. Nu dovedește identitate semantică. În **Check & remove duplicates**, analizați forme neregulate și distincții tehnice și confirmați numai ștergerile dorite. Obsidian gestionează coșul. Folderul de concepte nu este cache temporar; faceți backup.

### Domeniul comparației

Comparați cu vault-ul, același folder de concepte, foldere incluse sau un domeniu cu excluderi. Domeniul schimbă candidații, nu sensul unui duplicat.

## Utilizare

### Extragere independentă

Deschideți Markdown, verificați folderul și rulați **Extract concepts (current file)**. Sursa rămâne intactă. Examinați numele, acoperirea și backlinkurile.

### Extragere și conținut

**Batch generate from titles** completează concepte, dar poate include note eligibile existente. Verificați folderul înainte și destinația complete raportată după.

### Link din selecție

Acțiunea de selecție transformă termenul ales în link wiki și poate crea nota de concept dacă destinația este configurată.

## Recomandări

- Sursă mică și folder separat.
- Alegeți limba înaintea creării în masă.
- Evaluați separat sinonimele și duplicatele.
- Păstrați jurnalele necesare înainte de următoarea suprascriere.
