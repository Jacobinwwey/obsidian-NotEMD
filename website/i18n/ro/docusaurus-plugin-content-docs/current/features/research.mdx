# Cercetare și căutare web

<TLDR>Research & summarize caută după selecție sau titlu, cere LLM-ului un rezumat al contextului disponibil și îl adaugă notei Markdown active. Alegeți explicit Tavily sau DuckDuckGo și verificați sursele citate.</TLDR>

## Prezentare

Motorul de căutare și modelul de rezumare sunt alegeri separate. Tavily cere cheie; DuckDuckGo nu, dar necesită rețea și poate limita traficul. Un model local nu transformă cercetarea web într-o sarcină offline.

## Cum funcționează

### Căutare și rezumare

1. Deschideți destinația în editorul Markdown și selectați un subiect sau folosiți titlul.
2. Rulați **Research & summarize**.
3. Tavily furnizează fragmente; DuckDuckGo poate descărca pagini rezultate.
4. Contextul local permis poate fi adăugat din domeniul ales.
5. Modelul scrie sub `Research Summary`, cu subiect și tip de sursă.
6. Deschideți URL-urile și verificați afirmațiile. Contextul recuperat nu dovedește fiecare citat generat.

### Tavily sau DuckDuckGo

| Alegere | Pregătire | Limită operațională |
| -------- | ------- | ---------------------- |
| Tavily | Selectați Tavily și introduceți cheia | Cote de cont și fragmente returnate |
| DuckDuckGo | Selectați DuckDuckGo explicit | Fără cheie; restricții de căutare și disponibilitate a paginilor |

Cheia Tavily goală sau greșită nu schimbă serviciul. Cu puțin context web, citiți raportul. Fragmentele locale activate pot susține un rezumat; eticheta sursei îl diferențiază de conținutul bazat pe web.

### Cercetare în generarea din titluri

**Enable research in "Generate from title"** adaugă cercetare și loturilor, fiind oprită implicit. Aceasta este calea suportată pentru foldere; nu există o acțiune independentă generală Research Folder.

## Setări

| Setare | Valoare implicită | Efect |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Serviciu de căutare |
| `tavilyApiKey` | `''` | Cheie Tavily |
| `tavilyMaxResults` | `5` | Număr cerut de rezultate Tavily |
| `tavilySearchDepth` | `basic` | Adâncime Tavily |
| `ddgMaxResults` | `5` | Număr cerut de rezultate DuckDuckGo |
| `ddgFetchTimeout` | `15` | Timeout al paginilor în secunde |
| `maxResearchContentTokens` | `3000` | Buget aproximativ de context web |
| `researchProvider` | `DeepSeek` | Furnizor de rezumare la rutare per sarcină |
| `researchModel` | `''` | Gol preia modelul furnizorului |
| `researchSummarizeLanguage` | `en` | Limba rezultatului per sarcină |
| `enableResearchInGenerateContent` | `false` | Permite cercetarea la generarea din titluri |
| `enableLocalKnowledgeRetrieval` | `false` | Activează separat căutarea locală |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Context local pentru această sarcină |

### Context și model

Bugetele sunt estimări, nu tokenuri exacte ale furnizorului. Trunchierea poate elimina dovezi. Restrângeți întrebarea și ajustați modelul/bugetul. Indexul local caută lexical, fără embeddings ascunse sau garanție de recuperare completă.

## Exemplu

Creați `Codificare pozițională relativă`, cercetați și comparați cu publicațiile originale ori documentația oficială. Păstrați întrebarea, URL-urile reale și corecturile. Exemplul nu pretinde o căutare deja efectuată în vault-ul dvs.

## Anulare și confidențialitate

Adăugările finalizate rămân. Cererile de model/pagini deja acceptate pot termina. Motorul primește întrebarea, site-urile cererile, iar LLM-ul tot contextul, inclusiv fragmente locale permise. Verificați diagnosticele înainte de partajare.

## Recomandări

- Separați sursa web, nota locală și concluzia modelului.
- Verificați citatele, datele și afirmațiile în original.
- Testați căutarea și LLM-ul separat, cu o întrebare mică.
- Citiți rezumatele existente înainte de o nouă adăugare.
