# Fluxuri de lucru

<TLDR>Un flux execută pe rând acțiunile panoului. Fiecare poate cere un folder sau un editor activ. Nu este o conductă de text: acțiunile își păstrează intrările, rezultatele și efectele secundare. Începeți cu o notă și un folder de test.</TLDR>

## Prezentare

Fluxul implicit **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Adaugă linkuri notei active și poate crea concepte dacă folderul este configurat.
2. Generează după titlu pentru note eligibile din folderul de concepte/selectat, inclusiv existente.
3. Repară Mermaid în folderul complete al generării.

Lanțul implicit nu cercetează webul. Cercetarea poate fi activată separat la generarea din titluri. [Loturi](../advanced/batch-processing).

## Cum funcționează

### Execuție

Pașii rulează secvențial, cu stare și erori în panou. Anularea oprește pașii viitori și ajunge la cererile suportate. Fișierele terminate rămân; nu există tranzacție globală. Folderul de concepte are prioritate. Generarea în lot reține folderul sursă și complete; repararea Mermaid folosește complete. Alte acțiuni își păstrează cerințele de fișier, selecție și interacțiune.

### DSL

Un buton numit pe linie. `::` separă numele de acțiuni; `>` separă ID-urile. Liniile goale și cele care încep cu `#` sunt ignorate; ID-urile necunoscute sunt respinse.

```text
Concepte și diagramă::extract-concepts-current>summarize-as-mermaid
```

Folosiți editorul de flux sau DSL-ul. ID-urile rămân stabile, etichetele urmează UI. Variantele de folder au ID-uri proprii; nu le deduceți prin înlocuiri arbitrare.

| ID | Acțiune / condiție |
| ------------ | ----------------------- |
| `process-current-add-links` | Linkuri în nota activă |
| `process-folder-add-links` | Linkuri în folderul ales |
| `extract-concepts-current` | Concepte din nota activă |
| `extract-concepts-folder` | Concepte din folderul ales |
| `generate-from-title` | Conținut din titlul activ |
| `batch-generate-from-titles` | Conținut pentru notele eligibile ale folderului |
| `research-and-summarize` | Cercetare după selecție/titlu în editorul Markdown deschis |
| `summarize-as-mermaid` | Rezumarea intrării active suportate în Mermaid |
| `generate-diagram` | Selectează mai multe tipuri de diagramă într-o execuție și mai multe formate independente pentru fiecare tip. Debifarea păstrează formatele tipului; fără selecții, conținutul este analizat automat. |
| `preview-diagram` | Previzualizare de sursă sau diagramă suportată |
| `translate-current-file` | Traducerea fișierului activ suportat |
| `batch-translate-folder` | Traducerea folderului ales |
| `extract-original-text` | Extragerea pasajelor originale cerute |
| `batch-extract-original-text` | Pasaje din fișiere eligibile ale folderului |
| `split-note-by-chapters` | Împărțirea notei active în capitole |
| `batch-mermaid-fix` | Repararea blocurilor Mermaid din folder |
| `fix-formula-current` | Normalizarea delimitatorilor de formule în nota activă |
| `batch-fix-formula` | Normalizarea delimitatorilor de formule în folder |
| `check-duplicates-current` | Verificarea duplicatelor notei active |
| `check-remove-duplicate-concepts` | Examinarea și ștergerea interactivă a conceptelor duplicate |
| `test-llm-connection` | Testarea furnizorului configurat |
| `probe-slide-export-env` | Verificarea mediului local de export al prezentării |
| `export-slides` | Exportul fișierului activ în diapozitive |

### Lanț implicit sau propriu

One-Click Extract este predefinit. Definiți alte butoane prin nume și ordine și examinați descrierea din panou. Corectați erorile de parsare înainte de utilizare.

## Setări

| Setare | Valoare implicită | Efect |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Oprire la prima eroare raportată de pas |
| `useMultiModelSettings` | `false` | Furnizor activ până la activarea rutării per sarcină |
| `enableResearchInGenerateContent` | `false` | Fără cercetare în generarea din titluri până la activare |

`continue_on_error` permite continuarea după erori. Folosiți-l doar dacă pașii următori pot lucra cu intrările rămase. Continuarea nu transformă fluxul parțial în succes.

### Model per pas

Modelul aparține sarcinii. Un câmp gol preia modelul furnizorului acelei sarcini. Verificați toate rutele înainte de conținut privat.

## Exemplu

Alegeți un `trial-concepts` gol și o sursă de test. Verificați conceptele și folderul complete raportat. Dacă destinația este neclară, rulați pașii separat. Extindeți după control.

## Recomandări

- Păstrați lanțuri ușor de înțeles pentru diagnostic și proveniența fișierelor.
- Ștergerile păstrează confirmarea interactivă; evitați-le în fluxuri nesupravegheate.
- Citiți jurnalele și fișierele după anulare sau conflict.
- Testați exact modelul/folderul; conexiunea nu dovedește cote suficiente pentru un lot mare.
