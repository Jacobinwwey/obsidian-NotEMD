# Linkuri wiki

<TLDR>Process file (add links) cere LLM-ului selectat concepte și linkuri Obsidian. Implicit creează un `_processed.md` separat și păstrează sursa. Fișierele de concepte necesită un folder ales. Verificați rezultatul înainte de extindere.</TLDR>

## Prezentare

Selecția poate varia între rulări și poate viza concepte fără fișier existent. Linkul este o destinație de navigare, nu dovada aceluiași sens sau a unei explicații corecte.

## Cum funcționează

### Procesare

Nota este fragmentată, trimisă furnizorului/modelului și reasamblată din răspunsuri. Sarcina poate crea sau actualiza concepte în folderul ales. Verificați erorile parțiale și calea reală de ieșire.

### Exemplu

Sursă:

```text
Învățarea automată folosește rețele neuronale pentru recunoașterea tiparelor.
```

Rezultat posibil:

```markdown
[[Învățarea automată]] folosește [[rețele neuronale]] pentru recunoașterea tiparelor.
```

Este o ilustrare; termenii depind de sursă, model și prompt.

## Utilizare

### Nota activă

Rulați **Process file (add links)** pe o copie și deschideți `_processed.md` alăturat. Sufixul, folderul personalizat și mutarea originalului pot schimba destinația.

### Mai multe note

Alegeți **Process folder (add links)**, verificați folderul și limitele și începeți cu puține fișiere. Nu există un comutator comun de suprascriere/omitere pentru toate sarcinile. [Loturi](../advanced/batch-processing).

### Un termen selectat de dvs.

**Create wiki link and generate note from selection** este o acțiune separată pentru termenul selectat. Nu restrânge procesarea întregului fișier la selecție. Verificați nota de concept și conținutul generat.

## Alegerea metodei

Modelul propune concepte pe baza conținutului. Potrivirea deterministă după titlu este mai potrivită pentru legături repetabile cu note deja numite. Comparați alte instrumente prin documentația actuală și același eșantion datat.

## Opțiuni

### Limitarea sinonimelor

`replaceSynonymsDuringConceptExtraction` adaugă o instrucțiune de reducere a conceptelor suprapuse. Este Boolean, oprit implicit, nu un prag numeric de similaritate. Examinați abrevierile și sensurile apropiate.

### Integritatea linkurilor

Obsidian actualizează legăturile la redenumire conform setărilor și acțiunii efectuate. Ștergerea țintei poate lăsa un link wiki nerezolvat, diferit de o mențiune nelegată. Verificați numele identice din foldere diferite.

### Numai extragere

Folosiți **Extract concepts (current file)** pentru a păstra sursa neschimbată. Șabloanele și backlinkurile sale diferă de adăugarea linkurilor. [Note de concepte](./concept-notes).

## Fișiere de concepte

### Creare automată

Cu folderul activ și ales, pot apărea titluri și `Linked From`. Explicații documentate, secțiuni de concepte înrudite sau șabloane frontmatter generale nu sunt adăugate automat. Generați conținutul după titlu separat.

### Configurare

Găsiți folderul de concepte, folderul rezultatelor, sufixul și mutarea originalului. Folderul de concepte este inițial gol. Separați rezultatele de test de surse.

## Utilizare avansată

### Context și prompturi

`chunkWordCount` stabilește aproximativ mărimea fragmentelor. Domeniul și prompturile personale influențează selecția. Selectoare generale de propoziții/paragrafe, frecvențe minime și variabile de șabloane pentru concepte nu sunt opțiuni documentate ale acestei sarcini.

## Recomandări

- Comparați citatele, formulele și codul cu sursa.
- Decideți ce termeni merită o notă de concept.
- Testați schimbarea promptului pe o mostră fixă.
- Faceți backup înainte de mutare sau suprascriere.

## Performanță

Durata și costul depind de furnizor, model, intrare, ieșire și reîncercări. Nu există timp fix per notă sau preț per sută de fișiere. Măsurați propriul eșantion și consumul real.

## Depanare

### Nu apar linkuri

Verificați cererea, răspunsul, sursa și fișierul raportat. Un număr minim de cuvinte nu garantează linkuri utile.

### Prea multe linkuri

Restrângeți promptul sau domeniul. Instrucțiunile pentru sinonime ghidează modelul fără a impune un dicționar.

### Linkuri după redenumire

Verificați setările Obsidian și numele ambigue. Corectați destinația deliberat. Un nou apel LLM nu este o reparație deterministă a linkurilor.
