# Diagrame

<TLDR>
Selectează mai multe tipuri de diagramă într-o execuție și mai multe formate independente pentru fiecare tip. Debifarea păstrează formatele tipului; fără selecții, conținutul este analizat automat.
</TLDR>

## Trei alegeri distincte

| Alegere | Ce controlează | Exemple |
| --- | --- | --- |
| Tipul diagramei | Semnificația diagramei | Diagramă de flux, secvență, circuit, grafic de date |
| Formatul sursă | Fișierul editabil sau reutilizabil creat de Notemd | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Formatul de export | Imaginea sau documentul pentru partajare | SVG, PNG, PDF |

HTML-ul diagramei conține grafică cu zoom; HTML-ul rezumatului structurat conține text, structură și referințe. HTML/SVG editabil denumește un motor de randare, nu un editor web. Folosește sursa nativă pentru editare. Exportul prezentărilor, inclusiv PPTX și MP4, păstrează setări și dependențe separate.

## Alegerea sursei

| Format | Utilizare potrivită | Fișier sursă |
| --- | --- | --- |
| Mermaid | Diagrame direct în Markdown | Bloc de cod Mermaid |
| JSON Canvas | Fluxuri canvas native Obsidian | `.canvas` |
| Draw.io | Editare ulterioară în diagrams.net sau instrumente compatibile | `.drawio` |
| Drawnix | Editare de tablă sau cu aspect desenat manual | `.drawnix` |
| CircuitikZ | Circuite electrice și cu tranzistoare structurate | `.tex` |

Formatele acceptate apar primele; cele incompatibile rămân vizibile și dezactivate. Cererile inactive existente pot fi eliminate. Fiecare tip își păstrează formatele. Dacă niciunul nu este utilizabil, se încearcă sursa implicită a motorului de randare folosit și se raportează cererile indisponibile.

## Generare și export

1. Deschideți nota sursă suportată. Pentru un pasaj folosiți o notă separată; selecția textului nu restrânge acțiunea pe fișier.
2. Selectează mai multe tipuri de diagramă într-o execuție și mai multe formate independente pentru fiecare tip. Debifarea păstrează formatele tipului; fără selecții, conținutul este analizat automat.
3. Caseta include tipul. Apasă pe nume pentru a-l selecta și a-i modifica formatele. Trecerea cursorului sau focalizarea din tastatură schimbă previzualizarea fără salvarea setărilor. Escape închide meniul și restabilește focalizarea.
4. Rulați **Generate diagram** din panou sau paletă.
5. Fișierele selectate se exportă automat lângă nota sursă sau direct în dosarul configurat. Numele include tipul, de exemplu `topic_drawnix.pdf` și `topic_flowchart.svg`. Conflictele adaugă `-2`, `-3` etc., fără suprascriere.
6. Verificați spațiul comun derulabil vertical: Drawnix urmat de toate panourile Mermaid în ordinea sursei, cu înălțimea randată completă.
7. Folosiți **Export SVG**, **Export PNG** ori **Export PDF** per panou sau exportul de imagini superior pentru toate. La mai multe panouri, alegeți folderul sursei ori unul relativ la vault. Se scrie un fișier cu nume determinist per panou și se continuă după o eroare individuală. **Save source file** păstrează artefactul editabil.

Configurează un dosar intermediar comun relativ la Vault sau lasă câmpul gol pentru `notemd_assert/` lângă fiecare sursă. Aici se păstrează înregistrări de recuperare, randări în cache și atașamente opționale. Păstrează fișierele încă referite; schimbarea afectează numai execuțiile noi.

Tipurile se generează succesiv. O eroare nu le blochează pe celelalte; anularea oprește tipurile în așteptare și păstrează fișierele finalizate. Reîncearcă exportul din previzualizare sau istoric fără altă cerere către model. Eșecul generării necesită regenerarea acelui tip. Înregistrările v1/v2 rămân lizibile.

Meniul Export și antetul fiecărui panou oferă aceleași acțiuni SVG/PNG/PDF. O previzualizare mare nu trebuie redusă la o singură imagine opacă.

**History** deschide sertarul de istoric fără să ascundă diagrama. Căutați, filtrați, redeschideți previzualizări sau fișiere salvate. Istoricul este disponibil din paletă și panou și fără notă activă.

SVG și PDF provin din geometrie vectorială. PDF folosește aranjarea SVG și metrica textului, nu rasterizarea întregului rezultat. PPI afectează numai PNG: 72–600, implicit 300.

## Previzualizări lizibile pentru diagrame dense

Diagramele editabile HTML/SVG cu benzi și grile măsoară și împart rezumatul înainte de poziționarea titlului și antetului. Celulele sunt desenate înaintea conectorilor și etichetelor. Traseele ortogonale dintre benzi rezervă etichetele și celulele ocupate pentru a evita suprapunerea și deplasarea laterală inutilă.

Mermaid `quadrantChart` are normalizare specifică familiei. Reparațiile de ghilimele și forme rezervate flowchart sunt omise. O paranteză deschisă copiată de model este eliminată numai ca ultim caracter nepereche al etichetei unui punct; parantezele intenționate din titluri, axe și cadrane rămân.

[docs/diagram-examples/](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) conține intrări bilingve, SVG/PNG și manifest automatizat din rulări pe vault real pentru fiecare tip executabil. `passed` se referă la rularea și bundle-ul înregistrate, nu la o nouă testare a fiecărui tip pe orice versiune ulterioară.

Catalogul executabil are 33 de rânduri, UI 21 de localizări, iar site-ul 34 de rute lingvistice. Sunt suprafețe diferite. Cinci gramatici exacte de referință rămân în afara selectorului până la dovezi independente pentru contractele lor de aranjare.

## Drawnix cu Mermaid încorporat

Notemd sanitizează SVG-ul și păstrează sursa Mermaid în metadatele `.drawnix`. Previzualizarea nu necesită runtime Drawnix/Plait. Calea implicită este autonomă, fără director `.assets` separat. Activați **Also export complete Mermaid visuals** pentru surse Mermaid, SVG și manifest la predare sau editare externă. Vechile `.assets` rămân suportate; SVG lipsă poate fi refăcut din sursa din metadate.

Imaginile încorporate rezolvate primesc previzualizare SVG cu date incluse când este posibil. Încărcarea preferă datele, apoi fișierele vechi însoțitoare și apoi reconstruirea din text. Păstrați fișierele încă referite; un export nou autonom nu dovedește că un director comun vechi este inutil.

Suprafața unică derulabilă arată întâi Drawnix și apoi Mermaid în ordinea sursei. Redeschiderea istoricului reconstruiește lista, dimensiunile și acțiunile de export.

Drawnix afișează cel mult șase relații direcționate esențiale cu etichete, maximum trei pe nod. Cele omise rămân în metadate. Textul încadrat apare în PDF inclusiv din SVG vechi în cache. Săgețile dintre ramuri sunt statice și se pot desprinde după rearanjarea în Drawnix.

## Limitele exportului nativ

Exportul sursei și cel vizual sunt rezultate separate. Testați un artefact reprezentativ în aplicația țintă înainte de distribuție. Tabelele PowerPoint păstrează structura editabilă suportată, inclusiv separatoarele corectate sub celule îmbinate. Mermaid/SVG pot fi imagini în loc de forme native. Previzualizarea sau scorul global al unei capturi nu înlocuiește testarea aplicației.

## Circuite

Selectați **Circuit diagram** și **CircuitikZ source file**. Notemd generează întâi descrierea structurată, apoi sursa CircuitikZ, în loc să ceară modelului LaTeX fără constrângeri.

Suportul este intenționat restrâns: amplificatoare NMOS cu sursă comună și blocuri CMOS suportate. Verificați previzualizarea și sursa înainte de utilizare tehnică ori publicare. SVG-ul este însoțitor de control, nu dovada compilării `.tex` în LaTeX sau TikZJax local.

**Compilare nativă opțională.** Previzualizarea și exporturile sale SVG/PNG/PDF nu cer LaTeX. Pe desktop, **CircuitikZ native compile environment** oferă diagnostice sau PDF nativ LaTeX. Poate utiliza `tectonic`/`pdflatex` din sistem, un executabil propriu sau Tectonic gestionat cu versiune fixată după alegerea explicită **Install**. Panoul arată progresul/erorile și permite eliminarea runtime-ului.

## Depanare

### Tip de diagramă greșit

Selectați tipul explicit. Pentru circuit, **Circuit diagram** și **Generate diagram**, nu vechea **Summarise as Mermaid diagram**.

### Format sursă nepotrivit

Formatele acceptate apar primele; cele incompatibile rămân vizibile și dezactivate. Cererile inactive existente pot fi eliminate. Fiecare tip își păstrează formatele. Dacă niciunul nu este utilizabil, se încearcă sursa implicită a motorului de randare folosit și se raportează cererile indisponibile.

### Meniul Export lipsește

SVG/PNG/PDF cer previzualizare vizuală. Dacă există numai text sursă, salvați-l și deschideți-l în instrumentul extern potrivit.

### CircuitikZ nu se compilează extern

Deschideți **CircuitikZ native compile environment** și verificați mediul. Reparați runtime-ul gestionat sau confirmați că executabilul propriu/din sistem poate obține pachetul `circuitikz`. Pluginul nu include o distribuție TeX completă.
