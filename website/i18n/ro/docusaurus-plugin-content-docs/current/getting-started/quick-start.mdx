# Primii pași

<TLDR>Începeți cu o notă Markdown de test și un furnizor accesibil. Verificați fișierul rezultat înainte de a procesa un folder. Sarcinile cloud transmit conținut; și modelele locale au nevoie de un server pornit și un model pregătit.</TLDR>

## 1. Configurați modelul

1. [Instalați și activați](./installation), apoi deschideți **Settings → Notemd**.
2. Alegeți profilul, endpoint-ul, datele de autentificare și modelul disponibil. **Fetch models** nu înlocuiește un test de generare.
3. Rulați **Test connection** și rezolvați problemele de cont, model sau adresă.
4. La **Concept note folder path**, alegeți un folder separat, de exemplu `concepts`. Inițial câmpul este gol; numele este alegerea dvs.

Pentru Ollama, descărcați modelul și introduceți numele exact; adresa implicită este `http://localhost:11434/api`. Pentru LM Studio, porniți serverul și selectați `LMStudio`. Vedeți [modele locale](../providers/local). Cercetarea web necesită rețea chiar dacă rezumarea folosește un model local.

## 2. Prima sarcină

În `Notemd trial.md`, scrieți un text scurt pe care îl puteți trimite furnizorului:

```text
Învățarea automată folosește rețele neuronale pentru recunoașterea tiparelor.
```

Rulați **Process file (add links)** din panou sau paletă. Implicit sursa rămâne și apare alături `Notemd trial_processed.md`. Deschideți rezultatul. Exemplu:

```markdown
[[Învățarea automată]] folosește [[rețele neuronale]] pentru recunoașterea tiparelor.
```

Pot apărea și note în folderul de concepte. Verificați fișierele și linkurile; modelul nu garantează o listă completă sau corectă de concepte.

## 3. Alte sarcini

### Extragerea conceptelor

**Extract concepts (current file)** păstrează sursa și necesită un folder de concepte. Notele independente noi au doar titlu, fără backlink implicit. Activați-l explicit dacă îl doriți. [Note de concepte](../features/concept-notes).

### Cercetare și rezumare

Selectați un subiect în editorul Markdown sau folosiți titlul și rulați **Research & summarize**. Alegeți explicit Tavily cu cheie sau DuckDuckGo. Rezumatul se adaugă notei active. Deschideți sursele și verificați afirmațiile.

### Flux cu un clic

Fluxul implicit **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Adaugă linkuri, completează după titlu notele eligibile din folderul de concepte/selectat și repară Mermaid în folderul complete. Poate include note vechi. Începeți într-un folder de test; nu adaugă automat cercetare web sau generare generală de diagrame.

## Anulare și control

**Cancel** oprește lucrul ulterior unde este suportat. Rezultatele finalizate rămân; nu este rollback și nu garantează oprirea generării sau facturării la distanță. Așteptați încheierea, apoi verificați căile și conflictele de recuperare înainte de reluare.

## Probleme

- Cont/model: verificați profilul și conexiunea.
- Lipsesc concepte: selectați un folder activ, nevid.
- Linkuri inutile: examinați răspunsul și promptul; nicio lungime minimă nu garantează rezultatul.
- Limite: păstrați concurența `1` cât verificați cotele.
