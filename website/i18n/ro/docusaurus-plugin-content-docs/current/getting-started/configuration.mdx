# Configurare

<TLDR>Deschideți Settings → Notemd și căutați câmpul. Alegeți furnizorul și destinația înainte de pornire. Testați modificările pe o notă; o sarcină pornită poate păstra configurația inițială.</TLDR>

## Prezentare

Furnizorul inițial este DeepSeek cu autentificare necompletată. Selectarea profilului nu creează conturi, nu instalează modele și nu acordă drepturi. Vedeți [furnizori](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Căutare și favorite

**Search settings** caută nume, descrieri, aliasuri și categorii vizibile și deschide câmpul. **★ Favorites** afișează setările salvate cu descriere, categorie și destinație. Persistă per vault după restart; ID-urile învechite se curăță. Interogarea rămâne la restrângerea barei. Lista favoritelor este distinctă de filtrul care caută doar în favorite.

**Diagram preview export PPI** are implicit 300, interval 72–600, și afectează numai PNG. SVG/PDF păstrează geometria vectorială suportată. **Also export complete Mermaid visuals** controlează fișierele însoțitoare, nu afișarea Mermaid în previzualizarea Drawnix.

## 1. Furnizor

Introduceți endpoint-ul protocolului corect, cheia cerută și modelul disponibil. Verificați separat listarea și generarea. Serverul/modelul local trebuie pregătite; cloud-ul și gateway-ul primesc conținut. Înainte de date private, verificați și rutarea fiecărei sarcini.

## 2. Modele per sarcină

`useMultiModelSettings` permite profil/model separat pentru linkuri, titluri, cercetare, traducere, concepte, pasaje originale și Mermaid. Modelul gol îl preia pe cel al furnizorului; cu opțiunea oprită se folosește furnizorul activ. Comparați precizia, latența și costul real pe aceeași notă.

## 3. Rezultate

| Sarcină | Rezultat implicit |
| ------ | ------------------------- |
| Adăugare de linkuri | `_processed.md` separat lângă sursă; mutarea originalului este oprită |
| Extragere independentă de concepte | Folder de concepte selectat; doar titlu, fără backlink |
| Traducere | Lângă sursă ca `_<language>.md`; destinația existentă poate fi suprascrisă |
| Cercetare | Rezumat adăugat notei Markdown active |
| Generare în lot din titluri | Scrie sursele eligibile și le mută în `<folder>_complete` alăturat dacă destinația permite |
| Previzualizare/export de diagramă | Alegeți sursă sau export vizual suportat și verificați calea raportată |

Folderul de concepte este inițial gol; `concepts` este un exemplu. Notele independente au variantă minimă/completă, nu un motor general de șabloane. [Concepte](../features/concept-notes). Procesarea și traducerea au sufixe/foldere separate. Verificați coliziunile; anularea nu revine asupra scrierilor finalizate.

## 4. Limbi

UI are 21 de localizări, site-ul 34 de rute lingvistice. `uiLocale: auto` alege o potrivire suportată, altfel engleza. Limba generării este separată, implicit engleză; unele sarcini o pot suprascrie. Traducerea folosește `language`. Numerele nu dovedesc competența lingvistică a modelului.

## 5. Căutare

Alegeți Tavily cu cheie sau DuckDuckGo explicit. Cheia goală nu schimbă serviciul. Ambele folosesc rețeaua; DuckDuckGo poate descărca pagini rezultate. Cercetarea din generarea după titlu este oprită: `enableResearchInGenerateContent`. Căutarea locală este și ea oprită, cu propriile limite de foldere/sarcini. Fragmentele locale adăugate sunt trimise LLM-ului ales.

## 6. Fluxuri

Folosiți editorul de fluxuri sau câte un rând DSL numit pentru fiecare buton:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` separă numele de acțiuni, `>` separă ID-urile. Implicit fluxul se oprește la o eroare raportată. Vedeți [fluxuri](../features/workflows) pentru context și continuarea după erori.

## 7. Valori avansate

| Setare | Valoare implicită | Efect |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Furnizor fără rutare specifică sarcinii |
| `useMultiModelSettings` | `false` | Furnizor/model per sarcină |
| `useCustomConceptNoteFolder` | `true` | Permite rezultate de concepte după selectarea folderului |
| `conceptNoteFolder` | `''` | Niciun folder de concepte ales |
| `extractConceptsMinimalTemplate` | `true` | Doar titlu pentru concepte independente |
| `extractConceptsAddBacklink` | `false` | Backlink la extragerea independentă |
| `moveOriginalFileOnProcess` | `false` | Păstrarea sursei la adăugarea linkurilor |
| `chunkWordCount` | `3000` | Mărime aproximativă a fragmentului, nu limită de tokenuri |
| `batchConcurrency` | `1` | Concurență inițială a lotului |
| `enableBatchParallelism` | `false` | Planificare paralelă în căile care folosesc comutatorul |
| `enableStableApiCall` | `false` | Mod stabil de cereri activat explicit |
| `customWorkflowErrorStrategy` | `stop_on_error` | Oprirea fluxului la eroare raportată |

Mărimea fragmentului nu este bugetul de tokenuri de ieșire. Fragmente mai mici nu rezolvă orice limită de context, iar concurența scăzută nu previne toate erorile 429.

## Profiluri de setări

Setările sunt date ale extensiei în vault. Salvați-le înainte de modificare. Exportul furnizorilor are un contract propriu de eliminare a câmpurilor sensibile, nu este backup complet. Chiar și profilurile curățate pot păstra endpoint-uri private și metadate. Nu publicați setări brute sau diagnostice cu note private.

## Probleme de configurare

Testați exact profilul/modelul pe o notă mică. Pentru câmpuri lipsă, verificați căutarea, categoria, vizibilitatea în modul dezvoltator și vault-ul activ. Raportați versiunea și setările minime fără secrete.
