# Instalare

<TLDR>Instalați Notemd prin Community plugins sau copiați cele trei fișiere de execuție ale aceleiași versiuni în vault. Activați extensia, pregătiți furnizorul și testați o notă. Serverele de modele și instrumentele opționale de export se pregătesc separat.</TLDR>

## Metoda 1: Community plugins, recomandată

1. În vault-ul dorit, deschideți **Settings → Community plugins**.
2. Permiteți extensiile comunității dacă este necesar și alegeți **Browse**.
3. Căutați **Notemd**, verificați `Jacobinwwey/obsidian-NotEMD` și apăsați **Install**.
4. Alegeți **Enable** și deschideți panoul lateral din pictogramă sau paleta de comenzi.

[Deschideți Notemd în Obsidian](obsidian://show-plugin?id=notemd). Dacă browserul nu transmite linkul aplicației, folosiți meniul de mai sus. Citirea documentației nu necesită un gestionar al protocolului.

## Metoda 2: instalare manuală

### Condiții

Aveți nevoie de Obsidian și de un vault pentru care puteți face o copie de siguranță. Minimul `0.15.0` din manifest este o declarație de compatibilitate, nu dovada unui test recent pe acea versiune veche.

### Pași

1. Descărcați `main.js`, `manifest.json` și `styles.css` din aceeași [versiune GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` este documentație, nu fișier obligatoriu pentru execuție.
2. Puneți fișierele în `<vault>/.obsidian/plugins/notemd/`; adaptați calea dacă directorul de configurare este personalizat.
3. Reîncărcați Obsidian și activați extensia.
4. Verificați versiunea; nu combinați un manifest nou cu un bundle vechi.

## Alternativă: BRAT

Dacă folosiți deja [BRAT](https://github.com/TfTHacker/obsidian42-brat), adăugați depozitul prin procedura sa pentru extensii beta. Pentru reproducerea unei probleme, fixați versiunea. BRAT este un instrument extern opțional.

## Verificare

Configurați un model accesibil, rulați **Test connection**, apoi [primii pași](./quick-start). O listă de modele nu dovedește dreptul de a genera cu modelul selectat; verificați rezultatul real.

## Limite de sistem

| Domeniu | Limită |
| --------- | ---------- |
| Manifest | Obsidian minimum `0.15.0`; `isDesktopOnly` false |
| Dovezi de verificare | Consultați înregistrările datate; dispozitivele mobile fizice și 0.15.0 nu sunt verificate în prezent |
| Model în cloud | Rețea, cont/cheie autorizată și model disponibil |
| Model local | Server instalat separat și pornit, cu model descărcat/încărcat |
| Export pentru prezentări sau circuite | Instrumente desktop și dependențe de format; verificați mai întâi mediul |

Nu există o singură versiune de sistem de operare garantată pentru toate exporturile. Previzualizarea unui circuit nu dovedește compilarea TeX, iar testul desktop nu dovedește comportamentul mobil.

## Dezinstalare

Dezactivați sau dezinstalați din Community plugins. Notele și fișierele generate rămân fișiere obișnuite în vault. Verificați-le înainte de ștergere și salvați setările dacă este nevoie. Dezinstalarea nu anulează modificările finalizate.

## Actualizare

Folosiți **Check for updates**. Manual: opriți sarcinile, salvați vault-ul și setările, înlocuiți cele trei fișiere dintr-o singură versiune și reîncărcați. Citiți notele versiunii și testați un eșantion înaintea loturilor. Nu înlocuiți setările cu un fișier de distribuție. Revenirea necesită o versiune compatibilă aleasă deliberat și o copie de siguranță.
