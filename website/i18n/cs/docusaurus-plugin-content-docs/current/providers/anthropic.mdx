# Anthropic

<TLDR>Profil slouží nativnímu Messages API. Pro Claude za OpenAI-compatible bránou použijte její profil. Historický výchozí model může být nutné nahradit dostupným.</TLDR>

## Příprava

Vyberte **Anthropic**, klíč a dostupný model. Nativní endpoint zachovejte, pokud jiné nasazení neposkytuje stejný protokol. Ověřte spojení a poznámku.

## Endpoint a autentizace

| Pole | Výchozí hodnota |
| ------- | -------------- |
| Transport | `anthropic` |
| API klíč | Vyžadován |
| Základní URL | `https://api.anthropic.com` |
| Model | `claude-3-5-sonnet-20240620` |
| Teplota | `0.5` |
| Test spojení | `chat-only` |

Implementace používá `/v1/messages` s vlastními hlavičkami klíče/verze. Nepřidávejte cestu OpenAI chat. Výchozí hodnoty popisují konfiguraci repozitáře, nikoli dnešní dostupnost.

## Modely

Kde je povoleno, použijte nativní zjištění modelů. Při chráněném výpisu zadejte oprávněné ID a ověřte generování. Dlouhé či strukturované úlohy potřebují samostatný test.

## Potíže

- 401/403: klíč, projekt, účtování a přístup k modelu.
- 404: adresa a dostupnost.
- Odmítnuté ID brány: opravte profil a modelové ID.
- Chyby dlouhých požadavků: ověřte limity dříve, než zvýšíte počet opakování.

## Vhodné použití

Nativní Messages API. Srovnávejte vlastní zdroje, nikoli obecné pořadí poskytovatelů. Směrování podle úlohy umožňuje cílené použití.
