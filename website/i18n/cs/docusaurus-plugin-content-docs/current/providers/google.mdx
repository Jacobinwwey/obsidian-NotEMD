# Google

<TLDR>Google používá nativní Gemini Generative Language. Nastavte oprávněný klíč a dostupný model. Pro Gemini přes kompatibilní bránu vyberte odpovídající profil brány.</TLDR>

## Příprava

Vyberte **Google**, klíč, nativní endpoint a model dostupný ve zvolené verzi API. Ověřte spojení i poznámku. Profil automaticky nenastaví libovolné nasazení Google Cloud/Vertex.

## Endpoint a autentizace

| Pole | Výchozí hodnota |
| ------- | -------------- |
| Transport | `google` |
| API klíč | Vyžadován |
| Základní URL | `https://generativelanguage.googleapis.com/v1` |
| Model | `gemini-2.0-flash-exp` |
| Teplota | `0.5` |
| Test spojení | `chat-only` |

Sestavuje se požadavek `generateContent` s klíčem. Historická ID nezaručují přístup. Před sdílením prověřte URL v diagnostice; může obsahovat přihlašovací údaje.

## Modely

Použijte discovery poskytovatele a ověřte generování ve zvoleném API. Prázdný seznam může znamenat chybná oprávnění, endpoint nebo nedostupný model. Než změníte protokol, zjistěte příčinu.

## Potíže

- 400: ID, parametry a vstupní/výstupní limity.
- 401/403: omezení klíče, aktivace API a oprávnění.
- 404: dostupnost modelu v dané verzi API.
- Příklady pro bránu: vyberte odpovídající profil OpenAI-compatible.

## Vhodné použití

Nativní Gemini. Překlad, rešerši nebo diagramy ověřte na vlastních datech. Univerzální záruky rychlosti, ceny či kvality nejsou uváděny.
