# OpenAI

<TLDR>Profil používá společnou implementaci OpenAI Chat Completions. Zvolte klíč a model pro tento protokol. Výchozí model nezaručuje aktuální přístup ani univerzální kvalitu.</TLDR>

## Příprava

Pro oficiální službu vyberte **OpenAI**, klíč a `https://api.openai.com/v1`. Model uvedený v seznamu může vyžadovat jiné API. Brány mají vlastní profily/hlavičky; Azure používá **Azure OpenAI**, deployment a verzi API.

## Endpoint a autentizace

| Pole | Výchozí hodnota |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API klíč | Vyžadován |
| Základní URL | `https://api.openai.com/v1` |
| Model | `gpt-4o` |
| Teplota | `0.5` |
| Test spojení | `models-then-chat` |

Známé varianty URL se před sestavením cest normalizují. Začněte profilem a ověřte výslednou adresu místo náhodného přidávání segmentů.

## Modely

**Fetch models** získá dostupné modely. **Test connection** může uspět pouze výpisem. Vybraný model ověřte na poznámce. Reasoning, thinking, vzorkování i rozpočty musí odpovídat profilu/modelu.

## Potíže

- 401/403: klíč, projekt, oprávnění a účet.
- 404: endpoint, ID modelu a podporované API.
- Výpis funguje, generování ne: prozkoumejte chybu chat a parametry.
- Přerušená dlouhá odpověď: vstup, rozpočet a tělo odpovědi; krátký test tento případ nepokrývá.

## Vhodné použití

Přímé endpointy OpenAI s Chat Completions. Vyhodnoťte vlastní poznámky; ceny a dostupnost se mění nezávisle na Notemd.
