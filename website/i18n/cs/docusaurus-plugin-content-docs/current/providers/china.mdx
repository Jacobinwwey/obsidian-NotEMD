# Čínští poskytovatelé

<TLDR>Zvolte profil odpovídající účtu a nasazení. Ani společný protokol OpenAI-compatible nezajišťuje zaměnitelnost regionů, cest, modelů a oprávnění. Ověřte malou skutečnou úlohu.</TLDR>

## Příprava

Připravte účet/klíč, zvolte profil a ověřte region i dostupnost modelu. Výchozí hodnoty nezaručují dnešní přístup. Otestujte spojení a poznámku.

## Modely

Kde lze, použijte výpis modelů. Huawei Cloud MaaS vyžaduje znalost nasazení; jiné profily používají podporované OpenAI-compatible discovery. Chybějící oprávnění výpisu nemusí bránit generování s explicitním ID. DeepSeek může testem projít díky seznamu, zatímco několik regionálních profilů provádí krátké generování. Skutečná úloha zůstává nutná.

## Potíže

- Klíč přijat, generování selže: modelová práva, deployment a region.
- Ark odmítá ID: je vyžadován endpoint, nebo model?
- Uvažování je oříznuto: rozpočet a parametry thinking daného modelu.
- Síť: prověřte adresu ze zařízení Obsidianu a chybu transportu.

## Vhodné použití

Když odpovídají oprávnění, dostupnost a pravidla dat. Geografie neprokazuje jazykovou kvalitu ani nízkou cenu. Srovnávejte stejný vzorek se zaznamenaným nastavením.
