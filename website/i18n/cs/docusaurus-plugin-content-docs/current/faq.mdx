# Časté otázky

<TLDR>Začněte zkušební poznámkou, dostupným poskytovatelem a jasnými výstupními cestami. Odpovědi popisují implementované hranice; úplné nastavení a ověření najdete v odkazovaných návodech.</TLDR>

## Otázky

### Jak nainstaluji Notemd do Obsidianu?

Otevřete Settings → Community plugins → Browse, vyhledejte Notemd, nainstalujte jej a zapněte. Ruční instalace používá main.js, manifest.json a styles.css ze stejného GitHub Release. Manifest uvádí minimum Obsidian 0.15.0; tuto starou verzi ani fyzická mobilní zařízení současné doklady vydání neověřují.

### Které poskytovatele LLM podporuje?

Registr obsahuje 36 profilů pěti rodin protokolů: OpenAI-compatible, Anthropic, Google, Azure OpenAI a Ollama. Hostovaná API, brány a lokální servery potřebují vlastní endpoint, přihlašovací údaje a model. Profil ani uvedený model nezaručují současnou dostupnost nebo oprávnění generovat u poskytovatele.

### Lze používat lokální LLM?

Ano. Nastavte běžící Ollama, LM Studio, OVMS nebo kompatibilní vlastní endpoint. Nejprve stáhněte či načtěte model a otestujte zamýšlenou úlohu. Lokální inference nedělá webovou rešerši, instalaci závislostí ani samostatně směrované cloudové úlohy offline.

### Čím se Notemd liší od ChatGPT?

Notemd se soustředí na konkrétní souborové úlohy Obsidianu: odkazy, pojmy, připojování rešerší, překlad a vytváření artefaktů. Zvolte jej, pokud odpovídají vašim úlohám v trezoru. Ostatní nástroje hodnoťte podle jejich současného ukládání, exportu a integrací; i chatové nástroje mohou uchovávat historii a vytvářet soubory.

### Jak se srovnává s Copilot nebo Smart Connections?

Porovnejte přesné úlohy s aktuální verzí, nastavením a dokumentací každého projektu. Notemd transformuje poznámky a nabízí omezenou lexikální retrieval cestu. Neposkytuje obecné chat-with-vault ani sémantické hledání pomocí embeddings. Tento web netvrdí aktuální pořadí funkcí jiných projektů.

### Které vyhledávací služby používá rešerše?

Výslovně zvolte Tavily s API klíčem nebo DuckDuckGo. Prázdný klíč Tavily nepřepíná službu automaticky. Obě potřebují síť. Vybraný LLM shrne dostupný webový a volitelný lokální kontext a připojí shrnutí k aktivní poznámce Markdown. Ověřte URL zdrojů a důležitá tvrzení.

### Podporuje čínštinu a další jazyky?

UI pluginu má 21 lokalizací a web 34 jazykových cest. Jazyk generovaného obsahu se nastavuje zvlášť, s výjimkami podle úloh tam, kde jsou podporovány. Překladová schopnost a kvalita závisejí na modelu, nikoli na počtu jazyků UI či webu.

### Lze Notemd použít při čtení článků a PDF?

Převeďte dokument do čitelného Markdownu vhodným externím nástrojem a ověřte chyby rovnic, tabulek a obrázků. Pak propojujte pojmy, extrahujte původní pasáže, zkoumejte otázky, překládejte či vytvářejte diagramy. Standardní práce s poznámkami neslibuje nativní PDF OCR ani věrnou extrakci libovolných binárních dokumentů.

### Jaké diagramy může generovat?

Spustitelný katalog obsahuje 33 položek s kompatibilními zdroji a náhledy. Mermaid, JSON Canvas, Vega-Lite, editovatelný HTML/SVG, Draw.io, Drawnix a omezený CircuitikZ slouží různým účelům. Používejte podporované volby a ověřte výstup v cílovém nástroji; náhled neprokazuje věrnost nativní editace ani kompilace.

### Je Notemd zdarma a open source?

Notemd je dostupný pod licencí MIT. Účty poskytovatelů, inference, hledání a volitelné externí nástroje mají vlastní ceny a podmínky. Repozitář je veřejný a příspěvky vítány. Svobodná licence neznamená bezplatnost všech nastavených služeb.

### Funguje zcela offline?

Některé poznámkové úlohy mohou použít lokální model po instalaci serveru, modelových souborů a potřebných závislostí. Webová rešerše včetně DuckDuckGo vyžaduje síť. Před odpojením ověřte profily jednotlivých úloh a volitelné závislosti exportu. Pro všechny funkce neplatí jednotná offline záruka.

### Odcházejí má data do cloudu?

Prompty a obsah jdou nastavenému endpointu LLM. Vyhledávače dostávají dotazy a načítání výsledků kontaktuje weby. Lokální retrieval může přidat úryvky trezoru do cloudového promptu. I místní profil lze nastavit na vzdálenou adresu. Před sdílením prověřte směrování a očistěte záznamy; místní ukládání samo nezaručuje data výhradně na zařízení.

### Co skutečně spouští One-Click Extract?

Výchozí sekvence přidá odkazy k aktivní poznámce, generuje obsah způsobilých poznámek ve složce pojmů nebo zvolené složce a opraví Mermaid ve složce complete. Může zpracovat existující pojmy. Automaticky nepřidává webovou rešerši ani generování diagramu. Přesnou syntaxi name::action>action uvádí průvodce postupy.

### Vrátí zrušení úlohy její změny?

Ne. Zrušení zastavuje podporovanou další práci a zachovává dokončené výstupy. Přijatý požadavek či zápis může doběhnout a účtování řídí vzdálený poskytovatel. Vyčkejte na ustálení úlohy, prověřte hlášené cesty a konflikty obnovy a opakujte jen zamýšlenou práci.

### Může Agent automatizovat Notemd?

Čtyři omezené exportní příkazy vystavují profily s odstraněnými citlivými poli, schopnosti, kontrakty volání a veřejné CLI přes dostupný Obsidian a trezor. Mohou zapisovat exportní soubory. Operace správců repozitáře tvoří samostatný kontrakt; počet interních operací není veřejné automatizační API. Začněte průvodcem pro Agent.

### Kde mají začít vývojáři a přispěvatelé?

Vývojářský průvodce popisuje nastavení repozitáře, build, úplné testy, odpovědnost modulů a pravidla rozšiřování. AGENTS.md je verzovanou autoritou pro provádění práce. Hlášení mají být reprodukovatelná, s přesnými verzemi a očištěnými doklady. Změny ověřte před návrhem integrace.
