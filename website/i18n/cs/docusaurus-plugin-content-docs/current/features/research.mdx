# Rešerše a webové hledání

<TLDR>Research & summarize hledá podle výběru nebo názvu, požádá LLM o shrnutí dostupného kontextu a připojí je k aktivnímu Markdownu. Výslovně vyberte Tavily či DuckDuckGo a ověřte odkazované zdroje.</TLDR>

## Přehled

Vyhledávač a model shrnutí jsou samostatné volby. Tavily vyžaduje klíč; DuckDuckGo nikoli, ale potřebuje síť a může omezovat provoz. Lokální model z webové rešerše nedělá offline úlohu.

## Jak to funguje

### Hledání a shrnutí

1. Otevřete cílovou poznámku v editoru Markdown a vyberte téma, případně použijte název.
2. Spusťte **Research & summarize**.
3. Tavily vrátí úryvky; DuckDuckGo může načíst stránky výsledků.
4. Lze přidat povolený lokální kontext ze zvoleného rozsahu.
5. Model zapíše sekci `Research Summary` s tématem a označením zdroje.
6. Otevřete adresy a ověřte tvrzení. Získaný kontext nedokládá automaticky každou generovanou citaci.

### Tavily nebo DuckDuckGo

| Volba | Příprava | Provozní hranice |
| -------- | ------- | ---------------------- |
| Tavily | Vyberte Tavily a zadejte klíč | Limity účtu a vrácené úryvky |
| DuckDuckGo | Výslovně vyberte DuckDuckGo | Bez klíče; omezení hledání a dostupnost stránek |

Prázdný či chybný klíč Tavily nepřepíná službu. Při malém množství webového kontextu čtěte zprávu. Zapnuté místní úryvky mohou stále podpořit shrnutí; označení zdroje je odliší od obsahu založeného na webu.

### Rešerše při generování podle názvu

**Enable research in "Generate from title"** přidává rešerši také do dávky a výchozím stavem je vypnutá. To je podporovaná cesta pro složky; samostatná obecná akce Research Folder neexistuje.

## Nastavení

| Nastavení | Výchozí hodnota | Účinek |
| --------- | --------- | -------- |
| `searchProvider` | `tavily` | Vyhledávací služba |
| `tavilyApiKey` | `''` | Klíč Tavily |
| `tavilyMaxResults` | `5` | Požadovaný počet výsledků Tavily |
| `tavilySearchDepth` | `basic` | Hloubka hledání Tavily |
| `ddgMaxResults` | `5` | Požadovaný počet výsledků DuckDuckGo |
| `ddgFetchTimeout` | `15` | Časový limit stránek v sekundách |
| `maxResearchContentTokens` | `3000` | Přibližný rozpočet webového kontextu |
| `researchProvider` | `DeepSeek` | Poskytovatel shrnutí při směrování úloh |
| `researchModel` | `''` | Prázdná hodnota přebírá model poskytovatele |
| `researchSummarizeLanguage` | `en` | Výstupní jazyk úlohy |
| `enableResearchInGenerateContent` | `false` | Povolení rešerše při generování podle názvu |
| `enableLocalKnowledgeRetrieval` | `false` | Samostatné povolení lokálního hledání |
| `enableLocalKnowledgeForResearchSummarize` | `false` | Lokální kontext pro tuto úlohu |

### Kontext a model

Limity jsou odhady, nikoli přesné tokeny poskytovatele. Oříznutí může odebrat důkazy. Zúžte dotaz a upravte model/rozpočet. Lokální index vyhledává podle slov; nepoužívá skryté embeddings ani nezaručuje úplné nalezení.

## Příklad

Vytvořte poznámku `Relativní poziční kódování`, proveďte rešerši a porovnejte ji s původními publikacemi či oficiální dokumentací. Uchovejte dotaz, skutečné URL a opravy. Příklad netvrdí, že již proběhlo hledání ve vašem trezoru.

## Zrušení a soukromí

Dokončená připojení zůstávají. Přijatý požadavek modelu či stránky může doběhnout. Vyhledávač obdrží dotaz, weby požadavky a LLM celý kontext včetně povolených lokálních úryvků. Před sdílením ověřte diagnostiku.

## Doporučení

- Rozlišujte webový zdroj, místní poznámku a závěr modelu.
- Citace, data a hlavní tvrzení ověřte v originálu.
- Hledání a LLM testujte odděleně malým dotazem.
- Před dalším připojením přečtěte existující shrnutí.
