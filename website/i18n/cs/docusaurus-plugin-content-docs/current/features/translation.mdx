# Překlad

<TLDR>Notemd překládá aktivní soubor nebo způsobilé soubory složky pomocí vybraného LLM. Výchozí výstup je samostatný soubor s jazykovou příponou. Kvalita závisí na modelu; 21 jazyků UI a 34 jazykových cest webu nejsou limitem ani zárukou překladu.</TLDR>

## Přehled

Zvolte cílový jazyk a poskytovatele a vyzkoušejte kopii s terminologií, odkazy a kódem. Používá se LLM, nikoli zvláštní integrace Google Translate. Příkazy pracují se soubory/složkami. Pasáž vložte do dočasné poznámky; výběr neomezuje **Translate current file**.

## Jak to funguje

### Úloha překladu

1. Zvolte cílový jazyk, výchozí angličtinu, nezávisle na UI.
2. Otevřete zdroj a spusťte **Translate current file**.
3. Dlouhý text se rozdělí, odešle a spojí.
4. Otevřete hlášenou cestu a ověřte význam, termíny, citace, Markdown a kód.

Francouzský překlad `Example.md` standardně vytvoří `Example_fr.md` vedle zachovaného zdroje. Existující výstup přepíše. Připojení do originálu ani pevná sekce `Translation` nejsou výchozí zárukou.

### Jazykové páry

Zdrojový jazyk odhaduje model. Volba v nabídce nedokládá přesnost páru. Testujte smíšený jazyk a odborné termíny; dělení může ztrácet kontext.

### Model úlohy

Směrování používá `translateProvider`/`translateModel`, jinak aktivního poskytovatele. Lokálně potřebujete server a model; cloud obdrží obsah i prompt. Vyhodnoťte vzorek vlastního oboru.

### Překlad složky

**Batch translate folder** výchozím nastavením zahrnuje jen přímé potomky. Pokročilé profily to mohou změnit. Stejné názvy zdrojů v jednom výstupním adresáři mohou kolidovat. Před opakováním zkontrolujte starší překlady a cíle.

## Nastavení

| Nastavení | Výchozí hodnota | Účinek |
| --------- | --------- | -------- |
| `language` | `en` | Cílový jazyk |
| `translateProvider` | `DeepSeek` | Poskytovatel při zapnutém směrování úloh |
| `translateModel` | `''` | Prázdná hodnota přebírá model poskytovatele |
| `useCustomTranslationSuffix` | `false` | Jazykový kód jako výchozí přípona |
| `translationCustomSuffix` | `_translated` | Přípona při povolené vlastní volbě |
| `useCustomTranslationSavePath` | `false` | Výchozí ukládání vedle zdroje |
| `translationSavePath` | `''` | Výstupní složka relativní k trezoru |
| `batchConcurrency` | `1` | Požadovaná souběžnost překladu složky |

Pokud vlastní složku nelze připravit, může se použít složka zdroje. Čtěte skutečnou cestu. Prázdná vlastní přípona může cílit na originál; pro samostatný překlad použijte odlišnou příponu.

## Příklad

Zkopírujte krátkou čínskou poznámku do testovací složky, zvolte angličtinu a přeložte. Porovnejte `_en.md` se zdrojem, zejména termíny, čísla, vzorce a odkazy. Pak rozšiřte rozsah.

## Zrušení a kontrola

Zrušení zastavuje podporovanou další práci. Dokončené překlady zůstávají a zastavení účtování není zaručeno. Prověřte zprávu i soubory. Zachování Markdownu je pokyn modelu, nikoli parserová záruka stejného významu.

## Doporučení

- Zálohujte zdroj a prověřte kolize.
- Použijte testovací příponu či složku.
- Ručně ověřte kód, matematiku, URL a názvy.
- Diagnostiku před sdílením očistěte.
