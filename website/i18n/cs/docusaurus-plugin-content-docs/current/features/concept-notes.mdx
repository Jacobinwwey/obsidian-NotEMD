# Poznámky pojmů

<TLDR>Samostatná extrakce čte zdroj a vytváří poznámky Markdown ve zvolené složce. Výchozí složka není nastavena. Nové poznámky mají pouze název a žádný zpětný odkaz. Přidávání odkazů používá jinou podobu výstupu.</TLDR>

## Přehled

Nejprve zvolte **Concept note folder path**. Samostatná složka usnadňuje kontrolu výstupů, duplicit a generování podle názvů. Extrakce poznámky automaticky nenaplní rešeršními vysvětleními.

## Jak to funguje

### Extrakce

Vybraný LLM dostane text. Úloha čte řádky `CONCEPT:`, odstraňuje opakované názvy v rámci operace a vytváří či aktualizuje soubory. Dlouhé poznámky dělí na části. Prověřte selhané části; odpověď není úplný soupis pojmů.

### Prompt extrakce

Výchozí prompt žádá konkrétní relevantní pojmy. Obor a pravidla synonym nevynucují kanonický slovník. Ve vlastním promptu zachovejte `CONCEPT: Term`. [Prompty](../advanced/custom-prompts).

### Části textu

Výchozí `chunkWordCount` je přibližně 3000 slov, nikoli tokenů poskytovatele. Kontext mezi částmi je omezený; kontrolujte vztahy a nejednoznačné názvy.

## Vytváření souborů

### Názvy

Neplatné znaky cest se odstraňují, mezery normalizují a dlouhé názvy zkracují; prázdné výsledky se vynechají. Různé termíny tak mohou skončit na stejné cestě. Před velkou sadou prověřte názvy.

### Šablony

Minimální nová poznámka:

```markdown
# Název pojmu
```

Pro zpětný odkaz v nové samostatné poznámce povolte **Add "Linked From" backlink** a vypněte **Create minimal concept notes**:

```markdown
# Název pojmu

## Linked From
- [[Zdrojová poznámka]]
```

Přidávání odkazů vytváří plnější podobu se zdrojem, jsou-li výstupy pojmů povoleny. Přepínače samostatné extrakce tuto cestu nemění.

### Existující poznámky

Při povolených zpětných odkazech může pod `## Linked From` přibýt chybějící zdroj. Text zůstává zachován a tentýž odkaz se neduplikuje. Základní název zdroje může být mezi složkami nejednoznačný.

### Nastavení

| Nastavení | Výchozí hodnota | Účinek |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Výstupy pojmů po volbě složky |
| `conceptNoteFolder` | `''` | Složka není zvolena |
| `extractConceptsMinimalTemplate` | `true` | Jen název samostatných pojmů |
| `extractConceptsAddBacklink` | `false` | Zpětné odkazy samostatné extrakce |
| `extractConceptsProvider` | `DeepSeek` | Poskytovatel při směrování podle úloh |
| `extractConceptsModel` | `''` | Prázdná hodnota přebírá model poskytovatele |
| `extractConceptsLanguage` | `en` | Jazyk s volbami podle úlohy |
| `replaceSynonymsDuringConceptExtraction` | `false` | Pokyn k potlačení synonym |
| `generateConceptLogFile` | `false` | Volitelný soubor záznamu pojmů |

## Duplicity

Kontrola používá heuristiky názvů: velikost písmen, množná čísla, symboly a tam, kde je povoleno, obsažení slova v jiném názvu. Neprokazuje shodný význam. V **Check & remove duplicates** prověřte nepravidelné tvary a technické rozdíly; potvrďte jen zamýšlená smazání. Koš spravuje Obsidian. Složka pojmů není dočasná cache; zálohujte ji.

### Rozsah porovnání

Lze porovnávat s trezorem, stejnou složkou pojmů, zahrnutými složkami nebo rozsahem s výjimkami. Rozsah mění kandidáty, nikoli význam duplicity.

## Použití

### Samostatná extrakce

Otevřete Markdown, ověřte složku a zvolte **Extract concepts (current file)**. Zdroj se nemění. Zkontrolujte názvy, pokrytí a zpětné odkazy.

### Extrakce a obsah

**Batch generate from titles** doplní obsah, ale může zahrnout existující způsobilé poznámky. Předem ověřte složku a poté hlášené complete umístění.

### Odkaz z výběru

Akce výběru převede váš termín na wiki odkaz a při nastaveném cíli může vytvořit soubor pojmu.

## Doporučení

- Malý zdroj a oddělená složka.
- Jazyk zvolte před hromadným vytvářením.
- Synonyma a duplicity posuzujte samostatně.
- Potřebné záznamy uchovejte před dalším přepsáním.
