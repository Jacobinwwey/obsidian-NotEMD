# Rychlý start

<TLDR>Začněte zkušební poznámkou Markdown a poskytovatelem, ke kterému máte přístup. Před zpracováním složky zkontrolujte výstupní soubor. Cloudové úlohy odesílají obsah; i lokální model potřebuje běžící server a připravený model.</TLDR>

## 1. Nastavte model

1. [Nainstalujte a zapněte plugin](./installation), otevřete **Settings → Notemd**.
2. Zvolte profil, endpoint, potřebné přihlašovací údaje a dostupný model. **Fetch models** nenahrazuje test generování.
3. Spusťte **Test connection** a opravte případný problém účtu, modelu či adresy.
4. Najděte **Concept note folder path** a zvolte samostatnou složku, například `concepts`. Výchozí pole je prázdné; název si volíte sami.

Pro Ollama nejprve stáhněte model a použijte přesný název; výchozí adresa je `http://localhost:11434/api`. Pro LM Studio spusťte server a vyberte `LMStudio`. Viz [lokální modely](../providers/local). Webová rešerše vyžaduje síť i s lokálním modelem pro shrnutí.

## 2. První úloha

Do `Notemd trial.md` vložte krátký text, který smíte poskytovateli odeslat:

```text
Strojové učení používá neuronové sítě k rozpoznávání vzorů.
```

Spusťte **Process file (add links)** z panelu nebo palety. Ve výchozím nastavení zůstane zdroj a vedle vznikne `Notemd trial_processed.md`. Otevřete výstup. Příklad:

```markdown
[[Strojové učení]] používá [[neuronové sítě]] k rozpoznávání vzorů.
```

Ve složce pojmů mohou vzniknout další poznámky. Ověřte soubory a odkazy; model nezaručuje úplný ani správný seznam pojmů.

## 3. Další úlohy

### Extrakce pojmů

**Extract concepts (current file)** nemění zdroj a potřebuje složku pojmů. Nové samostatné poznámky mají zpočátku jen název, bez zpětného odkazu. Ten povolte výslovně. [Poznámky pojmů](../features/concept-notes).

### Rešerše a shrnutí

Vyberte téma v editoru Markdown nebo použijte název a spusťte **Research & summarize**. Výslovně zvolte Tavily s klíčem nebo DuckDuckGo. Shrnutí se připojí k aktivní poznámce. Otevřete zdroje a ověřte tvrzení.

### Jedno kliknutí

Výchozí **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

Přidá odkazy, doplní způsobilé poznámky podle názvů ve složce pojmů nebo vybrané složce a opraví Mermaid ve složce complete. Může zahrnout starší poznámky. Použijte zkušební složku. Webová rešerše ani obecné generování diagramů se automaticky nepřidávají.

## Zrušení a kontrola

**Cancel** zastavuje další práci tam, kde je to podporováno. Dokončené výstupy zůstávají; nejde o transakční vrácení změn ani záruku zastavení vzdáleného generování či účtování. Vyčkejte na ustálení úlohy a před opakováním zkontrolujte cesty a konflikty obnovy.

## Potíže

- Účet/model: prověřte profil a spojení.
- Chybějící pojmy: nastavte povolenou neprázdnou cílovou složku.
- Neužitečné odkazy: zkontrolujte odpověď a prompt; žádná minimální délka nezaručuje výsledek.
- Limity: při ověřování ponechte souběžnost `1`.
