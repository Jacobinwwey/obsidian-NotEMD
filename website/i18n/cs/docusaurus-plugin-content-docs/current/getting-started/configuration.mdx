# Nastavení

<TLDR>Otevřete Settings → Notemd a vyhledejte pole. Poskytovatele a umístění výstupu zvolte před spuštěním. Změny ověřte na jedné poznámce; běžící úloha si může ponechat nastavení, se kterým začala.</TLDR>

## Přehled

Výchozí poskytovatel je DeepSeek s prázdnými přihlašovacími údaji. Volba profilu nevytváří účet, neinstaluje model ani neuděluje oprávnění. Viz [poskytovatelé](../providers/overview).

## Hledání a oblíbené

**Search settings** hledá názvy, popisy, aliasy a viditelné kategorie a přejde na pole. **★ Favorites** ukazuje uložená nastavení s popisem, kategorií a cílem. Uchovávají se pro každý trezor i po restartu; zastaralá ID se odstraňují. Dotaz zůstává při sbalení lišty. Seznam oblíbených je odlišný od filtru hledání pouze v oblíbených.

**Diagram preview export PPI** má výchozí hodnotu 300 a rozsah 72–600, pouze pro PNG. SVG/PDF zachovávají podporovanou vektorovou geometrii. **Also export complete Mermaid visuals** řídí doprovodné soubory, nikoli zobrazení Mermaid v náhledu Drawnix.

Vyberte více typů diagramů pro jeden běh a pro každý typ více výstupních formátů. Zrušení výběru zachová jeho formáty; bez vybraného typu se obsah analyzuje automaticky.

Nastavte společnou mezisložku relativně k Vault, nebo nechte pole prázdné pro `notemd_assert/` vedle každého zdroje. Obsahuje záznamy obnovy, mezipaměť vykreslení a volitelné přílohy. Zachovejte stále odkazované soubory; změna platí jen pro nové běhy.

## 1. Poskytovatel

Zadejte endpoint správného protokolu, vyžadovaný klíč a dostupný model. Seznam modelů a generování ověřujte zvlášť. Lokální server/model musí být připraven; cloud i brána obdrží obsah. Před soukromými daty ověřte i směrování jednotlivých úloh.

## 2. Modely podle úloh

`useMultiModelSettings` umožňuje samostatné poskytovatele/modely pro odkazy, názvy, rešerši, překlad, pojmy, původní pasáže a Mermaid. Prázdný model přebírá model poskytovatele; po vypnutí platí aktivní profil. Přesnost, latenci a skutečné náklady porovnávejte na stejném vstupu.

## 3. Výstupy

| Úloha | Výchozí výstup |
| ------ | ------------------------- |
| Přidání odkazů | Samostatný `_processed.md` vedle zdroje; přesun originálu je vypnut |
| Samostatná extrakce pojmů | Zvolená složka pojmů; pouze název, zpětné odkazy vypnuty |
| Překlad | Vedle zdroje jako `_<language>.md`; existující cíl lze přepsat |
| Rešerše | Shrnutí se připojí k aktivnímu Markdownu |
| Dávkové generování podle názvů | Zapíše způsobilé zdroje a přesune do sousední `<folder>_complete`, dovolí-li to cíl |
| Náhled/export diagramu | Vybrané soubory se automaticky exportují vedle zdrojové poznámky nebo přímo do nastavené složky. Název obsahuje typ, například `topic_drawnix.pdf` a `topic_flowchart.svg`; při kolizi se přidá `-2`, `-3` atd. bez přepsání souborů. |
Složka pojmů je původně prázdná; `concepts` je příklad. Samostatné poznámky mají minimální/plnou variantu, nikoli obecný šablonovací systém. [Pojmy](../features/concept-notes). Zpracování a překlad mají vlastní přípony a složky. Zkontrolujte kolize; zrušení nevrací dokončené zápisy.

## 4. Jazyky

UI má 21 lokalizací, web 34 jazykových cest. `uiLocale: auto` použije podporovanou shodu, jinak angličtinu. Jazyk generování je samostatný, výchozí angličtina. Podporované úlohy mohou mít vlastní jazyk; překlad používá `language`. Počty neprokazují jazykové schopnosti modelu.

## 5. Hledání

Výslovně vyberte Tavily s klíčem nebo DuckDuckGo. Prázdný klíč nepřepíná službu. Obě používají síť; DuckDuckGo může načítat stránky výsledků. Rešerše při generování podle názvu je vypnutá: `enableResearchInGenerateContent`. Lokální vyhledávání je také vypnuté a má vlastní rozsah složek/úloh. Přidané místní úryvky se odesílají vybranému LLM.

## 6. Pracovní postupy

Použijte sestavovač nebo jeden pojmenovaný řádek DSL pro tlačítko:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` odděluje název od akcí, `>` odděluje ID. Výchozí politika zastaví na hlášené chybě. Viz [postupy](../features/workflows) pro kontext a pokračování po chybě.

## 7. Pokročilé hodnoty

| Nastavení | Výchozí hodnota | Účinek |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Poskytovatel bez zvláštního směrování úlohy |
| `useMultiModelSettings` | `false` | Poskytovatel/model pro jednotlivé úlohy |
| `useCustomConceptNoteFolder` | `true` | Povoluje výstupy pojmů po volbě složky |
| `conceptNoteFolder` | `''` | Složka pojmů není zvolena |
| `extractConceptsMinimalTemplate` | `true` | Pouze název samostatných pojmů |
| `extractConceptsAddBacklink` | `false` | Zpětné odkazy při samostatné extrakci |
| `moveOriginalFileOnProcess` | `false` | Zachování zdroje při přidávání odkazů |
| `chunkWordCount` | `3000` | Přibližná velikost částí, nikoli tokenový limit |
| `batchConcurrency` | `1` | Výchozí souběžnost dávky |
| `enableBatchParallelism` | `false` | Paralelní plánování tam, kde se přepínač používá |
| `enableStableApiCall` | `false` | Výslovný stabilní režim požadavků |
| `customWorkflowErrorStrategy` | `stop_on_error` | Zastavení postupu při hlášené chybě |

Velikost části textu není rozpočet výstupních tokenů. Menší části neřeší každý limit kontextu a nízká souběžnost nezabrání všem 429.

## Profily nastavení

Nastavení je součást dat pluginu v trezoru. Před změnami je zálohujte. Export poskytovatelů má vlastní kontrakt odstranění citlivých polí, nikoli úplnou zálohu. I profily s odstraněnými citlivými poli mohou obsahovat soukromé endpointy a metadata. Nesdílejte surové nastavení ani diagnostiku se soukromými poznámkami.

## Potíže s nastavením

Testujte přesný profil/model na malé poznámce. Chybějící pole hledejte podle kategorie, vyhledávání, režimu pro vývojáře a aktivního trezoru. Uveďte verzi a minimální nastavení bez tajných údajů.

## 1.9.10 — Bezpečné náhledy a místní nastavení Vault

Importované náhledy SVG odstraňují aktivní obsah a externí zdroje, zachovávají však čínské popisky a styly panelů. Místní poskytovatelé jsou odděleni podle Vault; starý seznam výslovně importujte v nastavení se zachováním seznamu a stávajících konfigurací. Prezentace používají loopback server se správou sdílených uživatelů. Chyby ukládání oblíbených a kopírování se zobrazí; mazání respektuje nastavení Vault. Kompatibilita PNG zůstává zapnutá: originál se zachová a ověřená kopie s nižším PPI přibude jen podle potřeby. Drawnix nemá pevný limit vztahů; prezentace mají samostatné nastavení. Nainstalujte soubory stejné verze, načtěte znovu a před dávkou otestujte jednu poznámku.

## 1.9.11

Protokoly se uchovávají mezi fázemi úkolu i při opětovném otevření náhledu během relace pluginu. Vymazat protokol je vynuluje; opětovné načtení pluginu historii nezachová.

Diagnostika je seskupena podle štítků a ve výchozím stavu sbalená. Rozbalte skupinu a přečtěte si všechny zprávy a rady; počty podle závažnosti zůstávají viditelné.
