# Instalace

<TLDR>Nainstalujte Notemd přes Community plugins nebo vložte tři soubory stejné verze do trezoru. Zapněte plugin, připravte poskytovatele a vyzkoušejte jednu poznámku. Servery modelů a volitelné nástroje pro export se instalují samostatně.</TLDR>

## Metoda 1: Community plugins, doporučeno

1. V cílovém trezoru otevřete **Settings → Community plugins**.
2. Povolte komunitní pluginy a zvolte **Browse**.
3. Vyhledejte **Notemd**, ověřte repozitář `Jacobinwwey/obsidian-NotEMD` a zvolte **Install**.
4. Zvolte **Enable** a otevřete panel ikonou nebo z palety příkazů.

[Otevřít Notemd v Obsidianu](obsidian://show-plugin?id=notemd). Pokud prohlížeč odkaz nepředá aplikaci, použijte uvedenou cestu v nastavení. Čtení dokumentace obsluhu protokolu nevyžaduje.

## Metoda 2: Ruční instalace

### Předpoklady

Potřebujete Obsidian a trezor, který můžete bezpečně zálohovat. Minimum `0.15.0` v manifestu je deklarace kompatibility, nikoli doklad o čerstvém testu této staré verze.

### Postup

1. Stáhněte `main.js`, `manifest.json` a `styles.css` ze stejného [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` je dokumentace, nikoli povinný soubor pro běh.
2. Vložte je do `<vault>/.obsidian/plugins/notemd/`; při změně konfiguračního adresáře upravte cestu.
3. Znovu načtěte Obsidian a plugin zapněte.
4. Ověřte verzi. Nekombinujte nový manifest se starým bundlem.

## Alternativa: BRAT

Pokud již používáte [BRAT](https://github.com/TfTHacker/obsidian42-brat), přidejte repozitář jeho postupem pro beta pluginy. Pro reprodukci chyby zvolte konkrétní verzi. BRAT je volitelný externí nástroj.

## Ověření

Nastavte dostupný model, spusťte **Test connection** a pokračujte [rychlým startem](./quick-start). Seznam modelů neprokazuje oprávnění generovat s vybraným modelem; zkontrolujte skutečný výstup.

## Systémové hranice

| Oblast | Hranice |
| --------- | ---------- |
| Manifest | Obsidian alespoň `0.15.0`; `isDesktopOnly` je false |
| Doklady o ověření | Viz datované záznamy; fyzická mobilní zařízení a 0.15.0 nejsou aktuálně ověřeny |
| Cloudový model | Síť, oprávněný účet/klíč a dostupný model |
| Lokální model | Samostatně připravený běžící server a stažený/načtený model |
| Export do prezentací a obvodů | Desktopové nástroje a závislosti formátu; nejprve ověřte prostředí |

Všechny exportéry nesdílejí jednu zaručenou verzi operačního systému. Náhled obvodu není důkaz kompilace TeXu a desktopový test neprokazuje chování mobilu.

## Odinstalace

Plugin vypněte nebo odinstalujte v Community plugins. Poznámky a vygenerované soubory zůstávají běžnými soubory trezoru. Před mazáním je prověřte a podle potřeby zálohujte nastavení. Odinstalace nevrací dokončené změny.

## Aktualizace

Použijte **Check for updates**. Při ruční aktualizaci zastavte úlohy, zálohujte trezor/nastavení, nahraďte tři soubory jedné verze a aplikaci znovu načtěte. Přečtěte poznámky k vydání a proveďte malý test. Nenahrazujte soubor nastavení distribučním souborem. Návrat vyžaduje záměrně zvolenou kompatibilní verzi a zálohu.
