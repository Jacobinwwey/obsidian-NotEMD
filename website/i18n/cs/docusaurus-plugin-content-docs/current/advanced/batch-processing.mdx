# Dávkové zpracování

<TLDR>Akce složek sdílejí výběr a průběh, nikoli jednu politiku přepsání. Výchozí souběžnost je jedna. Vyzkoušejte malou složku, ověřte rozsah a cíle a teprve potom dávku rozšiřte.</TLDR>

## Přehled

Panel a průzkumník nabízejí dávkové odkazy, pojmy, názvy, překlady, původní pasáže, Mermaid a vzorce. Obecná samostatná rešerše složky neexistuje; lze ji přidat ke generování podle názvů. Dávka není transakce celé složky: dokončené soubory zůstávají při chybě i zrušení.

## Jak to funguje

### Model provádění

1. Vyberte úlohu a složku s požadovanými soubory.
2. Kandidáty určují přípony, výběr a filtry výstupů konkrétní úlohy.
3. Úloha používá vlastní profil/model a hlásí stav, chyby a cesty.
4. Po dokončení nebo zrušení zkontrolujte zprávu a soubory před opakováním.

Odkazy, pojmy, názvy, původní pasáže, Mermaid a vzorce výchozím nastavením zahrnují podsložky. **Překlad složky výchozím nastavením zahrnuje pouze přímé potomky.** Vývojářský režim a pokročilé profily výběru mohou rozsah i filtry změnit. Prověřte skutečný výběr.

### Přepisování

| Úloha | Co prověřit před opakováním |
| ------ | ------------------------------------ |
| Odkazy | Výchozí samostatný výstup; ověřte příponu, složku a přesun zdroje |
| Pojmy | Zapnuté zpětné odkazy doplňují existující poznámky; duplicity jsou zvlášť |
| Generování podle názvů | Zapíše způsobilé zdroje a přesune je, pokud je cíl complete volný |
| Překlad | Existující překlad může přepsat; výchozí `_<language>.md` |
| Mermaid / vzorce | Mění vybrané poznámky; předem je zálohujte a výsledek zkontrolujte |

Neexistuje univerzální přeskočit/připojit/přepsat. Obsazený cíl complete blokuje přesun po generování, nikoli předcházející zápis obsahu. Počty vygenerovaných a přesunutých souborů se liší.

### Souběžnost

Ponechte `batchConcurrency: 1`, dokud vzorek neprojde. Některé cesty vyžadují také `enableBatchParallelism`; překlad složky používá souběžnost přímo. Vyšší souběžnost zatěžuje poskytovatele, paměť a lokální server bez záruky zrychlení. Rozestupy požadavků/skupin neodstraní všechny limity ani provoz jiných klientů stejného účtu.

## Nastavení

| Nastavení | Výchozí hodnota | Účinek |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Požadovaná souběžnost podporovaných cest |
| `enableBatchParallelism` | `false` | Povolení podporovaného paralelního plánování |
| `batchSize` | `50` | Velikost skupiny při skupinovém běhu |
| `batchInterDelayMs` | `1000` | Pauza mezi naplánovanými skupinami |
| `apiCallIntervalMs` | `500` | Rozestup souběžných API požadavků |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Zachování pravidel podsložek konkrétní úlohy |
| `enableStableApiCall` | `false` | Výslovný stabilní režim požadavků |

### Modely úloh

Složky používají model odpovídající souborové úlohy. Ověřte směrování soukromých dat. Lokální kontext dávky názvů používá jeden snímek od začátku; průběžné změny se nemíchají do pozdějšího vyhledávání. Pro nové změny spusťte novou dávku.

## Příklad

Vytvořte `trial-titles` se dvěma poznámkami obsahujícími názvy. Spusťte **Batch generate from titles** a ověřte obsah, sousední `trial-titles_complete` a počty generování, přesunů i chyb. Nejprve prozkoumejte selhaný soubor. Opakování zdrojové složky není automatické přesné pokračování nehotových položek.

## Zrušení a obnova

Zrušení zastaví nové plánování a podporované požadavky. Externí systémy mohou dokončit přijaté volání/zápis; účtování řídí poskytovatel. Vyčkejte, porovnejte dokončené soubory s cestami obnovy/konfliktů a až po kontrole uklízejte.

## Doporučení

- Prověřte skutečný výběr profilu.
- Při 429 snižte souběžnost a ověřte limity.
- Rozlišujte zrušené, selhané a dokončené položky.
- Uchovejte neměnný vzorek a zálohu.
