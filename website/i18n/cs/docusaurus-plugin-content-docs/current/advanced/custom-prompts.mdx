# Vlastní prompty

<TLDR>Neprázdný vlastní prompt nahradí vestavěný, pokud jsou zapnuté globální i odpovídající přepínače. Zachovejte výstupní kontrakt: šablonování automaticky nevrátí vynechané instrukce formátu.</TLDR>

## Přehled

Nejprve testujte výchozí prompt na reprezentativní poznámce. Zaměření oboru nebo pravidlo synonym může stačit. Vlastní politiku, strukturu či překladový styl porovnejte před dávkovým nasazením.

## Jak to funguje

### Sestavení

Notemd vybere vestavěný či vlastní prompt, přidá příslušné pokyny oboru/jazyka a dosadí proměnné dané úlohy. Text poznámky může být odeslán zvlášť. Proměnné nejsou univerzální. Náhrada může vynechat `CONCEPT:` nebo rešeršní kontext; platný požadavek nedokládá parsovatelnou ani podloženou odpověď.

### Proměnné

Dodržte velikost písmen a jednoduché složené závorky:

| Úloha | Dostupné proměnné |
| ------ | ----------------------- |
| Generování podle názvů | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Shrnutí rešerše | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Překlad | `{LANGUAGE}`, `{TEXT}` |
| Původní pasáže | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` se řídí jazykovou politikou úlohy. Odkazy a samostatné pojmy dostávají text jako obsah úlohy; nevymýšlejte jiné zástupné proměnné. Neznámé názvy se nedosadí. Jde o náhrady promptů, nikoli šablony souborů pojmů.

### Zaměření oboru

Zapněte zaměřené učení a zadejte například `elektrotechnika`. `Relevant Fields` směruje pozornost modelu, není však tvrdý filtr ani důkaz vyloučení jiného obsahu.

## Nastavení

| Úloha | Přepínač | Pole promptu |
| ------ | --------------- | -------------- |
| Odkazy | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Názvy | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Rešerše | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Shrnutí Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Pojmy | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Překlad | `useCustomPromptForTranslate` | `translatePrompt` |
| Původní text | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Všechny vyžadují `enableGlobalCustomPrompts`. Prázdný text použije výchozí prompt. Sjednocená extrakce původního textu má vlastní pevný formát tam, kde běžná náhrada neplatí. Generování diagramů vyžaduje typovaný výstup; prompt Mermaid není univerzální.

## Příklad

Zapněte globální přepínač a přepínač pojmů a zachovejte značku parseru:

```text
Najdi nejdůležitější elektrotechnické pojmy v poznámce.
Upřednostni konkrétní součástky a fyzikální mechanismy před obecnými výrazy.
Každý pojem napiš na samostatný řádek přesně takto:
CONCEPT: Název pojmu
Nepřidávej vysvětlení ani vnější blok kódu.
```

Na kopii porovnejte řádky, názvy souborů a chybějící pojmy s výchozím promptem. Předchozí prompt uchovejte pro návrat.

## Doporučení

- Ověřte jednu úlohu před zvětšením dávky.
- Zachovejte zdroje rešerše a přesné citace.
- Překládejte pokyny se stabilními ID a značkami.
- Po změně modelu test opakujte; prompt nenahrazuje validaci.
