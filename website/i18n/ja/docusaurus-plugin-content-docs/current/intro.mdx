# Notemd の紹介

<TLDR>
Notemd は MIT ライセンスの Obsidian プラグインです。ノートを、確認して保持できるリンク付き Markdown、概念ノート、調査要約、翻訳、図に変換します。モデル、タスク、出力範囲を選択し、生成物を確認してから知識ベースへ採用してください。
</TLDR>

## Notemd とは

36 のプロバイダープリセットでクラウド API、ゲートウェイ、ローカルサーバーを Vault の作業につなぎます。各タスクは固有の出力契約に従ってファイルを作成・更新し、個別にもサイドバーの連続処理としても実行できます。

保存した出力は Vault に残りますが、クラウド利用時は内容がそのエンドポイントへ送信されます。Web 調査も通信します。ローカル保存とローカル推論は別の選択です。

## 主な機能

### Wiki リンクと概念ノート

モデルに概念候補とリンクを提案させます。リンク追加は既定で別ノートを作成し、指定フォルダーには概念ファイルを出力できます。単独抽出はタイトルのみ・バックリンクなしが既定です。[リンク](./features/wiki-links)と[概念ノート](./features/concept-notes)に違いを記載しています。

### 調査とローカル文脈

Tavily または DuckDuckGo を選び、LLM の要約をノートに追記します。任意の範囲付きローカル検索で抜粋を渡すこともできます。索引は語彙検索で、embedding による意味検索ではありません。[調査](./features/research)で出典と通信範囲を確認してください。

### 翻訳と原文抽出

ファイルやフォルダーを選択言語へ翻訳します。質問に対応する原文を抽出した場合も、引用を原文と照合します。テキスト選択だけでファイル翻訳の範囲は変わりません。[翻訳](./features/translation)は命名と上書きを説明します。

### 図とエクスポート

図の種類と対応ソース形式を選び、プレビューを確認してソースや視覚出力を保存します。実行可能カタログは 33 項目で、ソース形式と出力形式は異なります。[図](./features/diagrams)で Draw.io、Drawnix、Mermaid、CircuitikZ と外部アプリの制約を確認できます。

### ワークフロー

既定の **One-Click Extract** はリンク追加、概念／選択フォルダーの対象ノートへの本文生成、complete フォルダーの Mermaid 修復を行い、既存ノートも対象になり得ます。各アクションの前提条件と出力は維持されます。DSL は[ワークフロー](./features/workflows)を参照してください。

## 使い始める

1. 対象 Vault に[インストール](./getting-started/installation)。
2. 利用できるモデルで破棄可能なノートをテスト。
3. 概念フォルダーと出力先を指定。
4. 結果を確認してからバッチを拡大。

完了時間や有用な出力を保証する最小長はありません。全体を確認できる小さな入力から始めます。

## 図機能の設計方針

対応カタログ項目には型付き仕様と対象別レンダラーを使います。`DiagramSpec` は開発契約であり、任意の構文や参考レイアウトすべてへの対応を意味しません。

回路は対応する `circuitikz` 構造に限定します。TikZJax は外部ツールで、プレビューはネイティブコンパイルの証拠ではありません。Drawnix の静的関係は再配置後の枝間矢印の接続を保証しません。

## アーキテクチャ

タスクを選択モデルへルーティングし、出力を検証／解析してノートや成果物へ書き込みます。検索は任意の文脈を補い、プレビューと出力には形式別制約があります。

所有モジュールと検証は[開発者ガイド](./developers/overview)、限定公開コマンドは [Agent ガイド](./agents/overview)を参照してください。内部 operation 登録数は一般公開 API の数ではありません。

## ツールの比較 {#notemd-vs-other-obsidian-ai-plugins}

ファイル変換、対話、決定的リンク、検索、ネイティブ編集のどれが必要かで選びます。各プロジェクトの現在の文書を読み、同じ代表タスクを使い、バージョンと有効な機能を記録して比較します。

## データと互換性の境界

クラウドは入力、検索サービスはクエリーを受け取ります。ローカル抜粋も有効ならプロンプトに入ります。ローカル運用と判断する前にタスク別ルートを確認します。キャンセルは後続処理を止め、完了出力を残しますが、遠隔生成や課金は保証しません。

manifest は最低 Obsidian `0.15.0` とモバイル読み込みを許可しています。ただし実機モバイルと最低版は未検証です。任意のネイティブ出力にはデスクトップツールが必要な場合があります。サイト 34 ルート、UI 21 ロケール、モデルの翻訳能力は別の指標です。
