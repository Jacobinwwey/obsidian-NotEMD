# 中国地域のプロバイダー

<TLDR>
アカウントと配備に一致するプリセットを選びます。同じ OpenAI-compatible でも地域 URL、モデル名、権限は交換できません。短い実タスクで確認してから用途を選んでください。
</TLDR>

## 導入

選択サービスで API アカウントとキーを用意し、Notemd の対応プリセットを指定します。地域とモデル利用権を確認し、接続テストとノート処理を行います。既定値は現行モデルの保証ではありません。

## エンドポイントと認証

| プリセット | 既定モデル | 基本 URL |
| -------- | --------------- | ------------------ |
| DeepSeek | `deepseek-v4-pro` | `https://api.deepseek.com` |
| Qwen | `qwen3-235b-a22b` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Qwen Code | `qwen3-coder-plus` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Doubao | `ep-xxxxxxxxxxxxxxxx` | `https://ark.cn-beijing.volces.com/api/v3` |

Doubao の値は Ark endpoint ID または配備が対応する model ID に置換します。GLM と Z AI は地域が異なり、別地域やサブスクリプション用キーが通るとは限りません。所在地だけで選ばずアカウント手順に従います。

## モデルの発見

許可される場合は一覧機能を使います。Huawei Cloud MaaS は配備対応の発見規則、他の一覧プリセットは対応する OpenAI-compatible 経路を使います。一覧権限がなくても指定モデルの生成は可能な場合があります。

接続テストも異なり、DeepSeek は一覧だけで成功し得る一方、複数の地域プリセットは短いチャットを実行します。出力要件は実タスクで確認します。

## トラブルシューティング

- キーは有効だが生成不可：モデル利用権、配備、地域を確認。
- Ark モデル拒否：endpoint ID か model ID かを確認。
- 推論の切断：出力上限と thinking 設定を調べる。
- 通信エラー：Obsidian 端末から実 URL を試し、通信エラーを見る。

## 選ぶ場面

アクセス可能な URL、データ取扱要件、実測結果で選びます。地域やブランドは品質、プライバシー、費用の保証ではありません。[概要](./overview)にはゲートウェイやローカルの選択肢もあります。
