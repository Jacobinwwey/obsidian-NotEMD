# Anthropic プロバイダー

<TLDR>
ネイティブ Messages API には Anthropic プリセットを使います。OpenAI-compatible ゲートウェイの Claude にはそのゲートウェイを選びます。履歴上の既定モデルが退役している場合は変更が必要です。
</TLDR>

## 導入

**Anthropic** と API key を設定し、同じプロトコルの独自配信でない限りネイティブ URL を維持します。現在利用できる Claude ID を指定し、接続テストと対象タスクの試行を行います。

## エンドポイントと認証

| 項目 | プリセット値 |
| ------- | -------------- |
| 通信プロトコル | `anthropic` |
| API key | 必須 |
| 基本 URL | `https://api.anthropic.com` |
| 既定モデル | `claude-3-5-sonnet-20240620` |
| Temperature | `0.5` |
| 接続テスト | `chat-only` |

`/v1/messages` とネイティブのキー／API version ヘッダーを使います。OpenAI 形式のチャットパスを入れないでください。モデル既定値はリポジトリの設定記録で、現在の提供保証ではありません。

## モデルの発見

利用可能なら Anthropic のネイティブ一覧経路を使用します。一覧が制限される場合は既知のモデルを入力し、チャット接続テストを行います。長文や構造化出力は別途確認します。

## トラブルシューティング

- `401`／`403`：キー、workspace／project、課金、モデル権限を確認。
- `404`：URL と現在のモデル提供を確認。
- ゲートウェイ ID の失敗：対応プリセットとその ID に変更。
- 長い応答の失敗：再試行を増やす前に上限と応答エラーを調べる。

## 選ぶ場面

エンドポイントが Anthropic Messages を提供する場合に選びます。プロバイダーを品質順位とみなさず、自分の資料で評価します。タスク別設定で適した用途だけに限定できます。
