# Google プロバイダー

<TLDR>
Google プリセットはネイティブ Gemini Generative Language API を使います。対応する権限のキーと現在利用できるモデルを指定します。OpenAI-compatible で Gemini を配信する場合はゲートウェイのプリセットを使います。
</TLDR>

## 導入

**Google** を選び、キー、Generative Language の URL、その API version が提供するモデルを設定します。接続テスト後にノート処理や翻訳を試します。任意の Google Cloud／Vertex 配備を自動設定するものではありません。

## エンドポイントと認証

| 項目 | プリセット値 |
| ------- | -------------- |
| 通信プロトコル | `google` |
| API key | 必須 |
| 基本 URL | `https://generativelanguage.googleapis.com/v1` |
| 既定モデル | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| 接続テスト | `chat-only` |

API key 認証を使うモデルの `generateContent` リクエストを作成します。履歴上のモデル ID は現在の保証ではありません。リクエスト詳細には認証情報が含まれ得るため、診断共有前に URL を確認します。

## モデルの発見

対応するネイティブ一覧機能を使い、モデルが選択 API version で生成可能か確認します。空の一覧は権限、URL、提供状況の問題かもしれません。無作為なプロトコル変更ではなく実設定をテストします。

## トラブルシューティング

- `400`：モデル、パラメーター、token／出力制限を確認。
- `401`／`403`：キーの制限、API 有効化、モデル権限を確認。
- `404`：モデルがその API version に存在するか確認。
- ゲートウェイ例が失敗：対応 OpenAI-compatible プリセットを使用。

## 選ぶ場面

ネイティブ Gemini API 向けです。翻訳、調査、図生成を代表サンプルで評価します。相対的な速度、費用、翻訳品質は保証しません。
