# 設定

<TLDR>
**設定 → Notemd** の検索から項目を探します。処理前にプロバイダーと出力先を指定してください。変更はノート一つで確認してからフォルダーに適用します。実行中のタスクは開始時の設定を保持する場合があります。
</TLDR>

## 設定の概要

初期プロバイダーは DeepSeek、認証情報は空です。プリセット選択はアカウント作成、モデル導入、クラウドへの権限付与を行いません。[プロバイダー設定](../providers/overview)でプロトコルとモデル一覧を確認できます。

## 設定の検索とお気に入り

- 設定検索は名前、説明、別名、表示カテゴリーに一致し、対象へ移動します。
- **★ Favorites** は保存した項目の説明、分類、移動先を示します。Vault ごとに保存され、再起動後も維持し、無効な ID は除外します。
- 矢印でツールバーを折り畳み、再度開くと検索語を復元します。
- お気に入り一覧と、お気に入りだけを検索するフィルターは別の操作です。

図プレビューの出力解像度は既定 **300 PPI**、範囲 **72–600**。PNG のラスター化に影響し、対応する SVG／PDF はベクトルを保持します。**Also export complete Mermaid visuals** は付属ファイルの設定であり、Drawnix 内の Mermaid 表示を切り替えるものではありません。

1 回の実行で複数の図表タイプを選び、タイプごとに複数の出力形式を指定できます。選択を解除しても形式の設定は保持されます。すべて解除すると、本文を自動解析します。

中間ファイル用に共通の Vault 相対パスを設定できます。空欄なら各ソースの隣の `notemd_assert/` を使います。復旧記録、描画キャッシュ、任意の添付ファイルを保存します。既存の出力が参照するファイルは保持してください。フォルダー変更は新しい実行だけに適用されます。

## 1. プロバイダー設定

必要な認証情報、プロトコルに合う URL、利用できるモデルを指定します。対応するモデル一覧を取得し、接続をテストします。一覧取得と生成成功は別の確認です。

ローカルには起動済みサーバーとモデルが必要です。クラウド／ゲートウェイにはタスク内容が渡ります。非公開資料ではタスク別プロバイダーも調べます。

## 2. タスク別モデル

`useMultiModelSettings` でリンク、タイトル生成、調査、翻訳、概念抽出、原文抽出、Mermaid 要約を個別設定できます。空のモデル上書きは選択プロバイダーのモデルを使い、未有効時は active provider を使います。

代表ノートで正確性、時間、実際の料金を比較します。ここではモデルの順位や継続的な提供を保証しません。

## 3. 出力設定

| タスク | 既定の出力 |
| ------ | ------------------------- |
| リンク追加 | 原文の隣に `_processed.md` を作成。原文移動は無効 |
| 単独の概念抽出 | 指定概念フォルダーが必要。タイトルのみ、バックリンクなし |
| 翻訳 | 原文の隣に `_<language>.md`。既存出力を上書きし得る |
| 調査 | アクティブな Markdown に要約を追記 |
| タイトルから一括生成 | 対象ノートに生成し、移動可能なら同階層の `<folder>_complete` へ |
| 図のプレビュー／出力 | 選択したファイルは元のノートと同じフォルダー、または指定した出力フォルダーへ直接、自動保存されます。名前には `topic_drawnix.pdf` や `topic_flowchart.svg` のようにタイプを付けます。同名の場合は `-2`、`-3` などを追加し、既存ファイルを上書きしません。 |
概念フォルダーは初期状態で空です。`concepts` は任意の例。単独概念テンプレートは最小／完全形式のみで、汎用テンプレート変数エンジンはありません。[概念ノート](../features/concept-notes)を参照してください。

リンク処理の接尾辞、処理後フォルダー、翻訳接尾辞と保存先は別設定です。再実行前に既存出力を調べ、復旧や競合の表示に従います。キャンセルは完了済みの書き込みを戻しません。

## 4. 言語設定

プラグイン UI は **21 ロケール**、サイトは **34 言語ルート**。`uiLocale: auto` は対応する UI 言語を選び、未対応なら英語になります。

生成言語は独立しており既定は英語です。リンク、タイトル生成、調査、概念抽出、Mermaid 要約はタスク別言語を設定できます。翻訳は選択した `language` を使います。モデルの言語能力は UI／サイトの数とは別です。

## 5. 検索連携

API key を設定した **Tavily** または **DuckDuckGo** を明示的に選びます。空の Tavily キーでは自動切替しません。両者とも通信し、DuckDuckGo は検索先ページも取得する場合があります。

タイトル生成は既定で調査しません。必要な場合だけ `enableResearchInGenerateContent` を有効にします。ローカル検索も既定で無効で、範囲とタスクを別設定します。ローカルに索引を作っても、プロンプトに使うノート断片は LLM に送信します。

## 6. ワークフロー設定

ビルダーを使うか、1行に名前付き DSL を記述します。既定は：

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` は名前とアクション列、`>` は ID の区切りです。既定では報告されたステップ失敗で停止します。[ワークフロー](../features/workflows)で ID、フォルダー文脈、エラー後の続行を確認できます。

## 7. 詳細設定

| 設定 | 既定値 | 意味 |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | タスク別指定がない場合のプロバイダー |
| `useMultiModelSettings` | `false` | タスク別モデルを有効化 |
| `useCustomConceptNoteFolder` | `true` | フォルダー指定後に概念出力を許可 |
| `conceptNoteFolder` | `''` | 初期概念フォルダーは未指定 |
| `extractConceptsMinimalTemplate` | `true` | 単独抽出をタイトルのみで作成 |
| `extractConceptsAddBacklink` | `false` | 単独抽出のバックリンクを明示的に許可 |
| `moveOriginalFileOnProcess` | `false` | リンク追加時に原文を保持 |
| `chunkWordCount` | `3000` | 概算の語数。プロバイダーの token 上限ではない |
| `batchConcurrency` | `1` | 既定のバッチ並行数 |
| `enableBatchParallelism` | `false` | このスイッチを使う経路で並行化 |
| `enableStableApiCall` | `false` | 明示的な安定リクエストモード |
| `customWorkflowErrorStrategy` | `stop_on_error` | 報告エラーでワークフロー停止 |

分割サイズと出力 token 予算は異なります。小さい分割でも文脈上限を保証しません。並行数を下げてもすべての 429 を防げるわけではありません。

## 設定プロファイル

設定は Vault のプラグインデータです。変更前にバックアップします。プロバイダープロファイルのマスキング済み出力は完全な Vault バックアップではありません。URL 等のメタデータも確認し、未加工の設定や機密ノート入り診断を公開しないでください。

## 設定の問題を調べる

正確なプロバイダー／モデルで接続テストと短いノートを試します。項目が見つからない場合は検索、カテゴリー、開発者モードの表示条件、対象 Vault を確認します。報告にはバージョンと機密情報を除いた設定を添えます。
