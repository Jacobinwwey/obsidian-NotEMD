# インストール

<TLDR>
Obsidian のコミュニティプラグインから **Notemd** を導入するか、同じ GitHub Release のプラグインファイル三つを Vault に配置します。有効化してプロバイダーを設定し、破棄できるノートで確認してください。モデルサーバーと任意のネイティブ出力には別途準備が必要です。
</TLDR>

## 方法1：コミュニティプラグイン（推奨）

1. 対象 Vault の**設定 → コミュニティプラグイン**を開きます。
2. 必要ならコミュニティプラグインを許可し、**閲覧**を選びます。
3. **Notemd** を検索し、リポジトリが `Jacobinwwey/obsidian-NotEMD` であることを確認してインストールします。
4. 有効化し、リボンアイコンまたはコマンドパレットからサイドバーを開きます。

[Obsidian で Notemd を開く](obsidian://show-plugin?id=notemd)。リンクを開けない場合は上記の手順を使ってください。このガイドを読むために専用のプロトコルハンドラーは不要です。

## 方法2：手動インストール

### 前提条件

Obsidian と、バックアップ可能な Vault を用意します。manifest の最低バージョンは `0.15.0` ですが、現在の候補版をその古いバージョンでテストしたという意味ではありません。

### 手順

1. 同じ [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest) から `main.js`、`manifest.json`、`styles.css` を取得します。`README.md` も付属しますが、実行に必要なファイルではありません。
2. `<vault>/.obsidian/plugins/notemd/` を作り、三つのファイルを置きます。設定ディレクトリを変更した Vault では実際のパスを使用します。
3. Obsidian を再読み込みし、プラグインを有効化します。
4. 表示バージョンを確認してからモデル設定に進みます。新しい manifest と古い bundle を混在させないでください。

## 別の方法：BRAT

[BRAT](https://github.com/TfTHacker/obsidian42-brat) を利用中なら、ベータプラグインの手順で `Jacobinwwey/obsidian-NotEMD` を追加できます。不具合再現時はバージョンを明記します。BRAT は任意の外部ツールで、通常の導入には不要です。

## 動作確認

利用可能なプロバイダーとモデルで **接続をテスト** を実行し、[クイックスタート](./quick-start)に従ってノートのコピーを処理します。接続テストによってはモデル一覧の到達性だけを確認します。生成とファイル出力は実際のタスクで検証します。

## 動作条件

| 対象 | 条件と限界 |
|---|---|
| manifest | 最低 Obsidian `0.15.0`、`isDesktopOnly` は false |
| 検証範囲 | リリースの日時付き検証記録を参照。実機モバイルと Obsidian 0.15.0 は未検証 |
| クラウド LLM | ネットワーク、権限のあるアカウント／キー、対応モデル |
| ローカル LLM | 別途導入して起動したサーバーと、取得／読み込み済みモデル |
| ネイティブなスライド／回路出力 | デスクトップツールと形式別依存関係。実行前に環境を確認 |

任意の出力機能すべてに適用できる OS バージョン保証はありません。プラグイン内の回路プレビューは TeX コンパイルの証明ではなく、デスクトップ検証からモバイルの動作も推定できません。

## アンインストール

コミュニティプラグインから無効化または削除します。生成ノートや成果物は Vault の通常ファイルとして残るため、削除前に確認してください。再導入するなら設定を保存します。アンインストールは完了済みの編集を取り消しません。

## 更新

コミュニティプラグインの更新確認を使います。手動更新ではタスクを停止し、Vault と設定をバックアップしてから、同じリリースの三つの実行ファイルに置き換えて再読み込みします。リリースノートを読み、小規模な試行後にバッチを再開します。

Vault の設定ファイルをリリース添付で置き換えないでください。戻す場合はバックアップを保ち、互換性が確認されたバージョンを明示的に選び、必要な生成物を残します。
