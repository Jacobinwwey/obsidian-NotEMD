# よくある質問

<TLDR>
破棄できるノート、利用可能なプロバイダー、明確な出力先を準備します。以下は実装されたタスクの境界です。完全な設定と検証は関連ガイドを参照してください。
</TLDR>

## 質問

### Obsidian にどうインストールしますか？

設定 → コミュニティプラグイン → 閲覧で Notemd を検索し、導入して有効化します。手動では同じ GitHub Release の main.js、manifest.json、styles.css を使います。manifest の最低 Obsidian は 0.15.0 ですが、この旧版と実機モバイルは現在の証拠では未検証です。

### どの LLM プロバイダーに対応しますか？

36 プリセットが OpenAI-compatible、Anthropic、Google、Azure OpenAI、Ollama の五系列をカバーします。クラウド API、ゲートウェイ、ローカルサーバーにはそれぞれ URL、認証、モデルが必要です。プリセットや一覧の存在は現時点の提供や生成権限を保証しません。

### ローカル LLM は使えますか？

起動済み Ollama、LM Studio、OVMS、または互換な自前エンドポイントを設定できます。モデルを先に取得／ロードし、対象タスクを試します。ローカル推論を選んでも Web 調査、依存導入、別途クラウド指定のタスクはオフラインになりません。

### ChatGPT との違いは何ですか？

Notemd はリンク追加、概念作成、調査追記、ファイル翻訳、図の保存など、Obsidian 内の明確なファイル操作に重点を置きます。その Vault 作業が合う場合に選びます。他ツールは現在の履歴保存、出力、統合で評価してください。チャット型ツールも履歴やファイルを保持できます。

### Copilot や Smart Connections とどう比較しますか？

実際に必要なタスクと、各プロジェクトの現在の版、設定、文書で比較します。Notemd はノート変換と範囲を限定した語彙検索を提供し、汎用 chat-with-vault UI や embedding 意味検索は提供しません。このサイトは他製品の現在の順位を主張しません。

### 調査で使える検索サービスは何ですか？

Tavily とキーを設定するか、DuckDuckGo を明示的に選びます。空の Tavily キーから自動切替はしません。両方とも通信します。LLM は Web と任意のローカル文脈を要約し、現在の Markdown に追記します。URL と重要な主張を確認してください。

### 日本語や中国語などに対応していますか？

UI は21ロケール、Web サイトは34言語ルートです。生成言語は独立設定で、対応タスクには個別指定もあります。翻訳能力と品質は選択モデルに依存し、UI や文書の言語数では決まりません。

### 論文や PDF の読解に使えますか？

適切な外部ツールで読みやすい Markdown に変換し、式、表、図の変換ミスを点検します。その後リンク、原文抽出、質問の調査、翻訳、図を利用できます。標準ノート作業はネイティブ PDF OCR や任意バイナリ文書の忠実な抽出を約束しません。

### どの種類の図を生成できますか？

実行可能カタログには33項目があり、対応するソースとプレビュー経路があります。Mermaid、JSON Canvas、Vega-Lite、編集可能 HTML/SVG、Draw.io、Drawnix、制約付き CircuitikZ は用途が異なります。選択肢に従い、出力先アプリで確認します。プレビューはネイティブ編集やコンパイルの証拠ではありません。

### 無料でオープンソースですか？

Notemd は MIT ライセンスです。モデル推論、サービスのアカウント、検索、外部ツールには別の費用と条件があります。ソースは公開され、貢献を受け付けています。自由なライセンスはすべての外部サービスが無料という意味ではありません。

### 完全オフラインで動きますか？

サーバー、モデル、依存を導入すれば一部ノート作業をローカルで行えます。DuckDuckGo を含む Web 調査は通信が必要です。切断前にタスク別 provider と出力依存を確認してください。全機能への一律なオフライン保証はありません。

### データはクラウドへ送られますか？

プロンプトと内容は設定 LLM へ、検索語は検索サービスへ、ページ取得は Web サイトへ送信されます。ローカル検索の抜粋もクラウド用プロンプトに入り得ます。ローカルプリセットも遠隔 URL に変更できます。ルートを確認し、ログの機密を除いて共有してください。ローカル保存だけでは端末内完結を意味しません。

### One-Click Extract は何を実行しますか？

現在のノートへのリンク追加、概念または選択フォルダーの対象ノートへの本文生成、complete フォルダーの Mermaid 修復です。既存概念を処理することもあります。調査や図生成を自動で追加しません。正確な name::action>action 構文はワークフローガイドを参照してください。

### キャンセルで変更は元に戻りますか？

戻りません。対応する後続作業を止め、完了出力を保持します。受理済み要求や書き込みは完了し得て、料金は遠隔側が管理します。停止を待ち、出力と復旧競合を確認して必要な部分だけ再試行します。

### Agent から自動操作できますか？

利用可能な Obsidian ホストと Vault を通じ、マスキング済み profile、能力一覧、呼び出し契約、公開 CLI 範囲を四つの限定コマンドで出力できます。ファイルを書き込みます。保守者用操作は別契約であり、内部 operation の数は公開 API の数ではありません。Agent ガイドから始めます。

### 開発者はどこから始めますか？

開発者ガイドにリポジトリの準備、ビルドと全テスト、所有モジュール、拡張規則があります。AGENTS.md が実行基準です。正確な版と機密情報を除いた再現証拠を報告し、統合を提案する前に変更を検証してください。
