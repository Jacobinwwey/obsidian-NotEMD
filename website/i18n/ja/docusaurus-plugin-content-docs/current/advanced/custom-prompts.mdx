# カスタムプロンプト

<TLDR>
全体とタスクの両スイッチが有効でテキストが空でない場合、既定プロンプトを置換します。出力契約は自分で保持してください。省略した指示を自動復元する汎用テンプレート機構はありません。
</TLDR>

## 概要

まず既定を代表ノートで確認します。分野指定や同義語抑制で足りるならそれを使い、特定の抽出方針、形式、翻訳スタイルが必要な場合にカスタム化します。バッチ前に比較します。

## 仕組み

### 構成

既定か有効なカスタム文を選び、適用可能な分野・言語指示を足し、そのタスクの変数を置換します。源文は別メッセージの場合もあります。研究用変数がすべての操作で使えるわけではありません。

抽出プロンプトから `CONCEPT:` を消したり、研究から文脈を抜いたりできます。合法なリクエストでも、解析可能性や証拠の裏付けは保証されません。

### 変数

以下の大文字名と一重波括弧をそのまま使います。

| タスク | 提供される変数 |
| ------ | ----------------------- |
| タイトル生成 | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| 調査要約 | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| 翻訳 | `{LANGUAGE}`, `{TEXT}` |
| 原文抽出 | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` はタスクの言語方針に従います。リンク追加と概念抽出はタスク内容として本文を渡すため、架空の content 変数を追加しないでください。未知変数は補完されません。これは概念ファイルのテンプレートではありません。

### 学習分野

例えば `electrical engineering` を指定すると `Relevant Fields` の指示を追加します。注意を向けるための指示で、無関係概念を排除する厳密なフィルターではありません。

## 設定

| タスク | 有効スイッチ | 本文フィールド |
| ------ | --------------- | -------------- |
| リンク追加 | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| タイトル生成 | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| 調査要約 | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid 要約 | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| 概念抽出 | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| 翻訳 | `useCustomPromptForTranslate` | `translatePrompt` |
| 原文抽出 | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

すべて `enableGlobalCustomPrompts` が必要です。空の本文は既定へ戻ります。統合された原文抽出は固有の組込み形式で、通常抽出の上書きとは別です。図生成も型付き出力が必要で、Mermaid 要約の上書きは汎用の図プロンプトではありません。

## 例

回路ノート用なら全体と抽出のスイッチを有効にし、解析契約を残します。

```text
入力ノートから中心的な電気工学の概念を抽出してください。
一般的な名詞より、具体的な部品名と物理メカニズムを優先します。
1行に1概念を、この形式で返してください。
CONCEPT: 用語名
説明や外側のコードブロックは付けないでください。
```

コピーで戻り値、ファイル名、抽出漏れを確認し、既定と比較します。変更前の文を残して復元できるようにします。

## ヒント

- 一度に一つのタスクを試し、範囲を整えてから量を増やす。
- 研究には証拠、原文抽出には正確な引用を残す。
- 翻訳しても識別子と必須マーカーを維持。
- モデル／サービス変更後に再確認。指示は検証保証ではありません。
