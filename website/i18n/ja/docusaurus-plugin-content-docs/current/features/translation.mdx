# 翻訳

<TLDR>
設定した LLM で現在のファイルやフォルダーの対象ファイルを翻訳します。既定では言語接尾辞付きの別ファイルに保存します。対応言語と精度はモデル次第で、UI 21 ロケールとサイト 34 ルートは翻訳の上限や保証ではありません。
</TLDR>

## 概要

出力言語と翻訳プロバイダーを先に選び、用語、リンク、コードを含むコピーで試します。選択した LLM を使う機能であり、専用の Google Translate 連携ではありません。

操作はファイル／フォルダー単位です。段落だけ必要なら一時ノートへコピーしてください。エディターで選択しても **現在のファイルを翻訳** の対象は狭まりません。

## 仕組み

### 翻訳コマンド

1. 言語コントロールで目標言語を選択。既定は英語で UI 言語とは独立。
2. 源ノートで **現在のファイルを翻訳** を実行。
3. 長文を分割して翻訳モデルへ送り、戻ったチャンクを結合。
4. 報告されたファイルを開き、意味、用語、引用、リンク、コードを照合。

既定で `Example.md` をフランス語にすると隣に `Example_fr.md` を作り、原文は残します。同名出力は上書きされます。既定の原文追記モードや保証された `Translation` 見出しはありません。

### 言語の組合せ

入力言語はモデルが推定します。メニューにあるだけでは翻訳対の精度を証明しません。専門語と混在言語を試してください。分割はチャンク間の文脈を損なう場合があります。

### タスク別モデル

個別設定有効時は `translateProvider` と `translateModel`、無効時は active provider を使います。ローカルはサーバーとモデルが必要で、クラウドはプロンプトと内容を受信します。

汎用ランキングだけで選ばず、小さい専門サンプルと原文を比較します。

### フォルダー翻訳

**フォルダーを一括翻訳** で対象範囲を確認します。既定は直下ファイルのみで、高度な選択プロファイルが変更できます。元の basename と言語接尾辞を使うため、同名源ファイルを一つのカスタム出力先へ集めると衝突し得ます。再実行前に既存訳を確認してください。

## 設定

| 設定 | 既定値 | 意味 |
| --------- | --------- | -------- |
| `language` | `en` | 目標言語 |
| `translateProvider` | `DeepSeek` | 個別設定時の翻訳プロバイダー |
| `translateModel` | `''` | 空ならプロバイダーのモデル |
| `useCustomTranslationSuffix` | `false` | 既定で言語コードを付加 |
| `translationCustomSuffix` | `_translated` | カスタム接尾辞有効時の値 |
| `useCustomTranslationSavePath` | `false` | 既定で原文の隣へ保存 |
| `translationSavePath` | `''` | Vault 相対の保存フォルダー |
| `batchConcurrency` | `1` | フォルダー翻訳の要求並行数 |

カスタムフォルダー作成に失敗すると原フォルダーへ戻る場合があります。報告された実パスを確認してください。空のカスタム接尾辞は原ファイルを指し得るため、別出力には異なる接尾辞を使います。

## 例

目標を英語にし、中国語の短いコピーを試行フォルダーで翻訳します。`_en.md` と原文を並べ、専門語、数字、式、リンクを確認してからフォルダーへ拡大します。

## キャンセルと確認

後続処理を止めても既存訳は取り消されず、遠隔課金停止も保証しません。レポートと出力を確認します。Markdown 保持のプロンプトは要求であって、パーサーが意味同一性を保証するものではありません。

## ヒント

- 原文を保存し、名前の衝突を確認。
- 試行には別接尾辞とフォルダーを使用。
- 識別子、数学表記、URL、固有名を手作業で照合。
- 診断から非公開内容を除いて共有。
