# 概念ノート

<TLDR>
単独抽出は原文を読み、指定フォルダーへ概念 Markdown を作成します。フォルダーは初期状態で空。新規ノートはタイトルのみ、出典バックリンクは無効が既定です。リンク追加は別テンプレートを使います。
</TLDR>

## 概要

先に **概念ノートのフォルダーパス** を設定します。専用フォルダーで出力、重複、後の本文生成範囲を把握しやすくなります。抽出だけでは調査済みの説明は埋まりません。

## 仕組み

### 抽出の流れ

LLM に内容を送り、`CONCEPT:` を解析し、操作内で名前を重複除去してファイルを作成／更新します。長文は分割されます。失敗チャンクや未完成を調べ、モデル応答を網羅的な概念一覧とみなさないでください。

### 抽出プロンプト

既定は対象分野の具体的概念を求めます。分野指定や同義語抑制は標準用語を保証しません。カスタムでも `CONCEPT: Term` の出力契約を残します。[プロンプト](../advanced/custom-prompts)を参照してください。

### 分割

`chunkWordCount` の既定は `3000`。語数の近似で、token 予算ではありません。チャンク間の文脈が限られるため、関連語や曖昧な名称を確認します。

## ファイルの作成

### ファイル名

不適切なパス文字を除去し、空白を正規化し、長い名前を短縮します。空名は飛ばします。異なる句が同一名になり得るため大量生成前に確認します。

### テンプレート

新規の単独概念ノートは既定で：

```markdown
# Concept Name
```

新規ノートに出典リンクが必要なら **Add "Linked From" backlink** を有効、**Create minimal concept notes** を無効にします。完全形式：

```markdown
# Concept Name

## Linked From
- [[Source Note]]
```

リンク追加は概念出力が有効なら完全形式とバックリンクを使います。単独抽出のスイッチはこの動作を変更しません。

### 既存ノート

バックリンク有効時は既存 `## Linked From` に不足リンクを追加し、本文を保持し、同じリンクを重複追記しません。出典は basename のため同名ノートに注意します。

### 設定

| 設定 | 既定値 | 意味 |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | フォルダー指定後に概念出力を許可 |
| `conceptNoteFolder` | `''` | 初期フォルダーは未選択 |
| `extractConceptsMinimalTemplate` | `true` | 単独抽出をタイトルだけで作成 |
| `extractConceptsAddBacklink` | `false` | 単独抽出のバックリンク |
| `extractConceptsProvider` | `DeepSeek` | 個別ルート有効時のプロバイダー |
| `extractConceptsModel` | `''` | 空ならプロバイダーのモデル |
| `extractConceptsLanguage` | `en` | 個別言語有効時の出力言語 |
| `replaceSynonymsDuringConceptExtraction` | `false` | 同義語を避ける指示 |
| `generateConceptLogFile` | `false` | 任意の概念ログ |

## 重複の確認

ファイル名の大文字小文字、複数形、記号正規化、範囲で許す単語包含などのヒューリスティックです。意味の同一性は証明しません。不規則複数形や異なる技術的意味は手動確認します。

**重複を確認して削除** で候補を読み、必要な削除だけ承認します。Obsidian のゴミ箱操作を使います。概念フォルダーは使い捨てキャッシュではないため、整理前に保存します。

### 比較範囲

Vault 全体、概念フォルダー、含めるフォルダー、指定パスを除いた範囲を選べます。範囲は候補集合に影響しますが、重複の意味は変えません。

## 使い方

### 単独の概念抽出

Markdown を開き、フォルダーを確認して **概念を抽出（現在のファイル）** を実行します。原文は変えず、名前、抽出漏れ、バックリンクを点検します。

### 抽出後に本文生成

**タイトルから一括生成** を概念フォルダーで実行します。新規だけでなく既存の対象ノートも処理します。事前にフォルダーを確認し、後で complete 出力先を調べます。

### 選択語からリンク作成

選択アクションは選んだ語を wiki リンクにし、出力先があれば概念ノートを作れます。モデルによる全文選別ではなく、自分で語を指定したい場合に使います。

## ヒント

- 小さい原文と専用フォルダーで始める。
- 大量作成前に言語を決める。
- 同義語と重複候補は別に点検する。
- 次の実行で上書きされる前に必要なログを保存する。
