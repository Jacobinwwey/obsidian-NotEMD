# 図表の作成

<TLDR>
必要な**図表の種類**を選択し、その後**編集可能なソース形式**を選びます。Obsidian 内で完全な結果をプレビューし、Drawnix ボードや埋め込まれた Mermaid 可視化コンテンツも確認でき、各パネルを SVG、PNG、または PDF としてエクスポートできます。
</TLDR>

## 3つの選択肢の意味を理解する

| 選択肢 | 制御対象 | 例 |
|---|---|---|
| 図表の種類 | 図表が表す内容 | フローチャート、シーケンス図、回路図、データチャート |
| ソース形式 | Notemd によって作成される編集可能または再利用可能なファイル | Mermaid、JSON Canvas、Draw.io、Drawnix、CircuitikZ |
| エクスポート形式 | 共有用の画像や文書 | SVG、PNG、PDF |

Draw.io と Drawnix は図表の種類ではなく**ソース形式**です。CircuitikZ は回路図専用に設計されたソース形式です。同じプレビュー内容を複数の視覚的フォーマットにエクスポートできるため、CircuitikZ を選んでも SVG に限定されることはありません。

## ソース形式を選択する

| フォーマット | 最適な利用場面 | ソースファイル |
|---|---|---|
| Mermaid | Markdown 内に直接図表を記述したい場合 | Mermaid コードブロック |
| JSON Canvas | Obsidian のネイティブキャンバスワークフロー向け | `.canvas` |
| Draw.io | diagram.net や互換ツールで後から編集したい場合 | `.drawio` |
| Drawnix | 手書き風やホワイトボード風の編集が必要な場合 | `.drawnix` |
| CircuitikZ | 構造化された電気回路やトランジスタ回路を作成したい場合 | `.tex` |

特定のエディタを使用しない場合は、「**推奨ソース形式**」を **Auto** のままにしておきます。Notemd が選択された図表の種類に適したフォーマットを自動的に選びます。

## 図表の生成とエクスポート

1. ノートを開いて、可視化したいテキストを選択します。
2. Notemd のサイドバーまたはコマンドパレットから **図表を生成** を選択します。
3. **図表の種類**を選択するか、「自動検出」のままにします。
4. **ソース形式**を選択するか、「Auto」のままにします。編集可能なノードと埋め込まれた Mermaid 可視化コンテンツを含むナレッジマップが欲しい場合は **Drawnix** を選びます。
5. プレビューを確認します。複数パネルの結果では、Drawnix ボードとすべての Mermaid パネルがソースの順序通りに1つの垂直スクロール可能なプレビューシェル内に表示されます。Mermaid パネルはクリッピングされることなく、実際にレンダリングされた高さで表示されます。
6. 1つの可視化コンテンツごとにパネルの **SVG をエクスポート**、**PNG をエクスポート**、または **PDF をエクスポート** の操作を選択するか、すべてのパネルを1つの画像としてエクスポートします。複数のパネルがある場合は、ソースフォルダや Vault 相対のカスタムフォルダを指定します。Notemd は各パネルごとに一意なファイルを作成し、1つのエクスポートで失敗しても処理を続行します。
7. 編集可能なソースファイルも必要な場合は **ソースファイルを保存** を使用します。

「エクスポート」メニューには、現在の視覚的プレビュー用の **SVG をエクスポート**、**PNG をエクスポート**、および **PDF をエクスポート** の操作が用意されています。各パネルのヘッダーにも単一の Mermaid または Drawnix 可視化コンテンツ用の同じ操作が表示されるため、大きなプレビューを1つの不透明画像としてエクスポートする必要はありません。

プレビュー内で **History** を選択すると、図表を非表示にすることなく Vault の履歴ダイアラーが開きます。完了した図表を検索・フィルタリングしたり、プレビューを再開したり、保存されたファイルを開いたりできます。ノートがアクティブでなくても、コマンドパレットや Notemd のサイドバーから直接図表の履歴にアクセス可能です。

SVG と PDF はベクタージオメトリから生成されます。PDF ではプレビュー全体をラスタライズする代わりに、同じ SVG のレイアウトとテキストメトリックが使用されます。Notemd 設定内の画像エクスポート用 PPI は PNG のラスタライズのみを制御します（72～600 PPI、デフォルトは300）。

## 密度の高い図表でも読みやすいプレビュー

編集可能な HTML/SVG lane-grid 図は、タイトルと lane ヘッダーを配置する前に概要を計測して折り返します。ヘッダーは保護された概要領域の下へ移動し、セルはコネクターとエッジラベルより先に描画されます。lane をまたぐエッジには衝突を考慮した直交グリッド経路を使い、lane ラベルと占有セルの領域を確保するため、長い説明が文字を隠したり、理解のために横へパンしたりする必要がありません。

Mermaid の quadrant chart には family 固有の正規化処理が適用されます。`quadrantChart` では flowchart 専用の引用符・形状修復をスキップし、タイトル、軸、象限名に意図的に含めた角括弧はそのまま表示します。provider がコピーした開き角括弧は、点ラベル末尾の不一致文字である場合にだけ削除されます。

リポジトリには、実際の Vault で実行した全 executable diagram type の学習・証拠セットがあります。バイリンガル入力ノート、生成済み SVG/PNG、機械可読な status manifest は [`docs/diagram-examples/`](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) を参照してください。`passed` はロード済み plugin bundle を通した実行結果であり、静的な screenshot fixture ではありません。

## 埋め込まれた Mermaid を含む Drawnix プレビュー

Drawnix ファイルに Mermaid 可視化コンテンツが含まれている場合、Notemd はレンダリングされた SVG をサニタイズし、Mermaid のソースを `.drawnix` メタデータ内に保持します。そのため、Drawnix や Plait のランタイムがなくても、Drawnix ナレッジマップ内に Mermaid 画像を表示できます。安全に埋め込まれた Mermaid のみの可視化コンテンツは別途 `.assets` ディレクトリを作成しませんが、外部のバイナリメディアや解決されていない可視化コンテンツについては補助ファイルが保持されるため、データが失われることはありません。

プレビューは意図的に1つのスクロール可能な領域として構成されており、まずメインの Drawnix キャンバスが表示され、その後ソースの順序通りに各埋め込まれた Mermaid パネルが表示されます。保存された履歴エントリを閉じて再開しても、同じパネル一覧、サイズ、およびエクスポート操作が復元されます。

## 回路図

対応する回路図の作成には、「**回路図**」と「**CircuitikZ ソースファイル**」を選択します。Notemd はまず構造化された回路記述を生成し、その後 CircuitikZ のソースを書き出します。これはモデルに無制限の LaTeX を書かせるよりも信頼性が高い方法です。

現在の CircuitikZ へのサポートは意図的に限定されています。共通のソース構造を持つ NMOS アンプや対応している CMOS ブロックが最もうまく動作します。技術文書や出版物で生成された回路図を使用する前には、必ずプレビューとソースコードを確認してください。

SVG プレビューは Notemd によって生成されるレビュー用の補助コンテンツです。これはローカルに LaTeX や TikZJax がインストールされて `.tex` ファイルを正常にコンパイルできたことの証明ではありません。

**オプションとしてのネイティブコンパイル。** プラグイン内のプレビューや SVG、PNG、プレビュー用 PDF のエクスポートには LaTeX は不要です。デスクトップ環境では、コンパイル時の診断情報やネイティブな LaTeX PDF を作成したい場合は、図表設定またはコマンドパレットから **CircuitikZ ネイティブコンパイル環境**を開きます。Notemd はシステムの `tectonic` や `pdflatex` を再利用したり、カスタム実行ファイルを使用したり、「インストール」を明示的に選択した後に固定された管理対象の Tectonic ランタイムをインストールしたりできます。環境パネルでは進捗状況やエラーが即座に表示され、後から管理対象のランタイムを削除することも可能です。

## トラブルシューティング

### 結果が間違った図表の種類になっている

「自動検出」を使用せず、明示的に図表の種類を選択してください。回路図の場合は、「**回路図**」を選び、「図表を生成」というコマンドを使用し、古い形式の「Mermaid 図表として要約する」コマンドは避けてください。

### ソース形式が適切でない

ソース形式を **Auto** に戻すか、その図表の種類に適したフォーマットを選択してください。CircuitikZ は回路図専用であり、Draw.io と Drawnix は対応する構造化図表向けです。

### 「エクスポート」メニューが表示されない

SVG、PNG、PDF の作成には視覚的プレビューが必要です。ソーステキストのみが利用可能な場合は、ソースファイルを保存し、対応する外部ツールで開いてください。

### CircuitikZ ファイルが外部でコンパイルされない

**CircuitikZ ネイティブコンパイル環境**を開き、環境チェックを実行してください。管理対象のランタイムを修復するか、カスタムまたはシステムのコンパイラが `circuitikz` パッケージを取得できるかを確認してください。Notemd にはプラグインファイル内に完全な TeX ディストリビューションが含まれていません。
