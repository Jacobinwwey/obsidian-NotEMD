# Notemd 1.9.10 — 安全なプレビューと Vault ごとのローカル設定

<TLDR>
読み込んだ SVG のプレビューでは、動的コンテンツと外部リソースを除去し、中国語ラベルとパネルのスタイルを保持します。端末専用プロバイダーは Vault ごとに分離されます。設定から旧一覧を明示的に読み込むと、元の一覧と既存設定は保持されます。プレゼンテーションは共有利用者の終了を管理する loopback サーバーを使います。お気に入り保存やコピーの失敗を通知し、削除は Vault の設定に従います。PNG 互換性は既定で有効です。原図を保持し、必要な場合だけ検証済みの低 PPI コピーを追加します。Drawnix の関係数に固定上限はなく、プレゼンテーションの設定は独立したままです。同じ版のファイルをインストールして再読み込みし、一括処理前に一つのノートで確認してください。
</TLDR>
