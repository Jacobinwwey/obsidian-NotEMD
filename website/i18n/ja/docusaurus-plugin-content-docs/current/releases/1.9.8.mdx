# Notemd 1.9.8 更新ガイド

<TLDR>
1.9.8 はキャンセルと出力所有権、バッチ検索の一貫性、ネイティブ出力、正確な文書を重視します。公開 GitHub Release で提供状態を確認し、実行ファイルは同じリリースから取得します。プロバイダーや図の数は既存機能です。
</TLDR>

## 1.9.7 からの変更

| 分野 | 利用者への影響 |
| ------ | ------------- |
| キャンセル | 予定作業、転送、再試行へ共通状態を伝え、遅い応答の保護対象書き込みを停止 |
| 保存と復旧 | 同名原文や共有添付を含め、重複保存と復旧の所有関係を確認 |
| ローカル検索 | タイトルバッチで一定スナップショットを使い、保持メモリーと固定コーパスを測定 |
| ネイティブ出力 | PowerPoint の結合セル下罫線と CircuitikZ の配線／ラベルを修正 |
| 検証 | Linux／Windows CI、診断別 lint、プロセス境界、実アプリ証拠 |
| 文書 | 実際の既定値を説明し、利用者別入口、直接執筆の訳、制御された配信を提供 |

履歴検索は非同期更新中も連続入力とカーソルを保ちます。プレビュー内ドロワーは Tab を内部に限定し、読み込み中もフォーカスを持ち、Escape を親プレビューへ伝えません。再試行と古い応答にもブラウザー回帰があります。

36 プロバイダーと33図項目は 1.9.7 に既に存在しました。コード変更、文書、マージ記録を分けて二重計上を避けます。

調査と翻訳は最後の原文読み取りや出力フォルダー準備の後、追記・作成・上書きの直前にキャンセルを再確認します。Vault が受理済みの書き込みは完了結果に残ります。

翻訳先フォルダーの作成を待つ間に別のタスクが同じフォルダーを作成した場合、そのフォルダーを再利用し、このタスクが作成したものとして扱いません。同名のファイルがある場合やフォルダーが存在しない場合は、従来どおりエラーを報告し、原文のフォルダーへフォールバックします。

## 安全に更新

1. 作業を停止し、Vault と設定をバックアップ。
2. コミュニティプラグインから更新、または同じ公開 [1.9.8](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/tag/1.9.8) の `main.js`、`manifest.json`、`styles.css` を取得。
3. 手動では実行ファイルだけを置換し、設定と生成物を保持。
4. 再読み込みしてバージョン確認。
5. ノート一つ、次に小フォルダーを確認して大量処理を再開。

コマンド ID と設定は維持します。One-Click Extract は引き続きリンク、タイトル一括生成、Mermaid 修復です。文書訂正が調査ステップの追加を意味するわけではありません。

## キャンセルと復旧

キャンセルは取り消し処理ではありません。完了出力や受理済み外部書き込みは残り、生成と課金はサービス次第です。停止処理を待ち、出力を確認してから再実行します。

復旧の競合は明示されます。現在のノートと復旧ファイルを比較してから削除してください。新出力が画像を内包しても、旧成果物が参照する添付ディレクトリは保持します。

## 出力と互換性の限界

- PowerPoint 罫線には対象を絞ったネイティブ検査があり、スライド全体の画像スコアだけでは不十分です。
- PPTX の Mermaid／SVG は画像フォールバックになり、全図形が編集可能とは限りません。
- Drawnix の枝間関係は静的で、再配置後の接続を保証しません。
- CircuitikZ のプレビューと TeX コンパイルは別検証。
- 実機モバイルと Obsidian 0.15.0 は未検証。manifest の下限は検証結果ではありません。
- 語彙検索の固定データ証拠は意味検索や任意 Vault の性能を保証しません。

## リリースの完全性

公開器は版数、ローカル／リモート tag、クリーンソースを確認し再ビルドします。下書きへアップロードし、ダウンロードしたハッシュを検証後に公開します。資産は `main.js`、`manifest.json`、`styles.css`、`README.md`。無関係な内容へ無言で差し替える再試行はできません。

サイトは公開 Release の存在を確認してから配信します。訳は Codex が直接執筆・点検し、LM Studio や翻訳エンジンを呼びません。AI 執筆は独立した母語話者の校閲を意味しません。
