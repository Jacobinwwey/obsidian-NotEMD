# Eigene Prompts

<TLDR>
Eigene Prompts ersetzen den Standard nur bei aktivierter globaler und aufgabenspezifischer Option sowie nichtleerem Text. Erhalte den Ausgabevertrag selbst; ein automatisches Vorlagensystem stellt ausgelassene Formatanweisungen nicht wieder her.
</TLDR>

## Überblick

Teste zuerst den Standard. Lerndomäne oder Synonymbegrenzung können genügen. Passe den Prompt für eine konkrete Extraktionsregel, Struktur oder Übersetzungsart an und vergleiche vor einem Stapel.

## Ablauf

### Zusammensetzung

Notemd wählt Standard oder eigenen Prompt, ergänzt passende Domänen-/Sprachanweisungen und ersetzt von der Aufgabe bereitgestellte Variablen. Notiztext kann als eigene Nachricht gesendet werden. Recherchevariablen sind nicht automatisch überall verfügbar.

Ein eigener Prompt kann `CONCEPT:` oder Recherchebelege auslassen. Eine gültige Anfrage garantiert deshalb weder parsebare Ausgabe noch belegte Aussagen.

### Variablen

Verwende genaue Großschreibung und einfache Klammern:

| Aufgabe | Bereitgestellte Variablen |
| ------ | ----------------------- |
| Titelgenerierung | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Recherche-Zusammenfassung | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Übersetzung | `{LANGUAGE}`, `{TEXT}` |
| Originaltextextraktion | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` folgt der Aufgaben-Sprachregel. Links und eigenständige Konzepte senden Text als Aufgabeninhalt; dafür keine Variable erfinden. Unbekannte Namen werden nicht magisch gefüllt. Diese Ersetzungen sind keine Konzeptdateivorlagen.

### Lerndomäne

Aktiviere fokussiertes Lernen und gib beispielsweise `Elektrotechnik` an. Die Anweisung `Relevant Fields` lenkt die Aufmerksamkeit, ist aber kein harter Filter für fachfremde Begriffe.

## Einstellungen

| Aufgabe | Aktivierung | Promptfeld |
| ------ | --------------- | -------------- |
| Links | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titelgenerierung | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Recherche | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid-Zusammenfassung | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Konzepte | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Übersetzung | `useCustomPromptForTranslate` | `translatePrompt` |
| Originaltext | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Alle benötigen `enableGlobalCustomPrompts`. Leerer Text fällt auf den Standard zurück. Zusammengeführte Originaltextextraktion hat ein eigenes eingebautes Format und nutzt nicht die gewöhnliche Überschreibung. Diagrammgenerierung hat typisierte Anforderungen; der Mermaid-Prompt ist kein universeller Diagrammprompt.

## Beispiel

Globale und Konzeptextraktionsoption einschalten und den Parsermarker bewahren:

```text
Extrahiere die zentralen elektrotechnischen Konzepte aus der Notiz.
Bevorzuge konkrete Bauteile und physikalische Mechanismen vor allgemeinen Begriffen.
Gib ein Konzept je Zeile exakt in dieser Form aus:
CONCEPT: Begriffsname
Keine Erklärungen oder umschließenden Codeblöcke hinzufügen.
```

Teste eine Kopie, prüfe Einträge, Dateinamen und fehlende Konzepte und vergleiche mit dem Standard. Alten Prompt vor Änderungen sichern.

## Tipps

- Eine Aufgabe einzeln prüfen, bevor der Umfang wächst.
- Quellenkontext und wörtliche Extrakte erhalten.
- Prosa übersetzen, ausführbare IDs und Ausgabemarker stabil halten.
- Nach Anbieter-/Modellwechsel neu prüfen; Anweisungen ersetzen keine Validierung.
