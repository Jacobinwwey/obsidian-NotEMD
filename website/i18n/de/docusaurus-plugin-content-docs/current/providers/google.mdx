# Google-Anbieter

<TLDR>
Das Google-Profil nutzt die native Gemini Generative Language API. Konfiguriere einen dafür berechtigten Schlüssel und verfügbares Modell. Gemini hinter einem OpenAI-kompatiblen Gateway nutzt dessen Profil.
</TLDR>

## Einrichtung

Wähle **Google**, Schlüssel, native Adresse und ein Modell für diese API-Version. **Verbindung testen** ausführen und eine Testnotiz übersetzen oder bearbeiten. Das Profil richtet beliebige Google-Cloud-/Vertex-Deployments nicht automatisch ein.

## Adresse und Authentifizierung

| Feld | Voreinstellung |
| ------- | -------------- |
| Transport | `google` |
| API-Schlüssel | Erforderlich |
| Basis-URL | `https://generativelanguage.googleapis.com/v1` |
| Modell | `gemini-2.0-flash-exp` |
| Temperatur | `0.5` |
| Verbindungstest | `chat-only` |

Die Laufzeit baut native `generateContent`-Anfragen mit API-Schlüssel. Der historische Modellname garantiert keine heutige Verfügbarkeit. Diagnose-URLs vor Weitergabe kontrollieren, da Anfrageinformationen Zugangsdaten enthalten können.

## Modelle finden

Native Google-Modellerkennung verwenden und Generierung auf der konfigurierten API-Version prüfen. Eine leere Liste kann Rechte-, Adress- oder Verfügbarkeitsprobleme bedeuten. Protokolle nicht ohne Diagnose wechseln.

## Fehlerbehebung

- `400`: Modell-ID, Parameter, Token-/Ausgabelimits.
- `401`/`403`: Schlüsselregeln, API-Aktivierung und Modellrechte.
- `404`: Modell auf gewählter API-Version verfügbar?
- Gateway-Beispiel scheitert: passendes OpenAI-kompatibles Profil nutzen.

## Geeigneter Einsatz

Für native Gemini-API. Übersetzung, Recherche oder Diagramm an eigener Stichprobe testen. Keine pauschale Geschwindigkeits-, Kosten- oder Qualitätszusage.
