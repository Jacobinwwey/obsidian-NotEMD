# Workflows

<TLDR>
Workflows führen bestehende Aktionen nacheinander aus. Sie können einen Ordnerdialog oder aktiven Editor verlangen. Es handelt sich nicht um eine Text-Pipeline: Eingaben, Ausgaben und Nebenwirkungen bleiben aufgabenspezifisch. Beginne mit Testnotiz und eigenem Ordner.
</TLDR>

## Überblick

Ausgelieferte **One-Click Extract**-Definition:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Aktive Notiz verlinken und bei konfiguriertem Konzeptordner Konzepte anlegen.
2. Geeignete vorhandene und neue Notizen im Konzept- oder ausgewählten Ordner aus Titeln ergänzen.
3. Mermaid im complete-Ordner dieses Stapels reparieren.

Die Standardkette enthält keine Webrecherche. Titelgenerierung recherchiert nur bei separat aktivierter Option. Siehe [Stapelverarbeitung](../advanced/batch-processing).

## Ablauf

### Ausführung

Schritte laufen sequenziell, mit Status und Fehlern in der Seitenleiste. Abbruch stoppt weitere Schritte und unterstützte Anfragen. Fertige Schreibvorgänge bleiben; es gibt kein Alles-oder-nichts-Rollback.

Anfangs wird der konfigurierte Konzeptordner bevorzugt. Stapelgenerierung hält Quell- und complete-Ordner fest; die folgende Mermaid-Reparatur nutzt complete. Andere Aktionen behalten ihre Datei-, Auswahl- und Dialogvoraussetzungen.

### DSL

Eine benannte Schaltfläche je Zeile: `::` trennt Name und Aktionen, `>` die IDs. Leerzeilen und Zeilen ab `#` werden ignoriert, unbekannte IDs abgelehnt.

```text
Extrahieren und darstellen::extract-concepts-current>summarize-as-mermaid
```

Builder oder direkte DSL-Eingabe nutzen. IDs bleiben stabil, UI-Bezeichnungen folgen der Sprache. Ordneraktionen haben eigene IDs, keine allgemeine Umbenennungsregel.

| ID | Aktion / Voraussetzung |
| ------------ | ----------------------- |
| `process-current-add-links` | Aktive Notiz verlinken |
| `process-folder-add-links` | Notizen eines Ordners verlinken |
| `extract-concepts-current` | Konzepte aus aktiver Notiz |
| `extract-concepts-folder` | Konzepte aus gewähltem Ordner |
| `generate-from-title` | Inhalt aus aktivem Titel |
| `batch-generate-from-titles` | Geeignete Ordnernotizen aus Titeln ergänzen |
| `research-and-summarize` | Auswahl oder Titel im Markdown-Editor recherchieren |
| `summarize-as-mermaid` | Unterstützte aktive Eingabe als Mermaid zusammenfassen |
| `generate-diagram` | Diagramm aus unterstützter Eingabe erzeugen |
| `preview-diagram` | Unterstützte Diagrammquelle oder Artefakt öffnen |
| `translate-current-file` | Aktive unterstützte Datei übersetzen |
| `batch-translate-folder` | Gewählten Ordner übersetzen |
| `extract-original-text` | Gewünschte Originalpassagen extrahieren |
| `batch-extract-original-text` | Passagen aus geeigneten Ordnerdateien extrahieren |
| `split-note-by-chapters` | Aktive Notiz nach Kapiteln teilen |
| `batch-mermaid-fix` | Mermaid-Blöcke eines Ordners reparieren |
| `fix-formula-current` | Formelbegrenzer der aktiven Notiz normalisieren |
| `batch-fix-formula` | Formelbegrenzer im Ordner normalisieren |

### Standard und eigene Schaltflächen

One-Click Extract wird mitgeliefert; weitere Definitionen stammen von dir. Benenne die Schaltfläche in den Einstellungen, ordne Aktionen und prüfe ihren Tooltip. Parserfehler vor dem Lauf korrigieren.

## Einstellungen

| Einstellung | Standard | Wirkung |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Beim ersten gemeldeten Schrittfehler stoppen |
| `useMultiModelSettings` | `false` | Aktiven Anbieter nutzen, bis Aufgabenrouting aktiviert wird |
| `enableResearchInGenerateContent` | `false` | Recherche in Titelgenerierung nur nach Aktivierung |

`continue_on_error` führt spätere Schritte trotz Fehler aus. Nur einsetzen, wenn die verbleibenden Eingaben ausreichen; Teilabschluss wird dadurch nicht zum Gesamterfolg.

### Aufgabenmodelle

Jede Aktion behält ihre Modellwahl. Leere Überschreibungen übernehmen das Modell des gewählten Anbieters. Vor privaten Inhalten jede Route prüfen.

## Beispiel

Lege `trial-concepts` leer an und starte mit einer Testnotiz. Prüfe Konzepte und gemeldeten complete-Ordner. Führe bei unklaren Zielen zunächst Einzelaktionen aus, bevor du den Umfang erweiterst.

## Tipps

- Kurze, nachvollziehbare Ketten bevorzugen.
- Interaktive Lösch-/Bereinigungsaktionen nicht unbeaufsichtigt einplanen.
- Nach Abbruch oder Konflikt Dateien und Protokoll prüfen.
- Exakten Anbieter und Umfang testen; Verbindungserfolg garantiert keine Quoten für lange Stapel.
