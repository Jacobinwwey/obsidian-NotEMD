# Fluxos de trabalho

<TLDR>
Um fluxo executa ações existentes em ordem. Pode exigir editor ativo ou seleção de pasta. Cada ação mantém entradas, saídas e efeitos; não é uma cadeia arbitrária de texto. Começar com nota descartável e pasta dedicada.
</TLDR>

## Visão geral

Definição incluída de **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Adicionar links à nota ativa e conceitos se houver pasta configurada.
2. Gerar conteúdo nas notas elegíveis, novas ou existentes, da pasta conceptual ou selecionada.
3. Reparar Mermaid na pasta complete resultante.

Não inclui pesquisa Web por padrão. A geração pode pesquisar se a sua opção separada estiver ativa. Ver [lotes](../advanced/batch-processing).

## Funcionamento

### Execução

As etapas são sequenciais, com progresso e falhas apresentados. Cancelar impede etapas posteriores e propaga-se a pedidos suportados. Escritas concluídas permanecem; não existe reversão global.

A pasta conceptual configurada é preferida inicialmente. Geração por lote regista origem e complete; a reparação Mermaid seguinte usa complete. Outras ações mantêm requisitos de documento ativo, seleção ou diálogo.

### DSL

Uma linha por botão. `::` separa nome e ações; `>` separa IDs. Linhas vazias ou iniciadas por `#` são ignoradas; ações desconhecidas são rejeitadas.

```text
Extrair e representar::extract-concepts-current>summarize-as-mermaid
```

Usar o construtor ou editar a DSL. IDs são estáveis e nomes visíveis seguem o idioma da interface. Variantes de pasta têm IDs próprios, não uma substituição genérica.

| Identificador | Ação / requisito |
| ------------ | ----------------------- |
| `process-current-add-links` | Adicionar links à nota ativa |
| `process-folder-add-links` | Adicionar links numa pasta |
| `extract-concepts-current` | Extrair conceitos da nota ativa |
| `extract-concepts-folder` | Extrair conceitos de pasta |
| `generate-from-title` | Gerar conteúdo pelo título ativo |
| `batch-generate-from-titles` | Gerar notas elegíveis de pasta por títulos |
| `research-and-summarize` | Pesquisar seleção/título em editor Markdown |
| `summarize-as-mermaid` | Resumir entrada ativa suportada em Mermaid |
| `generate-diagram` | Selecione vários tipos de diagrama numa execução e vários formatos independentes para cada tipo. Desmarcar um tipo conserva os seus formatos; sem seleção, o conteúdo é analisado automaticamente. |
| `preview-diagram` | Pré-visualizar fonte ou artefacto compatível |
| `translate-current-file` | Traduzir documento ativo suportado |
| `batch-translate-folder` | Traduzir pasta |
| `extract-original-text` | Extrair passagens originais pedidas |
| `batch-extract-original-text` | Extrair passagens de documentos elegíveis |
| `split-note-by-chapters` | Dividir nota ativa por capítulos |
| `batch-mermaid-fix` | Reparar Mermaid em pasta |
| `fix-formula-current` | Normalizar delimitadores de fórmulas ativos |
| `batch-fix-formula` | Normalizar fórmulas em pasta |
| `check-duplicates-current` | Verificar duplicados da nota ativa |
| `check-remove-duplicate-concepts` | Rever e remover conceitos duplicados com interação |
| `test-llm-connection` | Testar fornecedor |
| `probe-slide-export-env` | Verificar ambiente local de slides |
| `export-slides` | Exportar documento ativo como slides |

### Botões próprios

One-Click Extract é incluído. Outros botões são definições próprias. Dar nome, escolher e ordenar ações e verificar a descrição na barra lateral. Corrigir erros de análise antes de executar.

## Ajustes

| Ajuste | Padrão | Efeito |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Parar no primeiro erro de etapa comunicado |
| `useMultiModelSettings` | `false` | Usar fornecedor ativo até ativar rotas por tarefa |
| `enableResearchInGenerateContent` | `false` | Excluir pesquisa da geração por títulos salvo ativação |

`continue_on_error` permite etapas seguintes apesar de falha. Usar apenas se puderem trabalhar com entradas restantes; não converte resultado parcial em sucesso total.

### Modelos por tarefa

Cada ação mantém a sua escolha. Modelo específico vazio usa o do fornecedor. Verificar todas as rotas antes de tratar dados privados.

## Exemplo

Definir `trial-concepts` vazia e processar uma nota de teste. Verificar conceitos e complete. Executar ações separadamente se destinos não estiverem claros; só depois ampliar o âmbito.

## Conselhos

- Manter cadeias curtas com falhas e saídas atribuíveis.
- Evitar limpeza/apagamento sem supervisão; confirmações continuam necessárias.
- Após cancelamento ou conflito, inspecionar relatório e resultados.
- Testar modelo e seleção exatos; conexão válida não garante quota para lote longo.
