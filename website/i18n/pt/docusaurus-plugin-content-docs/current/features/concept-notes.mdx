# Notas de conceitos

<TLDR>
Extração independente lê a origem e cria conceitos Markdown numa pasta escolhida, cujo ajuste começa vazio. As novas notas têm apenas título e nenhum backlink por padrão. Adicionar links usa outra forma de nota.
</TLDR>

## Visão geral

Definir **Caminho da pasta de notas de conceito** antes de extrair. Uma pasta dedicada facilita revisão, duplicados e geração posterior. Extrair não preenche automaticamente cada nota com explicação pesquisada.

## Funcionamento

### Extração

O LLM recebe o texto; entradas `CONCEPT:` são analisadas, nomes deduplicados dentro da operação e documentos criados/atualizados. Notas longas são divididas. Consultar falhas parciais; a resposta não garante inventário completo.

### Prompt

O prompt integrado pede conceitos específicos do tema. Domínio e redução de equivalências orientam sem garantir vocabulário canónico. Um prompt próprio deve manter `CONCEPT: Term`. Ver [prompts](../advanced/custom-prompts).

### Divisão

`chunkWordCount` vale 3000 palavras aproximadas, não tokens do fornecedor. Contexto entre partes é limitado; rever nomes ambíguos e conceitos relacionados.

## Criação

### Nomes

Caracteres de caminho incompatíveis são removidos, espaços normalizados e nomes longos truncados. Nomes vazios são omitidos. Expressões diferentes podem convergir no mesmo nome; verificar antes de criar grandes coleções.

### Formas de nota

Forma mínima inicial:

```markdown
# Nome do conceito
```

Para backlinks em novas notas independentes, ativar **Add "Linked From" backlink** e desativar **Create minimal concept notes**:

```markdown
# Nome do conceito

## Linked From
- [[Nota de origem]]
```

A tarefa de links cria a forma completa quando a pasta conceptual está ativa. As opções da extração independente não alteram esse comportamento.

### Notas existentes

Com backlinks ativos, acrescenta-se a fonte em falta sob `## Linked From`, preservando o corpo e sem repetir a mesma ligação. A referência usa basename; verificar fontes homónimas.

### Ajustes

| Ajuste | Padrão | Efeito |
| --------- | --------- | -------- |
| `useCustomConceptNoteFolder` | `true` | Permitir conceitos após escolher pasta |
| `conceptNoteFolder` | `''` | Nenhuma pasta inicial |
| `extractConceptsMinimalTemplate` | `true` | Notas independentes apenas com título |
| `extractConceptsAddBacklink` | `false` | Backlinks na extração independente |
| `extractConceptsProvider` | `DeepSeek` | Fornecedor com rotas por tarefa |
| `extractConceptsModel` | `''` | Usar modelo do fornecedor se vazio |
| `extractConceptsLanguage` | `en` | Idioma com opções por tarefa |
| `replaceSynonymsDuringConceptExtraction` | `false` | Adicionar instrução contra termos equivalentes |
| `generateConceptLogFile` | `false` | Gerar registo conceptual opcional |

## Duplicados

A verificação usa heurísticas de nomes: maiúsculas, plurais, símbolos e inclusão de uma palavra conforme o âmbito. Não prova equivalência semântica. Rever plurais irregulares e sentidos técnicos distintos.

Em **Verificar e remover duplicados**, inspecionar candidatos e confirmar apenas os pretendidos. Os documentos aprovados são enviados para o lixo do Obsidian. A pasta não é cache descartável; fazer backup antes de limpar.

### Âmbitos

Comparar com cofre, pasta conceptual, pastas incluídas ou âmbito com exclusões. Confirmar o alcance antes de aprovar. A seleção muda candidatos, não a definição de duplicado.

## Uso

### Extrair de forma independente

Abrir Markdown, confirmar pasta e executar **Extrair conceitos (arquivo atual)**. A origem fica intacta. Verificar nomes, cobertura e backlinks.

### Extrair e gerar conteúdo

**Gerar em lote a partir dos títulos** pode preencher notas novas e anteriores elegíveis. Rever pasta antes e destino complete depois.

### Link por seleção

A ação de seleção pode criar link e nota para o termo escolhido, com destino configurado. A pessoa escolhe o conceito em vez de pedir extração do documento inteiro.

## Conselhos

- Fonte pequena e pasta dedicada.
- Escolher idioma antes de ampliar a coleção.
- Rever equivalências e duplicados separadamente.
- Preservar registos necessários antes de nova execução que os substitua.
