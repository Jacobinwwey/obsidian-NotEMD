# Prompts personalizados

<TLDR>
Um prompt próprio substitui o integrado quando as opções global e da tarefa estão ativas e o texto não está vazio. Manter o contrato de saída; não existe reposição automática de todas as instruções omitidas.
</TLDR>

## Visão geral

Testar primeiro o padrão. Domínio focalizado ou redução de equivalências podem bastar. Personalizar política, estrutura ou estilo e comparar antes de um lote.

## Funcionamento

### Composição

Notemd escolhe prompt integrado ou próprio, acrescenta instruções aplicáveis de domínio/idioma e substitui variáveis fornecidas pela tarefa. Conteúdo pode ser enviado como mensagem separada. Variáveis não são universais.

Substituição pode retirar `CONCEPT:` ou contexto pesquisado. Pedido válido não garante saída analisável nem afirmações apoiadas em fontes.

### Variáveis

Usar maiúsculas exatas e chavetas simples:

| Tarefa | Variáveis fornecidas |
| ------ | ----------------------- |
| Geração por título | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Resumo de pesquisa | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Tradução | `{LANGUAGE}`, `{TEXT}` |
| Extração original | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` segue a política da tarefa. Links e conceitos independentes enviam o texto como conteúdo; não inventar variável. Nomes desconhecidos não são preenchidos. Não são modelos de documentos de conceitos.

### Domínio focalizado

Ativar aprendizagem focalizada e indicar, por exemplo, `engenharia elétrica`. A instrução `Relevant Fields` orienta o modelo, mas não impõe filtro absoluto.

## Ajustes

| Tarefa | Ativação | Campo de prompt |
| ------ | --------------- | -------------- |
| Links | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Títulos | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Pesquisa | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Resumo Mermaid | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Conceitos | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Tradução | `useCustomPromptForTranslate` | `translatePrompt` |
| Texto original | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Todos exigem `enableGlobalCustomPrompts`. Texto vazio volta ao integrado. Extração original agregada usa formato próprio e não a substituição comum. Geração de diagramas exige saída tipada; o prompt Mermaid não é universal.

## Exemplo

Ativar opções global e de conceitos e conservar o marcador:

```text
Extrair os conceitos centrais de engenharia elétrica da nota fornecida.
Preferir componentes concretos e mecanismos físicos a nomes genéricos.
Devolver um conceito por linha neste formato exato:
CONCEPT: Nome do termo
Não acrescentar explicações nem um bloco de código envolvente.
```

Testar uma cópia e verificar entradas, nomes e omissões. Comparar com o padrão e preservar o prompt anterior para restaurar.

## Conselhos

- Testar uma tarefa antes de ampliar lotes.
- Preservar contexto de pesquisa e citações exatas.
- Traduzir instruções sem mudar IDs ou marcadores.
- Rever após trocar modelo; instruções não substituem validação.
