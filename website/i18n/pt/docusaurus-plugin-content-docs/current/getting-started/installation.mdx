# Instalação

<TLDR>
Instalar **Notemd** pelos plugins da comunidade ou copiar os três componentes da mesma versão GitHub para o cofre. Ativar, configurar um fornecedor e verificar uma nota de teste. Servidores locais e exportadores nativos têm requisitos próprios.
</TLDR>

## Método 1: plugins da comunidade (recomendado)

1. Abrir **Settings → Community plugins** no cofre pretendido.
2. Permitir plugins da comunidade, se necessário, e escolher **Browse**.
3. Procurar **Notemd**, confirmar `Jacobinwwey/obsidian-NotEMD` e selecionar **Install**.
4. Selecionar **Enable** e abrir a barra lateral pelo ícone ou pela paleta de comandos.

[Abrir Notemd no Obsidian](obsidian://show-plugin?id=notemd). Se o navegador não reconhecer o protocolo, seguir os passos acima.

## Método 2: instalação manual

### Requisitos

Ter Obsidian instalado e um cofre com possibilidade de cópia de segurança. O manifesto declara `0.15.0` como versão mínima; isso não comprova testes atuais nessa versão antiga.

### Passos

1. Obter `main.js`, `manifest.json` e `styles.css` da mesma [versão GitHub](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). O `README.md` é referência, não requisito de execução.
2. Copiar para `<vault>/.obsidian/plugins/notemd/`; adaptar `.obsidian` caso o cofre use outro diretório de configuração.
3. Recarregar Obsidian e ativar Notemd.
4. Confirmar a versão apresentada; não combinar manifesto novo com bundle antigo.

## Alternativa: BRAT

Quem já utiliza [BRAT](https://github.com/TfTHacker/obsidian42-brat) pode adicionar `Jacobinwwey/obsidian-NotEMD` no fluxo beta. Usar uma versão específica para reproduzir falhas. BRAT é opcional.

## Verificação

Selecionar fornecedor/modelo acessíveis e executar **Testar ligação**. Depois seguir o [início rápido](./quick-start) com uma cópia de nota. Alguns testes apenas verificam a lista de modelos; uma tarefa real verifica geração e escrita.

## Requisitos do sistema

| Área | Limite |
| --------- | ---------- |
| Manifesto | Mínimo declarado `0.15.0`; `isDesktopOnly` é false |
| Evidência de validação | Consultar a aceitação datada; dispositivos móveis físicos e Obsidian 0.15.0 sem validação atual |
| LLM hospedado | Rede, conta/chave autorizadas e modelo compatível |
| LLM local | Servidor instalado e ativo com modelo preparado |
| Exportação nativa de slides/circuitos | Ferramentas de desktop e dependências do formato; verificar o ambiente antes de exportar |

Não existe garantia geral de versão do sistema operativo para todos os exportadores. Pré-visualizar um circuito não comprova compilação TeX; testar no desktop não valida dispositivos móveis.

## Desinstalação

Desativar ou remover o plugin. As notas e os artefactos continuam no cofre; verificar antes de apagar. Guardar os ajustes para reinstalação. Desinstalar não desfaz edições concluídas.

## Atualização

Usar **Check for updates**. Manualmente, parar tarefas, criar cópia de segurança do cofre e ajustes, substituir os três componentes da mesma versão e recarregar. Ler as notas da versão e testar uma nota antes dos lotes.

Não substituir a configuração do cofre por um componente do Release. Para regressar a uma versão anterior, escolher uma versão compatível conhecida e conservar resultados necessários.
