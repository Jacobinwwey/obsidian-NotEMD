# Fornecedor Google

<TLDR>
O perfil Google usa Gemini Generative Language nativo. Introduzir chave autorizada e modelo disponível. Gemini por gateway OpenAI-compatible usa o perfil desse gateway.
</TLDR>

## Preparação

Selecionar **Google**, chave, endpoint nativo e modelo da versão API correspondente. Testar conexão e nota. Não configura automaticamente deployments arbitrários de Google Cloud ou Vertex.

## Endpoint e autenticação

| Campo | Valor inicial |
| ------- | -------------- |
| Transporte | `google` |
| Chave API | Obrigatória |
| URL base | `https://generativelanguage.googleapis.com/v1` |
| Modelo | `gemini-2.0-flash-exp` |
| Temperatura | `0.5` |
| Teste de conexão | `chat-only` |

É criado um pedido `generateContent` com chave API. O ID histórico não garante disponibilidade. Rever URLs antes de partilhar diagnósticos, pois detalhes podem conter autenticação.

## Modelos

Usar descoberta nativa e confirmar geração na API selecionada. Lista vazia pode indicar permissões, endpoint ou modelo ausente. Não mudar protocolos sem diagnóstico.

## Problemas

- `400`: ID, parâmetros e limites de tokens/saída.
- `401`/`403`: restrições da chave, API ativa e direitos.
- `404`: modelo disponível nessa versão API?
- Exemplos de gateway: usar o perfil OpenAI-compatible correspondente.

## Quando utilizar

Para Gemini nativo. Avaliar tradução, pesquisa ou diagramas com amostra própria. Sem promessa universal de rapidez, custo ou qualidade.
