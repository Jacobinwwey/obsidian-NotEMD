# উইকি লিংক

<TLDR>Process file (add links) নির্বাচিত LLM-কে ধারণা চিনে Obsidian লিংক যোগ করতে বলে। ডিফল্টে আলাদা `_processed.md` হয়, মূল থাকে। Concept files-এর জন্য folder নির্বাচন দরকার। কাজের পরিসর বাড়ানোর আগে ফল দেখুন।</TLDR>

## সারসংক্ষেপ

মডেল বেছে নেওয়া শব্দ run অনুযায়ী বদলাতে পারে এবং আগে ফাইল নেই এমন ধারণাকেও লিংক করতে পারে। Link একটি navigation target, ধারণা সমান বা ব্যাখ্যা সঠিক হওয়ার প্রমাণ নয়।

## কীভাবে কাজ করে

### প্রক্রিয়া

নোট chunk করে provider/model-এ পাঠানো হয়, উত্তর মিলে processed output লেখা হয়। নির্দিষ্ট folder-এ concept files তৈরি বা আপডেট হতে পারে। Partial failure ও প্রকৃত destination রিপোর্টে দেখুন।

### উদাহরণ

মূল:

```text
মেশিন লার্নিং ধরন চিনতে নিউরাল নেটওয়ার্ক ব্যবহার করে।
```

সম্ভাব্য ফল:

```markdown
[[মেশিন লার্নিং]] ধরন চিনতে [[নিউরাল নেটওয়ার্ক]] ব্যবহার করে।
```

এটি উদাহরণ; source, model ও prompt অনুযায়ী নির্বাচিত শব্দ বদলায়।

## ব্যবহার

### সক্রিয় নোট

কপি করা Markdown-এ **Process file (add links)** চালিয়ে পাশের `_processed.md` দেখুন। Custom suffix, processed folder ও original-moving setting destination বদলাতে পারে।

### একাধিক নোট

**Process folder (add links)**-এ folder ও scope নিশ্চিত করে ছোট নমুনা নিন। সব folder task-এর এক overwrite/skip switch নেই। [Batch](../advanced/batch-processing) দেখুন।

### নিজের নির্বাচিত শব্দ

**Create wiki link and generate note from selection** আলাদা কাজ। এটি whole-file add-links-কে selection-এ সীমিত করে না। তৈরি concept note ও content পরীক্ষা করুন।

## লিংকের পদ্ধতি বাছা

Content থেকে নতুন ধারণা পেতে model সহায়ক। বিদ্যমান note titles-এর সঙ্গে repeatability গুরুত্বপূর্ণ হলে deterministic matching দেখুন। অন্য plugin-কে বর্তমান docs ও একই তারিখযুক্ত sample দিয়ে তুলনা করুন।

## সুবিধা

### সমার্থক কমানো

`replaceSynonymsDuringConceptExtraction` কাছাকাছি ধারণা এড়ানোর নির্দেশ যোগ করে। এটি শুরুতে বন্ধ Boolean, সংখ্যাভিত্তিক similarity threshold নয়। সংক্ষিপ্ত রূপ ও অর্থভেদ নিজে দেখুন।

### লিংক অখণ্ডতা

Rename-এর সময় link updates Obsidian-এর setting ও ব্যবহৃত operation-এর দায়িত্ব। Target মুছলে unresolved link থাকতে পারে; তা unlinked mention নয়। অন্য folder-এর একই basename পরীক্ষা করুন।

### স্বাধীন extraction

মূল না লিখে concept files চাইলে **Extract concepts (current file)** নিন। Minimal form ও backlink controls add-links থেকে আলাদা। [Concept notes](./concept-notes)।

## ধারণার ফাইল

### স্বয়ংক্রিয় তৈরি

Concept output চালু ও path নির্ধারিত হলে title ও `Linked From`-সহ নোট হতে পারে। গবেষণাভিত্তিক ব্যাখ্যা, related-concepts section বা সাধারণ frontmatter template নিজে থেকে আসে না। পূর্ণ content আলাদা title generation দিয়ে করুন।

### সেটিংস

Concept folder, processed folder, suffix ও মূল সরানোর বিকল্প খুঁজুন। Concept folder প্রথমে ফাঁকা। পরীক্ষার output source collection থেকে আলাদা রাখুন।

## উন্নত বিকল্প

### Context ও prompt

`chunkWordCount` আনুমানিক chunk size। Focused domain ও নিজের prompt ধারণা সীমিত করতে পারে। Sentence/paragraph context selector, minimum-occurrence threshold বা সাধারণ concept-template variable এখানে নথিভুক্ত বৈশিষ্ট্য নয়।

## ভালো অভ্যাস

- উদ্ধৃতি, formula ও code মূলের সঙ্গে মেলান।
- নতুন linked term-এর আলাদা concept দরকার কি না দেখুন।
- একই sample-এ prompt বদল পরীক্ষা করুন।
- মূল সরানো বা পুরোনো destination-এ আবার লেখার আগে backup নিন।

## কর্মক্ষমতা

Latency ও খরচ provider, model, input/output এবং retries-এর উপর নির্ভর করে। প্রতি নোট সময় বা শত নোটের নির্দিষ্ট দাম নেই। নিজের sample ও actual account usage মাপুন।

## সমস্যা

### লিংক নেই

Request, model response, নির্দিষ্ট source ও reported output দেখুন। উপকারী লিংক নিশ্চিত করার minimum word count নেই।

### অতিরিক্ত লিংক

Prompt বা domain ছোট করুন। Synonym suppression মডেলকে নির্দেশ দেয়, vocabulary বাধ্যতামূলক করে না।

### Rename-এর পর ভাঙা লিংক

Obsidian update setting ও আগের ambiguity দেখুন, তারপর target মেরামত করুন। LLM আবার চালানো deterministic link repair নয়।
