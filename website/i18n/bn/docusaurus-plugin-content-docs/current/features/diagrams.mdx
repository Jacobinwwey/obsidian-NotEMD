# চিত্র ও ডায়াগ্রাম

<TLDR>আগে diagram type, পরে editable source format বাছুন। Obsidian-এ Drawnix board ও embedded Mermaid-সহ পুরো preview দেখুন। প্রতিটি panel SVG, PNG বা PDF-এ export করা যায়।</TLDR>

## তিনটি নির্বাচন

| নির্বাচন | যা নির্ধারণ করে | উদাহরণ |
| --- | --- | --- |
| Diagram type | Diagram-এর অর্থ | Flowchart, sequence, circuit, data chart |
| Source format | Editable বা reusable file | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Export format | শেয়ারের image/document | SVG, PNG, PDF |

Draw.io ও Drawnix source formats, diagram types নয়। CircuitikZ circuit-এর source; সেটি বাছলে visual export কেবল SVG-তে আটকে যায় না।

## Source format বাছা

| Format | উপযুক্ত কাজ | Source file |
| --- | --- | --- |
| Mermaid | Markdown-এর ভেতরের diagrams | Mermaid-এর code block |
| JSON Canvas | Native Obsidian canvas | `.canvas` |
| Draw.io | diagrams.net বা compatible editor-এ সম্পাদনা | `.drawio` |
| Drawnix | হাতে আঁকা/whiteboard-style সম্পাদনা | `.drawnix` |
| CircuitikZ | Structured electrical/transistor circuits | `.tex` |

নির্দিষ্ট editor না চাইলে **Preferred source format**-এ **Auto** রাখুন। Notemd type অনুযায়ী compatible format নেয়।

## তৈরি ও export

1. Supported source note খুলুন। শুধু passage চাইলে আলাদা note বানান; selection file action ছোট করে না।
2. Type বা **Auto-detect** নিন।
3. Source বা **Auto** নিন; Drawnix supported map-এ editable nodes ও Mermaid রাখে।
4. **Generate diagram** চালান।
5. একই vertical scroll preview-এ board ও source-order Mermaid panels দেখুন; panels প্রকৃত rendered height ব্যবহার করে।
6. Panel-এর **Export SVG**, **Export PNG**, **Export PDF** অথবা উপরের all-panel export নিন। Source/custom Vault-relative folder দিন; প্রতি panel deterministic file হয় এবং individual failure-এর পরে চলতে থাকে।
7. **Save source file** দিয়ে editable artifact রাখুন।

Export menu ও panel header একই তিনটি action দেয়। **History** preview না সরিয়ে search/filter, reopen ও saved artifact খোলে। Active note না থাকলেও palette/sidebar-এ history আছে।

SVG/PDF vector geometry থেকে হয়। PDF পুরো preview rasterise না করে SVG layout/text metrics ব্যবহার করে। PPI শুধু PNG-র জন্য: 72–600, default 300।

## ঘন diagram পড়া

Editable HTML/SVG lane-grid আগে summary মেপে wrap করে তারপর title/header রাখে। Cells আগে, connectors/labels পরে paint হয়। Orthogonal routing occupied cells ও label areas এড়িয়ে যায়।

`quadrantChart`-এ নিজস্ব normalisation, flowchart quote/shape repairs নয়। Copied opening bracket কেবল point-label-এর unmatched শেষ character হলে সরায়; title, axes ও quadrants-এর intentional brackets থাকে।

[Examples](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples)-এ bilingual inputs, SVG/PNG ও manifest আছে। `passed` নির্দিষ্ট run/bundle-এর, পরের release-এ সব type-এর নতুন test নয়। Executable catalog 33 rows, UI 21 locales, website 34 locales আলাদা। পাঁচ exact reference grammar independent layout evidence পর্যন্ত selector-এর বাইরে।

## Drawnix-এ Mermaid

SVG sanitise করে Mermaid source `.drawnix` metadata-তে রাখা হয়; preview-এর Drawnix/Plait runtime লাগে না। Default self-contained, আলাদা `.assets` নয়। **Also export complete Mermaid visuals** source, SVG ও manifest companions দেয়। পুরোনো `.assets` supported এবং missing SVG retained source থেকে তৈরি হতে পারে।

Resolved image embeds সম্ভব হলে data-backed SVG পায়। আগে embedded data, তারপর legacy files, শেষে available source rebuild ব্যবহার হয়। পুরোনো referenced companions রাখুন; নতুন self-contained export পুরোনো shared folder অপ্রয়োজনীয় প্রমাণ করে না।

এক scroll surface-এ আগে Drawnix, পরে source-order Mermaid। History reopen panels, dimensions ও export actions পুনর্গঠন করে। Titles, summaries ও relations-এর স্থান সংরক্ষিত; supported readable layout না হলে format error। Cross-branch arrows static relations, native rearrangement-এর পরে attachment বর্তমান evidence-এ supported নয়। Target editor-এ দেখুন।

## Native export সীমা

Source ও visual export আলাদা deliverables। শেয়ারের আগে target app-এ sample যাচাই করুন। PowerPoint supported editable tables ও corrected merged-cell separators রাখে; Mermaid/SVG image fallback হতে পারে। Preview বা whole-page screenshot score native check নয়।

## Circuit diagram

**Circuit diagram** ও **CircuitikZ source file** নিন। আগে structured circuit, পরে source, unrestricted LaTeX নয়। Support ইচ্ছাকৃতভাবে সীমিত, বিশেষত common-source NMOS ও supported CMOS blocks। Technical/publication use-এর আগে source/preview দেখুন।

SVG preview review companion, local LaTeX/TikZJax compilation proof নয়। Preview, SVG, PNG ও preview PDF-এ LaTeX লাগে না। Desktop native PDF/diagnostics-এর জন্য **CircuitikZ native compile environment** খুলুন: system `tectonic`/`pdflatex`, custom executable বা explicit **Install**-এর পরে pinned managed Tectonic। Panel progress/errors ও managed runtime removal দেয়।

## সমস্যা

### ভুল type

Type স্পষ্ট বাছুন। Circuit-এ **Circuit diagram** ও **Generate diagram**, পুরোনো **Summarise as Mermaid diagram** নয়।

### অনুপযুক্ত source

**Auto** বা type-এর compatible source-এ ফিরুন। CircuitikZ circuits-এর, Draw.io/Drawnix supported structures-এর জন্য।

### Export menu নেই

SVG/PNG/PDF-এ visual preview দরকার। শুধু text থাকলে source রেখে matching external tool-এ খুলুন।

### CircuitikZ compile হয় না

**CircuitikZ native compile environment** পরীক্ষা করুন। Managed runtime repair বা custom/system compiler-এর `circuitikz` package access দেখুন। Plugin file পুরো TeX distribution বহন করে না।
