# ধারণার নোট

<TLDR>স্বাধীন extraction মূল পড়ে নির্বাচিত folder-এ Markdown concept files বানায়। Folder প্রথমে নির্ধারিত নয়। নতুন নোটে শুধু title এবং backlinks বন্ধ থাকে। Add-links-এর concept template আলাদা।</TLDR>

## সারসংক্ষেপ

আগে **Concept note folder path** ঠিক করুন। আলাদা folder output, duplicate review ও পরবর্তী generation scope বোঝা সহজ করে। Extraction ফাইল বানায়, প্রতিটিতে গবেষণাসমৃদ্ধ ব্যাখ্যা ভরে না।

## কীভাবে কাজ করে

### Extraction ধাপ

LLM-এ content পাঠিয়ে `CONCEPT:` entries parse, একই operation-এ নাম deduplicate ও files create/update হয়। বড় নোট chunk হয়। Failed chunks দেখুন; model response সম্পূর্ণ ধারণাতালিকা নয়।

### Prompt

Built-in নির্দেশ topic-specific concrete concepts চায়। Domain ও synonym instructions canonical vocabulary নিশ্চিত করে না। Custom prompt-এ `CONCEPT: Term` রাখুন। [Prompts](../advanced/custom-prompts)।

### Chunking

`chunkWordCount` প্রথমে 3000, শব্দভিত্তিক অনুমান, provider token budget নয়। Chunk-এর মধ্যে context সীমিত; সম্পর্ক ও ambiguous names দেখুন।

## ফাইল তৈরি

### নামের নিয়ম

অনুপযুক্ত path characters বাদ, spaces normalise, দীর্ঘ নাম truncate এবং ফাঁকা ফল skip হয়। আলাদা শব্দগুচ্ছ একই filename হতে পারে। বড় collection-এর আগে নাম পরীক্ষা করুন।

### Templates

নতুন minimal note:

```markdown
# ধারণার নাম
```

নতুন স্বাধীন নোটে backlink চাইলে **Add "Linked From" backlink** চালু ও **Create minimal concept notes** বন্ধ করুন:

```markdown
# ধারণার নাম

## Linked From
- [[মূল নোট]]
```

Add-links concept output সক্রিয় থাকলে full form ও backlinks দেয়। স্বাধীন extraction switches সেই আচরণ বদলায় না।

### বিদ্যমান নোট

Backlinks চালু থাকলে `## Linked From`-এ অনুপস্থিত source link যোগ হতে পারে। পুরোনো body থাকে, একই backlink আবার যোগ হয় না। Source basename ব্যবহৃত হয়, তাই একই নামের উৎস পরীক্ষা করুন।

## Duplicates

Filename heuristics-এ case, plural, symbol normalisation ও অনুমোদিত scope-এ single-word containment থাকে। এগুলো semantic equivalence-এর প্রমাণ নয়। অনিয়মিত plural ও প্রযুক্তিগত অর্থভেদ নিজে দেখুন। **Check & remove duplicates**-এ শুধু উদ্দেশ্য অনুযায়ী files নিশ্চিত করুন; Obsidian trash ব্যবহার হয়। Concept folder disposable cache নয়, আগে backup নিন।

### তুলনার scope

Vault, concept folder নিজে, included folders অথবা কিছু folder বাদ দিয়ে তুলনা করা যায়। Scope প্রার্থী বদলায়, duplicate-এর অর্থ নয়। Delete-এর আগে নির্বাচন দেখুন।

## ব্যবহার

### স্বাধীন extraction

Markdown খুলে folder নিশ্চিত করে **Extract concepts (current file)** চালান। মূল বদলায় না। Names, coverage ও optional backlinks দেখুন।

### Extraction ও content

**Batch generate from titles** ব্যাখ্যা যোগ করে এবং পুরোনো যোগ্য notes-ও নিতে পারে। আগে folder দেখুন, পরে reported complete destination যাচাই করুন।

### Selection থেকে link

নির্বাচিত শব্দ wiki-link করে নির্ধারিত destination-এ concept বানাতে পারে। পুরো নোট থেকে model-কে বাছতে দেওয়ার বদলে নিজের শব্দ বেছে নিতে এটি ব্যবহার করুন।

## পরামর্শ

- ছোট source ও আলাদা concept folder।
- বড় সংগ্রহের আগে output language।
- Synonyms ও duplicate candidates আলাদা review।
- পরের run overwrite করার আগে দরকারি log রাখুন।
