# অনুবাদ

<TLDR>Notemd সক্রিয় file বা folder-এর যোগ্য files আপনার LLM দিয়ে অনুবাদ করে। ডিফল্টে language suffix-সহ আলাদা file হয়। গুণমান model-এর উপর নির্ভরশীল; UI-এর 21 ও site-এর 34 locales অনুবাদের সীমা বা নিশ্চয়তা নয়।</TLDR>

## সারসংক্ষেপ

Target language ও provider বেছে terms, links ও code-সহ copy note পরীক্ষা করুন। এটি নির্বাচিত LLM, বিশেষ Google Translate integration নয়। Registered actions file/folder-এ কাজ করে; একটি passage-এর জন্য temporary note বানান। Selection **Translate current file** সীমিত করে না।

## কীভাবে কাজ করে

### আদেশ

1. Output language বাছুন; প্রথমে English, UI থেকে আলাদা।
2. Source খুলে **Translate current file** চালান।
3. বড় content chunk হয়ে model-এ যায় ও responses যুক্ত হয়।
4. Reported path-এ অর্থ, terms, citations, Markdown links ও code পরীক্ষা করুন।

`Example.md`-এর French ফল সাধারণত পাশে `Example_fr.md`। Original থাকে, matching output overwrite হয়। Source-এ append বা নির্দিষ্ট `Translation` heading ডিফল্ট নয়।

### ভাষাজোড়া

Model source language অনুমান করে। Menu-তে থাকা pair accuracy প্রমাণ করে না। Mixed language ও terminology দেখুন; chunking cross-context হারাতে পারে।

### Task model

Task-specific settings-এ `translateProvider`/`translateModel`, অন্যথায় active provider চলে। Local server/model লাগে; cloud prompt ও content পায়। সাধারণ ranking নয়, নিজের domain sample যাচাই করুন।

### Folder translation

**Batch translate folder** প্রথমে direct children মাত্র নেয়; advanced profiles scope বদলাতে পারে। একই basename এক output folder-এ collision করতে পারে। পুনরায় চালানোর আগে destination ও পুরোনো translations দেখুন।

## সেটিংস

| সেটিং | প্রাথমিক মান | প্রভাব |
| --------- | --------- | -------- |
| `language` | `en` | নির্বাচিত target language |
| `translateProvider` | `DeepSeek` | Task routing সক্রিয় হলে translation provider |
| `translateModel` | `''` | ফাঁকা হলে সেই provider model |
| `useCustomTranslationSuffix` | `false` | ডিফল্ট language-code suffix |
| `translationCustomSuffix` | `_translated` | Custom suffix চালু হলে মান |
| `useCustomTranslationSavePath` | `false` | ডিফল্ট source-এর পাশে save |
| `translationSavePath` | `''` | Vault-relative output folder |
| `batchConcurrency` | `1` | Folder translation-এর requested concurrency |

Custom folder না বানাতে পারলে source folder fallback হতে পারে। প্রকৃত reported path দেখুন। ফাঁকা custom suffix মূল filename লক্ষ্য করতে পারে; আলাদা translation-এর জন্য আলাদা suffix দিন।

## উদাহরণ

ছোট Chinese note পরীক্ষার folder-এ রেখে English output-এ translate করুন। `_en.md`-এর terms, numbers, formulas ও links মূলের সঙ্গে মিলিয়ে তারপর folder বাড়ান।

## Cancel ও review

সমর্থিত পরের কাজ থামে, আগের translation বা provider billing ফেরত যায় না। Report ও files দেখুন। Markdown রাখার নির্দেশ একটি অনুরোধ, parser-level semantic equivalence-এর গ্যারান্টি নয়।

## পরামর্শ

- Source backup ও name collisions দেখুন।
- পরীক্ষায় আলাদা suffix/folder রাখুন।
- Code identifiers, math, URLs ও proper names যাচাই করুন।
- Diagnostic শেয়ারের আগে private content সরান।
