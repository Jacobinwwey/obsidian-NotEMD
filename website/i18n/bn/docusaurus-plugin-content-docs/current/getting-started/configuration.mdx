# কনফিগারেশন

<TLDR>Settings → Notemd খুলে field খুঁজুন। কাজের আগে provider ও output location ঠিক করুন। বদল একটি নোটে পরীক্ষা করুন; চলমান task শুরুর সময়ের settings রেখে দিতে পারে।</TLDR>

## সারসংক্ষেপ

প্রাথমিক provider DeepSeek, credentials ফাঁকা। Profile বাছলে account তৈরি, model install বা অধিকার পাওয়া হয় না। [Provider guide](../providers/overview) দেখুন।

## খোঁজ ও প্রিয় সেটিংস

**Search settings** নাম, বিবরণ, alias ও দৃশ্যমান category থেকে field খুঁজে সেখানে নিয়ে যায়। **★ Favorites** বিবরণ, category ও গন্তব্যসহ সংরক্ষিত settings দেখায়। তা বর্তমান vault-এ থাকে, restart টেকে এবং পুরোনো ID সরায়। Toolbar গুটিয়ে আবার খুললে query থাকে। Favorites list ও favorites-only search filter আলাদা।

**Diagram preview export PPI** প্রথমে 300, সীমা 72–600; কেবল PNG rasterization বদলায়। SVG/PDF সমর্থিত vector geometry রাখে। **Also export complete Mermaid visuals** companion files নিয়ন্ত্রণ করে, Drawnix-এ Mermaid দেখা যাবে কি না তা নয়।

একবার চালিয়ে একাধিক চিত্রের ধরন এবং প্রতিটি ধরনের জন্য আলাদাভাবে একাধিক আউটপুট ফরম্যাট বেছে নিন। ধরন অনির্বাচিত করলেও তার ফরম্যাট থাকে; কিছু না বাছলে বিষয়বস্তু স্বয়ংক্রিয়ভাবে বিশ্লেষণ হয়।

মধ্যবর্তী ফাইলের জন্য Vault-এর সাপেক্ষে একটি যৌথ ফোল্ডার নির্ধারণ করুন, অথবা প্রতিটি সোর্সের পাশে `notemd_assert/` ব্যবহারে ঘরটি ফাঁকা রাখুন। পুনরুদ্ধার রেকর্ড, রেন্ডার ক্যাশ ও ঐচ্ছিক সংযুক্তি সেখানে থাকে। এখনও ব্যবহৃত রেফারেন্সের ফাইল রাখুন; ফোল্ডার পরিবর্তন শুধু নতুন রানকে প্রভাবিত করে।

## ১. প্রদানকারী

সঠিক protocol-এর endpoint, প্রয়োজনীয় key ও উপলব্ধ model দিন। List এবং সফল generation আলাদা পরীক্ষা। Local server/model প্রস্তুত থাকতে হবে; cloud/gateway content নেয়। ব্যক্তিগত কাজের আগে task-specific routes-ও দেখুন।

## ২. কাজভিত্তিক মডেল

`useMultiModelSettings` links, titles, research, translation, concepts, original text ও Mermaid-এর আলাদা provider/model দেয়। ফাঁকা override সংশ্লিষ্ট provider-এর model নেয়; বন্ধ থাকলে active provider চলে। একই নোটে নির্ভুলতা, latency ও প্রকৃত দাম তুলুন, সাধারণ ranking ধরে নয়।

## ৩. আউটপুট

| কাজ | ডিফল্ট ফল |
| ------ | ------------------------- |
| Link যোগ | মূলের পাশে আলাদা `_processed.md`; মূল সরানো বন্ধ |
| স্বাধীন concept extraction | নির্বাচিত concept folder; শুধু title, backlinks বন্ধ |
| Translation | পাশে `_<language>.md`; বিদ্যমান target overwrite হতে পারে |
| Research | সক্রিয় Markdown-এ summary যোগ |
| Title থেকে batch generation | যোগ্য উৎসে লিখে গন্তব্য অনুমতি দিলে পাশের `<folder>_complete`-এ সরানো |
| Diagram preview/export | বাছাই করা ফাইল স্বয়ংক্রিয়ভাবে মূল নোটের পাশে বা সরাসরি নির্ধারিত আউটপুট ফোল্ডারে রপ্তানি হয়। নামে ধরন থাকে, যেমন `topic_drawnix.pdf` ও `topic_flowchart.svg`। নাম মিলে গেলে `-2`, `-3` ইত্যাদি যোগ হয়; পুরোনো ফাইল ওভাররাইট হয় না। |
Concept folder শুরুতে ফাঁকা। `concepts` আপনার উদাহরণ নির্বাচন। স্বাধীন নোটে minimal/full form আছে, সাধারণ template-variable engine নেই। [Concepts](../features/concept-notes)। Processing ও translation-এর suffix ও folders আলাদা। বিদ্যমান target ও recovery conflicts দেখুন; cancel সম্পন্ন লেখা ফেরত নেয় না।

## ৪. ভাষা

UI-তে 21 locales, site-এ 34 ভাষার route। `uiLocale: auto` সমর্থিত mapping নেয়; অসমর্থিত UI ভাষা ইংরেজিতে ফিরে যায়। Generated language আলাদা, প্রথমে English। সমর্থিত tasks নিজের ভাষা নিতে পারে; translation `language` নেয়। Model-এর ভাষাদক্ষতা এই সংখ্যা দিয়ে প্রমাণিত নয়।

## ৫. অনুসন্ধান

Tavily ও key বা DuckDuckGo স্পষ্টভাবে বাছুন। ফাঁকা Tavily key পরিবর্তন করে না। দুটিই network ব্যবহার করে; DuckDuckGo result page-ও আনতে পারে। Title generation research প্রথমে বন্ধ: `enableResearchInGenerateContent`। Local retrieval-ও বন্ধ, তার folder/task scopes আলাদা। Context হিসেবে ব্যবহৃত স্থানীয় অংশ নির্বাচিত LLM-এ পাঠানো হয়।

## ৬. কর্মপ্রবাহ

Builder বা প্রতি লাইনে নামসহ DSL ব্যবহার করুন:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` নাম ও actions, `>` action IDs আলাদা করে। ডিফল্ট নীতি reported error-এ থামে। [কর্মপ্রবাহ](../features/workflows)-এ scope ও error-এর পরে চলার প্রভাব দেখুন।

## ৭. উন্নত সেটিংস

| সেটিং | প্রাথমিক মান | প্রভাব |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | আলাদা task route না থাকলে provider |
| `useMultiModelSettings` | `false` | Task অনুযায়ী provider/model |
| `useCustomConceptNoteFolder` | `true` | Folder বাছার পর concept output অনুমোদন |
| `conceptNoteFolder` | `''` | শুরুতে concept folder নেই |
| `extractConceptsMinimalTemplate` | `true` | স্বাধীন নোটে শুধু title |
| `extractConceptsAddBacklink` | `false` | স্বাধীন extraction backlinks চালু করা |
| `moveOriginalFileOnProcess` | `false` | Link যোগের সময় মূল রাখা |
| `chunkWordCount` | `3000` | আনুমানিক text chunk, token limit নয় |
| `batchConcurrency` | `1` | ডিফল্ট batch concurrency |
| `enableBatchParallelism` | `false` | এই switch ব্যবহারকারী paths-এ parallel scheduling |
| `enableStableApiCall` | `false` | স্পষ্ট stable request mode |
| `customWorkflowErrorStrategy` | `stop_on_error` | Reported error-এ workflow থামানো |

Chunk size ও output token budget আলাদা। ছোট chunk সব context limit মেটাবে না, কম concurrency-ও প্রতিটি 429 আটকাবে না।

## সেটিংস প্রোফাইল

Settings vault-এর plugin data। বদলের আগে backup নিন। Provider export-এর নিজস্ব redaction contract আছে, পূর্ণ vault backup নয়। Redacted output-এও endpoint ও metadata দেখুন। Raw settings বা private notes-সহ diagnostic body প্রকাশ করবেন না।

## কনফিগারেশন সমস্যা

নির্দিষ্ট provider/model এবং ছোট নোট পরীক্ষা করুন। Field না পেলে search, category, developer-mode visibility ও vault দেখুন। Version ও গোপন তথ্যবিহীন minimal settings দিয়ে সমস্যা জানান।

## 1.9.10 — নিরাপদ প্রিভিউ ও Vault-ভিত্তিক স্থানীয় সেটিং

আমদানি করা SVG প্রিভিউ সক্রিয় বিষয়বস্তু ও বাইরের সম্পদ সরিয়ে দেয়, তবে চীনা লেবেল ও প্যানেলের স্টাইল রাখে। স্থানীয় প্রদানকারী এখন Vault অনুযায়ী পৃথক; সেটিং থেকে পুরোনো তালিকা স্পষ্টভাবে আমদানি করুন, যাতে মূল তালিকা ও বর্তমান কনফিগারেশন অক্ষত থাকে। উপস্থাপনা প্রিভিউ যৌথ ব্যবহারকারী পরিচালনাকারী loopback সার্ভার ব্যবহার করে। পছন্দ সংরক্ষণ ও কপি ব্যর্থ হলে ত্রুটি দেখায়; মুছে ফেলা Vault-এর পছন্দ অনুসরণ করে। PNG সামঞ্জস্য চালু থাকে: মূল ছবি রাখা হয় এবং প্রয়োজন হলেই যাচাইকৃত কম PPI কপি যোগ হয়। Drawnix সম্পর্কের নির্দিষ্ট সীমা নেই; উপস্থাপনার সেটিং পৃথক থাকে। একই সংস্করণের ফাইল ইনস্টল করে পুনরায় লোড করুন এবং ব্যাচের আগে একটি নোট পরীক্ষা করুন।

## 1.9.11

প্লাগইন সেশনে কাজের ধাপ ও প্রিভিউ পুনরায় খোলার মধ্যেও লগ জমা থাকে। রিসেট করতে লগ মুছুন ব্যবহার করুন; প্লাগইন পুনরায় লোড করলে আগের লগ থাকে না।

নির্ণয় বার্তাগুলো ট্যাগ অনুযায়ী গুচ্ছবদ্ধ এবং শুরুতে বন্ধ থাকে। প্রতিটি বার্তা ও পরামর্শ পড়তে গুচ্ছটি খুলুন; গুরুত্ব অনুযায়ী সংখ্যা দৃশ্যমান থাকে।

## 1.9.12 — আরও পরিচ্ছন্ন নির্ণয় প্রিভিউ

কোনো ত্রুটি না থাকলে পুরো নির্ণয় প্যানেল শুরুতে বন্ধ থাকে, শুধু শিরোনাম ও গুরুত্ব অনুযায়ী সংখ্যা দেখা যায়। ত্রুটি থাকলে প্যানেল স্বয়ংক্রিয়ভাবে খোলে। সব বার্তা ও পরামর্শ পড়তে প্যানেল এবং ট্যাগের গুচ্ছ খুলুন। কোনো নির্ণয় রেকর্ড মুছে ফেলা হয় না। শুধু ত্রুটির গুচ্ছ স্বয়ংক্রিয়ভাবে খোলে; একই ট্যাগ থাকলেও সতর্কতা ও তথ্যের গুচ্ছ বন্ধ থাকে।
