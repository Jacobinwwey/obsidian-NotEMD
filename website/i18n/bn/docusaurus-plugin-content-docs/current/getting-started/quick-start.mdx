# দ্রুত শুরু

<TLDR>একটি পরীক্ষার Markdown নোট ও আপনার প্রবেশাধিকার আছে এমন প্রদানকারী দিয়ে শুরু করুন। ফোল্ডার চালানোর আগে ফলের ফাইল দেখুন। ক্লাউড কাজ পাঠায়; স্থানীয় মডেলেরও চলমান server ও প্রস্তুত model লাগে।</TLDR>

## ১. মডেল ঠিক করুন

1. [ইনস্টল ও চালু](./installation) করে **Settings → Notemd** খুলুন।
2. Profile, endpoint, প্রয়োজনীয় credentials ও উপলব্ধ model বেছে নিন। **Fetch models** generation পরীক্ষার বিকল্প নয়।
3. **Test connection** চালিয়ে account, model বা address-এর সমস্যা ঠিক করুন।
4. **Concept note folder path** খুঁজে `concepts`-এর মতো আলাদা folder দিন। শুরুর মান ফাঁকা; নামটি আপনার নির্বাচিত উদাহরণ।

Ollama-তে আগে model নিন ও সঠিক নাম দিন; প্রাথমিক endpoint `http://localhost:11434/api`। LM Studio server চালিয়ে `LMStudio` profile নিন। [স্থানীয় মডেল](../providers/local) দেখুন। সারাংশের মডেল স্থানীয় হলেও web research-এর নেটওয়ার্ক লাগে।

## ২. প্রথম কাজ

`Notemd trial.md`-এ এমন ছোট লেখা রাখুন যা provider-কে পাঠানো অনুমোদিত:

```text
মেশিন লার্নিং উদাহরণ থেকে ধরন শিখতে নিউরাল নেটওয়ার্ক ব্যবহার করে।
```

Sidebar বা palette থেকে **Process file (add links)** চালান। সাধারণত মূলটি থাকে এবং পাশে `Notemd trial_processed.md` হয়। আসল ফল খুলুন। একটি সম্ভাব্য উদাহরণ:

```markdown
[[মেশিন লার্নিং]] উদাহরণ থেকে ধরন শিখতে [[নিউরাল নেটওয়ার্ক]] ব্যবহার করে।
```

নির্বাচিত concept folder-এও নোট তৈরি হতে পারে। ফাইল ও links পরীক্ষা করুন; model সব গুরুত্বপূর্ণ ধারণা সঠিকভাবে খুঁজে পাবে এমন নিশ্চয়তা নেই।

## ৩. অন্য সুবিধা

### ধারণা বের করা

**Extract concepts (current file)** মূল লেখে না এবং concept folder চায়। আলাদা নতুন নোট প্রথমে শুধু title পায়, backlinks বন্ধ থাকে। প্রয়োজনে স্পষ্টভাবে চালু করুন। [ধারণার নোট](../features/concept-notes)।

### গবেষণা ও সারাংশ

Markdown editor-এ বিষয় বাছুন বা title ব্যবহার করে **Research & summarize** চালান। Tavily ও key অথবা DuckDuckGo স্পষ্টভাবে বেছে নিন। বর্তমান নোটে summary যোগ হয়; উৎস খুলে দাবি মিলিয়ে নিন।

### এক-ক্লিক কর্মপ্রবাহ

ডিফল্ট **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

এটি link যোগ করে, concept/নির্বাচিত folder-এর যোগ্য নোট title থেকে ভরে এবং complete folder-এর Mermaid ঠিক করে। পুরোনো নোটও আসতে পারে। প্রথমে পরীক্ষার folder নিন। Web research বা সাধারণ diagram generation নিজে থেকে যোগ হয় না।

## বাতিল ও ফল দেখা

**Cancel** সমর্থিত পরের কাজ থামায়। সম্পন্ন output থাকে; এটি undo transaction নয় এবং provider-এর generation বা billing বন্ধের নিশ্চয়তা দেয় না। শেষ হওয়া পর্যন্ত অপেক্ষা করে paths ও recovery conflicts দেখে পুনরায় চালান।

## সমস্যা

- Account/model: profile ও connection ঠিক করুন।
- Concept নেই: সক্রিয়, ফাঁকা নয় এমন folder দিন।
- উপকারী link নেই: response ও prompt দেখুন; কোনো ন্যূনতম শব্দসংখ্যা নিশ্চয়তা দেয় না।
- Limit: quota দেখার সময় concurrency `1` রাখুন।
