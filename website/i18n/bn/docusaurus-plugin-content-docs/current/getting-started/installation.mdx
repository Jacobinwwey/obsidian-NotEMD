# ইনস্টলেশন

<TLDR>Community plugins থেকে Notemd ইনস্টল করুন, অথবা একই GitHub Release-এর তিনটি রানটাইম ফাইল ভল্টে রাখুন। প্লাগইন চালু করে প্রদানকারী বেছে নিয়ে পরীক্ষার নোট চালান। মডেল সার্ভার ও ঐচ্ছিক নেটিভ রপ্তানি সরঞ্জাম আলাদাভাবে প্রস্তুত করতে হয়।</TLDR>

## পদ্ধতি ১: Community plugins, প্রস্তাবিত

1. নির্দিষ্ট ভল্টে **Settings → Community plugins** খুলুন।
2. প্রয়োজনে community plugin অনুমোদন করে **Browse** বেছে নিন।
3. **Notemd** খুঁজে `Jacobinwwey/obsidian-NotEMD` রিপোজিটরি যাচাই করে **Install** চাপুন।
4. **Enable** করে রিবন বা command palette থেকে পাশের প্যানেল খুলুন।

[Obsidian-এ Notemd খুলুন](obsidian://show-plugin?id=notemd)। ব্রাউজার লিংক খুলতে না পারলে উপরের মেনু ব্যবহার করুন। এই নির্দেশিকা পড়তে protocol handler দরকার নেই।

## পদ্ধতি ২: হাতে ইনস্টল

### পূর্বশর্ত

ইনস্টল করা Obsidian এবং ব্যাকআপযোগ্য ভল্ট লাগবে। Manifest-এর ন্যূনতম `0.15.0` একটি ঘোষণা; সেই পুরোনো সংস্করণে নতুন প্রার্থী পরীক্ষা হয়েছে, এমন প্রমাণ নয়।

### ধাপ

1. একই [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest) থেকে `main.js`, `manifest.json`, `styles.css` নিন। `README.md` তথ্যসূত্র, রানটাইমের আবশ্যিক ফাইল নয়।
2. তিনটি ফাইল `<vault>/.obsidian/plugins/notemd/`-এ রাখুন। কনফিগারেশন ফোল্ডার বদলানো থাকলে প্রকৃত পথ ব্যবহার করুন।
3. Obsidian আবার লোড করে প্লাগইন চালু করুন।
4. সংস্করণ দেখুন; নতুন manifest-এর সঙ্গে পুরোনো bundle মেশাবেন না।

## বিকল্প: BRAT

আগে থেকে [BRAT](https://github.com/TfTHacker/obsidian42-brat) ব্যবহার করলে তার beta-plugin প্রক্রিয়ায় রিপোজিটরি যোগ করুন। ত্রুটি পুনরুত্পাদনে নির্দিষ্ট release ব্যবহার করুন। BRAT ঐচ্ছিক বাইরের সরঞ্জাম।

## যাচাই

উপলব্ধ প্রদানকারী ও মডেল ঠিক করে **Test connection**, তারপর [শুরুর কাজ](./quick-start) চালান। শুধু মডেল তালিকা পাওয়া generation-এর অধিকার প্রমাণ করে না; প্রকৃত আউটপুটও দেখুন।

## সিস্টেমের সীমা

| অংশ | সীমা |
| --------- | ---------- |
| Manifest | ন্যূনতম Obsidian `0.15.0`; `isDesktopOnly` false |
| পরীক্ষার প্রমাণ | তারিখযুক্ত release report দেখুন; বাস্তব মোবাইল ও 0.15.0 বর্তমানে যাচাই করা নয় |
| ক্লাউড মডেল | নেটওয়ার্ক, অনুমোদিত account/key ও সমর্থিত model |
| স্থানীয় মডেল | আলাদা ইনস্টল করা চলমান server এবং নেওয়া/লোড করা model |
| নেটিভ স্লাইড বা সার্কিট রপ্তানি | Desktop tools ও format-specific dependencies; আগে environment দেখুন |

সব ঐচ্ছিক exporter-এর জন্য একক OS-version নিশ্চয়তা নেই। সার্কিট preview TeX compilation প্রমাণ করে না; desktop পরীক্ষা mobile আচরণের প্রমাণ নয়।

## সরানো

Community plugins থেকে বন্ধ বা uninstall করুন। তৈরি নোট ও artifacts সাধারণ ভল্ট ফাইল হিসেবে থাকবে। মুছতে হলে আগে দেখুন; পুনঃইনস্টলের জন্য settings backup রাখুন। প্লাগইন সরালে সম্পন্ন সম্পাদনা ফেরত যায় না।

## আপডেট

**Check for updates** ব্যবহার করুন। হাতে আপডেটে কাজ থামান, ভল্ট ও settings backup নিন, একই release-এর তিনটি runtime file বদলে reload করুন। ছোট পরীক্ষা ও release notes দেখে batch চালান। Settings file release asset দিয়ে বদলাবেন না। ফিরে যেতে পরিচিত সামঞ্জস্যপূর্ণ release ও backup সচেতনভাবে ব্যবহার করুন।
