## প্রশ্ন

### Notemd কীভাবে ইনস্টল করব?

Settings → Community plugins → Browse-এ Notemd খুঁজে install ও enable করুন। হাতে একই GitHub Release-এর main.js, manifest.json, styles.css ব্যবহার করুন। ন্যূনতম ঘোষিত Obsidian 0.15.0; ওই পুরোনো সংস্করণ ও বাস্তব মোবাইল ডিভাইস বর্তমানে যাচাই করা নয়।

### কোন LLM প্রদানকারী সমর্থিত?

36 profiles পাঁচ পরিবারে আছে: OpenAI-compatible, Anthropic, Google, Azure OpenAI ও Ollama। Cloud, gateway ও local server-এর নিজস্ব endpoint, credentials ও model দরকার। Profile বা model list বর্তমান availability বা generation rights নিশ্চিত করে না।

### স্থানীয় model ব্যবহার করা যায়?

হ্যাঁ, Ollama, LM Studio, OVMS বা নিজের সক্রিয় compatible endpoint দিয়ে। Model প্রস্তুত করে বাস্তব task test করুন। Local inference web research, dependency installation বা আলাদা cloud-routed tasks offline করে না।

### ChatGPT থেকে পার্থক্য কী?

Notemd Obsidian documents-এ নির্দিষ্ট file tasks করে: links, concepts, research append, translation ও diagrams। Vault-এর কাজ অনুযায়ী বাছুন। বর্তমান persistence, export ও integration দেখুন; chat tools-ও history রাখতে ও documents বানাতে পারে।

### Copilot বা Smart Connections-এর সঙ্গে তুলনা কীভাবে করব?

একই concrete task, বর্তমান versions, settings ও documentation ব্যবহার করুন। Notemd note transformation ও scoped lexical retrieval দেয়, সাধারণ vault chat বা embedding semantic search নয়। অন্য projects-এর বর্তমান ranking দাবি করা হয় না।
