# Notemd পরিচিতি

<TLDR>Notemd একটি MIT-লাইসেন্সের Obsidian প্লাগইন। এটি পরীক্ষা ও সংরক্ষণযোগ্য wiki-linked Markdown, concept notes, research summaries, translations ও diagrams তৈরি করে। Provider, task ও scope নিজে বাছুন এবং model output জ্ঞানভাণ্ডারে নেওয়ার আগে পরীক্ষা করুন।</TLDR>

## Notemd কী?

এটি vault-এর কাজকে 36 cloud, gateway ও local-server profiles-এর সঙ্গে যুক্ত করে। প্রত্যেক task নিজস্ব output contract মেনে লেখে। Actions আলাদা বা sidebar workflow-তে চালানো যায়। Results vault-এ থাকে, কিন্তু cloud task content পাঠায় এবং web research network ব্যবহার করে। Local storage ও local inference আলাদা সিদ্ধান্ত।

## প্রধান সুবিধা

### Wiki-links ও concepts

মডেলকে ধারণা খুঁজে links যোগ করতে বলুন। Default add-links আলাদা processed note দেয়। Concept files-এর নির্বাচিত folder লাগে; standalone extraction প্রথমে title-only, backlinks off। [Links](./features/wiki-links), [concepts](./features/concept-notes)।

### Research ও স্থানীয় context

Tavily/DuckDuckGo context দিয়ে summary active note-এ যোগ হয়। Optional scoped local retrieval generation-এ excerpts দিতে পারে। বর্তমান index lexical, embedding semantic search নয়। [Research](./features/research)।

### Translation ও মূল passages

File/folder translate করুন বা প্রশ্নভিত্তিক মূল অংশ বের করুন। উদ্ধৃতি source-এর সঙ্গে মিলান। Selection file-level translation ছোট করে না। [Translation](./features/translation)।

### Diagram ও export

একবার চালিয়ে একাধিক চিত্রের ধরন এবং প্রতিটি ধরনের জন্য আলাদাভাবে একাধিক আউটপুট ফরম্যাট বেছে নিন। ধরন অনির্বাচিত করলেও তার ফরম্যাট থাকে; কিছু না বাছলে বিষয়বস্তু স্বয়ংক্রিয়ভাবে বিশ্লেষণ হয়। [চিত্রের নির্দেশিকা: Draw.io, Drawnix, Mermaid, CircuitikZ](./features/diagrams).

### Workflows

**One-Click Extract** links যোগ করে, concept/selected folder-এর eligible notes titles থেকে তৈরি করে এবং complete folder-এ Mermaid repair করে। পুরোনো concepts-ও আসতে পারে। প্রত্যেক action তার শর্ত ও output রাখে। [সঠিক DSL](./features/workflows)।

## শুরু করা

1. নির্দিষ্ট vault-এ [ইনস্টল](./getting-started/installation) করুন।
2. Accessible model দিয়ে disposable note test করুন।
3. Concept folder ও output paths দেখুন।
4. বড় batch-এর আগে results পরীক্ষা করুন।

নির্দিষ্ট সময় বা সর্বজনীন minimum note length নেই। পর্যালোচনা করা যায় এমন ছোট কাজ নিন।

## Diagram ক্ষমতার দিক

Typed specifications ও target-specific rendering supported ক্ষেত্র ঠিক করে। `DiagramSpec` সব syntax বা reference layout-এর প্রতিশ্রুতি নয়। `circuitikz` সীমিত supported structure ব্যবহার করে। TikZJax বাহ্যিক; preview native compilation প্রমাণ নয়। Drawnix-এর static cross-branch relations rearrangement-এর পরে attachment নিশ্চিত করে না।

## গঠন

Task selected provider-এ যায়, response parse/validate হয়ে note বা artifact-এ লেখা হয়। Search optional context দেয়; preview/export-এর format-specific সীমা আছে। [Developer guide](./developers/overview)-এ source ownership ও tests, [Agent guide](./agents/overview)-এ bounded public exports। Internal registry সাধারণ public automation API নয়।

## Tools তুলনা {#notemd-vs-other-obsidian-ai-plugins}

নিজের কাজ অনুযায়ী বাছুন: file transformation, conversation, deterministic linking, retrieval বা native editing। বর্তমান docs ও একই sample ব্যবহার করে versions/settings লিখে তুলনা করুন।

## ডেটা ও সামঞ্জস্য

Cloud task inputs, search queries ও LLM enabled local excerpts পায়। ব্যক্তিগত কাজের routes পরীক্ষা করুন। Cancellation supported পরের কাজ থামায় ও completed outputs রাখে; remote generation/billing থামার নিশ্চয়তা নেই।

Manifest minimum Obsidian `0.15.0` ও mobile loading অনুমোদন করে। সেই version ও physical mobile devices বর্তমানে যাচাই করা নয়। Optional native exports desktop tools চাইতে পারে। Website-এ 34 locale routes, UI-তে 21 locales; model language ability আলাদা।
