# OpenAI প্রদানকারী

<TLDR>এই profile shared OpenAI Chat Completions runtime ব্যবহার করে। সেই protocol গ্রহণকারী model ও key দিন। Initial model বর্তমান অধিকার বা সর্বজনীন quality নিশ্চিত করে না।</TLDR>

## প্রস্তুতি

Official service-এ **OpenAI**, key ও `https://api.openai.com/v1` নিন। তালিকার কোনো model অন্য API-র জন্য হতে পারে। Gateway নিজের profile/headers চায়; Azure-এ **Azure OpenAI**, deployment ও API version লাগে।

## Endpoint ও authentication

| ফিল্ড | প্রাথমিক মান |
| ------- | -------------- |
| প্রোটোকল | `openai-compatible` |
| API key | আবশ্যিক |
| Base URL | `https://api.openai.com/v1` |
| মডেল | `gpt-4o` |
| Temperature | `0.5` |
| Connection test | `models-then-chat` |

পরিচিত URL forms normalize করে runtime route বানায়। Profile থেকে শুরু করে resolved address দেখুন; অনুমানে path segment যোগ করবেন না।

## মডেল

**Fetch models** তালিকা আনে। **Test connection** শুধু list থেকে সফল হতে পারে, তাই exact model-এ note চালান। Reasoning, thinking, sampling ও budgets model/profile অনুযায়ী দিন।

## সমস্যা

- 401/403: key, project, অধিকার ও account।
- 404: endpoint, ID ও API compatibility।
- List সফল, task নয়: chat error ও parameters দেখুন।
- Long response থেমে গেলে input, budget ও output দেখুন; short test যথেষ্ট নয়।

## কখন ব্যবহার করবেন

Direct OpenAI Chat Completions endpoints-এর জন্য। নিজের notes-এ ফল যাচাই করুন; price ও availability Notemd-এর বাইরে বদলায়।
