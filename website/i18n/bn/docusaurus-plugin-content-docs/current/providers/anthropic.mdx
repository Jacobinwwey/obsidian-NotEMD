# Anthropic প্রদানকারী

<TLDR>Profile-টি native Messages-এর জন্য। OpenAI-compatible gateway দিয়ে Claude হলে সেই gateway profile নিন। Historical initial model-এর বদলে উপলব্ধ model লাগতে পারে।</TLDR>

## প্রস্তুতি

**Anthropic**, key ও accessible model বাছুন। একই protocol-এর অন্য deployment না হলে native endpoint রাখুন। Connection ও একটি নোট পরীক্ষা করুন।

## Endpoint ও authentication

| ফিল্ড | প্রাথমিক মান |
| ------- | -------------- |

| API key | আবশ্যিক |
| Base URL | `https://api.anthropic.com` |
| মডেল | `claude-3-5-sonnet-20240620` |

`/v1/messages` এবং native key/version headers ব্যবহৃত হয়। OpenAI chat route যোগ করবেন না। Table repository defaults দেখায়, current availability নয়।

## মডেল

Native discovery থাকলে ব্যবহার করুন। List সীমিত হলে authorized ID দিয়ে generation test করুন। Long ও structured-output tasks আলাদা যাচাই করুন।

## সমস্যা

- 401/403: key, project, billing ও model rights।
- 404: endpoint ও model availability।
- Gateway ID rejected: profile/identifier মেলান।
- Long failure: retries বাড়ানোর আগে limits দেখুন।

## কখন ব্যবহার করবেন

Native Messages endpoints-এ। নিজের sources দিয়ে ফল তুলুন; universal provider ranking ধরে নেবেন না। Per-task routing দিয়ে নির্দিষ্ট কাজে বেছে নিতে পারেন।
