# চীনা প্রদানকারী

<TLDR>নিজের account ও deployment-এর profile নিন। একই OpenAI-compatible protocol হলেও অঞ্চল, path, model ও অধিকার পরস্পর বদলযোগ্য নয়। একটি ছোট বাস্তব task যাচাই করুন।</TLDR>

## প্রস্তুতি

Account/key নিয়ে profile, region ও model entitlement নিশ্চিত করুন। Preset current availability নিশ্চয়তা দেয় না। Connection-এর পরে note test করুন।

## মডেল

অনুমোদিত list ব্যবহার করুন। Huawei Cloud MaaS deployment-specific, অন্য profiles যেখানে supported সেখানে compatible discovery করে। List নিষিদ্ধ হলেও explicit model generation সম্ভব হতে পারে। DeepSeek test শুধু list-এ সফল হতে পারে; কিছু regional profiles ছোট generation করে। Real task validation জরুরি।

## সমস্যা

- Key accepted, generation denied: model rights, deployment ও region।
- Ark ID rejected: endpoint ID নাকি model name দরকার?
- Reasoning কাটা: budget ও model-specific thinking।
- Network: Obsidian device থেকে endpoint ও transport error দেখুন।

## কখন ব্যবহার করবেন

অধিকার, availability ও data terms মিললে। Geography থেকে language quality বা কম price অনুমান নয়; settings-সহ sample comparison করুন।
