# Google প্রদানকারী

<TLDR>Google profile native Gemini Generative Language ব্যবহার করে। Authorized key ও available model দিন। Compatible gateway-র Gemini-তে gateway profile লাগে।</TLDR>

## প্রস্তুতি

**Google**, key, native endpoint ও নির্দিষ্ট API version-এর model নিন। Connection ও note test করুন। এটি ইচ্ছামতো Google Cloud বা Vertex deployment স্বয়ংক্রিয়ভাবে configure করে না।

## Endpoint ও authentication

| ফিল্ড | প্রাথমিক মান |
| ------- | -------------- |
| প্রোটোকল | `google` |
| API key | আবশ্যিক |
| Base URL | `https://generativelanguage.googleapis.com/v1` |
| মডেল | `gemini-2.0-flash-exp` |
| Temperature | `0.5` |
| Connection test | `chat-only` |

Key-সহ `generateContent` request তৈরি হয়। Historical ID বর্তমান availability নিশ্চিত করে না। Diagnostic URL-এ authentication থাকতে পারে; শেয়ারের আগে দেখুন।

## মডেল

Native list ও selected API-তে generation পরীক্ষা করুন। Empty list permissions, endpoint বা missing model বোঝাতে পারে। Diagnosis না করে protocol বদলাবেন না।

## সমস্যা

- 400: ID, parameters, input/output limits।
- 401/403: key restrictions, API enabled কি না, rights।
- 404: ওই API version-এ model আছে কি না।
- Gateway examples: সঠিক OpenAI-compatible profile নিন।

## কখন ব্যবহার করবেন

Native Gemini-র জন্য। Translation, research ও diagram নিজের sample-এ তুলুন। Speed, cost বা quality-র সাধারণ নিশ্চয়তা নেই।
