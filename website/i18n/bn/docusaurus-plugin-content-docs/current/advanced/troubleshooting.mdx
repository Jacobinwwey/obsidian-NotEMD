# সমস্যা সমাধান

<TLDR>একটি disposable note-এ একই provider, model ও task settings দিয়ে সমস্যা পুনরুত্পাদন করুন। Progress log ও reported path দেখুন। Authentication, generation, parsing ও writing আলাদা; connection success পুরো workflow পরীক্ষা করে না।</TLDR>

## সারসংক্ষেপ

Notemd/Obsidian version, OS, action, protocol, model ও minimal steps লিখুন। Cancel settle না হওয়া পর্যন্ত নতুন task নয়। Output/recovery কার তৈরি বোঝার আগে সরাবেন না।

## Diagnostics

### Connection test

**Test connection** profile অনুযায়ী list বা short generation পরীক্ষা করে। নির্বাচিত model/output-এর জন্য ছোট real task চালান।

### Progress ও developer diagnostics

Progress status, error ও destination দেয়; API activity pending ও finished attempts আলাদা করে। Debug দরকারেই চালু করুন। Long diagnostic quota খরচ করতে পারে। Body-তে note, partial response, endpoint বা credentials থাকতে পারে; local review/redaction করে শেয়ার করুন। Redacted profile-ও metadata review চায়।

## সাধারণ errors

### ভুল বা ফাঁকা key

401: সঠিক provider/endpoint-এর key ও অনিচ্ছাকৃত spaces দেখুন। 403: account/project rights, model entitlement ও billing। Retry credentials ঠিক করে না।

### Network

Obsidian device থেকে host, port, protocol ও route দেখুন। Ollama/LM Studio server এবং model প্রস্তুত থাকতে হবে। `localhost` বর্তমান device, অন্য computer নয়। Correct profile নিন; runtime fallback automatic, UI transport switch নয়।

### 429 limit

Concurrency কমিয়ে request/token quota ও একই key-র অন্য clients দেখুন। Retry কিছু transient failure মাত্র সারায়।

### Model নেই

**Fetch models** বা পরিচিত model/deployment দিন। API version ও region দেখুন; historical preset অবসর নিতে পারে। Azure deployment name ও Ark endpoint ID চাইতে পারে।

### Links বা concepts নেই

প্রকৃত output, উপকারী source, expected response form ও nonempty active concept folder দেখুন। Standalone extraction title-only, backlinks off দিয়ে শুরু হয়। Custom prompt marker বাদ দিলে built-in দিয়ে তুলুন।

### Output অনুপস্থিত বা অন্যত্র

Reported `_processed.md`, `_<language>.md` বা complete path দেখুন। Translation folder create ব্যর্থ হলে source folder fallback হতে পারে। Retry-এর আগে collision ও permissions দেখুন।

### Cancel-এর পরে files

Completed writes থাকে এবং accepted requests/writes শেষ হতে পারে। Delete বা whole-folder repeat-এর আগে per-file ফল ও recovery conflicts দেখুন।

### Diagram বা native export

Supported type/source নিন এবং slide/CircuitikZ environment check করুন। Preview native verification নয়। শুধু text থাকলে source রেখে matching external tool-এ খুলুন। [Diagrams](../features/diagrams)।

## সমস্যা জানান

1. Synthetic small note ও আলাদা folder-এ reproduce করুন।
2. Versions, action, model, দরকারি settings, expected ও actual লিখুন।
3. Secrets/private content/অপ্রয়োজনীয় endpoint metadata বাদ দিয়ে minimal artifacts ও logs দিন।
4. একটি file ও built-in prompt-এও হয় কি না জানান।
5. [GitHub Issues](https://github.com/Jacobinwwey/obsidian-NotEMD/issues) খুলুন।

Screenshot একা format বা cancellation issue খুব কমই প্রমাণ করে। সম্ভব হলে source/output বা minimal sequence দিন।
