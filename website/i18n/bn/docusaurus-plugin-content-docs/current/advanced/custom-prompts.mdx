# নিজের prompts

<TLDR>Global ও task switch চালু এবং text ফাঁকা না হলে custom prompt built-in-কে প্রতিস্থাপন করে। Output contract নিজে বজায় রাখুন; বাদ দেওয়া সব format instruction নিজে থেকে ফেরে না।</TLDR>

## সারসংক্ষেপ

প্রথমে representative note-এ default দেখুন। Focused domain বা synonym suppression যথেষ্ট হতে পারে। Extraction policy, structure বা translation style বদলাতে চাইলে sample তুলনা করে batch-এ যান।

## কীভাবে কাজ করে

### গঠন

Built-in বা custom prompt বেছে প্রযোজ্য domain/language instruction ও task placeholders যোগ হয়। Content আলাদা message-ও হতে পারে। Variables সর্বজনীন নয়। `CONCEPT:` বাদ দিলে parsing এবং research context বাদ দিলে evidence হারায়। Valid request সঠিক result প্রমাণ করে না।

### Variables

Exact uppercase ও single braces ব্যবহার করুন:

| কাজ | প্রদত্ত placeholders |
| ------ | ----------------------- |
| Title generation | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Research summary | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Translation | `{LANGUAGE}`, `{TEXT}` |
| Original-text extraction | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` task policy থেকে আসে। Add-links ও standalone concepts content সরাসরি পাঠায়; নতুন placeholder বানাবেন না। অজানা নাম পূরণ হয় না। এগুলো prompt substitutions, concept-file templates নয়।

### Focused domain

Focused learning চালু করে `তড়িৎ প্রকৌশল`-এর মতো domain দিন। `Relevant Fields` model-এর মনোযোগ নির্দেশ করে, hard filter নয়।

## সেটিংস

| কাজ | Enable switch | Prompt field |
| ------ | --------------- | -------------- |
| Links | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titles | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Research | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid summary | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Concepts | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Translation | `useCustomPromptForTranslate` | `translatePrompt` |
| Original text | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

সকলের `enableGlobalCustomPrompts` দরকার। Empty custom text built-in নেয়। Merged original extraction-এর আলাদা built-in form আছে; ordinary override প্রযোজ্য নয়। Diagram generation-এর typed output rules আছে; Mermaid summary prompt সব diagram-এর জন্য নয়।

## উদাহরণ

Global ও concept switches চালু করে parser marker রাখুন:

```text
নোট থেকে মূল তড়িৎ প্রকৌশল ধারণা বের করুন।
সাধারণ নামের বদলে নির্দিষ্ট উপাদান ও ভৌত প্রক্রিয়া বাছুন।
প্রতি ধারণা এক লাইনে এই সঠিক রূপে দিন:
CONCEPT: পরিভাষার নাম
ব্যাখ্যা বা বাইরের code block যোগ করবেন না।
```

Copy note-এ entries, filenames ও missed concepts default-এর সঙ্গে মেলান। ফিরে যাওয়ার জন্য পুরোনো prompt রাখুন।

## পরামর্শ

- Batch বাড়ানোর আগে একটি task test করুন।
- Research evidence ও exact original excerpts রাখুন।
- Prose অনুবাদ করুন, executable ID ও markers নয়।
- Model পরিবর্তনে পুনরায় test করুন; instruction validation guarantee নয়।
