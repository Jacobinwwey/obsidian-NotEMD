# Introduktion til Notemd

<TLDR>Notemd er en MIT-licenseret Obsidian-udvidelse, som skaber wiki-linket Markdown, begrebsnoter, researchopsummeringer, oversættelser og diagrammer, der kan gennemgås og gemmes. Vælg udbyder, opgave og omfang, og kontrollér modeloutput før genbrug i vidensbasen.</TLDR>

## Hvad er Notemd?

Udvidelsen forbinder vault-opgaver med 36 profiler til cloud, gateways og lokale servere. Hver opgave skriver efter sin egen outputkontrakt. Handlinger kan køres separat eller som sidepanelarbejdsgange. Resultater gemmes i vaulten, men cloudopgaver sender indhold, og webresearch bruger netværk. Lokal lagring og lokal inferens er to forskellige valg.

## Centrale funktioner

### Wiki-links og begreber

Bed modellen finde begreber og tilføje links. Standardlinkning skaber en separat behandlet note. Begrebsfiler kræver valgt mappe; selvstændigt udtræk starter med titel uden backlinks. [Links](./features/wiki-links), [begreber](./features/concept-notes).

### Research og lokal kontekst

Tavily/DuckDuckGo giver grundlag til opsummeringer, der føjes til aktiv note. Valgfri afgrænset lokal hentning kan give uddrag til generering. Indekset er leksikalt, ikke embeddingbaseret semantisk søgning. [Research](./features/research).

### Oversættelser og originalpassager

Oversæt filer/mapper eller udtræk originale passager til bestemte spørgsmål. Sammenlign citater med kilden. Markering begrænser ikke filoversættelse. [Oversættelse](./features/translation).

### Diagrammer og eksport

Vælg type og kompatibel kilde, gennemgå preview, og gem kilde eller understøttet visuel eksport. Det eksekverbare katalog har 33 poster. Kildeformat og eksportformat er forskellige. [Diagrammer](./features/diagrams).

### Arbejdsgange

**One-Click Extract** tilføjer links, genererer egnede noter fra titler i begrebs-/valgt mappe og reparerer Mermaid i complete-mappen. Ældre begreber kan indgå. Hvert trin beholder egne forudsætninger og output. [Præcis DSL](./features/workflows).

## Kom i gang

1. [Installer](./getting-started/installation) i den ønskede vault.
2. Test en engangsnote med tilgængelig model.
3. Kontrollér begrebsmappe og outputstier.
4. Gennemgå resultatet før store batcher.

Der er ingen fast tid eller universel minimumslængde. Vælg noget lille, som kan gennemgås.

## Diagrammernes grænser

Typede specifikationer og målspecifik rendering afgrænser understøttelsen. `DiagramSpec` lover ikke al syntaks eller præcist referencelayout. `circuitikz` bruger afgrænsede strukturer. TikZJax er eksternt; preview beviser ikke native kompilering. Statiske Drawnix-pile mellem grene garanterer ikke fasthæftning efter omrokering.

## Struktur

Opgaven sendes til valgt udbyder, svaret parses/valideres og skrives som note eller artefakt. Søgning leverer valgfri kontekst; preview/eksport har formatgrænser. [Udviklerguiden](./developers/overview) viser kildeansvar og tests; [Agentguiden](./agents/overview) afgrænsede offentlige eksporter. Internt register er ikke et generelt offentligt automations-API.

## Sammenlign værktøjer {#notemd-vs-other-obsidian-ai-plugins}

Vælg efter opgaven: filomformning, samtale, deterministisk linkning, hentning eller native redigering. Brug aktuelle vejledninger og samme prøve med noterede versioner/indstillinger.

## Data og kompatibilitet

Cloudopgaver modtager input, søgeforespørgsler og aktiverede lokale uddrag. Kontrollér private dataruter. Annullering stopper understøttet fortsættelse og bevarer output, uden garanti for stop af fjernarbejde eller fakturering.

Manifestet angiver mindst Obsidian `0.15.0` og tillader mobil indlæsning. Den version og fysiske mobilenheder er ikke aktuelt verificeret. Valgfri native eksport kan kræve desktopværktøjer. Webstedet har 34 sprogruter, UI 21 sprogversioner; modellens sprogevner er særskilte.
