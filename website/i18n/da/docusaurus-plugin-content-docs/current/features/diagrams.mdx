# Diagrammer

<TLDR>Vælg diagramtype og derefter redigerbart kildeformat. Se hele resultatet i Obsidian, inklusive Drawnix og indlejrede Mermaid-paneler. Eksportér panelerne til SVG, PNG eller PDF.</TLDR>

## Tre adskilte valg

| Valg | Bestemmer | Eksempler |
| --- | --- | --- |
| Diagramtype | Hvad diagrammet betyder | Flow, sekvens, kredsløb, graf |
| Kildeformat | Den redigerbare eller genbrugelige fil | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Eksportformat | Billedet eller dokumentet til deling | SVG, PNG, PDF |

Draw.io og Drawnix er kildeformater, ikke diagramtyper. CircuitikZ er en kredsløbskilde og begrænser ikke visuel eksport til SVG.

## Vælg kilde

| Format | Passer til | Kildefil |
| --- | --- | --- |
| Mermaid | Diagrammer i Markdown | Mermaid-kodeblok |
| JSON Canvas | Native Obsidian-canvas | `.canvas` |
| Draw.io | Redigering i diagrams.net eller kompatible værktøjer | `.drawio` |
| Drawnix | Håndtegnet/whiteboard-redigering | `.drawnix` |
| CircuitikZ | Strukturerede elektriske kredsløb og transistorkredsløb | `.tex` |

Lad **Preferred source format** stå på **Auto**, hvis en bestemt editor ikke kræves. Notemd vælger kompatibel kilde.

## Generér og eksportér

1. Åbn en understøttet kildenote. Flyt passager til særskilt note; markering begrænser ikke en filopgave.
2. Vælg type eller **Auto-detect**.
3. Vælg kilde eller **Auto**; Drawnix understøtter videnskort med redigerbare knuder og Mermaid.
4. Vælg **Generate diagram**.
5. Gennemgå tavle og Mermaid-paneler i kildeorden i én lodret rullevisning med panelernes faktiske højde.
6. Brug **Export SVG**, **Export PNG** eller **Export PDF** pr. panel, eller eksportér alle fra toppen. Vælg kildemappe eller egen vault-relativ mappe. Navne er deterministiske pr. panel, og en panelfejl stopper ikke resten.
7. Gem redigerbar kilde med **Save source file**.

Eksportmenu og paneloverskrifter giver samme tre handlinger. **History** viser søgning, filtre, genåbning og gemte filer uden at skjule preview. Historik er også i palette/sidepanel uden aktiv note.

SVG/PDF bruger vektorgeometri. PDF bevarer SVG-layout og tekstmål i stedet for at rasterisere alt. PPI gælder kun PNG: 72–600, standard 300.

## Læsbare tætte diagrammer

Redigerbare HTML/SVG-baner måler og ombryder opsummeringen før titel og rækkeoverskrifter. Celler tegnes før forbindelser/etiketter; ortogonale ruter undgår optagne celler og reserverer tekstplads.

`quadrantChart` får særskilt normalisering uden flowchart-rettelser af citationstegn/former. En kopieret åbningsparentes fjernes kun som uparret afslutning i en punktetiket. Tilsigtede parenteser i titel, akser og kvadranter bevares.

[Eksempelkataloget](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) indeholder tosproget input, SVG/PNG og manifest. `passed` henviser til den angivne kørsel/bundle, ikke en frisk test af alle typer i senere versioner. Der er 33 eksekverbare rækker, 21 UI-sprogversioner og 34 websprog. Fem præcise referencegrammatikker holdes uden for vælgeren, indtil layoutet er bevist særskilt.

## Drawnix med indbygget Mermaid

Notemd renser SVG og gemmer Mermaid-kilde i `.drawnix`-metadata. Preview kræver ikke Drawnix/Plait-runtime. Standardfilen er selvstændig uden `.assets`. **Also export complete Mermaid visuals** tilføjer kilde-, SVG- og manifestledsagere. Ældre `.assets` understøttes; manglende SVG kan genskabes fra gemt kilde.

Billeder får om muligt preview med indlejrede data. Prioritet: indlejret indhold, gamle ledsagefiler, tilgængelig kildetekst. Bevar stadig refererede filer: ny selvstændig eksport beviser ikke, at en gammel delt mappe er overflødig.

Rullevisningen viser Drawnix først, dernæst Mermaid i kildeorden. Historik genskaber paneler, mål og eksporthandlinger. Titler, opsummeringer og relationer får plads; et ikke-understøttet læsbart layout giver formatfejl. Pile mellem grene er statiske; nuværende evidens beviser ikke fasthæftning efter omrokering i Drawnix. Test den ønskede editor.

## Native eksportgrænser

Kilde og visuel eksport er separate leverancer. Test en repræsentativ fil i målprogrammet. PowerPoint bevarer understøttede redigerbare tabeller, inklusive rettede skillelinjer under flettede celler; Mermaid/SVG kan blive billeder. Preview eller helslide-billedscore erstatter ikke native kontrol.

## Kredsløb

Vælg **Circuit diagram** og **CircuitikZ source file**. Notemd genererer først en struktureret beskrivelse og derefter kilde; det begrænser vilkårlig LaTeX. Understøttelsen er bevidst afgrænset, især common-source NMOS og understøttede CMOS-blokke. Kontrollér kilde og preview før teknisk brug eller publicering.

SVG-preview er kontrolhjælp, ikke bevis for lokal LaTeX/TikZJax-kompilering. Preview, SVG/PNG og preview-PDF kræver ikke LaTeX. Åbn på desktop **CircuitikZ native compile environment** til diagnostik/native PDF: systemets `tectonic`/`pdflatex`, egen executable eller fastlagt administreret Tectonic efter udtrykkelig **Install**. Panelet viser status/fejl og kan fjerne den administrerede runtime.

## Problemer

### Forkert diagramtype

Vælg typen udtrykkeligt. Kredsløb bruger **Circuit diagram** og **Generate diagram**, ikke ældre **Summarise as Mermaid diagram**.

### Uegnet kilde

Gå tilbage til **Auto**, eller vælg format til typen. CircuitikZ er til kredsløb; Draw.io/Drawnix til understøttede strukturer.

### Eksportmenu mangler

SVG/PNG/PDF kræver visuelt preview. Er kun tekst tilgængelig, gem kilden og åbn den i passende eksternt værktøj.

### CircuitikZ kompilerer ikke

Kontrollér **CircuitikZ native compile environment**. Reparér administreret runtime, eller verificér at egen/systemkompilator kan hente `circuitikz`. Pluginbundlen indeholder ikke en fuld TeX-distribution.
