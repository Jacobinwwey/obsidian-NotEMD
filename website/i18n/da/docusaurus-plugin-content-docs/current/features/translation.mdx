# Oversættelse

<TLDR>Notemd oversætter den aktive fil eller egnede mappefiler med den valgte LLM. Standardoutput er en separat fil med sprogsuffiks. Kvaliteten afhænger af modellen; 21 UI-sprog og 34 webstedssprog er hverken grænser eller garantier for oversættelse.</TLDR>

## Overblik

Vælg målsprog og udbyder, og test en kopi med fagtermer, links og kode. Opgaven bruger LLM, ingen særlig Google Translate-integration. Handlingerne gælder filer/mapper. Flyt en passage til en midlertidig note; markering afgrænser ikke **Translate current file**.

## Sådan virker det

### Oversættelsesopgave

1. Vælg målsprog; oprindeligt engelsk, uafhængigt af UI.
2. Åbn kilden, og kør **Translate current file**.
3. Lang tekst opdeles, sendes og samles.
4. Åbn rapporteret fil, og kontrollér betydning, termer, citater, Markdown-links og kode.

Fransk fra `Example.md` bliver normalt `Example_fr.md` ved den bevarede kilde. Eksisterende output overskrives. Tilføjelse i originalen eller en fast overskrift `Translation` er ingen standardgaranti.

### Sprogpar

Modellen udleder kildesproget. Et menupunkt beviser ikke præcision for sprogparret. Test blandede sprog og fagtermer; opdeling kan miste kontekst.

### Opgavespecifik model

Routing bruger `translateProvider`/`translateModel`, ellers den aktive udbyder. Lokal model kræver server/model; cloud modtager indhold og prompt. Bedøm en relevant prøve frem for generelle ranglister.

### Mappeoversættelse

**Batch translate folder** tager som standard kun direkte børn; avancerede profiler kan ændre det. Ens kildenavne i samme outputmappe kan kollidere. Kontrollér tidligere oversættelser og destinationer før gentagelse.

## Indstillinger

| Indstilling | Startværdi | Virkning |
| --------- | --------- | -------- |
| `language` | `en` | Valgt målsprog |
| `translateProvider` | `DeepSeek` | Udbyder med opgaverouting |
| `translateModel` | `''` | Tomt bruger udbyderens model |
| `useCustomTranslationSuffix` | `false` | Sprogkode som standardsuffiks |
| `translationCustomSuffix` | `_translated` | Suffiks med eget alternativ aktivt |
| `useCustomTranslationSavePath` | `false` | Som standard ved siden af kilden |
| `translationSavePath` | `''` | Egen vault-relativ outputmappe |
| `batchConcurrency` | `1` | Ønsket samtidighed for mappeoversættelse |

Hvis egen mappe ikke kan oprettes, kan opgaven falde tilbage til kildemappen. Læs den faktiske sti. Et tomt eget suffiks kan pege på kilden; vælg et særskilt suffiks til en separat oversættelse.

## Eksempel

Kopiér en kort kinesisk note til testmappen, vælg engelsk, og oversæt filen. Sammenlign `_en.md` med kilden: termer, tal, formler og links. Udvid bagefter.

## Annullering og kontrol

Annullering stopper understøttet videre arbejde, ikke færdige oversættelser eller garanteret fakturering. Gennemgå rapport og filer. Bevarelse af Markdown er en modelinstruktion, ikke en parsergaranti for betydningslighed.

## Tips

- Backup og kontrol for navnekonflikter.
- Særskilt testsuffiks og mappe.
- Manuel kontrol af kode, matematik, URL’er og egennavne.
- Gennemgå diagnostik før deling.
