# Arbejdsgange

<TLDR>En arbejdsgang kører sidepanelhandlinger efter hinanden. En handling kan kræve mappevalg eller aktiv editor. Det er ikke en tekstpipeline: hvert trin beholder egne input, output og sideeffekter. Begynd med en testnote og separat mappe.</TLDR>

## Overblik

Den medfølgende **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Tilføj links til den aktive note; opret begreber, hvis en mappe er valgt.
2. Generér indhold til egnede noter i begrebs-/valgt mappe, også eksisterende noter.
3. Reparér Mermaid i genereringens complete-mappe.

Standardkæden udfører ikke webresearch. Titelgenerering kan tilføje research via en separat indstilling. Se [batcher](../advanced/batch-processing).

## Sådan virker det

### Udførelse

Trin kører sekventielt med status og fejl i sidepanelet. Annullering stopper kommende trin og når understøttede anmodninger. Færdige filer bevares; kæden er ingen transaktion. Begrebsmappen er første mappepræference. Batchgenerering husker kilde-/complete-mappe, og Mermaid bruger complete. Andre handlinger beholder krav til fil, markering og interaktion.

### DSL

Én navngiven knap pr. linje. `::` adskiller navn fra handlinger; `>` adskiller handlings-ID’er. Tomme linjer og linjer med indledende `#` ignoreres; ukendte ID’er afvises.

```text
Udtræk og tegn::extract-concepts-current>summarize-as-mermaid
```

Brug arbejdsgangsbyggeren eller redigér DSL. ID’er er stabile, mens etiketter følger UI-sproget. Mappevarianter har egne ID’er; de udledes ikke ved vilkårlig teksterstatning.

| ID | Handling / forudsætning |
| ------------ | ----------------------- |
| `process-current-add-links` | Links i aktiv note |
| `process-folder-add-links` | Links i valgt mappe |
| `extract-concepts-current` | Begreber fra aktiv note |
| `extract-concepts-folder` | Begreber fra valgt mappe |
| `generate-from-title` | Indhold fra aktiv titel |
| `batch-generate-from-titles` | Indhold til egnede mappenoter |
| `research-and-summarize` | Undersøg markering/titel i åben Markdown-editor |
| `summarize-as-mermaid` | Opsummér understøttet aktivt input som Mermaid |
| `generate-diagram` | Vælg flere diagramtyper i samme kørsel og flere outputformater for hver type. Fravalg bevarer typens formater; uden valgte typer analyseres indholdet automatisk. |
| `preview-diagram` | Preview af understøttet kilde eller diagram |
| `translate-current-file` | Oversæt aktiv understøttet fil |
| `batch-translate-folder` | Oversæt valgt mappe |
| `extract-original-text` | Udtræk efterspurgte originalpassager |
| `batch-extract-original-text` | Passager fra egnede mappefiler |
| `split-note-by-chapters` | Opdel aktiv note i kapitler |
| `batch-mermaid-fix` | Reparér Mermaid-kodeblokke i valgt mappe |
| `fix-formula-current` | Normalisér formelafgrænsere i aktiv note |
| `batch-fix-formula` | Normalisér formelafgrænsere i mappe |
| `check-duplicates-current` | Kontrollér dubletter i aktiv note |
| `check-remove-duplicate-concepts` | Gennemgå og fjern begrebsdubletter interaktivt |
| `test-llm-connection` | Test konfigureret udbyder |
| `probe-slide-export-env` | Kontrollér lokalt præsentationseksportmiljø |
| `export-slides` | Eksportér aktiv fil til slides |

### Standard eller egen kæde

One-Click Extract er forudindstillet. Definér øvrige knapper med navn og rækkefølge, og kontrollér sidepanelets værktøjstip. Ret parserfejl før brug.

## Indstillinger

| Indstilling | Startværdi | Virkning |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stop ved første rapporterede trinfejl |
| `useMultiModelSettings` | `false` | Aktiv udbyder, indtil opgaverouting aktiveres |
| `enableResearchInGenerateContent` | `false` | Ingen research ved titelgenerering før aktivering |

`continue_on_error` fortsætter efter fejl. Brug det kun, hvis efterfølgende handlinger kan arbejde med det resterende input. Fortsættelse gør ikke en delvis arbejdsgang vellykket.

### Model pr. trin

Opgaven ejer modelvalget. Tom override bruger den valgte udbyders model. Kontrollér alle ruter før privat indhold.

## Eksempel

Vælg en tom `trial-concepts` og en testkilde. Gennemgå begreber og rapporteret complete-mappe. Kør trinnene separat først, hvis destinationen er uklar. Udvid efter kontrol.

## Tips

- Hold kæder overskuelige, så fejl og filernes oprindelse kan følges.
- Sletning beholder interaktiv bekræftelse; undgå sådanne trin i uovervågede kæder.
- Se log og filer efter annullering eller genoprettelseskonflikt.
- Test samme model/mappe; forbindelsestest beviser ikke kvoter til lange batcher.
