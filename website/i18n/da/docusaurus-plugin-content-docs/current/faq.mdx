# Ofte stillede spørgsmål

<TLDR>Start med en testnote, tilgængelig udbyder og tydelige destinationer. Svarene beskriver implementerede grænser; vejledningerne viser forberedelse og kontrol af resultater.</TLDR>

## Spørgsmål

### Hvordan installerer jeg Notemd?

Åbn Settings → Community plugins → Browse, find Notemd, installer og aktivér. Manuelt bruges main.js, manifest.json og styles.css fra samme GitHub Release. Manifestet angiver Obsidian 0.15.0; den ældre version og fysiske mobilenheder er ikke aktuelt verificeret.

### Hvilke LLM-udbydere understøttes?

36 profiler fordelt på fem familier: OpenAI-compatible, Anthropic, Google, Azure OpenAI og Ollama. Cloud, gateways og lokale servere kræver eget endpoint, nøgle og model. Profil eller modelliste garanterer ikke aktuel adgang eller genereringsret.

### Kan jeg bruge lokale modeller?

Ja, med Ollama, LM Studio, OVMS eller en aktiv kompatibel egen server. Forbered modellen og test en opgave. Lokal inferens gør ikke websøgning, afhængighedsinstallation eller særskilt cloudroutede opgaver offline.

### Hvad er forskellen fra ChatGPT?

Notemd fokuserer på dokumentopgaver i Obsidian: links, begreber, tilføjet research, oversættelse og diagrammer. Vælg efter arbejdet i din vault. Sammenlign aktuel lagring, eksport og integration; chatværktøjer kan også gemme historik og producere dokumenter.

### Hvordan sammenligner jeg med Copilot eller Smart Connections?

Sammenlign konkrete opgaver med aktuelle versioner, indstillinger og dokumentation. Notemd behandler noter og tilbyder afgrænset leksikal hentning, ikke generel vault-chat eller embeddingbaseret semantisk søgning. Ingen aktuel rangorden for andre projekter hævdes.

### Hvilke søgemaskiner bruges?

Vælg Tavily med nøgle eller DuckDuckGo eksplicit. Tom Tavily-nøgle skifter ikke tjeneste. Begge bruger netværk. LLM opsummerer webkontekst og valgfrie lokale uddrag og tilføjer teksten til aktiv Markdown. Kontrollér URL’er og væsentlige påstande.

### Hvilke sprog findes?

UI har 21 sprogversioner og webstedet 34 sprogruter. Genereringssprog vælges separat og kan ændres pr. understøttet opgave. Oversættelsesomfang og kvalitet afhænger af modellen, ikke af disse tal.

### Kan jeg bruge artikler eller PDF?

Konvertér først til Markdown med egnet eksternt værktøj, og kontrollér formler, tabeller og figurer. Brug derefter begreber, originalpassager, research, oversættelse eller diagrammer. Native PDF-OCR eller fejlfrit udtræk fra alle binære dokumenter loves ikke.

### Hvilke diagrammer findes?

Det eksekverbare katalog har 33 poster med passende kilder/previews. Mermaid, JSON Canvas, Vega-Lite, redigerbar HTML/SVG, Draw.io, Drawnix og afgrænset CircuitikZ tjener forskellige formål. Vælg understøttede kombinationer, og test målapplikationen; preview beviser ikke native redigering eller kompilering.

### Er Notemd gratis og open source?

Notemd har MIT-licens, offentligt repository og modtager gerne bidrag. Udbydere, inferens, søgning og eksterne værktøjer har egne omkostninger og vilkår. Pluginlicensen gør ikke alle tilsluttede tjenester gratis.

### Virker alt offline?

Nogle opgaver kan bruge lokal model efter forberedelse af server, modeller og afhængigheder. Websøgning, også DuckDuckGo, forbliver online. Kontrollér opgaverouting og eksportafhængigheder før frakobling. Ingen generel offlinegaranti gives.

### Sendes data til skyen?

Prompt og indhold sendes til konfigureret LLM-endpoint. Søgetjenester modtager forespørgsler og websteder anmodninger. Lokale uddrag kan indgå i cloudprompts; en lokal profil kan pege på ekstern vært. Kontrollér ruter og diagnostik. Lokal lagring garanterer ikke lokal behandling.

### Hvad gør One-Click Extract?

Standardkæden tilføjer links, genererer egnede noter fra titler i begrebs-/valgt mappe og reparerer Mermaid i complete. Eksisterende begreber kan indgå. Webresearch og diagramgenerering tilføjes ikke automatisk. Guiden viser præcis DSL name::action>action.

### Fortryder annullering ændringerne?

Nej. Understøttet videre arbejde stoppes, og færdige resultater bevares. Accepterede anmodninger/skrivninger kan afsluttes, og udbyderen styrer fakturering. Vent, kontrollér stier og konflikter, og gentag kun nødvendigt arbejde.

### Kan en Agent automatisere Notemd?

Fire afgrænsede offentlige kommandoer eksporterer maskerede profiler, kapabiliteter, kaldskontrakt og offentligt CLI-interface via fungerende Obsidian og vault. De skriver outputfiler. Vedligeholdelsesoperationer i repositoryet er separate; internt antal er ikke et offentligt API. Start med Agentguiden.

### Hvor begynder jeg som udvikler?

Udviklerguiden beskriver miljø, build, fulde tests, kildeansvar og udvidelseskontrakter. AGENTS.md er den versionsstyrede udførelsesautoritet. Rapportér reproduktion med præcise versioner og renset evidens, og validér før integration.
