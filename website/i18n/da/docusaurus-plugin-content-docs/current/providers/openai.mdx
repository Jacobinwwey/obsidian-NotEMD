# OpenAI

<TLDR>Profilen bruger den fælles OpenAI Chat Completions-runtime. Vælg nøgle og model til den protokol. Startmodellen garanterer ikke aktuel adgang eller universel kvalitet.</TLDR>

## Forberedelse

Brug **OpenAI**, nøgle og `https://api.openai.com/v1` til den officielle tjeneste. En listet model kan kræve en anden API. Gateways har egne profiler/headers; Azure bruger **Azure OpenAI**, deployment og API-version.

## Endpoint og autentifikation

| Felt | Startværdi |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API-nøgle | Påkrævet |
| Basis-URL | `https://api.openai.com/v1` |
| Model | `gpt-4o` |
| Temperatur | `0.5` |
| Forbindelsestest | `models-then-chat` |

Kendte URL-former normaliseres før opbygning af ruter. Start fra profilen, og kontrollér den afledte adresse frem for tilfældige ekstra stisegmenter.

## Modeller

**Fetch models** henter tilgængelige modeller. **Test connection** kan bestås på listen alene. Kontrollér den præcise model med en note. Reasoning, thinking, sampling og budgetter skal passe til profil/model.

## Problemer

- 401/403: nøgle, projekt, rettigheder og konto.
- 404: endpoint, model-ID og API-støtte.
- Liste virker, generering fejler: chatfejl og parametre.
- Langt svar afbrudt: input, budget og svar; kort test dækker ikke dette.

## Hvornår bruges profilen?

Til direkte OpenAI-endpoints med Chat Completions. Vurder dine egne noter; priser og adgang ændres uafhængigt af Notemd.
