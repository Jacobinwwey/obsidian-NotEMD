# Anthropic

<TLDR>Vælg profilen til native Messages. Claude via OpenAI-kompatibel gateway bruger gatewayprofilen. Den historiske startmodel kan kræve udskiftning med en tilgængelig model.</TLDR>

## Forberedelse

Vælg **Anthropic**, nøgle og tilgængelig model. Bevar native URL, medmindre din deployment leverer samme protokol. Test forbindelse og note.

## Endpoint og autentifikation

| Felt | Startværdi |
| ------- | -------------- |
| Transport | `anthropic` |
| API-nøgle | Påkrævet |
| Basis-URL | `https://api.anthropic.com` |
| Model | `claude-3-5-sonnet-20240620` |
| Temperatur | `0.5` |
| Forbindelsestest | `chat-only` |

Runtime bruger `/v1/messages` med native nøgle-/versionsheaders. Tilføj ikke OpenAI-chatstier. Startværdierne beskriver repositorykonfiguration, ikke aktuel modeltilgængelighed.

## Modeller

Brug native opdagelse, hvor det er tilladt. Er listen beskyttet, angiv et tilladt ID og test generering. Lange og strukturerede opgaver kræver særskilt kontrol.

## Problemer

- 401/403: nøgle, projekt, fakturering og modelrettigheder.
- 404: adresse og tilgængelighed.
- Gateway-ID afvises: vælg passende profil/ID.
- Lange anmodninger fejler: undersøg grænser før flere forsøg.

## Hvornår bruges profilen?

Til native Messages-endpoints. Sammenlign med egne kilder frem for en generel udbyderrangliste. Opgaverouting muliggør afgrænset brug.
