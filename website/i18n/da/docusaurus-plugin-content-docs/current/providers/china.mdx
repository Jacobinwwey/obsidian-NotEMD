# Kinesiske udbydere

<TLDR>Vælg profilen til konto og deployment. Selv med fælles OpenAI-kompatibel protokol er regioner, stier, modeller og rettigheder ikke udskiftelige. Kontrollér en lille opgave.</TLDR>

## Forberedelse

Opret konto/nøgle, vælg profil, og bekræft region/modeladgang. Standarder garanterer ikke aktuel tilgængelighed. Test forbindelse og note.

Erstat Doubao-eksemplet med faktisk Ark-endpoint-ID eller understøttet model. GLM og Z AI er separate regionale profiler. Nøgler fra anden region eller abonnementstype kan være ugyldige. Følg kontoinstruktioner, ikke alene fysisk placering.

## Modeller

Brug lister, hvor tilladt. Huawei Cloud MaaS kræver deploymentkendskab; andre bruger understøttet OpenAI-kompatibel opdagelse. Manglende listerettighed udelukker ikke altid generering med eksplicit ID. DeepSeek kan bestå forbindelsestest på en liste; flere regionale profiler genererer kort. En reel opgave skal stadig testes.

## Problemer

- Nøgle accepteret, generering afvist: modeladgang, deployment og region.
- Ark-ID afvist: kræves endpoint-ID eller model-ID?
- Ræsonnement afkortet: budget og modelspecifik thinking.
- Netværk: kontrollér adresse fra Obsidian, og læs transportfejlen.

## Hvornår bruges profilen?

Når konto, adgang og datavilkår passer. Geografi beviser hverken sprogkvalitet eller lav pris. Sammenlign samme prøve med dokumenterede indstillinger.
