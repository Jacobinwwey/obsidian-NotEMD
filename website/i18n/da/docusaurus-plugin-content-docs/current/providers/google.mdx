# Google

<TLDR>Google bruger native Gemini Generative Language. Angiv tilladt nøgle og tilgængelig model. Gemini via kompatibel gateway bruger gatewayprofilen.</TLDR>

## Forberedelse

Vælg **Google**, nøgle, native endpoint og model til den valgte API-version. Test forbindelse og note. Dette konfigurerer ikke vilkårlige Google Cloud-/Vertex-deployments automatisk.

## Endpoint og autentifikation

| Felt | Startværdi |
| ------- | -------------- |
| Transport | `google` |
| API-nøgle | Påkrævet |
| Basis-URL | `https://generativelanguage.googleapis.com/v1` |
| Model | `gemini-2.0-flash-exp` |
| Temperatur | `0.5` |
| Forbindelsestest | `chat-only` |

Der sendes `generateContent` med nøgle. Historiske ID’er garanterer ikke adgang. Gennemgå diagnostiske URL’er før deling; de kan indeholde autentifikation.

## Modeller

Brug native opdagelse, og verificér generering på den valgte API. Tom liste kan skyldes adgang, endpoint eller manglende model. Undersøg årsagen før protokolskift.

## Problemer

- 400: ID, parametre og input-/outputgrænser.
- 401/403: nøglebegrænsninger, aktiveret API og rettigheder.
- 404: findes modellen i denne API-version?
- Gatewayeksempler: brug korrekt OpenAI-kompatibel profil.

## Hvornår bruges profilen?

Til native Gemini. Test oversættelse, research eller diagrammer på egne data. Ingen generelle garantier for hastighed, pris eller kvalitet.
