# Batchbehandling

<TLDR>Mappehandlinger deler udvælgelse og statusvisning, men ikke overskrivningsadfærd. Standardsamtidighed er én. Begynd i en lille testmappe, kontrollér omfang og destinationer, og udvid derefter.</TLDR>

## Overblik

Sidepanel/filbrowser tilbyder links, begreber, titler, oversættelse, originalpassager samt Mermaid-/formelreparation for mapper. Ingen generel mappe-researchhandling findes; titelgenerering kan tilføje research. En batch er ingen mappetransaktion: færdigt output bevares ved fejl og annullering.

## Sådan virker det

### Udførelsesmodel

1. Vælg opgave og en mappe med kun de ønskede filer.
2. Filendelser, udvælgelse og opgavespecifikke outputfiltre bestemmer kandidater.
3. Opgaven anvender sin udbyder/model og rapporterer status, fejl og stier.
4. Gennemgå rapport og output efter afslutning/annullering, før du gentager.

Links, begreber, titler, originalpassager, Mermaid og formler inkluderer normalt undermapper. **Mappeoversættelse bruger normalt kun direkte børn.** Udviklertilstand og avancerede udvælgelsesprofiler kan ændre omfang/filtre. Kontrollér faktiske træffere.

### Overskrivning

| Opgave | Kontrol før gentagelse |
| ------ | ------------------------------------ |
| Links | Separat standardresultat; kontrollér eget suffiks, mappe og flytning |
| Begreber | Aktive backlinks kan supplere eksisterende noter; dubletter håndteres særskilt |
| Titelgenerering | Skriver egnede kilder og flytter, hvis complete-målet er ledigt |
| Oversættelse | Eksisterende oversættelse kan erstattes; normalt `_<language>.md` |
| Mermaid / formler | Ændrer valgte noter; gennemgå og tag backup |

Ingen fælles spring over/tilføj/erstat-indstilling. Et optaget complete-mål blokerer flytningen efter titelgenerering, ikke selve genereringen. Genereret og flyttet tælles separat.

### Samtidighed

Behold `batchConcurrency: 1`, til en stikprøve virker. Nogle ruter kræver også `enableBatchParallelism`; mappeoversættelse anvender samtidigheden direkte. Mere parallelisme belaster udbyder, hukommelse og lokal server og garanterer ikke højere hastighed. Intervaller mellem anmodninger/grupper fjerner ikke alle kvoter eller anden brug af kontoen.

## Indstillinger

| Indstilling | Startværdi | Virkning |
| --------- | --------- | -------- |
| `batchConcurrency` | `1` | Ønsket samtidighed på relevante ruter |
| `enableBatchParallelism` | `false` | Aktivér understøttet parallel planlægning |
| `batchSize` | `50` | Gruppestørrelse ved batchplanlægning |
| `batchInterDelayMs` | `1000` | Pause mellem planlagte grupper |
| `apiCallIntervalMs` | `500` | Interval mellem samtidige API-anmodninger |
| `folderTaskIncludeSubfoldersMode` | `legacy` | Bevar hver opgaves undermappeadfærd |
| `enableStableApiCall` | `false` | Eksplicit stabil anmodningstilstand |

### Opgavemodeller

Mappehandlinger følger den tilsvarende filopgaves modelvalg. Kontrollér ruter før privat materiale. Lokal kontekst ved batchtitelgenerering bruger ét snapshot fra start: løbende ændringer blandes ikke ind i senere opslag. Start ny batch for at medtage dem.

## Eksempel

Opret `trial-titles` med to titelnoter. Kør **Batch generate from titles**, og kontrollér indhold, tilstødende `trial-titles_complete` samt antal genereret/flyttet/fejl. Undersøg en mislykket fil først. Gentagelse af kildemappen genoptager ikke automatisk præcis resten.

## Annullering og genoprettelse

Annullering stopper ny planlægning og understøttede anmodninger. Eksterne systemer kan fuldføre accepterede anmodninger/skrivninger; udbyderen styrer fakturering. Vent, sammenlign færdige filer med genoprettelses-/konfliktstier, og ryd først op efter kontrol.

## Tips

- Kontrollér profilens faktiske filudvalg.
- Sænk samtidighed, og undersøg kvoter ved 429.
- Skeln annulleret, fejlet og færdigt.
- Gem en uændret prøve og backup.
