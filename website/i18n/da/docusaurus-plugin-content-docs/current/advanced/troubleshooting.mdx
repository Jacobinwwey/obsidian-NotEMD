# Fejlfinding

<TLDR>Genskab problemet på én testnote med samme udbyder, model og opgaveindstillinger. Læs status og outputsti. Adskil autentifikation, generering, parsing og skrivning; forbindelsestesten dækker ikke hele arbejdsgangen.</TLDR>

## Overblik

Notér Notemd-/Obsidian-version, OS, handling, protokol, model og minimale trin. Start ikke forfra, mens annullering afsluttes. Bevar output og genoprettelsesfiler, indtil oprindelsen er klar.

## Diagnostik

### Forbindelsestest

**Test connection** kan kun kontrollere en modelliste eller en kort generering. Kør derefter en lille rigtig opgave med valgt model og outputformat.

### Status og udviklerdiagnostik

Status viser fejl og filplaceringer; API-aktivitet skelner ventende og færdige anmodninger. Brug debug efter behov. Lang diagnostik kan bruge kvoter. Rapporter kan indeholde noter, delsvar, endpointdetaljer og nøgler. Gennemgå og maskér lokalt før deling, også metadata i maskerede profiler.

## Typiske fejl

### Ugyldig eller manglende nøgle

401: korrekt profil/endpoint, ingen utilsigtede mellemrum. 403: konto, projekt, modelrettigheder og betaling. Gentagelse retter ikke legitimationsfejl.

### Netværk

Kontrollér vært, port, protokol og sti fra Obsidian-enheden. Ollama/LM Studio skal køre med modellen tilgængelig. `localhost` er denne enhed, ikke en anden computer. Vælg korrekt profil; fallback vælges automatisk, ikke via en transportknap.

### Begrænsning 429

Sænk samtidighed, og undersøg anmodnings-/tokenkvoter samt anden brug af nøglen. Nye forsøg løser kun visse midlertidige fejl.

### Model ikke fundet

Brug **Fetch models** eller kendt model/deployment. Kontrollér API-version og region. Eksempler kan være forældede; Azure kræver deployment, Ark kan kræve endpoint-ID.

### Ingen links eller begreber

Kontrollér faktisk outputfil, brugbar kilde, svarformat og valgt aktiv begrebsmappe. Selvstændigt udtræk starter med titler uden backlinks. Sammenlign med standardprompten, hvis markører er fjernet.

### Output mangler eller ligger forkert

Læs rapporteret `_processed.md`, `_<language>.md` eller complete-sti. En fejlet oversættelsesmappe kan give fallback til kildemappen. Undersøg konflikter og rettigheder før gentagelse.

### Filer efter annullering

Færdige skrivninger bevares; accepterede anmodninger kan afsluttes. Gennemgå filer og genoprettelseskonflikter før sletning eller ny hel mappekørsel.

### Diagram eller native eksport

Vælg understøttet type/kilde, og kontrollér slide-/CircuitikZ-miljø. Preview er ingen native test. Gem tekstkilde til det rigtige eksterne værktøj, hvis visuelt preview mangler. [Diagrammer](../features/diagrams).

## Rapportér en fejl

1. Reproducér med syntetisk note og testmappe.
2. Angiv versioner, handling, model, nødvendige indstillinger samt forventet/faktisk resultat.
3. Vedlæg minimale filer/logs uden nøgler, privat tekst eller overflødig endpointmetadata.
4. Angiv om fejlen findes på én fil med standardprompts.
5. Åbn [GitHub Issues](https://github.com/Jacobinwwey/obsidian-NotEMD/issues).

Et screenshot beviser sjældent alene en format- eller annulleringsfejl. Giv om muligt kilde/output eller minimale reproduktionstrin.
