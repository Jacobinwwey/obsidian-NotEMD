# Egne prompts

<TLDR>En ikke-tom egen prompt erstatter standarden, når både global og opgavespecifik kontakt er slået til. Bevar outputkontrakten: skabelonsystemet genindsætter ikke automatisk udeladte formatinstruktioner.</TLDR>

## Overblik

Prøv standarden på en repræsentativ note først. Fagområde- eller synonyminstruktion kan være nok. Tilpas struktur, politik eller oversættelsesstil efter behov, og sammenlign før batch.

## Sådan virker det

### Sammensætning

Notemd vælger standard/egen prompt, tilføjer relevante fagområde-/sproginstruktioner og indsætter opgavens variabler. Notetekst kan være en separat besked. Variabler er ikke universelle. En erstatning kan udelade `CONCEPT:` eller researchkontekst; gyldig anmodning beviser ikke parsebart eller underbygget output.

### Variabler

Brug præcis versalisering og enkelte klammer:

| Opgave | Tilgængelige variabler |
| ------ | ----------------------- |
| Titelgenerering | `{TITLE}`, `{RESEARCH_CONTEXT_SECTION}` |
| Researchopsummering | `{TOPIC}`, `{LANGUAGE}`, `{SEARCH_RESULTS_CONTEXT}` |
| Oversættelse | `{LANGUAGE}`, `{TEXT}` |
| Originalpassager | `{REFERENCE_CONTENT}`, `{USER_INPUT}` |

`{LANGUAGE}` følger opgavens sprogpolitik. Links og selvstændigt begrebsudtræk sender tekst som opgaveindhold; opfind ikke flere pladsholdere. Ukendte navne udfyldes ikke. Dette er promptvariabler, ikke begrebsfilskabeloner.

### Afgrænset fagområde

Aktivér fokuseret læring og angiv eksempelvis `elektroteknik`. `Relevant Fields` guider opmærksomheden uden hårdt filter eller garanti for udelukkelse.

## Indstillinger

| Opgave | Kontakt | Promptfelt |
| ------ | --------------- | -------------- |
| Links | `useCustomPromptForAddLinks` | `customPromptAddLinks` |
| Titler | `useCustomPromptForGenerateTitle` | `customPromptGenerateTitle` |
| Research | `useCustomPromptForResearchSummarize` | `customPromptResearchSummarize` |
| Mermaid-opsummering | `useCustomPromptForSummarizeToMermaid` | `customPromptSummarizeToMermaid` |
| Begreber | `useCustomPromptForExtractConcepts` | `customPromptExtractConcepts` |
| Oversættelse | `useCustomPromptForTranslate` | `translatePrompt` |
| Originaltekst | `useCustomPromptForExtractOriginalText` | `customPromptExtractOriginalText` |

Alle kræver `enableGlobalCustomPrompts`. Tom tekst bruger standarden. Sammenlagt originaltekstudtræk har sin egen faste form, hvor almindelig override ikke gælder. Diagramgenerering kræver typet output; Mermaid-prompten er ikke universel.

## Eksempel

Aktivér global og begrebsspecifik kontakt, og bevar parsermarkøren:

```text
Udtræk notens vigtigste elektrotekniske begreber.
Prioritér konkrete komponenter og fysiske mekanismer frem for generelle navneord.
Skriv ét begreb pr. linje i præcis denne form:
CONCEPT: Begrebets navn
Tilføj ingen forklaringer eller omsluttende kodeblok.
```

Sammenlign linjer, filnavne og manglende begreber med standarden på en kopi. Gem den forrige prompt, så du kan vende tilbage.

## Tips

- Test én opgave før større batcher.
- Bevar researchkilder og præcise citater.
- Oversæt instruktioner med uændrede ID’er og markører.
- Test efter modelskift; instruktioner er ingen valideringsgaranti.
