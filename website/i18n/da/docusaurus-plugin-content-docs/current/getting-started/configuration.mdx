# Konfiguration

<TLDR>Åbn Settings → Notemd, og søg efter feltet. Vælg udbyder og outputplacering før opgaven. Afprøv ændringer på én note; en kørende opgave kan beholde indstillingerne fra start.</TLDR>

## Overblik

Standardudbyderen er DeepSeek uden legitimationsoplysninger. En profil opretter ingen konto, installerer ingen model og giver ingen rettigheder. Se [udbyderguiden](../providers/overview).

<!-- notemd-settings-favorites-guide -->
## Søgning og favoritter

**Search settings** søger i navne, beskrivelser, aliaser og synlige kategorier og fører til feltet. **★ Favorites** viser gemte indstillinger med beskrivelse, kategori og destination. De gemmes pr. vault, overlever genstart og fjerner gamle ID’er. Søgningen bevares, når værktøjslinjen foldes sammen. Favoritlisten er forskellig fra søgefilteret for kun favoritter.

**Diagram preview export PPI** er oprindeligt 300, interval 72–600, og påvirker kun PNG. SVG/PDF bevarer understøttet vektorgeometri. **Also export complete Mermaid visuals** styrer ledsagefiler, ikke om Mermaid vises i Drawnix-preview.

## 1. Udbyder

Angiv endpoint til korrekt protokol, krævet nøgle og tilgængelig model. Modelliste og generering er separate kontroller. Lokal server/model skal være klar; cloud/gateway modtager indhold. Kontrollér også opgavespecifikke ruter før privat materiale.

## 2. Model pr. opgave

`useMultiModelSettings` giver særskilte udbydere/modeller til links, titler, research, oversættelse, begreber, originaltekst og Mermaid. Tom override bruger udbyderens model; deaktiveret bruger den aktive udbyder. Sammenlign præcision, ventetid og faktiske omkostninger på samme note.

## 3. Output

| Opgave | Standardresultat |
| ------ | ------------------------- |
| Links | Separat `_processed.md` ved kilden; flytning af original er fra |
| Selvstændigt begrebsudtræk | Valgt begrebsmappe; kun titel, backlinks fra |
| Oversættelse | Ved siden af som `_<language>.md`; eksisterende mål kan overskrives |
| Research | Opsummering føjes til aktiv Markdown |
| Batchgenerering fra titler | Skriver egnede kilder og flytter til tilstødende `<folder>_complete`, hvis målet tillader det |
| Diagram-preview/eksport | Vælg understøttet kilde eller visuel eksport og kontrollér rapporteret sti |

Begrebsmappen starter tom; `concepts` er et eksempel. Selvstændige noter har minimal/fuld form, ingen generel skabelonmotor. [Begreber](../features/concept-notes). Behandling og oversættelse har hver deres suffikser/mapper. Kontrollér mål og genoprettelseskonflikter; annullering ruller ikke færdige skrivninger tilbage.

## 4. Sprog

UI har 21 sprogversioner, webstedet 34 sprogruter. `uiLocale: auto` vælger understøttet mapping, ellers engelsk. Genereret sprog er særskilt og starter som engelsk. Understøttede opgaver kan have eget sprog; oversættelse bruger `language`. Antallene beviser ikke modellernes sprogevner.

## 5. Søgning

Vælg Tavily med nøgle eller DuckDuckGo eksplicit. Tom Tavily-nøgle skifter ikke tjeneste. Begge bruger netværk; DuckDuckGo kan hente resultatsider. Research ved titelgenerering er fra: `enableResearchInGenerateContent`. Lokal hentning er også fra med egne mappe-/opgavegrænser. Lokale uddrag i konteksten sendes til valgt LLM.

## 6. Arbejdsgange

Brug byggeren eller én navngiven DSL-linje pr. knap:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

`::` adskiller navn og handlinger, `>` adskiller handlings-ID’er. Standardpolitikken stopper ved rapporteret fejl. Se [arbejdsgange](../features/workflows) for omfang og fortsættelse efter fejl.

## 7. Avancerede indstillinger

| Indstilling | Startværdi | Virkning |
| --------- | --------- | -------- |
| `activeProvider` | `DeepSeek` | Udbyder uden separat opgaverute |
| `useMultiModelSettings` | `false` | Udbyder/model pr. opgave |
| `useCustomConceptNoteFolder` | `true` | Tillad begrebsoutput efter valg af mappe |
| `conceptNoteFolder` | `''` | Ingen begrebsmappe fra start |
| `extractConceptsMinimalTemplate` | `true` | Kun titel i selvstændige begreber |
| `extractConceptsAddBacklink` | `false` | Backlinks ved selvstændigt udtræk |
| `moveOriginalFileOnProcess` | `false` | Bevar original ved linktilføjelse |
| `chunkWordCount` | `3000` | Omtrentlige tekststykker, ikke tokengrænse |
| `batchConcurrency` | `1` | Standard for batchsamtidighed |
| `enableBatchParallelism` | `false` | Parallel planlægning på ruter, der bruger kontakten |
| `enableStableApiCall` | `false` | Eksplicit stabil anmodningstilstand |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stop arbejdsgang ved rapporteret fejl |

Størrelsen af tekststykker og outputbudgettet i tokens er forskellige. Mindre stykker løser ikke alle kontekstgrænser, og lav samtidighed forhindrer ikke alle 429-fejl.

## Indstillingsprofiler

Indstillinger er plugin-data i din vault. Sikkerhedskopiér før ændring. Udbydereksport har egen maskeringskontrakt, ikke en fuld vault-backup. Kontrollér endpoints og metadata, også i maskeret output. Offentliggør ikke rå indstillinger eller diagnostik med private noter.

## Konfigurationsproblemer

Test præcis udbyder/model med en lille note. Mangler et felt, kontrollér søgning, kategori, udviklertilstand og vault. Rapportér version og minimale indstillinger uden hemmeligheder.
