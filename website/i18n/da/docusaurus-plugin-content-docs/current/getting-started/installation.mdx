# Installation

<TLDR>Installer Notemd via Community plugins, eller læg de tre programfiler fra samme GitHub Release i din vault. Aktivér udvidelsen, vælg udbyder, og test en note. Modelservere og valgfrie native eksportværktøjer forberedes separat.</TLDR>

## Metode 1: Community plugins, anbefalet

1. Åbn **Settings → Community plugins** i den ønskede vault.
2. Tillad community-udvidelser om nødvendigt, og vælg **Browse**.
3. Søg efter **Notemd**, kontrollér `Jacobinwwey/obsidian-NotEMD`, og vælg **Install**.
4. Vælg **Enable**, og åbn sidepanelet fra værktøjslinjen eller kommandopaletten.

[Åbn Notemd i Obsidian](obsidian://show-plugin?id=notemd). Brug menuen ovenfor, hvis browseren ikke åbner linket. Vejledningen kan læses uden en protokolhåndtering.

## Metode 2: Manuel installation

### Forudsætninger

Du skal have Obsidian og en vault, der kan sikkerhedskopieres. Manifestets minimum `0.15.0` er en erklæring, ikke dokumentation for en frisk test på den version.

### Trin

1. Hent `main.js`, `manifest.json` og `styles.css` fra samme [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` er reference, ikke en nødvendig programfil.
2. Placér de tre filer i `<vault>/.obsidian/plugins/notemd/`. Tilpas stien, hvis konfigurationsmappen er ændret.
3. Genindlæs Obsidian, og aktivér udvidelsen.
4. Kontrollér versionen; bland ikke nyt manifest med gammel bundle.

## Alternativ: BRAT

Bruger du allerede [BRAT](https://github.com/TfTHacker/obsidian42-brat), kan projektet tilføjes via dets beta-plugin-forløb. Brug en bestemt release til reproduktion af fejl. BRAT er et valgfrit eksternt værktøj.

## Kontrol

Vælg en tilgængelig model, kør **Test connection** og derefter [hurtigstart](./quick-start). En modelliste beviser ikke adgang til at generere med modellen; kontrollér det faktiske output.

## Systemgrænser

| Del | Grænse |
| --------- | ---------- |
| Manifest | Mindst Obsidian `0.15.0`; `isDesktopOnly` er false |
| Testgrundlag | Se daterede rapporter; fysiske mobilenheder og 0.15.0 er ikke verificeret i den aktuelle accept |
| Cloudmodel | Netværk, autoriseret konto/nøgle og tilgængelig model |
| Lokal model | Separat installeret, aktiv server og hentet/indlæst model |
| Native præsentations- eller kredsløbseksport | Desktopværktøjer og formatafhængigheder; kontrollér miljøet først |

Der er ingen fælles OS-versionsgaranti for alle valgfrie eksportører. Kredsløbspreview beviser ikke TeX-kompilering, og desktoptest beviser ikke mobiladfærd.

## Afinstallation

Deaktivér eller afinstallér under Community plugins. Genererede noter og artefakter bliver liggende som almindelige vault-filer. Gennemgå dem før sletning; gem indstillingerne, hvis du vil geninstallere. Afinstallation fortryder ikke tidligere ændringer.

## Opdatering

Brug **Check for updates**. Ved manuel opdatering: stop opgaver, sikkerhedskopiér vault og indstillinger, erstat de tre programfiler fra samme release, og genindlæs. Læs ændringerne og test småt før batcher. Erstat ikke indstillingsfilen med et release-asset. Tilbageførsel kræver en bevidst valgt kompatibel version og sikkerhedskopi.
