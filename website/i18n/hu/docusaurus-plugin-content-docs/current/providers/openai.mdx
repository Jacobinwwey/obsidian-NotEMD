# OpenAI

<TLDR>A profil a közös OpenAI Chat Completions megvalósítást használja. Ehhez a protokollhoz jogosult kulcsot és modellt válasszon. Az alapmodell nem garantál jelenlegi hozzáférést vagy általános minőséget.</TLDR>

## Előkészítés

A hivatalos szolgáltatáshoz válassza az **OpenAI** profilt, kulcsot és `https://api.openai.com/v1` címet. Listázott modell más API-t is igényelhet. Az átjáróknak saját profiljuk/fejléceik vannak; Azure-hoz **Azure OpenAI**, deployment és API-verzió kell.

## Végpont és hitelesítés

| Mező | Alapérték |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API-kulcs | Kötelező |
| Alap-URL | `https://api.openai.com/v1` |
| Modell | `gpt-4o` |
| Hőmérséklet | `0.5` |
| Kapcsolatteszt | `models-then-chat` |

Az ismert URL-változatok normalizálódnak az útvonal összeállítása előtt. Kezdjen a profillal, és ellenőrizze a kész címet; ne adjon hozzá találomra szegmenseket.

## Modellek

A **Fetch models** modelleket listáz. A **Test connection** ettől már sikeres lehet. A pontos modellt jegyzettel próbálja. Reasoning, thinking, mintavétel és keret illeszkedjen a profilhoz/modellhez.

## Hibaelhárítás

- 401/403: kulcs, projekt, jogosultság és fiók.
- 404: végpont, modell-ID és API-támogatás.
- Lista működik, generálás nem: chat-hiba és paraméterek vizsgálata.
- Hosszú válasz megszakad: bemenet, keret és választest; a rövid próba ezt nem igazolja.

## Mikor megfelelő?

Közvetlen OpenAI-végponthoz, Chat Completions használatával. Saját jegyzeteken mérjen; ár és elérhetőség a Notemdtől függetlenül változhat.
