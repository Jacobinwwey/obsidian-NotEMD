# Google

<TLDR>A Google-profil a natív Gemini Generative Language protokollt használja. Jogosult kulcsot és elérhető modellt állítson be. Kompatibilis átjáró Gemini-modelljéhez az átjáró profilját válassza.</TLDR>

## Előkészítés

Válassza a **Google** profilt, kulcsot, natív végpontot és az API-verzióban elérhető modellt. Kapcsolatot és jegyzetet is teszteljen. Ez nem állít be automatikusan tetszőleges Google Cloud/Vertex telepítést.

## Végpont és hitelesítés

| Mező | Alapérték |
| ------- | -------------- |
| Transport | `google` |
| API-kulcs | Kötelező |
| Alap-URL | `https://generativelanguage.googleapis.com/v1` |
| Modell | `gemini-2.0-flash-exp` |
| Hőmérséklet | `0.5` |
| Kapcsolatteszt | `chat-only` |

A kérés `generateContent` formát és kulcsot használ. Történeti ID nem garantál hozzáférést. Diagnosztikai URL megosztás előtt vizsgálandó, mert hitelesítő adatot tartalmazhat.

## Modellek

Szolgáltatói felderítés után a kiválasztott API-n teszteljen generálást. Üres lista lehet jogosultság-, végpont- vagy modellhiba; protokollváltás előtt vizsgálja meg.

## Hibaelhárítás

- 400: ID, paraméterek és bemeneti/kimeneti korlátok.
- 401/403: kulcskorlátozás, API-engedélyezés és jogok.
- 404: modell elérhetősége az adott API-verzióban.
- Átjárópélda: válasszon megfelelő OpenAI-compatible profilt.

## Mikor megfelelő?

Natív Geminihez. Fordítást, kutatást vagy diagramot saját anyagon értékeljen. Nincs általános sebesség-, ár- vagy minőségi garancia.
