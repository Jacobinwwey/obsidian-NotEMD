# Anthropic

<TLDR>A profil a natív Messages API-hoz való. OpenAI-kompatibilis átjáró Claude-modelljéhez az átjáró profilját használja. A történeti alapmodellt szükség lehet elérhetőre cserélni.</TLDR>

## Előkészítés

Válassza az **Anthropic** profilt, adjon kulcsot és elérhető modellt. A natív végpontot csak azonos protokollú telepítésre cserélje. Kapcsolatot és jegyzetet is teszteljen.

## Végpont és hitelesítés

| Mező | Alapérték |
| ------- | -------------- |
| Transport | `anthropic` |
| API-kulcs | Kötelező |
| Alap-URL | `https://api.anthropic.com` |
| Modell | `claude-3-5-sonnet-20240620` |
| Hőmérséklet | `0.5` |
| Kapcsolatteszt | `chat-only` |

A megvalósítás `/v1/messages` útvonalat és saját kulcs/verzió fejléceket használ. Ne adjon hozzá OpenAI chat-útvonalat. Az alapérték a tároló konfigurációja, nem mai elérhetőségi ígéret.

## Modellek

Használja a natív felderítést, ahol engedett. Védett listánál adjon jogosult ID-t, és próbáljon generálni. Hosszú vagy strukturált feladat külön tesztet igényel.

## Hibaelhárítás

- 401/403: kulcs, projekt, számlázás és modelljog.
- 404: cím és elérhetőség.
- Átjáró-ID elutasítása: megfelelő profil és ID szükséges.
- Hosszú kérések hibája: újrapróbálás növelése előtt keretek ellenőrzése.

## Mikor megfelelő?

Natív Messages API-hoz. Saját forrásokon értékeljen, ne általános szolgáltatórangsor alapján. Feladatonkénti útválasztással célzottan használható.
