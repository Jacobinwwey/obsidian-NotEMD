# Munkafolyamatok

<TLDR>A munkafolyamat az oldalsáv műveleteit egymás után futtatja. Egy-egy lépés mappaválasztást vagy aktív szerkesztőt igényelhet. Nem szöveges csővezeték: minden művelet megtartja bemenetét, kimenetét és mellékhatásait. Kezdjen próbaadatokkal.</TLDR>

## Áttekintés

Az alapértelmezett **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Hivatkozásokat ad az aktív jegyzethez, beállított mappával fogalmakat hozhat létre.
2. A fogalom- vagy választott mappa alkalmas jegyzeteihez cím alapján tartalmat generál, meglévőkhöz is.
3. A generálás complete mappájában Mermaid-javítást végez.

Az alaplánc nem kutat a weben. A címgenerálás kutatása külön bekapcsolható. [Kötegek](../advanced/batch-processing).

## Működés

### Végrehajtás

A lépések sorban futnak, állapotuk és hibáik a panelen láthatók. A megszakítás leállítja a további lépéseket és támogatott kéréseket. A kész fájlok megmaradnak; nincs közös tranzakció. Elsőbbséget kap a fogalommappa. A kötegelt címgenerálás megjegyzi a forrás- és complete mappát; a Mermaid-javítás a complete mappát használja. Más műveletek megőrzik fájl-, kijelölés- és interakcióigényüket.

### DSL

Soronként egy elnevezett gomb. A `::` elválasztja a nevet, a `>` a művelet-ID-kat. Üres és `#` kezdetű sorok kimaradnak; ismeretlen ID-t a parser elutasít.

```text
Fogalmak és diagram::extract-concepts-current>summarize-as-mermaid
```

Használja a munkafolyamat-szerkesztőt vagy a DSL-t. Az ID stabil, a címke felületfüggő. A mappaváltozatok saját ID-val rendelkeznek; ne képezze őket találomra.

| ID | Művelet / követelmény |
| ------------ | ----------------------- |
| `process-current-add-links` | Hivatkozások az aktív jegyzetben |
| `process-folder-add-links` | Hivatkozások a választott mappában |
| `extract-concepts-current` | Fogalmak az aktív jegyzetből |
| `extract-concepts-folder` | Fogalmak a választott mappából |
| `generate-from-title` | Tartalom az aktív címből |
| `batch-generate-from-titles` | Mappa alkalmas jegyzeteinek kitöltése |
| `research-and-summarize` | Kutatás kijelölés/cím alapján nyitott Markdown-szerkesztőben |
| `summarize-as-mermaid` | Támogatott aktív bemenet Mermaid-összefoglalása |
| `generate-diagram` | Diagram támogatott bemenetből |
| `preview-diagram` | Támogatott forrás vagy diagram előnézete |
| `translate-current-file` | Aktív támogatott fájl fordítása |
| `batch-translate-folder` | Választott mappa fordítása |
| `extract-original-text` | Kért eredeti részletek kinyerése |
| `batch-extract-original-text` | Részletek mappa alkalmas fájljaiból |

### Alaplánc vagy saját sor

A One-Click Extract előre beállított. Más gombhoz adjon nevet és sorrendet, nézze meg a panel leírását, és használat előtt javítsa a parserhibát.

## Beállítások

| Beállítás | Alapérték | Hatás |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Leállás az első jelentett lépéshibánál |
| `useMultiModelSettings` | `false` | Aktív szolgáltató a feladatútválasztás bekapcsolásáig |
| `enableResearchInGenerateContent` | `false` | Címgenerálás kutatás nélkül, amíg külön nem engedélyezi |

A `continue_on_error` hibák után is folytat. Csak akkor használja, ha a következő lépések a megmaradt bemenetből működhetnek. A folytatás nem teszi sikeressé a részleges folyamatot.

### Modell lépésenként

A modell a feladathoz tartozik. Üres mező annak szolgáltatói modelljét használja. Magánadatok előtt az összes útvonalat ellenőrizze.

## Példa

Válasszon üres `trial-concepts` mappát és próba-forrásjegyzetet. Nézze meg a fogalmakat és jelentett complete helyet. Bizonytalan cél esetén futtassa a lépéseket külön. Csak ellenőrzés után bővítsen.

## Javaslatok

- Átlátható lánc segíti a hibák és fájleredet követését.
- Törlési lépések megtartják interaktív jóváhagyásukat; ne használja felügyelet nélkül.
- Megszakítás és ütközés után olvassa a naplót és fájlokat.
- Pontos modellt/mappát teszteljen; a kapcsolatteszt nem bizonyít nagy köteghez elegendő kvótát.
