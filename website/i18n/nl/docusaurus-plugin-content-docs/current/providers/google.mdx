# Google-provider

<TLDR>Google gebruikt native Gemini Generative Language. Stel toegestane sleutel en beschikbaar model in. Voor Gemini via een compatibele gateway kies je het gatewayprofiel.</TLDR>

## Voorbereiding

Kies **Google**, sleutel, native endpoint en model van de gekozen API-versie. Test verbinding en notitie. Dit configureert geen willekeurige Google Cloud- of Vertex-deployment automatisch.

## Endpoint en authenticatie

| Veld | Beginwaarde |
| ------- | -------------- |
| Transport | `google` |
| API-sleutel | Verplicht |
| Basis-URL | `https://generativelanguage.googleapis.com/v1` |
| Model | `gemini-2.0-flash-exp` |
| Temperatuur | `0.5` |
| Verbindingstest | `chat-only` |

Er wordt een `generateContent`-aanvraag met sleutel gemaakt. Historische ID’s garanderen geen toegang. Controleer diagnose-URL’s vóór delen; ze kunnen authenticatie bevatten.

## Modellen

Gebruik native ontdekking en verifieer generatie op de gekozen API. Een lege lijst kan duiden op rechten, endpoint of ontbrekend model. Diagnoseer voordat je het protocol wijzigt.

## Problemen

- 400: ID, parameters en in-/uitvoerlimieten.
- 401/403: sleutelbeperkingen, ingeschakelde API en rechten.
- 404: model beschikbaar in deze API-versie?
- Gatewayvoorbeelden: gebruik het juiste OpenAI-compatible profiel.

## Wanneer gebruiken

Voor native Gemini. Test vertaling, onderzoek of diagrammen op eigen materiaal. Geen algemene garanties voor snelheid, kosten of kwaliteit.
