# OpenAI-provider

<TLDR>Dit profiel gebruikt de gedeelde OpenAI Chat Completions-runtime. Kies een sleutel en model voor dat protocol. De beginwaarde garandeert geen actuele toegang of universele kwaliteit.</TLDR>

## Voorbereiding

Gebruik **OpenAI**, sleutel en `https://api.openai.com/v1` voor de officiële dienst. Een model in de lijst kan een andere API vereisen. Gateways hebben eigen profielen/headers; Azure gebruikt **Azure OpenAI**, deployment en API-versie.

## Endpoint en authenticatie

| Veld | Beginwaarde |
| ------- | -------------- |
| Transport | `openai-compatible` |
| API-sleutel | Verplicht |
| Basis-URL | `https://api.openai.com/v1` |
| Model | `gpt-4o` |
| Temperatuur | `0.5` |
| Verbindingstest | `models-then-chat` |

Bekende URL-vormen worden genormaliseerd voordat routes worden gebouwd. Begin bij het profiel en controleer het opgeloste adres in plaats van willekeurig padsegmenten toe te voegen.

## Modellen

**Fetch models** vraagt beschikbare modellen op. **Verbinding testen** kan met alleen de lijst slagen. Controleer het exacte model met een notitie. Reasoning, thinking, sampling en budgetten moeten bij profiel/model passen.

## Problemen

- 401/403: sleutel, project, rechten en account.
- 404: endpoint, model-ID en API-ondersteuning.
- Lijst werkt maar generatie niet: chatfout en parameters.
- Lang antwoord afgebroken: invoer, budget en antwoord; een korte test dekt dit niet.

## Wanneer gebruiken

Voor directe OpenAI-endpoints die Chat Completions ondersteunen. Beoordeel eigen notities; prijzen en beschikbaarheid veranderen onafhankelijk van Notemd.
