# Anthropic-provider

<TLDR>Gebruik dit profiel voor native Messages. Claude via een OpenAI-compatible gateway gebruikt het gatewayprofiel. Het historische beginmodel kan vervangen moeten worden door een beschikbaar exemplaar.</TLDR>

## Voorbereiding

Kies **Anthropic**, sleutel en toegankelijk model. Behoud de native URL tenzij je deployment hetzelfde protocol biedt. Test de verbinding en één notitie.

## Endpoint en authenticatie

| Veld | Beginwaarde |
| ------- | -------------- |
| Transport | `anthropic` |
| API-sleutel | Verplicht |
| Basis-URL | `https://api.anthropic.com` |
| Model | `claude-3-5-sonnet-20240620` |
| Temperatuur | `0.5` |
| Verbindingstest | `chat-only` |

De runtime gebruikt `/v1/messages` met native sleutel- en versieheaders. Voeg geen OpenAI-chatroute toe. Beginwaarden beschrijven de repositoryconfiguratie, geen actuele beschikbaarheid.

## Modellen

Gebruik native ontdekking waar beschikbaar. Is de lijst afgeschermd, geef een toegestaan ID en test generatie. Lange en gestructureerde taken vereisen aparte controles.

## Problemen

- 401/403: sleutel, project, facturering en modelrechten.
- 404: adres en beschikbaarheid.
- Gateway-ID geweigerd: kies passend profiel/ID.
- Lange fouten: onderzoek limieten voordat je meer herhalingen instelt.

## Wanneer gebruiken

Voor native Messages-endpoints. Vergelijk resultaten met eigen bronnen zonder universele providerrangorde. Taakroutering laat gericht gebruik toe.
