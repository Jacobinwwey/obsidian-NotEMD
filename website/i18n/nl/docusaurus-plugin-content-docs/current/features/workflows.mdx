# Workflows

<TLDR>Een workflow voert zijbalkacties na elkaar uit. Een actie kan een mapkeuze of actieve editor vereisen. Dit is geen tekstpijplijn: elke stap houdt eigen invoer, uitvoer en neveneffecten. Begin met een testnotitie en aparte map.</TLDR>

## Overzicht

De meegeleverde **One-Click Extract**:

```text
One-Click Extract::process-current-add-links>batch-generate-from-titles>batch-mermaid-fix
```

1. Voeg links toe aan de actieve notitie; maak concepten als een map is ingesteld.
2. Genereer inhoud voor geschikte notities in de concept- of gekozen map, inclusief bestaande notities.
3. Herstel Mermaid in de complete-map van die generatie.

De standaardketen doet geen webonderzoek. Generatie kan dat alleen met de aparte instelling toevoegen. Zie [batchverwerking](../advanced/batch-processing).

## Werking

### Uitvoering

Stappen lopen opeenvolgend; de zijbalk meldt actieve stap en fouten. Annulering stopt volgende stappen en bereikt ondersteunde aanvragen. Voltooide bestanden blijven: geen transactie over de hele keten. De conceptmap is aanvankelijke voorkeur; batchgeneratie bewaart bron- en complete-map, waarna Mermaid de complete-map gebruikt. Andere acties behouden eisen aan bestand, selectie en interactie.

### DSL

Gebruik één benoemde knop per regel. `::` scheidt naam van acties, `>` scheidt actie-ID’s. Lege regels en regels die met `#` beginnen worden genegeerd; onbekende ID’s geweigerd.

```text
Extraheren en tekenen::extract-concepts-current>summarize-as-mermaid
```

Gebruik de workflowbouwer of bewerk de DSL. ID’s blijven stabiel; labels volgen de UI-taal. Mapvarianten hebben eigen ID’s en worden niet via willekeurige tekstvervanging afgeleid.

| ID | Actie / vereiste |
| ------------ | ----------------------- |
| `process-current-add-links` | Links toevoegen aan actieve notitie |
| `process-folder-add-links` | Links toevoegen in gekozen map |
| `extract-concepts-current` | Concepten uit actieve notitie |
| `extract-concepts-folder` | Concepten uit gekozen map |
| `generate-from-title` | Inhoud vanuit actieve titel |
| `batch-generate-from-titles` | Inhoud voor geschikte mapnotities |
| `research-and-summarize` | Selectie of titel onderzoeken in open Markdown-editor |
| `summarize-as-mermaid` | Ondersteunde actieve invoer als Mermaid samenvatten |
| `generate-diagram` | Selecteer meerdere diagramtypen per uitvoering en voor elk type meerdere uitvoerformaten. Uitvinken bewaart de formaten van dat type; zonder selectie wordt de inhoud automatisch geanalyseerd. |
| `preview-diagram` | Voorbeeld van ondersteunde bron of diagram |
| `translate-current-file` | Actief ondersteund bestand vertalen |
| `batch-translate-folder` | Gekozen map vertalen |
| `extract-original-text` | Gevraagde oorspronkelijke passages extraheren |
| `batch-extract-original-text` | Passages uit geschikte mapbestanden |
| `split-note-by-chapters` | Actieve notitie in hoofdstukken splitsen |
| `batch-mermaid-fix` | Mermaid-codeblokken in gekozen map herstellen |
| `fix-formula-current` | Formulescheiding in actieve notitie normaliseren |
| `batch-fix-formula` | Formulescheiding in map normaliseren |

### Standaard of eigen keten

One-Click Extract is vooraf ingesteld. Andere knoppen definieer je zelf. Zoek workflowinstellingen, kies naam en volgorde en controleer de tooltip in de zijbalk. Los parserfouten op voordat je op de keten vertrouwt.

## Instellingen

| Instelling | Beginwaarde | Effect |
| --------- | --------- | -------- |
| `customWorkflowErrorStrategy` | `stop_on_error` | Stoppen bij de eerste gemelde stapfout |
| `useMultiModelSettings` | `false` | Actieve provider totdat taakroutering aanstaat |
| `enableResearchInGenerateContent` | `false` | Geen onderzoek bij titelgeneratie totdat aangezet |

`continue_on_error` laat vervolgacties lopen na een fout. Gebruik dit alleen als ze met de resterende invoer kunnen werken. Doorgaan maakt een gedeeltelijke workflow niet succesvol.

### Modellen per stap

De keuze blijft bij de taak. Een lege override gebruikt het geconfigureerde model van de gekozen provider. Controleer alle routes voordat je privé-inhoud verwerkt.

## Voorbeeld

Configureer een lege `trial-concepts`, gebruik een wegwerpbron en controleer de concepten en gemelde complete-map. Voer acties eerst apart uit als de bestemming onduidelijk is. Vergroot scope na beoordeling.

## Tips

- Houd ketens kort genoeg om fouten en uitvoerherkomst te begrijpen.
- Verwijder- en opruimacties houden hun interactieve bevestiging; vermijd ze in onbeheerde ketens.
- Bekijk log en bestanden na annulering of herstelconflict.
- Test exact model en map: een verbindingstest bewijst geen toereikende quota voor lange batches.
