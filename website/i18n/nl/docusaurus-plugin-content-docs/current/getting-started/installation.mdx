# Installatie

<TLDR>Installeer Notemd via Community plugins of kopieer de drie uitvoerbestanden uit dezelfde GitHub Release naar je kluis. Schakel de plug-in in, stel een provider in en test een wegwerpnotitie. Modelservers en optionele native export vereisen afzonderlijke voorbereiding.</TLDR>

## Methode 1: Community plugins, aanbevolen

1. Open **Settings → Community plugins** in de bedoelde kluis.
2. Sta communityplug-ins zo nodig toe en kies **Browse**.
3. Zoek **Notemd**, controleer `Jacobinwwey/obsidian-NotEMD` en kies **Install**.
4. Kies **Enable** en open de zijbalk via het lint of opdrachtenpalet.

[Open Notemd in Obsidian](obsidian://show-plugin?id=notemd). Werkt de browserkoppeling niet, gebruik dan de menu’s hierboven. Voor deze handleiding is geen protocolkoppeling nodig.

## Methode 2: handmatig

### Voorwaarden

Gebruik een geïnstalleerde Obsidian en een kluis waarvan je een back-up kunt maken. Minimumversie `0.15.0` in het manifest is een declaratie, geen actuele test op die oude versie.

### Stappen

1. Download `main.js`, `manifest.json` en `styles.css` uit dezelfde [GitHub Release](https://github.com/Jacobinwwey/obsidian-NotEMD/releases/latest). `README.md` is naslagwerk en geen vereist uitvoerbestand.
2. Plaats de drie bestanden in `<vault>/.obsidian/plugins/notemd/`. Gebruik de werkelijke configuratiemap als die afwijkt.
3. Herlaad Obsidian en schakel Notemd in.
4. Controleer de versie; combineer geen nieuw manifest met een oude bundel.

## Alternatief: BRAT

Gebruik je al [BRAT](https://github.com/TfTHacker/obsidian42-brat), voeg dan de repository toe via zijn bètaplug-inprocedure. Kies een expliciete versie voor foutreproductie. BRAT is een optioneel extern hulpmiddel.

## Controle

Stel een bereikbare provider en model in, gebruik **Verbinding testen** en voer daarna de [eerste taak](./quick-start) uit. Een modellijsttest bewijst geen generatierechten; controleer ook de werkelijke uitvoer.

## Systeemvoorwaarden

| Onderdeel | Grens |
| --------- | ---------- |
| Manifest | Minimum Obsidian `0.15.0`; `isDesktopOnly` is false |
| Testbewijs | Zie het gedateerde releaseverslag; fysieke mobiele apparaten en 0.15.0 zijn niet actueel getest |
| Cloudmodel | Netwerk, toegestaan account/sleutel en model |
| Lokaal model | Afzonderlijk geïnstalleerde actieve server en geladen model |
| Native dia- en schakelingexport | Desktopgereedschap en formaatafhankelijke onderdelen; controleer eerst de omgeving |

Er is geen algemene OS-versiegarantie voor alle exporteurs. Een schakelingsvoorbeeld bewijst geen TeX-compilatie; desktoptests bewijzen geen mobiel gedrag.

## Verwijderen

Schakel Notemd uit of verwijder het via Community plugins. Gegenereerde notities en bestanden blijven in de kluis. Controleer ze voordat je iets wist en bewaar instellingen voor herinstallatie. Verwijderen draait voltooide bewerkingen niet terug.

## Bijwerken

Gebruik **Check for updates**. Handmatig: stop taken, maak een back-up van kluis en instellingen, vervang de drie uitvoerbestanden vanuit één release en herlaad. Lees de wijzigingen en test een kleine taak voordat je batches hervat. Vervang nooit je instellingenbestand door een releasebestand. Teruggaan vereist een bewust gekozen compatibele versie en bewaarde resultaten.
