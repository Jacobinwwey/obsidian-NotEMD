# China Providers

<TLDR>
Use the provider preset matching your account and deployment. Regional endpoint paths, model names and permissions are not interchangeable, even when providers expose the same OpenAI-compatible protocol. Verify a small task before choosing a provider for a workload.
</TLDR>

## Setup

Create an API account with the chosen provider, obtain its key, and select the corresponding Notemd preset. Confirm the account's endpoint region and model entitlement. Run **Test connection** and a disposable note task; preset defaults do not guarantee current model availability.

A key for one account region or subscription path may not work on another endpoint; use the provider's account instructions rather than choosing solely by your physical location.

## Model Discovery

Use model discovery where the provider permits it. Huawei Cloud MaaS uses deployment-aware discovery; other listed presets have OpenAI-compatible discovery paths where supported. Lack of listing permission does not necessarily mean an explicitly configured model cannot generate.

Connection-test behavior also differs by preset. DeepSeek can succeed from a model-list response alone, while several regional presets perform a short chat request. A real task remains necessary to verify its prompt and output requirements.

## Troubleshooting

- Key accepted but generation denied: check model entitlement, deployment and account region.
- Ark model rejected: confirm whether that endpoint expects a deployment ID or model ID.
- Truncated reasoning response: inspect requested output limits and provider-specific thinking settings.
- Network error: test the configured endpoint from the device running Obsidian and inspect the reported transport error.

## When To Use

Choose according to reachable account endpoints, data-handling requirements and measured task output. Region or model branding is not a quality, privacy or cost guarantee. [Provider overview](./overview) also lists gateways and local servers when those better match your deployment.
