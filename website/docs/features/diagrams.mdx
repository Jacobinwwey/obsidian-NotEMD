# Diagrams

<TLDR>
Choose **what kind of diagram you need**, then choose its **editable source format**. Preview the complete result in Obsidian, including a Drawnix board and its embedded Mermaid visuals, and export each panel as SVG, PNG, or PDF.
</TLDR>

## Understand the three choices

| Choice | What it controls | Examples |
|---|---|---|
| Diagram type | What the diagram means | Flowchart, sequence diagram, circuit diagram, data chart |
| Source format | The editable or reusable file that Notemd creates | Mermaid, JSON Canvas, Draw.io, Drawnix, CircuitikZ |
| Export format | The image or document used for sharing | SVG, PNG, PDF |

Draw.io and Drawnix are **source formats**, not diagram types. CircuitikZ is a source format designed for circuit diagrams. The same preview can be exported to several visual formats, so selecting CircuitikZ does not limit you to SVG.

## Choose a source format

| Format | Best for | Source file |
|---|---|---|
| Mermaid | Diagrams kept directly in Markdown | Mermaid code block |
| JSON Canvas | Native Obsidian canvas workflows | `.canvas` |
| Draw.io | Editing later in diagrams.net or compatible tools | `.drawio` |
| Drawnix | Hand-drawn or whiteboard-style editing | `.drawnix` |
| CircuitikZ | Structured electrical and transistor circuits | `.tex` |

Leave **Preferred source format** on **Auto** if you do not need a particular editor. Notemd chooses a compatible format for the selected diagram type.

## Generate and export a diagram

1. Open the note or select the text you want to visualize.
2. Choose **Generate diagram** from the Notemd sidebar or command palette.
3. Select a **diagram type**, or leave it on **Auto-detect**.
4. Select a **source format**, or leave it on **Auto**. Choose **Drawnix** when you want a knowledge map with editable nodes and embedded Mermaid visuals.
5. Review the preview. A multi-panel result keeps the Drawnix board and every Mermaid panel in source order inside one vertically scrollable preview shell; Mermaid panels use their rendered height instead of being clipped.
6. Choose a panel's **Export SVG**, **Export PNG**, or **Export PDF** action for one visual, or use a top-level image export for all panels. For multiple panels, choose the source folder or a custom Vault-relative folder; Notemd writes one deterministic file per panel and continues after an individual failure.
7. Use **Save source file** when you also need the editable artifact.

The Export menu provides **Export SVG**, **Export PNG**, and **Export PDF** actions for the current visual preview. Each panel header exposes the same actions for a single Mermaid or Drawnix visual, so a large preview does not have to be exported as one opaque image.

Choose **History** in the preview to open the Vault history drawer without hiding the diagram. You can search and filter completed diagrams, reopen a preview, or open saved artifacts. Diagram history is also available directly from the command palette and Notemd sidebar, even when no note is active.

SVG and PDF are produced from vector geometry; PDF uses the same SVG layout and text metrics instead of rasterizing the whole preview. The image export PPI in Notemd settings controls PNG rasterization only (72-600 PPI, 300 by default).

## Readable previews for dense diagrams

Editable HTML/SVG lane-grid diagrams measure and wrap the summary before placing the title and lane header. The header is moved below that protected summary region, and cells are painted before connectors and edge labels. Cross-lane edges use collision-aware orthogonal grid routes that reserve lane labels and occupied cells, so long descriptions do not hide text or force a user to pan sideways to understand the diagram.

Mermaid quadrant charts receive a family-specific normalization pass. Flowchart-only quote and shape repairs are skipped for `quadrantChart`, and a provider-copied opening bracket is removed only when it is the unmatched trailing character of a point label. Intentional brackets in titles, axes, and quadrant names remain visible.

The repository keeps a real-Vault learning and evidence set for every executable diagram type. See [`docs/diagram-examples/`](https://github.com/Jacobinwwey/obsidian-NotEMD/tree/main/docs/diagram-examples) for bilingual input notes, generated SVG/PNG results, and the machine-readable status manifest. `passed` entries represent a run through the loaded plugin bundle, not a static screenshot fixture.

The current executable catalog has 33 rows, while the plugin UI has 21 locales and the published website route set has 34 locales. These are different surfaces: UI locale count is not the same as published documentation locale count. Five exact reference grammars remain outside the selector until their layout contracts have independent evidence.

## Drawnix previews with embedded Mermaid

When a Drawnix artifact contains Mermaid visuals, Notemd sanitizes the rendered SVG and keeps the Mermaid source alongside it in the `.drawnix` metadata. The preview can therefore show the Mermaid image inside the Drawnix knowledge map without requiring the Drawnix or Plait runtime. The default path is self-contained and does not create a separate `.assets` directory. Enable **Also export complete Mermaid visuals** when you need Mermaid source, SVG, and manifest companions for handoff or external editing. Existing artifacts with `.assets` remain supported, and a missing legacy Mermaid SVG can be rebuilt from source text retained in metadata.

Resolved image embeds also receive a data-backed SVG preview when possible, so removing an old companion folder does not make a saved Drawnix preview disappear. Preview loading uses embedded data first, then legacy companion files, then the source-text rebuild fallback.

The preview is intentionally a single scrollable surface: the main Drawnix canvas appears first, followed by each embedded Mermaid panel in source order. Closing and reopening a saved history entry reconstructs the same panel list, dimensions, and export actions.

Drawnix relationship explanations are laid out as first-class visual elements. The renderer routes dashed arrows around placed node rectangles and reserves a measured title/summary header as a protected region. Long summaries and relation labels wrap to measured lines, the forest moves below the resulting header height, and an opaque label box is painted after the node layer. The header is rendered last with an opaque background, so an outer route cannot obscure text such as `以 Notemd 插件为对象的知识地图，覆盖系统架构、LLM 调用管道、图表渲染平台、模块地图、CLI 边界现实、关键设计决策与验证。` or a relation explanation such as `RendererRegistry feeds Vault files, preview modal, and export`. The native `.drawnix` arrow uses Plait-compatible `shape`, `texts[]`, markers, and stroke fields while retaining legacy metadata for older readers. If a requested Drawnix map cannot find a collision-free route or label position, generation fails with a format error instead of silently saving a Mermaid fallback under a `.drawnix` operation.

## Circuit diagrams

Choose **Circuit diagram** with **CircuitikZ source file** for supported circuit requests. Notemd generates a structured circuit description first and then writes the CircuitikZ source. This is more reliable than asking the model to write unrestricted LaTeX.

Current CircuitikZ support is intentionally constrained. Common-source NMOS amplifiers and supported CMOS building blocks work best. Always inspect the preview and source before using a generated circuit in technical or publication work.

The SVG preview is a review companion generated by Notemd. It is not proof that a local LaTeX or TikZJax installation compiled the `.tex` file successfully.

**Optional native compilation.** You do not need LaTeX for the in-plugin preview or SVG, PNG, and preview PDF export. On desktop, open **CircuitikZ native compile environment** from diagram settings or the command palette when you need compile diagnostics or a native LaTeX PDF. Notemd can reuse a system `tectonic` or `pdflatex`, use a custom executable, or install the pinned managed Tectonic runtime after you explicitly choose **Install**. The environment panel shows progress and errors inline and lets you remove the managed runtime later.

## Troubleshooting

### The result is the wrong diagram type

Select the diagram type explicitly instead of using Auto-detect. For a circuit, choose **Circuit diagram** and use the **Generate diagram** command, not the legacy **Summarise as Mermaid diagram** command.

### A source format is unsuitable

Return the source format to **Auto**, or choose a format intended for that diagram type. CircuitikZ is for circuit diagrams; Draw.io and Drawnix are intended for supported structured diagrams.

### The Export menu is missing

SVG, PNG, and PDF require a visual preview. If only source text is available, save the source file and open it in the matching external tool.

### A CircuitikZ file does not compile externally

Open **CircuitikZ native compile environment** and run the environment check. Repair the managed runtime or verify that your custom/system compiler can obtain the `circuitikz` package. Notemd does not bundle a complete TeX distribution inside the plugin file.
